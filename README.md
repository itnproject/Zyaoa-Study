> Zyaoa-Study是一个使用HTML/CSS/JavaScript编写的初中数学在线学习平台。专注于提供简洁美观的学习体验，支持Markdown内容渲染和数学公式显示。由于这是itnproject制作的学习平台项目，出现bug可以在Issues提交问题，你的提交是完善项目的最大帮助！

# 项目介绍
* 这是什么：一个使用HTML/CSS/JavaScript编写的初中数学在线学习平台。
* 有何不同：
  * 简洁现代的UI设计
  * 支持深色模式
  * Markdown内容渲染
  * KaTeX数学公式支持
  * 树形导航结构
  * 搜索功能
  * 纯前端，无需后端
* 支持年级：七年级、八年级、九年级

# 项目帮助
#### 如何本地运行？
答：直接用浏览器打开index.html即可。
#### 我在使用时出现问题怎么反馈？
答：提交Issues。最好截图，描述完全。

> [!TIP]
> 太猎奇的问题不要提交Issues，以免引人嘲笑😂
