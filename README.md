> Zyaoa-Study是一个使用HTML/CSS/JavaScript编写的初中数学在线学习平台。专注于提供简洁美观的学习体验，支持Markdown内容渲染和数学公式显示。出现bug可以在Issues提交问题，你的提交是完善项目的最大帮助！

# 项目介绍
* 这是什么：一个使用HTML/CSS/JavaScript编写的初中数学在线学习平台。
* 有何不同：
  * 简洁现代的UI设计
  * 支持深色模式
  * Markdown内容渲染
  * KaTeX数学公式支持
  * 树形导航结构
  * 搜索功能
  * 纯前端，无需后端
* 支持年级：七年级、八年级、九年级
