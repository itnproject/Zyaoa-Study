# 陆地与海洋

## 学习目标

- 了解海陆分布
- 认识七大洲和四大洋
- 理解板块构造学说

## 海陆分布

- 地球表面71%是海洋，29%是陆地
- "七分海洋，三分陆地"
- 陆地主要集中在北半球

## 板块构造学说

### 基本观点

- 地球岩石圈由六大板块组成
- 板块在不断运动
- 板块内部比较稳定，板块交界处地壳活跃

### 六大板块

| 板块 | 范围 |
|------|------|
| 亚欧板块 | 亚洲和欧洲大部分 |
| 非洲板块 | 非洲 |
| 美洲板块 | 北美洲和南美洲 |
| 太平洋板块 | 太平洋大部分 |
| 印度洋板块 | 印度洋、澳大利亚、印度 |
| 南极洲板块 | 南极洲 |

### 板块运动的结果

- **碰撞挤压**：形成山脉（如喜马拉雅山脉）
- **张裂拉伸**：形成裂谷或海洋（如东非大裂谷）

## 小结

地球表面七分海洋三分陆地，七大洲四大洋构成了地球的海陆分布，板块运动塑造了地表形态。
