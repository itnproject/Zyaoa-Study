# 中国的经济发展

## 学习目标

- 了解中国的农业分布
- 认识中国的工业发展
- 理解交通运输的重要性

## 农业

### 农业的部门

- 种植业
- 林业
- 畜牧业
- 渔业

### 农业分布

| 地区 | 主要农业类型 | 主要作物 |
|------|-------------|----------|
| 东部平原 | 种植业 | 水稻、小麦、玉米 |
| 东北 | 商品粮基地 | 小麦、玉米、大豆 |
| 南方 | 水田农业 | 水稻、油菜 |
| 北方 | 旱地农业 | 小麦、棉花 |
| 西北 | 畜牧业 | 牛羊 |
| 青藏 | 高寒畜牧业 | 牦牛、藏绵羊 |

### 秦岭-淮河一线的地理意义

- 南方与北方的分界线
- 水田与旱地的分界线
- 800毫米年等降水量线
- 1月0°C等温线
- 亚热带与暖温带的分界线

## 工业

### 工业分布特点

- 东部沿海地区工业发达
- 中西部地区工业相对落后
- 形成了四大工业基地

### 四大工业基地

| 工业基地 | 位置 | 特点 |
|----------|------|------|
| 辽中南工业基地 | 辽宁中南部 | 重工业为主 |
| 京津唐工业基地 | 北京、天津、唐山 | 综合性工业基地 |
| 沪宁杭工业基地 | 上海、南京、杭州 | 全国最大综合性工业基地 |
| 珠江三角洲工业基地 | 广东珠江三角洲 | 轻工业为主，外向型经济 |

### 高新技术产业

- 分布：多依附于大城市，呈大分散、小集中特点
- 代表：北京中关村（中国硅谷）

## 交通运输

### 主要运输方式

| 运输方式 | 优点 | 缺点 | 适用 |
|----------|------|------|------|
| 铁路 | 运量大、运费低 | 灵活性差 | 长途大宗货物 |
| 公路 | 灵活方便 | 运量小、运费高 | 短途运输 |
| 水路 | 运量大、运费最低 | 速度慢 | 大宗货物、长途 |
| 航空 | 速度快 | 运费高、运量小 | 贵重、急需物品 |
| 管道 | 连续性强 | 灵活性差 | 石油、天然气 |

### 主要铁路干线

| 干线 | 起止点 | 走向 |
|------|--------|------|
| 京沪线 | 北京-上海 | 南北 |
| 京广线 | 北京-广州 | 南北 |
| 京九线 | 北京-九龙 | 南北 |
| 陇海线 | 连云港-兰州 | 东西 |
| 兰新线 | 兰州-乌鲁木齐 | 东西 |
| 沪昆线 | 上海-昆明 | 东西 |
