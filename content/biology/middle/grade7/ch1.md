# 认识生物

## 学习目标

- 了解生物的基本特征
- 能区分生物和非生物
- 认识生物的多样性

## 生物的基本特征

### 1. 生物的生活需要营养

- 植物通过光合作用制造有机物
- 动物从外界获取现成的有机物

### 2. 生物能进行呼吸

- 吸入氧气，呼出二氧化碳
- 呼吸作用是生物的共同特征

### 3. 生物能排出体内产生的废物

- 动物通过排尿、出汗、呼出气体排出废物
- 植物通过落叶排出废物

### 4. 生物能对外界刺激作出反应

- 含羞草受到触碰会合拢叶片
- 草履虫能逃避有害刺激

### 5. 生物能生长和繁殖

- 生物体由小长大
- 生物能产生后代

### 6. 生物都有遗传和变异的特性

- 种瓜得瓜，种豆得豆（遗传）
- 一母生九子，连母十个样（变异）

## 生物与非生物的区别

| 特征 | 生物 | 非生物 |
|------|------|--------|
| 需要营养 | ✓ | ✗ |
| 能呼吸 | ✓ | ✗ |
| 能排出废物 | ✓ | ✗ |
| 能对外界刺激作出反应 | ✓ | ✗ |
| 能生长和繁殖 | ✓ | ✗ |
| 有遗传和变异 | ✓ | ✗ |

## 生物的多样性

地球上已知的生物约有200多万种，包括：

- **植物**：藻类、苔藓、蕨类、种子植物
- **动物**：无脊椎动物、脊椎动物
- **微生物**：细菌、真菌、病毒

## 练习

1. 珊瑚是生物吗？为什么？
2. 列举生物的三个基本特征。
3. 钟乳石能慢慢长大，它是生物吗？

## 小结

生物具有营养、呼吸、排泄、应激性、生长繁殖、遗传变异等基本特征，这些特征将生物与非生物区分开来。
