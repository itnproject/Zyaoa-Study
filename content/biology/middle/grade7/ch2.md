# 细胞

## 学习目标

- 认识细胞的基本结构
- 了解动植物细胞的区别
- 理解细胞是生命活动的基本单位

## 细胞的基本结构

### 动物细胞

| 结构 | 功能 |
|------|------|
| 细胞膜 | 保护细胞，控制物质进出 |
| 细胞质 | 细胞生命活动的主要场所 |
| 细胞核 | 含有遗传物质，控制细胞的生命活动 |
| 线粒体 | 呼吸作用的场所，提供能量 |

### 植物细胞

植物细胞比动物细胞多了以下结构：

| 结构 | 功能 |
|------|------|
| 细胞壁 | 保护和支持细胞 |
| 叶绿体 | 光合作用的场所 |
| 液泡 | 储存营养物质和水分 |

## 动植物细胞的区别

| 结构 | 动物细胞 | 植物细胞 |
|------|----------|----------|
| 细胞壁 | 无 | 有 |
| 细胞膜 | 有 | 有 |
| 细胞质 | 有 | 有 |
| 细胞核 | 有 | 有 |
| 叶绿体 | 无 | 有 |
| 液泡 | 无（或小） | 有（大液泡） |
| 线粒体 | 有 | 有 |

## 细胞是生命活动的基本单位

- 除病毒外，生物都是由细胞构成的
- 细胞是生物体结构和功能的基本单位
- 细胞通过分裂产生新细胞

## 练习

1. 植物细胞特有的结构有哪些？
2. 细胞核的功能是什么？
3. 病毒是细胞构成的吗？

## 小结

细胞是生命活动的基本单位，动植物细胞有共同结构也有不同之处，植物细胞特有细胞壁、叶绿体和大液泡。
