# 12.2.4 AAS（角角边）

## 一、从三角形内角和引入

我们知道三角形内角和是180°。

如果知道两个角，第三个角也就确定了。

所以，如果两个三角形有两个角和其中一个角的对边对应相等，它们一定全等。

这就是AAS判定。

## 二、AAS判定方法

**判定定理：两角和其中一个角的对边对应相等的两个三角形全等**

简记为AAS或"角角边"。

在△ABC和△DEF中：

∠A = ∠D

∠B = ∠E

BC = EF（BC是∠A的对边，EF是∠D的对边）

∴ △ABC≌△DEF（AAS）

## 三、AAS可由ASA推出

**推导过程**

在△ABC和△DEF中，

已知∠A = ∠D，∠B = ∠E

由三角形内角和定理：

∠C = 180° - ∠A - ∠B

∠F = 180° - ∠D - ∠E

因为∠A = ∠D，∠B = ∠E

所以∠C = ∠F

又已知BC = EF

所以可以用ASA：

∠B = ∠E，BC = EF，∠C = ∠F

∴ △ABC≌△DEF（ASA）

因此AAS本质上是ASA的推论。

## 四、ASA和AAS的区别

**ASA：两角和它们的夹边**

边在两个角的中间。

比如∠B、BC、∠C，BC是∠B和∠C的夹边。

**AAS：两角和其中一个角的对边**

边不在两个角的中间。

比如∠A、∠B、BC，BC是∠A的对边，不是∠A和∠B的夹边。

**记忆方法**

ASA：角-边-角，边在中间。

AAS：角-角-边，边在旁边。

## 五、几何书写格式

**标准证明格式**

在△ABC和△DEF中，

∠A = ∠D（已知）

∠B = ∠E（已知）

BC = EF（已知）

∴ △ABC≌△DEF（AAS）

## 六、例题讲解

**例题1：** 如图，∠A = ∠D，∠B = ∠E，BC = EF。求证：△ABC≌△DEF。

∴ △ABC≌△DEF（AAS）

**例题2：** 如图，AB⊥BC，DE⊥EF，AC = DF，∠A = ∠D。求证：△ABC≌△DEF。

证明：

∵ AB⊥BC，DE⊥EF

∴ ∠B = ∠E = 90°

在△ABC和△DEF中，

∠A = ∠D（已知）

∠B = ∠E = 90°（已证）

AC = DF（已知）

∴ △ABC≌△DEF（AAS）

**例题3：** 如图，∠1 = ∠2，∠C = ∠D。求证：AC = AD。

证明：

在△ABC和△ABD中，

∠1 = ∠2（已知）

∠C = ∠D（已知）

AB = AB（公共边）

∴ △ABC≌△ABD（AAS）

∴ AC = AD（全等三角形的对应边相等）

**例题4：** 如图，AB // DE，∠A = ∠D，BF = EC。求证：△ABC≌△DEF。

证明：

∵ AB // DE

∴ ∠B = ∠E（两直线平行，内错角相等）

∵ BF = EC

∴ BF + FC = EC + FC

即BC = EF

在△ABC和△DEF中，

∠A = ∠D（已知）

∠B = ∠E（已证）

BC = EF（已证）

∴ △ABC≌△DEF（AAS）

**例题5：** 如图，BE⊥AC，CF⊥AB，BE = CF。求证：AB = AC。

证明：

∵ BE⊥AC，CF⊥AB

∴ ∠AEB = ∠AFC = 90°

在△ABE和△ACF中，

∠A = ∠A（公共角）

∠AEB = ∠AFC = 90°（已证）

BE = CF（已知）

∴ △ABE≌△ACF（AAS）

∴ AB = AC（全等三角形的对应边相等）

## 七、常见错误

**错误1：ASA和AAS混淆**

错误做法：把AAS写成ASA。

正确理解：边是夹边用ASA，边是对边用AAS。

**错误2：对边找错**

错误做法：认为BC是∠B的对边。

正确理解：BC是∠A的对边，AC是∠B的对边，AB是∠C的对边。

**错误3：忽略公共边**

错误做法：没有发现公共边这个隐含条件。

正确理解：公共边是常用的隐含条件。

**错误4：没有注明判定方法**

错误做法：直接写∴ △ABC≌△DEF。

正确做法：写∴ △ABC≌△DEF（AAS）。

**错误5：直角三角形用错**

错误做法：直角三角形中，已知一直角边和一锐角对应相等，不用AAS。

正确理解：这种情况可以用AAS。
