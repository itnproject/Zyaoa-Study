# 12.2.1 SSS（边边边）

## 一、从生活实例引入

给你三根长度固定的木棍。

用这三根木棍拼一个三角形。

你会发现，无论怎么拼，只能拼出一种形状的三角形。

这就是SSS判定的直观理解。

三边确定了，三角形就唯一确定了。

## 二、SSS判定方法

**判定定理：三边对应相等的两个三角形全等**

简记为SSS或"边边边"。

在△ABC和△DEF中：

AB = DE

BC = EF

CA = FD

∴ △ABC≌△DEF（SSS）

## 三、几何书写格式

**标准证明格式**

在△ABC和△DEF中，

AB = DE（已知）

BC = EF（已知）

CA = FD（已知）

∴ △ABC≌△DEF（SSS）

## 四、尺规作图：已知三边作三角形

已知线段a、b、c，求作△ABC，使BC = a，AC = b，AB = c。

步骤：

第一步：作线段BC = a。

第二步：以B为圆心，c为半径画弧。

第三步：以C为圆心，b为半径画弧。

第四步：两弧交于点A。

第五步：连接AB、AC。

△ABC即为所求。

## 五、三角形的稳定性与SSS的关系

三角形具有稳定性，就是因为SSS判定。

三边确定后，三角形唯一确定，形状不会改变。

这就是为什么桥梁、自行车架等都用三角形结构。

## 六、例题讲解

**例题1：** 如图，AB = AD，BC = DC。求证：△ABC≌△ADC。

证明：

在△ABC和△ADC中，

AB = AD（已知）

BC = DC（已知）

AC = AC（公共边）

∴ △ABC≌△ADC（SSS）

**例题2：** 如图，点B、E、C、F在一条直线上，AB = DE，AC = DF，BE = CF。求证：△ABC≌△DEF。

证明：

∵ BE = CF

∴ BE + EC = CF + EC

即BC = EF

在△ABC和△DEF中，

AB = DE（已知）

AC = DF（已知）

BC = EF（已证）

∴ △ABC≌△DEF（SSS）

**例题3：** 如图，AB = CD，AD = CB。求证：∠A = ∠C。

证明：

连接BD。

在△ABD和△CDB中，

AB = CD（已知）

AD = CB（已知）

BD = DB（公共边）

∴ △ABD≌△CDB（SSS）

∴ ∠A = ∠C（全等三角形的对应角相等）

**例题4：** 如图，AC = BD，AD = BC。求证：△ACD≌△BDC。

证明：

在△ACD和△BDC中，

AC = BD（已知）

AD = BC（已知）

CD = DC（公共边）

∴ △ACD≌△BDC（SSS）

**例题5：** 如图，AB = AC，D是BC的中点。求证：AD平分∠BAC。

证明：

∵ D是BC的中点

∴ BD = CD

在△ABD和△ACD中，

AB = AC（已知）

BD = CD（已证）

AD = AD（公共边）

∴ △ABD≌△ACD（SSS）

∴ ∠BAD = ∠CAD（全等三角形的对应角相等）

∴ AD平分∠BAC

## 七、常见错误

**错误1：用SSA判定全等**

错误做法：两边和其中一边的对角对应相等，认为全等。

正确理解：SSA不能判定全等，只有SAS（两边和夹角）才能判定。

**错误2：漏掉公共边**

错误做法：证明时没有写出公共边这个条件。

正确做法：公共边是隐含条件，必须写出来。

**错误3：对应边写错**

错误做法：AB = DF，BC = DE。

正确做法：对应边要对应好，AB = DE，BC = EF。

**错误4：没有注明判定方法**

错误做法：直接写∴ △ABC≌△DEF。

正确做法：写∴ △ABC≌△DEF（SSS）。

**错误5：三边条件不够就用SSS**

错误做法：只找到两组对应边相等，就用SSS。

正确做法：必须三组对应边都相等才能用SSS。

## 八、练习题

**练习1：** 如图，AB = DE，BC = EF，AC = DF。求证：△ABC≌△DEF。

证明：

在△ABC和△DEF中，

AB = DE（已知）

BC = EF（已知）

AC = DF（已知）

∴ △ABC≌△DEF（SSS）

**练习2：** 如图，AB = AD，CB = CD。求证：∠B = ∠D。

证明：

连接AC。

在△ABC和△ADC中，

AB = AD（已知）

CB = CD（已知）

AC = AC（公共边）

∴ △ABC≌△ADC（SSS）

∴ ∠B = ∠D（全等三角形的对应角相等）

**练习3：** 如图，点A、D、B、E在一条直线上，AD = BE，AC = DF，BC = EF。求证：△ABC≌△DEF。

证明：

∵ AD = BE

∴ AD + DB = BE + DB

即AB = DE

在△ABC和△DEF中，

AB = DE（已证）

AC = DF（已知）

BC = EF（已知）

∴ △ABC≌△DEF（SSS）

**练习4：** 如图，AB = AC，DB = DC。求证：AD⊥BC。

证明：

在△ABD和△ACD中，

AB = AC（已知）

DB = DC（已知）

AD = AD（公共边）

∴ △ABD≌△ACD（SSS）

∴ ∠ADB = ∠ADC

∵ ∠ADB + ∠ADC = 180°

∴ ∠ADB = ∠ADC = 90°

∴ AD⊥BC

**练习5：** 如图，OA = OB，CA = CB。求证：OC平分∠AOB。

证明：

在△OAC和△OBC中，

OA = OB（已知）

CA = CB（已知）

OC = OC（公共边）

∴ △OAC≌△OBC（SSS）

∴ ∠AOC = ∠BOC（全等三角形的对应角相等）

∴ OC平分∠AOB
