# 12.2.6 判定方法的选择与综合运用

## 一、五种判定方法对比

**SSS（边边边）**

条件：三边对应相等

适用：已知三组边相等

**SAS（边角边）**

条件：两边和它们的夹角对应相等

适用：已知两组边相等和它们的夹角相等

**ASA（角边角）**

条件：两角和它们的夹边对应相等

适用：已知两组角相等和它们的夹边相等

**AAS（角角边）**

条件：两角和其中一个角的对边对应相等

适用：已知两组角相等和一组对边相等

**HL（斜边直角边）**

条件：斜边和一条直角边对应相等

适用：只适用于直角三角形

## 二、根据已知条件选择方法

**已知两边**

找夹角，用SAS。

找第三边，用SSS。

**已知一边两角**

找夹边，用ASA。

找对边，用AAS。

**已知两角**

只能用ASA或AAS。

需要找边的条件。

**已知三边**

直接用SSS。

**直角三角形**

优先看能否用HL。

也可以用其他四种方法。

## 三、多次证明的思路

有些题目需要多次证明三角形全等。

先证一对三角形全等。

利用所得结论（对应边相等或对应角相等）。

再证另一对三角形全等。

## 四、例题讲解

**例题1：** 如图，AB = AC，AD = AE，∠BAD = ∠CAE。求证：△ABD≌△ACE。

证明：

在△ABD和△ACE中，

AB = AC（已知）

∠BAD = ∠CAE（已知）

AD = AE（已知）

∴ △ABD≌△ACE（SAS）

**例题2：** 如图，AB = CD，AD = BC。求证：AB // CD。

证明：

连接AC。

在△ABC和△CDA中，

AB = CD（已知）

BC = DA（已知）

AC = CA（公共边）

∴ △ABC≌△CDA（SSS）

∴ ∠BAC = ∠DCA（全等三角形的对应角相等）

∴ AB // CD（内错角相等，两直线平行）

**例题3：** 如图，点B、E、C、F在一条直线上，AB = DE，∠A = ∠D，∠B = ∠DEF。求证：BE = CF。

证明：

在△ABC和△DEF中，

∠A = ∠D（已知）

AB = DE（已知）

∠B = ∠DEF（已知）

∴ △ABC≌△DEF（ASA）

∴ BC = EF（全等三角形的对应边相等）

∴ BC - EC = EF - EC

即BE = CF

**例题4：** 如图，AB = AC，D是BC的中点，DE⊥AB于E，DF⊥AC于F。求证：DE = DF。

证明：

∵ D是BC的中点

∴ BD = CD

在△ABD和△ACD中，

AB = AC（已知）

BD = CD（已证）

AD = AD（公共边）

∴ △ABD≌△ACD（SSS）

∴ ∠B = ∠C（全等三角形的对应角相等）

∵ DE⊥AB，DF⊥AC

∴ ∠BED = ∠CFD = 90°

在△BDE和△CDF中，

∠BED = ∠CFD = 90°（已证）

∠B = ∠C（已证）

BD = CD（已证）

∴ △BDE≌△CDF（AAS）

∴ DE = DF（全等三角形的对应边相等）

**例题5：** 如图，在△ABC中，AB = AC，∠BAC = 90°，D是BC的中点，E、F分别在AB、AC上，且BE = AF。求证：DE = DF。

证明：

连接AD。

∵ AB = AC，∠BAC = 90°，D是BC的中点

∴ AD = BD = CD（等腰直角三角形斜边中线等于斜边一半）

∠B = ∠C = 45°

∠BAD = ∠CAD = 45°

在△BDE和△ADF中，

BD = AD（已证）

∠B = ∠DAF = 45°（已证）

BE = AF（已知）

∴ △BDE≌△ADF（SAS）

∴ DE = DF（全等三角形的对应边相等）

## 五、常见错误

**错误1：判定方法选错**

错误做法：已知两边和一角，不管是不是夹角，都用SAS。

正确做法：角必须是夹角才能用SAS，否则用其他方法。

**错误2：多次证明时漏掉中间步骤**

错误做法：直接跳到最终结论。

正确做法：先证第一对全等，写出结论，再证第二对全等。

**错误3：忽略隐含条件**

错误做法：没有发现公共边、公共角、对顶角等隐含条件。

正确做法：仔细分析图形，找出所有隐含条件。

**错误4：全等后对应关系搞错**

错误做法：全等后直接写对应边相等，但对应关系错了。

正确做法：根据全等符号的对应关系写对应边和对应角。

**错误5：条件不够强行证明**

错误做法：条件不够，强行用某个判定方法。

正确做法：条件不够时，需要先推导更多条件。

## 六、练习题

**练习1：** 如图，AB = DE，AC = DF，BE = CF。求证：△ABC≌△DEF。

证明：

∵ BE = CF

∴ BE + EC = CF + EC

即BC = EF

在△ABC和△DEF中，

AB = DE（已知）

AC = DF（已知）

BC = EF（已证）

∴ △ABC≌△DEF（SSS）

**练习2：** 如图，AB = AD，∠BAC = ∠DAC。求证：BC = DC。

证明：

在△ABC和△ADC中，

AB = AD（已知）

∠BAC = ∠DAC（已知）

AC = AC（公共边）

∴ △ABC≌△ADC（SAS）

∴ BC = DC（全等三角形的对应边相等）

**练习3：** 如图，∠B = ∠D = 90°，AB = CD。求证：△ABC≌△CDA。

证明：

在Rt△ABC和Rt△CDA中，

AC = CA（公共边，斜边）

AB = CD（已知，直角边）

∴ Rt△ABC≌Rt△CDA（HL）

**练习4：** 如图，AB = AC，∠B = ∠C，D、E分别在AB、AC上，且BD = CE。求证：AD = AE。

证明：

在△ABD和△ACE中，

AB = AC（已知）

∠B = ∠C（已知）

BD = CE（已知）

∴ △ABD≌△ACE（SAS）

∴ AD = AE（全等三角形的对应边相等）

**练习5：** 如图，AB = AC，D是BC上一点，DE⊥AB于E，DF⊥AC于F，DE = DF。求证：BD = CD。

证明：

∵ DE⊥AB，DF⊥AC

∴ ∠AED = ∠AFD = 90°

在Rt△ADE和Rt△ADF中，

DE = DF（已知）

AD = AD（公共边）

∴ Rt△ADE≌Rt△ADF（HL）

∴ ∠DAE = ∠DAF

即AD平分∠BAC

在△ABD和△ACD中，

AB = AC（已知）

∠BAD = ∠CAD（已证）

AD = AD（公共边）

∴ △ABD≌△ACD（SAS）

∴ BD = CD（全等三角形的对应边相等）
