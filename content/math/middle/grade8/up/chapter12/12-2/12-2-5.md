# 12.2.5 HL（斜边直角边）

## 一、从生活实例引入

你有两个直角三角形的木框。

你量了它们的斜边，一样长。

你又量了其中一条直角边，也一样长。

你会发现，这两个直角三角形完全一样。

这就是HL判定。

## 二、HL判定方法

**判定定理：斜边和一条直角边对应相等的两个直角三角形全等**

简记为HL或"斜边直角边"。

在Rt△ABC和Rt△DEF中（∠C = ∠F = 90°）：

AB = DE（斜边）

AC = DF（直角边）

∴ Rt△ABC≌Rt△DEF（HL）

**重要：HL只适用于直角三角形**

普通三角形不能用HL判定。

必须先在题目中确认是直角三角形。

## 三、为什么直角三角形可以用HL

**理解**

普通三角形中，SSA不能判定全等。

但直角三角形中，已知一个角是90°，情况就不同了。

根据勾股定理，已知斜边和一条直角边，另一条直角边也就确定了。

所以三条边都确定了，三角形唯一确定。

**用勾股定理解释**

在Rt△ABC中，已知AB和AC。

由勾股定理：BC = √(AB² - AC²)

所以BC也确定了。

三边都确定，由SSS可知三角形全等。

## 四、几何书写格式

**标准证明格式**

在Rt△ABC和Rt△DEF中，

AB = DE（已知）

AC = DF（已知）

∴ Rt△ABC≌Rt△DEF（HL）

**注意：必须先注明是直角三角形**

## 五、四种通用判定方法+HL的对比

**通用判定方法（适用于所有三角形）**

SSS：三边对应相等

SAS：两边和夹角对应相等

ASA：两角和夹边对应相等

AAS：两角和对边对应相等

**直角三角形专用判定方法**

HL：斜边和一条直角边对应相等

**直角三角形可以用所有五种方法**

通用四种+HL，共五种。

## 六、例题讲解

**例题1：** 如图，∠C = ∠F = 90°，AB = DE，AC = DF。求证：Rt△ABC≌Rt△DEF。

证明：

在Rt△ABC和Rt△DEF中，

AB = DE（已知）

AC = DF（已知）

∴ Rt△ABC≌Rt△DEF（HL）

**例题2：** 如图，AC⊥BC，BD⊥AD，AC = BD。求证：BC = AD。

证明：

∵ AC⊥BC，BD⊥AD

∴ ∠C = ∠D = 90°

在Rt△ABC和Rt△BAD中，

AB = BA（公共边，斜边）

AC = BD（已知，直角边）

∴ Rt△ABC≌Rt△BAD（HL）

∴ BC = AD（全等三角形的对应边相等）

**例题3：** 如图，AB = CD，BE⊥AC于E，DF⊥AC于F，BE = DF。求证：AE = CF。

证明：

∵ BE⊥AC，DF⊥AC

∴ ∠AEB = ∠CFD = 90°

在Rt△ABE和Rt△CDF中，

AB = CD（已知）

BE = DF（已知）

∴ Rt△ABE≌Rt△CDF（HL）

∴ AE = CF（全等三角形的对应边相等）

**例题4：** 如图，∠B = ∠D = 90°，AB = CD，AC和BD相交于点O。求证：OA = OC。

证明：

在Rt△ABC和Rt△CDA中，

AC = CA（公共边，斜边）

AB = CD（已知，直角边）

∴ Rt△ABC≌Rt△CDA（HL）

∴ BC = DA（全等三角形的对应边相等）

在△AOB和△COD中，

∠B = ∠D = 90°（已知）

∠AOB = ∠COD（对顶角相等）

AB = CD（已知）

∴ △AOB≌△COD（AAS）

∴ OA = OC（全等三角形的对应边相等）

**例题5：** 如图，AB = AC，AD⊥BC于D。求证：BD = CD。

解：

这不是HL的典型应用，因为AD是公共边。

∵ AD⊥BC

∴ ∠ADB = ∠ADC = 90°

在Rt△ABD和Rt△ACD中，

AB = AC（已知）

AD = AD（公共边）

∴ Rt△ABD≌Rt△ACD（HL）

∴ BD = CD（全等三角形的对应边相等）

## 七、常见错误

**错误1：用HL判定非直角三角形**

错误做法：普通三角形中，用两边和一角对应相等，写HL。

正确理解：HL只适用于直角三角形。

**错误2：没有注明直角**

错误做法：直接写△ABC≌△DEF（HL）。

正确做法：先写"在Rt△ABC和Rt△DEF中"，再写HL。

**错误3：斜边和直角边搞混**

错误做法：把直角边当成斜边。

正确理解：斜边是直角所对的边，是最长的边。

**错误4：HL和SAS混淆**

错误做法：直角三角形中，用两条直角边和夹角，写HL。

正确理解：两条直角边和夹角用SAS，斜边和直角边用HL。

**错误5：忽略公共斜边**

错误做法：两个直角三角形共用斜边，没有发现这个条件。

正确理解：公共斜边是隐含条件。

## 八、练习题

**练习1：** 如图，∠C = ∠D = 90°，AB = AB，AC = BD。求证：Rt△ABC≌Rt△BAD。

证明：

在Rt△ABC和Rt△BAD中，

AB = BA（公共边，斜边）

AC = BD（已知，直角边）

∴ Rt△ABC≌Rt△BAD（HL）

**练习2：** 如图，CE⊥AB于E，BF⊥AC于F，CE = BF。求证：AB = AC。

证明：

在Rt△BCE和Rt△CBF中，

BC = CB（公共边，斜边）

CE = BF（已知，直角边）

∴ Rt△BCE≌Rt△CBF（HL）

∴ ∠B = ∠C（全等三角形的对应角相等）

在△ABC中，∠B = ∠C

∴ AB = AC（等角对等边）

**练习3：** 如图，∠A = ∠D = 90°，AB = DC，AC和BD相交于点O。求证：OB = OC。

证明：

在Rt△ABC和Rt△DCB中，

BC = CB（公共边，斜边）

AB = DC（已知，直角边）

∴ Rt△ABC≌Rt△DCB（HL）

∴ ∠ACB = ∠DBC（全等三角形的对应角相等）

在△OBC中，∠OCB = ∠OBC

∴ OB = OC（等角对等边）

**练习4：** 如图，AD⊥BC，BE⊥AC，AD = BE。求证：AC = BC。

证明：

在Rt△ADC和Rt△BEC中，

∠ADC = ∠BEC = 90°（已知）

∠C = ∠C（公共角）

AD = BE（已知）

∴ △ADC≌△BEC（AAS）

∴ AC = BC（全等三角形的对应边相等）

**练习5：** 如图，AB = AD，AC = AE，∠B = ∠D = 90°。求证：BC = DE。

证明：

在Rt△ABC和Rt△ADE中，

AC = AE（已知，斜边）

AB = AD（已知，直角边）

∴ Rt△ABC≌Rt△ADE（HL）

∴ BC = DE（全等三角形的对应边相等）
