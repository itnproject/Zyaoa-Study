# 12.2.2 SAS（边角边）

## 一、从生活实例引入

给你两根长度固定的木棍和一个固定角度。

把两根木棍按这个角度拼在一起。

你会发现，只能拼出一种形状的三角形。

这就是SAS判定的直观理解。

## 二、SAS判定方法

**判定定理：两边和它们的夹角对应相等的两个三角形全等**

简记为SAS或"边角边"。

在△ABC和△DEF中：

AB = DE

∠B = ∠E

BC = EF

∴ △ABC≌△DEF（SAS）

**重要：角必须是两边的夹角**

在△ABC中，AB和BC的夹角是∠B。

在△DEF中，DE和EF的夹角是∠E。

如果给的角不是夹角，就不能用SAS。

## 三、SSA不能判定全等

**反例说明**

画一个△ABC，AB = 5cm，BC = 4cm，∠A = 30°。

以B为圆心，4cm为半径画弧。

这条弧可能与AC有两个交点。

也就是说，满足AB = 5cm，BC = 4cm，∠A = 30°的三角形可以有两个。

所以SSA不能判定全等。

**结论：两边和其中一边的对角对应相等，不能判定全等**

## 四、几何书写格式

**标准证明格式**

在△ABC和△DEF中，

AB = DE（已知）

∠B = ∠E（已知）

BC = EF（已知）

∴ △ABC≌△DEF（SAS）

## 五、尺规作图：已知两边及其夹角作三角形

已知线段a、b和角α，求作△ABC，使BC = a，AC = b，∠C = α。

步骤：

第一步：作∠MCN = α。

第二步：在CM上截取CB = a。

第三步：在CN上截取CA = b。

第四步：连接AB。

△ABC即为所求。

## 六、例题讲解

**例题1：** 如图，AB = DE，∠B = ∠E，BC = EF。求证：△ABC≌△DEF。

证明：

在△ABC和△DEF中，

AB = DE（已知）

∠B = ∠E（已知）

BC = EF（已知）

∴ △ABC≌△DEF（SAS）

**例题2：** 如图，OA = OC，OB = OD。求证：△AOB≌△COD。

证明：

∵ ∠AOB和∠COD是对顶角

∴ ∠AOB = ∠COD

在△AOB和△COD中，

OA = OC（已知）

∠AOB = ∠COD（对顶角相等）

OB = OD（已知）

∴ △AOB≌△COD（SAS）

**例题3：** 如图，AB = AC，AD = AE，∠BAD = ∠CAE。求证：△ABD≌△ACE。

证明：

在△ABD和△ACE中，

AB = AC（已知）

∠BAD = ∠CAE（已知）

AD = AE（已知）

∴ △ABD≌△ACE（SAS）

**例题4：** 如图，点E、F在BC上，BE = CF，AB = DC，∠B = ∠C。求证：△ABF≌△DCE。

证明：

∵ BE = CF

∴ BE + EF = CF + EF

即BF = CE

在△ABF和△DCE中，

AB = DC（已知）

∠B = ∠C（已知）

BF = CE（已证）

∴ △ABF≌△DCE（SAS）

**例题5：** 如图，AB = AD，AC = AE，∠BAD = ∠CAE = 90°。求证：BC = DE。

证明：

∵ ∠BAD = ∠CAE = 90°

∴ ∠BAD + ∠DAC = ∠CAE + ∠DAC

即∠BAC = ∠DAE

在△ABC和△ADE中，

AB = AD（已知）

∠BAC = ∠DAE（已证）

AC = AE（已知）

∴ △ABC≌△ADE（SAS）

∴ BC = DE（全等三角形的对应边相等）

## 七、常见错误

**错误1：用SSA判定全等**

错误做法：AB = DE，BC = EF，∠A = ∠D，认为全等。

正确理解：∠A不是AB和BC的夹角，不能用SAS。

**错误2：夹角找错**

错误做法：AB = DE，AC = DF，∠B = ∠E，认为用SAS。

正确理解：∠B不是AB和AC的夹角，∠A才是。

**错误3：忽略对顶角相等**

错误做法：没有发现对顶角这个隐含条件。

正确理解：对顶角相等是常用隐含条件。

**错误4：没有注明判定方法**

错误做法：直接写∴ △ABC≌△DEF。

正确做法：写∴ △ABC≌△DEF（SAS）。

**错误5：边的对应关系搞错**

错误做法：AB = EF，BC = DE。

正确做法：对应边要对应好，AB = DE，BC = EF。
