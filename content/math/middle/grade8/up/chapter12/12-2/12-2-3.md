# 12.2.3 ASA（角边角）

## 一、从生活实例引入

给你两个角度和它们之间的一条边的长度。

用这些条件画一个三角形。

你会发现，只能画出一种形状的三角形。

这就是ASA判定的直观理解。

## 二、ASA判定方法

**判定定理：两角和它们的夹边对应相等的两个三角形全等**

简记为ASA或"角边角"。

在△ABC和△DEF中：

∠B = ∠E

BC = EF

∠C = ∠F

∴ △ABC≌△DEF（ASA）

**重要：边必须是两角的夹边**

在△ABC中，∠B和∠C的夹边是BC。

在△DEF中，∠E和∠F的夹边是EF。

如果给的边不是夹边，就不能用ASA，而要用AAS。

## 三、几何书写格式

**标准证明格式**

在△ABC和△DEF中，

∠B = ∠E（已知）

BC = EF（已知）

∠C = ∠F（已知）

∴ △ABC≌△DEF（ASA）

## 四、尺规作图：已知两角及其夹边作三角形

已知角α、角β和线段a，求作△ABC，使∠B = α，∠C = β，BC = a。

步骤：

第一步：作线段BC = a。

第二步：以B为顶点，BC为一边，作∠B = α。

第三步：以C为顶点，CB为一边，作∠C = β。

第四步：两条射线的交点为A。

△ABC即为所求。

## 五、例题讲解

**例题1：** 如图，∠B = ∠E，BC = EF，∠C = ∠F。求证：△ABC≌△DEF。

证明：

在△ABC和△DEF中，

∠B = ∠E（已知）

BC = EF（已知）

∠C = ∠F（已知）

∴ △ABC≌△DEF（ASA）

**例题2：** 如图，AB⊥BC，DE⊥EF，BC = EF，∠A = ∠D。求证：△ABC≌△DEF。

证明：

∵ AB⊥BC，DE⊥EF

∴ ∠B = ∠E = 90°

在△ABC和△DEF中，

∠A = ∠D（已知）

BC = EF（已知）

∠B = ∠E = 90°（已证）

∴ △ABC≌△DEF（ASA）

**例题3：** 如图，AB // CD，AD // BC。求证：△ABC≌△CDA。

证明：

∵ AB // CD

∴ ∠BAC = ∠DCA（两直线平行，内错角相等）

∵ AD // BC

∴ ∠BCA = ∠DAC（两直线平行，内错角相等）

在△ABC和△CDA中，

∠BAC = ∠DCA（已证）

AC = CA（公共边）

∠BCA = ∠DAC（已证）

∴ △ABC≌△CDA（ASA）

**例题4：** 如图，∠1 = ∠2，∠3 = ∠4。求证：△ABC≌△ABD。

证明：

在△ABC和△ABD中，

∠1 = ∠2（已知）

AB = AB（公共边）

∠3 = ∠4（已知）

∴ △ABC≌△ABD（ASA）

**例题5：** 如图，点D在AB上，点E在AC上，BE和CD相交于点O，AB = AC，∠B = ∠C。求证：BD = CE。

证明：

在△ABE和△ACD中，

∠A = ∠A（公共角）

AB = AC（已知）

∠B = ∠C（已知）

∴ △ABE≌△ACD（ASA）

∴ AE = AD（全等三角形的对应边相等）

∵ AB = AC

∴ AB - AD = AC - AE

即BD = CE

## 六、常见错误

**错误1：夹边找错**

错误做法：∠A = ∠D，∠B = ∠E，AC = DF，认为用ASA。

正确理解：AC不是∠A和∠B的夹边，AB才是。这种情况应该用AAS。

**错误2：忽略公共边**

错误做法：没有发现公共边这个隐含条件。

正确理解：公共边是常用的隐含条件。

**错误3：平行线性质用错**

错误做法：AB // CD，认为∠A = ∠C。

正确理解：AB // CD，内错角相等，∠BAC = ∠DCA。

**错误4：没有注明判定方法**

错误做法：直接写∴ △ABC≌△DEF。

正确做法：写∴ △ABC≌△DEF（ASA）。

**错误5：角的对应关系搞错**

错误做法：∠A = ∠F，∠B = ∠D。

正确做法：对应角要对应好。

## 七、练习题

**练习1：** 如图，∠A = ∠D，AB = DE，∠B = ∠E。求证：△ABC≌△DEF。

证明：

在△ABC和△DEF中，

∠A = ∠D（已知）

AB = DE（已知）

∠B = ∠E（已知）

∴ △ABC≌△DEF（ASA）

**练习2：** 如图，∠ABC = ∠DCB = 90°，BC = CB，∠ACB = ∠DBC。求证：△ABC≌△DCB。

证明：

在△ABC和△DCB中，

∠ABC = ∠DCB = 90°（已知）

BC = CB（公共边）

∠ACB = ∠DBC（已知）

∴ △ABC≌△DCB（ASA）

**练习3：** 如图，AB // CD，∠A = ∠D。求证：△AOB≌△DOC（O是AC和BD的交点）。

证明：

∵ AB // CD

∴ ∠B = ∠C（两直线平行，内错角相等）

在△AOB和△DOC中，

∠A = ∠D（已知）

∠AOB = ∠DOC（对顶角相等）

但需要夹边相等。

题目条件不足，需要补充AO = DO或BO = CO。

**练习4：** 如图，∠B = ∠D = 90°，BC = DC，∠ACB = ∠ECD。求证：AB = ED。

证明：

在△ABC和△EDC中，

∠B = ∠D = 90°（已知）

BC = DC（已知）

∠ACB = ∠ECD（已知）

∴ △ABC≌△EDC（ASA）

∴ AB = ED（全等三角形的对应边相等）

**练习5：** 如图，AD = BC，AD // BC。求证：△ADC≌△CBA。

证明：

∵ AD // BC

∴ ∠DAC = ∠BCA（两直线平行，内错角相等）

在△ADC和△CBA中，

AD = BC（已知）

∠DAC = ∠BCA（已证）

AC = CA（公共边）

∴ △ADC≌△CBA（ASA）
