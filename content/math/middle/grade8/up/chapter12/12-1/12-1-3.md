# 12.1.3 全等三角形的性质

## 一、从生活实例引入

你有两块完全相同的三角形饼干。

把它们叠在一起，完全重合。

既然完全重合，那么它们的边一定一样长，角一定一样大。

这就是全等三角形的性质。

## 二、全等三角形的性质

**性质1：全等三角形的对应边相等**

如果△ABC≌△DEF，那么AB = DE，BC = EF，CA = FD。

**性质2：全等三角形的对应角相等**

如果△ABC≌△DEF，那么∠A = ∠D，∠B = ∠E，∠C = ∠F。

**性质3：全等三角形的周长相等**

因为对应边相等，所以周长也相等。

**性质4：全等三角形的面积相等**

因为能够完全重合，所以面积相等。

## 三、几何语言书写

**标准格式**

∵ △ABC≌△DEF（已知）

∴ AB = DE，BC = EF，CA = FD（全等三角形的对应边相等）

∴ ∠A = ∠D，∠B = ∠E，∠C = ∠F（全等三角形的对应角相等）

## 四、利用全等性质求线段长度和角度

已知两个三角形全等，可以利用对应边相等求未知线段的长度。

已知两个三角形全等，可以利用对应角相等求未知角的大小。

## 五、例题讲解

**例题1：** 已知△ABC≌△DEF，AB = 6cm，BC = 8cm，AC = 10cm。求△DEF的三边长。

解：

∵ △ABC≌△DEF

∴ DE = AB = 6cm

EF = BC = 8cm

DF = AC = 10cm

答：△DEF的三边长分别是6cm、8cm、10cm。

**例题2：** 已知△ABC≌△DEF，∠A = 45°，∠B = 75°。求∠F。

解：

∵ △ABC≌△DEF

∴ ∠D = ∠A = 45°，∠E = ∠B = 75°

在△DEF中，∠F = 180° - ∠D - ∠E = 180° - 45° - 75° = 60°

答：∠F是60°。

**例题3：** 如图，△ABC≌△ADE，AB = 5cm，BD = 3cm。求DE的长。

解：

AD = AB + BD = 5 + 3 = 8cm

∵ △ABC≌△ADE

∴ AC = AE，BC = DE，AB = AD

等等，AB = 5cm，AD = 8cm，矛盾。

重新理解：△ABC≌△ADE，对应顶点A和A，B和D，C和E。

所以AB = AD = 5cm

但BD = 3cm，说明B和D不重合。

AD = AB = 5cm

BC = DE

AC = AE

题目求DE，需要知道BC的长。

题目条件不足，需要补充BC的长。

假设BC = 4cm，则DE = BC = 4cm。

**例题4：** 已知△ABC≌△DEF，△ABC的周长是24cm，AB = 7cm，BC = 9cm。求DF的长和△DEF的面积（已知△ABC中BC边上的高是4cm）。

解：

AC = 24 - 7 - 9 = 8cm

∵ △ABC≌△DEF

∴ DF = AC = 8cm

△ABC的面积 = 1/2 × BC × 高 = 1/2 × 9 × 4 = 18cm²

∵ △ABC≌△DEF

∴ △DEF的面积 = △ABC的面积 = 18cm²

答：DF的长是8cm，△DEF的面积是18cm²。

**例题5：** 如图，△ABC≌△CDA，∠B = 70°，∠BAC = 50°。求∠DCA。

解：

∵ △ABC≌△CDA

对应顶点：A和C，B和D，C和A

∴ ∠DCA = ∠BAC = 50°

答：∠DCA是50°。

## 六、常见错误

**错误1：对应边找错**

错误做法：△ABC≌△DEF，认为AB对应DF。

正确做法：根据对应顶点，A对应D，B对应E，所以AB对应DE。

**错误2：对应角找错**

错误做法：△ABC≌△DEF，认为∠A对应∠E。

正确做法：A对应D，所以∠A对应∠D。

**错误3：忽略对应关系**

错误做法：直接用AB = EF。

正确做法：必须先确定对应关系，再用对应边相等。

**错误4：几何语言书写不规范**

错误做法：直接写AB = DE。

正确做法：先写"∵ △ABC≌△DEF"，再写"∴ AB = DE"。

**错误5：周长和面积混淆**

错误做法：认为全等三角形周长相等，但面积不一定相等。

正确理解：全等三角形周长和面积都相等。

## 七、练习题

**练习1：** 已知△ABC≌△DEF，AB = 4cm，BC = 5cm，AC = 6cm。求△DEF的周长。

解：

∵ △ABC≌△DEF

∴ DE = AB = 4cm，EF = BC = 5cm，DF = AC = 6cm

△DEF的周长 = 4 + 5 + 6 = 15cm

答：△DEF的周长是15cm。

**练习2：** 已知△ABC≌△DEF，∠A = 80°，∠C = 40°。求∠E。

解：

∵ △ABC≌△DEF

∴ ∠D = ∠A = 80°，∠F = ∠C = 40°

∠E = 180° - 80° - 40° = 60°

答：∠E是60°。

**练习3：** 已知△ABC≌△DEF，AB = 3cm，BC = 4cm，AC = 5cm。判断△DEF是什么三角形。

解：

∵ △ABC≌△DEF

∴ DE = 3cm，EF = 4cm，DF = 5cm

3² + 4² = 9 + 16 = 25 = 5²

所以△DEF是直角三角形。

答：△DEF是直角三角形。

**练习4：** 已知△ABC≌△ADE，∠BAC = 60°，∠DAE = 60°，∠B = 50°。求∠E。

解：

∵ △ABC≌△ADE

对应顶点：A和A，B和D，C和E

∴ ∠E = ∠C

在△ABC中，∠C = 180° - 60° - 50° = 70°

∴ ∠E = 70°

答：∠E是70°。

**练习5：** 已知△ABC≌△DEF，△ABC的面积是30cm²，BC = 10cm。求△DEF中EF边上的高。

解：

∵ △ABC≌△DEF

∴ △DEF的面积 = 30cm²，EF = BC = 10cm

设EF边上的高为h。

1/2 × EF × h = 30

1/2 × 10 × h = 30

h = 6cm

答：EF边上的高是6cm。
