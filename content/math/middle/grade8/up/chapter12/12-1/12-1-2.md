# 12.1.2 全等三角形及其对应元素

## 一、全等三角形的定义

能够完全重合的两个三角形，叫做全等三角形。

把两个全等的三角形叠放在一起，它们能够完全重合。

## 二、对应元素

**对应顶点**

重合的顶点叫做对应顶点。

如果△ABC和△DEF全等，A和D重合，B和E重合，C和F重合。

那么A和D是对应顶点，B和E是对应顶点，C和F是对应顶点。

**对应边**

重合的边叫做对应边。

AB和DE是对应边，BC和EF是对应边，CA和FD是对应边。

**对应角**

重合的角叫做对应角。

∠A和∠D是对应角，∠B和∠E是对应角，∠C和∠F是对应角。

## 三、全等的表示方法

△ABC≌△DEF

读作"三角形ABC全等于三角形DEF"。

符号"≌"表示全等。

**重要规则：对应顶点要写在对应位置上**

如果A对应D，B对应E，C对应F，就要写成△ABC≌△DEF。

不能写成△ABC≌△DFE，因为这样对应关系就错了。

## 四、找对应元素的规律

**规律1：公共边是对应边**

两个三角形如果有公共边，那么公共边就是对应边。

**规律2：公共角是对应角**

两个三角形如果有公共角，那么公共角就是对应角。

**规律3：对顶角是对应角**

两个三角形如果有对顶角，那么对顶角就是对应角。

**规律4：最大边对应最大边，最小边对应最小边**

全等三角形中，最长边对应最长边，最短边对应最短边。

**规律5：最大角对应最大角，最小角对应最小角**

全等三角形中，最大角对应最大角，最小角对应最小角。

## 五、例题讲解

**例题1：** 已知△ABC≌△DEF，写出所有的对应边和对应角。

解：

对应顶点：A和D，B和E，C和F

对应边：AB和DE，BC和EF，CA和FD

对应角：∠A和∠D，∠B和∠E，∠C和∠F

**例题2：** 已知△ABC≌△DEF，AB = 5cm，BC = 6cm，AC = 7cm。求DE、EF、DF的长。

解：

因为△ABC≌△DEF

所以AB = DE = 5cm

BC = EF = 6cm

AC = DF = 7cm

答：DE = 5cm，EF = 6cm，DF = 7cm。

**例题3：** 已知△ABC≌△DEF，∠A = 50°，∠B = 60°。求∠F。

解：

因为△ABC≌△DEF

所以∠A = ∠D = 50°，∠B = ∠E = 60°

在△DEF中，∠F = 180° - ∠D - ∠E = 180° - 50° - 60° = 70°

答：∠F是70°。

**例题4：** 如图，△ABC≌△CDA，写出对应边和对应角。

解：

对应顶点：A和C，B和D，C和A

对应边：AB和CD，BC和DA，CA和AC

对应角：∠A和∠C，∠B和∠D，∠C和∠A

注意：AC是公共边，对应边是CA（即AC）。

**例题5：** 已知△ABC≌△DEF，△ABC的周长是18cm，AB = 5cm，BC = 6cm。求DF的长。

解：

AC = 18 - 5 - 6 = 7cm

因为△ABC≌△DEF

所以DF = AC = 7cm

答：DF的长是7cm。

## 六、常见错误

**错误1：对应顶点写错位置**

错误做法：△ABC≌△DEF，但实际A对应E，B对应D。

正确做法：对应顶点要写在对应位置，应写成△ABC≌△EDF。

**错误2：对应边找错**

错误做法：认为AB对应DF。

正确做法：根据对应顶点找对应边，A对应D，B对应E，所以AB对应DE。

**错误3：忽略公共边**

错误做法：两个三角形有公共边，但没有利用这个条件。

正确做法：公共边一定是对应边。

**错误4：对应角搞混**

错误做法：认为∠A对应∠E。

正确做法：根据全等符号的对应关系，A对应D，所以∠A对应∠D。

**错误5：读法错误**

错误做法：把"△ABC≌△DEF"读成"三角形ABC等于三角形DEF"。

正确读法："三角形ABC全等于三角形DEF"。

## 七、练习题

**练习1：** 已知△ABC≌△DEF，∠A = 40°，∠C = 80°。求∠E。

解：

因为△ABC≌△DEF

所以∠A = ∠D = 40°，∠C = ∠F = 80°

在△DEF中，∠E = 180° - 40° - 80° = 60°

答：∠E是60°。

**练习2：** 已知△ABC≌△DEF，AB = 3cm，AC = 4cm，BC = 5cm。求△DEF的周长。

解：

因为△ABC≌△DEF

所以DE = AB = 3cm，EF = BC = 5cm，DF = AC = 4cm

△DEF的周长 = 3 + 5 + 4 = 12cm

答：△DEF的周长是12cm。

**练习3：** 已知△ABC≌△CDA，写出对应顶点、对应边、对应角。

解：

对应顶点：A和C，B和D，C和A

对应边：AB和CD，BC和DA，CA和AC

对应角：∠BAC和∠DCA，∠B和∠D，∠BCA和∠DAC

**练习4：** 已知△ABC≌△DEF，AB = 4cm，BC = 7cm，△DEF的周长是18cm。求AC的长。

解：

因为△ABC≌△DEF

所以△ABC的周长 = △DEF的周长 = 18cm

AC = 18 - 4 - 7 = 7cm

答：AC的长是7cm。

**练习5：** 已知△ABC≌△DEF，∠A = 3∠B，∠C = 2∠B。求∠D、∠E、∠F。

解：

设∠B = x，则∠A = 3x，∠C = 2x

3x + x + 2x = 180°

6x = 180°

x = 30°

∠A = 90°，∠B = 30°，∠C = 60°

因为△ABC≌△DEF

所以∠D = ∠A = 90°，∠E = ∠B = 30°，∠F = ∠C = 60°

答：∠D = 90°，∠E = 30°，∠F = 60°。
