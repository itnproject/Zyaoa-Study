# 12.3.2 角平分线的判定

## 一、从性质反过来思考

角平分线的性质：角平分线上的点到角两边的距离相等。

反过来想：到角两边距离相等的点，是不是在角平分线上？

答案是肯定的。

这就是角平分线的判定。

## 二、角平分线的判定定理

**判定定理：到角两边距离相等的点在角的平分线上**

点P在∠AOB内部。

PD⊥OA于D，PE⊥OB于E。

如果PD = PE，那么点P在∠AOB的平分线上。

## 三、用HL证明判定定理

**证明**

连接OP。

∵ PD⊥OA，PE⊥OB

∴ ∠PDO = ∠PEO = 90°

在Rt△PDO和Rt△PEO中，

PD = PE（已知）

OP = OP（公共边）

∴ Rt△PDO≌Rt△PEO（HL）

∴ ∠POD = ∠POE（全等三角形的对应角相等）

∴ OP平分∠AOB

即点P在∠AOB的平分线上。

## 四、几何语言

**标准格式**

∵ PD⊥OA于D，PE⊥OB于E，PD = PE

∴ 点P在∠AOB的平分线上（到角两边距离相等的点在角的平分线上）

## 五、区分性质和判定

**性质：已知平分推距离相等**

已知：OP平分∠AOB，PD⊥OA，PE⊥OB

结论：PD = PE

**判定：已知距离相等推平分**

已知：PD⊥OA，PE⊥OB，PD = PE

结论：OP平分∠AOB

**记忆方法**

性质：平分 → 距离相等

判定：距离相等 → 平分

## 六、例题讲解

**例题1：** 如图，P是∠AOB内部一点，PD⊥OA于D，PE⊥OB于E，PD = PE。求证：OP平分∠AOB。

证明：

连接OP。

在Rt△PDO和Rt△PEO中，

PD = PE（已知）

OP = OP（公共边）

∴ Rt△PDO≌Rt△PEO（HL）

∴ ∠POD = ∠POE（全等三角形的对应角相等）

∴ OP平分∠AOB

**例题2：** 如图，在△ABC中，D是BC上一点，DE⊥AB于E，DF⊥AC于F，DE = DF。求证：AD平分∠BAC。

证明：

∵ DE⊥AB，DF⊥AC，DE = DF

∴ 点D在∠BAC的平分线上（到角两边距离相等的点在角的平分线上）

∴ AD平分∠BAC

**例题3：** 如图，在△ABC中，BE⊥AC于E，CF⊥AB于F，BE和CF交于点D，且BD = CD。求证：AD平分∠BAC。

证明：

∵ BE⊥AC，CF⊥AB

∴ ∠BFD = ∠CED = 90°

在△BFD和△CED中，

∠BFD = ∠CED = 90°（已证）

∠BDF = ∠CDE（对顶角相等）

BD = CD（已知）

∴ △BFD≌△CED（AAS）

∴ DF = DE（全等三角形的对应边相等）

∵ DF⊥AB，DE⊥AC，DF = DE

∴ 点D在∠BAC的平分线上

∴ AD平分∠BAC

**例题4：** 如图，在△ABC中，∠C = 90°，D是BC上一点，DE⊥AB于E，且CD = DE。求证：AD平分∠BAC。

证明：

∵ ∠C = 90°

∴ DC⊥AC

∵ DE⊥AB，CD = DE

∴ 点D在∠BAC的平分线上（到角两边距离相等的点在角的平分线上）

∴ AD平分∠BAC

**例题5：** 如图，CD⊥AB于D，BE⊥AC于E，CD和BE交于点O，且OD = OE。求证：AB = AC。

证明：

∵ CD⊥AB，BE⊥AC，OD = OE

∴ 点O在∠BAC的平分线上（到角两边距离相等的点在角的平分线上）

∴ AO平分∠BAC

∴ ∠BAO = ∠CAO

在△ABO和△ACO中，

∠BAO = ∠CAO（已证）

AO = AO（公共边）

∠AOB = ∠AOC（对顶角相等）

但需要更多条件。

重新分析：

在Rt△BDO和Rt△CEO中，

OD = OE（已知）

∠BDO = ∠CEO = 90°（已知）

∠BOD = ∠COE（对顶角相等）

∴ △BDO≌△CEO（ASA）

∴ OB = OC，BD = CE

在Rt△ADO和Rt△AEO中，

OD = OE（已知）

AO = AO（公共边）

∴ Rt△ADO≌Rt△AEO（HL）

∴ AD = AE

∴ AD + BD = AE + CE

即AB = AC

## 七、常见错误

**错误1：性质和判定用反**

错误做法：已知OP平分∠AOB，用判定定理推PD = PE。

正确理解：已知平分推距离相等用性质，已知距离相等推平分用判定。

**错误2：没有注明垂直条件**

错误做法：已知PD = PE，直接说OP平分∠AOB。

正确做法：必须先说明PD⊥OA，PE⊥OB。

**错误3：忽略点在角内部**

错误做法：角外部的点到角两边距离相等，也在平分线上。

正确理解：判定定理要求点在角的内部。

**错误4：证明过程不完整**

错误做法：直接写"所以AD平分∠BAC"。

正确做法：先说明垂直和距离相等，再用判定定理。

**错误5：HL用错**

错误做法：用HL证明时，没有注明是直角三角形。

正确做法：先注明Rt△，再用HL。
