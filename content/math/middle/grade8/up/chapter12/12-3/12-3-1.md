# 12.3.1 角平分线的性质

## 一、复习角的平分线

角的平分线：从一个角的顶点出发，把这个角分成两个相等的角的射线。

在∠AOB中，OC平分∠AOB，则∠AOC = ∠BOC。

## 二、角平分线的性质

**性质：角平分线上的点到角两边的距离相等**

点P在∠AOB的平分线上。

PD⊥OA于D，PE⊥OB于E。

则PD = PE。

**这里的"距离"是指垂线段的长度**

点到直线的距离，是从这个点向直线作垂线，垂线段的长度。

## 三、用AAS证明这个性质

**证明**

∵ OP平分∠AOB

∴ ∠AOP = ∠BOP

∵ PD⊥OA，PE⊥OB

∴ ∠PDO = ∠PEO = 90°

在△PDO和△PEO中，

∠PDO = ∠PEO = 90°（已证）

∠AOP = ∠BOP（已证）

OP = OP（公共边）

∴ △PDO≌△PEO（AAS）

∴ PD = PE（全等三角形的对应边相等）

## 四、几何语言

**标准格式**

∵ OP平分∠AOB，PD⊥OA于D，PE⊥OB于E

∴ PD = PE（角平分线上的点到角两边的距离相等）

## 五、例题讲解

**例题1：** 如图，OC平分∠AOB，P是OC上一点，PD⊥OA于D，PE⊥OB于E。已知PD = 3cm。求PE。

解：

∵ OC平分∠AOB，PD⊥OA，PE⊥OB

∴ PE = PD = 3cm（角平分线上的点到角两边的距离相等）

答：PE是3cm。

**例题2：** 如图，在△ABC中，∠C = 90°，AD平分∠BAC，DE⊥AB于E。已知CD = 4cm。求DE。

解：

∵ AD平分∠BAC，DC⊥AC（∠C = 90°），DE⊥AB

∴ DE = DC = 4cm（角平分线上的点到角两边的距离相等）

答：DE是4cm。

**例题3：** 如图，在△ABC中，∠C = 90°，AD平分∠BAC，DE⊥AB于E。已知BC = 8cm，BD = 5cm。求DE。

解：

CD = BC - BD = 8 - 5 = 3cm

∵ AD平分∠BAC，DC⊥AC，DE⊥AB

∴ DE = DC = 3cm（角平分线上的点到角两边的距离相等）

答：DE是3cm。

**例题4：** 如图，在△ABC中，AD平分∠BAC，DE⊥AB于E，DF⊥AC于F。求证：AE = AF。

证明：

∵ AD平分∠BAC，DE⊥AB，DF⊥AC

∴ DE = DF（角平分线上的点到角两边的距离相等）

在Rt△ADE和Rt△ADF中，

DE = DF（已证）

AD = AD（公共边）

∴ Rt△ADE≌Rt△ADF（HL）

∴ AE = AF（全等三角形的对应边相等）

**例题5：** 如图，在△ABC中，∠C = 90°，AD平分∠BAC交BC于D。已知BC = 10cm，BD = 6cm，AB = 12cm。求△ABD的面积。

解：

CD = BC - BD = 10 - 6 = 4cm

∵ AD平分∠BAC，DC⊥AC，过D作DE⊥AB于E

∴ DE = DC = 4cm（角平分线上的点到角两边的距离相等）

△ABD的面积 = 1/2 × AB × DE = 1/2 × 12 × 4 = 24cm²

答：△ABD的面积是24cm²。

## 六、常见错误

**错误1：忽略"距离"是垂线段**

错误做法：认为点到角两边的距离是任意线段。

正确理解：距离必须是垂线段的长度。

**错误2：没有注明垂直条件**

错误做法：直接用角平分线性质，没有说明垂直。

正确做法：必须先说明PD⊥OA，PE⊥OB。

**错误3：性质和判定混淆**

错误做法：已知PD = PE，直接说OP是角平分线。

正确理解：这是判定，不是性质。性质是已知平分推距离相等。

**错误4：对应关系搞错**

错误做法：认为PD = OE。

正确理解：PD = PE，是到两边的距离相等。

**错误5：忽略点在平分线上这个前提**

错误做法：任意一点到角两边的距离相等。

正确理解：只有角平分线上的点才满足这个性质。

## 七、练习题

**练习1：** 如图，OC平分∠AOB，P是OC上一点，PD⊥OA于D，PE⊥OB于E。已知PE = 5cm。求PD。

解：

∵ OC平分∠AOB，PD⊥OA，PE⊥OB

∴ PD = PE = 5cm

答：PD是5cm。

**练习2：** 如图，在△ABC中，∠C = 90°，AD平分∠BAC，DE⊥AB于E。已知DE = 3cm。求CD。

解：

∵ AD平分∠BAC，DC⊥AC，DE⊥AB

∴ CD = DE = 3cm

答：CD是3cm。

**练习3：** 如图，在△ABC中，∠C = 90°，AD平分∠BAC，DE⊥AB于E。已知CD = 3cm，BD = 5cm。求BC。

解：

BC = CD + BD = 3 + 5 = 8cm

答：BC是8cm。

**练习4：** 如图，在△ABC中，AD平分∠BAC，DE⊥AB于E，DF⊥AC于F。已知DE = 4cm。求DF。

解：

∵ AD平分∠BAC，DE⊥AB，DF⊥AC

∴ DF = DE = 4cm

答：DF是4cm。

**练习5：** 如图，在△ABC中，∠C = 90°，AD平分∠BAC，DE⊥AB于E。已知AC = 6cm，BC = 8cm。求△ABD的面积。

解：

由勾股定理：AB = √(6² + 8²) = √100 = 10cm

设CD = x，则BD = 8 - x。

∵ AD平分∠BAC，DC⊥AC，DE⊥AB

∴ DE = DC = x

△ABD的面积 = 1/2 × AB × DE = 1/2 × 10 × x = 5x

△ACD的面积 = 1/2 × AC × CD = 1/2 × 6 × x = 3x

△ABC的面积 = 1/2 × 6 × 8 = 24cm²

5x + 3x = 24

8x = 24

x = 3

△ABD的面积 = 5 × 3 = 15cm²

答：△ABD的面积是15cm²。
