# 11.1.1 三角形的边

## 一、从生活实例引入

你见过自行车的车架吗？它的主体框架就是一个三角形。

你用过三角尺吗？它也是一个三角形。

你注意过屋顶的框架吗？很多屋顶的钢架也是三角形结构。

为什么这些结构都喜欢用三角形呢？

因为三角形是最基本的几何图形，也是最稳定的图形。

## 二、什么是三角形

由不在同一直线上的三条线段首尾顺次相接所组成的图形，叫做三角形。

理解这个定义要注意三点：

第一，三条线段不能在同一直线上。

第二，三条线段要首尾顺次相接，也就是第一条的尾接第二条的头，第二条的尾接第三条的头，第三条的尾再接第一条的头。

第三，必须围成一个封闭的图形。

## 三、三角形的表示方法

三角形用符号"△"表示。

比如三角形ABC，记作△ABC。

三角形有三个顶点、三条边、三个内角。

在△ABC中：

三个顶点：A、B、C

三条边：AB、BC、CA（也可以用a、b、c表示，其中a是BC边，b是AC边，c是AB边）

三个内角：∠A、∠B、∠C

顶点和边的对应关系：顶点A对着边a（BC），顶点B对着边b（AC），顶点C对着边c（AB）。

## 四、三角形按边分类

**不等边三角形**

三条边都不相等的三角形。

比如三边分别是3cm、4cm、5cm的三角形。

**等腰三角形**

有两条边相等的三角形。

相等的两条边叫做腰，另一条边叫做底边。

等边三角形是特殊的等腰三角形。

**等边三角形**

三条边都相等的三角形。

等边三角形也叫正三角形。

等边三角形是特殊的等腰三角形，但不是所有等腰三角形都是等边三角形。

## 五、三角形按角分类

**锐角三角形**

三个角都是锐角的三角形。

比如三个角分别是60°、70°、50°的三角形。

**直角三角形**

有一个角是直角的三角形。

直角三角形中，直角所对的边叫做斜边，另外两条边叫做直角边。

**钝角三角形**

有一个角是钝角的三角形。

注意：一个三角形最多只能有一个直角或一个钝角。

## 六、三角形的三边关系

**定理：三角形两边之和大于第三边**

在△ABC中，a + b > c，a + c > b，b + c > a。

通俗理解：从A到C，直接走AC最近。如果从A走到B再走到C，路程肯定比直接走AC长。

**推论：三角形两边之差小于第三边**

在△ABC中，|a - b| < c，|a - c| < b，|b - c| < a。

## 七、快速判断法

判断三条线段能否构成三角形，有一个简便方法：

把三条线段按长度排序，找出最长的那条。

如果较短的两条之和大于最长的那条，就能构成三角形。

否则就不能构成三角形。

比如3、4、5：3 + 4 = 7 > 5，能构成三角形。

比如2、3、6：2 + 3 = 5 < 6，不能构成三角形。

## 八、求第三边的范围

已知三角形的两边长分别是a和b，求第三边c的范围。

根据三边关系：

a + b > c，所以 c < a + b

|a - b| < c，所以 c > |a - b|

综合起来：|a - b| < c < a + b

比如已知两边是3和5，第三边的范围是：5 - 3 < c < 5 + 3，即 2 < c < 8。

## 九、例题讲解

**例题1：** 下列长度的三条线段能否构成三角形？

（1）3cm、4cm、5cm

（2）2cm、3cm、6cm

（3）5cm、5cm、5cm

解：

（1）排序：3、4、5。较短两边之和：3 + 4 = 7 > 5。能构成三角形。

（2）排序：2、3、6。较短两边之和：2 + 3 = 5 < 6。不能构成三角形。

（3）排序：5、5、5。较短两边之和：5 + 5 = 10 > 5。能构成三角形（等边三角形）。

**例题2：** 已知三角形的两边长分别是4cm和7cm，求第三边的取值范围。

解：

设第三边为x cm。

根据三边关系：|7 - 4| < x < 7 + 4

3 < x < 11

答：第三边的取值范围是 3 < x < 11。

**例题3：** 已知等腰三角形的两边长分别是3cm和7cm，求这个三角形的周长。

解：

情况1：腰长是3cm，底边是7cm。

检验：3 + 3 = 6 < 7，不能构成三角形。舍去。

情况2：腰长是7cm，底边是3cm。

检验：7 + 3 = 10 > 7，能构成三角形。

周长 = 7 + 7 + 3 = 17cm。

答：这个三角形的周长是17cm。

**例题4：** 下列各组线段中，能构成三角形的是：

A. 1、2、3

B. 2、3、4

C. 3、3、6

D. 4、4、9

解：

A：1 + 2 = 3，不大于3。不能。

B：2 + 3 = 5 > 4。能。

C：3 + 3 = 6，不大于6。不能。

D：4 + 4 = 8 < 9。不能。

答案：B

**例题5：** 已知三角形的三边长分别是2、x、5，且x为整数，求x的所有可能值。

解：

根据三边关系：|5 - 2| < x < 5 + 2

3 < x < 7

x为整数，所以x可以取4、5、6。

答：x的所有可能值是4、5、6。

## 十、常见误解

**误解1：认为两边之和等于第三边也能构成三角形**

错误想法：3 + 3 = 6，所以3、3、6能构成三角形。

正确理解：两边之和必须大于第三边，等于也不行。3、3、6三条线段只能拼成一条直线。

**误解2：认为等边三角形不是等腰三角形**

错误想法：等边三角形和等腰三角形是两种不同的三角形。

正确理解：等边三角形是特殊的等腰三角形。

**误解3：忽略分类讨论**

错误做法：等腰三角形两边是3和7，直接认为腰是3。

正确理解：需要分两种情况讨论，并检验是否能构成三角形。

**误解4：三边关系用错**

错误做法：认为两边之差大于第三边。

正确理解：两边之差小于第三边。

**误解5：求范围时漏掉一边**

错误做法：只算a + b > c，漏掉|a - b| < c。

正确理解：三边关系有两个方面，都要考虑。

## 十一、练习题

**练习1：** 下列长度的三条线段能否构成三角形？

（1）5cm、6cm、10cm

（2）4cm、4cm、8cm

（3）6cm、8cm、10cm

解：

（1）5 + 6 = 11 > 10。能构成三角形。

（2）4 + 4 = 8，不大于8。不能构成三角形。

（3）6 + 8 = 14 > 10。能构成三角形。

**练习2：** 已知三角形的两边长分别是5cm和9cm，求第三边的取值范围。

解：

设第三边为x cm。

|9 - 5| < x < 9 + 5

4 < x < 14

答：第三边的取值范围是 4 < x < 14。

**练习3：** 已知等腰三角形的两边长分别是4cm和9cm，求这个三角形的周长。

解：

情况1：腰长是4cm，底边是9cm。

检验：4 + 4 = 8 < 9。不能构成三角形。舍去。

情况2：腰长是9cm，底边是4cm。

检验：9 + 4 = 13 > 9。能构成三角形。

周长 = 9 + 9 + 4 = 22cm。

答：这个三角形的周长是22cm。

**练习4：** 已知三角形的三边长分别是3、x、7，且x为整数，求x的所有可能值。

解：

|7 - 3| < x < 7 + 3

4 < x < 10

x为整数，所以x可以取5、6、7、8、9。

答：x的所有可能值是5、6、7、8、9。

**练习5：** 一个三角形的三边长分别是a、b、c，其中a = 6，b = 8，c是偶数。求c的所有可能值。

解：

|8 - 6| < c < 8 + 6

2 < c < 14

c是偶数，所以c可以取4、6、8、10、12。

答：c的所有可能值是4、6、8、10、12。
