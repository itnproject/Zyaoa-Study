# 11.3.1 多边形与对角线

## 一、从生活实例引入

你见过蜂巢吗？蜂巢是由许多正六边形组成的。

你见过地砖吗？地砖有正方形、正六边形等形状。

你见过五角星吗？五角星与五边形密切相关。

这些图形都是多边形。

## 二、多边形的定义

在平面内，由一些不在同一直线上的线段首尾顺次相接组成的封闭图形，叫做多边形。

组成多边形的线段叫做多边形的边。

相邻两边的公共端点叫做多边形的顶点。

相邻两边组成的角叫做多边形的内角。

## 三、多边形的基本概念

**边数与名称**

三条边：三角形

四条边：四边形

五条边：五边形

六条边：六边形

n条边：n边形

**内角与外角**

多边形的内角：相邻两边组成的角。

多边形的外角：一边与相邻边的延长线组成的角。

每个顶点处，内角 + 外角 = 180°。

## 四、对角线

**定义**

连接多边形不相邻的两个顶点的线段，叫做多边形的对角线。

**从一个顶点出发的对角线数**

从n边形的一个顶点出发，可以引(n - 3)条对角线。

为什么是(n - 3)？

因为从一个顶点出发，不能连自己，不能连相邻的两个顶点。

所以可以连的顶点数 = n - 1 - 2 = n - 3。

**总的对角线数**

n边形的对角线总数 = n(n - 3)/2

为什么除以2？

因为每条对角线被计算了两次（从两个端点各算一次）。

**举例**

三角形：3(3-3)/2 = 0条对角线

四边形：4(4-3)/2 = 2条对角线

五边形：5(5-3)/2 = 5条对角线

六边形：6(6-3)/2 = 9条对角线

## 五、正多边形

**定义**

各边相等、各角也相等的多边形，叫做正多边形。

正三角形（等边三角形）：三边相等，三角都是60°。

正方形：四边相等，四角都是90°。

正五边形：五边相等，五角都是108°。

正六边形：六边相等，六角都是120°。

**注意**

各边相等的多边形不一定是正多边形（菱形各边相等但角不一定相等）。

各角相等的多边形也不一定是正多边形（矩形各角相等但边不一定相等）。

必须同时满足"各边相等"和"各角相等"。

## 六、例题讲解

**例题1：** 从八边形的一个顶点出发，可以引几条对角线？

解：

从一个顶点出发的对角线数 = n - 3 = 8 - 3 = 5条

答：可以引5条对角线。

**例题2：** 十边形有多少条对角线？

解：

对角线总数 = n(n - 3)/2 = 10 × 7 / 2 = 35条

答：十边形有35条对角线。

**例题3：** 一个多边形有14条对角线，求这个多边形的边数。

解：

n(n - 3)/2 = 14

n² - 3n = 28

n² - 3n - 28 = 0

(n - 7)(n + 4) = 0

n = 7 或 n = -4（舍去）

答：这个多边形是七边形。

**例题4：** 下列说法正确的是：

A. 各边相等的多边形是正多边形

B. 各角相等的多边形是正多边形

C. 各边相等且各角相等的多边形是正多边形

D. 三角形没有对角线

解：

A错误：菱形各边相等但不是正多边形。

B错误：矩形各角相等但不是正多边形。

C正确：必须同时满足。

D正确：三角形没有对角线。

答案：C、D

**例题5：** 从n边形的一个顶点出发可以引7条对角线，求n。

解：

n - 3 = 7

n = 10

答：n = 10，是十边形。

## 七、常见错误

**错误1：对角线数算错**

错误做法：从n边形一个顶点出发有(n - 2)条对角线。

正确理解：从n边形一个顶点出发有(n - 3)条对角线。

**错误2：总对角线公式记错**

错误做法：总对角线数 = n(n - 3)

正确公式：总对角线数 = n(n - 3)/2

**错误3：正多边形定义不完整**

错误做法：各边相等的多边形就是正多边形。

正确理解：必须各边相等且各角相等。

**错误4：对角线定义搞错**

错误做法：连接任意两个顶点的线段都是对角线。

正确理解：连接不相邻的两个顶点的线段才是对角线。

**错误5：三角形对角线数搞错**

错误做法：三角形有3条对角线。

正确理解：三角形没有对角线。

## 八、练习题

**练习1：** 从十二边形的一个顶点出发，可以引几条对角线？

解：

n - 3 = 12 - 3 = 9条

答：可以引9条对角线。

**练习2：** 十五边形有多少条对角线？

解：

n(n - 3)/2 = 15 × 12 / 2 = 90条

答：十五边形有90条对角线。

**练习3：** 一个多边形有27条对角线，求这个多边形的边数。

解：

n(n - 3)/2 = 27

n² - 3n = 54

n² - 3n - 54 = 0

(n - 9)(n + 6) = 0

n = 9

答：这个多边形是九边形。

**练习4：** 正六边形的每个内角是多少度？

解：

正六边形内角和 = (6 - 2) × 180° = 720°

每个内角 = 720° / 6 = 120°

答：正六边形的每个内角是120°。

**练习5：** 判断：各角相等的六边形一定是正六边形。

解：

错误。

各角相等但各边不一定相等。

比如可以把正六边形的边拉长或缩短，保持角度不变，就不是正六边形了。
