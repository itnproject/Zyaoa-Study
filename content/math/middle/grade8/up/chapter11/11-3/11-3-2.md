# 11.3.2 多边形内角和

## 一、从三角形内角和推广

我们知道三角形的内角和是180°。

那四边形的内角和是多少？五边形呢？n边形呢？

今天我们就来研究多边形的内角和。

## 二、推导方法

**方法：从一个顶点引对角线**

从n边形的一个顶点出发，引对角线。

可以引(n - 3)条对角线。

这些对角线把n边形分成了(n - 2)个三角形。

每个三角形的内角和是180°。

所以n边形的内角和 = (n - 2) × 180°

**举例验证**

三角形：(3 - 2) × 180° = 180° ✓

四边形：(4 - 2) × 180° = 360° ✓

五边形：(5 - 2) × 180° = 540° ✓

六边形：(6 - 2) × 180° = 720° ✓

## 三、多边形内角和公式

**公式：n边形内角和 = (n - 2) × 180°**

其中n ≥ 3，且n为整数。

**正n边形每个内角**

正n边形每个内角 = (n - 2) × 180° / n

比如正五边形每个内角 = 540° / 5 = 108°

正六边形每个内角 = 720° / 6 = 120°

## 四、重要规律

**边数与内角和的关系**

边数每增加1，内角和增加180°。

三角形：180°

四边形：360°（增加180°）

五边形：540°（再增加180°）

六边形：720°（再增加180°）

**内角和一定是180°的倍数**

因为(n - 2)是整数，所以内角和一定是180°的整数倍。

## 五、例题讲解

**例题1：** 求八边形的内角和。

解：

(8 - 2) × 180° = 6 × 180° = 1080°

答：八边形的内角和是1080°。

**例题2：** 一个多边形的内角和是1440°，求这个多边形的边数。

解：

(n - 2) × 180° = 1440°

n - 2 = 8

n = 10

答：这个多边形是十边形。

**例题3：** 正十二边形的每个内角是多少度？

解：

内角和 = (12 - 2) × 180° = 10 × 180° = 1800°

每个内角 = 1800° / 12 = 150°

答：正十二边形的每个内角是150°。

**例题4：** 一个多边形的边数增加1，内角和增加多少？

解：

原内角和 = (n - 2) × 180°

新内角和 = (n + 1 - 2) × 180° = (n - 1) × 180°

增加 = (n - 1) × 180° - (n - 2) × 180° = 180°

答：内角和增加180°。

**例题5：** 在四边形ABCD中，∠A = 80°，∠B = 100°，∠C = 90°，求∠D。

解：

四边形内角和 = 360°

∠D = 360° - 80° - 100° - 90° = 90°

答：∠D是90°。

## 六、常见错误

**错误1：公式记错**

错误做法：n边形内角和 = n × 180°

正确公式：(n - 2) × 180°

**错误2：求边数时忘记减2**

错误做法：1440° / 180° = 8，所以是八边形。

正确做法：1440° / 180° = 8，n - 2 = 8，n = 10，是十边形。

**错误3：正多边形每个内角算错**

错误做法：正n边形每个内角 = 180° / n

正确公式：(n - 2) × 180° / n

**错误4：内角和不是180°的倍数**

错误做法：认为某个多边形内角和是500°。

正确理解：内角和一定是180°的整数倍。

**错误5：n的取值范围搞错**

错误做法：认为n可以是1或2。

正确理解：n ≥ 3，因为最少要有3条边才能组成多边形。

## 七、练习题

**练习1：** 求九边形的内角和。

解：

(9 - 2) × 180° = 7 × 180° = 1260°

答：九边形的内角和是1260°。

**练习2：** 一个多边形的内角和是900°，求这个多边形的边数。

解：

(n - 2) × 180° = 900°

n - 2 = 5

n = 7

答：这个多边形是七边形。

**练习3：** 正八边形的每个内角是多少度？

解：

内角和 = (8 - 2) × 180° = 1080°

每个内角 = 1080° / 8 = 135°

答：正八边形的每个内角是135°。

**练习4：** 一个多边形的内角和是1800°，求这个多边形的边数。

解：

(n - 2) × 180° = 1800°

n - 2 = 10

n = 12

答：这个多边形是十二边形。

**练习5：** 在五边形ABCDE中，∠A = 100°，∠B = 110°，∠C = 120°，∠D = 130°，求∠E。

解：

五边形内角和 = (5 - 2) × 180° = 540°

∠E = 540° - 100° - 110° - 120° - 130° = 80°

答：∠E是80°。
