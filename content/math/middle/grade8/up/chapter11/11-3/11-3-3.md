# 11.3.3 多边形外角和

## 一、从"绕着楼走一圈"引入

想象你绕着一栋楼走一圈。

在每个拐角处，你都要转过一个角。

走完一圈回到起点，你一共转过了多少度？

答案是360°，刚好转了一圈。

这个360°，就是多边形的外角和。

## 二、多边形外角和定理

**定理：多边形的外角和等于360°**

无论多边形有多少条边，外角和都是360°。

三角形外角和 = 360°

四边形外角和 = 360°

五边形外角和 = 360°

n边形外角和 = 360°

**外角和与边数无关**

这是多边形外角和最重要的特点。

内角和与边数有关，但外角和始终是360°。

## 三、推导过程

**推导方法**

每个顶点处：内角 + 外角 = 180°

n个顶点共：n × 180°

内角和：(n - 2) × 180°

外角和 = n × 180° - (n - 2) × 180°

= n × 180° - n × 180° + 2 × 180°

= 360°

**理解**

内角和随着边数增加而增加。

但外角和始终是360°，不变。

## 四、正n边形的外角

**正n边形每个外角**

正n边形每个外角 = 360° / n

比如正三角形每个外角 = 360° / 3 = 120°

正方形每个外角 = 360° / 4 = 90°

正五边形每个外角 = 360° / 5 = 72°

正六边形每个外角 = 360° / 6 = 60°

**内角与外角的关系**

内角 + 外角 = 180°

所以正n边形每个内角 = 180° - 360°/n

## 五、例题讲解

**例题1：** 求正十边形的每个外角。

解：

每个外角 = 360° / 10 = 36°

答：正十边形的每个外角是36°。

**例题2：** 一个正多边形的每个外角是45°，求这个多边形的边数。

解：

360° / n = 45°

n = 360° / 45° = 8

答：这个多边形是正八边形。

**例题3：** 一个正多边形的每个内角是144°，求这个多边形的边数。

解：

每个外角 = 180° - 144° = 36°

n = 360° / 36° = 10

答：这个多边形是正十边形。

**例题4：** 多边形的外角和与内角和相等，求这个多边形的边数。

解：

外角和 = 360°

内角和 = (n - 2) × 180°

(n - 2) × 180° = 360°

n - 2 = 2

n = 4

答：这个多边形是四边形。

**例题5：** 一个多边形的内角和是外角和的3倍，求这个多边形的边数。

解：

外角和 = 360°

内角和 = 3 × 360° = 1080°

(n - 2) × 180° = 1080°

n - 2 = 6

n = 8

答：这个多边形是八边形。

## 六、常见错误

**错误1：把外角和记成180°**

错误做法：多边形外角和是180°。

正确理解：多边形外角和是360°。

**错误2：和三角形外角性质混淆**

错误做法：三角形一个外角等于不相邻两内角和，所以外角和是180°。

正确理解：一个外角等于不相邻两内角和，但三个外角加起来是360°。

**错误3：正多边形外角算错**

错误做法：正n边形每个外角 = 180° / n

正确公式：360° / n

**错误4：外角和与边数有关**

错误做法：边数越多，外角和越大。

正确理解：外角和始终是360°，与边数无关。

**错误5：内角外角关系搞错**

错误做法：内角 = 外角

正确理解：内角 + 外角 = 180°

## 七、练习题

**练习1：** 求正十五边形的每个外角。

解：

每个外角 = 360° / 15 = 24°

答：正十五边形的每个外角是24°。

**练习2：** 一个正多边形的每个外角是30°，求这个多边形的边数。

解：

n = 360° / 30° = 12

答：这个多边形是正十二边形。

**练习3：** 一个正多边形的每个内角是150°，求这个多边形的边数。

解：

每个外角 = 180° - 150° = 30°

n = 360° / 30° = 12

答：这个多边形是正十二边形。

**练习4：** 一个多边形的内角和是外角和的2倍，求这个多边形的边数。

解：

外角和 = 360°

内角和 = 2 × 360° = 720°

(n - 2) × 180° = 720°

n - 2 = 4

n = 6

答：这个多边形是六边形。

**练习5：** 一个多边形的边数增加1，外角和增加多少？

解：

外角和始终是360°，与边数无关。

所以外角和增加0°。

答：外角和不增加，始终是360°。
