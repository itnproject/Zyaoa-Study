# 11.2.1 三角形内角和定理

## 一、从撕角实验引入

拿出一张纸，画一个三角形。

把三个角撕下来。

把三个角拼在一起，你会发现它们刚好拼成一个平角。

平角是多少度？180°。

所以三角形的三个内角加起来是180°。

## 二、三角形内角和定理

**定理：三角形的内角和等于180°**

在△ABC中，∠A + ∠B + ∠C = 180°

**证明思路**

过点A作直线DE平行于BC。

因为DE // BC，根据平行线的性质：

∠DAB = ∠B（内错角相等）

∠EAC = ∠C（内错角相等）

而∠DAB + ∠BAC + ∠EAC = 180°（平角）

所以∠B + ∠BAC + ∠C = 180°

即∠A + ∠B + ∠C = 180°

**几何书写格式**

在△ABC中，

∵ ∠A + ∠B + ∠C = 180°（三角形内角和定理）

∴ 已知其中两个角，可以求第三个角。

## 三、应用：已知两个角求第三个角

如果已知三角形的两个角，求第三个角：

第三个角 = 180° - 已知角1 - 已知角2

比如已知∠A = 50°，∠B = 60°，求∠C。

∠C = 180° - 50° - 60° = 70°

## 四、重要推论

**推论1：直角三角形的两个锐角互余**

在Rt△ABC中，∠C = 90°

所以∠A + ∠B = 180° - 90° = 90°

即直角三角形的两个锐角互余。

**推论2：三角形中最多有一个直角或一个钝角**

如果有两个直角，内角和至少是90° + 90° = 180°，第三个角为0°，不可能。

如果有两个钝角，内角和超过180°，不可能。

**推论3：等边三角形的每个内角都是60°**

等边三角形三边相等，三角也相等。

每个角 = 180° ÷ 3 = 60°

## 五、例题讲解

**例题1：** 在△ABC中，∠A = 40°，∠B = 70°，求∠C。

解：

∠C = 180° - ∠A - ∠B = 180° - 40° - 70° = 70°

答：∠C是70°。

**例题2：** 在△ABC中，∠A : ∠B : ∠C = 2 : 3 : 4，求三个角的度数。

解：

设∠A = 2x，∠B = 3x，∠C = 4x。

2x + 3x + 4x = 180°

9x = 180°

x = 20°

∠A = 40°，∠B = 60°，∠C = 80°

答：三个角分别是40°、60°、80°。

**例题3：** 在△ABC中，∠A = ∠B = 2∠C，求三个角的度数。

解：

设∠C = x，则∠A = ∠B = 2x。

2x + 2x + x = 180°

5x = 180°

x = 36°

∠A = 72°，∠B = 72°，∠C = 36°

答：三个角分别是72°、72°、36°。

**例题4：** 在△ABC中，∠A = 50°，∠B - ∠C = 30°，求∠B和∠C。

解：

∠B + ∠C = 180° - 50° = 130°

∠B - ∠C = 30°

两式相加：2∠B = 160°，∠B = 80°

∠C = 130° - 80° = 50°

答：∠B是80°，∠C是50°。

**例题5：** 一个三角形的三个内角中，最大的角是89°，这个三角形是什么三角形？

解：

最大角是89°，说明三个角都小于90°。

三个角都是锐角，所以是锐角三角形。

答：锐角三角形。

## 六、常见错误

**错误1：把外角和当内角和**

错误做法：三角形内角和是360°。

正确理解：三角形内角和是180°，外角和才是360°。

**错误2：漏掉直角90°**

错误做法：直角三角形中，认为两个锐角和是180°。

正确理解：直角三角形中，两个锐角和是90°。

**错误3：比例计算错误**

错误做法：∠A : ∠B : ∠C = 1 : 2 : 3，直接认为∠A = 1°。

正确做法：设∠A = x，∠B = 2x，∠C = 3x，x + 2x + 3x = 180°，x = 30°。

**错误4：忽略三角形内角和的前提**

错误做法：把四边形、五边形的内角和也当成180°。

正确理解：180°只适用于三角形。

**错误5：计算时漏掉一个角**

错误做法：180° - 50° = 130°，就认为第三个角是130°。

正确做法：180° - 50° - 60° = 70°，要减去两个已知角。

## 七、练习题

**练习1：** 在△ABC中，∠A = 60°，∠B = 50°，求∠C。

解：

∠C = 180° - 60° - 50° = 70°

答：∠C是70°。

**练习2：** 在△ABC中，∠A : ∠B : ∠C = 1 : 2 : 3，求三个角的度数，并判断是什么三角形。

解：

设∠A = x，∠B = 2x，∠C = 3x。

x + 2x + 3x = 180°

6x = 180°

x = 30°

∠A = 30°，∠B = 60°，∠C = 90°

最大角是90°，所以是直角三角形。

答：三个角分别是30°、60°、90°，是直角三角形。

**练习3：** 在等腰三角形中，顶角是40°，求底角。

解：

设底角为x。

40° + x + x = 180°

2x = 140°

x = 70°

答：底角是70°。

**练习4：** 在△ABC中，∠A = 3∠B，∠C = 2∠B，求三个角的度数。

解：

设∠B = x，则∠A = 3x，∠C = 2x。

3x + x + 2x = 180°

6x = 180°

x = 30°

∠A = 90°，∠B = 30°，∠C = 60°

答：三个角分别是90°、30°、60°。

**练习5：** 一个三角形的三个内角中，最小的角是46°，这个三角形是什么三角形？

解：

最小角是46°，设三个角分别是46°、x、y。

x + y = 180° - 46° = 134°

因为x ≥ 46°，y ≥ 46°，且x + y = 134°

如果x = 46°，则y = 88°，三个角都小于90°，是锐角三角形。

如果x > 46°，y可能大于90°。

比如x = 50°，y = 84°，还是锐角三角形。

比如x = 47°，y = 87°，还是锐角三角形。

但x可以更大，比如x = 90°，y = 44°，但y < 46°，矛盾。

所以y最大是134° - 46° = 88° < 90°。

三个角都小于90°，所以一定是锐角三角形。

答：锐角三角形。
