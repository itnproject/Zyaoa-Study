# 11.2.2 直角三角形的两个锐角互余

## 一、从直角三角板引入

你用过直角三角板吗？

直角三角板有一个直角和两个锐角。

你量过这两个锐角吗？

你会发现，这两个锐角加起来刚好是90°。

这就是直角三角形的一个重要性质。

## 二、直角三角形的性质

**性质：直角三角形的两个锐角互余**

在Rt△ABC中，∠C = 90°

所以∠A + ∠B = 180° - 90° = 90°

即∠A和∠B互余。

**互余的定义**

如果两个角的和是90°，就说这两个角互余。

比如30°和60°互余，45°和45°互余。

**几何语言表示**

在Rt△ABC中，∵ ∠C = 90°

∴ ∠A + ∠B = 90°

## 三、逆定理

**逆定理：有两个角互余的三角形是直角三角形**

在△ABC中，如果∠A + ∠B = 90°

那么∠C = 180° - (∠A + ∠B) = 180° - 90° = 90°

所以△ABC是直角三角形。

**记号**

直角三角形用"Rt△"表示。

比如直角三角形ABC，记作Rt△ABC。

## 四、应用

**求角度**

已知直角三角形的一个锐角，求另一个锐角。

另一个锐角 = 90° - 已知锐角

比如已知一个锐角是35°，另一个锐角 = 90° - 35° = 55°。

**证直角**

要证明一个三角形是直角三角形，可以证明其中两个角互余。

## 五、例题讲解

**例题1：** 在Rt△ABC中，∠C = 90°，∠A = 35°，求∠B。

解：

因为∠C = 90°，所以∠A + ∠B = 90°

∠B = 90° - ∠A = 90° - 35° = 55°

答：∠B是55°。

**例题2：** 在△ABC中，∠A = 40°，∠B = 50°。判断△ABC是什么三角形。

解：

∠A + ∠B = 40° + 50° = 90°

所以∠C = 180° - 90° = 90°

所以△ABC是直角三角形。

答：△ABC是直角三角形。

**例题3：** 在Rt△ABC中，∠C = 90°，∠A = 2∠B，求∠A和∠B。

解：

因为∠A + ∠B = 90°，且∠A = 2∠B

所以2∠B + ∠B = 90°

3∠B = 90°

∠B = 30°

∠A = 60°

答：∠A是60°，∠B是30°。

**例题4：** 在△ABC中，CD⊥AB，垂足为D。已知∠A = 30°，求∠ACD。

解：

因为CD⊥AB，所以∠ADC = 90°

在Rt△ADC中，∠A + ∠ACD = 90°

∠ACD = 90° - 30° = 60°

答：∠ACD是60°。

**例题5：** 在Rt△ABC中，∠C = 90°，CD是AB边上的高。已知∠A = 40°，求∠BCD。

解：

在Rt△ABC中，∠B = 90° - ∠A = 90° - 40° = 50°

因为CD是高，所以∠CDB = 90°

在Rt△CDB中，∠BCD = 90° - ∠B = 90° - 50° = 40°

答：∠BCD是40°。

## 六、常见错误

**错误1：把互余当成互补**

错误做法：直角三角形两个锐角和是180°。

正确理解：直角三角形两个锐角和是90°（互余），不是180°（互补）。

**错误2：忽略直角90°**

错误做法：直角三角形中，三个角加起来是90°。

正确理解：直角三角形中，三个角加起来是180°，其中一个是90°。

**错误3：逆定理用错**

错误做法：有一个角是90°的三角形，两个锐角不一定互余。

正确理解：有一个角是90°，另外两个角一定互余。

**错误4：记号写错**

错误做法：直角三角形写成"RT△"。

正确写法：直角三角形写成"Rt△"。

**错误5：求角时算错**

错误做法：90° - 35° = 65°。

正确计算：90° - 35° = 55°。

## 七、练习题

**练习1：** 在Rt△ABC中，∠C = 90°，∠B = 65°，求∠A。

解：

∠A = 90° - ∠B = 90° - 65° = 25°

答：∠A是25°。

**练习2：** 在△ABC中，∠A = 55°，∠B = 35°。判断△ABC是什么三角形。

解：

∠A + ∠B = 55° + 35° = 90°

所以∠C = 180° - 90° = 90°

所以△ABC是直角三角形。

答：直角三角形。

**练习3：** 在Rt△ABC中，∠C = 90°，∠A - ∠B = 20°，求∠A和∠B。

解：

∠A + ∠B = 90°

∠A - ∠B = 20°

两式相加：2∠A = 110°，∠A = 55°

∠B = 90° - 55° = 35°

答：∠A是55°，∠B是35°。

**练习4：** 在Rt△ABC中，∠C = 90°，CD是AB边上的高。已知∠B = 50°，求∠ACD。

解：

在Rt△ABC中，∠A = 90° - ∠B = 90° - 50° = 40°

因为CD是高，所以∠ADC = 90°

在Rt△ADC中，∠ACD = 90° - ∠A = 90° - 40° = 50°

答：∠ACD是50°。

**练习5：** 在△ABC中，∠A + ∠B = 90°，∠A = 2∠B。求三个角的度数。

解：

因为∠A + ∠B = 90°，且∠A = 2∠B

所以2∠B + ∠B = 90°

3∠B = 90°

∠B = 30°

∠A = 60°

∠C = 180° - 90° = 90°

答：三个角分别是60°、30°、90°。
