# 11.2.3 三角形的外角

## 一、从延长边引入

画一个三角形ABC。

把BC边延长到点D。

∠ACD就是三角形的一个外角。

外角就是三角形的一边与另一边的延长线组成的角。

## 二、外角的定义

三角形的一边与另一边的延长线组成的角，叫做三角形的外角。

在△ABC中，延长BC到D，则∠ACD是△ABC的一个外角。

## 三、三角形有多少个外角

每个顶点处有2个外角（两边各延长一次）。

三角形有3个顶点，所以有6个外角。

每个顶点处的两个外角互为对顶角，所以相等。

通常我们只考虑每个顶点处的一个外角，共3个。

## 四、外角的性质

**性质1：三角形的一个外角等于与它不相邻的两个内角的和**

在△ABC中，延长BC到D，则∠ACD = ∠A + ∠B。

推导：

∠ACB + ∠ACD = 180°（邻补角）

∠A + ∠B + ∠ACB = 180°（三角形内角和）

所以∠ACD = ∠A + ∠B

**性质2：三角形的一个外角大于任何一个与它不相邻的内角**

在△ABC中，∠ACD = ∠A + ∠B

所以∠ACD > ∠A，∠ACD > ∠B

## 五、外角和

三角形的外角和 = 360°

推导：

每个顶点处的外角 + 内角 = 180°

三个顶点共 3 × 180° = 540°

减去内角和180°

外角和 = 540° - 180° = 360°

## 六、例题讲解

**例题1：** 在△ABC中，∠A = 50°，∠B = 60°，求∠C的外角。

解：

∠C的外角 = ∠A + ∠B = 50° + 60° = 110°

答：∠C的外角是110°。

**例题2：** 在△ABC中，∠A = 40°，∠C的外角是100°，求∠B。

解：

∠C的外角 = ∠A + ∠B

100° = 40° + ∠B

∠B = 60°

答：∠B是60°。

**例题3：** 在△ABC中，∠A的外角是120°，∠B的外角是110°，求∠C。

解：

∠A = 180° - 120° = 60°

∠B = 180° - 110° = 70°

∠C = 180° - 60° - 70° = 50°

答：∠C是50°。

**例题4：** 三角形的外角和是多少？

解：

三角形的外角和 = 360°

答：360°。

**例题5：** 在△ABC中，D是BC延长线上一点。已知∠A = 70°，∠ACD = 120°，求∠B。

解：

∠ACD是△ABC的外角。

∠ACD = ∠A + ∠B

120° = 70° + ∠B

∠B = 50°

答：∠B是50°。

## 七、常见错误

**错误1：把相邻内角当成不相邻内角**

错误做法：∠ACD = ∠C + ∠B。

正确理解：外角等于不相邻的两个内角和，∠ACD = ∠A + ∠B。

**错误2：算外角和算成180°**

错误做法：三角形外角和是180°。

正确理解：三角形外角和是360°，内角和才是180°。

**错误3：外角定义搞错**

错误做法：外角是三角形外面的角。

正确理解：外角是一边与另一边延长线组成的角。

**错误4：漏掉"不相邻"这个关键词**

错误做法：外角等于两个内角和。

正确理解：外角等于与它不相邻的两个内角和。

**错误5：外角与内角的关系搞反**

错误做法：内角 = 外角 + 另一个内角。

正确理解：外角 = 两个不相邻内角和。

## 八、练习题

**练习1：** 在△ABC中，∠A = 30°，∠B = 80°，求∠C的外角。

解：

∠C的外角 = ∠A + ∠B = 30° + 80° = 110°

答：∠C的外角是110°。

**练习2：** 在△ABC中，∠A的外角是150°，∠B = 70°，求∠C。

解：

∠A = 180° - 150° = 30°

∠C = 180° - ∠A - ∠B = 180° - 30° - 70° = 80°

答：∠C是80°。

**练习3：** 在△ABC中，D是BC延长线上一点。已知∠B = 45°，∠ACD = 100°，求∠A。

解：

∠ACD = ∠A + ∠B

100° = ∠A + 45°

∠A = 55°

答：∠A是55°。

**练习4：** 三角形的一个外角是130°，与它不相邻的一个内角是50°，求另一个不相邻的内角。

解：

外角 = 两个不相邻内角和

130° = 50° + 另一个内角

另一个内角 = 80°

答：另一个不相邻的内角是80°。

**练习5：** 在△ABC中，∠A : ∠B : ∠C = 2 : 3 : 4，求∠A、∠B、∠C的外角。

解：

设∠A = 2x，∠B = 3x，∠C = 4x。

2x + 3x + 4x = 180°

9x = 180°

x = 20°

∠A = 40°，∠B = 60°，∠C = 80°

∠A的外角 = 180° - 40° = 140°

∠B的外角 = 180° - 60° = 120°

∠C的外角 = 180° - 80° = 100°

答：∠A、∠B、∠C的外角分别是140°、120°、100°。
