# 15.4.2 条件分式的求值

## 一、已知条件变形后整体代入

**已知条件变形**

把已知条件变形。

整体代入要求的式子。

**例子**

已知x+1/x = 3，求x²+1/x²。

x²+1/x² = (x+1/x)² - 2 = 9 - 2 = 7。

## 二、设k法

**已知比例关系时设未知数**

已知x/y = 2/3。

设x = 2k，y = 3k。

代入求值。

**例子**

已知x/y = 2/3，求(x+y)/y。

(x+y)/y = (2k+3k)/(3k) = 5k/(3k) = 5/3。

## 三、倒数法

**分子分母互换的技巧**

已知x+1/x = a。

求1/x+x = a（一样的）。

已知x-1/x = a。

求1/x-x = -a。

## 四、构造法

**创造条件使用公式**

已知x+y = a，xy = b。

求x²+y²。

x²+y² = (x+y)² - 2xy = a² - 2b。

## 五、例题讲解

**例题1：** 已知x+1/x = 3，求x²+1/x²的值。

解：

x²+1/x² = (x+1/x)² - 2

= 3² - 2

= 9 - 2

= 7

答：7。

**例题2：** 已知x/y = 2/3，求(2x+y)/(x-y)的值。

解：

设x = 2k，y = 3k。

(2x+y)/(x-y) = (4k+3k)/(2k-3k) = 7k/(-k) = -7

答：-7。

**例题3：** 已知x-1/x = 2，求x²+1/x²的值。

解：

x²+1/x² = (x-1/x)² + 2

= 2² + 2

= 4 + 2

= 6

答：6。

**例题4：** 已知x+y = 5，xy = 6，求x/y+y/x的值。

解：

x/y+y/x = (x²+y²)/(xy)

x²+y² = (x+y)² - 2xy = 25 - 12 = 13

x/y+y/x = 13/6

答：13/6。

**例题5：** 已知a/b = 3/4，b/c = 5/6，求a/c的值。

解：

a/c = (a/b) × (b/c)

= 3/4 × 5/6

= 15/24

= 5/8

答：5/8。

## 六、常见错误

**错误1：完全平方公式用错**

错误做法：(x+1/x)² = x²+1/x²。

正确理解：(x+1/x)² = x²+2+1/x²。

**错误2：设k法时k消不掉**

错误做法：设k后代入，k没有消掉。

正确理解：设k后k应该能消掉。

**错误3：符号搞错**

错误做法：x-1/x = 2，x²+1/x² = (x-1/x)² - 2。

正确理解：x²+1/x² = (x-1/x)² + 2。

**错误4：整体代入时搞错**

错误做法：已知x+1/x = 3，求x³+1/x³时直接用3³。

正确理解：x³+1/x³ = (x+1/x)³ - 3(x+1/x) = 27 - 9 = 18。

**错误5：比例关系搞错**

错误做法：a/b = 3/4，b/c = 5/6，a/c = 3/4 + 5/6。

正确理解：a/c = (a/b) × (b/c)。

## 七、练习题

**练习1：** 已知x+1/x = 4，求x²+1/x²的值。

解：

x²+1/x² = (x+1/x)² - 2

= 4² - 2

= 16 - 2

= 14

答：14。

**练习2：** 已知x/y = 3/5，求(x+2y)/(x-y)的值。

解：

设x = 3k，y = 5k。

(x+2y)/(x-y) = (3k+10k)/(3k-5k) = 13k/(-2k) = -13/2

答：-13/2。

**练习3：** 已知x-1/x = 3，求x²+1/x²的值。

解：

x²+1/x² = (x-1/x)² + 2

= 3² + 2

= 9 + 2

= 11

答：11。

**练习4：** 已知x+y = 4，xy = 3，求x²/y+y²/x的值。

解：

x²/y+y²/x = (x³+y³)/(xy)

x³+y³ = (x+y)³ - 3xy(x+y) = 64 - 36 = 28

x²/y+y²/x = 28/3

答：28/3。

**练习5：** 已知a/b = 2/3，b/c = 4/5，求a/c的值。

解：

a/c = (a/b) × (b/c)

= 2/3 × 4/5

= 8/15

答：8/15。
