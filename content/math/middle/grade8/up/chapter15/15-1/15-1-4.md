# 15.1.4 分式的通分

## 一、通分的定义

**通分：把几个异分母分式化成同分母分式**

和分数通分类似。

1/2 + 1/3 = 3/6 + 2/6 = 5/6

分式通分也是同样的道理。

## 二、最简公分母

**最简公分母：各分母所有因式的最高次幂的积**

**找最简公分母的方法**

系数：取各分母系数的最小公倍数。

字母：取各分母中所有字母的最高次幂。

多项式：先因式分解，再取各因式的最高次幂。

## 三、通分步骤

**第一步：找最简公分母**

对每个分母因式分解。

取所有因式的最高次幂相乘。

**第二步：分子分母同乘相应因式**

每个分式分子分母同乘缺少的因式。

## 四、系数和字母的处理

**系数取最小公倍数**

2和3的最小公倍数是6。

**字母取最高次幂**

x和x²的最高次幂是x²。

## 五、例题讲解

**例题1：** 通分：1/(2x) 和 1/(3x²)

解：

找最简公分母：

系数：2和3的最小公倍数是6。

x：x和x²的最高次幂是x²。

最简公分母：6x²

1/(2x) = (1·3x)/(2x·3x) = 3x/(6x²)

1/(3x²) = (1·2)/(3x²·2) = 2/(6x²)

答：3x/(6x²) 和 2/(6x²)。

**例题2：** 通分：1/x 和 1/(x+1)

解：

找最简公分母：

分母：x 和 x+1

最简公分母：x(x+1)

1/x = (1·(x+1))/[x·(x+1)] = (x+1)/[x(x+1)]

1/(x+1) = (1·x)/[(x+1)·x] = x/[x(x+1)]

答：(x+1)/[x(x+1)] 和 x/[x(x+1)]。

**例题3：** 通分：1/(x-1) 和 1/(x²-1)

解：

分母因式分解：

x-1 = x-1

x²-1 = (x+1)(x-1)

最简公分母：(x+1)(x-1)

1/(x-1) = (1·(x+1))/[(x-1)·(x+1)] = (x+1)/[(x+1)(x-1)]

1/(x²-1) = 1/[(x+1)(x-1)]

答：(x+1)/[(x+1)(x-1)] 和 1/[(x+1)(x-1)]。

**例题4：** 通分：2/(3x) 和 3/(2y)

解：

找最简公分母：

系数：3和2的最小公倍数是6。

字母：x和y的最高次幂是xy。

最简公分母：6xy

2/(3x) = (2·2y)/(3x·2y) = 4y/(6xy)

3/(2y) = (3·3x)/(2y·3x) = 9x/(6xy)

答：4y/(6xy) 和 9x/(6xy)。

**例题5：** 通分：1/(x²-4) 和 1/(x+2)

解：

分母因式分解：

x²-4 = (x+2)(x-2)

x+2 = x+2

最简公分母：(x+2)(x-2)

1/(x²-4) = 1/[(x+2)(x-2)]

1/(x+2) = (1·(x-2))/[(x+2)·(x-2)] = (x-2)/[(x+2)(x-2)]

答：1/[(x+2)(x-2)] 和 (x-2)/[(x+2)(x-2)]。

## 六、常见错误

**错误1：最简公分母找错**

错误做法：1/(2x) 和 1/(3x) 的最简公分母是x。

正确理解：系数最小公倍数是6，最简公分母是6x。

**错误2：没有先因式分解**

错误做法：1/(x²-1) 和 1/(x-1) 的最简公分母是(x²-1)(x-1)。

正确理解：x²-1 = (x+1)(x-1)，最简公分母是(x+1)(x-1)。

**错误3：分子没有同乘**

错误做法：1/x = 1/[x(x+1)]。

正确理解：1/x = (x+1)/[x(x+1)]。

**错误4：漏掉某个因式**

错误做法：1/(x-1) 和 1/(x+1) 的最简公分母是x-1。

正确理解：最简公分母是(x-1)(x+1)。

**错误5：系数没有取最小公倍数**

错误做法：1/(4x) 和 1/(6x) 的最简公分母是24x。

正确理解：4和6的最小公倍数是12，最简公分母是12x。

## 七、练习题

**练习1：** 通分：1/(3x) 和 1/(4x²)

解：

系数：3和4的最小公倍数是12。

x：x和x²的最高次幂是x²。

最简公分母：12x²

1/(3x) = 4x/(12x²)

1/(4x²) = 3/(12x²)

答：4x/(12x²) 和 3/(12x²)。

**练习2：** 通分：1/(x+2) 和 1/(x-2)

解：

最简公分母：(x+2)(x-2)

1/(x+2) = (x-2)/[(x+2)(x-2)]

1/(x-2) = (x+2)/[(x+2)(x-2)]

答：(x-2)/[(x+2)(x-2)] 和 (x+2)/[(x+2)(x-2)]。

**练习3：** 通分：2/(x²-x) 和 1/(x-1)

解：

分母因式分解：

x²-x = x(x-1)

x-1 = x-1

最简公分母：x(x-1)

2/(x²-x) = 2/[x(x-1)]

1/(x-1) = x/[x(x-1)]

答：2/[x(x-1)] 和 x/[x(x-1)]。

**练习4：** 通分：1/(2x+2) 和 1/(3x+3)

解：

分母因式分解：

2x+2 = 2(x+1)

3x+3 = 3(x+1)

最简公分母：6(x+1)

1/[2(x+1)] = 3/[6(x+1)]

1/[3(x+1)] = 2/[6(x+1)]

答：3/[6(x+1)] 和 2/[6(x+1)]。

**练习5：** 通分：1/(x²-9) 和 1/(x²+3x)

解：

分母因式分解：

x²-9 = (x+3)(x-3)

x²+3x = x(x+3)

最简公分母：x(x+3)(x-3)

1/[(x+3)(x-3)] = x/[x(x+3)(x-3)]

1/[x(x+3)] = (x-3)/[x(x+3)(x-3)]

答：x/[x(x+3)(x-3)] 和 (x-3)/[x(x+3)(x-3)]。
