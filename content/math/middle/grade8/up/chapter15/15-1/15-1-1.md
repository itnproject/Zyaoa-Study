# 15.1.1 从分数到分式

## 一、从生活实例引入

小明把3个蛋糕平均分给4个人。

每人分到多少？

3 ÷ 4 = 3/4 个蛋糕。

小红走了120千米，用了t小时。

速度是多少？

速度 = 120 ÷ t = 120/t 千米/小时。

这里的120/t，分母里有字母t。

这就是分式。

## 二、分式的定义

**分式：形如A/B的式子，其中A、B都是整式，B中含有字母，且B≠0**

A叫做分子，B叫做分母。

**例子**

3/x 是分式，分母x含有字母。

(x+1)/(x-2) 是分式，分母x-2含有字母。

3/4 不是分式，分母4不含字母，这是分数。

## 三、分子和分母都是整式

**整式：单项式和多项式的统称**

分子可以是单项式：3x

分子可以是多项式：x+1

分母可以是单项式：x

分母可以是多项式：x²-1

**关键：分母中必须含有字母**

## 四、分式有意义的条件

**分式有意义的条件：分母≠0**

分母为0时，分式无意义。

**例子**

1/x 有意义的条件：x ≠ 0

3/(x-2) 有意义的条件：x - 2 ≠ 0，即 x ≠ 2

(x+1)/(x²-1) 有意义的条件：x² - 1 ≠ 0，即 x ≠ 1 且 x ≠ -1

## 五、分式值为0的条件

**分式值为0的条件：分子=0 且 分母≠0**

两个条件必须同时满足。

**例子**

(x-3)/(x+1) = 0

分子 x - 3 = 0，得 x = 3

分母 x + 1 ≠ 0，即 x ≠ -1

x = 3 满足分母≠0。

所以 x = 3 时分式值为0。

## 六、区分整式和分式

**整式：分母不含字母**

3x、x²+1、5 都是整式。

**分式：分母含有字母**

3/x、(x+1)/(x-2)、5/(x²+1) 都是分式。

**判断方法：看分母有没有字母**

有字母→分式

没字母→整式

## 七、例题讲解

**例题1：** 判断下列式子哪些是分式：3/x，x/3，(x+1)/π，2/(x-1)

解：

3/x：分母x含字母，是分式。

x/3：分母3不含字母，不是分式。

(x+1)/π：分母π是常数，不含字母，不是分式。

2/(x-1)：分母x-1含字母，是分式。

答：3/x 和 2/(x-1) 是分式。

**例题2：** 当x取何值时，分式 3/(x-2) 有意义？

解：

分式有意义的条件：分母≠0

x - 2 ≠ 0

x ≠ 2

答：x ≠ 2 时分式有意义。

**例题3：** 当x取何值时，分式 (x+1)/(x²-4) 有意义？

解：

分式有意义的条件：分母≠0

x² - 4 ≠ 0

(x+2)(x-2) ≠ 0

x ≠ -2 且 x ≠ 2

答：x ≠ -2 且 x ≠ 2 时分式有意义。

**例题4：** 当x取何值时，分式 (x-3)/(x+2) 的值为0？

解：

分式值为0的条件：分子=0 且 分母≠0

分子 x - 3 = 0，得 x = 3

分母 x + 2 ≠ 0，即 x ≠ -2

x = 3 满足 x ≠ -2。

答：x = 3 时分式值为0。

**例题5：** 当x取何值时，分式 (x²-1)/(x+1) 的值为0？

解：

分子 x² - 1 = 0

(x+1)(x-1) = 0

x = -1 或 x = 1

分母 x + 1 ≠ 0，即 x ≠ -1

x = -1 不满足分母≠0，舍去。

x = 1 满足分母≠0。

答：x = 1 时分式值为0。

## 八、常见错误

**错误1：分母为0时分式仍有意义**

错误做法：1/0 = 无意义，但认为x=0时1/x有意义。

正确理解：分母为0时分式无意义。

**错误2：分式值为0只看分子**

错误做法：(x-1)/(x+1) = 0，只看x-1=0得x=1。

正确理解：还要验证分母≠0，x=1时分母2≠0，正确。

**错误3：把分数当成分式**

错误做法：3/4 是分式。

正确理解：3/4 分母不含字母，是分数不是分式。

**错误4：分母含多个字母时漏解**

错误做法：1/(x-1)(x+2) 有意义条件只写x≠1。

正确理解：x≠1 且 x≠-2。

**错误5：分子为0但分母也为0**

错误做法：(x-1)/(x-1) = 0 时 x = 1。

正确理解：x=1时分母也为0，分式无意义，值不为0。

## 九、练习题

**练习1：** 判断下列式子哪些是分式：5/x，(x+2)/3，x/(x-1)，π/2

解：

5/x：分母x含字母，是分式。

(x+2)/3：分母3不含字母，不是分式。

x/(x-1)：分母x-1含字母，是分式。

π/2：分母2不含字母，不是分式。

答：5/x 和 x/(x-1) 是分式。

**练习2：** 当x取何值时，分式 2/(x+3) 有意义？

解：

分母 x + 3 ≠ 0

x ≠ -3

答：x ≠ -3 时分式有意义。

**练习3：** 当x取何值时，分式 (x+2)/(x²-9) 有意义？

解：

分母 x² - 9 ≠ 0

(x+3)(x-3) ≠ 0

x ≠ -3 且 x ≠ 3

答：x ≠ -3 且 x ≠ 3 时分式有意义。

**练习4：** 当x取何值时，分式 (x-5)/(x+3) 的值为0？

解：

分子 x - 5 = 0，得 x = 5

分母 x + 3 ≠ 0，即 x ≠ -3

x = 5 满足 x ≠ -3。

答：x = 5 时分式值为0。

**练习5：** 当x取何值时，分式 (x²-4)/(x-2) 的值为0？

解：

分子 x² - 4 = 0

(x+2)(x-2) = 0

x = -2 或 x = 2

分母 x - 2 ≠ 0，即 x ≠ 2

x = 2 不满足分母≠0，舍去。

x = -2 满足分母≠0。

答：x = -2 时分式值为0。
