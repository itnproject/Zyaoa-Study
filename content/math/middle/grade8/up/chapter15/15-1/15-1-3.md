# 15.1.3 分式的约分

## 一、约分的定义

**约分：把分式中分子分母的公因式约去**

和分数约分类似。

6/8 = 3/4（分子分母同除以2）

分式约分也是同样的道理。

## 二、最简分式

**最简分式：分子分母没有公因式的分式**

约分要进行到最简分式为止。

**例子**

2x/4x² = 1/(2x) 是最简分式。

(x²-1)/(x+1) = x-1 约分后是整式。

## 三、约分步骤

**第一步：找公因式**

系数：取最大公约数。

字母：取相同字母的最低次幂。

多项式：先因式分解再找公因式。

**第二步：约去公因式**

分子分母同除以公因式。

## 四、系数和字母的处理

**系数约最大公约数**

6和9的最大公约数是3。

**字母约相同字母的最低次幂**

x²和x的最低次幂是x。

## 五、注意符号的处理

**分子或分母有负号**

可以把负号提到分式前面。

-x/(x+1) = -(x/(x+1))

**分子分母都有负号**

负号可以约去。

(-x)/(-y) = x/y

## 六、例题讲解

**例题1：** 约分：6x²y/9xy²

解：

系数：6和9的最大公约数是3。

x：x²和x的最低次幂是x。

y：y和y²的最低次幂是y。

公因式：3xy

6x²y ÷ 3xy = 2x

9xy² ÷ 3xy = 3y

6x²y/9xy² = 2x/(3y)

答：2x/(3y)。

**例题2：** 约分：(x²-4)/(x+2)

解：

分子因式分解：x²-4 = (x+2)(x-2)

(x²-4)/(x+2) = (x+2)(x-2)/(x+2) = x-2

答：x-2。

**例题3：** 约分：(x²-2x+1)/(x²-1)

解：

分子：x²-2x+1 = (x-1)²

分母：x²-1 = (x+1)(x-1)

公因式：x-1

(x-1)²/[(x+1)(x-1)] = (x-1)/(x+1)

答：(x-1)/(x+1)。

**例题4：** 约分：(4-x²)/(x-2)

解：

分子：4-x² = -(x²-4) = -(x+2)(x-2)

(4-x²)/(x-2) = -(x+2)(x-2)/(x-2) = -(x+2) = -x-2

答：-x-2。

**例题5：** 约分：(x²+2x)/(x²+4x+4)

解：

分子：x²+2x = x(x+2)

分母：x²+4x+4 = (x+2)²

公因式：x+2

x(x+2)/(x+2)² = x/(x+2)

答：x/(x+2)。

## 七、常见错误

**错误1：没有先因式分解就约分**

错误做法：(x²-4)/(x+2) 直接约。

正确理解：先因式分解，(x+2)(x-2)/(x+2) = x-2。

**错误2：约分不彻底**

错误做法：6x²/9x = 2x²/3x。

正确理解：6x²/9x = 2x/3。

**错误3：只约分子或只约分母**

错误做法：6x/9 = 2x/9。

正确理解：6x/9 = 2x/3。

**错误4：符号处理错误**

错误做法：(4-x²)/(x-2) = x+2。

正确理解：(4-x²)/(x-2) = -(x+2) = -x-2。

**错误5：约去不是公因式的项**

错误做法：(x+2)/(x+3) = 2/3。

正确理解：x+2和x+3没有公因式，不能约分。

## 八、练习题

**练习1：** 约分：8a³b²/12a²b³

解：

系数：8和12的最大公约数是4。

a：a³和a²的最低次幂是a²。

b：b²和b³的最低次幂是b²。

公因式：4a²b²

8a³b² ÷ 4a²b² = 2a

12a²b³ ÷ 4a²b² = 3b

8a³b²/12a²b³ = 2a/(3b)

答：2a/(3b)。

**练习2：** 约分：(x²-9)/(x-3)

解：

分子：x²-9 = (x+3)(x-3)

(x²-9)/(x-3) = (x+3)(x-3)/(x-3) = x+3

答：x+3。

**练习3：** 约分：(x²-6x+9)/(x²-9)

解：

分子：x²-6x+9 = (x-3)²

分母：x²-9 = (x+3)(x-3)

公因式：x-3

(x-3)²/[(x+3)(x-3)] = (x-3)/(x+3)

答：(x-3)/(x+3)。

**练习4：** 约分：(x-x²)/(x²-1)

解：

分子：x-x² = -x(x-1)

分母：x²-1 = (x+1)(x-1)

公因式：x-1

-x(x-1)/[(x+1)(x-1)] = -x/(x+1)

答：-x/(x+1)。

**练习5：** 约分：(x²+3x+2)/(x²+5x+6)

解：

分子：x²+3x+2 = (x+1)(x+2)

分母：x²+5x+6 = (x+2)(x+3)

公因式：x+2

(x+1)(x+2)/[(x+2)(x+3)] = (x+1)/(x+3)

答：(x+1)/(x+3)。
