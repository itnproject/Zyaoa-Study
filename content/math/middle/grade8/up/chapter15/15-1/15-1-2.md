# 15.1.2 分式的基本性质

## 一、类比分数的基本性质

分数的基本性质：分数的分子分母同乘或同除以同一个不为0的数，分数值不变。

2/3 = 2×2 / 3×2 = 4/6

分式也有类似的性质。

## 二、分式的基本性质

**性质：分式的分子与分母同乘（或除以）同一个不等于0的整式，分式的值不变**

**公式：A/B = (A·C)/(B·C)（C≠0）**

**公式：A/B = (A÷C)/(B÷C)（C≠0）**

**注意：C必须是不等于0的整式**

## 三、为什么C不能为0

因为0不能做除数。

如果C=0，那么B·C=0，分母为0分式无意义。

所以C必须不等于0。

## 四、性质的应用

**化简分式**

6x/9x² = (6x÷3x)/(9x²÷3x) = 2/(3x)

**通分**

1/x = (1·2x)/(x·2x) = 2x/(2x²)

**变形**

x/(x+1) = x(x-1)/[(x+1)(x-1)] = x(x-1)/(x²-1)

## 五、例题讲解

**例题1：** 填空：2/x = ( )/(3x)

解：

分母从x变成3x，乘了3。

分子也要乘3。

2 × 3 = 6

2/x = 6/(3x)

答：6。

**例题2：** 填空：(x+1)/(x-1) = (x²-1)/( )

解：

分子从x+1变成x²-1。

x²-1 = (x+1)(x-1)，乘了x-1。

分母也要乘x-1。

(x-1)(x-1) = (x-1)²

答：(x-1)²。

**例题3：** 化简：6x²y/9xy²

解：

找分子分母的公因式：3xy

6x²y ÷ 3xy = 2x

9xy² ÷ 3xy = 3y

6x²y/9xy² = 2x/(3y)

答：2x/(3y)。

**例题4：** 不改变分式的值，使分子分母的最高次项系数为正：-x/(x-1)

解：

分子分母同乘-1：

-x/(x-1) = (-x)×(-1) / [(x-1)×(-1)] = x/(1-x)

答：x/(1-x)。

**例题5：** 判断下列变形是否正确：x/(x+1) = x²/(x²+x)

解：

右边分母x²+x = x(x+1)

右边 = x²/[x(x+1)] = x/(x+1)（x≠0）

左边 = x/(x+1)

左边=右边，变形正确（x≠0）。

答：正确（x≠0）。

## 六、常见错误

**错误1：C可以为0**

错误做法：A/B = (A·0)/(B·0)。

正确理解：C≠0，0不能做除数。

**错误2：只乘分子不乘分母**

错误做法：x/(x+1) = x²/(x+1)。

正确理解：分子分母要同乘，x/(x+1) = x²/(x²+x)。

**错误3：分子分母乘不同的式子**

错误做法：x/(x+1) = 2x/[3(x+1)]。

正确理解：要同乘同一个式子。

**错误4：忽略C≠0的条件**

错误做法：x/x = 1（x可以为0）。

正确理解：x/x = 1（x≠0）。

**错误5：符号处理错误**

错误做法：-x/(x-1) = x/(x-1)。

正确理解：-x/(x-1) = x/(1-x)。

## 七、练习题

**练习1：** 填空：3/x = ( )/(xy)

解：

分母从x变成xy，乘了y。

分子也要乘y。

3 × y = 3y

答：3y。

**练习2：** 填空：2/(x+1) = (2x)/( )

解：

分子从2变成2x，乘了x。

分母也要乘x。

(x+1) × x = x(x+1)

答：x(x+1)。

**练习3：** 化简：12a³b/18a²b²

解：

公因式：6a²b

12a³b ÷ 6a²b = 2a

18a²b² ÷ 6a²b = 3b

12a³b/18a²b² = 2a/(3b)

答：2a/(3b)。

**练习4：** 不改变分式的值，使分子分母的最高次项系数为正：-x²/(1-x)

解：

分子分母同乘-1：

-x²/(1-x) = x²/(x-1)

答：x²/(x-1)。

**练习5：** 判断下列变形是否正确：(x-1)/(x+1) = (x²-1)/(x²+2x+1)

解：

右边分子x²-1 = (x-1)(x+1)

右边分母x²+2x+1 = (x+1)²

右边 = (x-1)(x+1)/(x+1)² = (x-1)/(x+1)

左边 = (x-1)/(x+1)

左边=右边，变形正确。

答：正确。
