# 15.2.2 分式的加减

## 一、同分母分式加减

**法则：分母不变，分子相加减**

**公式：a/c + b/c = (a+b)/c**

**公式：a/c - b/c = (a-b)/c**

和同分母分数加减法完全一样。

2/5 + 1/5 = 3/5

x/y + 3/y = (x+3)/y

## 二、异分母分式加减

**法则：先通分，再加减**

和异分母分数加减法一样。

1/2 + 1/3 = 3/6 + 2/6 = 5/6

## 三、运算步骤

**第一步：通分**

找最简公分母。

把各分式化成同分母。

**第二步：加减**

分母不变，分子相加减。

**第三步：化简**

约分到最简分式。

## 四、注意分子相加减时要加括号

**减法时分子要加括号**

a/c - b/c = (a-b)/c

如果分子是多项式，更要加括号。

(x+1)/(x-1) - (x-2)/(x-1) = [(x+1)-(x-2)]/(x-1) = 3/(x-1)

## 五、例题讲解

**例题1：** 计算：2/x + 3/x

解：

同分母，分子相加：

2/x + 3/x = (2+3)/x = 5/x

答：5/x。

**例题2：** 计算：(x+1)/(x-1) - (x-2)/(x-1)

解：

同分母，分子相减：

[(x+1)-(x-2)]/(x-1)

= (x+1-x+2)/(x-1)

= 3/(x-1)

答：3/(x-1)。

**例题3：** 计算：1/x + 1/(x+1)

解：

通分，最简公分母：x(x+1)

1/x = (x+1)/[x(x+1)]

1/(x+1) = x/[x(x+1)]

(x+1)/[x(x+1)] + x/[x(x+1)] = (x+1+x)/[x(x+1)] = (2x+1)/[x(x+1)]

答：(2x+1)/[x(x+1)]。

**例题4：** 计算：2/(x-1) - 1/(x+1)

解：

通分，最简公分母：(x-1)(x+1)

2/(x-1) = 2(x+1)/[(x-1)(x+1)]

1/(x+1) = (x-1)/[(x-1)(x+1)]

[2(x+1)-(x-1)]/[(x-1)(x+1)] = (2x+2-x+1)/[(x-1)(x+1)] = (x+3)/[(x-1)(x+1)]

答：(x+3)/[(x-1)(x+1)]。

**例题5：** 计算：x/(x²-4) + 2/(x+2)

解：

通分，最简公分母：(x+2)(x-2)

x/[(x+2)(x-2)] + 2/(x+2) = x/[(x+2)(x-2)] + 2(x-2)/[(x+2)(x-2)]

= [x+2(x-2)]/[(x+2)(x-2)] = (x+2x-4)/[(x+2)(x-2)] = (3x-4)/[(x+2)(x-2)]

答：(3x-4)/[(x+2)(x-2)]。

## 六、常见错误

**错误1：异分母直接加减**

错误做法：1/x + 1/y = 2/(x+y)。

正确理解：先通分，1/x + 1/y = (y+x)/(xy)。

**错误2：减法时分子没加括号**

错误做法：(x+1)/(x-1) - (x-2)/(x-1) = (x+1-x-2)/(x-1) = -1/(x-1)。

正确理解：(x+1-x+2)/(x-1) = 3/(x-1)。

**错误3：通分时分子没同乘**

错误做法：1/x + 1/(x+1) = 1/[x(x+1)] + 1/[x(x+1)]。

正确理解：1/x = (x+1)/[x(x+1)]。

**错误4：最简公分母找错**

错误做法：1/(x-1) + 1/(x²-1) 的最简公分母是(x-1)(x²-1)。

正确理解：x²-1 = (x+1)(x-1)，最简公分母是(x+1)(x-1)。

**错误5：结果没有化简**

错误做法：2x/(x²+x) 不化简。

正确理解：2x/(x²+x) = 2x/[x(x+1)] = 2/(x+1)。

## 七、练习题

**练习1：** 计算：3/x - 1/x

解：

同分母，分子相减：

(3-1)/x = 2/x

答：2/x。

**练习2：** 计算：(2x+1)/(x+3) + (x-4)/(x+3)

解：

同分母，分子相加：

(2x+1+x-4)/(x+3) = (3x-3)/(x+3) = 3(x-1)/(x+3)

答：3(x-1)/(x+3)。

**练习3：** 计算：1/(x-2) + 1/(x+2)

解：

通分，最简公分母：(x-2)(x+2)

(x+2)/[(x-2)(x+2)] + (x-2)/[(x-2)(x+2)] = (x+2+x-2)/[(x-2)(x+2)] = 2x/[(x-2)(x+2)]

答：2x/[(x-2)(x+2)]。

**练习4：** 计算：3/(x+1) - 2/(x-1)

解：

通分，最简公分母：(x+1)(x-1)

3(x-1)/[(x+1)(x-1)] - 2(x+1)/[(x+1)(x-1)] = (3x-3-2x-2)/[(x+1)(x-1)] = (x-5)/[(x+1)(x-1)]

答：(x-5)/[(x+1)(x-1)]。

**练习5：** 计算：1/(x²-x) + 1/(x-1)

解：

通分，最简公分母：x(x-1)

1/[x(x-1)] + x/[x(x-1)] = (1+x)/[x(x-1)]

答：(x+1)/[x(x-1)]。
