# 15.3.1 分式方程的概念

## 一、分式方程的定义

**分式方程：分母中含有未知数的方程**

**关键特征：分母中有字母（未知数）**

**例子**

1/x = 2 是分式方程，分母x含未知数。

(x+1)/(x-2) = 3 是分式方程，分母x-2含未知数。

## 二、区分分式方程和整式方程

**整式方程：分母中不含未知数**

2x + 3 = 7 是整式方程。

x/2 + 1 = 3 是整式方程（分母2不含未知数）。

**分式方程：分母中含未知数**

2/x + 1 = 3 是分式方程。

(x+1)/(x-2) = 3 是分式方程。

## 三、分式方程的特征

**特征：分母中有字母**

看分母，不看分子。

分子有字母不一定是分式方程。

分母有字母一定是分式方程。

**判断方法**

第一步：找到方程中的分式。

第二步：看分式的分母是否含未知数。

第三步：有就是分式方程，没有就是整式方程。

## 四、例题讲解

**例题1：** 判断下列方程哪些是分式方程：2/x = 3，x/2 = 3，(x+1)/x = 2，x²+1 = 3

解：

2/x = 3：分母x含未知数，是分式方程。

x/2 = 3：分母2不含未知数，是整式方程。

(x+1)/x = 2：分母x含未知数，是分式方程。

x²+1 = 3：没有分式，是整式方程。

答：2/x = 3 和 (x+1)/x = 2 是分式方程。

**例题2：** 判断：1/(x-1) + 2 = 3 是不是分式方程？

解：

分母x-1含未知数x。

是分式方程。

答：是分式方程。

**例题3：** 判断：x/(x+1) = x/(x+2) 是不是分式方程？

解：

左边分母x+1含未知数。

右边分母x+2含未知数。

是分式方程。

答：是分式方程。

**例题4：** 判断：(x+π)/(x-1) = 2 是不是分式方程？

解：

分母x-1含未知数x。

π是常数，不影响判断。

是分式方程。

答：是分式方程。

**例题5：** 判断：2x + 1/(x+1) = 3 是不是分式方程？

解：

1/(x+1)的分母x+1含未知数。

是分式方程。

答：是分式方程。

## 五、常见错误

**错误1：分子有字母就认为是分式方程**

错误做法：x/2 = 3 是分式方程。

正确理解：分母2不含未知数，是整式方程。

**错误2：分母有常数就认为不是分式方程**

错误做法：(x+1)/2 = 3 是分式方程。

正确理解：分母2不含未知数，是整式方程。

**错误3：方程中有分式就是分式方程**

错误做法：x/2 + 1 = 3 是分式方程。

正确理解：分母不含未知数，是整式方程。

**错误4：π当未知数**

错误做法：x/π = 2 是分式方程。

正确理解：π是常数，分母不含未知数，是整式方程。

**错误5：忽略隐含的分式**

错误做法：x⁻¹ = 2 不是分式方程。

正确理解：x⁻¹ = 1/x，分母含未知数，是分式方程。

## 六、练习题

**练习1：** 判断下列方程哪些是分式方程：3/x = 1，x/3 = 1，(x-1)/(x+1) = 2，2x = 5

解：

3/x = 1：分母x含未知数，是分式方程。

x/3 = 1：分母3不含未知数，是整式方程。

(x-1)/(x+1) = 2：分母x+1含未知数，是分式方程。

2x = 5：没有分式，是整式方程。

答：3/x = 1 和 (x-1)/(x+1) = 2 是分式方程。

**练习2：** 判断：2/(x+3) = 1 是不是分式方程？

解：

分母x+3含未知数x。

是分式方程。

答：是分式方程。

**练习3：** 判断：(x²+1)/x = x 是不是分式方程？

解：

左边分母x含未知数。

是分式方程。

答：是分式方程。

**练习4：** 判断：x/(x-1) + 1/(x+1) = 2 是不是分式方程？

解：

x/(x-1)的分母x-1含未知数。

1/(x+1)的分母x+1含未知数。

是分式方程。

答：是分式方程。

**练习5：** 判断：(x+2)/3 = (x-1)/2 是不是分式方程？

解：

左边分母3不含未知数。

右边分母2不含未知数。

是整式方程。

答：不是分式方程，是整式方程。
