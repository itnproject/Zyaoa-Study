# 15.3.6 分式方程的实际应用——销售问题

## 一、销售问题的基本公式

**总价 = 单价 × 数量**

**利润 = 售价 - 进价**

**利润率 = 利润 ÷ 进价 × 100%**

**售价 = 进价 × (1 + 利润率)**

## 二、常见题型

**降价促销**

原价和现价的关系。

**提价销售**

提价后销量的变化。

**利润率问题**

已知利润率求进价或售价。

## 三、单价×数量=总价

**这是销售问题的核心公式**

用这个公式列分式方程。

数量 = 总价 ÷ 单价

单价 = 总价 ÷ 数量

## 四、例题讲解

**例题1：** 某商品原价每件100元，降价后每件80元，用4000元可以多买多少件？

解：

原价买的数量：4000/100 = 40件

现价买的数量：4000/80 = 50件

多买：50 - 40 = 10件

答：可以多买10件。

**例题2：** 某商店用6000元购进一批商品，如果每件降价10元，就可以多买20件。求商品的原价。

解：

设原价为x元。

原价买的数量：6000/x

降价后买的数量：6000/(x-10)

6000/(x-10) - 6000/x = 20

最简公分母：x(x-10)

6000x - 6000(x-10) = 20x(x-10)

6000x - 6000x + 60000 = 20x² - 200x

20x² - 200x - 60000 = 0

x² - 10x - 3000 = 0

(x-60)(x+50) = 0

x = 60 或 x = -50（舍去）

检验：x = 60 符合实际。

答：商品的原价是60元。

**例题3：** 某商品进价每件200元，售价每件280元，利润率是多少？

解：

利润：280 - 200 = 80元

利润率：80/200 × 100% = 40%

答：利润率是40%。

**例题4：** 某商店用2400元购进一批商品，每件售价比进价多20元，全部售出后获利400元。求商品的进价。

解：

设进价为x元。

售价为(x+20)元。

数量：2400/x

利润：400元

利润 = 数量 × 每件利润

400 = (2400/x) × 20

400 = 48000/x

x = 48000/400 = 120

检验：x = 120 符合实际。

答：商品的进价是120元。

**例题5：** 某商品按定价的八折出售，仍可获利20%。已知进价为100元，求商品的定价。

解：

设定价为x元。

售价：0.8x

利润：0.8x - 100

利润率：(0.8x-100)/100 = 20% = 0.2

0.8x - 100 = 20

0.8x = 120

x = 150

检验：x = 150 符合实际。

答：商品的定价是150元。

## 五、常见错误

**错误1：利润率公式搞错**

错误做法：利润率 = 利润 ÷ 售价。

正确理解：利润率 = 利润 ÷ 进价。

**错误2：数量关系搞反**

错误做法：降价后数量变少。

正确理解：降价后数量变多。

**错误3：单位不统一**

错误做法：元和角混用。

正确理解：统一用元。

**错误4：不检验实际意义**

错误做法：价格为负也当答案。

正确理解：价格必须为正。

**错误5：等量关系找错**

错误做法：多买的数量搞错。

正确理解：降价后数量 - 原价数量 = 多买的数量。

## 六、练习题

**练习1：** 某商品原价每件50元，降价后每件40元，用2000元可以多买多少件？

解：

原价买的数量：2000/50 = 40件

现价买的数量：2000/40 = 50件

多买：50 - 40 = 10件

答：可以多买10件。

**练习2：** 某商店用3000元购进一批商品，如果每件降价5元，就可以多买10件。求商品的原价。

解：

设原价为x元。

3000/(x-5) - 3000/x = 10

最简公分母：x(x-5)

3000x - 3000(x-5) = 10x(x-5)

3000x - 3000x + 15000 = 10x² - 50x

10x² - 50x - 15000 = 0

x² - 5x - 1500 = 0

(x-40)(x+35) = 0

x = 40 或 x = -35（舍去）

检验：x = 40 符合实际。

答：商品的原价是40元。

**练习3：** 某商品进价每件150元，售价每件210元，利润率是多少？

解：

利润：210 - 150 = 60元

利润率：60/150 × 100% = 40%

答：利润率是40%。

**练习4：** 某商店用1800元购进一批商品，每件售价比进价多15元，全部售出后获利300元。求商品的进价。

解：

设进价为x元。

300 = (1800/x) × 15

300 = 27000/x

x = 27000/300 = 90

检验：x = 90 符合实际。

答：商品的进价是90元。

**练习5：** 某商品按定价的七五折出售，仍可获利25%。已知进价为80元，求商品的定价。

解：

设定价为x元。

售价：0.75x

利润：0.75x - 80

利润率：(0.75x-80)/80 = 25% = 0.25

0.75x - 80 = 20

0.75x = 100

x = 400/3 ≈ 133.33

检验：x = 400/3 符合实际。

答：商品的定价是400/3元（约133.33元）。
