# 15.3.3 分式方程的增根

## 一、增根的产生原因

**去分母时两边乘了可能为0的整式**

比如：1/(x-1) = 2

两边乘(x-1)：1 = 2(x-1)

如果x=1，那么x-1=0。

两边乘0，方程变形了。

所以可能产生增根。

## 二、增根的特征

**是整式方程的根，但不是原分式方程的根**

增根满足去分母后的整式方程。

但增根使原分式方程的分母为0。

**增根的值就是使最简公分母为0的值**

## 三、含参数的分式方程

**已知有增根求参数值**

第一步：去分母，得到整式方程。

第二步：找出使最简公分母为0的值（增根）。

第三步：把增根代入整式方程，求参数。

## 四、例题讲解

**例题1：** 已知方程 1/(x-2) = m/(x-2) 有增根，求m的值。

解：

最简公分母：x-2

增根：x-2 = 0，即 x = 2

去分母：1 = m

所以 m = 1

答：m = 1。

**例题2：** 已知方程 2/(x-1) + m/(x+1) = 4/(x²-1) 有增根，求m的值。

解：

最简公分母：(x-1)(x+1)

增根：x = 1 或 x = -1

去分母：2(x+1) + m(x-1) = 4

当x = 1时：2(2) + m(0) = 4，4 = 4，恒成立。

当x = -1时：2(0) + m(-2) = 4，-2m = 4，m = -2。

答：m = -2 时，x = -1 是增根。

**例题3：** 已知方程 x/(x-3) = m/(x-3) + 2 有增根，求m的值。

解：

最简公分母：x-3

增根：x = 3

去分母：x = m + 2(x-3)

x = m + 2x - 6

-x = m - 6

x = 6 - m

增根x = 3：3 = 6 - m，m = 3

答：m = 3。

**例题4：** 已知方程 1/(x-1) + 1/(x+1) = m/(x²-1) 有增根，求m的值。

解：

最简公分母：(x-1)(x+1)

增根：x = 1 或 x = -1

去分母：(x+1) + (x-1) = m

2x = m

当x = 1时：m = 2

当x = -1时：m = -2

答：m = 2 或 m = -2。

**例题5：** 已知方程 (x+m)/(x-2) = 3 无解，求m的值。

解：

最简公分母：x-2

去分母：x+m = 3(x-2)

x+m = 3x-6

-2x = -6-m

x = (6+m)/2

无解说明解是增根。

增根：x = 2

(6+m)/2 = 2

6+m = 4

m = -2

答：m = -2。

## 五、常见错误

**错误1：增根的概念不清**

错误做法：增根是方程的解。

正确理解：增根不是原方程的解。

**错误2：增根找错**

错误做法：1/(x-1) + 1/(x+1) 的增根是x = 0。

正确理解：增根是x = 1 或 x = -1。

**错误3：只考虑一个增根**

错误做法：1/(x-1) + 1/(x+1) 只考虑x = 1。

正确理解：x = 1 和 x = -1 都要考虑。

**错误4：代入原方程而不是整式方程**

错误做法：把增根代入原分式方程。

正确理解：把增根代入去分母后的整式方程。

**错误5：无解和增根混淆**

错误做法：方程无解就是没有增根。

正确理解：方程无解可能是因为解是增根。

## 六、练习题

**练习1：** 已知方程 3/(x-1) = m/(x-1) 有增根，求m的值。

解：

最简公分母：x-1

增根：x = 1

去分母：3 = m

答：m = 3。

**练习2：** 已知方程 1/(x-2) + m/(x+2) = 4/(x²-4) 有增根，求m的值。

解：

最简公分母：(x-2)(x+2)

增根：x = 2 或 x = -2

去分母：(x+2) + m(x-2) = 4

当x = 2时：4 + 0 = 4，恒成立。

当x = -2时：0 + m(-4) = 4，m = -1。

答：m = -1 时，x = -2 是增根。

**练习3：** 已知方程 (x+m)/(x-1) = 2 有增根，求m的值。

解：

最简公分母：x-1

增根：x = 1

去分母：x+m = 2(x-1)

x+m = 2x-2

x = m+2

增根x = 1：1 = m+2，m = -1

答：m = -1。

**练习4：** 已知方程 2/(x+1) + 1/(x-1) = m/(x²-1) 有增根，求m的值。

解：

最简公分母：(x+1)(x-1)

增根：x = 1 或 x = -1

去分母：2(x-1) + (x+1) = m

2x-2+x+1 = m

3x-1 = m

当x = 1时：m = 2

当x = -1时：m = -4

答：m = 2 或 m = -4。

**练习5：** 已知方程 (x-m)/(x-3) = 1 无解，求m的值。

解：

最简公分母：x-3

去分母：x-m = x-3

-m = -3

m = 3

此时方程变为 0 = 0，x可以是任意值。

但x = 3时分母为0，舍去。

x ≠ 3 时方程恒成立，有无数解。

重新分析：x-m = x-3 → -m = -3 → m = 3

当m = 3时，(x-3)/(x-3) = 1，x ≠ 3时成立。

当m ≠ 3时，-m = -3不成立，无解。

答：m ≠ 3。
