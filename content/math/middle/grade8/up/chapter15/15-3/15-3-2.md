# 15.3.2 分式方程的解法

## 一、基本思想

**去分母，把分式方程转化为整式方程**

分式方程不好解。

整式方程好解。

所以要把分式方程变成整式方程。

## 二、解分式方程的步骤

**第一步：找最简公分母**

把所有分母因式分解。

取各因式的最高次幂相乘。

**第二步：去分母**

方程两边同乘最简公分母。

**第三步：解整式方程**

解出未知数的值。

**第四步：检验**

把解代入最简公分母，看是否为0。

为0是增根，舍去。

不为0是原方程的解。

## 三、增根

**增根：使最简公分母为0的根**

增根是整式方程的根。

但不是原分式方程的根。

**为什么要检验**

去分母时两边乘了可能为0的整式。

可能产生增根。

**检验方法**

代入最简公分母，看是否为0。

## 四、例题讲解

**例题1：** 解方程：2/x = 3

解：

最简公分母：x

去分母：2 = 3x

解整式方程：x = 2/3

检验：x = 2/3 时，x ≠ 0。

答：x = 2/3。

**例题2：** 解方程：1/(x-1) = 2/(x+1)

解：

最简公分母：(x-1)(x+1)

去分母：x+1 = 2(x-1)

x+1 = 2x-2

x = 3

检验：x = 3 时，(x-1)(x+1) = 2×4 = 8 ≠ 0。

答：x = 3。

**例题3：** 解方程：1/x + 1/(x+1) = 2/(x²+x)

解：

最简公分母：x(x+1) = x²+x

去分母：(x+1) + x = 2

2x+1 = 2

x = 1/2

检验：x = 1/2 时，x(x+1) = 1/2 × 3/2 = 3/4 ≠ 0。

答：x = 1/2。

**例题4：** 解方程：x/(x-2) = 2/(x-2) + 1

解：

最简公分母：x-2

去分母：x = 2 + (x-2)

x = x

x可以是任意值？

不对，要检验。

x = 2 时分母为0，舍去。

x ≠ 2 时方程恒成立。

答：x ≠ 2 的任意实数。

**例题5：** 解方程：1/(x-1) + 1/(x+1) = 2/(x²-1)

解：

最简公分母：(x-1)(x+1) = x²-1

去分母：(x+1) + (x-1) = 2

2x = 2

x = 1

检验：x = 1 时，(x-1)(x+1) = 0。

x = 1 是增根，舍去。

答：原方程无解。

## 五、常见错误

**错误1：不检验**

错误做法：解出x就直接写答案。

正确理解：必须检验是否为增根。

**错误2：最简公分母找错**

错误做法：1/(x-1) + 1/(x+1) 的最简公分母是(x-1)(x+1)(x²-1)。

正确理解：x²-1 = (x-1)(x+1)，最简公分母是(x-1)(x+1)。

**错误3：去分母时漏乘**

错误做法：1/x + 1 = 2，去分母得1 + 1 = 2x。

正确理解：1 + x = 2x。

**错误4：检验方法错误**

错误做法：把解代入原方程检验。

正确理解：代入最简公分母检验更简便。

**错误5：增根当解**

错误做法：x = 1 是 1/(x-1) = 2 的解。

正确理解：x = 1 时分母为0，是增根。

## 六、练习题

**练习1：** 解方程：3/x = 2

解：

最简公分母：x

去分母：3 = 2x

x = 3/2

检验：x = 3/2 时，x ≠ 0。

答：x = 3/2。

**练习2：** 解方程：2/(x-1) = 3/(x+2)

解：

最简公分母：(x-1)(x+2)

去分母：2(x+2) = 3(x-1)

2x+4 = 3x-3

x = 7

检验：x = 7 时，(x-1)(x+2) = 6×9 = 54 ≠ 0。

答：x = 7。

**练习3：** 解方程：1/x + 2/(x+1) = 3/(x²+x)

解：

最简公分母：x(x+1)

去分母：(x+1) + 2x = 3

3x+1 = 3

x = 2/3

检验：x = 2/3 时，x(x+1) = 2/3 × 5/3 = 10/9 ≠ 0。

答：x = 2/3。

**练习4：** 解方程：x/(x-1) = 1/(x-1) + 2

解：

最简公分母：x-1

去分母：x = 1 + 2(x-1)

x = 1 + 2x - 2

x = 2x - 1

x = 1

检验：x = 1 时，x-1 = 0。

x = 1 是增根，舍去。

答：原方程无解。

**练习5：** 解方程：1/(x+2) + 1/(x-2) = 4/(x²-4)

解：

最简公分母：(x+2)(x-2) = x²-4

去分母：(x-2) + (x+2) = 4

2x = 4

x = 2

检验：x = 2 时，(x+2)(x-2) = 0。

x = 2 是增根，舍去。

答：原方程无解。
