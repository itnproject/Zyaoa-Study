# 14.2.3 添括号法则

## 一、回顾去括号法则

括号前是正号，去掉括号，括号里的各项不变号。

a + (b + c) = a + b + c

括号前是负号，去掉括号，括号里的各项都变号。

a - (b + c) = a - b - c

## 二、添括号法则

添括号是去括号的逆运算。

**法则1：括号前是正号，括到括号里的各项都不变号**

a + b + c = a + (b + c)

**法则2：括号前是负号，括到括号里的各项都变号**

a - b - c = a - (b + c)

a - b + c = a - (b - c)

## 三、用于乘法公式中的变形

**平方差公式的变形**

(a+b+c)(a+b-c) = [(a+b)+c][(a+b)-c] = (a+b)² - c²

**完全平方公式的变形**

(a-b+c)² = [(a-b)+c]² = (a-b)² + 2(a-b)c + c²

## 四、例题讲解

**例题1：** 在a-b+c-d中，把后两项添括号，括号前是负号。

解：

a - b + c - d = a - b - (-c + d) = a - b - (d - c)

或者：a - (b - c + d)

答：a - (b - c + d)。

**例题2：** 计算：(a+b+c)(a+b-c)

解：

把(a+b)看作一个整体。

(a+b+c)(a+b-c) = [(a+b)+c][(a+b)-c]

= (a+b)² - c²（平方差公式）

= a² + 2ab + b² - c²

答：a² + 2ab + b² - c²。

**例题3：** 计算：(a-b+c)²

解：

把(a-b)看作一个整体。

(a-b+c)² = [(a-b)+c]²

= (a-b)² + 2(a-b)c + c²（完全平方公式）

= a² - 2ab + b² + 2ac - 2bc + c²

= a² + b² + c² - 2ab + 2ac - 2bc

答：a² + b² + c² - 2ab + 2ac - 2bc。

**例题4：** 计算：(x+y-z)(x-y+z)

解：

把x看作相同项。

(x+y-z)(x-y+z) = [x+(y-z)][x-(y-z)]

= x² - (y-z)²（平方差公式）

= x² - (y² - 2yz + z²)

= x² - y² + 2yz - z²

答：x² - y² + 2yz - z²。

**例题5：** 计算：(a+b-c)(a-b+c)

解：

(a+b-c)(a-b+c) = [a+(b-c)][a-(b-c)]

= a² - (b-c)²（平方差公式）

= a² - (b² - 2bc + c²)

= a² - b² + 2bc - c²

答：a² - b² + 2bc - c²。

## 五、常见错误

**错误1：添括号时不变号**

错误做法：a - b - c = a - (b - c)。

正确理解：括号前是负号，括号里各项要变号，a - b - c = a - (b + c)。

**错误2：添括号时变号错误**

错误做法：a - b + c = a - (b + c)。

正确理解：a - b + c = a - (b - c)。

**错误3：整体没有加括号**

错误做法：(a+b)² - c² = a+b² - c²。

正确理解：(a+b)²要整体平方，(a+b)² = a² + 2ab + b²。

**错误4：去括号时不变号**

错误做法：a² - (b-c)² = a² - b² - c²。

正确理解：a² - (b² - 2bc + c²) = a² - b² + 2bc - c²。

**错误5：分组错误**

错误做法：(a+b+c)(a+b-c) = a² + b² + c² - a² - b² - c²。

正确理解：要把(a+b)看作整体，用平方差公式。

## 六、练习题

**练习1：** 在a+b-c+d中，把后三项添括号，括号前是正号。

解：

a + b - c + d = a + (b - c + d)

答：a + (b - c + d)。

**练习2：** 计算：(x+y+z)(x+y-z)

解：

(x+y+z)(x+y-z) = [(x+y)+z][(x+y)-z]

= (x+y)² - z²

= x² + 2xy + y² - z²

答：x² + 2xy + y² - z²。

**练习3：** 计算：(a+b-c)²

解：

(a+b-c)² = [(a+b)-c]²

= (a+b)² - 2(a+b)c + c²

= a² + 2ab + b² - 2ac - 2bc + c²

= a² + b² + c² + 2ab - 2ac - 2bc

答：a² + b² + c² + 2ab - 2ac - 2bc。

**练习4：** 计算：(m+n-p)(m-n+p)

解：

(m+n-p)(m-n+p) = [m+(n-p)][m-(n-p)]

= m² - (n-p)²

= m² - (n² - 2np + p²)

= m² - n² + 2np - p²

答：m² - n² + 2np - p²。

**练习5：** 计算：(x-y-z)(x+y+z)

解：

(x-y-z)(x+y+z) = [x-(y+z)][x+(y+z)]

= x² - (y+z)²

= x² - (y² + 2yz + z²)

= x² - y² - 2yz - z²

答：x² - y² - 2yz - z²。
