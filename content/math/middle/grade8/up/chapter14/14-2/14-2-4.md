# 14.2.4 乘法公式的综合应用

## 一、三项式的完全平方

**公式：(a+b+c)² = a² + b² + c² + 2ab + 2ac + 2bc**

**推导**

(a+b+c)² = [(a+b)+c]²

= (a+b)² + 2(a+b)c + c²

= a² + 2ab + b² + 2ac + 2bc + c²

= a² + b² + c² + 2ab + 2ac + 2bc

**记忆方法**

各项平方和，加上每两项积的2倍。

## 二、乘法公式的灵活变形

**平方差公式变形**

a² - b² = (a+b)(a-b)

a² - b² - c² + 2bc = a² - (b-c)² = (a+b-c)(a-b+c)

**完全平方公式变形**

a² + 2ab + b² = (a+b)²

a² + b² = (a+b)² - 2ab

a² + b² = (a-b)² + 2ab

(a+b)² - (a-b)² = 4ab

## 三、利用乘法公式简化计算

**接近整百整十的数**

99² = (100-1)² = 10000 - 200 + 1 = 9801

101 × 99 = (100+1)(100-1) = 10000 - 1 = 9999

**大数计算**

2024² - 2023 × 2025 = 2024² - (2024-1)(2024+1) = 2024² - (2024² - 1) = 1

## 四、例题讲解

**例题1：** 计算：(x+y+z)²

解：

(x+y+z)² = x² + y² + z² + 2xy + 2xz + 2yz

答：x² + y² + z² + 2xy + 2xz + 2yz。

**例题2：** 已知a+b=5，ab=6。求a²+b²。

解：

a² + b² = (a+b)² - 2ab = 25 - 12 = 13

答：13。

**例题3：** 计算：2023² - 2022 × 2024

解：

2023² - 2022 × 2024 = 2023² - (2023-1)(2023+1)

= 2023² - (2023² - 1)

= 1

答：1。

**例题4：** 已知a-b=3，ab=2。求(a+b)²。

解：

(a+b)² = (a-b)² + 4ab = 9 + 8 = 17

答：17。

**例题5：** 计算：(x+1)²(x-1)²

解：

(x+1)²(x-1)² = [(x+1)(x-1)]²

= (x²-1)²

= x⁴ - 2x² + 1

答：x⁴ - 2x² + 1。

## 五、常见错误

**错误1：三项式完全平方漏项**

错误做法：(a+b+c)² = a² + b² + c²。

正确理解：还要加上2ab + 2ac + 2bc。

**错误2：变形公式记错**

错误做法：a² + b² = (a+b)²。

正确理解：a² + b² = (a+b)² - 2ab。

**错误3：符号搞错**

错误做法：(a-b)² = a² + 2ab + b²。

正确理解：(a-b)² = a² - 2ab + b²。

**错误4：公式用错场景**

错误做法：(a+b)(a+c) = a² + bc。

正确理解：(a+b)(a+c) = a² + ac + ab + bc。

**错误5：计算顺序错误**

错误做法：(x+1)²(x-1)² = (x²+1)(x²-1)。

正确理解：先合并为[(x+1)(x-1)]²，再计算。

## 六、练习题

**练习1：** 计算：(2a-b+c)²

解：

(2a-b+c)² = (2a)² + (-b)² + c² + 2(2a)(-b) + 2(2a)c + 2(-b)c

= 4a² + b² + c² - 4ab + 4ac - 2bc

答：4a² + b² + c² - 4ab + 4ac - 2bc。

**练习2：** 已知a+b=7，ab=10。求a²+b²。

解：

a² + b² = (a+b)² - 2ab = 49 - 20 = 29

答：29。

**练习3：** 计算：101² - 99²

解：

101² - 99² = (101+99)(101-99) = 200 × 2 = 400

答：400。

**练习4：** 已知a+b=4，a²+b²=10。求ab。

解：

(a+b)² = a² + 2ab + b²

16 = 10 + 2ab

2ab = 6

ab = 3

答：3。

**练习5：** 计算：(x+2)² - (x-2)²

解：

方法1：展开计算

(x+2)² - (x-2)² = (x² + 4x + 4) - (x² - 4x + 4) = 8x

方法2：用平方差公式

(x+2)² - (x-2)² = [(x+2)+(x-2)][(x+2)-(x-2)] = (2x)(4) = 8x

答：8x。
