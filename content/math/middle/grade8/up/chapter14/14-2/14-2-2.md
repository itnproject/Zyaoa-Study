# 14.2.2 完全平方公式

## 一、从计算引入

计算：(x+3)²

= (x+3)(x+3)

= x² + 3x + 3x + 9

= x² + 6x + 9

你发现了什么规律？

x²是首项的平方，9是尾项的平方，6x是首尾积的2倍。

这就是完全平方公式。

## 二、完全平方公式

**公式1：(a+b)² = a² + 2ab + b²**

**公式2：(a-b)² = a² - 2ab + b²**

**文字描述：首平方、尾平方、积的2倍放中央**

**推导**

(a+b)² = (a+b)(a+b) = a² + ab + ab + b² = a² + 2ab + b²

(a-b)² = (a-b)(a-b) = a² - ab - ab + b² = a² - 2ab + b²

## 三、符号规律

**中间项的符号与括号内相同**

(a+b)²中间项是+2ab。

(a-b)²中间项是-2ab。

## 四、区分平方差公式和完全平方公式

**平方差公式：(a+b)(a-b) = a² - b²**

两项，符号相反。

**完全平方公式：(a±b)² = a² ± 2ab + b²**

三项，中间项是首尾积的2倍。

## 五、例题讲解

**例题1：** 计算：(x+4)²

解：

首项是x，尾项是4。

首平方：x²

尾平方：16

积的2倍：2 × x × 4 = 8x

结果：x² + 8x + 16

答：x² + 8x + 16。

**例题2：** 计算：(2x-3)²

解：

首项是2x，尾项是3。

首平方：(2x)² = 4x²

尾平方：9

积的2倍：2 × 2x × 3 = 12x，符号为负

结果：4x² - 12x + 9

答：4x² - 12x + 9。

**例题3：** 计算：(3a+2b)²

解：

首项是3a，尾项是2b。

首平方：(3a)² = 9a²

尾平方：(2b)² = 4b²

积的2倍：2 × 3a × 2b = 12ab

结果：9a² + 12ab + 4b²

答：9a² + 12ab + 4b²。

**例题4：** 计算：(-x+5)²

解：

首项是-x，尾项是5。

首平方：(-x)² = x²

尾平方：25

积的2倍：2 × (-x) × 5 = -10x

结果：x² - 10x + 25

答：x² - 10x + 25。

**例题5：** 计算：98²

解：

98² = (100-2)² = 100² - 2 × 100 × 2 + 2² = 10000 - 400 + 4 = 9604

答：9604。

## 六、常见错误

**错误1：漏掉中间项**

错误做法：(x+3)² = x² + 9。

正确理解：(x+3)² = x² + 6x + 9。

**错误2：中间项系数不是2**

错误做法：(x+3)² = x² + 3x + 9。

正确理解：中间项是2ab，(x+3)² = x² + 6x + 9。

**错误3：符号搞错**

错误做法：(x-3)² = x² + 6x + 9。

正确理解：(x-3)² = x² - 6x + 9。

**错误4：系数不平方**

错误做法：(2x+3)² = 2x² + 12x + 9。

正确理解：(2x)² = 4x²，(2x+3)² = 4x² + 12x + 9。

**错误5：混淆平方差和完全平方**

错误做法：(x+3)² = x² - 9。

正确理解：(x+3)² = x² + 6x + 9。

## 七、练习题

**练习1：** 计算：(x+6)²

解：

首平方：x²

尾平方：36

积的2倍：2 × x × 6 = 12x

结果：x² + 12x + 36

答：x² + 12x + 36。

**练习2：** 计算：(3x-2)²

解：

首平方：(3x)² = 9x²

尾平方：4

积的2倍：2 × 3x × 2 = 12x，符号为负

结果：9x² - 12x + 4

答：9x² - 12x + 4。

**练习3：** 计算：(a+5b)²

解：

首平方：a²

尾平方：(5b)² = 25b²

积的2倍：2 × a × 5b = 10ab

结果：a² + 10ab + 25b²

答：a² + 10ab + 25b²。

**练习4：** 计算：(4-x)²

解：

首平方：16

尾平方：x²

积的2倍：2 × 4 × (-x) = -8x

结果：16 - 8x + x² = x² - 8x + 16

答：x² - 8x + 16。

**练习5：** 计算：102²

解：

102² = (100+2)² = 100² + 2 × 100 × 2 + 2² = 10000 + 400 + 4 = 10404

答：10404。
