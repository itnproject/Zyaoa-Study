# 14.1.5 单项式乘多项式

## 一、从面积引入

一个长方形的长是m，宽是a+b+c。

面积 = m × (a+b+c) = ma + mb + mc。

这就是单项式乘多项式。

## 二、单项式乘多项式法则

**法则：用单项式去乘多项式的每一项，再把积相加**

**实质是乘法分配律**

m(a+b+c) = ma + mb + mc

**步骤**

第一步：用单项式乘多项式的第一项。

第二步：用单项式乘多项式的第二项。

第三步：依次类推，乘完每一项。

第四步：把所有积相加。

## 三、注意符号

每一项都要带上前面的符号。

正号可以省略，负号不能省略。

## 四、例题讲解

**例题1：** 计算：2x(x+3)

解：

2x · x = 2x²

2x · 3 = 6x

结果：2x² + 6x

答：2x² + 6x。

**例题2：** 计算：-3a(2a-5)

解：

(-3a) · 2a = -6a²

(-3a) · (-5) = 15a

结果：-6a² + 15a

答：-6a² + 15a。

**例题3：** 计算：4x²(2x²-3x+1)

解：

4x² · 2x² = 8x⁴

4x² · (-3x) = -12x³

4x² · 1 = 4x²

结果：8x⁴ - 12x³ + 4x²

答：8x⁴ - 12x³ + 4x²。

**例题4：** 计算：-2xy(3x²y-xy²+2)

解：

(-2xy) · 3x²y = -6x³y²

(-2xy) · (-xy²) = 2x²y³

(-2xy) · 2 = -4xy

结果：-6x³y² + 2x²y³ - 4xy

答：-6x³y² + 2x²y³ - 4xy。

**例题5：** 计算：5a²b(2ab²-3a²b+ab)

解：

5a²b · 2ab² = 10a³b³

5a²b · (-3a²b) = -15a⁴b²

5a²b · ab = 5a³b²

结果：10a³b³ - 15a⁴b² + 5a³b²

答：10a³b³ - 15a⁴b² + 5a³b²。

## 五、常见错误

**错误1：漏乘某一项**

错误做法：2x(x+3) = 2x² + 3。

正确理解：每一项都要乘，2x(x+3) = 2x² + 6x。

**错误2：符号搞错**

错误做法：-3a(2a-5) = -6a² - 15a。

正确理解：负 × 负 = 正，-3a(2a-5) = -6a² + 15a。

**错误3：指数搞错**

错误做法：x² · x = x²。

正确理解：指数相加，x² · x = x³。

**错误4：系数不乘**

错误做法：2x(3x+4) = 2x² + 4x。

正确理解：系数也要乘，2x(3x+4) = 6x² + 8x。

**错误5：项数不对**

错误做法：单项式乘三项式，结果只有两项。

正确理解：乘几项式，结果就有几项（合并同类项前）。

## 六、练习题

**练习1：** 计算：3x(x-2)

解：

3x · x = 3x²

3x · (-2) = -6x

结果：3x² - 6x

答：3x² - 6x。

**练习2：** 计算：-2a(3a+4)

解：

(-2a) · 3a = -6a²

(-2a) · 4 = -8a

结果：-6a² - 8a

答：-6a² - 8a。

**练习3：** 计算：5x²(2x²-3x+4)

解：

5x² · 2x² = 10x⁴

5x² · (-3x) = -15x³

5x² · 4 = 20x²

结果：10x⁴ - 15x³ + 20x²

答：10x⁴ - 15x³ + 20x²。

**练习4：** 计算：-3xy(2x²y-xy²+3)

解：

(-3xy) · 2x²y = -6x³y²

(-3xy) · (-xy²) = 3x²y³

(-3xy) · 3 = -9xy

结果：-6x³y² + 3x²y³ - 9xy

答：-6x³y² + 3x²y³ - 9xy。

**练习5：** 计算：4ab(3a²b-2ab²+a)

解：

4ab · 3a²b = 12a³b²

4ab · (-2ab²) = -8a²b³

4ab · a = 4a²b

结果：12a³b² - 8a²b³ + 4a²b

答：12a³b² - 8a²b³ + 4a²b。
