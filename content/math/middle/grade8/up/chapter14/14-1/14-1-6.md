# 14.1.6 多项式乘多项式

## 一、从面积引入

一个长方形的长是a+b，宽是c+d。

面积 = (a+b)(c+d) = ac + ad + bc + bd。

这就是多项式乘多项式。

## 二、多项式乘多项式法则

**法则：先用一个多项式的每一项乘另一个多项式的每一项，再把积相加**

**公式：(a+b)(c+d) = ac + ad + bc + bd**

**理解方法**

用(a+b)的每一项去乘(c+d)：

a乘(c+d)得ac + ad。

b乘(c+d)得bc + bd。

加起来：ac + ad + bc + bd。

## 三、按顺序逐项相乘

**避免遗漏的方法**

第一个多项式的第一项 × 第二个多项式的每一项。

第一个多项式的第二项 × 第二个多项式的每一项。

依次类推，直到乘完。

**合并同类项化简**

乘完后，如果有同类项，要合并。

## 四、例题讲解

**例题1：** 计算：(x+2)(x+3)

解：

x · x = x²

x · 3 = 3x

2 · x = 2x

2 · 3 = 6

合并：x² + 3x + 2x + 6 = x² + 5x + 6

答：x² + 5x + 6。

**例题2：** 计算：(2x-1)(x+4)

解：

2x · x = 2x²

2x · 4 = 8x

(-1) · x = -x

(-1) · 4 = -4

合并：2x² + 8x - x - 4 = 2x² + 7x - 4

答：2x² + 7x - 4。

**例题3：** 计算：(x-3)(x-5)

解：

x · x = x²

x · (-5) = -5x

(-3) · x = -3x

(-3) · (-5) = 15

合并：x² - 5x - 3x + 15 = x² - 8x + 15

答：x² - 8x + 15。

**例题4：** 计算：(3x+2)(2x-1)

解：

3x · 2x = 6x²

3x · (-1) = -3x

2 · 2x = 4x

2 · (-1) = -2

合并：6x² - 3x + 4x - 2 = 6x² + x - 2

答：6x² + x - 2。

**例题5：** 计算：(x²+x+1)(x-1)

解：

x² · x = x³

x² · (-1) = -x²

x · x = x²

x · (-1) = -x

1 · x = x

1 · (-1) = -1

合并：x³ - x² + x² - x + x - 1 = x³ - 1

答：x³ - 1。

## 五、常见错误

**错误1：漏乘某一项**

错误做法：(x+2)(x+3) = x² + 3x + 6。

正确理解：要逐项相乘，(x+2)(x+3) = x² + 5x + 6。

**错误2：符号搞错**

错误做法：(x-2)(x+3) = x² + 3x - 2x - 6 = x² + x - 6（这个对了）。

错误做法：(x-2)(x-3) = x² - 3x - 2x - 6 = x² - 5x - 6。

正确理解：(-2) × (-3) = +6，(x-2)(x-3) = x² - 5x + 6。

**错误3：没有合并同类项**

错误做法：(x+2)(x+3) = x² + 3x + 2x + 6。

正确理解：要合并同类项，x² + 5x + 6。

**错误4：指数搞错**

错误做法：x · x = x²（这个对了）。

错误做法：x² · x = x²。

正确理解：指数相加，x² · x = x³。

**错误5：项数算错**

错误做法：二项式乘二项式，结果只有三项。

正确理解：二项式乘二项式，展开后有四项，合并后可能减少。

## 六、练习题

**练习1：** 计算：(x+1)(x+5)

解：

x · x = x²

x · 5 = 5x

1 · x = x

1 · 5 = 5

合并：x² + 5x + x + 5 = x² + 6x + 5

答：x² + 6x + 5。

**练习2：** 计算：(2x+3)(x-2)

解：

2x · x = 2x²

2x · (-2) = -4x

3 · x = 3x

3 · (-2) = -6

合并：2x² - 4x + 3x - 6 = 2x² - x - 6

答：2x² - x - 6。

**练习3：** 计算：(x-4)(x-6)

解：

x · x = x²

x · (-6) = -6x

(-4) · x = -4x

(-4) · (-6) = 24

合并：x² - 6x - 4x + 24 = x² - 10x + 24

答：x² - 10x + 24。

**练习4：** 计算：(3x-1)(2x+5)

解：

3x · 2x = 6x²

3x · 5 = 15x

(-1) · 2x = -2x

(-1) · 5 = -5

合并：6x² + 15x - 2x - 5 = 6x² + 13x - 5

答：6x² + 13x - 5。

**练习5：** 计算：(x+2)(x²+3x+4)

解：

x · x² = x³

x · 3x = 3x²

x · 4 = 4x

2 · x² = 2x²

2 · 3x = 6x

2 · 4 = 8

合并：x³ + 3x² + 4x + 2x² + 6x + 8 = x³ + 5x² + 10x + 8

答：x³ + 5x² + 10x + 8。
