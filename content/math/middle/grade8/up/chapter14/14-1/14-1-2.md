# 14.1.2 幂的乘方

## 一、从计算引入

(2³)² = 2³ × 2³ = 2⁶。

你发现了什么规律？

3 × 2 = 6。

指数相乘了！

这就是幂的乘方法则。

## 二、幂的乘方法则

**法则：幂的乘方，底数不变，指数相乘**

**公式：(aᵐ)ⁿ = aᵐⁿ（m、n都是正整数）**

**推导证明**

(aᵐ)ⁿ = aᵐ × aᵐ × ... × aᵐ（n个aᵐ相乘）

= aᵐ⁺ᵐ⁺...⁺ᵐ（n个m相加）

= aᵐⁿ

## 三、区分同底数幂的乘法和幂的乘方

**同底数幂的乘法：指数相加**

aᵐ · aⁿ = aᵐ⁺ⁿ

**幂的乘方：指数相乘**

(aᵐ)ⁿ = aᵐⁿ

**对比**

x³ · x⁴ = x⁷（指数相加）

(x³)⁴ = x¹²（指数相乘）

## 四、例题讲解

**例题1：** 计算：(x³)⁴

解：

(x³)⁴ = x³ˣ⁴ = x¹²

答：x¹²。

**例题2：** 计算：(2⁴)²

解：

(2⁴)² = 2⁴ˣ² = 2⁸ = 256

答：256。

**例题3：** 计算：[(-3)²]³

解：

[(-3)²]³ = (-3)²ˣ³ = (-3)⁶ = 729

答：729。

**例题4：** 计算：(a²)³ · (a⁴)²

解：

(a²)³ = a⁶

(a⁴)² = a⁸

(a²)³ · (a⁴)² = a⁶ · a⁸ = a¹⁴

答：a¹⁴。

**例题5：** 计算：[(x+y)²]³

解：

把(x+y)看作一个整体。

[(x+y)²]³ = (x+y)²ˣ³ = (x+y)⁶

答：(x+y)⁶。

## 五、常见错误

**错误1：指数相加而不是相乘**

错误做法：(x³)⁴ = x⁷。

正确理解：幂的乘方，指数相乘，(x³)⁴ = x¹²。

**错误2：底数也乘方**

错误做法：(2³)² = 4⁶。

正确理解：底数不变，(2³)² = 2⁶。

**错误3：混淆两种运算**

错误做法：x³ · x⁴ = x¹²。

正确理解：同底数幂相乘，指数相加，x³ · x⁴ = x⁷。

**错误4：多层乘方漏算**

错误做法：[(x²)³]² = x⁶。

正确理解：[(x²)³]² = x²ˣ³ˣ² = x¹²。

**错误5：负号处理错误**

错误做法：(-x²)³ = x⁶。

正确理解：(-x²)³ = -(x²)³ = -x⁶。

## 六、练习题

**练习1：** 计算：(a⁵)³

解：

(a⁵)³ = a⁵ˣ³ = a¹⁵

答：a¹⁵。

**练习2：** 计算：(10²)⁴

解：

(10²)⁴ = 10²ˣ⁴ = 10⁸ = 100000000

答：100000000。

**练习3：** 计算：(y⁴)² · y³

解：

(y⁴)² = y⁸

y⁸ · y³ = y¹¹

答：y¹¹。

**练习4：** 计算：[(m²)³]²

解：

[(m²)³]² = m²ˣ³ˣ² = m¹²

答：m¹²。

**练习5：** 计算：(-a³)⁴

解：

(-a³)⁴ = (-1)⁴ · (a³)⁴ = 1 · a¹² = a¹²

答：a¹²。
