# 14.3.6 分组分解法

## 一、适用场景

四项及以上的多项式。

不能直接提公因式。

不能直接用公式。

这时候就要用分组分解法。

## 二、分组原则

**分组后能提公因式或能用公式**

分组的目的是让每组内部能分解。

然后组与组之间能继续分解。

## 三、常见的分组方式

**两两分组**

四项式，分成两组，每组两项。

ax + ay + bx + by = (ax + ay) + (bx + by)

**三一分组**

四项式，分成一组三项和一组一项。

通常三项是完全平方式。

## 四、步骤

**第一步：合理分组**

根据多项式的特点选择分组方式。

**第二步：组内分解**

对每组分别提公因式或用公式。

**第三步：组间提公因式**

组内分解后，看组与组之间是否有公因式。

## 五、例题讲解

**例题1：** 把ax + ay + bx + by因式分解。

解：

两两分组：

(ax + ay) + (bx + by)

= a(x + y) + b(x + y)

= (x + y)(a + b)

答：(x + y)(a + b)。

**例题2：** 把x² - y² + x - y因式分解。

解：

两两分组：

(x² - y²) + (x - y)

= (x + y)(x - y) + (x - y)

= (x - y)(x + y + 1)

答：(x - y)(x + y + 1)。

**例题3：** 把x² + 2xy + y² - 4因式分解。

解：

三一分组：

(x² + 2xy + y²) - 4

= (x + y)² - 4

= (x + y + 2)(x + y - 2)

答：(x + y + 2)(x + y - 2)。

**例题4：** 把a² - b² + 2b - 1因式分解。

解：

一三分组：

a² - (b² - 2b + 1)

= a² - (b - 1)²

= (a + b - 1)(a - b + 1)

答：(a + b - 1)(a - b + 1)。

**例题5：** 把x³ + x² + x + 1因式分解。

解：

两两分组：

(x³ + x²) + (x + 1)

= x²(x + 1) + (x + 1)

= (x + 1)(x² + 1)

答：(x + 1)(x² + 1)。

## 六、常见错误

**错误1：分组不合理**

错误做法：x² + 2xy + y² - 4 = (x² + 2xy) + (y² - 4)。

正确理解：应该把完全平方式分在一起。

**错误2：组内没有分解完**

错误做法：组内分解后直接写答案。

正确理解：组内分解后，还要检查组间能否继续分解。

**错误3：符号搞错**

错误做法：a² - b² + 2b - 1 = a² - (b² + 2b + 1)。

正确理解：a² - (b² - 2b + 1)。

**错误4：分组后没有公因式**

错误做法：随便分组。

正确理解：分组后必须能提公因式或用公式。

**错误5：漏项**

错误做法：分组后某一项漏掉了。

正确理解：分组后所有项都要包含。

## 七、练习题

**练习1：** 把ax - ay + bx - by因式分解。

解：

两两分组：

(ax - ay) + (bx - by)

= a(x - y) + b(x - y)

= (x - y)(a + b)

答：(x - y)(a + b)。

**练习2：** 把x² - 4x + 4 - y²因式分解。

解：

三一分组：

(x² - 4x + 4) - y²

= (x - 2)² - y²

= (x - 2 + y)(x - 2 - y)

答：(x + y - 2)(x - y - 2)。

**练习3：** 把a² + 2ab + b² - c²因式分解。

解：

三一分组：

(a² + 2ab + b²) - c²

= (a + b)² - c²

= (a + b + c)(a + b - c)

答：(a + b + c)(a + b - c)。

**练习4：** 把x³ - x² + x - 1因式分解。

解：

两两分组：

(x³ - x²) + (x - 1)

= x²(x - 1) + (x - 1)

= (x - 1)(x² + 1)

答：(x - 1)(x² + 1)。

**练习5：** 把ab + ac + bd + cd因式分解。

解：

两两分组：

(ab + ac) + (bd + cd)

= a(b + c) + d(b + c)

= (b + c)(a + d)

答：(b + c)(a + d)。
