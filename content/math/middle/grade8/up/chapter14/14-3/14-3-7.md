# 14.3.7 因式分解的一般步骤

## 一、口诀

**一提二套三十字，四分组五检查**

这是因式分解的通用步骤。

按照这个顺序，大部分因式分解题都能解决。

## 二、一提：先提公因式

**第一步永远是提公因式**

有公因式先提公因式。

没有公因式再考虑其他方法。

**例子**

2x² + 4x = 2x(x + 2)

## 三、二套：看能不能用平方差或完全平方公式

**提完公因式后，看剩下的部分**

两项，符号相反，考虑平方差公式。

三项，首尾是平方，考虑完全平方公式。

**例子**

x² - 4 = (x+2)(x-2)

x² + 6x + 9 = (x+3)²

## 四、三十字：考虑十字相乘法

**公式用不了，考虑十字相乘法**

二次三项式，二次项系数不为1。

用十字相乘法分解。

**例子**

2x² + 7x + 3 = (x+3)(2x+1)

## 五、四分组：以上都不行就用分组分解法

**四项及以上，考虑分组分解法**

两两分组或三一分组。

分组后能提公因式或用公式。

**例子**

ax + ay + bx + by = (x+y)(a+b)

## 六、五检查：分解是否彻底

**检查每个因式是否还能再分解**

能分解的继续分解。

不能分解的停止。

**例子**

x⁴ - 16 = (x²+4)(x²-4) 没有分解完。

x⁴ - 16 = (x²+4)(x+2)(x-2) 才分解完。

## 七、例题讲解

**例题1：** 把2x³ - 8x因式分解。

解：

一提：2x(x² - 4)

二套：x² - 4 = (x+2)(x-2)

结果：2x(x+2)(x-2)

检查：每个因式都不能再分解。

答：2x(x+2)(x-2)。

**例题2：** 把x⁴ - 81因式分解。

解：

一提：没有公因式。

二套：x⁴ - 81 = (x²+9)(x²-9)

继续套：x² - 9 = (x+3)(x-3)

结果：(x²+9)(x+3)(x-3)

检查：x²+9不能再分解。

答：(x²+9)(x+3)(x-3)。

**例题3：** 把3x² + 12x + 12因式分解。

解：

一提：3(x² + 4x + 4)

二套：x² + 4x + 4 = (x+2)²

结果：3(x+2)²

检查：不能再分解。

答：3(x+2)²。

**例题4：** 把2x² + 5x + 2因式分解。

解：

一提：没有公因式。

二套：不是完全平方式。

三十字：2x² + 5x + 2 = (x+2)(2x+1)

结果：(x+2)(2x+1)

检查：不能再分解。

答：(x+2)(2x+1)。

**例题5：** 把ax + ay + bx + by因式分解。

解：

一提：没有公因式。

二套：不是公式形式。

三十字：不是二次三项式。

四分组：(ax+ay)+(bx+by) = a(x+y)+b(x+y) = (x+y)(a+b)

结果：(x+y)(a+b)

检查：不能再分解。

答：(x+y)(a+b)。

## 八、常见错误

**错误1：不先提公因式**

错误做法：2x² + 4x + 2 直接套公式。

正确理解：先提公因式2，2(x² + 2x + 1) = 2(x+1)²。

**错误2：分解不彻底**

错误做法：x⁴ - 1 = (x²+1)(x²-1)。

正确理解：x⁴ - 1 = (x²+1)(x+1)(x-1)。

**错误3：步骤顺序搞错**

错误做法：先套公式，再提公因式。

正确理解：先提公因式，再套公式。

**错误4：没有检查**

错误做法：分解完就写答案。

正确理解：要检查每个因式是否还能再分解。

**错误5：方法选择不当**

错误做法：四项式用十字相乘法。

正确理解：四项式用分组分解法。

## 九、练习题

**练习1：** 把4x³ - 16x因式分解。

解：

一提：4x(x² - 4)

二套：x² - 4 = (x+2)(x-2)

结果：4x(x+2)(x-2)

答：4x(x+2)(x-2)。

**练习2：** 把x³ + 6x² + 9x因式分解。

解：

一提：x(x² + 6x + 9)

二套：x² + 6x + 9 = (x+3)²

结果：x(x+3)²

答：x(x+3)²。

**练习3：** 把3x² - 12因式分解。

解：

一提：3(x² - 4)

二套：x² - 4 = (x+2)(x-2)

结果：3(x+2)(x-2)

答：3(x+2)(x-2)。

**练习4：** 把6x² + 7x + 2因式分解。

解：

一提：没有公因式。

二套：不是完全平方式。

三十字：6x² + 7x + 2 = (2x+1)(3x+2)

结果：(2x+1)(3x+2)

答：(2x+1)(3x+2)。

**练习5：** 把x² - y² + x + y因式分解。

解：

一提：没有公因式。

二套：部分可以。

四分组：(x² - y²) + (x + y) = (x+y)(x-y) + (x+y) = (x+y)(x-y+1)

结果：(x+y)(x-y+1)

答：(x+y)(x-y+1)。
