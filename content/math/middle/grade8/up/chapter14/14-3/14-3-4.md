# 14.3.4 用完全平方公式因式分解

## 一、从乘法公式反过来

完全平方公式：(a+b)² = a² + 2ab + b²

反过来：a² + 2ab + b² = (a+b)²

(a-b)² = a² - 2ab + b²

反过来：a² - 2ab + b² = (a-b)²

## 二、适用条件

**三项条件**

第一，必须是三项。

第二，首尾两项是平方形式，且符号为正。

第三，中间项是首尾积的2倍（符号可正可负）。

**形式：□² ± 2·□·○ + ○²**

## 三、步骤

**第一步：找首尾**

找出哪两项是平方项。

**第二步：检查中间项**

中间项是否等于首尾积的2倍。

**第三步：套公式**

符号为正：(□+○)²

符号为负：(□-○)²

## 四、区分完全平方式和普通三项式

**完全平方式：满足上述三个条件**

x² + 6x + 9 = (x+3)²

**普通三项式：不满足条件**

x² + 5x + 6 不是完全平方式（中间项5x ≠ 2·x·3 = 6x）。

## 五、例题讲解

**例题1：** 把x² + 6x + 9因式分解。

解：

首项：x² = x²

尾项：9 = 3²

中间项：6x = 2·x·3 ✓

x² + 6x + 9 = (x+3)²

答：(x+3)²。

**例题2：** 把4x² - 12x + 9因式分解。

解：

首项：4x² = (2x)²

尾项：9 = 3²

中间项：12x = 2·2x·3 ✓，符号为负

4x² - 12x + 9 = (2x-3)²

答：(2x-3)²。

**例题3：** 把x² + 5x + 6因式分解。

解：

首项：x² = x²

尾项：6 不是完全平方数。

中间项：5x ≠ 2·x·√6。

这不是完全平方式。

用十字相乘法：x² + 5x + 6 = (x+2)(x+3)

答：(x+2)(x+3)。

**例题4：** 把a³ + 2a²b + ab²因式分解。

解：

先提公因式a：

a³ + 2a²b + ab² = a(a² + 2ab + b²)

再用完全平方公式：

a² + 2ab + b² = (a+b)²

结果：a(a+b)²

答：a(a+b)²。

**例题5：** 把(x+y)² + 6(x+y) + 9因式分解。

解：

把(x+y)看作一个整体。

(x+y)² + 6(x+y) + 9 = [(x+y)+3]² = (x+y+3)²

答：(x+y+3)²。

## 六、常见错误

**错误1：不是完全平方式硬套**

错误做法：x² + 5x + 6 = (x+3)²。

正确理解：中间项5x ≠ 6x，不是完全平方式。

**错误2：符号搞错**

错误做法：x² - 6x + 9 = (x+3)²。

正确理解：中间项为负，x² - 6x + 9 = (x-3)²。

**错误3：首尾项符号不对**

错误做法：x² + 6x - 9 = (x+3)²。

正确理解：尾项必须是正的，x² + 6x - 9不是完全平方式。

**错误4：没有先提公因式**

错误做法：2x² + 12x + 18 直接套公式。

正确理解：先提公因式，2(x² + 6x + 9) = 2(x+3)²。

**错误5：中间项系数不是2**

错误做法：x² + 3x + 9/4 = (x+3/2)²（这个其实对了）。

错误做法：x² + 4x + 4 = (x+4)²。

正确理解：x² + 4x + 4 = (x+2)²。

## 七、练习题

**练习1：** 把x² + 10x + 25因式分解。

解：

首项：x² = x²

尾项：25 = 5²

中间项：10x = 2·x·5 ✓

x² + 10x + 25 = (x+5)²

答：(x+5)²。

**练习2：** 把9x² - 6x + 1因式分解。

解：

首项：9x² = (3x)²

尾项：1 = 1²

中间项：6x = 2·3x·1 ✓，符号为负

9x² - 6x + 1 = (3x-1)²

答：(3x-1)²。

**练习3：** 把x² + 8x + 16因式分解。

解：

首项：x² = x²

尾项：16 = 4²

中间项：8x = 2·x·4 ✓

x² + 8x + 16 = (x+4)²

答：(x+4)²。

**练习4：** 把2x³ - 8x² + 8x因式分解。

解：

先提公因式2x：

2x³ - 8x² + 8x = 2x(x² - 4x + 4)

再用完全平方公式：

x² - 4x + 4 = (x-2)²

结果：2x(x-2)²

答：2x(x-2)²。

**练习5：** 把a² + 2a(b+c) + (b+c)²因式分解。

解：

把(b+c)看作一个整体。

a² + 2a(b+c) + (b+c)² = [a+(b+c)]² = (a+b+c)²

答：(a+b+c)²。
