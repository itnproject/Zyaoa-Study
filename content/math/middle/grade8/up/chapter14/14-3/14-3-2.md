# 14.3.2 提公因式法

## 一、从分配律引入

3 × 5 + 3 × 7 = 3 × (5 + 7) = 3 × 12 = 36

把公共的因数3提出来。

这就是提公因式法的思想。

## 二、公因式的定义

**公因式：多项式中各项都含有的公共因式**

比如：6x² + 9x

第一项：6x² = 2 × 3 × x × x

第二项：9x = 3 × 3 × x

公共部分：3 × x = 3x

所以公因式是3x。

## 三、找公因式的方法

**系数：取各项系数的最大公约数**

6和9的最大公约数是3。

**字母：取相同字母的最低次幂**

x²和x的最低次幂是x。

**公因式：3x**

## 四、提公因式法

**把公因式提到括号外面**

6x² + 9x = 3x(2x + 3)

**注意：提完公因式后，剩下的项数要和原来一样**

原来有两项，提完后括号里也要有两项。

## 五、公因式可以是多项式

**公因式也可以是多项式**

x(x-y) + y(x-y) = (x-y)(x+y)

公因式是(x-y)。

## 六、例题讲解

**例题1：** 把6x² + 9x因式分解。

解：

找公因式：6和9的最大公约数是3，x²和x的最低次幂是x。

公因式是3x。

6x² + 9x = 3x(2x + 3)

答：3x(2x + 3)。

**例题2：** 把4a³b - 6a²b²因式分解。

解：

找公因式：4和6的最大公约数是2。

a³和a²的最低次幂是a²。

b和b²的最低次幂是b。

公因式是2a²b。

4a³b - 6a²b² = 2a²b(2a - 3b)

答：2a²b(2a - 3b)。

**例题3：** 把-3x² + 6x - 9因式分解。

解：

找公因式：3、6、9的最大公约数是3。

首项系数是负的，通常把负号也提出来。

公因式是-3。

-3x² + 6x - 9 = -3(x² - 2x + 3)

答：-3(x² - 2x + 3)。

**例题4：** 把x(x-y) + y(x-y)因式分解。

解：

公因式是(x-y)。

x(x-y) + y(x-y) = (x-y)(x+y)

答：(x-y)(x+y)。

**例题5：** 把2a(b+c) - 3(b+c)因式分解。

解：

公因式是(b+c)。

2a(b+c) - 3(b+c) = (b+c)(2a-3)

答：(b+c)(2a-3)。

## 七、常见错误

**错误1：公因式找不全**

错误做法：6x² + 9x = 3(2x² + 3x)。

正确理解：公因式是3x，6x² + 9x = 3x(2x + 3)。

**错误2：提完公因式项数变少**

错误做法：3x² + 3x = 3x(x)。

正确理解：提完后项数不变，3x² + 3x = 3x(x + 1)。

**错误3：符号搞错**

错误做法：-3x² + 6x = -3(x² + 2x)。

正确理解：-3x² + 6x = -3(x² - 2x)。

**错误4：漏掉1**

错误做法：3x² + 3x = 3x(x)。

正确理解：3x² + 3x = 3x(x + 1)，不要漏掉1。

**错误5：多项式公因式没加括号**

错误做法：x(x-y) + y(x-y) = x-y(x+y)。

正确理解：x(x-y) + y(x-y) = (x-y)(x+y)。

## 八、练习题

**练习1：** 把8x³ - 12x²因式分解。

解：

找公因式：8和12的最大公约数是4。

x³和x²的最低次幂是x²。

公因式是4x²。

8x³ - 12x² = 4x²(2x - 3)

答：4x²(2x - 3)。

**练习2：** 把15a²b + 10ab²因式分解。

解：

找公因式：15和10的最大公约数是5。

a²和a的最低次幂是a。

b和b²的最低次幂是b。

公因式是5ab。

15a²b + 10ab² = 5ab(3a + 2b)

答：5ab(3a + 2b)。

**练习3：** 把-4x³ + 8x² - 12x因式分解。

解：

找公因式：4、8、12的最大公约数是4。

首项是负的，提出负号。

x³、x²、x的最低次幂是x。

公因式是-4x。

-4x³ + 8x² - 12x = -4x(x² - 2x + 3)

答：-4x(x² - 2x + 3)。

**练习4：** 把a(m-n) - b(m-n)因式分解。

解：

公因式是(m-n)。

a(m-n) - b(m-n) = (m-n)(a-b)

答：(m-n)(a-b)。

**练习5：** 把3x(x+y) - 2(x+y)²因式分解。

解：

公因式是(x+y)。

3x(x+y) - 2(x+y)² = (x+y)[3x - 2(x+y)]

= (x+y)(3x - 2x - 2y)

= (x+y)(x - 2y)

答：(x+y)(x - 2y)。
