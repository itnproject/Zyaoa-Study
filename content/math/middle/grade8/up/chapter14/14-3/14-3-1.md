# 14.3.1 因式分解的概念

## 一、从整式乘法的逆运算引入

整式乘法：(x+2)(x+3) = x² + 5x + 6

反过来：x² + 5x + 6 = (x+2)(x+3)

把一个多项式变成几个整式的积。

这就是因式分解。

## 二、因式分解的定义

**因式分解：把一个多项式化成几个整式的积的形式**

也叫分解因式。

x² + 5x + 6 = (x+2)(x+3)

左边是多项式，右边是积的形式。

## 三、因式分解与整式乘法的关系

**互为逆变形**

整式乘法：积 → 和

因式分解：和 → 积

(x+2)(x+3) → x² + 5x + 6（整式乘法）

x² + 5x + 6 → (x+2)(x+3)（因式分解）

## 四、判断一个变形是不是因式分解

**判断标准**

第一，左边必须是多项式。

第二，右边必须是几个整式的积。

第三，左右两边必须相等。

**例子**

x² - 4 = (x+2)(x-2) 是因式分解。

x² - 4 = x(x - 4/x) 不是因式分解（右边不是整式）。

(x+1)(x-1) = x² - 1 不是因式分解（这是整式乘法）。

## 五、因式分解的要求

**分解到不能再分解为止**

每个因式都要分解到不能再分解。

比如：x⁴ - 16 = (x²+4)(x²-4) 没有分解完。

x⁴ - 16 = (x²+4)(x+2)(x-2) 才分解完。

## 六、例题讲解

**例题1：** 判断下列变形是否为因式分解：

（1）x² - 4 = (x+2)(x-2)

（2）x² + 2x + 1 = x(x+2) + 1

（3）(x+1)(x+2) = x² + 3x + 2

解：

（1）是。左边是多项式，右边是积的形式。

（2）不是。右边不是积的形式。

（3）不是。这是整式乘法，不是因式分解。

**例题2：** 把x² - 9因式分解。

解：

x² - 9 = x² - 3² = (x+3)(x-3)

答：(x+3)(x-3)。

**例题3：** 把x² + 6x + 9因式分解。

解：

x² + 6x + 9 = x² + 2·x·3 + 3² = (x+3)²

答：(x+3)²。

**例题4：** 把x³ - x因式分解。

解：

x³ - x = x(x² - 1) = x(x+1)(x-1)

答：x(x+1)(x-1)。

**例题5：** 判断：x² + 1 = (x+1)(x-1)

解：

错误。

(x+1)(x-1) = x² - 1 ≠ x² + 1。

x² + 1在实数范围内不能因式分解。

## 七、常见错误

**错误1：右边不是积的形式**

错误做法：x² + x = x(x+1) + 0。

正确理解：右边必须是纯积的形式。

**错误2：分解不彻底**

错误做法：x⁴ - 1 = (x²+1)(x²-1)。

正确理解：x⁴ - 1 = (x²+1)(x+1)(x-1)。

**错误3：把整式乘法当成因式分解**

错误做法：(x+1)(x+2) = x² + 3x + 2是因式分解。

正确理解：这是整式乘法。

**错误4：右边出现分式**

错误做法：x² - x = x(x - 1/x)。

正确理解：因式分解要求右边是整式的积。

**错误5：等式不成立**

错误做法：x² + 4 = (x+2)²。

正确理解：(x+2)² = x² + 4x + 4 ≠ x² + 4。

## 八、练习题

**练习1：** 判断下列变形是否为因式分解：

（1）x² - 1 = (x+1)(x-1)

（2）x² + 2x = x(x+2)

（3）(x+3)(x-3) = x² - 9

解：

（1）是。

（2）是。

（3）不是，这是整式乘法。

**练习2：** 把x² - 25因式分解。

解：

x² - 25 = x² - 5² = (x+5)(x-5)

答：(x+5)(x-5)。

**练习3：** 把x² - 10x + 25因式分解。

解：

x² - 10x + 25 = x² - 2·x·5 + 5² = (x-5)²

答：(x-5)²。

**练习4：** 把x³ - 4x因式分解。

解：

x³ - 4x = x(x² - 4) = x(x+2)(x-2)

答：x(x+2)(x-2)。

**练习5：** 判断：x² + 2x + 1 = (x+1)²是因式分解。

解：

正确。

左边是多项式，右边是积的形式（(x+1)² = (x+1)(x+1)）。
