# 14.3.5 十字相乘法

## 一、从整式乘法引入

(x+2)(x+3) = x² + 5x + 6

反过来：x² + 5x + 6 = (x+2)(x+3)

2和3有什么关系？

2 + 3 = 5（一次项系数）

2 × 3 = 6（常数项）

这就是十字相乘法的原理。

## 二、十字相乘法的原理

**从(x+p)(x+q) = x² + (p+q)x + pq引入**

二次项系数是1时，把常数项分解成两个因数。

这两个因数的和等于一次项系数。

**十字相乘法的图示**

```
x    p
x    q
```

交叉相乘：xq + xp = (p+q)x

求和：p + q = 一次项系数

## 三、步骤

**第一步：竖分二次项和常数项**

二次项x²分成x和x。

常数项分解成两个因数。

**第二步：交叉相乘**

左边的x乘右边的因数，右边的x乘左边的因数。

**第三步：求和验中项**

交叉相乘的结果相加，看是否等于一次项系数。

**第四步：横写因式**

(x + 第一个因数)(x + 第二个因数)

## 四、注意符号的处理

**常数项为正**

两个因数同号。

一次项系数为正，两个因数都为正。

一次项系数为负，两个因数都为负。

**常数项为负**

两个因数异号。

绝对值大的因数符号与一次项系数相同。

## 五、例题讲解

**例题1：** 把x² + 5x + 6因式分解。

解：

常数项6分解：6 = 2 × 3

2 + 3 = 5 ✓（等于一次项系数）

x² + 5x + 6 = (x+2)(x+3)

答：(x+2)(x+3)。

**例题2：** 把x² - 7x + 12因式分解。

解：

常数项12为正，一次项系数为负，两个因数都为负。

12 = (-3) × (-4)

(-3) + (-4) = -7 ✓

x² - 7x + 12 = (x-3)(x-4)

答：(x-3)(x-4)。

**例题3：** 把x² + 2x - 15因式分解。

解：

常数项为负，两个因数异号。

-15 = 5 × (-3) 或 (-5) × 3

5 + (-3) = 2 ✓

x² + 2x - 15 = (x+5)(x-3)

答：(x+5)(x-3)。

**例题4：** 把2x² + 7x + 3因式分解。

解：

二次项系数不是1，也要分解。

2x² = x × 2x 或 2x² = 2x × x

常数项3 = 1 × 3

尝试：
```
x    1
2x   3
```
交叉相乘：3x + 2x = 5x ≠ 7x ✗

尝试：
```
x    3
2x   1
```
交叉相乘：x + 6x = 7x ✓

2x² + 7x + 3 = (x+3)(2x+1)

答：(x+3)(2x+1)。

**例题5：** 把3x² - 10x + 3因式分解。

解：

3x² = x × 3x

常数项3 = (-1) × (-3)

尝试：
```
x    -1
3x   -3
```
交叉相乘：-3x + (-3x) = -6x ≠ -10x ✗

尝试：
```
x    -3
3x   -1
```
交叉相乘：-x + (-9x) = -10x ✓

3x² - 10x + 3 = (x-3)(3x-1)

答：(x-3)(3x-1)。

## 六、常见错误

**错误1：因数分解找错**

错误做法：x² + 5x + 6 = (x+1)(x+6)。

正确理解：1 + 6 = 7 ≠ 5，x² + 5x + 6 = (x+2)(x+3)。

**错误2：符号搞错**

错误做法：x² - 5x + 6 = (x+2)(x+3)。

正确理解：两个因数都为负，x² - 5x + 6 = (x-2)(x-3)。

**错误3：二次项系数不为1时分解错误**

错误做法：2x² + 7x + 3 = (2x+3)(x+1)。

正确理解：交叉验证：2x + 3x = 5x ≠ 7x。

**错误4：没有验证**

错误做法：随便找两个因数就写答案。

正确理解：必须验证交叉相乘的和等于一次项系数。

**错误5：常数项为负时符号搞错**

错误做法：x² + 2x - 15 = (x-5)(x+3)。

正确理解：-5 + 3 = -2 ≠ 2，x² + 2x - 15 = (x+5)(x-3)。

## 七、练习题

**练习1：** 把x² + 7x + 12因式分解。

解：

12 = 3 × 4

3 + 4 = 7 ✓

x² + 7x + 12 = (x+3)(x+4)

答：(x+3)(x+4)。

**练习2：** 把x² - 8x + 15因式分解。

解：

15 = (-3) × (-5)

(-3) + (-5) = -8 ✓

x² - 8x + 15 = (x-3)(x-5)

答：(x-3)(x-5)。

**练习3：** 把x² - 3x - 10因式分解。

解：

-10 = 2 × (-5)

2 + (-5) = -3 ✓

x² - 3x - 10 = (x+2)(x-5)

答：(x+2)(x-5)。

**练习4：** 把2x² + 5x + 2因式分解。

解：

2x² = x × 2x

2 = 1 × 2

尝试：
```
x    1
2x   2
```
交叉相乘：2x + 2x = 4x ≠ 5x ✗

尝试：
```
x    2
2x   1
```
交叉相乘：x + 4x = 5x ✓

2x² + 5x + 2 = (x+2)(2x+1)

答：(x+2)(2x+1)。

**练习5：** 把3x² + 8x - 3因式分解。

解：

3x² = x × 3x

-3 = (-1) × 3 或 1 × (-3)

尝试：
```
x    -1
3x   3
```
交叉相乘：3x + (-3x) = 0 ≠ 8x ✗

尝试：
```
x    3
3x   -1
```
交叉相乘：-x + 9x = 8x ✓

3x² + 8x - 3 = (x+3)(3x-1)

答：(x+3)(3x-1)。
