# 13.2.3 等腰三角形的判定

## 一、从性质反过来思考

等腰三角形的性质：等边对等角。

反过来想：如果一个三角形有两个角相等，这个三角形是不是等腰三角形？

答案是肯定的。

这就是等腰三角形的判定。

## 二、等腰三角形的判定定理

**判定定理：如果一个三角形有两个角相等，那么这两个角所对的边也相等**

简记为"等角对等边"。

在△ABC中，∠B = ∠C。

则AB = AC。

## 三、用全等三角形证明

**已知：△ABC中，∠B = ∠C**

**求证：AB = AC**

**证明**

作AD平分∠BAC，交BC于点D。

在△ABD和△ACD中：

∠B = ∠C（已知）

∠BAD = ∠CAD（AD平分∠BAC）

AD = AD（公共边）

∴ △ABD≌△ACD（AAS）

∴ AB = AC

## 四、区分性质和判定

**性质：已知等腰推角相等**

已知：AB = AC

结论：∠B = ∠C

**判定：已知角相等推等腰**

已知：∠B = ∠C

结论：AB = AC

**记忆方法**

性质：等边 → 等角

判定：等角 → 等边

## 五、几何语言

**标准格式**

∵ ∠B = ∠C（已知）

∴ AB = AC（等角对等边）

## 六、例题讲解

**例题1：** 在△ABC中，∠B = 50°，∠C = 50°。判断△ABC的形状。

解：

∵ ∠B = ∠C = 50°

∴ AB = AC（等角对等边）

∴ △ABC是等腰三角形。

**例题2：** 在△ABC中，∠A = 80°，∠B = 50°。判断△ABC的形状。

解：

∠C = 180° - 80° - 50° = 50°

∵ ∠B = ∠C = 50°

∴ AB = AC（等角对等边）

∴ △ABC是等腰三角形。

**例题3：** 如图，在△ABC中，∠ABC和∠ACB的平分线交于点O，过O作DE∥BC，交AB于D，交AC于E。求证：BD + CE = DE。

证明：

∵ DE∥BC

∴ ∠DOB = ∠OBC（内错角相等）

∵ OB平分∠ABC

∴ ∠DBO = ∠OBC

∴ ∠DOB = ∠DBO

∴ BD = OD（等角对等边）

同理：CE = OE

∴ BD + CE = OD + OE = DE

**例题4：** 如图，在△ABC中，AB = AC，∠A = 36°，BD平分∠ABC。求证：AD = BD = BC。

证明：

∵ AB = AC，∠A = 36°

∴ ∠ABC = ∠C = (180° - 36°)/2 = 72°

∵ BD平分∠ABC

∴ ∠ABD = ∠DBC = 36°

在△ABD中，∠A = ∠ABD = 36°

∴ AD = BD（等角对等边）

在△BDC中，∠BDC = 180° - 36° - 72° = 72°

∴ ∠BDC = ∠C = 72°

∴ BD = BC（等角对等边）

∴ AD = BD = BC

**例题5：** 如图，在△ABC中，D是BC上一点，∠1 = ∠2，∠3 = ∠4。已知∠BAC = 60°。求∠DAC。

解：

∠1 + ∠3 = ∠BAC = 60°

∵ ∠1 = ∠2，∠3 = ∠4

∠2 + ∠4 = 60°

在△ABC中，∠B = ∠2，∠C = ∠4

∠B + ∠C = 60°

∠BAC = 180° - 60° = 120°

但已知∠BAC = 60°，矛盾。

题目条件需要重新理解。

如果∠1 = ∠2表示AD平分∠BAC，则：

∠DAC = ∠BAC/2 = 30°

答：∠DAC是30°。

## 七、常见错误

**错误1：性质和判定用反**

错误做法：已知AB = AC，用等角对等边。

正确理解：已知等腰用等边对等角，已知等角用等角对等边。

**错误2：对应关系搞错**

错误做法：∠A = ∠B，认为AC = BC。

正确理解：∠A = ∠B，BC = AC（角所对的边）。

**错误3：忽略三角形内角和**

错误做法：只给出一个角就判断等腰。

正确理解：需要两个角相等。

**错误4：没有先证明角相等**

错误做法：直接说等角对等边，没有证明角相等。

正确做法：先证明两个角相等，再用等角对等边。

**错误5：混淆等腰和等边**

错误做法：两个角相等就说是等边三角形。

正确理解：两个角相等是等腰三角形，三个角相等才是等边三角形。

## 八、练习题

**练习1：** 在△ABC中，∠A = 40°，∠B = 70°。判断△ABC的形状。

解：

∠C = 180° - 40° - 70° = 70°

∵ ∠B = ∠C = 70°

∴ AB = AC（等角对等边）

∴ △ABC是等腰三角形。

**练习2：** 如图，在△ABC中，BD平分∠ABC，DE∥BC交AB于E。求证：BE = DE。

证明：

∵ DE∥BC

∴ ∠EDB = ∠DBC（内错角相等）

∵ BD平分∠ABC

∴ ∠EBD = ∠DBC

∴ ∠EDB = ∠EBD

∴ BE = DE（等角对等边）

**练习3：** 在△ABC中，∠A = 36°，∠B = 72°。判断△ABC的形状。

解：

∠C = 180° - 36° - 72° = 72°

∵ ∠B = ∠C = 72°

∴ AB = AC（等角对等边）

∴ △ABC是等腰三角形。

**练习4：** 如图，在△ABC中，AB = AC，D是BC延长线上一点，DE∥AB交AC的延长线于E。求证：CE = CD。

证明：

∵ DE∥AB

∴ ∠CDE = ∠B（同位角相等）

∵ AB = AC

∴ ∠B = ∠C（等边对等角）

∴ ∠CDE = ∠C

∴ CE = CD（等角对等边）

**练习5：** 判断：有两个角是60°的三角形是等边三角形。

解：

正确。

两个角是60°，第三个角 = 180° - 60° - 60° = 60°。

三个角都相等，所以是等边三角形。
