# 13.2.1 等腰三角形的性质（等边对等角）

## 一、从生活实例引入

你见过金字塔吗？金字塔的侧面是等腰三角形。

你见过交通标志吗？很多交通标志是等腰三角形。

你见过屋顶的横截面吗？很多屋顶的横截面是等腰三角形。

这些等腰三角形有什么特点？

## 二、等腰三角形的定义

有两边相等的三角形叫做等腰三角形。

**各部分名称**

相等的两边叫做腰。

第三边叫做底边。

两腰的夹角叫做顶角。

腰和底边的夹角叫做底角。

**特殊情况**

三边都相等的三角形叫做等边三角形。

等边三角形是特殊的等腰三角形。

## 三、性质1：等边对等角

**等腰三角形的两个底角相等**

在△ABC中，AB = AC。

则∠B = ∠C。

**用全等证明**

作AD平分∠BAC，交BC于点D。

在△ABD和△ACD中：

AB = AC（已知）

∠BAD = ∠CAD（AD平分∠BAC）

AD = AD（公共边）

∴ △ABD≌△ACD（SAS）

∴ ∠B = ∠C

**用轴对称证明**

等腰三角形是轴对称图形。

对称轴是顶角平分线所在的直线。

沿对称轴折叠，两个底角重合。

所以两个底角相等。

## 四、几何语言

**标准格式**

∵ AB = AC（已知）

∴ ∠B = ∠C（等边对等角）

## 五、推论

**推论1：等腰三角形顶角的平分线、底边上的中线、底边上的高互相重合**

这就是"三线合一"，将在下一节详细讲解。

**推论2：等边三角形的三个角都相等，且都等于60°**

等边三角形三边相等，所以三个角都相等。

每个角 = 180°/3 = 60°。

## 六、例题讲解

**例题1：** 在△ABC中，AB = AC，∠B = 50°。求∠C和∠A。

解：

∵ AB = AC

∴ ∠C = ∠B = 50°（等边对等角）

∠A = 180° - ∠B - ∠C = 180° - 50° - 50° = 80°

答：∠C是50°，∠A是80°。

∵ AB = AC

∴ ∠B = ∠C（等边对等角）

∠B + ∠C = 180° - ∠A = 180° - 40° = 140°

∠B = ∠C = 140°/2 = 70°

答：∠B和∠C都是70°。

**例题3：** 在△ABC中，AB = AC，∠A = 90°。求∠B和∠C。

∵ AB = AC

∴ ∠B = ∠C（等边对等角）

∠B + ∠C = 180° - 90° = 90°

∠B = ∠C = 90°/2 = 45°

答：∠B和∠C都是45°。

**例题4：** 在△ABC中，AB = AC，∠B = 75°。求∠A。

解：

∵ AB = AC

∴ ∠C = ∠B = 75°（等边对等角）

∠A = 180° - 75° - 75° = 30°

答：∠A是30°。

**例题5：** 在△ABC中，AB = AC，点D在BC上，AD = BD。已知∠C = 40°。求∠BAD。

∵ AD = BD

## 七、常见错误

**错误1：顶角和底角搞混**

错误做法：认为∠A是底角。

正确理解：顶角是两腰的夹角，底角是腰和底边的夹角。

**错误2：等边对等角用错**

错误做法：AB = AC，认为∠A = ∠B。

正确理解：AB = AC，∠B和∠C是底角，∠B = ∠C。

**错误3：忽略三角形内角和**

错误做法：只求出底角，不求顶角。

正确理解：三个角的和是180°。

**错误4：认为等腰三角形只能是锐角三角形**

错误做法：认为等腰三角形的顶角必须小于90°。

正确理解：等腰三角形的顶角可以是锐角、直角或钝角。

**错误5：对应关系搞错**

错误做法：AB = BC，认为∠A = ∠C。

正确理解：AB = BC，∠A和∠C是底角，∠A = ∠C。

## 八、练习题

**练习1：** 在△ABC中，AB = AC，∠A = 100°。求∠B和∠C。

解：

∵ AB = AC

∴ ∠B = ∠C（等边对等角）

∠B + ∠C = 180° - 100° = 80°

∠B = ∠C = 80°/2 = 40°

答：∠B和∠C都是40°。

**练习2：** 在△ABC中，AB = AC，∠B = 65°。求∠A和∠C。

解：

∵ AB = AC

∴ ∠C = ∠B = 65°（等边对等角）

∠A = 180° - 65° - 65° = 50°

答：∠A是50°，∠C是65°。

**练习3：** 在等腰三角形中，一个角是80°。求另外两个角。

解：

情况1：80°是顶角。

另外两个角 = (180° - 80°)/2 = 50°。

情况2：80°是底角。

另一个底角 = 80°。

顶角 = 180° - 80° - 80° = 20°。

答：另外两个角是50°和50°，或80°和20°。

**练习4：** 在△ABC中，AB = AC，∠A = 36°。求∠B。

解：

∵ AB = AC

∴ ∠B = ∠C（等边对等角）

∠B = (180° - 36°)/2 = 72°

答：∠B是72°。

**练习5：** 在△ABC中，AB = AC，点D在AC上，BD = BC。已知∠A = 36°。求∠DBC。

解：

∵ AB = AC

∴ ∠ABC = ∠C = (180° - 36°)/2 = 72°

∵ BD = BC

∴ ∠BDC = ∠C = 72°（等边对等角）

在△BDC中，∠DBC = 180° - 72° - 72° = 36°

答：∠DBC是36°。
