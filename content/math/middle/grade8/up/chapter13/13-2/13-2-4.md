# 13.2.4 等边三角形的性质

## 一、从等腰三角形引入

等腰三角形是有两边相等的三角形。

如果三边都相等呢？

这就是等边三角形。

等边三角形是特殊的等腰三角形。

## 二、等边三角形的定义

三边都相等的三角形叫做等边三角形。

也叫正三角形。

**与等腰三角形的关系**

等边三角形是特殊的等腰三角形。

等腰三角形不一定是等边三角形。

## 三、性质1：三个内角都相等

**等边三角形的三个内角都相等，且都等于60°**

在△ABC中，AB = BC = CA。

则∠A = ∠B = ∠C = 60°。

**证明**

∵ AB = BC = CA

∴ ∠A = ∠B（等边对等角）

∴ ∠B = ∠C（等边对等角）

∴ ∠A = ∠B = ∠C

∵ ∠A + ∠B + ∠C = 180°

∴ ∠A = ∠B = ∠C = 60°

## 四、性质2：三条对称轴

等边三角形有三条对称轴。

每条边上的高所在的直线都是对称轴。

等边三角形是轴对称图形。

## 五、性质3：每条边上都有三线合一

等边三角形每条边上的高、中线、对角平分线都重合。

因为等边三角形每个角都可以看作"顶角"。

所以每条边上都满足三线合一。

## 六、例题讲解

**例题1：** 等边三角形的一个内角是多少度？

解：

等边三角形的三个内角都相等。

每个内角 = 180°/3 = 60°。

答：60°。

**例题2：** 在等边△ABC中，AD⊥BC于D。已知AB = 6cm。求BD和AD。

解：

∵ △ABC是等边三角形，AD⊥BC

∴ BD = BC/2 = 3cm（三线合一）

在Rt△ABD中，由勾股定理：

AD = √(AB² - BD²) = √(36 - 9) = √27 = 3√3 cm

答：BD是3cm，AD是3√3 cm。

**例题3：** 在等边△ABC中，D是AB的中点，E是AC的中点。求证：DE = BC/2。

证明：

∵ D是AB的中点，E是AC的中点

∴ DE是△ABC的中位线

∴ DE = BC/2（中位线定理）

**例题4：** 在等边△ABC中，点D、E、F分别在AB、BC、CA上，且AD = BE = CF。求证：△DEF是等边三角形。

证明：

∵ △ABC是等边三角形

∴ AB = BC = CA，∠A = ∠B = ∠C = 60°

∵ AD = BE = CF

∴ BD = CE = AF

在△ADF和△BED中：

AD = BE（已知）

∠A = ∠B = 60°（已证）

AF = BD（已证）

∴ △ADF≌△BED（SAS）

∴ DF = ED

同理：ED = FE

∴ DF = ED = FE

∴ △DEF是等边三角形

**例题5：** 等边三角形有几条对称轴？

解：

等边三角形有三条对称轴。

每条边上的高所在的直线都是对称轴。

答：3条。

## 七、常见错误

**错误1：等边三角形的角不是60°**

错误做法：认为等边三角形的角可以是其他度数。

正确理解：等边三角形的每个角都是60°。

**错误2：对称轴数量数错**

错误做法：认为等边三角形有1条或2条对称轴。

正确理解：等边三角形有3条对称轴。

**错误3：混淆等边和等腰**

错误做法：认为等边三角形和等腰三角形完全一样。

正确理解：等边是特殊的等腰，但等腰不一定是等边。

**错误4：三线合一用错**

错误做法：认为等边三角形只有一条边满足三线合一。

正确理解：等边三角形每条边都满足三线合一。

**错误5：面积公式用错**

错误做法：用一般三角形面积公式，不用等边三角形的特殊公式。

正确理解：等边三角形面积 = (√3/4) × 边长²。

## 八、练习题

**练习1：** 等边三角形的周长是18cm。求边长。

解：

等边三角形三边相等。

边长 = 18/3 = 6cm。

答：6cm。

**练习2：** 在等边△ABC中，AD是BC边上的高。已知AD = 4√3 cm。求AB。

解：

设AB = x。

BD = x/2（三线合一）

在Rt△ABD中，由勾股定理：

x² = (x/2)² + (4√3)²

x² = x²/4 + 48

3x²/4 = 48

x² = 64

x = 8cm

答：AB是8cm。

**练习3：** 等边三角形的面积是9√3 cm²。求边长。

解：

等边三角形面积 = (√3/4) × 边长²

9√3 = (√3/4) × 边长²

边长² = 36

边长 = 6cm

答：6cm。

**练习4：** 在等边△ABC中，D是BC上一点，∠BAD = 20°。求∠DAC。

解：

∵ △ABC是等边三角形

∴ ∠BAC = 60°

∠DAC = ∠BAC - ∠BAD = 60° - 20° = 40°

答：∠DAC是40°。

**练习5：** 判断：等边三角形既是轴对称图形，也是中心对称图形。

解：

错误。

等边三角形是轴对称图形（有3条对称轴）。

但等边三角形不是中心对称图形。

中心对称图形需要绕中心旋转180°后与原图形重合。

等边三角形旋转180°后不与原图形重合。
