# 13.2.6 含30°角的直角三角形的性质

## 一、从等边三角形的高引入

画一个等边三角形ABC。

作BC边上的高AD。

AD把等边三角形分成两个直角三角形。

在Rt△ABD中，∠B = 60°，∠BAD = 30°。

BD = BC/2 = AB/2。

这就是含30°角的直角三角形的性质。

## 二、性质

**在直角三角形中，如果一个锐角等于30°，那么它所对的直角边等于斜边的一半**

在Rt△ABC中，∠C = 90°，∠A = 30°。

则BC = AB/2。

## 三、用等边三角形的性质证明

**证明**

延长BC到D，使CD = BC。

连接AD。

在△ABC和△ADC中：

BC = DC（构造）

∠ACB = ∠ACD = 90°（已知）

AC = AC（公共边）

∴ △ABC≌△ADC（SAS）

∴ AB = AD，∠BAC = ∠DAC = 30°

∴ ∠BAD = 60°

∴ △ABD是等边三角形（有一个角是60°的等腰三角形）

∴ BD = AB

∵ BD = 2BC

∴ AB = 2BC

∴ BC = AB/2

## 四、几何语言

**标准格式**

∵ ∠C = 90°，∠A = 30°

∴ BC = AB/2（在直角三角形中，30°角所对的直角边等于斜边的一半）

## 五、逆命题

**如果一条直角边等于斜边的一半，那么这条直角边所对的角是30°**

在Rt△ABC中，∠C = 90°，BC = AB/2。

则∠A = 30°。

**证明**

延长BC到D，使CD = BC。

连接AD。

BD = 2BC = AB

在△ABC和△ADC中：

BC = DC（构造）

∠ACB = ∠ACD = 90°

AC = AC（公共边）

∴ △ABC≌△ADC（SAS）

∴ AB = AD

∴ AB = AD = BD

∴ △ABD是等边三角形

∴ ∠BAD = 60°

∴ ∠BAC = 30°

## 六、常用结论

**含30°角的直角三角形三边之比**

BC : AC : AB = 1 : √3 : 2

30°角所对的直角边 : 60°角所对的直角边 : 斜边 = 1 : √3 : 2

## 七、例题讲解

**例题1：** 在Rt△ABC中，∠C = 90°，∠A = 30°，AB = 10cm。求BC。

解：

∵ ∠C = 90°，∠A = 30°

∴ BC = AB/2 = 10/2 = 5cm

答：BC是5cm。

**例题2：** 在Rt△ABC中，∠C = 90°，∠A = 30°，BC = 6cm。求AB。

解：

∵ ∠C = 90°，∠A = 30°

∴ BC = AB/2

∴ AB = 2BC = 2 × 6 = 12cm

答：AB是12cm。

**例题3：** 在Rt△ABC中，∠C = 90°，∠A = 30°，AB = 8cm。求AC。

解：

∵ ∠C = 90°，∠A = 30°

∴ BC = AB/2 = 4cm

在Rt△ABC中，由勾股定理：

AC = √(AB² - BC²) = √(64 - 16) = √48 = 4√3 cm

答：AC是4√3 cm。

**例题4：** 在Rt△ABC中，∠C = 90°，BC = 5cm，AB = 10cm。求∠A。

解：

∵ BC = 5cm，AB = 10cm

∴ BC = AB/2

∴ ∠A = 30°（直角边等于斜边的一半，所对的角是30°）

答：∠A是30°。

**例题5：** 如图，在Rt△ABC中，∠C = 90°，∠A = 30°，D是AB的中点。求证：CD = AB/2。

证明：

∵ ∠C = 90°，∠A = 30°

∴ BC = AB/2

∵ D是AB的中点

∴ BD = AB/2

∴ BC = BD

在Rt△ABC中，D是斜边AB的中点。

∴ CD = AB/2（直角三角形斜边上的中线等于斜边的一半）

## 八、常见错误

**错误1：30°角所对的边搞错**

错误做法：认为30°角所对的边是AC。

正确理解：30°角所对的边是BC（∠A的对边）。

**错误2：比例关系记错**

错误做法：认为三边之比是1 : 2 : √3。

正确理解：三边之比是1 : √3 : 2。

**错误3：逆命题不会用**

错误做法：已知BC = AB/2，不会推∠A = 30°。

正确理解：直角边等于斜边的一半，所对的角是30°。

**错误4：混淆30°和60°**

错误做法：认为60°角所对的直角边等于斜边的一半。

正确理解：30°角所对的直角边等于斜边的一半。

**错误5：没有注明直角三角形**

错误做法：在一般三角形中用这个性质。

正确理解：这个性质只适用于直角三角形。

## 九、练习题

**练习1：** 在Rt△ABC中，∠C = 90°，∠A = 30°，AB = 14cm。求BC。

解：

∵ ∠C = 90°，∠A = 30°

∴ BC = AB/2 = 14/2 = 7cm

答：BC是7cm。

**练习2：** 在Rt△ABC中，∠C = 90°，∠A = 30°，AC = 6√3 cm。求AB。

解：

∵ ∠C = 90°，∠A = 30°

∴ BC = AB/2

AC = √(AB² - BC²) = √(AB² - AB²/4) = √(3AB²/4) = AB√3/2

6√3 = AB√3/2

AB = 12cm

答：AB是12cm。

**练习3：** 在Rt△ABC中，∠C = 90°，BC = 3cm，AB = 6cm。求∠A。

解：

∵ BC = 3cm，AB = 6cm

∴ BC = AB/2

∴ ∠A = 30°

答：∠A是30°。

**练习4：** 在Rt△ABC中，∠C = 90°，∠A = 30°，BC = 4cm。求△ABC的面积。

解：

∵ ∠C = 90°，∠A = 30°

∴ BC = AB/2 = 4cm

AB = 8cm

AC = √(AB² - BC²) = √(64 - 16) = √48 = 4√3 cm

面积 = BC × AC / 2 = 4 × 4√3 / 2 = 8√3 cm²

答：面积是8√3 cm²。

**练习5：** 如图，在Rt△ABC中，∠C = 90°，∠A = 30°，∠ABC的平分线交AC于点D。已知BC = 2cm。求AD。

解：

∵ ∠C = 90°，∠A = 30°

∴ ∠ABC = 60°

AB = 2BC = 4cm

AC = √(16 - 4) = √12 = 2√3 cm

∵ BD平分∠ABC

∴ ∠ABD = ∠DBC = 30°

在Rt△BCD中，∠DBC = 30°

CD = BC/2 = 1cm

AD = AC - CD = 2√3 - 1 cm

答：AD是(2√3 - 1)cm。
