# 13.2.2 等腰三角形的性质（三线合一）

## 一、从等腰三角形的对称性引入

等腰三角形是轴对称图形。

对称轴是顶角平分线所在的直线。

沿对称轴折叠，左右两边完全重合。

这条对称轴有什么特殊性质？

## 二、三线合一的性质

**性质2：等腰三角形顶角平分线、底边上的中线、底边上的高相互重合**

在△ABC中，AB = AC。

AD是顶角∠BAC的平分线。

AD也是底边BC上的中线。

AD也是底边BC上的高。

这三条线重合为一条线。

## 三、用全等三角形证明

**已知：△ABC中，AB = AC，AD平分∠BAC**

**求证：AD⊥BC，BD = CD**

**证明**

在△ABD和△ACD中：

AB = AC（已知）

∠BAD = ∠CAD（AD平分∠BAC）

AD = AD（公共边）

∴ △ABD≌△ACD（SAS）

∴ BD = CD（对应边相等）

∴ ∠ADB = ∠ADC（对应角相等）

∵ ∠ADB + ∠ADC = 180°

∴ ∠ADB = ∠ADC = 90°

∴ AD⊥BC

## 四、三线合一的三种表述方式

**表述1：已知平分线，推中线和高**

∵ AB = AC，AD平分∠BAC

∴ BD = CD，AD⊥BC

**表述2：已知中线，推平分线和高**

∵ AB = AC，BD = CD

∴ AD平分∠BAC，AD⊥BC

**表述3：已知高，推平分线和中线**

∵ AB = AC，AD⊥BC

∴ AD平分∠BAC，BD = CD

## 五、重要注意事项

**只有顶角的平分线才满足三线合一**

底角的平分线不满足三线合一。

底角平分线不是对边的中线，也不是对边的高。

**等边三角形的三线合一**

等边三角形每条边上都有三线合一。

因为等边三角形每个角都可以看作"顶角"。

## 六、例题讲解

**例题1：** 在△ABC中，AB = AC，AD⊥BC于D。已知BC = 8cm。求BD。

解：

∵ AB = AC，AD⊥BC

∴ AD是底边BC上的中线（三线合一）

∴ BD = BC/2 = 4cm

答：BD是4cm。

**例题2：** 在△ABC中，AB = AC，AD是BC边上的中线。已知∠B = 50°。求∠BAD。

解：

∵ AB = AC，AD是BC边上的中线

∴ AD平分∠BAC（三线合一）

∠C = ∠B = 50°（等边对等角）

∠BAC = 180° - 50° - 50° = 80°

∠BAD = ∠BAC/2 = 40°

答：∠BAD是40°。

**例题3：** 在△ABC中，AB = AC，AD平分∠BAC。已知BC = 10cm，AD = 12cm。求AB。

解：

∵ AB = AC，AD平分∠BAC

∴ BD = BC/2 = 5cm，AD⊥BC（三线合一）

在Rt△ABD中，由勾股定理：

AB = √(BD² + AD²) = √(25 + 144) = √169 = 13cm

答：AB是13cm。

**例题4：** 在△ABC中，AB = AC，AD⊥BC于D。已知AB = 10cm，BD = 6cm。求AD和BC。

解：

∵ AB = AC，AD⊥BC

∴ BD = CD = 6cm（三线合一）

BC = 2 × BD = 12cm

在Rt△ABD中，由勾股定理：

AD = √(AB² - BD²) = √(100 - 36) = √64 = 8cm

答：AD是8cm，BC是12cm。

**例题5：** 在△ABC中，AB = AC，D是BC的中点，DE⊥AB于E，DF⊥AC于F。求证：DE = DF。

证明：

∵ AB = AC，D是BC的中点

∴ AD平分∠BAC（三线合一）

∵ DE⊥AB，DF⊥AC

∴ DE = DF（角平分线上的点到角两边的距离相等）

## 七、常见错误

**错误1：底角平分线也用三线合一**

错误做法：∠B的平分线也是AC边上的中线和高。

正确理解：只有顶角的平分线才满足三线合一。

**错误2：三线合一用错方向**

错误做法：已知AD⊥BC，直接说BD = CD，没有说明AB = AC。

正确理解：必须先说明是等腰三角形。

**错误3：忽略三线合一的前提**

错误做法：任意三角形也用三线合一。

正确理解：只有等腰三角形才有三线合一。

**错误4：混淆中线和角平分线**

错误做法：认为中线就是角平分线。

正确理解：只有等腰三角形中，底边上的中线才同时是顶角平分线。

**错误5：证明过程跳步**

错误做法：直接写结论，不说明用了三线合一。

正确做法：先说明等腰三角形，再说明用了三线合一。
