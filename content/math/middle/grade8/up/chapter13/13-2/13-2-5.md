# 13.2.5 等边三角形的判定

## 一、从等腰三角形引入

等腰三角形是有两边相等的三角形。

怎样判断一个三角形是等边三角形？

有三种方法。

## 二、判定1：三边都相等

**三边都相等的三角形是等边三角形**

在△ABC中，AB = BC = CA。

则△ABC是等边三角形。

这是定义的直接应用。

## 三、判定2：三个角都相等

**三个角都相等的三角形是等边三角形**

在△ABC中，∠A = ∠B = ∠C。

则△ABC是等边三角形。

**证明**

∵ ∠A = ∠B

∴ BC = AC（等角对等边）

∵ ∠B = ∠C

∴ AC = AB（等角对等边）

∴ AB = BC = CA

∴ △ABC是等边三角形

## 四、判定3：有一个角是60°的等腰三角形

**有一个角是60°的等腰三角形是等边三角形**

在△ABC中，AB = AC，∠A = 60°。

则△ABC是等边三角形。

**证明**

∵ AB = AC

∴ ∠B = ∠C（等边对等角）

∵ ∠A = 60°

∴ ∠B + ∠C = 180° - 60° = 120°

∴ ∠B = ∠C = 60°

∴ ∠A = ∠B = ∠C = 60°

∴ △ABC是等边三角形

**注意：这个60°的角可以是顶角，也可以是底角**

如果60°是顶角，如上证明。

如果60°是底角，则另一个底角也是60°，顶角 = 60°。

## 五、三种判定方法的对比和选择

**已知三边：用判定1**

直接验证三边是否相等。

**已知三角：用判定2**

直接验证三角是否相等。

**已知等腰+一个角：用判定3**

验证这个角是否是60°。

## 六、例题讲解

**例题1：** 在△ABC中，AB = 5cm，BC = 5cm，CA = 5cm。判断△ABC的形状。

解：

∵ AB = BC = CA = 5cm

∴ △ABC是等边三角形（三边都相等）

**例题2：** 在△ABC中，∠A = 60°，∠B = 60°。判断△ABC的形状。

解：

∠C = 180° - 60° - 60° = 60°

∵ ∠A = ∠B = ∠C = 60°

∴ △ABC是等边三角形（三个角都相等）

**例题3：** 在△ABC中，AB = AC，∠A = 60°。判断△ABC的形状。

解：

∵ AB = AC，∠A = 60°

∴ △ABC是等边三角形（有一个角是60°的等腰三角形）

**例题4：** 在△ABC中，AB = AC，∠B = 60°。判断△ABC的形状。

解：

∵ AB = AC

∴ ∠C = ∠B = 60°（等边对等角）

∠A = 180° - 60° - 60° = 60°

∴ △ABC是等边三角形

**例题5：** 在△ABC中，∠A = ∠B = ∠C。已知AB = 4cm。求△ABC的周长。

解：

∵ ∠A = ∠B = ∠C

∴ △ABC是等边三角形

∴ AB = BC = CA = 4cm

周长 = 4 + 4 + 4 = 12cm

答：周长是12cm。

## 七、常见错误

**错误1：只有一个角是60°就说是等边**

错误做法：∠A = 60°，就说是等边三角形。

正确理解：必须是等腰三角形且有一个角是60°。

**错误2：两边相等就说是等边**

错误做法：AB = AC，就说是等边三角形。

正确理解：两边相等是等腰，三边相等才是等边。

**错误3：两个角相等就说是等边**

错误做法：∠A = ∠B，就说是等边三角形。

正确理解：两个角相等是等腰，三个角相等才是等边。

**错误4：60°的角位置搞错**

错误做法：认为60°必须是顶角。

正确理解：60°可以是顶角，也可以是底角。

**错误5：判定方法选择不当**

错误做法：已知三角相等，用三边相等来判定。

正确理解：根据已知条件选择合适的判定方法。

## 八、练习题

**练习1：** 在△ABC中，AB = 7cm，BC = 7cm，CA = 7cm。判断△ABC的形状。

解：

∵ AB = BC = CA

∴ △ABC是等边三角形。

**练习2：** 在△ABC中，∠A = 70°，∠B = 55°。判断△ABC是否为等边三角形。

解：

∠C = 180° - 70° - 55° = 55°

∵ ∠A ≠ ∠B

∴ △ABC不是等边三角形。

**练习3：** 在△ABC中，AB = AC，∠C = 60°。判断△ABC的形状。

解：

∵ AB = AC

∴ ∠B = ∠C = 60°（等边对等角）

∠A = 180° - 60° - 60° = 60°

∴ △ABC是等边三角形。

**练习4：** 在△ABC中，∠A = ∠B = ∠C。已知周长是15cm。求AB。

解：

∵ ∠A = ∠B = ∠C

∴ △ABC是等边三角形

AB = 15/3 = 5cm

答：AB是5cm。

**练习5：** 判断：有一个角是60°的三角形是等边三角形。

解：

错误。

必须是等腰三角形且有一个角是60°。

一般三角形有一个角是60°，不一定是等边三角形。

比如∠A = 60°，∠B = 50°，∠C = 70°，不是等边三角形。
