# 13.1.2 两个图形关于某直线对称

## 一、从生活实例引入

你照过镜子吗？镜子里的你和镜子外的你，关于镜面对称。

你看过水中的倒影吗？水中的倒影和水上的实物，关于水面对称。

你把一张纸对折后，在折痕一侧画一个图案，展开后另一侧也有一个相同的图案。

这两个图案关于折痕对称。

## 二、两个图形成轴对称的定义

把一个图形沿着某条直线折叠，如果它能够与另一个图形重合，那么就说这两个图形关于这条直线对称。

这条直线叫做对称轴。

折叠后重合的点叫做对应点或对称点。

折叠后重合的线段叫做对应线段。

折叠后重合的角叫做对应角。

## 三、对应元素

**对应点（对称点）**

折叠后重合的点。

如果点A和点A'关于直线l对称，那么A和A'是对应点。

**对应线段**

折叠后重合的线段。

如果线段AB和线段A'B'关于直线l对称，那么AB和A'B'是对应线段，且AB = A'B'。

**对应角**

折叠后重合的角。

如果∠A和∠A'关于直线l对称，那么∠A和∠A'是对应角，且∠A = ∠A'。

## 四、轴对称图形 vs 两个图形成轴对称

**区别**

轴对称图形：一个图形自身的特征。

两个图形成轴对称：两个图形之间的关系。

**联系**

如果把轴对称图形沿对称轴分成两部分，那么这两部分关于这条直线对称。

如果把两个成轴对称的图形拼在一起，那么整个图形是轴对称图形。

## 五、轴对称的性质

关于某条直线对称的两个图形是全等形。

对应线段相等。

对应角相等。

对称点的连线被对称轴垂直平分。

## 六、例题讲解

**例题1：** 如图，△ABC和△A'B'C'关于直线l对称。已知AB = 5cm，∠A = 60°。求A'B'和∠A'。

解：

∵ △ABC和△A'B'C'关于直线l对称

∴ A'B' = AB = 5cm（对应线段相等）

∴ ∠A' = ∠A = 60°（对应角相等）

答：A'B' = 5cm，∠A' = 60°。

**例题2：** 如图，点A和点B关于直线l对称。已知点A到直线l的距离是3cm。求点B到直线l的距离。

解：

∵ 点A和点B关于直线l对称

∴ 点A和点B到直线l的距离相等。

∴ 点B到直线l的距离 = 3cm。

答：3cm。

**例题3：** 判断：两个全等的图形一定关于某条直线对称。

解：

错误。

两个全等的图形形状和大小相同，但位置关系不一定满足轴对称。

比如两个全等的三角形，可以通过平移得到，不一定关于某条直线对称。

**例题4：** 如图，△ABC和△DEF关于直线l对称。已知△ABC的周长是15cm，面积是12cm²。求△DEF的周长和面积。

解：

∵ △ABC和△DEF关于直线l对称

∴ △ABC≌△DEF

∴ △DEF的周长 = 15cm

∴ △DEF的面积 = 12cm²

答：周长15cm，面积12cm²。

**例题5：** 如图，四边形ABCD和四边形A'B'C'D'关于直线l对称。已知∠A = 80°，∠B = 100°，∠C = 70°。求∠D'。

解：

∵ 四边形ABCD和四边形A'B'C'D'关于直线l对称

∴ ∠D' = ∠D

在四边形ABCD中，∠D = 360° - 80° - 100° - 70° = 110°

∴ ∠D' = 110°

答：∠D'是110°。

## 七、常见错误

**错误1：混淆轴对称图形和两个图形成轴对称**

错误做法：认为一个图形关于某直线对称，就是两个图形成轴对称。

正确理解：轴对称图形是一个图形的特征，两个图形成轴对称是两个图形之间的关系。

**错误2：对应点找错**

错误做法：认为A的对应点是B。

正确理解：根据对称关系找对应点。

**错误3：认为对称图形位置必须相同**

错误做法：两个图形位置不同，认为不对称。

正确理解：轴对称与位置无关，只与折叠后能否重合有关。

**错误4：忽略全等关系**

错误做法：没有利用对称图形全等这个性质。

正确理解：关于某直线对称的两个图形一定全等。

**错误5：对称轴找错**

错误做法：随便画一条直线作为对称轴。

正确理解：对称轴是对应点连线的垂直平分线。

**练习1：** 如图，△ABC和△A'B'C'关于直线l对称。已知BC = 7cm，∠C = 45°。求B'C'和∠C'。

解：

∵ △ABC和△A'B'C'关于直线l对称

∴ B'C' = BC = 7cm

∴ ∠C' = ∠C = 45°

答：B'C' = 7cm，∠C' = 45°。

**练习2：** 点P和点Q关于直线m对称。已知PQ = 8cm。求点P到直线m的距离。

解：

∵ 点P和点Q关于直线m对称

∴ 直线m垂直平分PQ。

∴ 点P到直线m的距离 = PQ/2 = 4cm。

答：4cm。

**练习3：** 判断：关于某直线对称的两个图形面积一定相等。

解：

正确。

关于某直线对称的两个图形全等。

全等图形面积相等。

**练习4：** 如图，△ABC和△A'B'C'关于直线l对称。已知∠A = 50°，∠B' = 70°。求∠C。

解：

∵ △ABC和△A'B'C'关于直线l对称

∴ ∠B = ∠B' = 70°

在△ABC中，∠C = 180° - 50° - 70° = 60°

答：∠C是60°。

**练习5：** 如图，线段AB和线段A'B'关于直线l对称。已知AB = 6cm，AA' = 4cm。求A'B'和点A到直线l的距离。

解：

∵ 线段AB和线段A'B'关于直线l对称

∴ A'B' = AB = 6cm

∵ 点A和点A'关于直线l对称

∴ 点A到直线l的距离 = AA'/2 = 2cm。

答：A'B' = 6cm，点A到直线l的距离是2cm。
