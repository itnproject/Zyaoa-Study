# 13.1.5 轴对称的性质

## 一、从折叠实验引入

拿一张纸，画一个图形。

把纸沿一条直线对折。

在折痕另一侧描出图形的轮廓。

展开后，你会看到两个关于折痕对称的图形。

这两个图形有什么关系？

## 二、轴对称的性质

**性质1：关于某条直线对称的两个图形是全等形**

如果△ABC和△A'B'C'关于直线l对称，那么△ABC≌△A'B'C'。

**性质2：对称点的连线被对称轴垂直平分**

如果点A和点A'关于直线l对称，那么直线l垂直平分AA'。

**性质3：对称线段相等，对称角相等**

如果线段AB和线段A'B'关于直线l对称，那么AB = A'B'。

如果∠A和∠A'关于直线l对称，那么∠A = ∠A'。

## 三、利用性质作图：找对称点

**已知点A和直线l，求作点A关于直线l的对称点A'**

步骤：

第一步：过点A作直线l的垂线，垂足为O。

第二步：在垂线上截取OA' = OA。

第三步：点A'即为所求。

**原理**

对称点的连线被对称轴垂直平分。

所以AA'⊥l，且O是AA'的中点。

## 四、例题讲解

**例题1：** 如图，△ABC和△A'B'C'关于直线l对称。已知AB = 6cm，∠C = 50°。求A'B'和∠C'。

解：

∵ △ABC和△A'B'C'关于直线l对称

∴ △ABC≌△A'B'C'

∴ A'B' = AB = 6cm

∴ ∠C' = ∠C = 50°

答：A'B' = 6cm，∠C' = 50°。

**例题2：** 如图，点A和点A'关于直线l对称。已知AA' = 10cm。求点A到直线l的距离。

解：

∵ 点A和点A'关于直线l对称

∴ 直线l垂直平分AA'。

∴ 点A到直线l的距离 = AA'/2 = 5cm。

答：5cm。

**例题3：** 如图，四边形ABCD和四边形A'B'C'D'关于直线l对称。已知∠A = 70°，∠B = 110°，∠C = 80°。求∠D'。

解：

∵ 四边形ABCD和四边形A'B'C'D'关于直线l对称

∴ ∠D' = ∠D

在四边形ABCD中，∠D = 360° - 70° - 110° - 80° = 100°

∴ ∠D' = 100°

答：∠D'是100°。

**例题4：** 如图，点A、B在直线l的同侧。在直线l上找一点P，使PA + PB最小。

解：

作点A关于直线l的对称点A'。

连接A'B，交直线l于点P。

则点P即为所求。

理由：

PA = PA'（对称性质）

PA + PB = PA' + PB = A'B

根据两点之间线段最短，A'B是最短路径。

**例题5：** 如图，△ABC中，AB = 8cm，AC = 6cm，BC的垂直平分线交AB于点D。求△ACD的周长。

解：

∵ BC的垂直平分线交AB于点D

∴ DB = DC

△ACD的周长 = AC + CD + AD = AC + DB + AD = AC + AB = 6 + 8 = 14cm

答：△ACD的周长是14cm。

## 五、常见错误

**错误1：对称点连线不被对称轴垂直**

错误做法：认为对称点连线只是被平分，不一定垂直。

正确理解：对称点连线被对称轴垂直平分。

**错误2：最短路径问题不会做**

错误做法：直接连接AB。

正确做法：先作对称点，再连接。

**错误3：对称图形不全等**

错误做法：认为对称图形只是形状相同，大小不一定相同。

正确理解：对称图形一定全等。

**错误4：对应关系搞错**

错误做法：A的对称点是B。

正确理解：根据对称轴找对应点。

**错误5：作对称点时不垂直**

错误做法：随便画一条线找对称点。

正确做法：必须过已知点作对称轴的垂线。

## 六、练习题

**练习1：** 如图，△ABC和△A'B'C'关于直线l对称。已知BC = 9cm，∠A = 40°。求B'C'和∠A'。

解：

∵ △ABC和△A'B'C'关于直线l对称

∴ B'C' = BC = 9cm

∴ ∠A' = ∠A = 40°

答：B'C' = 9cm，∠A' = 40°。

**练习2：** 如图，点P和点P'关于直线m对称。已知PP' = 12cm。求点P到直线m的距离。

解：

∵ 点P和点P'关于直线m对称

∴ 直线m垂直平分PP'。

∴ 点P到直线m的距离 = 12/2 = 6cm。

答：6cm。

**练习3：** 如图，点A、B在直线l的同侧。在直线l上找一点P，使PA + PB最小。已知A到l的距离是3cm，B到l的距离是5cm，A、B在l上的投影之间的距离是8cm。求PA + PB的最小值。

解：

作点A关于直线l的对称点A'。

A'到l的距离也是3cm。

A'B = √(8² + (3+5)²) = √(64 + 64) = √128 = 8√2 cm

PA + PB的最小值 = A'B = 8√2 cm

答：PA + PB的最小值是8√2 cm。

**练习4：** 如图，在△ABC中，AB = 10cm，AC = 7cm，AB的垂直平分线交AC于点E。求△BCE的周长。

解：

∵ AB的垂直平分线交AC于点E

∴ EA = EB

△BCE的周长 = BC + CE + EB = BC + CE + EA

但BC未知。

题目条件不足，需要补充BC的长。

**练习5：** 判断：关于某直线对称的两个图形，对应线段一定平行。

解：

错误。

对应线段不一定平行。

比如一个三角形关于一条直线对称，对应线段可能相交。

只有当对称轴平行于对应线段时，对应线段才平行。
