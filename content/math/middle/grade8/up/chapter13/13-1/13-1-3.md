# 13.1.3 线段的垂直平分线

## 一、从生活实例引入

你有一条线段AB。

你想找到这条线段的"中垂线"。

这条线既经过AB的中点，又垂直于AB。

这就是线段的垂直平分线。

## 二、垂直平分线的定义

经过线段中点并且垂直于这条线段的直线，叫做这条线段的垂直平分线。

也叫中垂线。

**两个条件**

第一，经过线段的中点。

第二，垂直于这条线段。

两个条件缺一不可。

## 三、垂直平分线的性质

**性质：线段垂直平分线上的点到线段两端点的距离相等**

直线MN是线段AB的垂直平分线。

点P是MN上任意一点。

则PA = PB。

**用SAS证明**

设MN交AB于点O，则O是AB的中点，MN⊥AB。

在△POA和△POB中：

OA = OB（O是中点）

∠POA = ∠POB = 90°（MN⊥AB）

OP = OP（公共边）

∴ △POA≌△POB（SAS）

∴ PA = PB

## 四、几何语言

**标准格式**

∵ MN垂直平分AB，点P在MN上

∴ PA = PB（线段垂直平分线上的点到线段两端点的距离相等）

## 五、例题讲解

**例题1：** 如图，直线l是线段AB的垂直平分线，点P在l上。已知PA = 5cm。求PB。

解：

∵ 直线l垂直平分AB，点P在l上

∴ PB = PA = 5cm

答：PB是5cm。

**例题2：** 如图，在△ABC中，DE垂直平分AB，交AC于点E。已知AC = 8cm，BC = 6cm。求△BCE的周长。

解：

∵ DE垂直平分AB，点E在DE上

∴ EA = EB

△BCE的周长 = BC + CE + EB = BC + CE + EA = BC + AC = 6 + 8 = 14cm

答：△BCE的周长是14cm。

**例题3：** 如图，在△ABC中，AB的垂直平分线交BC于点D。已知AC = 5cm，△ADC的周长是13cm。求BC。

解：

∵ AB的垂直平分线交BC于点D

∴ DA = DB

△ADC的周长 = AD + DC + AC = 13

DB + DC + AC = 13

BC + AC = 13

BC + 5 = 13

BC = 8cm

答：BC是8cm。

**例题4：** 如图，点P在线段AB的垂直平分线上。已知PA = 7cm，AB = 10cm。求点P到AB的距离。

解：

设AB的中点为O，PO⊥AB。

OA = AB/2 = 5cm

在Rt△POA中，由勾股定理：

PO = √(PA² - OA²) = √(49 - 25) = √24 = 2√6 cm

答：点P到AB的距离是2√6 cm。

**例题5：** 如图，在△ABC中，AB = AC，DE垂直平分AC，交AB于点D，交AC于点E。已知△BCD的周长是18cm，BC = 6cm。求AB。

解：

∵ DE垂直平分AC

∴ DA = DC

△BCD的周长 = BC + CD + BD = BC + DA + BD = BC + AB = 18

6 + AB = 18

AB = 12cm

答：AB是12cm。

## 六、常见错误

**错误1：忽略"直线"这个条件**

错误做法：认为垂直平分线是线段。

正确理解：垂直平分线是一条直线。

**错误2：只满足一个条件**

错误做法：只经过中点，不垂直。

正确理解：必须同时满足经过中点和垂直两个条件。

**错误3：点不在垂直平分线上也用性质**

错误做法：任意一点到线段两端距离相等。

正确理解：只有垂直平分线上的点才满足这个性质。

**错误4：对应关系搞错**

错误做法：PA = AB。

正确理解：PA = PB，是到两端点的距离相等。

**错误5：周长计算时没有替换**

错误做法：没有利用DA = DB进行等量代换。

正确理解：利用垂直平分线性质进行等量代换是常用技巧。

## 七、练习题

**练习1：** 如图，直线l是线段AB的垂直平分线，点P在l上。已知PB = 9cm。求PA。

解：

∵ 直线l垂直平分AB，点P在l上

∴ PA = PB = 9cm

答：PA是9cm。

**练习2：** 如图，DE垂直平分BC，交AB于点D。已知AB = 10cm，AC = 7cm。求△ADC的周长。

解：

∵ DE垂直平分BC，点D在DE上

∴ DB = DC

△ADC的周长 = AD + DC + AC = AD + DB + AC = AB + AC = 10 + 7 = 17cm

答：△ADC的周长是17cm。

**练习3：** 如图，在△ABC中，AC的垂直平分线交AB于点D。已知AB = 8cm，BC = 5cm。求△BCD的周长。

解：

∵ AC的垂直平分线交AB于点D

∴ DA = DC

△BCD的周长 = BC + CD + BD = BC + DA + BD = BC + AB = 5 + 8 = 13cm

答：△BCD的周长是13cm。

**练习4：** 如图，点P在线段AB的垂直平分线上。已知PA = 13cm，AB = 10cm。求点P到AB的距离。

解：

设AB的中点为O，PO⊥AB。

OA = 5cm

PO = √(13² - 5²) = √(169 - 25) = √144 = 12cm

答：点P到AB的距离是12cm。

**练习5：** 如图，在△ABC中，BC的垂直平分线交AC于点D。已知AB = 9cm，AD = 3cm。求AC。

解：

∵ BC的垂直平分线交AC于点D

∴ DB = DC

AC = AD + DC = AD + DB

在△ABD中，已知AB = 9cm，AD = 3cm。

但DB未知，需要更多条件。

如果题目补充DB = 9cm（即DB = AB），则：

AC = 3 + 9 = 12cm。
