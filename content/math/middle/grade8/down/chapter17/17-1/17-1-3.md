# 17.1.3 勾股定理的实际应用

## 一、梯子靠墙问题

**梯子、地面、墙构成直角三角形**

梯子是斜边。

地面到墙的距离是一条直角边。

墙上的高度是另一条直角边。

**解题步骤**

第一步：画出直角三角形。

第二步：标出已知边长。

第三步：用勾股定理求未知边。

## 二、旗杆折断问题

**旗杆折断后构成直角三角形**

折断点到地面的距离是一条直角边。

折断点到旗杆底部的距离是另一条直角边。

折断部分是斜边。

**解题步骤**

第一步：设旗杆原高为x。

第二步：根据题意列出方程。

第三步：用勾股定理解方程。

## 三、最短路径问题（立体图形表面展开）

**把立体图形展开成平面**

在平面上，两点之间线段最短。

展开后连接两点。

用勾股定理求线段长。

**常见展开方式**

圆柱侧面展开是长方形。

长方体表面展开有多种方式。

选择使路径最短的展开方式。

## 四、航海问题（方位角）

**方位角：从正北方向顺时针转到目标方向的角度**

北偏东30°：从正北向东偏30°。

南偏西45°：从正南向西偏45°。

**解题步骤**

第一步：画出方位图。

第二步：构造直角三角形。

第三步：用勾股定理求距离。

## 五、例题讲解

**例题1：** 一架梯子长10米，斜靠在墙上，梯子底部离墙6米，求梯子顶端离地面多高。

解：

梯子是斜边c = 10。

地面到墙的距离a = 6。

设墙上的高度为b。

由勾股定理：a² + b² = c²

6² + b² = 10²

36 + b² = 100

b² = 64

b = 8

答：梯子顶端离地面8米。

**例题2：** 一根旗杆高16米，在某处折断，旗杆顶部落在离底部8米处，求折断点离地面多高。

解：

设折断点离地面x米。

折断部分为(16-x)米。

由勾股定理：x² + 8² = (16-x)²

x² + 64 = 256 - 32x + x²

64 = 256 - 32x

32x = 192

x = 6

答：折断点离地面6米。

**例题3：** 一个圆柱底面周长为12，高为5，一只蚂蚁从底面一点沿侧面爬到顶面相对点，求最短路径。

解：

把圆柱侧面展开成长方形。

长方形的长 = 底面周长 = 12。

长方形的宽 = 高 = 5。

蚂蚁从底面一点到顶面相对点。

展开后，水平距离 = 12/2 = 6。

垂直距离 = 5。

最短路径 = √(6² + 5²) = √(36 + 25) = √61

答：最短路径为√61。

**例题4：** 一艘船从港口出发，先向北航行30千米，再向东航行40千米，求船离港口的距离。

解：

画出方位图。

向北30千米，向东40千米。

构成直角三角形。

两直角边分别为30和40。

由勾股定理：30² + 40² = c²

900 + 1600 = c²

c² = 2500

c = 50

答：船离港口50千米。

**例题5：** 一个长方体长6、宽4、高3，一只蚂蚁从一个顶点沿表面爬到对角顶点，求最短路径。

解：

有三种展开方式：

方式一：(6+4)和3，路径 = √(10² + 3²) = √109

方式二：(6+3)和4，路径 = √(9² + 4²) = √97

方式三：(4+3)和6，路径 = √(7² + 6²) = √85

最短路径 = √85

答：最短路径为√85。

## 六、常见错误

**错误1：梯子问题中斜边搞错**

错误做法：把梯子当成直角边。

正确理解：梯子是斜边。

**错误2：旗杆问题中方程列错**

错误做法：x² + 8² = 16²。

正确理解：x² + 8² = (16-x)²。

**错误3：展开方式选错**

错误做法：只考虑一种展开方式。

正确理解：要考虑所有可能的展开方式，选最短的。

**错误4：方位角理解错误**

错误做法：北偏东30°当成从正东向北偏30°。

正确理解：从正北向东偏30°。

**错误5：圆柱展开后水平距离算错**

错误做法：水平距离 = 底面周长。

正确理解：到相对点，水平距离 = 底面周长的一半。

## 七、练习题

**练习1：** 一架梯子长13米，斜靠在墙上，梯子顶端离地面12米，求梯子底部离墙多远。

解：

梯子是斜边c = 13。

墙上的高度b = 12。

设地面到墙的距离为a。

由勾股定理：a² + b² = c²

a² + 12² = 13²

a² + 144 = 169

a² = 25

a = 5

答：梯子底部离墙5米。

**练习2：** 一根旗杆高20米，在某处折断，旗杆顶部落在离底部10米处，求折断点离地面多高。

解：

设折断点离地面x米。

折断部分为(20-x)米。

由勾股定理：x² + 10² = (20-x)²

x² + 100 = 400 - 40x + x²

100 = 400 - 40x

40x = 300

x = 7.5

答：折断点离地面7.5米。

**练习3：** 一个圆柱底面周长为16，高为6，一只蚂蚁从底面一点沿侧面爬到顶面相对点，求最短路径。

解：

把圆柱侧面展开成长方形。

水平距离 = 16/2 = 8。

垂直距离 = 6。

最短路径 = √(8² + 6²) = √(64 + 36) = √100 = 10

答：最短路径为10。

**练习4：** 一艘船从港口出发，先向南航行24千米，再向西航行7千米，求船离港口的距离。

解：

构成直角三角形。

两直角边分别为24和7。

由勾股定理：24² + 7² = c²

576 + 49 = c²

c² = 625

c = 25

答：船离港口25千米。

**练习5：** 一个长方体长8、宽6、高4，一只蚂蚁从一个顶点沿表面爬到对角顶点，求最短路径。

解：

有三种展开方式：

方式一：(8+6)和4，路径 = √(14² + 4²) = √212

方式二：(8+4)和6，路径 = √(12² + 6²) = √180

方式三：(6+4)和8，路径 = √(10² + 8²) = √164

最短路径 = √164 = 2√41

答：最短路径为2√41。
