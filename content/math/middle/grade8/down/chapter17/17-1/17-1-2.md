# 17.1.2 勾股定理的简单应用

## 一、已知两边求第三边

**已知两条直角边，求斜边**

a² + b² = c²

直接代入计算。

**已知一条直角边和斜边，求另一条直角边**

a² + b² = c²

移项：b² = c² - a²

再开平方。

## 二、已知一边和特殊角求其他边

**30°-60°-90°三角形**

30°角所对的直角边是斜边的一半。

设30°角所对的边为a。

斜边c = 2a。

另一直角边b = a√3。

**45°-45°-90°三角形**

两条直角边相等。

设直角边为a。

斜边c = a√2。

## 三、在数轴上表示无理数

**表示√2**

画一个直角边都为1的等腰直角三角形。

斜边就是√2。

以原点为圆心，斜边长为半径画弧。

弧与数轴的交点就是√2。

**表示√3**

先表示出√2。

以√2为一条直角边，1为另一条直角边。

斜边就是√3。

## 四、注意：先判断哪条边是斜边

**斜边是最长的边**

斜边对着直角。

直角边对着锐角。

**已知三边中的两边时**

先确定哪条是斜边。

斜边的平方等于两直角边的平方和。

## 五、例题讲解

**例题1：** 在Rt△ABC中，∠C=90°，a=7，b=24，求c。

解：

由勾股定理：a² + b² = c²

7² + 24² = c²

49 + 576 = c²

c² = 625

c = 25

答：c = 25。

**例题2：** 在Rt△ABC中，∠C=90°，a=12，c=35，求b。

解：

由勾股定理：a² + b² = c²

12² + b² = 35²

144 + b² = 1225

b² = 1081

b = √1081

答：b = √1081。

**例题3：** 等腰直角三角形的直角边为5，求斜边。

解：

设斜边为c。

由勾股定理：5² + 5² = c²

25 + 25 = c²

c² = 50

c = 5√2

答：斜边为5√2。

**例题4：** 在Rt△ABC中，∠C=90°，∠A=30°，a=4，求b和c。

解：

30°角所对的直角边a = 4。

斜边c = 2a = 8。

由勾股定理：a² + b² = c²

4² + b² = 8²

16 + b² = 64

b² = 48

b = 4√3

答：b = 4√3，c = 8。

**例题5：** 在数轴上画出表示√5的点。

解：

先画一个直角边分别为1和2的直角三角形。

斜边 = √(1² + 2²) = √5。

以原点为圆心，√5为半径画弧。

弧与数轴正半轴的交点就是√5。

答：如上所述。

## 六、常见错误

**错误1：斜边和直角边搞混**

错误做法：已知a=3，c=5，求b时写成3²+b²=5²，b²=16，b=4（这个对了）。

错误做法：已知a=3，b=4，求c时写成a²=c²-b²。

正确理解：a²+b²=c²。

**错误2：特殊三角形边长关系记错**

错误做法：30°角所对的边是斜边的√3倍。

正确理解：30°角所对的边是斜边的一半。

**错误3：数轴上表示无理数时半径搞错**

错误做法：用直角边长作为半径。

正确理解：用斜边长作为半径。

**错误4：结果没有化简**

错误做法：c = √50。

正确理解：c = 5√2。

**错误5：负数也作为边长**

错误做法：c² = 25，c = ±5。

正确理解：边长为正数，c = 5。

## 七、练习题

**练习1：** 在Rt△ABC中，∠C=90°，a=10，b=26，求c。

解：

由勾股定理：a² + b² = c²

10² + 26² = c²

100 + 676 = c²

c² = 776

c = 2√194

答：c = 2√194。

**练习2：** 在Rt△ABC中，∠C=90°，a=15，c=39，求b。

解：

由勾股定理：a² + b² = c²

15² + b² = 39²

225 + b² = 1521

b² = 1296

b = 36

答：b = 36。

**练习3：** 等腰直角三角形的斜边为10，求直角边。

解：

设直角边为a。

由勾股定理：a² + a² = 10²

2a² = 100

a² = 50

a = 5√2

答：直角边为5√2。

**练习4：** 在Rt△ABC中，∠C=90°，∠A=45°，a=6，求b和c。

解：

∠A = 45°，所以∠B = 45°。

a = b = 6。

由勾股定理：a² + b² = c²

6² + 6² = c²

72 = c²

c = 6√2

答：b = 6，c = 6√2。

**练习5：** 在数轴上画出表示√10的点。

解：

画一个直角边分别为1和3的直角三角形。

斜边 = √(1² + 3²) = √10。

以原点为圆心，√10为半径画弧。

弧与数轴正半轴的交点就是√10。

答：如上所述。
