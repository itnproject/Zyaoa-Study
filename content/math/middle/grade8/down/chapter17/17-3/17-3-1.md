# 17.3.1 折叠问题中的勾股定理

## 一、矩形纸片折叠问题

**折叠的性质**

折叠前后图形全等。

对应边相等，对应角相等。

折痕是对称轴。

**解题关键**

第一步：找出折叠前后的对应关系。

第二步：设未知数。

第三步：利用勾股定理建立方程。

第四步：解方程求解。

## 二、三角形纸片折叠问题

**折叠后形成新的直角三角形**

找出折叠后的直角三角形。

利用勾股定理列方程。

**常见类型**

顶点折叠到边上。

顶点折叠到内部某点。

## 三、关键：找出折叠前后的对应关系

**折叠前后长度不变**

折叠前的线段长度等于折叠后的对应线段长度。

**折叠前后角度不变**

折叠前的角度等于折叠后的对应角度。

**设未知数列方程**

设要求的线段长为x。

用x表示其他相关线段。

在直角三角形中用勾股定理列方程。

## 四、利用勾股定理建立方程求解

**找直角三角形**

折叠后通常会出现直角三角形。

**列方程**

用勾股定理：a² + b² = c²。

把各边用x表示。

解一元一次方程或一元二次方程。

## 五、例题讲解

**例题1：** 矩形ABCD中，AB=8，BC=6，将矩形沿对角线AC折叠，点B落在点E处，求DE的长。

解：

折叠后，AE = AB = 8。

CE = CB = 6。

在矩形ABCD中，AC = √(8²+6²) = 10。

在△ADE中，AD = 6，AE = 8。

DE² = AE² - AD² = 64 - 36 = 28。

DE = 2√7。

答：DE = 2√7。

**例题2：** 矩形ABCD中，AB=6，BC=8，将矩形沿EF折叠（E在AB上，F在CD上），使点A与点C重合，求EF的长。

解：

折叠后A与C重合。

EF是AC的垂直平分线。

AC = √(6²+8²) = 10。

设AE = x，则EB = 6-x。

折叠后CE = AE = x。

在Rt△BCE中：(6-x)² + 8² = x²。

36 - 12x + x² + 64 = x²。

100 - 12x = 0。

x = 25/3。

EF = √(6² + (25/3-8)²) = √(36 + 1/9) = √(325/9) = 5√13/3。

答：EF = 5√13/3。

**例题3：** Rt△ABC中，∠C=90°，AC=6，BC=8，将△ABC沿AD折叠，使点C落在AB上的点E处，求CD的长。

解：

折叠后，AE = AC = 6。

DE = CD。

AB = √(6²+8²) = 10。

BE = AB - AE = 10 - 6 = 4。

设CD = x，则BD = 8-x。

在Rt△BDE中：DE² + BE² = BD²。

x² + 4² = (8-x)²。

x² + 16 = 64 - 16x + x²。

16x = 48。

x = 3。

答：CD = 3。

**例题4：** 矩形ABCD中，AB=4，BC=3，将矩形沿AE折叠，使点D落在BC上的点F处，求BF的长。

解：

折叠后，AF = AD = 3。

EF = DE。

设BF = x，则FC = 4-x。

在Rt△ABF中：AB² + BF² = AF²。

4² + x² = 3²。

16 + x² = 9。

x² = -7（不可能）。

说明F不在BC上，需要重新分析。

设D落在BC延长线上的F处。

AF = AD = 3。

在Rt△ABF中：AB² + BF² = AF²。

4² + BF² = 3²。

BF² = 9 - 16 = -7（不可能）。

说明此题条件有误，AB=4>AD=3，D不可能落在BC上。

答：题目条件不合理。

**例题5：** 矩形ABCD中，AB=6，BC=8，将矩形沿AE折叠，使点B落在CD上的点F处，求CE的长。

解：

折叠后，AF = AB = 6。

EF = BE。

设CE = x，则DE = 8-x。

在Rt△ADF中：AD² + DF² = AF²。

8² + DF² = 6²。

64 + DF² = 36。

DF² = -28（不可能）。

说明F不在CD上。

设B落在AD上的F处。

AF = AB = 6。

在Rt△ABF中：BF² = AB² + AF² = 36 + 36 = 72。

BF = 6√2。

答：需要明确F的位置。

## 六、常见错误

**错误1：折叠后对应关系搞错**

错误做法：折叠后对应边不相等。

正确理解：折叠前后对应边相等。

**错误2：直角三角形找错**

错误做法：在非直角三角形中用勾股定理。

正确理解：先确认是直角三角形。

**错误3：方程列错**

错误做法：x² + a² = b²写成x² = a² + b²。

正确理解：移项要变号。

**错误4：设未知数不合理**

错误做法：设的未知数无法表示其他线段。

正确理解：设要求的线段为x。

**错误5：忽略实际情况**

错误做法：算出负数或无意义的结果。

正确理解：边长必须为正数。

## 七、练习题

**练习1：** 矩形ABCD中，AB=6，BC=8，将矩形沿对角线AC折叠，点B落在点E处，求CE的长。

解：

折叠后，AE = AB = 6。

CE = CB = 8。

答：CE = 8。

**练习2：** Rt△ABC中，∠C=90°，AC=8，BC=6，将△ABC沿AD折叠，使点C落在AB上的点E处，求CD的长。

解：

折叠后，AE = AC = 8。

DE = CD。

AB = √(8²+6²) = 10。

BE = AB - AE = 10 - 8 = 2。

设CD = x，则BD = 6-x。

在Rt△BDE中：DE² + BE² = BD²。

x² + 2² = (6-x)²。

x² + 4 = 36 - 12x + x²。

12x = 32。

x = 8/3。

答：CD = 8/3。

**练习3：** 矩形ABCD中，AB=3，BC=4，将矩形沿AE折叠，使点B落在CD上的点F处，求DF的长。

解：

折叠后，AF = AB = 3。

设DF = x，则FC = 4-x。

在Rt△ADF中：AD² + DF² = AF²。

4² + x² = 3²。

16 + x² = 9。

x² = -7（不可能）。

说明F不在CD上。

答：题目条件不合理。

**练习4：** 矩形ABCD中，AB=8，BC=6，将矩形沿AE折叠，使点D落在BC上的点F处，求BF的长。

解：

折叠后，AF = AD = 6。

设BF = x，则FC = 8-x。

在Rt△ABF中：AB² + BF² = AF²。

8² + x² = 6²。

64 + x² = 36。

x² = -28（不可能）。

说明F不在BC上。

答：题目条件不合理。

**练习5：** Rt△ABC中，∠C=90°，AC=3，BC=4，将△ABC沿AD折叠，使点C落在AB上的点E处，求CD的长。

解：

折叠后，AE = AC = 3。

DE = CD。

AB = √(3²+4²) = 5。

BE = AB - AE = 5 - 3 = 2。

设CD = x，则BD = 4-x。

在Rt△BDE中：DE² + BE² = BD²。

x² + 2² = (4-x)²。

x² + 4 = 16 - 8x + x²。

8x = 12。

x = 3/2。

答：CD = 3/2。
