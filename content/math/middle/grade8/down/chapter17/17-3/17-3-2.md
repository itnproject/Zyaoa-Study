# 17.3.2 最短路径问题

## 一、圆柱体表面最短路径

**把圆柱侧面展开成长方形**

圆柱侧面展开后是一个长方形。

长方形的长 = 底面周长 = 2πr。

长方形的宽 = 圆柱的高 = h。

**在展开图上连接两点**

两点之间线段最短。

用勾股定理求线段长。

## 二、长方体表面最短路径

**长方体表面展开有多种方式**

从一个顶点到对角顶点。

有三种展开方式。

选择使路径最短的展开方式。

**三种展开方式**

方式一：(长+宽)和高。

方式二：(长+高)和宽。

方式三：(宽+高)和长。

**比较三种方式的路径长**

取最小值。

## 三、台阶上的最短路径

**把台阶展开成平面**

台阶可以看作折线。

展开后变成直线。

用勾股定理求最短路径。

**台阶展开**

水平台阶总长 = 各台阶宽度之和。

垂直台阶总高 = 各台阶高度之和。

展开后构成直角三角形。

## 四、方法：展开成平面，两点之间线段最短

**核心思想**

把立体图形展开成平面图形。

在平面上，两点之间线段最短。

连接两点，用勾股定理求距离。

**注意**

要考虑所有可能的展开方式。

选择最短的路径。

## 五、例题讲解

**例题1：** 一个圆柱底面半径为3，高为8，一只蚂蚁从底面一点沿侧面爬到顶面相对点，求最短路径（π取3）。

解：

把圆柱侧面展开成长方形。

长方形的长 = 底面周长 = 2πr = 2×3×3 = 18。

水平距离 = 18/2 = 9（到相对点）。

垂直距离 = 高 = 8。

最短路径 = √(9² + 8²) = √(81 + 64) = √145。

答：最短路径为√145。

**例题2：** 一个长方体长4、宽3、高2，一只蚂蚁从一个顶点沿表面爬到对角顶点，求最短路径。

解：

有三种展开方式：

方式一：(4+3)和2，路径 = √(7² + 2²) = √53。

方式二：(4+2)和3，路径 = √(6² + 3²) = √45 = 3√5。

方式三：(3+2)和4，路径 = √(5² + 4²) = √41。

最短路径 = √41。

答：最短路径为√41。

**例题3：** 一个台阶共5级，每级宽30cm，高20cm，一只蚂蚁从最下面一级的前端爬到最上面一级的后端，求最短路径。

解：

水平台阶总长 = 5 × 30 = 150cm。

垂直台阶总高 = 5 × 20 = 100cm。

展开后构成直角三角形。

最短路径 = √(150² + 100²) = √(22500 + 10000) = √32500 = 50√13。

答：最短路径为50√13 cm。

**例题4：** 一个圆柱底面周长为16，高为12，一只蚂蚁从底面一点沿侧面爬到顶面同侧点正上方，求最短路径。

解：

把圆柱侧面展开成长方形。

水平距离 = 0（同侧点）。

垂直距离 = 高 = 12。

最短路径 = 12。

答：最短路径为12。

**例题5：** 一个长方体长6、宽4、高3，一只蚂蚁从底面一个顶点沿表面爬到顶面相对顶点，求最短路径。

解：

有三种展开方式：

方式一：(6+4)和3，路径 = √(10² + 3²) = √109。

方式二：(6+3)和4，路径 = √(9² + 4²) = √97。

方式三：(4+3)和6，路径 = √(7² + 6²) = √85。

最短路径 = √85。

答：最短路径为√85。

## 六、常见错误

**错误1：展开方式选错**

错误做法：只考虑一种展开方式。

正确理解：要考虑所有可能的展开方式。

**错误2：圆柱展开后水平距离算错**

错误做法：水平距离 = 底面周长。

正确理解：到相对点，水平距离 = 底面周长的一半。

**错误3：台阶展开时算错**

错误做法：水平台阶总长 = 每级宽度。

正确理解：水平台阶总长 = 每级宽度 × 级数。

**错误4：长方体展开时边长搞错**

错误做法：(长+宽)和高，路径 = √(长² + 宽² + 高²)。

正确理解：路径 = √((长+宽)² + 高²)。

**错误5：忘记比较所有方式**

错误做法：算出一种方式就认为是答案。

正确理解：要比较所有方式，取最小值。

## 七、练习题

**练习1：** 一个圆柱底面半径为4，高为6，一只蚂蚁从底面一点沿侧面爬到顶面相对点，求最短路径（π取3）。

解：

把圆柱侧面展开成长方形。

长方形的长 = 底面周长 = 2πr = 2×3×4 = 24。

水平距离 = 24/2 = 12。

垂直距离 = 高 = 6。

最短路径 = √(12² + 6²) = √(144 + 36) = √180 = 6√5。

答：最短路径为6√5。

**练习2：** 一个长方体长5、宽4、高3，一只蚂蚁从一个顶点沿表面爬到对角顶点，求最短路径。

解：

有三种展开方式：

方式一：(5+4)和3，路径 = √(9² + 3²) = √90 = 3√10。

方式二：(5+3)和4，路径 = √(8² + 4²) = √80 = 4√5。

方式三：(4+3)和5，路径 = √(7² + 5²) = √74。

最短路径 = √74。

答：最短路径为√74。

**练习3：** 一个台阶共4级，每级宽25cm，高15cm，一只蚂蚁从最下面一级的前端爬到最上面一级的后端，求最短路径。

解：

水平台阶总长 = 4 × 25 = 100cm。

垂直台阶总高 = 4 × 15 = 60cm。

展开后构成直角三角形。

最短路径 = √(100² + 60²) = √(10000 + 3600) = √13600 = 20√34。

答：最短路径为20√34 cm。

**练习4：** 一个长方体长10、宽8、高6，一只蚂蚁从底面一个顶点沿表面爬到顶面相对顶点，求最短路径。

解：

有三种展开方式：

方式一：(10+8)和6，路径 = √(18² + 6²) = √360 = 6√10。

方式二：(10+6)和8，路径 = √(16² + 8²) = √320 = 8√5。

方式三：(8+6)和10，路径 = √(14² + 10²) = √296 = 2√74。

最短路径 = 2√74。

答：最短路径为2√74。

**练习5：** 一个圆柱底面周长为20，高为15，一只蚂蚁从底面一点沿侧面爬到顶面相对点，求最短路径。

解：

把圆柱侧面展开成长方形。

水平距离 = 20/2 = 10。

垂直距离 = 高 = 15。

最短路径 = √(10² + 15²) = √(100 + 225) = √325 = 5√13。

答：最短路径为5√13。
