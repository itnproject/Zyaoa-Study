# 17.2.3 逆定理的应用——判定直角三角形

## 一、已知三边判断三角形形状

**步骤**

第一步：找出最长边c。

第二步：计算a²+b²和c²。

第三步：比较大小。

a²+b²=c²：直角三角形。

a²+b²>c²：锐角三角形。

a²+b²<c²：钝角三角形。

## 二、已知三边判断最大角

**最大角对着最长边**

a²+b²=c²：最大角是直角（90°）。

a²+b²>c²：最大角是锐角（<90°）。

a²+b²<c²：最大角是钝角（>90°）。

**记忆方法**

等于号对应直角。

大于号对应锐角（角小，对边平方和小）。

小于号对应钝角（角大，对边平方和大）。

## 三、在四边形中构造直角三角形

**连接对角线**

把四边形分成两个三角形。

判断是否有直角三角形。

**作垂线**

从顶点向对边作垂线。

构造直角三角形。

用勾股定理和逆定理求解。

## 四、例题讲解

**例题1：** 已知三角形三边为6、8、10，判断三角形形状。

解：

最长边为10。

6² + 8² = 36 + 64 = 100

10² = 100

6² + 8² = 10²

是直角三角形。

答：直角三角形。

**例题2：** 已知三角形三边为4、5、6，判断最大角是锐角、直角还是钝角。

解：

最长边为6。

4² + 5² = 16 + 25 = 41

6² = 36

4² + 5² > 6²

最大角是锐角。

答：锐角。

**例题3：** 已知三角形三边为3、4、7，判断最大角是锐角、直角还是钝角。

解：

最长边为7。

3² + 4² = 9 + 16 = 25

7² = 49

3² + 4² < 7²

最大角是钝角。

答：钝角。

**例题4：** 四边形ABCD中，AB=3，BC=4，CD=12，DA=13，∠B=90°，求四边形面积。

解：

连接AC。

在Rt△ABC中：AC² = 3² + 4² = 25，AC = 5。

在△ACD中：AC=5，CD=12，DA=13。

5² + 12² = 25 + 144 = 169 = 13²。

△ACD是直角三角形，∠ACD=90°。

S_ABCD = S_ABC + S_ACD = (1/2)×3×4 + (1/2)×5×12 = 6 + 30 = 36。

答：36。

**例题5：** 四边形ABCD中，AB=5，BC=12，CD=13，DA=10，∠B=90°，求AC的长。

解：

连接AC。

在Rt△ABC中：AC² = 5² + 12² = 25 + 144 = 169。

AC = 13。

答：AC = 13。

## 五、常见错误

**错误1：判断形状时比较搞反**

错误做法：a²+b²>c²当成钝角三角形。

正确理解：a²+b²>c²是锐角三角形。

**错误2：最长边找错**

错误做法：三边为3、5、4，把5当成直角边。

正确理解：5是最长边，是斜边。

**错误3：四边形中不会构造**

错误做法：直接求四边形面积。

正确理解：连接对角线，分成两个三角形。

**错误4：三角形不存在也判断**

错误做法：三边为1、2、4，判断形状。

正确理解：1+2<4，不能构成三角形。

**错误5：计算错误**

错误做法：5²+12²=25+144=159。

正确理解：5²+12²=25+144=169=13²。

## 六、练习题

**练习1：** 已知三角形三边为5、12、13，判断三角形形状。

解：

最长边为13。

5² + 12² = 25 + 144 = 169

13² = 169

5² + 12² = 13²

是直角三角形。

答：直角三角形。

**练习2：** 已知三角形三边为7、8、9，判断最大角是锐角、直角还是钝角。

解：

最长边为9。

7² + 8² = 49 + 64 = 113

9² = 81

7² + 8² > 9²

最大角是锐角。

答：锐角。

**练习3：** 已知三角形三边为5、6、9，判断最大角是锐角、直角还是钝角。

解：

最长边为9。

5² + 6² = 25 + 36 = 61

9² = 81

5² + 6² < 9²

最大角是钝角。

答：钝角。

**练习4：** 四边形ABCD中，AB=6，BC=8，CD=15，DA=17，∠B=90°，求四边形面积。

解：

连接AC。

在Rt△ABC中：AC² = 6² + 8² = 36 + 64 = 100，AC = 10。

在△ACD中：AC=10，CD=15，DA=17。

10² + 15² = 100 + 225 = 325

17² = 289

10² + 15² ≠ 17²

△ACD不是直角三角形。

用海伦公式或其他方法求△ACD面积。

半周长s = (10+15+17)/2 = 21

S_ACD = √(21×11×6×4) = √5544 = 6√154

S_ABCD = (1/2)×6×8 + 6√154 = 24 + 6√154

答：24 + 6√154。

**练习5：** 四边形ABCD中，AB=8，BC=15，CD=20，DA=25，∠B=90°，求AC的长。

解：

连接AC。

在Rt△ABC中：AC² = 8² + 15² = 64 + 225 = 289。

AC = 17。

答：AC = 17。
