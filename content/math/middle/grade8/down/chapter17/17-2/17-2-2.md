# 17.2.2 勾股数

## 一、勾股数的定义

**满足a²+b²=c²的三个正整数**

a、b、c都是正整数。

a² + b² = c²。

这三个数叫勾股数。

**例子**

3、4、5是勾股数。

3² + 4² = 9 + 16 = 25 = 5²。

## 二、常见勾股数

**3-4-5**

3² + 4² = 5²

**5-12-13**

5² + 12² = 25 + 144 = 169 = 13²

**8-15-17**

8² + 15² = 64 + 225 = 289 = 17²

**7-24-25**

7² + 24² = 49 + 576 = 625 = 25²

**9-40-41**

9² + 40² = 81 + 1600 = 1681 = 41²

## 三、勾股数的规律

**奇数规律**

设n为奇数（n≥3）。

a = n。

b = (n²-1)/2。

c = (n²+1)/2。

**例子**

n = 3：a = 3，b = (9-1)/2 = 4，c = (9+1)/2 = 5。

n = 5：a = 5，b = (25-1)/2 = 12，c = (25+1)/2 = 13。

n = 7：a = 7，b = (49-1)/2 = 24，c = (49+1)/2 = 25。

**偶数规律**

设n为偶数（n≥4）。

a = n。

b = (n/2)² - 1。

c = (n/2)² + 1。

**例子**

n = 4：a = 4，b = 4-1 = 3，c = 4+1 = 5。

n = 6：a = 6，b = 9-1 = 8，c = 9+1 = 10。

n = 8：a = 8，b = 16-1 = 15，c = 16+1 = 17。

## 四、勾股数的倍数仍是勾股数

**如果a、b、c是勾股数**

那么ka、kb、kc也是勾股数（k为正整数）。

**例子**

3、4、5是勾股数。

6、8、10也是勾股数（k=2）。

9、12、15也是勾股数（k=3）。

**注意**

有些勾股数不是基本勾股数的倍数。

如8、15、17是基本勾股数。

## 五、例题讲解

**例题1：** 判断：6、8、10是不是勾股数？

解：

6² + 8² = 36 + 64 = 100

10² = 100

6² + 8² = 10²

都是正整数。

是勾股数。

答：是。

**例题2：** 判断：9、12、15是不是勾股数？

解：

9² + 12² = 81 + 144 = 225

15² = 225

9² + 12² = 15²

都是正整数。

是勾股数。

答：是。

**例题3：** 已知一组勾股数中两个数为12和16，求第三个数。

解：

12² + 16² = 144 + 256 = 400

√400 = 20

第三个数为20。

答：20。

**例题4：** 已知一组勾股数中两个数为5和13，求第三个数。

解：

13是斜边（最大）。

5² + b² = 13²

25 + b² = 169

b² = 144

b = 12

第三个数为12。

答：12。

**例题5：** 已知一组勾股数中两个数为9和41，求第三个数。

解：

41是斜边（最大）。

9² + b² = 41²

81 + b² = 1681

b² = 1600

b = 40

第三个数为40。

答：40。

## 六、常见错误

**错误1：忘记都是正整数**

错误做法：3、4、5是勾股数，3/2、4/2、5/2也是勾股数。

正确理解：勾股数必须是正整数。

**错误2：倍数关系搞错**

错误做法：3、4、5的2倍是5、6、7。

正确理解：3、4、5的2倍是6、8、10。

**错误3：哪个是斜边搞错**

错误做法：已知5和12，第三个数是√(5²+12²)=13（这个对了）。

错误做法：已知5和13，第三个数是√(5²+13²)。

正确理解：13是斜边，应该是13²-5²=144，第三个数是12。

**错误4：规律记错**

错误做法：n=3时，b=(3²+1)/2=5。

正确理解：b=(n²-1)/2=4。

**错误5：计算错误**

错误做法：8²+15²=64+225=279。

正确理解：8²+15²=64+225=289=17²。

## 七、练习题

**练习1：** 判断：10、24、26是不是勾股数？

解：

10² + 24² = 100 + 576 = 676

26² = 676

10² + 24² = 26²

都是正整数。

是勾股数。

答：是。

**练习2：** 已知一组勾股数中两个数为15和17，求第三个数。

解：

17是斜边（最大）。

15² + b² = 17²

225 + b² = 289

b² = 64

b = 8

第三个数为8。

答：8。

**练习3：** 已知一组勾股数中两个数为20和21，求第三个数。

解：

20² + 21² = 400 + 441 = 841

√841 = 29

第三个数为29。

答：29。

**练习4：** 判断：12、35、37是不是勾股数？

解：

12² + 35² = 144 + 1225 = 1369

37² = 1369

12² + 35² = 37²

都是正整数。

是勾股数。

答：是。

**练习5：** 已知一组勾股数中两个数为11和61，求第三个数。

解：

61是斜边（最大）。

11² + b² = 61²

121 + b² = 3721

b² = 3600

b = 60

第三个数为60。

答：60。
