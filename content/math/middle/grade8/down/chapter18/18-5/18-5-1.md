# 18.5.1 正方形的性质

## 一、从生活实例引入

**魔方面**

魔方的每个面都是正方形。

四条边相等。

四个角都是直角。

**围棋棋盘**

围棋棋盘的格子是正方形。

正方形规整美观。

**地砖**

很多地砖是正方形的。

正方形便于铺设。

## 二、正方形的定义

**有一组邻边相等且有一个角是直角的平行四边形叫正方形**

正方形是最特殊的平行四边形。

既是矩形又是菱形。

## 三、正方形既是矩形又是菱形

**正方形具备矩形的所有性质**

四个角都是直角。

对角线相等。

**正方形具备菱形的所有性质**

四条边都相等。

对角线互相垂直。

对角线平分一组对角。

## 四、性质：具备矩形和菱形的所有性质

**边的性质**

四条边都相等。

对边平行。

**角的性质**

四个角都是直角。

**对角线的性质**

对角线相等。

对角线互相垂直。

对角线互相平分。

对角线平分一组对角。

## 五、正方形是轴对称图形

**正方形有4条对称轴**

两条对角线所在的直线。

过对边中点的两条直线。

## 六、正方形的对角线相等、垂直、互相平分

**正方形ABCD中**

AC = BD（相等）。

AC⊥BD（垂直）。

OA = OC，OB = OD（互相平分）。

## 七、例题讲解

**例题1：** 正方形ABCD中，AB = 5，求正方形的周长和面积。

解：

周长 = 4 × 5 = 20。

面积 = 5² = 25。

答：周长为20，面积为25。

**例题2：** 正方形ABCD中，AB = 6，求对角线AC的长。

解：

在Rt△ABC中，∠B = 90°。

AC² = AB² + BC² = 36 + 36 = 72。

AC = 6√2。

答：AC = 6√2。

**例题3：** 正方形ABCD中，对角线AC = 10，求正方形的面积。

解：

面积 = (1/2) × AC² = (1/2) × 100 = 50。

答：面积为50。

**例题4：** 正方形ABCD中，对角线AC和BD相交于点O，AB = 4，求△AOB的面积。

解：

正方形被对角线分成四个面积相等的小三角形。

正方形面积 = 16。

△AOB的面积 = 16/4 = 4。

答：面积为4。

**例题5：** 正方形ABCD中，对角线AC和BD相交于点O，AC = 8，求正方形的边长。

解：

AC² = 2AB²。

64 = 2AB²。

AB² = 32。

AB = 4√2。

答：边长为4√2。

## 八、常见错误

**错误1：正方形只有两条对称轴**

错误做法：正方形有两条对称轴。

正确理解：正方形有四条对称轴。

**错误2：正方形对角线不平分对角**

错误做法：正方形对角线不平分对角。

正确理解：正方形对角线平分一组对角。

**错误3：正方形面积公式用错**

错误做法：面积 = 对角线乘积。

正确理解：面积 = 边长² = (1/2) × 对角线²。

**错误4：正方形和菱形搞混**

错误做法：正方形就是菱形。

正确理解：正方形是特殊的菱形。

**错误5：正方形和矩形搞混**

错误做法：正方形就是矩形。

正确理解：正方形是特殊的矩形。

## 九、练习题

**练习1：** 正方形ABCD中，AB = 7，求正方形的周长和面积。

解：

周长 = 4 × 7 = 28。

面积 = 7² = 49。

答：周长为28，面积为49。

**练习2：** 正方形ABCD中，AB = 8，求对角线AC的长。

解：

AC² = 64 + 64 = 128。

AC = 8√2。

答：AC = 8√2。

**练习3：** 正方形ABCD中，对角线AC = 12，求正方形的面积。

解：

面积 = (1/2) × 144 = 72。

答：面积为72。

**练习4：** 正方形ABCD中，对角线AC和BD相交于点O，AB = 3，求△AOB的面积。

解：

正方形面积 = 9。

△AOB的面积 = 9/4。

答：面积为9/4。

**练习5：** 正方形ABCD中，对角线AC和BD相交于点O，AC = 6，求正方形的边长。

解：

AC² = 2AB²。

36 = 2AB²。

AB² = 18。

AB = 3√2。

答：边长为3√2。
