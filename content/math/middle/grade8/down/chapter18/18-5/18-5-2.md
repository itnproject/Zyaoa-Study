# 18.5.2 正方形的判定

## 一、判定1：有一组邻边相等的矩形是正方形

**矩形ABCD中，AB = AD → 正方形ABCD**

矩形有一个角是直角。

邻边相等。

四条边都相等。

所以是正方形。

## 二、判定2：有一个角是直角的菱形是正方形

**菱形ABCD中，∠A = 90° → 正方形ABCD**

菱形四条边相等。

有一个角是直角。

四个角都是直角。

所以是正方形。

## 三、判定3：对角线相等且垂直的平行四边形是正方形

**□ABCD中，AC = BD，AC⊥BD → 正方形ABCD**

对角线相等 → 矩形。

对角线垂直 → 菱形。

既是矩形又是菱形 → 正方形。

## 四、平行四边形、矩形、菱形、正方形的包含关系

**平行四边形**

最一般的四边形。

两组对边分别平行。

**矩形**

特殊的平行四边形。

有一个角是直角。

**菱形**

特殊的平行四边形。

有一组邻边相等。

**正方形**

最特殊的平行四边形。

既是矩形又是菱形。

**包含关系**

正方形 ⊂ 矩形 ⊂ 平行四边形

正方形 ⊂ 菱形 ⊂ 平行四边形

## 五、例题讲解

**例题1：** 矩形ABCD中，AB = AD，判断矩形ABCD的形状。

解：

有一组邻边相等的矩形是正方形。

答：正方形。

**例题2：** 菱形ABCD中，∠A = 90°，判断菱形ABCD的形状。

解：

有一个角是直角的菱形是正方形。

答：正方形。

**例题3：** 在□ABCD中，AC = BD，AC⊥BD，判断□ABCD的形状。

解：

对角线相等且垂直的平行四边形是正方形。

答：正方形。

**例题4：** 矩形ABCD中，对角线AC⊥BD，判断矩形ABCD的形状。

解：

矩形对角线相等。

又AC⊥BD。

对角线相等且垂直的平行四边形是正方形。

答：正方形。

**例题5：** 菱形ABCD中，对角线AC = BD，判断菱形ABCD的形状。

解：

菱形对角线互相垂直。

又AC = BD。

对角线相等且垂直的平行四边形是正方形。

答：正方形。

## 六、常见错误

**错误1：对角线相等的菱形是正方形**

错误做法：菱形对角线相等 → 正方形（这个对了）。

**错误2：对角线垂直的矩形是正方形**

错误做法：矩形对角线垂直 → 正方形（这个对了）。

**错误3：邻边相等的平行四边形是正方形**

错误做法：AB = AD → 正方形。

正确理解：需要有一个角是直角。

**错误4：有一个角是直角的平行四边形是正方形**

错误做法：∠A = 90° → 正方形。

正确理解：需要邻边相等。

**错误5：判定条件不充分**

错误做法：对角线互相平分 → 正方形。

正确理解：对角线互相平分是平行四边形。

## 七、练习题

**练习1：** 矩形ABCD中，AB = BC，判断矩形ABCD的形状。

解：

有一组邻边相等的矩形是正方形。

答：正方形。

**练习2：** 菱形ABCD中，∠B = 90°，判断菱形ABCD的形状。

解：

有一个角是直角的菱形是正方形。

答：正方形。

**练习3：** 在□ABCD中，AC = BD，AC⊥BD，AB = 5，求□ABCD的面积。

解：

□ABCD是正方形。

面积 = 5² = 25。

答：面积为25。

**练习4：** 矩形ABCD中，对角线AC⊥BD，AB = 3，求矩形ABCD的面积。

解：

矩形ABCD是正方形。

面积 = 3² = 9。

答：面积为9。

**练习5：** 菱形ABCD中，对角线AC = BD，AB = 4，求菱形ABCD的面积。

解：

菱形ABCD是正方形。

面积 = 4² = 16。

答：面积为16。
