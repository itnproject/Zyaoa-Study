# 18.5.3 特殊平行四边形的综合应用

## 一、四边形从一般到特殊的演变关系

**四边形 → 平行四边形 → 矩形/菱形 → 正方形**

一般四边形加两组对边平行 → 平行四边形。

平行四边形加一个直角 → 矩形。

平行四边形加一组邻边相等 → 菱形。

矩形加一组邻边相等 → 正方形。

菱形加一个直角 → 正方形。

## 二、矩形、菱形、正方形的性质对比

**边的性质**

矩形：对边相等。

菱形：四条边相等。

正方形：四条边相等。

**角的性质**

矩形：四个角都是直角。

菱形：对角相等。

正方形：四个角都是直角。

**对角线的性质**

矩形：对角线相等。

菱形：对角线垂直。

正方形：对角线相等且垂直。

## 三、矩形、菱形、正方形的判定对比

**矩形判定**

有一个角是直角的平行四边形。

有三个角是直角的四边形。

对角线相等的平行四边形。

**菱形判定**

有一组邻边相等的平行四边形。

四条边都相等的四边形。

对角线互相垂直的平行四边形。

**正方形判定**

有一组邻边相等的矩形。

有一个角是直角的菱形。

对角线相等且垂直的平行四边形。

## 四、中点四边形问题

**任意四边形的中点四边形是平行四边形**

连接四边形各边中点。

形成的四边形是平行四边形。

**特殊四边形的中点四边形**

矩形的中点四边形是菱形。

菱形的中点四边形是矩形。

正方形的中点四边形是正方形。

## 五、例题讲解

**例题1：** 判断：对角线相等且互相平分的四边形是什么图形？

解：

对角线互相平分 → 平行四边形。

对角线相等 → 矩形。

答：矩形。

**例题2：** 判断：对角线互相垂直且平分的四边形是什么图形？

解：

对角线互相平分 → 平行四边形。

对角线垂直 → 菱形。

答：菱形。

**例题3：** 判断：对角线相等、垂直且互相平分的四边形是什么图形？

解：

对角线互相平分 → 平行四边形。

对角线相等 → 矩形。

对角线垂直 → 菱形。

既是矩形又是菱形 → 正方形。

答：正方形。

**例题4：** 矩形ABCD中，E、F、G、H分别是AB、BC、CD、DA的中点，判断四边形EFGH的形状。

解：

矩形的中点四边形是菱形。

连接AC、BD。

EF = AC/2，FG = BD/2，GH = AC/2，HE = BD/2。

AC = BD。

EF = FG = GH = HE。

四边形EFGH是菱形。

答：菱形。

**例题5：** 菱形ABCD中，E、F、G、H分别是AB、BC、CD、DA的中点，判断四边形EFGH的形状。

解：

菱形的中点四边形是矩形。

连接AC、BD。

EF∥AC，FG∥BD。

AC⊥BD。

EF⊥FG。

四边形EFGH是矩形。

答：矩形。

## 六、常见错误

**错误1：中点四边形判断错误**

错误做法：任意四边形的中点四边形是矩形。

正确理解：任意四边形的中点四边形是平行四边形。

**错误2：性质混淆**

错误做法：菱形对角线相等。

正确理解：菱形对角线垂直。

**错误3：判定条件不充分**

错误做法：对角线相等 → 正方形。

正确理解：需要对角线相等且垂直。

**错误4：演变关系搞错**

错误做法：矩形加对角线垂直 → 菱形。

正确理解：矩形加对角线垂直 → 正方形。

**错误5：综合题不会分析**

错误做法：直接猜答案。

正确理解：逐步分析条件。

## 七、练习题

**练习1：** 判断：对角线互相平分且有一个角是直角的四边形是什么图形？

解：

对角线互相平分 → 平行四边形。

有一个角是直角 → 矩形。

答：矩形。

**练习2：** 判断：四条边相等且有一个角是直角的四边形是什么图形？

解：

四条边相等 → 菱形。

有一个角是直角 → 正方形。

答：正方形。

**练习3：** 正方形ABCD中，E、F、G、H分别是AB、BC、CD、DA的中点，判断四边形EFGH的形状。

解：

正方形的中点四边形是正方形。

答：正方形。

**练习4：** 平行四边形ABCD中，AC = BD，AC⊥BD，判断平行四边形ABCD的形状。

解：

AC = BD → 矩形。

AC⊥BD → 菱形。

既是矩形又是菱形 → 正方形。

答：正方形。

**练习5：** 四边形ABCD中，E、F、G、H分别是AB、BC、CD、DA的中点，AC = BD，判断四边形EFGH的形状。

解：

EF = AC/2，FG = BD/2，GH = AC/2，HE = BD/2。

AC = BD。

EF = FG = GH = HE。

四边形EFGH是菱形。

答：菱形。
