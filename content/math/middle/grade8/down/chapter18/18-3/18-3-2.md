# 18.3.2 矩形的判定

## 一、判定1：有一个角是直角的平行四边形是矩形（定义）

**□ABCD中，∠A = 90° → 矩形ABCD**

这是矩形的定义。

也是最基本的判定方法。

## 二、判定2：有三个角是直角的四边形是矩形

**四边形ABCD中，∠A = ∠B = ∠C = 90° → 矩形ABCD**

**证明**

∵ ∠A + ∠B + ∠C + ∠D = 360°。

∠A = ∠B = ∠C = 90°。

∴ ∠D = 90°。

四个角都是直角。

∴ AB∥CD，AD∥BC。

∴ 四边形ABCD是平行四边形。

又∵ 有一个角是直角。

∴ 四边形ABCD是矩形。

## 三、判定3：对角线相等的平行四边形是矩形

**□ABCD中，AC = BD → 矩形ABCD**

**证明**

在△ABC和△DCB中：

AB = DC（平行四边形对边相等）。

AC = DB（已知）。

BC = CB（公共边）。

∴ △ABC ≌ △DCB（SSS）。

∴ ∠ABC = ∠DCB。

又∵ AB∥CD。

∴ ∠ABC + ∠DCB = 180°。

∴ ∠ABC = ∠DCB = 90°。

∴ 矩形ABCD。

## 四、各种判定方法的选择

**已知是平行四边形**

用判定1：有一个角是直角。

用判定3：对角线相等。

**不知道是不是平行四边形**

用判定2：有三个角是直角。

## 五、例题讲解

**例题1：** 在□ABCD中，∠A = 90°，判断□ABCD的形状。

解：

有一个角是直角的平行四边形是矩形。

答：矩形。

**例题2：** 在四边形ABCD中，∠A = ∠B = ∠C = 90°，判断四边形ABCD的形状。

解：

有三个角是直角的四边形是矩形。

答：矩形。

**例题3：** 在□ABCD中，AC = BD，判断□ABCD的形状。

解：

对角线相等的平行四边形是矩形。

答：矩形。

**例题4：** 在四边形ABCD中，∠A = 90°，∠B = 90°，∠C = 90°，AB = 5，BC = 8，求四边形ABCD的面积。

解：

四边形ABCD是矩形。

面积 = AB × BC = 5 × 8 = 40。

答：面积为40。

**例题5：** 在□ABCD中，对角线AC和BD相交于点O，△AOB是等边三角形，判断□ABCD的形状。

解：

△AOB是等边三角形。

OA = OB = AB。

AC = 2OA，BD = 2OB。

AC = BD。

对角线相等的平行四边形是矩形。

答：矩形。

## 六、常见错误

**错误1：有一个角是直角的四边形是矩形**

错误做法：∠A = 90° → 矩形。

正确理解：需要是平行四边形。

**错误2：对角线相等的四边形是矩形**

错误做法：AC = BD → 矩形。

正确理解：需要是平行四边形。

**错误3：两个角是直角就是矩形**

错误做法：∠A = ∠B = 90° → 矩形。

正确理解：需要三个角是直角。

**错误4：判定条件不充分**

错误做法：对角线互相平分 → 矩形。

正确理解：对角线互相平分是平行四边形。

**错误5：矩形和正方形搞混**

错误做法：对角线相等且垂直 → 矩形。

正确理解：对角线相等且垂直 → 正方形。
