# 18.3.1 矩形的性质

## 一、从生活实例引入

**书本封面**

书本的封面是矩形。

四个角都是直角。

对边相等且平行。

**电脑屏幕**

电脑屏幕是矩形。

长方形的设计便于观看。

**门窗**

门窗大多是矩形。

矩形结构稳定。

## 二、矩形的定义

**有一个角是直角的平行四边形叫矩形**

矩形是特殊的平行四边形。

具备平行四边形的所有性质。

还有自己的特殊性质。

## 三、矩形是特殊的平行四边形

**矩形具备平行四边形的所有性质**

对边平行且相等。

对角相等。

对角线互相平分。

**矩形还有特殊性质**

四个角都是直角。

对角线相等。

## 四、性质1：矩形的四个角都是直角

**矩形ABCD中，∠A = ∠B = ∠C = ∠D = 90°**

**证明**

∵ 矩形是平行四边形。

∴ 对角相等。

∵ 有一个角是直角。

∴ 四个角都是直角。

## 五、性质2：矩形的对角线相等

**矩形ABCD中，AC = BD**

**证明**

在△ABC和△DCB中：

AB = DC（平行四边形对边相等）。

∠ABC = ∠DCB = 90°。

BC = CB（公共边）。

∴ △ABC ≌ △DCB（SAS）。

∴ AC = BD。

## 六、性质3：矩形是轴对称图形

**矩形有两条对称轴**

过对边中点的直线是对称轴。

两条对称轴互相垂直。

## 七、例题讲解

**例题1：** 矩形ABCD中，AB = 6，BC = 8，求对角线AC的长。

解：

在Rt△ABC中，∠B = 90°。

AC² = AB² + BC² = 36 + 64 = 100。

AC = 10。

答：AC = 10。

**例题2：** 矩形ABCD中，对角线AC = 10，AB = 6，求BC的长。

解：

在Rt△ABC中，∠B = 90°。

BC² = AC² - AB² = 100 - 36 = 64。

BC = 8。

答：BC = 8。

**例题3：** 矩形ABCD中，对角线AC和BD相交于点O，∠AOB = 60°，AB = 4，求AC的长。

解：

∵ 矩形对角线相等且互相平分。

∴ OA = OB = AC/2。

∵ ∠AOB = 60°。

∴ △AOB是等边三角形。

OA = AB = 4。

AC = 2OA = 8。

答：AC = 8。

**例题4：** 矩形ABCD中，AB = 5，BC = 12，求矩形的面积和周长。

解：

面积 = AB × BC = 5 × 12 = 60。

周长 = 2(AB + BC) = 2(5 + 12) = 34。

答：面积为60，周长为34。

**例题5：** 矩形ABCD中，对角线AC和BD相交于点O，AC = 10，△AOB的周长为16，求AB的长。

解：

OA = OB = AC/2 = 5。

△AOB的周长 = OA + OB + AB = 16。

5 + 5 + AB = 16。

AB = 6。

答：AB = 6。

## 八、常见错误

**错误1：矩形对角线垂直**

错误做法：矩形对角线互相垂直。

正确理解：矩形对角线相等，不一定垂直。

**错误2：矩形对角线平分对角**

错误做法：矩形对角线平分对角。

正确理解：矩形对角线不平分对角。

**错误3：矩形是轴对称图形只有一条对称轴**

错误做法：矩形只有一条对称轴。

正确理解：矩形有两条对称轴。

**错误4：四个角是直角的四边形是矩形**

错误做法：四个角是直角就是矩形（这个对了）。

错误做法：三个角是直角不是矩形。

正确理解：三个角是直角的四边形是矩形。

**错误5：矩形面积公式用错**

错误做法：面积 = 对角线乘积。

正确理解：面积 = 长 × 宽。

## 九、练习题

**练习1：** 矩形ABCD中，AB = 3，BC = 4，求对角线AC的长。

解：

AC² = 3² + 4² = 9 + 16 = 25。

AC = 5。

答：AC = 5。

**练习2：** 矩形ABCD中，对角线AC = 13，AB = 5，求BC的长。

解：

BC² = 13² - 5² = 169 - 25 = 144。

BC = 12。

答：BC = 12。

**练习3：** 矩形ABCD中，对角线AC和BD相交于点O，∠AOB = 90°，AB = 5，求AC的长。

解：

∠AOB = 90°，OA = OB。

△AOB是等腰直角三角形。

OA = AB/√2 = 5/√2 = 5√2/2。

AC = 2OA = 5√2。

答：AC = 5√2。

**练习4：** 矩形ABCD中，AB = 7，BC = 24，求矩形的面积和周长。

解：

面积 = 7 × 24 = 168。

周长 = 2(7 + 24) = 62。

答：面积为168，周长为62。

**练习5：** 矩形ABCD中，对角线AC和BD相交于点O，AC = 12，△AOB的周长为18，求AB的长。

解：

OA = OB = 6。

6 + 6 + AB = 18。

AB = 6。

答：AB = 6。
