# 18.1.3 平行四边形的对角线性质

## 一、性质：平行四边形的对角线互相平分

**□ABCD中，对角线AC和BD相交于点O**

OA = OC，OB = OD。

对角线互相平分。

这是平行四边形的重要性质。

## 二、用三角形全等证明

**证明**

∵ 四边形ABCD是平行四边形。

∴ AB∥CD，AB = CD。

∴ ∠BAO = ∠DCO（内错角相等）。

∴ ∠ABO = ∠CDO（内错角相等）。

在△ABO和△CDO中：

∠BAO = ∠DCO。

AB = CD。

∠ABO = ∠CDO。

∴ △ABO ≌ △CDO（ASA）。

∴ OA = OC，OB = OD。

## 三、几何书写格式

```
∵ □ABCD
∴ OA = OC，OB = OD
（平行四边形的对角线互相平分）
```

## 四、平行四边形被对角线分成四个面积相等的小三角形

**对角线把平行四边形分成四个小三角形**

△AOB、△BOC、△COD、△DOA。

这四个小三角形面积相等。

**原因**

OA = OC，OB = OD。

等底等高的三角形面积相等。

## 五、例题讲解

**例题1：** 在□ABCD中，对角线AC和BD相交于点O，AC = 10，BD = 8，求OA和OB的长。

解：

∵ □ABCD是平行四边形。

∴ OA = OC = AC/2 = 5。

OB = OD = BD/2 = 4。

答：OA = 5，OB = 4。

**例题2：** 在□ABCD中，对角线AC和BD相交于点O，OA = 6，OB = 7，求AC和BD的长。

解：

∵ □ABCD是平行四边形。

∴ AC = 2OA = 12。

BD = 2OB = 14。

答：AC = 12，BD = 14。

**例题3：** 在□ABCD中，对角线AC和BD相交于点O，△AOB的周长为15，AB = 5，AC = 8，求BD的长。

解：

△AOB的周长 = OA + OB + AB = 15。

OA = AC/2 = 4。

4 + OB + 5 = 15。

OB = 6。

BD = 2OB = 12。

答：BD = 12。

**例题4：** 在□ABCD中，对角线AC和BD相交于点O，AB = 6，BC = 8，AC = 10，求□ABCD的面积。

解：

在△ABC中，AB = 6，BC = 8，AC = 10。

6² + 8² = 36 + 64 = 100 = 10²。

∴ △ABC是直角三角形，∠B = 90°。

□ABCD的面积 = AB × BC = 6 × 8 = 48。

答：面积为48。

**例题5：** 在□ABCD中，对角线AC和BD相交于点O，△AOB的面积为12，求□ABCD的面积。

解：

对角线把平行四边形分成四个面积相等的小三角形。

□ABCD的面积 = 4 × △AOB的面积 = 4 × 12 = 48。

答：面积为48。

## 六、常见错误

**错误1：对角线相等**

错误做法：平行四边形的对角线相等。

正确理解：平行四边形的对角线互相平分，不一定相等。

**错误2：对角线垂直**

错误做法：平行四边形的对角线垂直。

正确理解：平行四边形的对角线不一定垂直。

**错误3：OA = OB**

错误做法：OA = OB。

正确理解：OA = OC，OB = OD。

**错误4：四个小三角形全等**

错误做法：四个小三角形全等。

正确理解：四个小三角形面积相等，不一定全等。

**错误5：对角线平分对角**

错误做法：对角线平分对角。

正确理解：平行四边形的对角线不平分对角。

## 七、练习题

**练习1：** 在□ABCD中，对角线AC和BD相交于点O，AC = 14，BD = 10，求OA和OB的长。

解：

OA = AC/2 = 7。

OB = BD/2 = 5。

答：OA = 7，OB = 5。

**练习2：** 在□ABCD中，对角线AC和BD相交于点O，OA = 5，OB = 8，求AC和BD的长。

解：

AC = 2OA = 10。

BD = 2OB = 16。

答：AC = 10，BD = 16。

**练习3：** 在□ABCD中，对角线AC和BD相交于点O，△AOB的周长为18，AB = 7，BD = 12，求AC的长。

解：

OB = BD/2 = 6。

OA + OB + AB = 18。

OA + 6 + 7 = 18。

OA = 5。

AC = 2OA = 10。

答：AC = 10。

**练习4：** 在□ABCD中，对角线AC和BD相交于点O，△AOB的面积为8，求□ABCD的面积。

解：

□ABCD的面积 = 4 × 8 = 32。

答：面积为32。

**练习5：** 在□ABCD中，对角线AC和BD相交于点O，AB = 5，OA = 4，OB = 3，判断△AOB的形状。

解：

OA² + OB² = 16 + 9 = 25 = 5² = AB²。

∴ △AOB是直角三角形，∠AOB = 90°。

答：直角三角形。
