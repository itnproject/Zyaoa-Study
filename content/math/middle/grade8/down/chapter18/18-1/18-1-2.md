# 18.1.2 平行四边形的边角性质

## 一、性质1：平行四边形的对边相等

**□ABCD中，AB = CD，AD = BC**

平行四边形的对边不仅平行。

而且相等。

这是平行四边形的重要性质。

**证明**

连接AC。

∵ AB∥CD，∴ ∠BAC = ∠DCA（内错角相等）。

∵ AD∥BC，∴ ∠DAC = ∠BCA（内错角相等）。

又∵ AC = AC（公共边）。

∴ △ABC ≌ △CDA（ASA）。

∴ AB = CD，BC = DA。

## 二、性质2：平行四边形的对角相等

**□ABCD中，∠A = ∠C，∠B = ∠D**

平行四边形的对角相等。

**证明**

由上面的证明：△ABC ≌ △CDA。

∴ ∠B = ∠D。

同理可证：∠A = ∠C。

## 三、性质3：平行四边形的邻角互补

**□ABCD中，∠A + ∠B = 180°，∠B + ∠C = 180°**

平行四边形的邻角互补。

**证明**

∵ AD∥BC。

∴ ∠A + ∠B = 180°（同旁内角互补）。

同理：∠B + ∠C = 180°。

## 四、用三角形全等证明这些性质

**证明思路**

连接对角线。

把平行四边形分成两个三角形。

用ASA证明两个三角形全等。

由全等推出对边相等、对角相等。

**几何书写格式**

```
∵ 四边形ABCD是平行四边形
∴ AB = CD，AD = BC（平行四边形对边相等）
∴ ∠A = ∠C，∠B = ∠D（平行四边形对角相等）
∴ ∠A + ∠B = 180°（平行四边形邻角互补）
```

## 五、例题讲解

**例题1：** 在□ABCD中，AB = 6，BC = 8，求□ABCD的周长。

解：

∵ □ABCD是平行四边形。

∴ AB = CD = 6，BC = AD = 8。

周长 = AB + BC + CD + AD = 6 + 8 + 6 + 8 = 28。

答：周长为28。

**例题2：** 在□ABCD中，∠A = 70°，求∠B、∠C、∠D的度数。

解：

∵ □ABCD是平行四边形。

∴ ∠C = ∠A = 70°（对角相等）。

∠A + ∠B = 180°（邻角互补）。

∠B = 180° - 70° = 110°。

∠D = ∠B = 110°（对角相等）。

答：∠B = 110°，∠C = 70°，∠D = 110°。

**例题3：** 在□ABCD中，AB = 5，BC = 7，∠B = 60°，求□ABCD的面积。

解：

过A作AE⊥BC于E。

在Rt△ABE中，∠B = 60°，AB = 5。

AE = AB × sin60° = 5 × √3/2 = 5√3/2。

面积 = BC × AE = 7 × 5√3/2 = 35√3/2。

答：面积为35√3/2。

**例题4：** 在□ABCD中，AB:BC = 2:3，周长为30，求AB和BC的长。

解：

设AB = 2x，BC = 3x。

∵ □ABCD是平行四边形。

∴ CD = AB = 2x，AD = BC = 3x。

周长 = 2x + 3x + 2x + 3x = 10x = 30。

x = 3。

AB = 2x = 6，BC = 3x = 9。

答：AB = 6，BC = 9。

**例题5：** 在□ABCD中，∠A:∠B = 2:3，求各角的度数。

解：

设∠A = 2x，∠B = 3x。

∵ ∠A + ∠B = 180°（邻角互补）。

∴ 2x + 3x = 180°。

5x = 180°。

x = 36°。

∠A = 72°，∠B = 108°。

∠C = ∠A = 72°，∠D = ∠B = 108°。

答：∠A = 72°，∠B = 108°，∠C = 72°，∠D = 108°。

## 六、常见错误

**错误1：对边相等和对边平行搞混**

错误做法：对边平行就是对边相等。

正确理解：对边平行且相等是两个不同的性质。

**错误2：邻角互补记成邻角相等**

错误做法：∠A = ∠B。

正确理解：∠A + ∠B = 180°。

**错误3：周长计算错误**

错误做法：周长 = AB + BC。

正确理解：周长 = 2(AB + BC)。

**错误4：对角相等记成邻角相等**

错误做法：∠A = ∠B。

正确理解：∠A = ∠C，∠B = ∠D。

**错误5：证明时不写依据**

错误做法：∴ AB = CD。

正确理解：∴ AB = CD（平行四边形对边相等）。

## 七、练习题

**练习1：** 在□ABCD中，AB = 4，BC = 9，求□ABCD的周长。

解：

∵ □ABCD是平行四边形。

∴ CD = AB = 4，AD = BC = 9。

周长 = 2(4 + 9) = 26。

答：周长为26。

**练习2：** 在□ABCD中，∠C = 100°，求∠A、∠B、∠D的度数。

解：

∵ □ABCD是平行四边形。

∴ ∠A = ∠C = 100°。

∠A + ∠B = 180°。

∠B = 80°。

∠D = ∠B = 80°。

答：∠A = 100°，∠B = 80°，∠D = 80°。

**练习3：** 在□ABCD中，AB = 3，BC = 5，∠A = 30°，求□ABCD的面积。

解：

过B作BE⊥AD于E。

在Rt△ABE中，∠A = 30°，AB = 3。

BE = AB × sin30° = 3 × 1/2 = 3/2。

面积 = AD × BE = 5 × 3/2 = 15/2。

答：面积为15/2。

**练习4：** 在□ABCD中，AB:BC = 3:4，周长为42，求AB和BC的长。

解：

设AB = 3x，BC = 4x。

周长 = 2(3x + 4x) = 14x = 42。

x = 3。

AB = 9，BC = 12。

答：AB = 9，BC = 12。

**练习5：** 在□ABCD中，∠A:∠B = 1:2，求各角的度数。

解：

设∠A = x，∠B = 2x。

∠A + ∠B = 180°。

x + 2x = 180°。

x = 60°。

∠A = 60°，∠B = 120°。

∠C = 60°，∠D = 120°。

答：∠A = 60°，∠B = 120°，∠C = 60°，∠D = 120°。
