# 18.4.2 菱形的判定

## 一、判定1：有一组邻边相等的平行四边形是菱形（定义）

**□ABCD中，AB = AD → 菱形ABCD**

这是菱形的定义。

也是最基本的判定方法。

## 二、判定2：四条边都相等的四边形是菱形

**四边形ABCD中，AB = BC = CD = DA → 菱形ABCD**

**证明**

∵ AB = CD，AD = BC。

∴ 四边形ABCD是平行四边形。

又∵ AB = AD。

∴ 菱形ABCD。

## 三、判定3：对角线互相垂直的平行四边形是菱形

**□ABCD中，AC⊥BD → 菱形ABCD**

**证明**

∵ □ABCD是平行四边形。

∴ OA = OC，OB = OD。

又∵ AC⊥BD。

在△ABD中，AO⊥BD，OB = OD。

∴ AB = AD（线段垂直平分线上的点到两端点距离相等）。

∴ 菱形ABCD。

## 四、各种判定方法的选择

**已知是平行四边形**

用判定1：有一组邻边相等。

用判定3：对角线互相垂直。

**不知道是不是平行四边形**

用判定2：四条边都相等。

## 五、例题讲解

**例题1：** 在□ABCD中，AB = AD，判断□ABCD的形状。

解：

有一组邻边相等的平行四边形是菱形。

答：菱形。

**例题2：** 在四边形ABCD中，AB = BC = CD = DA = 5，判断四边形ABCD的形状。

解：

四条边都相等的四边形是菱形。

答：菱形。

**例题3：** 在□ABCD中，AC⊥BD，判断□ABCD的形状。

解：

对角线互相垂直的平行四边形是菱形。

答：菱形。

**例题4：** 在四边形ABCD中，AB = 6，BC = 6，CD = 6，DA = 6，AC = 8，求BD的长。

解：

四边形ABCD是菱形。

OA = 4。

在Rt△AOB中，OB² = AB² - OA² = 36 - 16 = 20。

OB = 2√5。

BD = 2OB = 4√5。

答：BD = 4√5。

**例题5：** 在□ABCD中，对角线AC和BD相交于点O，AB = 5，OA = 3，OB = 4，判断□ABCD的形状。

解：

OA² + OB² = 9 + 16 = 25 = 5² = AB²。

∴ △AOB是直角三角形，∠AOB = 90°。

∴ AC⊥BD。

对角线互相垂直的平行四边形是菱形。

答：菱形。

## 六、常见错误

**错误1：对角线互相垂直的四边形是菱形**

错误做法：AC⊥BD → 菱形。

正确理解：需要是平行四边形。

**错误2：邻边相等的四边形是菱形**

错误做法：AB = AD → 菱形。

正确理解：需要是平行四边形。

**错误3：对角线平分对角的四边形是菱形**

错误做法：对角线平分对角 → 菱形。

正确理解：需要是平行四边形。

**错误4：判定条件不充分**

错误做法：对边相等 → 菱形。

正确理解：对边相等是平行四边形。

**错误5：菱形和正方形搞混**

错误做法：对角线相等且垂直 → 菱形。

正确理解：对角线相等且垂直 → 正方形。

## 七、练习题

**练习1：** 在□ABCD中，AB = BC，判断□ABCD的形状。

解：

有一组邻边相等的平行四边形是菱形。

答：菱形。

**练习2：** 在四边形ABCD中，AB = BC = CD = DA = 8，判断四边形ABCD的形状。

解：

四条边都相等的四边形是菱形。

答：菱形。

**练习3：** 在□ABCD中，AC⊥BD，AC = 6，BD = 8，求□ABCD的面积。

解：

□ABCD是菱形。

面积 = (1/2) × 6 × 8 = 24。

答：面积为24。

**练习4：** 在四边形ABCD中，AB = 3，BC = 3，CD = 3，DA = 3，AC = 4，求BD的长。

解：

四边形ABCD是菱形。

OA = 2。

OB² = 9 - 4 = 5。

OB = √5。

BD = 2√5。

答：BD = 2√5。

**练习5：** 在□ABCD中，对角线AC和BD相交于点O，AB = 10，OA = 6，OB = 8，判断□ABCD的形状。

解：

OA² + OB² = 36 + 64 = 100 = 10² = AB²。

∴ AC⊥BD。

对角线互相垂直的平行四边形是菱形。

答：菱形。
