# 18.2.2 平行四边形的判定（角和对角线）

## 一、判定4：两组对角分别相等的四边形是平行四边形

**∠A = ∠C，∠B = ∠D → 四边形ABCD是平行四边形**

**证明**

∵ ∠A + ∠B + ∠C + ∠D = 360°。

∠A = ∠C，∠B = ∠D。

∴ 2∠A + 2∠B = 360°。

∴ ∠A + ∠B = 180°。

∴ AD∥BC（同旁内角互补，两直线平行）。

同理：AB∥CD。

∴ 四边形ABCD是平行四边形。

## 二、判定5：对角线互相平分的四边形是平行四边形

**OA = OC，OB = OD → 四边形ABCD是平行四边形**

**证明**

在△AOB和△COD中：

OA = OC。

∠AOB = ∠COD（对顶角相等）。

OB = OD。

∴ △AOB ≌ △COD（SAS）。

∴ AB = CD，∠OAB = ∠OCD。

∴ AB∥CD。

同理：AD∥BC。

∴ 四边形ABCD是平行四边形。

## 三、五种判定方法的对比总结

**判定1：两组对边分别平行**

条件：AB∥CD，AD∥BC。

**判定2：两组对边分别相等**

条件：AB = CD，AD = BC。

**判定3：一组对边平行且相等**

条件：AB∥CD，AB = CD。

**判定4：两组对角分别相等**

条件：∠A = ∠C，∠B = ∠D。

**判定5：对角线互相平分**

条件：OA = OC，OB = OD。

## 四、选择合适判定方法的技巧

**已知平行关系**

用判定1或判定3。

**已知边长关系**

用判定2或判定3。

**已知角度关系**

用判定4。

**已知对角线关系**

用判定5。

## 五、例题讲解

**例题1：** 在四边形ABCD中，∠A = 80°，∠B = 100°，∠C = 80°，∠D = 100°，判断四边形ABCD的形状。

解：

∠A = ∠C = 80°，∠B = ∠D = 100°。

两组对角分别相等。

根据判定4：是平行四边形。

答：平行四边形。

**例题2：** 在四边形ABCD中，对角线AC和BD相交于点O，OA = 5，OC = 5，OB = 7，OD = 7，判断四边形ABCD的形状。

解：

OA = OC = 5，OB = OD = 7。

对角线互相平分。

根据判定5：是平行四边形。

答：平行四边形。

**例题3：** 在四边形ABCD中，∠A = ∠C，∠B = 120°，∠D = 120°，判断四边形ABCD的形状。

解：

∠B = ∠D = 120°。

∠A + ∠B + ∠C + ∠D = 360°。

2∠A + 240° = 360°。

∠A = 60° = ∠C。

两组对角分别相等。

是平行四边形。

答：平行四边形。

**例题4：** 在四边形ABCD中，对角线AC和BD相交于点O，OA = 3，OC = 4，OB = 5，OD = 5，判断四边形ABCD是平行四边形吗？

解：

OA ≠ OC。

对角线不互相平分。

不是平行四边形。

答：不是。

**例题5：** 在四边形ABCD中，AB∥CD，∠A = ∠C，判断四边形ABCD的形状。

解：

∵ AB∥CD。

∴ ∠A + ∠D = 180°。

∵ ∠A = ∠C。

∴ ∠C + ∠D = 180°。

∴ AD∥BC。

两组对边分别平行。

是平行四边形。

答：平行四边形。

## 六、常见错误

**错误1：一组对角相等就判定**

错误做法：∠A = ∠C → 平行四边形。

正确理解：需要两组对角分别相等。

**错误2：对角线相等就判定**

错误做法：AC = BD → 平行四边形。

正确理解：需要对角线互相平分。

**错误3：对角线垂直就判定**

错误做法：AC⊥BD → 平行四边形。

正确理解：需要对角线互相平分。

**错误4：判定方法选错**

错误做法：已知对角线关系用边的判定。

正确理解：根据已知条件选择合适的判定方法。

**错误5：证明过程不完整**

错误做法：直接得出结论。

正确理解：要写出判定依据。
