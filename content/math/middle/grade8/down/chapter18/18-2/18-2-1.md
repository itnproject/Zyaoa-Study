# 18.2.1 平行四边形的判定（边）

## 一、判定1：两组对边分别平行的四边形是平行四边形（定义）

**AB∥CD，AD∥BC → 四边形ABCD是平行四边形**

这是平行四边形的定义。

也是最基本的判定方法。

## 二、判定2：两组对边分别相等的四边形是平行四边形

**AB = CD，AD = BC → 四边形ABCD是平行四边形**

**证明**

连接AC。

在△ABC和△CDA中：

AB = CD。

BC = DA。

AC = AC（公共边）。

∴ △ABC ≌ △CDA（SSS）。

∴ ∠BAC = ∠DCA。

∴ AB∥CD（内错角相等，两直线平行）。

同理：AD∥BC。

∴ 四边形ABCD是平行四边形。

## 三、判定3：一组对边平行且相等的四边形是平行四边形

**AB∥CD，AB = CD → 四边形ABCD是平行四边形**

**证明**

连接AC。

∵ AB∥CD。

∴ ∠BAC = ∠DCA（内错角相等）。

在△ABC和△CDA中：

AB = CD。

∠BAC = ∠DCA。

AC = AC（公共边）。

∴ △ABC ≌ △CDA（SAS）。

∴ BC = DA。

∴ 四边形ABCD是平行四边形（两组对边分别相等）。

## 四、例题讲解

**例题1：** 在四边形ABCD中，AB∥CD，AD∥BC，判断四边形ABCD的形状。

解：

两组对边分别平行。

根据判定1：是平行四边形。

答：平行四边形。

**例题2：** 在四边形ABCD中，AB = CD = 5，AD = BC = 8，判断四边形ABCD的形状。

解：

两组对边分别相等。

根据判定2：是平行四边形。

答：平行四边形。

**例题3：** 在四边形ABCD中，AB∥CD，AB = CD = 6，判断四边形ABCD的形状。

解：

一组对边平行且相等。

根据判定3：是平行四边形。

答：平行四边形。

**例题4：** 在四边形ABCD中，AB = 4，CD = 4，AD = 7，BC = 7，判断四边形ABCD的形状。

解：

AB = CD = 4，AD = BC = 7。

两组对边分别相等。

根据判定2：是平行四边形。

答：平行四边形。

**例题5：** 在四边形ABCD中，AB∥CD，AD = BC，判断四边形ABCD一定是平行四边形吗？

解：

一组对边平行，另一组对边相等。

不能判定是平行四边形。

可能是等腰梯形。

答：不一定。

## 五、常见错误

**错误1：一组对边平行，另一组对边相等就判定**

错误做法：AB∥CD，AD = BC → 平行四边形。

正确理解：可能是等腰梯形。

**错误2：两组邻边相等就判定**

错误做法：AB = AD，BC = CD → 平行四边形。

正确理解：可能是筝形。

**错误3：判定条件不充分**

错误做法：AB∥CD → 平行四边形。

正确理解：需要两组对边分别平行。

**错误4：证明时逻辑混乱**

错误做法：直接得出结论。

正确理解：要写出判定依据。

**错误5：一组对边平行且相等理解错误**

错误做法：AB∥CD，AD = BC → 平行四边形。

正确理解：AB∥CD，AB = CD → 平行四边形。

## 六、练习题

**练习1：** 在四边形ABCD中，AB∥CD，AD∥BC，AB = 5，求CD的长。

解：

四边形ABCD是平行四边形。

CD = AB = 5。

答：CD = 5。

**练习2：** 在四边形ABCD中，AB = 6，CD = 6，AD = 9，BC = 9，判断四边形ABCD的形状。

解：

两组对边分别相等。

是平行四边形。

答：平行四边形。

**练习3：** 在四边形ABCD中，AB∥CD，AB = 7，CD = 7，判断四边形ABCD的形状。

解：

一组对边平行且相等。

是平行四边形。

答：平行四边形。

**练习4：** 在四边形ABCD中，AB = 3，BC = 5，CD = 3，DA = 5，判断四边形ABCD的形状。

解：

AB = CD = 3，BC = DA = 5。

两组对边分别相等。

是平行四边形。

答：平行四边形。

**练习5：** 在四边形ABCD中，AB∥CD，AB = 8，CD = 8，AD = 6，求BC的长。

解：

四边形ABCD是平行四边形。

BC = AD = 6。

答：BC = 6。
