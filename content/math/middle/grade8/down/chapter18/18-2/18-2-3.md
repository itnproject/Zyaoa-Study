# 18.2.3 三角形的中位线

## 一、中位线的定义

**连接三角形两边中点的线段叫三角形的中位线**

△ABC中，D是AB的中点，E是AC的中点。

DE是△ABC的中位线。

**注意**

中位线连接的是两边的中点。

不是顶点和对边中点。

## 二、中位线定理

**三角形的中位线平行于第三边，且等于第三边的一半**

DE∥BC，DE = BC/2。

这是三角形中位线的重要性质。

## 三、用平行四边形证明中位线定理

**证明**

延长DE到F，使EF = DE。

连接CF。

在△ADE和△CFE中：

AE = CE（E是AC中点）。

∠AED = ∠CEF（对顶角相等）。

DE = FE。

∴ △ADE ≌ △CFE（SAS）。

∴ AD = CF，∠A = ∠ECF。

∴ AB∥CF。

又∵ AD = BD。

∴ BD = CF。

∴ 四边形DBCF是平行四边形（一组对边平行且相等）。

∴ DF∥BC，DF = BC。

∵ DE = DF/2。

∴ DE∥BC，DE = BC/2。

## 四、中位线和中线的区别

**中位线**

连接两边中点的线段。

平行于第三边，等于第三边的一半。

**中线**

连接顶点和对边中点的线段。

不一定平行于任何边。

## 五、例题讲解

**例题1：** 在△ABC中，D、E分别是AB、AC的中点，BC = 10，求DE的长。

解：

DE是△ABC的中位线。

DE = BC/2 = 10/2 = 5。

答：DE = 5。

**例题2：** 在△ABC中，D、E分别是AB、AC的中点，DE = 6，求BC的长。

解：

DE是△ABC的中位线。

BC = 2DE = 2 × 6 = 12。

答：BC = 12。

**例题3：** 在△ABC中，D、E、F分别是AB、BC、CA的中点，AB = 8，BC = 10，CA = 12，求△DEF的周长。

解：

DE = CA/2 = 6。

EF = AB/2 = 4。

FD = BC/2 = 5。

△DEF的周长 = 6 + 4 + 5 = 15。

答：周长为15。

**例题4：** 在△ABC中，D、E分别是AB、AC的中点，∠A = 60°，∠B = 70°，求∠ADE的度数。

解：

DE是中位线。

DE∥BC。

∠ADE = ∠B = 70°（同位角相等）。

答：∠ADE = 70°。

**例题5：** 在△ABC中，D、E分别是AB、AC的中点，F是BC上一点，BF = FC，求证：DE和AF互相平分。

解：

D、E分别是AB、AC的中点。

DE是中位线。

DE∥BC，DE = BC/2。

F是BC中点。

连接DF、EF。

四边形ADFE中，DF∥AE，EF∥AD。

四边形ADFE是平行四边形。

对角线DE和AF互相平分。

答：证明如上。

## 六、常见错误

**错误1：中位线和中线搞混**

错误做法：中线平行于第三边。

正确理解：中位线平行于第三边。

**错误2：中位线等于第三边**

错误做法：DE = BC。

正确理解：DE = BC/2。

**错误3：中位线不平行于第三边**

错误做法：中位线不一定平行。

正确理解：中位线一定平行于第三边。

**错误4：三个中点连线不是中位线**

错误做法：连接三个中点的线段都是中位线。

正确理解：每两条中位线连接的是不同边的中点。

**错误5：中位线定理用错**

错误做法：DE = AB/2。

正确理解：DE = BC/2（DE平行于BC）。

## 七、练习题

**练习1：** 在△ABC中，D、E分别是AB、AC的中点，BC = 14，求DE的长。

解：

DE = BC/2 = 7。

答：DE = 7。

**练习2：** 在△ABC中，D、E分别是AB、AC的中点，DE = 8，求BC的长。

解：

BC = 2DE = 16。

答：BC = 16。

**练习3：** 在△ABC中，D、E、F分别是AB、BC、CA的中点，AB = 6，BC = 8，CA = 10，求△DEF的周长。

解：

DE = CA/2 = 5。

EF = AB/2 = 3。

FD = BC/2 = 4。

周长 = 5 + 3 + 4 = 12。

答：周长为12。

**练习4：** 在△ABC中，D、E分别是AB、AC的中点，∠C = 50°，求∠AED的度数。

解：

DE∥BC。

∠AED = ∠C = 50°（同位角相等）。

答：∠AED = 50°。

**练习5：** 在△ABC中，D、E分别是AB、AC的中点，△ADE的周长为12，求△ABC的周长。

解：

DE = BC/2，AD = AB/2，AE = AC/2。

△ADE的周长 = (AB + BC + CA)/2。

△ABC的周长 = 2 × 12 = 24。

答：周长为24。
