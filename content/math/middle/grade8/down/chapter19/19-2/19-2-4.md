# 19.2.4 待定系数法求一次函数解析式

## 一、待定系数法的定义

**先设解析式，再代入已知条件求未知系数**

一次函数的解析式：y = kx + b。

k和b是待定的系数。

通过已知条件求出k和b。

## 二、步骤：设→代→解→写

**第一步：设**

设一次函数解析式为y = kx + b。

**第二步：代**

把已知点的坐标代入解析式。

**第三步：解**

解方程（组）求k和b。

**第四步：写**

写出一次函数解析式。

## 三、已知两点求一次函数解析式

**两个点可以确定一条直线**

设y = kx + b。

把两个点的坐标代入。

解二元一次方程组求k和b。

**例子**

已知直线经过(1, 3)和(2, 5)。

3 = k + b。

5 = 2k + b。

解得k = 2，b = 1。

y = 2x + 1。

## 四、已知一点和k或b求解析式

**已知一点和k**

设y = kx + b。

把点和k代入求b。

**已知一点和b**

设y = kx + b。

把点和b代入求k。

## 五、例题讲解

**例题1：** 已知一次函数经过点(1, 2)和(3, 8)，求解析式。

解：

设y = kx + b。

2 = k + b。

8 = 3k + b。

两式相减：6 = 2k，k = 3。

b = 2 - 3 = -1。

y = 3x - 1。

答：y = 3x - 1。

**例题2：** 已知一次函数经过点(0, 3)和(2, 7)，求解析式。

解：

设y = kx + b。

b = 3。

7 = 2k + 3。

k = 2。

y = 2x + 3。

答：y = 2x + 3。

**例题3：** 已知一次函数k = 2，且经过点(1, 5)，求解析式。

解：

设y = 2x + b。

5 = 2 × 1 + b。

b = 3。

y = 2x + 3。

答：y = 2x + 3。

**例题4：** 已知一次函数b = -1，且经过点(2, 3)，求解析式。

解：

设y = kx - 1。

3 = 2k - 1。

k = 2。

y = 2x - 1。

答：y = 2x - 1。

**例题5：** 已知一次函数经过点(-1, 1)和(2, 7)，求解析式。

解：

设y = kx + b。

1 = -k + b。

7 = 2k + b。

两式相减：6 = 3k，k = 2。

b = 1 + 2 = 3。

y = 2x + 3。

答：y = 2x + 3。

## 六、常见错误

**错误1：设解析式时忘记k≠0**

错误做法：设y = kx + b，不说明k≠0。

正确理解：k ≠ 0。

**错误2：代入时坐标搞反**

错误做法：点(1, 2)，代入x = 2，y = 1。

正确理解：x = 1，y = 2。

**错误3：解方程组计算错误**

错误做法：2 = k + b，8 = 3k + b，相减得6 = k。

正确理解：相减得6 = 2k，k = 3。

**错误4：已知b = 0还设y = kx + b**

错误做法：已知过原点，还设y = kx + b。

正确理解：直接设y = kx。

**错误5：求出k和b后不写解析式**

错误做法：求出k = 2，b = 3就结束。

正确理解：要写出y = 2x + 3。

## 七、练习题

**练习1：** 已知一次函数经过点(0, 1)和(3, 7)，求解析式。

解：

设y = kx + b。

b = 1。

7 = 3k + 1。

k = 2。

y = 2x + 1。

答：y = 2x + 1。

**练习2：** 已知一次函数经过点(1, 4)和(2, 6)，求解析式。

解：

设y = kx + b。

4 = k + b。

6 = 2k + b。

相减：2 = k。

b = 4 - 2 = 2。

y = 2x + 2。

答：y = 2x + 2。

**练习3：** 已知一次函数k = -1，且经过点(2, 1)，求解析式。

解：

设y = -x + b。

1 = -2 + b。

b = 3。

y = -x + 3。

答：y = -x + 3。

**练习4：** 已知一次函数b = 2，且经过点(-1, 0)，求解析式。

解：

设y = kx + 2。

0 = -k + 2。

k = 2。

y = 2x + 2。

答：y = 2x + 2。

**练习5：** 已知一次函数经过点(-2, 0)和(0, 4)，求解析式。

解：

设y = kx + b。

b = 4。

0 = -2k + 4。

k = 2。

y = 2x + 4。

答：y = 2x + 4。
