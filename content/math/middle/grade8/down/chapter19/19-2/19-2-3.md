# 19.2.3 一次函数的图象

## 一、一次函数的图象是一条直线

**y = kx + b的图象是一条直线**

只需要两个点就能确定一条直线。

最常用的两个点：与x轴和y轴的交点。

## 二、k决定直线的倾斜方向和程度

**k > 0：直线上升**

y随x增大而增大。

从左下到右上。

**k < 0：直线下降**

y随x增大而减小。

从左上到右下。

**|k|越大，直线越陡**

## 三、b决定直线与y轴的交点

**直线与y轴的交点为(0, b)**

b > 0：交点在y轴正半轴。

b < 0：交点在y轴负半轴。

b = 0：经过原点。

## 四、画一次函数图象：两点法

**步骤**

第一步：求与y轴交点，令x = 0，得(0, b)。

第二步：求与x轴交点，令y = 0，得(-b/k, 0)。

第三步：连接两点画直线。

**例子**

y = 2x + 4。

与y轴交点：(0, 4)。

与x轴交点：2x + 4 = 0，x = -2，点(-2, 0)。

连接(0, 4)和(-2, 0)画直线。

## 五、平移规律

**y = kx + b可由y = kx上下平移得到**

b > 0：向上平移b个单位。

b < 0：向下平移|b|个单位。

**例子**

y = 2x + 3由y = 2x向上平移3个单位得到。

y = 2x - 3由y = 2x向下平移3个单位得到。

## 六、例题讲解

**例题1：** 画出y = 2x + 1的图象。

解：

与y轴交点：(0, 1)。

与x轴交点：2x + 1 = 0，x = -1/2，点(-1/2, 0)。

连接两点画直线。

k = 2 > 0，直线上升。

答：如上所述。

**例题2：** 画出y = -x + 2的图象。

解：

与y轴交点：(0, 2)。

与x轴交点：-x + 2 = 0，x = 2，点(2, 0)。

连接两点画直线。

k = -1 < 0，直线下降。

答：如上所述。

**例题3：** 直线y = 3x - 6经过哪些象限？

解：

k = 3 > 0，b = -6 < 0。

经过一、三、四象限。

答：一、三、四象限。

**例题4：** 直线y = -2x + 4由y = -2x怎样平移得到？

解：

b = 4 > 0。

向上平移4个单位。

答：向上平移4个单位。

**例题5：** 已知直线y = kx + 3经过点(1, 5)，求k的值。

解：

5 = k × 1 + 3。

k = 2。

答：k = 2。

## 七、常见错误

**错误1：与x轴交点求错**

错误做法：y = 2x + 4，令y = 0，x = 4。

正确理解：2x + 4 = 0，x = -2。

**错误2：k的符号与增减性搞混**

错误做法：k > 0时y随x增大而减小。

正确理解：k > 0时y随x增大而增大。

**错误3：平移方向搞反**

错误做法：b > 0时向下平移。

正确理解：b > 0时向上平移。

**错误4：象限判断错误**

错误做法：k > 0，b < 0，经过一、二、三象限。

正确理解：经过一、三、四象限。

**错误5：两点法取的点不对**

错误做法：取两个x值，不计算y值。

正确理解：要计算对应的y值。

## 八、练习题

**练习1：** 画出y = 3x - 3的图象。

解：

与y轴交点：(0, -3)。

与x轴交点：3x - 3 = 0，x = 1，点(1, 0)。

连接两点画直线。

答：如上所述。

**练习2：** 画出y = -2x - 4的图象。

解：

与y轴交点：(0, -4)。

与x轴交点：-2x - 4 = 0，x = -2，点(-2, 0)。

连接两点画直线。

答：如上所述。

**练习3：** 直线y = -x + 1经过哪些象限？

解：

k = -1 < 0，b = 1 > 0。

经过一、二、四象限。

答：一、二、四象限。

**练习4：** 直线y = 2x - 5由y = 2x怎样平移得到？

解：

b = -5 < 0。

向下平移5个单位。

答：向下平移5个单位。

**练习5：** 已知直线y = kx - 2经过点(3, 4)，求k的值。

解：

4 = k × 3 - 2。

3k = 6。

k = 2。

答：k = 2。
