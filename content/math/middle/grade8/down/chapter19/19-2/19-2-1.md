# 19.2.1 正比例函数

## 一、从生活实例引入

**匀速运动中路程与时间的关系**

汽车以60km/h的速度匀速行驶。

路程s与时间t的关系：s = 60t。

路程与时间成正比例。

**购买商品的总价与数量的关系**

每支笔2元。

总价y与数量x的关系：y = 2x。

总价与数量成正比例。

## 二、正比例函数的定义

**形如y = kx（k≠0）的函数叫正比例函数**

k叫做比例系数。

k是常数，且k≠0。

x是自变量，y是因变量。

**例子**

y = 2x是正比例函数，k = 2。

y = -3x是正比例函数，k = -3。

y = x/2是正比例函数，k = 1/2。

## 三、正比例函数的图象

**经过原点的一条直线**

当x = 0时，y = 0。

图象一定经过原点(0, 0)。

只需要再找一个点就能画出图象。

## 四、k>0时图象经过一三象限

**k>0时，y随x增大而增大**

图象从左下到右上。

经过第一、三象限。

**例子**

y = 2x，k = 2 > 0。

图象经过一三象限。

y随x增大而增大。

## 五、k<0时图象经过二四象限

**k<0时，y随x增大而减小**

图象从左上到右下。

经过第二、四象限。

**例子**

y = -2x，k = -2 < 0。

图象经过二四象限。

y随x增大而减小。

## 六、|k|越大，直线越陡

**|k|决定直线的倾斜程度**

|k|越大，直线越陡。

|k|越小，直线越平缓。

**例子**

y = 3x比y = x更陡。

y = -3x比y = -x更陡。

## 七、例题讲解

**例题1：** 判断：y = 5x是否是正比例函数？

解：

形如y = kx，k = 5 ≠ 0。

是正比例函数。

答：是。

**例题2：** 判断：y = x + 1是否是正比例函数？

解：

不是y = kx的形式。

不是正比例函数。

答：不是。

**例题3：** 已知y与x成正比例，当x = 2时，y = 6，求正比例函数解析式。

解：

设y = kx。

6 = k × 2。

k = 3。

y = 3x。

答：y = 3x。

**例题4：** 画出y = -2x的图象。

解：

过原点(0, 0)。

再取x = 1，y = -2，点(1, -2)。

连接两点画直线。

k = -2 < 0，图象经过二四象限。

答：如上所述。

**例题5：** 比较y = 2x和y = 5x的图象哪个更陡？

解：

|2| = 2，|5| = 5。

5 > 2。

y = 5x更陡。

答：y = 5x更陡。

## 八、常见错误

**错误1：k = 0也当成正比例函数**

错误做法：y = 0x是正比例函数。

正确理解：k ≠ 0。

**错误2：y = kx + b当成正比例函数**

错误做法：y = 2x + 1是正比例函数。

正确理解：b ≠ 0时不是正比例函数。

**错误3：k的符号搞错**

错误做法：y = -3x经过一三象限。

正确理解：k < 0，经过二四象限。

**错误4：增减性搞反**

错误做法：k > 0时y随x增大而减小。

正确理解：k > 0时y随x增大而增大。

**错误5：求k时计算错误**

错误做法：x = 2，y = 6，k = 2/6 = 1/3。

正确理解：k = y/x = 6/2 = 3。

## 九、练习题

**练习1：** 判断：y = -x/3是否是正比例函数？

解：

形如y = kx，k = -1/3 ≠ 0。

是正比例函数。

答：是。

**练习2：** 已知y与x成正比例，当x = 3时，y = -9，求正比例函数解析式。

解：

设y = kx。

-9 = k × 3。

k = -3。

y = -3x。

答：y = -3x。

**练习3：** 画出y = 3x的图象，并指出经过哪些象限。

解：

过原点(0, 0)。

再取x = 1，y = 3，点(1, 3)。

连接两点画直线。

k = 3 > 0，经过一三象限。

答：经过一三象限。

**练习4：** 比较y = -x和y = -4x的图象哪个更陡？

解：

|-1| = 1，|-4| = 4。

4 > 1。

y = -4x更陡。

答：y = -4x更陡。

**练习5：** 已知正比例函数y = kx的图象经过点(-2, 6)，求k的值。

解：

6 = k × (-2)。

k = -3。

答：k = -3。
