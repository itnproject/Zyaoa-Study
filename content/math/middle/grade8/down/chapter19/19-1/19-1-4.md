# 19.1.4 函数值

## 一、函数值的定义

**当自变量取某一确定值时，对应的因变量的值叫函数值**

y = f(x)。

当x = a时，y = f(a)。

f(a)就是x = a时的函数值。

## 二、求函数值：代入自变量计算

**步骤**

第一步：把自变量的值代入解析式。

第二步：计算得出函数值。

**例子**

y = 2x + 1。

x = 3时，y = 2 × 3 + 1 = 7。

函数值为7。

## 三、已知函数值求自变量：解方程

**步骤**

第一步：把函数值代入解析式。

第二步：解方程求自变量。

**例子**

y = 2x + 1。

y = 7时，7 = 2x + 1。

2x = 6。

x = 3。

## 四、例题讲解

**例题1：** 已知y = 3x - 2，求x = 4时的函数值。

解：

y = 3 × 4 - 2 = 12 - 2 = 10。

答：函数值为10。

**例题2：** 已知y = x² + 1，求x = -3时的函数值。

解：

y = (-3)² + 1 = 9 + 1 = 10。

答：函数值为10。

**例题3：** 已知y = 2x + 5，当函数值为11时，求x的值。

解：

11 = 2x + 5。

2x = 6。

x = 3。

答：x = 3。

**例题4：** 已知y = x² - 4x + 3，当函数值为0时，求x的值。

解：

0 = x² - 4x + 3。

(x - 1)(x - 3) = 0。

x = 1或x = 3。

答：x = 1或x = 3。

**例题5：** 已知y = √(x + 1)，求x = 8时的函数值。

解：

y = √(8 + 1) = √9 = 3。

答：函数值为3。

## 五、常见错误

**错误1：代入时符号搞错**

错误做法：x = -3时，y = (-3)² = -9。

正确理解：(-3)² = 9。

**错误2：已知函数值不解方程**

错误做法：y = 2x + 1，y = 7，x = 7。

正确理解：7 = 2x + 1，x = 3。

**错误3：一元二次方程漏解**

错误做法：x² = 4，x = 2。

正确理解：x = 2或x = -2。

**错误4：函数值超出取值范围**

错误做法：y = √(x-3)，x = 2时y = √(-1)。

正确理解：x = 2不在取值范围内。

**错误5：计算错误**

错误做法：y = 3 × 4 - 2 = 14。

正确理解：y = 12 - 2 = 10。

## 六、练习题

**练习1：** 已知y = 5x + 3，求x = 2时的函数值。

解：

y = 5 × 2 + 3 = 13。

答：函数值为13。

**练习2：** 已知y = x² - 2x + 1，求x = -2时的函数值。

解：

y = (-2)² - 2 × (-2) + 1 = 4 + 4 + 1 = 9。

答：函数值为9。

**练习3：** 已知y = 4x - 7，当函数值为9时，求x的值。

解：

9 = 4x - 7。

4x = 16。

x = 4。

答：x = 4。

**练习4：** 已知y = x² - 9，当函数值为0时，求x的值。

解：

0 = x² - 9。

x² = 9。

x = 3或x = -3。

答：x = 3或x = -3。

**练习5：** 已知y = √(2x - 4)，求x = 6时的函数值。

解：

y = √(12 - 4) = √8 = 2√2。

答：函数值为2√2。
