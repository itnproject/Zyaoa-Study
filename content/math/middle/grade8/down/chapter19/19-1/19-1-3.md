# 19.1.3 函数自变量的取值范围

## 一、整式型：全体实数

**y = 2x + 1**

x可以取任何实数。

取值范围：全体实数。

**y = x² - 3x + 2**

x可以取任何实数。

取值范围：全体实数。

## 二、分式型：分母≠0

**y = 1/(x - 2)**

分母x - 2 ≠ 0。

x ≠ 2。

取值范围：x ≠ 2。

**y = 3/(x + 1)**

分母x + 1 ≠ 0。

x ≠ -1。

取值范围：x ≠ -1。

## 三、根式型：被开方数≥0

**y = √(x - 3)**

被开方数x - 3 ≥ 0。

x ≥ 3。

取值范围：x ≥ 3。

**y = √(2x + 4)**

被开方数2x + 4 ≥ 0。

x ≥ -2。

取值范围：x ≥ -2。

## 四、实际问题：还要符合实际意义

**矩形面积y = x(10 - x)，x为边长**

x > 0且10 - x > 0。

0 < x < 10。

**人数y = 2x + 3，x为组数**

x为正整数。

## 五、多个限制条件取公共部分

**y = √(x - 1)/(x - 3)**

根式：x - 1 ≥ 0，即x ≥ 1。

分式：x - 3 ≠ 0，即x ≠ 3。

公共部分：x ≥ 1且x ≠ 3。

## 六、例题讲解

**例题1：** 求y = 3x - 5中自变量x的取值范围。

解：

整式型。

x可以取全体实数。

答：全体实数。

**例题2：** 求y = 2/(x + 3)中自变量x的取值范围。

解：

分式型。

x + 3 ≠ 0。

x ≠ -3。

答：x ≠ -3。

**例题3：** 求y = √(x + 2)中自变量x的取值范围。

解：

根式型。

x + 2 ≥ 0。

x ≥ -2。

答：x ≥ -2。

**例题4：** 求y = √(x - 1)/(x - 4)中自变量x的取值范围。

解：

根式：x - 1 ≥ 0，即x ≥ 1。

分式：x - 4 ≠ 0，即x ≠ 4。

公共部分：x ≥ 1且x ≠ 4。

答：x ≥ 1且x ≠ 4。

**例题5：** 用20cm长的绳子围矩形，设一边长为x，面积为y，求x的取值范围。

解：

另一边长为(10 - x)。

x > 0且10 - x > 0。

0 < x < 10。

答：0 < x < 10。

## 七、常见错误

**错误1：分式型忘记分母≠0**

错误做法：y = 1/(x-2)，x取全体实数。

正确理解：x ≠ 2。

**错误2：根式型忘记被开方数≥0**

错误做法：y = √(x-3)，x取全体实数。

正确理解：x ≥ 3。

**错误3：多个条件只考虑一个**

错误做法：y = √(x-1)/(x-3)，只考虑x ≥ 1。

正确理解：x ≥ 1且x ≠ 3。

**错误4：实际问题不考虑实际意义**

错误做法：边长可以为负数。

正确理解：边长必须为正数。

**错误5：不等号方向搞错**

错误做法：x - 3 ≥ 0，x ≤ 3。

正确理解：x ≥ 3。

## 八、练习题

**练习1：** 求y = x² + 2x - 1中自变量x的取值范围。

解：

整式型。

x取全体实数。

答：全体实数。

**练习2：** 求y = 5/(x - 7)中自变量x的取值范围。

解：

x - 7 ≠ 0。

x ≠ 7。

答：x ≠ 7。

**练习3：** 求y = √(3 - x)中自变量x的取值范围。

解：

3 - x ≥ 0。

x ≤ 3。

答：x ≤ 3。

**练习4：** 求y = √(x + 1)/(x - 2)中自变量x的取值范围。

解：

x + 1 ≥ 0，即x ≥ -1。

x - 2 ≠ 0，即x ≠ 2。

公共部分：x ≥ -1且x ≠ 2。

答：x ≥ -1且x ≠ 2。

**练习5：** 用30cm长的绳子围矩形，设一边长为x，面积为y，求x的取值范围。

解：

另一边长为(15 - x)。

x > 0且15 - x > 0。

0 < x < 15。

答：0 < x < 15。
