# 19.3.3 一次函数与二元一次方程组

## 一、两个一次函数图象的交点坐标就是对应方程组的解

**两个一次函数：y = k₁x + b₁ 和 y = k₂x + b₂**

它们的图象是两条直线。

两条直线的交点坐标就是方程组的解。

**例子**

y = 2x + 1 和 y = -x + 4。

交点：2x + 1 = -x + 4。

3x = 3，x = 1。

y = 3。

交点为(1, 3)。

方程组的解是x = 1，y = 3。

## 二、图象法解二元一次方程组

**步骤**

第一步：把两个方程化成y = kx + b的形式。

第二步：分别画出两条直线。

第三步：找到两条直线的交点。

第四步：交点坐标就是方程组的解。

**例子**

解方程组：
x + y = 5
2x - y = 1

化成：y = -x + 5 和 y = 2x - 1。

画图象找交点。

交点为(2, 3)。

方程组的解是x = 2，y = 3。

## 三、两直线位置关系与方程组解的情况

**相交：一个交点，方程组有唯一解**

k₁ ≠ k₂。

**平行：没有交点，方程组无解**

k₁ = k₂，b₁ ≠ b₂。

**重合：无数个交点，方程组有无数解**

k₁ = k₂，b₁ = b₂。

## 四、例题讲解

**例题1：** 用图象法解方程组：y = x + 1，y = -2x + 4。

解：

画两条直线。

交点：x + 1 = -2x + 4。

3x = 3，x = 1。

y = 2。

交点为(1, 2)。

方程组的解是x = 1，y = 2。

答：x = 1，y = 2。

**例题2：** 判断方程组：y = 2x + 1，y = 2x + 3的解的情况。

解：

k₁ = k₂ = 2，b₁ ≠ b₂。

两直线平行。

方程组无解。

答：无解。

**例题3：** 判断方程组：y = 3x - 2，y = 3x - 2的解的情况。

解：

k₁ = k₂ = 3，b₁ = b₂ = -2。

两直线重合。

方程组有无数解。

答：无数解。

**例题4：** 已知直线y = x + 2和y = -x + 6，求它们的交点坐标。

解：

x + 2 = -x + 6。

2x = 4，x = 2。

y = 4。

交点为(2, 4)。

答：(2, 4)。

**例题5：** 已知方程组：2x + y = 7，x - y = 2，用图象法求解。

解：

化成：y = -2x + 7 和 y = x - 2。

交点：-2x + 7 = x - 2。

3x = 9，x = 3。

y = 1。

交点为(3, 1)。

方程组的解是x = 3，y = 1。

答：x = 3，y = 1。

## 五、常见错误

**错误1：交点坐标写反**

错误做法：交点(1, 2)写成x = 2，y = 1。

正确理解：x = 1，y = 2。

**错误2：平行和重合搞混**

错误做法：k相同就是重合。

正确理解：k相同，b不同是平行。

**错误3：图象法不画准确**

错误做法：随便画两条直线找交点。

正确理解：要准确画出图象。

**错误4：解方程时计算错误**

错误做法：x + 1 = -2x + 4，x = 3。

正确理解：3x = 3，x = 1。

**错误5：不化成y = kx + b形式就画图象**

错误做法：直接画2x + y = 7的图象。

正确理解：先化成y = -2x + 7。

## 六、练习题

**练习1：** 用图象法解方程组：y = 2x - 1，y = x + 3。

解：

交点：2x - 1 = x + 3。

x = 4。

y = 7。

交点为(4, 7)。

方程组的解是x = 4，y = 7。

答：x = 4，y = 7。

**练习2：** 判断方程组：y = -x + 2，y = -x + 5的解的情况。

解：

k₁ = k₂ = -1，b₁ ≠ b₂。

两直线平行。

方程组无解。

答：无解。

**练习3：** 判断方程组：y = 2x - 3，y = 2x - 3的解的情况。

解：

k₁ = k₂ = 2，b₁ = b₂ = -3。

两直线重合。

方程组有无数解。

答：无数解。

**练习4：** 已知直线y = 3x - 1和y = -x + 7，求它们的交点坐标。

解：

3x - 1 = -x + 7。

4x = 8，x = 2。

y = 5。

交点为(2, 5)。

答：(2, 5)。

**练习5：** 已知方程组：x + y = 6，2x - y = 3，用图象法求解。

解：

化成：y = -x + 6 和 y = 2x - 3。

交点：-x + 6 = 2x - 3。

3x = 9，x = 3。

y = 3。

交点为(3, 3)。

方程组的解是x = 3，y = 3。

答：x = 3，y = 3。
