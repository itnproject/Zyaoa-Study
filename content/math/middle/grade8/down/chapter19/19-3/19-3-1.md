# 19.3.1 一次函数与一元一次方程

## 一、从y=kx+b中令y=0得到kx+b=0

**一次函数y = kx + b**

当y = 0时，kx + b = 0。

这就是一元一次方程。

**例子**

y = 2x + 4。

令y = 0，2x + 4 = 0。

x = -2。

## 二、解方程kx+b=0等价于求直线与x轴交点横坐标

**方程kx + b = 0的解就是直线y = kx + b与x轴交点的横坐标**

直线与x轴交点：y = 0。

交点坐标为(x, 0)。

x就是方程的解。

**例子**

y = 2x + 4。

与x轴交点：2x + 4 = 0，x = -2。

交点为(-2, 0)。

方程2x + 4 = 0的解是x = -2。

## 三、图象法解一元一次方程

**步骤**

第一步：画出y = kx + b的图象。

第二步：找到图象与x轴的交点。

第三步：交点的横坐标就是方程的解。

**例子**

解方程3x - 6 = 0。

画y = 3x - 6的图象。

与x轴交点：(2, 0)。

方程的解是x = 2。

## 四、例题讲解

**例题1：** 用图象法解方程2x + 4 = 0。

解：

画y = 2x + 4的图象。

与x轴交点：2x + 4 = 0，x = -2。

交点为(-2, 0)。

方程的解是x = -2。

答：x = -2。

**例题2：** 已知直线y = 3x - 9，求方程3x - 9 = 0的解。

解：

3x - 9 = 0。

3x = 9。

x = 3。

答：x = 3。

**例题3：** 直线y = -x + 5与x轴的交点坐标是什么？

解：

令y = 0。

-x + 5 = 0。

x = 5。

交点为(5, 0)。

答：(5, 0)。

**例题4：** 方程4x + 8 = 0的解对应直线y = 4x + 8与哪个轴的交点？

解：

令y = 0。

与x轴的交点。

答：x轴。

**例题5：** 已知直线y = kx + 3与x轴交于点(-1, 0)，求方程kx + 3 = 0的解。

解：

交点横坐标就是方程的解。

x = -1。

答：x = -1。

## 五、常见错误

**错误1：与y轴交点当成方程的解**

错误做法：y = 2x + 4，与y轴交点(0, 4)，x = 4。

正确理解：与x轴交点才是方程的解。

**错误2：解方程时符号搞错**

错误做法：2x + 4 = 0，x = 2。

正确理解：x = -2。

**错误3：图象法不画准确**

错误做法：随便画条直线找交点。

正确理解：要准确画出图象。

**错误4：混淆方程和函数**

错误做法：2x + 4 = 0是函数。

正确理解：2x + 4 = 0是方程。

**错误5：交点坐标写反**

错误做法：交点(0, -2)。

正确理解：交点(-2, 0)。
