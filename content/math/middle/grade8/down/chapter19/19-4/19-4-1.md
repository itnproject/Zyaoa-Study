# 19.4.1 一次函数应用题——方案选择

## 一、常见题型

**话费套餐选择**

套餐A：月租20元，每分钟0.1元。

套餐B：月租50元，每分钟0.05元。

哪种套餐更划算？

**租车方案**

公司A：每天100元，每公里1元。

公司B：每天200元，每公里0.5元。

哪种方案更省钱？

**购票方案**

方案A：成人票100元，儿童票50元。

方案B：团体票80元/人（10人以上）。

哪种方案更优惠？

## 二、步骤：设变量→列函数→比较函数值→选择最优方案

**第一步：设变量**

设自变量为x。

**第二步：列函数**

列出各方案的费用函数。

**第三步：比较函数值**

令两个函数相等，求交点。

**第四步：选择最优方案**

根据x的范围选择费用更低的方案。

## 三、分段计费问题

**不同范围不同计费方式**

例如：用电量不超过100度，每度0.5元。

超过100度，超过部分每度0.8元。

需要分段列函数。

## 四、例题讲解

**例题1：** 话费套餐A：月租20元，每分钟0.1元；套餐B：月租50元，每分钟0.05元。如何选择？

解：

设通话时间为x分钟。

y₁ = 0.1x + 20。

y₂ = 0.05x + 50。

令y₁ = y₂：0.1x + 20 = 0.05x + 50。

0.05x = 30，x = 600。

x < 600时，选套餐A。

x > 600时，选套餐B。

x = 600时，两种一样。

答：通话时间少于600分钟选A，多于600分钟选B。

**例题2：** 租车公司A：每天100元，每公里1元；公司B：每天200元，每公里0.5元。如何选择？

解：

设行驶x公里。

y₁ = x + 100。

y₂ = 0.5x + 200。

令y₁ = y₂：x + 100 = 0.5x + 200。

0.5x = 100，x = 200。

x < 200时，选公司A。

x > 200时，选公司B。

答：行驶少于200公里选A，多于200公里选B。

**例题3：** 某市出租车计费：3公里内10元，超过3公里每公里2元。行驶8公里需付多少元？

解：

超过3公里的部分：8 - 3 = 5公里。

超过部分费用：5 × 2 = 10元。

总费用：10 + 10 = 20元。

答：20元。

**例题4：** 印刷厂A：制版费500元，每本5元；印刷厂B：制版费200元，每本8元。印多少本时费用相同？

解：

设印x本。

y₁ = 5x + 500。

y₂ = 8x + 200。

令y₁ = y₂：5x + 500 = 8x + 200。

3x = 300，x = 100。

答：印100本时费用相同。

**例题5：** 上网套餐A：每月30元，不限时；套餐B：每月10元，每小时1元，最多50小时。如何选择？

解：

设上网x小时（x ≤ 50）。

y₁ = 30。

y₂ = x + 10。

令y₁ = y₂：x + 10 = 30，x = 20。

x < 20时，选套餐B。

x > 20时，选套餐A。

答：上网少于20小时选B，多于20小时选A。

## 五、常见错误

**错误1：不列函数直接猜**

错误做法：凭感觉选方案。

正确理解：要列函数比较。

**错误2：变量设错**

错误做法：设费用为x。

正确理解：设影响费用的量为x。

**错误3：交点求错**

错误做法：0.1x + 20 = 0.05x + 50，x = 30。

正确理解：x = 600。

**错误4：范围判断错误**

错误做法：x < 600时选B。

正确理解：x < 600时选A（费用更低）。

**错误5：分段计费不分段**

错误做法：8公里按每公里2元算，16元。

正确理解：前3公里10元，后5公里10元，共20元。

## 六、练习题

**练习1：** 健身房A：年费500元，每次10元；健身房B：年费200元，每次20元。去多少次时费用相同？

解：

设去x次。

y₁ = 10x + 500。

y₂ = 20x + 200。

令y₁ = y₂：10x + 500 = 20x + 200。

10x = 300，x = 30。

答：去30次时费用相同。

**练习2：** 快递A：首重10元，续重每千克2元；快递B：首重15元，续重每千克1元。寄多少千克时费用相同？

解：

设寄x千克（x > 1）。

y₁ = 2(x - 1) + 10 = 2x + 8。

y₂ = 1(x - 1) + 15 = x + 14。

令y₁ = y₂：2x + 8 = x + 14。

x = 6。

答：寄6千克时费用相同。

**练习3：** 手机套餐A：月租30元，每分钟0.2元；套餐B：月租80元，每分钟0.1元。如何选择？

解：

设通话x分钟。

y₁ = 0.2x + 30。

y₂ = 0.1x + 80。

令y₁ = y₂：0.2x + 30 = 0.1x + 80。

0.1x = 50，x = 500。

x < 500时选A，x > 500时选B。

答：通话少于500分钟选A，多于500分钟选B。

**练习4：** 旅游公司A：每人200元；公司B：10人以上每人150元。15人选哪家？

解：

公司A：15 × 200 = 3000元。

公司B：15 × 150 = 2250元。

2250 < 3000。

答：选公司B。

**练习5：** 停车A：每小时5元；停车B：每天30元。停8小时选哪家？

解：

停车A：8 × 5 = 40元。

停车B：30元。

30 < 40。

答：选停车B。
