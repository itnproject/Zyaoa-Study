# 19.4.2 一次函数应用题——行程与利润

## 一、行程问题：s=vt的图象分析

**路程 = 速度 × 时间**

s = vt。

匀速运动时，路程与时间成正比例。

图象是经过原点的直线。

**速度是直线的斜率**

速度越大，直线越陡。

**相遇问题**

两人相向而行。

路程和 = 速度和 × 时间。

**追及问题**

两人同向而行。

路程差 = 速度差 × 时间。

## 二、利润问题：利润=收入-成本

**利润 = 收入 - 成本**

利润 = 售价 × 数量 - 成本。

**成本 = 固定成本 + 变动成本**

固定成本：不随数量变化。

变动成本：随数量变化。

**利润函数**

y = (售价 - 成本价) × 数量 - 固定成本。

## 三、分段函数在实际问题中的应用

**不同范围不同函数关系**

例如：购买不超过10件，每件10元。

超过10件，超过部分每件8元。

需要分段列函数。

## 四、例题讲解

**例题1：** 甲乙两人分别从A、B两地同时出发，相向而行。甲的速度是60km/h，乙的速度是40km/h，AB两地相距200km。几小时后相遇？

解：

设x小时后相遇。

甲走的路程：60x。

乙走的路程：40x。

60x + 40x = 200。

100x = 200。

x = 2。

答：2小时后相遇。

**例题2：** 小明以每小时5km的速度步行，2小时后小红骑自行车以每小时15km的速度从同一地点出发追赶小明。几小时后追上？

解：

设x小时后追上。

小明走的路程：5(x + 2)。

小红走的路程：15x。

15x = 5(x + 2)。

15x = 5x + 10。

10x = 10。

x = 1。

答：1小时后追上。

**例题3：** 某商品进价20元，售价30元，每天固定成本100元。每天卖多少件才能不亏本？

解：

设每天卖x件。

利润y = (30 - 20)x - 100 = 10x - 100。

不亏本：y ≥ 0。

10x - 100 ≥ 0。

x ≥ 10。

答：每天至少卖10件。

**例题4：** 某商店卖文具，不超过20件每件5元，超过20件超过部分每件4元。买35件需付多少元？

解：

前20件：20 × 5 = 100元。

超过部分：15 × 4 = 60元。

总费用：100 + 60 = 160元。

答：160元。

**例题5：** 一辆汽车从A地出发，以60km/h的速度行驶2小时后，休息1小时，再以80km/h的速度继续行驶。画出路程与时间的函数图象。

解：

0 ≤ t ≤ 2：s = 60t。

2 < t ≤ 3：s = 120（休息）。

t > 3：s = 120 + 80(t - 3) = 80t - 120。

分段函数。

答：如上所述。

## 五、常见错误

**错误1：相遇问题路程和搞错**

错误做法：60x - 40x = 200。

正确理解：60x + 40x = 200。

**错误2：追及问题时间搞错**

错误做法：追及时间相同。

正确理解：先出发的人多走一段时间。

**错误3：利润公式搞错**

错误做法：利润 = 售价 × 数量。

正确理解：利润 = 收入 - 成本。

**错误4：分段函数不分段**

错误做法：35件按每件5元算，175元。

正确理解：前20件5元，后15件4元。

**错误5：图象中休息时间不水平**

错误做法：休息时路程还在增加。

正确理解：休息时路程不变，图象水平。

## 六、练习题

**练习1：** 甲乙两人从相距300km的两地同时出发，相向而行。甲的速度是80km/h，乙的速度是70km/h。几小时后相遇？

解：

设x小时后相遇。

80x + 70x = 300。

150x = 300。

x = 2。

答：2小时后相遇。

**练习2：** 小刚以每小时4km的速度步行，1小时后小强骑自行车以每小时12km的速度从同一地点出发追赶。几小时后追上？

解：

设x小时后追上。

4(x + 1) = 12x。

4x + 4 = 12x。

8x = 4。

x = 0.5。

答：0.5小时后追上。

**练习3：** 某商品进价15元，售价25元，每天固定成本200元。每天卖多少件才能不亏本？

解：

设每天卖x件。

利润y = (25 - 15)x - 200 = 10x - 200。

10x - 200 ≥ 0。

x ≥ 20。

答：每天至少卖20件。

**练习4：** 某书店卖书，不超过10本每本20元，超过10本超过部分每本15元。买25本需付多少元？

解：

前10本：10 × 20 = 200元。

超过部分：15 × 15 = 225元。

总费用：200 + 225 = 425元。

答：425元。

**练习5：** 一辆汽车以50km/h的速度行驶3小时后，休息0.5小时，再以60km/h的速度继续行驶。求t = 5小时时的路程。

解：

前3小时：50 × 3 = 150km。

休息0.5小时：路程不变，150km。

再行驶1.5小时：60 × 1.5 = 90km。

总路程：150 + 90 = 240km。

答：240km。
