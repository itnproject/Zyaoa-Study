# 20.3.1 数据分析的实际应用

## 一、选择合适的统计量描述数据

**平均数：数据均匀分布时**

没有极端值。

所有数据都重要。

**中位数：有极端值时**

数据中有特别大或特别小的值。

中位数不受极端值影响。

**众数：关注最常见值时**

想知道哪个值出现最多。

商业决策中常用。

**方差：比较稳定性时**

比较两组数据的波动。

方差小更稳定。

## 二、平均数、中位数、众数、方差的综合运用

**例子：某公司10人月薪（元）**

5000、5500、6000、6500、7000、7500、8000、8500、9000、50000。

平均数：11300元。

中位数：7250元。

众数：没有。

极差：45000元。

**分析**

平均数被50000拉高。

中位数7250更能代表一般水平。

极差大说明收入差距大。

## 三、从图表中获取信息进行分析

**条形图**

比较各组数据的多少。

**折线图**

观察数据的变化趋势。

**扇形图**

观察各部分占总体的比例。

**直方图**

观察数据的分布情况。

## 四、撰写简单的数据分析报告

**第一步：描述数据**

列出平均数、中位数、众数、方差。

**第二步：分析数据**

数据有什么特点。

有什么趋势。

**第三步：得出结论**

根据分析得出结论。

**第四步：提出建议**

根据结论提出建议。

## 五、例题讲解

**例题1：** 甲乙两组学生各5人的数学成绩：

甲：80、85、90、85、80。

乙：70、90、80、100、80。

从平均数、中位数、方差分析哪组更好。

解：

甲平均数 = 84，中位数 = 85，方差 = 14。

乙平均数 = 84，中位数 = 80，方差 = 104。

平均数相同。

甲中位数更高，中间水平更好。

甲方差更小，成绩更稳定。

综合来看甲组更好。

答：甲组更好。

**例题2：** 某商店一周各天营业额（元）：

周一3000，周二3500，周三4000，周四3800，周五5000，周六6000，周日5500。

分析营业额情况。

解：

平均数 = (3000+3500+4000+3800+5000+6000+5500)/7

= 30800/7 = 4400元。

中位数 = 4000元（排序后第4个）。

众数 = 没有。

极差 = 6000 - 3000 = 3000元。

分析：周末营业额高于工作日。

建议：周末增加人手。

答：平均营业额4400元，周末较高。

**例题3：** 某班30名学生的身高统计如下：

155cm有3人，160cm有8人，165cm有12人，170cm有5人，175cm有2人。

求平均身高、中位数、众数。

解：

平均身高 = (155×3+160×8+165×12+170×5+175×2)/30

= (465+1280+1980+850+350)/30

= 4925/30 ≈ 164.2cm。

中位数：第15和第16个都是165cm。

中位数 = 165cm。

众数：165cm出现12次，最多。

众数 = 165cm。

答：平均身高约164.2cm，中位数165cm，众数165cm。

**例题4：** 某工厂两条生产线生产零件，各抽取5个测量直径（mm）：

A线：10.0、10.1、9.9、10.0、10.0。

B线：9.8、10.2、10.0、9.7、10.3。

哪条生产线质量更稳定？

解：

A线平均数 = 10.0，方差 = 0.004。

B线平均数 = 10.0，方差 = 0.052。

0.004 < 0.052，A线更稳定。

答：A线质量更稳定。

**例题5：** 某学校调查学生每天课外阅读时间，随机抽取50名学生，结果如下：

0小时5人，0.5小时10人，1小时15人，1.5小时12人，2小时8人。

分析学生阅读情况。

解：

平均时间 = (0×5+0.5×10+1×15+1.5×12+2×8)/50

= (0+5+15+18+16)/50 = 54/50 = 1.08小时。

中位数：第25和第26个都是1小时。

中位数 = 1小时。

众数：1小时出现15次，最多。

众数 = 1小时。

分析：大部分学生每天阅读1小时左右。

建议：鼓励学生增加阅读时间。

答：平均阅读时间1.08小时，建议增加阅读。

## 六、常见错误

**错误1：统计量选择不当**

错误做法：有极端值还用平均数。

正确理解：有极端值用中位数。

**错误2：从图表中读错数据**

错误做法：看错条形图的高度。

正确理解：仔细读图。

**错误3：分析不全面**

错误做法：只看平均数就下结论。

正确理解：综合多个统计量分析。

**错误4：结论没有依据**

错误做法：凭空得出结论。

正确理解：结论要基于数据分析。

**错误5：建议不具体**

错误做法：建议"提高成绩"。

正确理解：建议要具体可操作。

## 七、练习题

**练习1：** 甲乙两人5次射击成绩：

甲：8、9、8、9、8。

乙：6、10、8、10、8。

从平均数和方差分析谁更稳定。

解：

甲平均数 = 8.4，方差 = 0.24。

乙平均数 = 8.4，方差 = 3.04。

0.24 < 3.04，甲更稳定。

答：甲更稳定。

**练习2：** 某班8名同学的零花钱（元）：20、30、25、35、20、30、25、40。求平均数、中位数、众数。

解：

平均数 = (20+30+25+35+20+30+25+40)/8 = 225/8 = 28.125元。

排序：20、20、25、25、30、30、35、40。

中位数 = (25+30)/2 = 27.5元。

众数：20、25、30都出现2次。

众数是20、25、30。

答：平均数约28.1元，中位数27.5元，众数20、25、30。

**练习3：** 某超市一周营业额（万元）：5、6、7、6.5、8、9、8.5。分析营业额趋势。

解：

平均数 = (5+6+7+6.5+8+9+8.5)/7 = 50/7 ≈ 7.14万元。

从周一到周日整体呈上升趋势。

周末营业额高于工作日。

建议：周末增加库存和人手。

答：平均约7.14万元，呈上升趋势。

**练习4：** 某校调查学生每天运动时间，随机抽取40名学生：

0小时4人，0.5小时8人，1小时12人，1.5小时10人，2小时6人。

求平均运动时间。

解：

平均时间 = (0×4+0.5×8+1×12+1.5×10+2×6)/40

= (0+4+12+15+12)/40 = 43/40 = 1.075小时。

答：平均运动时间约1.075小时。

**练习5：** 两组数据：

A：50、55、60、65、70。

B：40、50、60、70、80。

比较两组数据的波动大小。

解：

A平均数 = 60，方差 = 50。

B平均数 = 60，方差 = 200。

50 < 200，A组波动更小。

答：A组波动更小。
