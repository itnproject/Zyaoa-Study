# 20.2.2 方差

## 一、从生活实例引入

**两位射击选手谁更稳定**

甲选手5次成绩：9、10、9、10、10。

乙选手5次成绩：6、10、10、10、12。

两人平均成绩都是9.6环。

但甲的成绩更集中，更稳定。

乙的成绩波动更大。

怎么衡量稳定性？

用方差。

## 二、方差的定义

**各数据与平均数的差的平方的平均数**

第一步：求平均数x̄。

第二步：每个数据减去平均数。

第三步：把差平方。

第四步：求这些平方的平均数。

**公式**

s² = [(x₁-x̄)² + (x₂-x̄)² + ... + (xₙ-x̄)²] / n

s²表示方差。

n是数据个数。

## 三、方差越小，数据越稳定

**方差小：数据集中在平均数附近**

数据波动小。

数据稳定。

**方差大：数据分散**

数据波动大。

数据不稳定。

**例子**

甲：9、10、9、10、10，平均数9.6。

方差 = [(9-9.6)²+(10-9.6)²+(9-9.6)²+(10-9.6)²+(10-9.6)²]/5

= [0.36+0.16+0.36+0.16+0.16]/5

= 1.2/5 = 0.24。

乙：6、10、10、10、12，平均数9.6。

方差 = [(6-9.6)²+(10-9.6)²+(10-9.6)²+(10-9.6)²+(12-9.6)²]/5

= [12.96+0.16+0.16+0.16+5.76]/5

= 19.2/5 = 3.84。

0.24 < 3.84，甲更稳定。

## 四、方差的意义

**衡量数据的波动大小**

方差是衡量数据波动最常用的统计量。

方差考虑了所有数据。

比方差更全面的是标准差。

## 五、标准差

**方差的算术平方根**

s = √s²

标准差的单位与原数据相同。

标准差更直观。

**例子**

方差s² = 4。

标准差s = √4 = 2。

## 六、例题讲解

**例题1：** 求数据2、4、6、8、10的方差。

解：

平均数x̄ = (2+4+6+8+10)/5 = 6。

方差s² = [(2-6)²+(4-6)²+(6-6)²+(8-6)²+(10-6)²]/5

= [16+4+0+4+16]/5

= 40/5 = 8。

答：方差是8。

**例题2：** 求数据3、3、3、3、3的方差。

解：

平均数x̄ = 3。

方差s² = [(3-3)²+(3-3)²+(3-3)²+(3-3)²+(3-3)²]/5

= 0/5 = 0。

答：方差是0。

**例题3：** 甲乙两人5次测验成绩：

甲：80、85、90、85、80。

乙：70、90、80、100、80。

谁更稳定？

解：

甲平均数 = (80+85+90+85+80)/5 = 420/5 = 84。

甲方差 = [(80-84)²+(85-84)²+(90-84)²+(85-84)²+(80-84)²]/5

= [16+1+36+1+16]/5 = 70/5 = 14。

乙平均数 = (70+90+80+100+80)/5 = 420/5 = 84。

乙方差 = [(70-84)²+(90-84)²+(80-84)²+(100-84)²+(80-84)²]/5

= [196+36+16+256+16]/5 = 520/5 = 104。

14 < 104，甲更稳定。

答：甲更稳定。

**例题4：** 求数据1、2、3、4、5的方差和标准差。

解：

平均数x̄ = 3。

方差s² = [(1-3)²+(2-3)²+(3-3)²+(4-3)²+(5-3)²]/5

= [4+1+0+1+4]/5 = 10/5 = 2。

标准差s = √2 ≈ 1.41。

答：方差是2，标准差约1.41。

**例题5：** 已知数据x、2、4、6、8的平均数是5，求方差。

解：

x + 2 + 4 + 6 + 8 = 5 × 5 = 25。

x = 25 - 20 = 5。

数据：5、2、4、6、8。

平均数x̄ = 5。

方差s² = [(5-5)²+(2-5)²+(4-5)²+(6-5)²+(8-5)²]/5

= [0+9+1+1+9]/5 = 20/5 = 4。

答：方差是4。

## 七、常见错误

**错误1：忘记平方**

错误做法：(x-x̄)直接相加。

正确理解：要先平方再相加。

**错误2：平均数算错**

错误做法：平均数算错导致方差全错。

正确理解：先仔细算平均数。

**错误3：负数平方出错**

错误做法：(-3)² = -9。

正确理解：(-3)² = 9。

**错误4：忘记除以n**

错误做法：平方和就是方差。

正确理解：平方和要除以n。

**错误5：方差和标准差搞混**

错误做法：方差就是标准差。

正确理解：标准差是方差的算术平方根。

## 八、练习题

**练习1：** 求数据1、3、5、7、9的方差。

解：

平均数x̄ = 5。

方差s² = [(1-5)²+(3-5)²+(5-5)²+(7-5)²+(9-5)²]/5

= [16+4+0+4+16]/5 = 40/5 = 8。

答：方差是8。

**练习2：** 求数据5、5、5、5、5的方差。

解：

平均数x̄ = 5。

方差s² = 0。

答：方差是0。

**练习3：** 甲乙两组数据：

甲：10、12、14、12、10。

乙：5、15、10、15、5。

哪组更稳定？

解：

甲平均数 = 58/5 = 11.6。

甲方差 = [(10-11.6)²+(12-11.6)²+(14-11.6)²+(12-11.6)²+(10-11.6)²]/5

= [2.56+0.16+5.76+0.16+2.56]/5 = 11.2/5 = 2.24。

乙平均数 = 50/5 = 10。

乙方差 = [(5-10)²+(15-10)²+(10-10)²+(15-10)²+(5-10)²]/5

= [25+25+0+25+25]/5 = 100/5 = 20。

2.24 < 20，甲更稳定。

答：甲更稳定。

**练习4：** 求数据2、4、6、8的方差和标准差。

解：

平均数x̄ = 5。

方差s² = [(2-5)²+(4-5)²+(6-5)²+(8-5)²]/4

= [9+1+1+9]/4 = 20/4 = 5。

标准差s = √5 ≈ 2.24。

答：方差是5，标准差约2.24。

**练习5：** 已知数据3、x、7、9的平均数是6，求方差。

解：

3 + x + 7 + 9 = 6 × 4 = 24。

x = 24 - 19 = 5。

数据：3、5、7、9。

平均数x̄ = 6。

方差s² = [(3-6)²+(5-6)²+(7-6)²+(9-6)²]/4

= [9+1+1+9]/4 = 20/4 = 5。

答：方差是5。
