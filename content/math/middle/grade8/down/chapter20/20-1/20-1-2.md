# 20.1.2 加权平均数

## 一、从生活实例引入

**期末成绩计算**

期末总评成绩 = 平时成绩30% + 期中成绩30% + 期末成绩40%。

小明平时90分，期中80分，期末85分。

总评 = 90×30% + 80×30% + 85×40% = 27 + 24 + 34 = 85分。

不是简单平均(90+80+85)÷3 = 85分。

虽然结果一样，但计算方法不同。

**招聘评分**

某公司招聘，专业知识占50%，表达能力占30%，形象占20%。

甲：专业知识80，表达90，形象70。

甲的得分 = 80×50% + 90×30% + 70×20% = 40 + 27 + 14 = 81分。

## 二、权的含义

**权表示各个数据的重要程度**

权越大，这个数据对结果的影响越大。

权越小，这个数据对结果的影响越小。

**例子**

期末成绩中，期末占40%，平时占30%。

期末成绩更重要，影响更大。

## 三、加权平均数的计算公式

**公式**

x̄ = (x₁w₁ + x₂w₂ + ... + xₙwₙ) / (w₁ + w₂ + ... + wₙ)

x₁, x₂, ..., xₙ是各个数据。

w₁, w₂, ..., wₙ是各个数据对应的权。

**当权的和为1时**

x̄ = x₁w₁ + x₂w₂ + ... + xₙwₙ

## 四、权可以是百分比、次数、比值

**百分比形式**

平时30%，期中30%，期末40%。

权分别是0.3、0.3、0.4。

**次数形式**

数据80出现3次，90出现2次。

权分别是3和2。

加权平均 = (80×3 + 90×2) ÷ (3+2) = 420÷5 = 84。

**比值形式**

甲乙丙的权比是2:3:5。

权分别是2、3、5。

## 五、加权平均数与算术平均数的区别

**算术平均数：所有数据同等重要**

(80 + 90) ÷ 2 = 85。

**加权平均数：数据重要程度不同**

80×30% + 90×70% = 24 + 63 = 87。

权不同，结果不同。

**算术平均数是加权平均数的特殊情况**

当所有权相等时，加权平均数 = 算术平均数。

## 六、例题讲解

**例题1：** 某学生平时成绩85分，期中成绩90分，期末成绩80分。按平时20%、期中30%、期末50%计算总评成绩。

解：

总评 = 85×20% + 90×30% + 80×50%。

= 17 + 27 + 40。

= 84分。

答：总评成绩84分。

**例题2：** 某商品第一天卖10元/件，卖了20件；第二天卖12元/件，卖了30件。求平均售价。

解：

总销售额：10×20 + 12×30 = 200 + 360 = 560元。

总件数：20 + 30 = 50件。

平均售价：560 ÷ 50 = 11.2元。

答：平均售价11.2元。

**例题3：** 数据80的权是3，数据90的权是2，数据70的权是5，求加权平均数。

解：

加权平均 = (80×3 + 90×2 + 70×5) ÷ (3+2+5)。

= (240 + 180 + 350) ÷ 10。

= 770 ÷ 10 = 77。

答：加权平均数是77。

**例题4：** 某班40人，男生25人平均身高170cm，女生15人平均身高160cm，求全班平均身高。

解：

男生总身高：25 × 170 = 4250cm。

女生总身高：15 × 160 = 2400cm。

全班总身高：4250 + 2400 = 6650cm。

全班平均：6650 ÷ 40 = 166.25cm。

答：全班平均身高166.25cm。

**例题5：** 某公司招聘，笔试占60%，面试占40%。甲笔试85分，面试90分；乙笔试90分，面试80分。谁被录取？

解：

甲：85×60% + 90×40% = 51 + 36 = 87分。

乙：90×60% + 80×40% = 54 + 32 = 86分。

87 > 86，甲被录取。

答：甲被录取。

## 七、常见错误

**错误1：权搞混**

错误做法：平时50%，期末20%。

正确理解：看清题目中各部分的权。

**错误2：忘记除以权的和**

错误做法：80×3 + 90×2 = 420就是答案。

正确理解：420 ÷ 5 = 84。

**错误3：百分比没化成小数**

错误做法：80×30 = 2400。

正确理解：80×0.3 = 24。

**错误4：算术平均和加权平均搞混**

错误做法：(80+90+70)÷3 = 80。

正确理解：要考虑权。

**错误5：权的和不为1时处理错误**

错误做法：权是2、3、5，直接80×2 + 90×3 + 70×5。

正确理解：要除以(2+3+5)=10。

## 八、练习题

**练习1：** 某学生平时成绩80分，期中成绩85分，期末成绩90分。按平时30%、期中30%、期末40%计算总评成绩。

解：

总评 = 80×30% + 85×30% + 90×40%。

= 24 + 25.5 + 36。

= 85.5分。

答：总评成绩85.5分。

**练习2：** 数据70的权是2，数据80的权是3，数据90的权是5，求加权平均数。

解：

加权平均 = (70×2 + 80×3 + 90×5) ÷ (2+3+5)。

= (140 + 240 + 450) ÷ 10。

= 830 ÷ 10 = 83。

答：加权平均数是83。

**练习3：** 某班50人，男生30人平均分80，女生20人平均分90，求全班平均分。

解：

男生总分：30 × 80 = 2400。

女生总分：20 × 90 = 1800。

全班总分：2400 + 1800 = 4200。

全班平均：4200 ÷ 50 = 84。

答：全班平均分84分。

**练习4：** 某商品A种买10件每件5元，B种买20件每件4元，求平均每件价格。

解：

总金额：10×5 + 20×4 = 50 + 80 = 130元。

总件数：10 + 20 = 30件。

平均价格：130 ÷ 30 ≈ 4.33元。

答：平均每件约4.33元。

**练习5：** 某考核中，工作态度占20%，工作能力占50%，工作业绩占30%。甲态度85分，能力90分，业绩80分，求总分。

解：

总分 = 85×20% + 90×50% + 80×30%。

= 17 + 45 + 24。

= 86分。

答：总分86分。
