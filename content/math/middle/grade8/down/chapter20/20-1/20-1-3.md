# 20.1.3 中位数

## 一、从生活实例引入

**工资水平调查**

某公司9人，月薪分别是：3000、3500、4000、4500、5000、5500、6000、6500、50000。

平均数：(3000+3500+...+50000)÷9 ≈ 9778元。

但9人中只有1人超过这个数。

平均数被50000拉高了。

中位数是5000元，更能代表一般水平。

**中位数比平均数更合理**

当数据中有极端值时。

中位数不受极端值影响。

中位数更能反映数据的真实水平。

## 二、中位数的定义

**将数据从小到大排列，处在中间位置的数**

先排序。

再找中间位置的数。

这个数就是中位数。

**例子**

数据：3、1、4、2、5。

排序：1、2、3、4、5。

中间位置是第3个。

中位数是3。

## 三、求中位数的步骤

**第一步：排序**

把数据从小到大排列。

**第二步：确定中间位置**

n个数据，中间位置是第(n+1)/2个。

**第三步：找出中位数**

奇数个：中间那个数。

偶数个：中间两个数的平均数。

## 四、奇数个数据：中间那个

**例子**

数据：2、5、3、8、1。

排序：1、2、3、5、8。

n = 5，中间位置是第3个。

中位数是3。

**例子**

数据：10、20、30、40、50、60、70。

排序：10、20、30、40、50、60、70。

n = 7，中间位置是第4个。

中位数是40。

## 五、偶数个数据：中间两个的平均数

**例子**

数据：2、5、3、8。

排序：2、3、5、8。

n = 4，中间位置是第2和第3个。

中位数 = (3 + 5) ÷ 2 = 4。

**例子**

数据：10、20、30、40、50、60。

排序：10、20、30、40、50、60。

n = 6，中间位置是第3和第4个。

中位数 = (30 + 40) ÷ 2 = 35。

## 六、中位数的意义

**不受极端值影响**

数据：1、2、3、4、100。

中位数是3。

100这个极端值不影响中位数。

**反映数据的中等水平**

中位数把数据分成两半。

一半比中位数大。

一半比中位数小。

## 七、例题讲解

**例题1：** 求数据3、1、5、2、4的中位数。

解：

排序：1、2、3、4、5。

n = 5，中间位置是第3个。

中位数是3。

答：中位数是3。

**例题2：** 求数据6、2、8、4的中位数。

解：

排序：2、4、6、8。

n = 4，中间位置是第2和第3个。

中位数 = (4 + 6) ÷ 2 = 5。

答：中位数是5。

**例题3：** 求数据12、8、15、10、6、14的中位数。

解：

排序：6、8、10、12、14、15。

n = 6，中间位置是第3和第4个。

中位数 = (10 + 12) ÷ 2 = 11。

答：中位数是11。

**例题4：** 某班10名同学的身高（cm）：160、165、158、170、162、168、155、172、163、167，求中位数。

解：

排序：155、158、160、162、163、165、167、168、170、172。

n = 10，中间位置是第5和第6个。

中位数 = (163 + 165) ÷ 2 = 164。

答：中位数是164cm。

**例题5：** 数据1、2、x、6、7的中位数是4，求x。

解：

排序后中间位置是第3个。

中位数是4，所以x = 4。

答：x = 4。

## 八、常见错误

**错误1：不排序就找中位数**

错误做法：3、1、5、2、4，中位数是5。

正确理解：先排序1、2、3、4、5，中位数是3。

**错误2：偶数个数据只取一个**

错误做法：2、4、6、8，中位数是6。

正确理解：(4+6)÷2 = 5。

**错误3：从大到小排序**

错误做法：从大到小排序找中位数。

正确理解：从小到大排序。

**错误4：中间位置算错**

错误做法：n=7，中间位置是第4个，算成第3个。

正确理解：(7+1)/2 = 4。

**错误5：中位数和平均数搞混**

错误做法：中位数就是平均数。

正确理解：中位数是排序后中间的数。
