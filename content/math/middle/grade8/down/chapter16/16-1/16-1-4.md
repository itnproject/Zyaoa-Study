# 16.1.4 二次根式的性质（√ab与√a/b）

## 一、√ab = √a·√b

**积的算术平方根等于算术平方根的积**

**公式：√ab = √a · √b（a≥0，b≥0）**

**例子**

√(4×9) = √4 × √9 = 2 × 3 = 6

√(16×25) = √16 × √25 = 4 × 5 = 20

## 二、√(a/b) = √a/√b

**商的算术平方根等于算术平方根的商**

**公式：√(a/b) = √a/√b（a≥0，b>0）**

**例子**

√(4/9) = √4/√9 = 2/3

√(16/25) = √16/√25 = 4/5

## 三、积的算术平方根

**√ab = √a · √b（a≥0，b≥0）**

注意：a和b都必须是非负数。

√((-2)×(-3)) ≠ √(-2) × √(-3)

左边 = √6，右边没有意义。

## 四、商的算术平方根

**√(a/b) = √a/√b（a≥0，b>0）**

注意：b必须大于0（分母不能为0）。

a可以等于0。

√(0/4) = √0/√4 = 0/2 = 0

## 五、逆用：把根号外的因式移到根号内

**√a · √b = √ab**

3√2 = √9 × √2 = √18

2√3 = √4 × √3 = √12

**方法**

把根号外的数平方后移到根号内。

## 六、例题讲解

**例题1：** 计算：√(12)

解：

√12 = √(4×3) = √4 × √3 = 2√3

答：2√3。

**例题2：** 计算：√(2/25)

解：

√(2/25) = √2/√25 = √2/5

答：√2/5。

**例题3：** 化简：√(18)

解：

√18 = √(9×2) = √9 × √2 = 3√2

答：3√2。

**例题4：** 把3√2移到根号内。

解：

3√2 = √(3²) × √2 = √9 × √2 = √18

答：√18。

**例题5：** 计算：√(50)/√2

解：

√50/√2 = √(50/2) = √25 = 5

答：5。

## 七、常见错误

**错误1：负数也拆开**

错误做法：√((-2)×(-3)) = √(-2) × √(-3)。

正确理解：负数不能拆，√((-2)×(-3)) = √6。

**错误2：b=0时也拆**

错误做法：√(3/0) = √3/√0。

正确理解：分母不能为0。

**错误3：移到根号内不平方**

错误做法：3√2 = √6。

正确理解：3√2 = √9 × √2 = √18。

**错误4：加减也拆**

错误做法：√(4+9) = √4 + √9 = 2+3 = 5。

正确理解：√(4+9) = √13 ≠ 5。

**错误5：系数处理错误**

错误做法：2√3 = √6。

正确理解：2√3 = √4 × √3 = √12。

## 八、练习题

**练习1：** 计算：√(27)

解：

√27 = √(9×3) = √9 × √3 = 3√3

答：3√3。

**练习2：** 计算：√(9/16)

解：

√(9/16) = √9/√16 = 3/4

答：3/4。

**练习3：** 化简：√(48)

解：

√48 = √(16×3) = √16 × √3 = 4√3

答：4√3。

**练习4：** 把2√5移到根号内。

解：

2√5 = √(2²) × √5 = √4 × √5 = √20

答：√20。

**练习5：** 计算：√(72)/√8

解：

√72/√8 = √(72/8) = √9 = 3

答：3。
