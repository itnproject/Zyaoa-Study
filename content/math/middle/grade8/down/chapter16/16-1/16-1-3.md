# 16.1.3 二次根式的性质（√a²）

## 一、性质：√a² = |a|

**√a² = |a|**

这是二次根式的重要性质。

√(3²) = |3| = 3

√((-3)²) = |-3| = 3

## 二、当a≥0时

**√a² = a（a≥0）**

正数的平方的算术平方根等于它本身。

√(5²) = 5

√(0²) = 0

## 三、当a<0时

**√a² = -a（a<0）**

负数的平方的算术平方根等于它的相反数。

√((-5)²) = -(-5) = 5

√((-2)²) = -(-2) = 2

## 四、与(√a)²的区别

**(√a)² = a（a≥0）**

先开方再平方。

(√5)² = 5

(√3)² = 3

**√a² = |a|（a为任意实数）**

先平方再开方。

√(5²) = 5

√((-5)²) = 5

**区别**

(√a)² 要求a≥0。

√a² 对任意实数a都有意义。

## 五、化简含字母的√a²

**不知道字母正负时，结果带绝对值**

√(x²) = |x|

**知道字母正负时，可以去掉绝对值**

已知x≥0：√(x²) = x

已知x<0：√(x²) = -x

## 六、例题讲解

**例题1：** 计算：√(4²)

解：

√(4²) = |4| = 4

答：4。

**例题2：** 计算：√((-4)²)

解：

√((-4)²) = |-4| = 4

答：4。

**例题3：** 化简：√(x²)（x≥0）

解：

x ≥ 0

√(x²) = |x| = x

答：x。

**例题4：** 化简：√((x-1)²)（x<1）

解：

x < 1

x - 1 < 0

√((x-1)²) = |x-1| = -(x-1) = 1-x

答：1-x。

**例题5：** 化简：(√3)² - √((-3)²)

解：

(√3)² = 3

√((-3)²) = |-3| = 3

3 - 3 = 0

答：0。

## 七、常见错误

**错误1：√a² = a**

错误做法：√((-3)²) = -3。

正确理解：√((-3)²) = |-3| = 3。

**错误2：(√a)² = |a|**

错误做法：(√(-3))² = |-3| = 3。

正确理解：(√a)² = a（a≥0），√(-3)没有意义。

**错误3：含字母时不讨论正负**

错误做法：√(x²) = x。

正确理解：√(x²) = |x|。

**错误4：去绝对值时符号搞错**

错误做法：x<0时，|x| = x。

正确理解：x<0时，|x| = -x。

**错误5：混淆两种形式**

错误做法：(√a)² 和 √a² 是一样的。

正确理解：(√a)² = a（a≥0），√a² = |a|。

## 八、练习题

**练习1：** 计算：√(7²)

解：

√(7²) = |7| = 7

答：7。

**练习2：** 计算：√((-7)²)

解：

√((-7)²) = |-7| = 7

答：7。

**练习3：** 化简：√(x²)（x<0）

解：

x < 0

√(x²) = |x| = -x

答：-x。

**练习4：** 化简：√((2-x)²)（x>2）

解：

x > 2

2 - x < 0

√((2-x)²) = |2-x| = -(2-x) = x-2

答：x-2。

**练习5：** 化简：(√5)² + √((-2)²)

解：

(√5)² = 5

√((-2)²) = |-2| = 2

5 + 2 = 7

答：7。
