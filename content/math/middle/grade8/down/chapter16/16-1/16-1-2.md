# 16.1.2 二次根式有意义的条件

## 一、被开方数≥0

**二次根式有意义的条件：被开方数≥0**

√a 有意义的条件：a ≥ 0。

√(x-2) 有意义的条件：x - 2 ≥ 0，即 x ≥ 2。

**这是最基本的条件**

## 二、多个二次根式同时有意义

**取公共部分**

√(x-1) + √(x-3) 有意义。

x - 1 ≥ 0，即 x ≥ 1。

x - 3 ≥ 0，即 x ≥ 3。

公共部分：x ≥ 3。

## 三、分母中有二次根式

**被开方数>0**

1/√x 有意义。

分母不能为0：√x ≠ 0，即 x ≠ 0。

被开方数≥0：x ≥ 0。

综合：x > 0。

## 四、分式与二次根式结合的情况

**同时满足分式和二次根式的条件**

√(x-1)/(x-2) 有意义。

二次根式条件：x - 1 ≥ 0，即 x ≥ 1。

分式条件：x - 2 ≠ 0，即 x ≠ 2。

综合：x ≥ 1 且 x ≠ 2。

## 五、例题讲解

**例题1：** 当x取何值时，√(2x-4) 有意义？

解：

被开方数≥0：

2x - 4 ≥ 0

2x ≥ 4

x ≥ 2

答：x ≥ 2 时有意义。

**例题2：** 当x取何值时，√(x+1) + √(x-2) 有意义？

解：

x + 1 ≥ 0，即 x ≥ -1。

x - 2 ≥ 0，即 x ≥ 2。

公共部分：x ≥ 2。

答：x ≥ 2 时有意义。

**例题3：** 当x取何值时，1/√(x-3) 有意义？

解：

被开方数≥0：x - 3 ≥ 0，即 x ≥ 3。

分母≠0：√(x-3) ≠ 0，即 x - 3 ≠ 0，x ≠ 3。

综合：x > 3。

答：x > 3 时有意义。

**例题4：** 当x取何值时，√(x-1)/(x-3) 有意义？

解：

二次根式条件：x - 1 ≥ 0，即 x ≥ 1。

分式条件：x - 3 ≠ 0，即 x ≠ 3。

综合：x ≥ 1 且 x ≠ 3。

答：x ≥ 1 且 x ≠ 3 时有意义。

**例题5：** 当x取何值时，√(x+2)/√(x-1) 有意义？

解：

分子：x + 2 ≥ 0，即 x ≥ -2。

分母：x - 1 > 0（分母不能为0），即 x > 1。

公共部分：x > 1。

答：x > 1 时有意义。

## 六、常见错误

**错误1：多个根式只考虑一个**

错误做法：√(x-1) + √(x-3) 只考虑x≥1。

正确理解：要同时满足，x≥3。

**错误2：分母有根号时忽略分母≠0**

错误做法：1/√x 有意义条件x≥0。

正确理解：x>0。

**错误3：分式条件漏掉**

错误做法：√(x-1)/(x-2) 有意义条件x≥1。

正确理解：x≥1且x≠2。

**错误4：公共部分取错**

错误做法：x≥1和x≥3的公共部分是x≥1。

正确理解：公共部分是x≥3。

**错误5：根号在分母时条件搞错**

错误做法：1/√(x-2) 有意义条件x≥2。

正确理解：x>2。

## 七、练习题

**练习1：** 当x取何值时，√(3x+6) 有意义？

解：

3x + 6 ≥ 0

3x ≥ -6

x ≥ -2

答：x ≥ -2 时有意义。

**练习2：** 当x取何值时，√(x-2) + √(x+3) 有意义？

解：

x - 2 ≥ 0，即 x ≥ 2。

x + 3 ≥ 0，即 x ≥ -3。

公共部分：x ≥ 2。

答：x ≥ 2 时有意义。

**练习3：** 当x取何值时，1/√(x+1) 有意义？

解：

x + 1 > 0

x > -1

答：x > -1 时有意义。

**练习4：** 当x取何值时，√(x+3)/(x-1) 有意义？

解：

二次根式条件：x + 3 ≥ 0，即 x ≥ -3。

分式条件：x - 1 ≠ 0，即 x ≠ 1。

综合：x ≥ -3 且 x ≠ 1。

答：x ≥ -3 且 x ≠ 1 时有意义。

**练习5：** 当x取何值时，√(2x-4)/√(x+1) 有意义？

解：

分子：2x - 4 ≥ 0，即 x ≥ 2。

分母：x + 1 > 0，即 x > -1。

公共部分：x ≥ 2。

答：x ≥ 2 时有意义。
