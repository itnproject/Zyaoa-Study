# 16.1.1 二次根式的概念

## 一、从生活实例引入

一个正方形的面积是2。

边长是多少？

边长 = √2。

物体自由落体，下落时间t = √(2h/g)。

这些式子都带有根号。

这就是二次根式。

## 二、二次根式的定义

**二次根式：形如√a（a≥0）的式子**

√叫做二次根号。

a叫做被开方数。

**例子**

√2 是二次根式。

√x 是二次根式（x≥0）。

√(x+1) 是二次根式（x+1≥0）。

## 三、被开方数必须是非负数

**a≥0**

根号下的数不能是负数。

√(-3) 没有意义。

√(x-2) 有意义的条件：x-2≥0，即x≥2。

**为什么不能是负数**

任何实数的平方都是非负数。

没有实数的平方等于负数。

所以负数不能开平方。

## 四、√a的双重非负性

**√a≥0 且 a≥0**

第一重：被开方数a≥0。

第二重：算术平方根√a≥0。

**例子**

√4 = 2，不是-2。

√9 = 3，不是-3。

算术平方根是非负的。

## 五、区分二次根式与算术平方根

**算术平方根：√a 表示a的算术平方根**

是一个数。

√4 = 2。

**二次根式：形如√a的式子**

是一个式子。

√x 是二次根式。

**关系**

二次根式√a表示a的算术平方根。

当a是具体数字时，二次根式就是算术平方根。

## 六、例题讲解

**例题1：** 判断下列式子哪些是二次根式：√3，√(-2)，√x（x≥0），³√8

解：

√3：被开方数3≥0，是二次根式。

√(-2)：被开方数-2<0，不是二次根式。

√x（x≥0）：被开方数x≥0，是二次根式。

³√8：是三次根式，不是二次根式。

答：√3 和 √x（x≥0）是二次根式。

**例题2：** 当x取何值时，√(x-3) 有意义？

解：

被开方数≥0：

x - 3 ≥ 0

x ≥ 3

答：x ≥ 3 时有意义。

**例题3：** 当x取何值时，√(2x+4) 有意义？

解：

被开方数≥0：

2x + 4 ≥ 0

2x ≥ -4

x ≥ -2

答：x ≥ -2 时有意义。

**例题4：** 计算：√16

解：

√16 = 4

注意：不是-4。

算术平方根是非负的。

答：4。

**例题5：** 计算：√(3²)

解：

√(3²) = √9 = 3

答：3。

## 七、常见错误

**错误1：被开方数可以是负数**

错误做法：√(-4) = -2。

正确理解：√(-4) 没有意义。

**错误2：算术平方根可以是负数**

错误做法：√4 = ±2。

正确理解：√4 = 2，算术平方根是非负的。

**错误3：二次根号和根号混淆**

错误做法：³√8 是二次根式。

正确理解：³√8 是三次根式。

**错误4：忽略被开方数的条件**

错误做法：√(x-1) 对任意x都有意义。

正确理解：x-1≥0，即x≥1时才有意义。

**错误5：√a² = a**

错误做法：√((-3)²) = -3。

正确理解：√((-3)²) = √9 = 3 = |-3|。

## 八、练习题

**练习1：** 判断下列式子哪些是二次根式：√5，√(-1)，√(x²+1)，√(1-x)（x≤1）

解：

√5：被开方数5≥0，是二次根式。

√(-1)：被开方数-1<0，不是二次根式。

√(x²+1)：x²+1≥1>0，是二次根式。

√(1-x)（x≤1）：1-x≥0，是二次根式。

答：√5、√(x²+1)、√(1-x)（x≤1）是二次根式。

**练习2：** 当x取何值时，√(x+5) 有意义？

解：

x + 5 ≥ 0

x ≥ -5

答：x ≥ -5 时有意义。

**练习3：** 当x取何值时，√(3x-6) 有意义？

解：

3x - 6 ≥ 0

3x ≥ 6

x ≥ 2

答：x ≥ 2 时有意义。

**练习4：** 计算：√25

解：

√25 = 5

答：5。

**练习5：** 计算：√((-5)²)

解：

√((-5)²) = √25 = 5

答：5。
