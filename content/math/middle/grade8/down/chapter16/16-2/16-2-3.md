# 16.2.3 最简二次根式

## 一、最简二次根式的三个条件

**条件一：被开方数不含分母**

√(3/4) 不是最简二次根式。

√3/2 是最简二次根式。

**条件二：被开方数中不含能开得尽方的因数或因式**

√12 不是最简二次根式（12 = 4×3，4能开方）。

2√3 是最简二次根式。

**条件三：分母中不含根号**

1/√2 不是最简二次根式。

√2/2 是最简二次根式。

## 二、如何化为最简二次根式

**第一步：分解被开方数**

把被开方数分解质因数。

找出能开得尽方的因数。

**第二步：移出根号**

把能开得尽方的因数移出根号。

**第三步：分母有理化**

如果分母有根号，进行分母有理化。

## 三、判断一个二次根式是否最简

**三个条件都满足才是最简**

检查被开方数是否含分母。

检查被开方数是否有能开方的因数。

检查分母是否含根号。

## 四、例题讲解

**例题1：** 化简：√50

解：

√50 = √(25×2) = 5√2

5√2 是最简二次根式。

答：5√2。

**例题2：** 化简：√(3/8)

解：

√(3/8) = √3/√8 = √3/(2√2) = √6/4

答：√6/4。

**例题3：** 化简：√(12x³)（x≥0）

解：

√(12x³) = √(4×3×x²×x) = 2x√(3x)

答：2x√(3x)。

**例题4：** 判断：√18 是不是最简二次根式？

解：

√18 = √(9×2) = 3√2

被开方数18含有能开得尽方的因数9。

不是最简二次根式。

答：不是，化简后为3√2。

**例题5：** 化简：3/√12

解：

3/√12 = 3/(2√3) = 3√3/(2×3) = √3/2

答：√3/2。

## 五、常见错误

**错误1：没有分解彻底**

错误做法：√12 = √(4×3) = 2√3（这个对了）。

错误做法：√72 = √(36×2) = 6√2（这个对了）。

错误做法：√72 = √(4×18) = 2√18。

正确理解：2√18 = 2×3√2 = 6√2。

**错误2：分母有理化漏乘**

错误做法：2/√3 = √3/3。

正确理解：2/√3 = 2√3/3。

**错误3：含字母时处理错误**

错误做法：√(x³) = x√x（x可以是负数）。

正确理解：√(x³) = x√x（x≥0）。

**错误4：判断错误**

错误做法：√7 不是最简二次根式。

正确理解：7不含能开方的因数，√7是最简二次根式。

**错误5：化简后不是最简**

错误做法：√20 = 2√5（这个对了）。

错误做法：√20 = √(4×5) 不继续化简。

正确理解：√20 = 2√5。

## 六、练习题

**练习1：** 化简：√75

解：

√75 = √(25×3) = 5√3

答：5√3。

**练习2：** 化简：√(2/3)

解：

√(2/3) = √2/√3 = √6/3

答：√6/3。

**练习3：** 化简：√(8x²)（x≥0）

解：

√(8x²) = √(4×2×x²) = 2x√2

答：2x√2。

**练习4：** 判断：√21 是不是最简二次根式？

解：

21 = 3×7

不含能开得尽方的因数。

是最简二次根式。

答：是。

**练习5：** 化简：5/√20

解：

5/√20 = 5/(2√5) = 5√5/(2×5) = √5/2

答：√5/2。
