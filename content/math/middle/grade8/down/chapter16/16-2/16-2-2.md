# 16.2.2 二次根式的除法

## 一、除法法则

**法则：√a/√b = √(a/b)（a≥0，b>0）**

两个二次根式相除。

把被开方数相除。

根号不变。

**例子**

√8/√2 = √4 = 2

√12/√3 = √4 = 2

## 二、分母有理化

**概念：去掉分母中的根号**

1/√2 = √2/2

3/√5 = 3√5/5

**方法**

分子分母同乘分母的根号。

## 三、分母有理化的方法

**分子分母同乘分母的有理化因式**

1/√a = √a/a

b/√a = b√a/a

**例子**

2/√3 = 2√3/3

5/√7 = 5√7/7

## 四、最简二次根式的条件

**三个条件**

第一，被开方数不含分母。

第二，被开方数中不含能开得尽方的因数。

第三，分母中不含根号。

## 五、例题讲解

**例题1：** 计算：√18/√2

解：

√18/√2 = √(18/2) = √9 = 3

答：3。

**例题2：** 计算：√50/√8

解：

√50/√8 = √(50/8) = √(25/4) = 5/2

答：5/2。

**例题3：** 计算：6/√3

解：

6/√3 = 6√3/3 = 2√3

答：2√3。

**例题4：** 计算：√12/√27

解：

√12/√27 = √(12/27) = √(4/9) = 2/3

答：2/3。

**例题5：** 计算：(3√2)/(2√6)

解：

(3√2)/(2√6) = 3/2 × √2/√6 = 3/2 × √(2/6) = 3/2 × √(1/3) = 3/2 × √3/3 = √3/2

答：√3/2。

## 六、常见错误

**错误1：被开方数相减而不是相除**

错误做法：√8/√2 = √6。

正确理解：√8/√2 = √4 = 2。

**错误2：分母有理化时漏乘分子**

错误做法：3/√2 = 1/√2 × √2 = √2/2。

正确理解：3/√2 = 3√2/2。

**错误3：结果不是最简**

错误做法：√8/√2 = √4 = 2（这个对了）。

错误做法：√12/√3 = √4 = 2（这个对了）。

**错误4：b=0时也除**

错误做法：√5/√0。

正确理解：分母不能为0。

**错误5：系数处理错误**

错误做法：(2√6)/(3√2) = 2/3 × √3（这个对了）。

错误做法：(2√6)/(3√2) = 2/3 × √8。

正确理解：√6/√2 = √3。

## 七、练习题

**练习1：** 计算：√32/√2

解：

√32/√2 = √16 = 4

答：4。

**练习2：** 计算：√45/√5

解：

√45/√5 = √9 = 3

答：3。

**练习3：** 计算：8/√2

解：

8/√2 = 8√2/2 = 4√2

答：4√2。

**练习4：** 计算：√20/√45

解：

√20/√45 = √(20/45) = √(4/9) = 2/3

答：2/3。

**练习5：** 计算：(4√3)/(2√12)

解：

(4√3)/(2√12) = 2 × √3/√12 = 2 × √(3/12) = 2 × √(1/4) = 2 × 1/2 = 1

答：1。
