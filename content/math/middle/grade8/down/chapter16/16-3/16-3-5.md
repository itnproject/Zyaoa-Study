# 16.3.5 二次根式的化简求值

## 一、先化简代数式，再代入求值

**不要直接代入**

先化简代数式。

再代入数值计算。

这样计算更简单。

**例子**

已知x = √2 + 1，求x² - 2x。

直接代入：(√2+1)² - 2(√2+1) = 3+2√2 - 2√2 - 2 = 1。

先化简：x² - 2x = x(x-2)。

代入：(√2+1)(√2+1-2) = (√2+1)(√2-1) = 2-1 = 1。

## 二、利用完全平方公式和平方差公式

**完全平方公式**

(a+b)² = a² + 2ab + b²

(a-b)² = a² - 2ab + b²

**平方差公式**

(a+b)(a-b) = a² - b²

**在二次根式中的应用**

(√a + √b)² = a + 2√ab + b

(√a + √b)(√a - √b) = a - b

## 三、整体代入的技巧

**已知条件整体代入**

已知x = √3 + √2。

求x²。

x² = (√3 + √2)² = 3 + 2√6 + 2 = 5 + 2√6。

**已知x + 1/x = a**

求x² + 1/x²。

x² + 1/x² = (x + 1/x)² - 2 = a² - 2。

## 四、已知条件为根式时的处理方法

**已知x = √a + √b**

求x²：x² = a + b + 2√ab

求x² - 2(a+b)x：化简后代入

**已知x = √a - √b**

求x²：x² = a + b - 2√ab

## 五、例题讲解

**例题1：** 已知x = √3 + 1，求x² - 2x的值。

解：

x² - 2x = x(x-2)

= (√3+1)(√3+1-2)

= (√3+1)(√3-1)

= 3 - 1

= 2

答：2。

**例题2：** 已知x = √5 + √3，y = √5 - √3，求x² + y²的值。

解：

x² = (√5+√3)² = 5 + 2√15 + 3 = 8 + 2√15

y² = (√5-√3)² = 5 - 2√15 + 3 = 8 - 2√15

x² + y² = (8+2√15) + (8-2√15) = 16

答：16。

**例题3：** 已知x = √2 + 1，求x² - 2x - 1的值。

解：

x² = (√2+1)² = 2 + 2√2 + 1 = 3 + 2√2

x² - 2x - 1 = (3+2√2) - 2(√2+1) - 1

= 3 + 2√2 - 2√2 - 2 - 1

= 0

答：0。

**例题4：** 已知x = √7 + 2，求x + 1/x的值。

解：

1/x = 1/(√7+2) = (√7-2)/(7-4) = (√7-2)/3

x + 1/x = (√7+2) + (√7-2)/3

= (3√7+6+√7-2)/3

= (4√7+4)/3

答：(4√7+4)/3。

**例题5：** 已知x = √3 + √2，求x² - 2√6的值。

解：

x² = (√3+√2)² = 3 + 2√6 + 2 = 5 + 2√6

x² - 2√6 = (5+2√6) - 2√6 = 5

答：5。

## 六、常见错误

**错误1：直接代入不化简**

错误做法：直接代入计算，计算量大容易出错。

正确理解：先化简再代入。

**错误2：完全平方公式用错**

错误做法：(√a + √b)² = a + b。

正确理解：(√a + √b)² = a + 2√ab + b。

**错误3：分母有理化错误**

错误做法：1/(√a+√b) = 1/√a + 1/√b。

正确理解：1/(√a+√b) = (√a-√b)/(a-b)。

**错误4：符号搞错**

错误做法：(√a - √b)² = a + 2√ab + b。

正确理解：(√a - √b)² = a - 2√ab + b。

**错误5：整体代入时搞错**

错误做法：已知x = √2+1，求x²-2x时算成(√2+1)²-2 = 3+2√2-2。

正确理解：x²-2x = (√2+1)²-2(√2+1)。

## 七、练习题

**练习1：** 已知x = √2 + 1，求x²的值。

解：

x² = (√2+1)² = 2 + 2√2 + 1 = 3 + 2√2

答：3 + 2√2。

**练习2：** 已知x = √5 + 1，求x² - 2x的值。

解：

x² - 2x = x(x-2)

= (√5+1)(√5+1-2)

= (√5+1)(√5-1)

= 5 - 1

= 4

答：4。

**练习3：** 已知x = √3 + √2，y = √3 - √2，求xy的值。

解：

xy = (√3+√2)(√3-√2) = 3 - 2 = 1

答：1。

**练习4：** 已知x = √6 + √5，求x² - 2√30的值。

解：

x² = (√6+√5)² = 6 + 2√30 + 5 = 11 + 2√30

x² - 2√30 = 11 + 2√30 - 2√30 = 11

答：11。

**练习5：** 已知x = √7 + √3，求x² + 1/x²的值（提示：先求x²）。

解：

x² = (√7+√3)² = 7 + 2√21 + 3 = 10 + 2√21

1/x² = 1/(10+2√21) = (10-2√21)/(100-84) = (10-2√21)/16

x² + 1/x² = (10+2√21) + (10-2√21)/16

= (160+32√21+10-2√21)/16

= (170+30√21)/16

= (85+15√21)/8

答：(85+15√21)/8。
