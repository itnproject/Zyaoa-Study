# 16.3.2 二次根式的加减法

## 一、法则

**先化简，再合并同类二次根式**

第一步：把每个二次根式化为最简二次根式。

第二步：找出同类二次根式。

第三步：合并同类二次根式。

## 二、合并方法

**系数相加减，根号部分不变**

2√3 + 5√3 = 7√3

4√2 - √2 = 3√2

**类比合并同类项**

2x + 5x = 7x

2√3 + 5√3 = 7√3

## 三、不能合并的保留不动

**不是同类二次根式不能合并**

√2 + √3 不能合并。

2√3 + 3√5 不能合并。

保留原样即可。

## 四、类比合并同类项来理解

**合并同类项：2x + 3x = 5x**

系数相加，字母部分不变。

**合并同类二次根式：2√3 + 3√3 = 5√3**

系数相加，根号部分不变。

**不同类不能合并**

2x + 3y 不能合并。

2√3 + 3√5 不能合并。

## 五、例题讲解

**例题1：** 计算：2√3 + 5√3

解：

2√3 + 5√3 = (2+5)√3 = 7√3

答：7√3。

**例题2：** 计算：√12 + √27

解：

√12 = 2√3

√27 = 3√3

2√3 + 3√3 = 5√3

答：5√3。

**例题3：** 计算：3√8 - 2√18

解：

√8 = 2√2

√18 = 3√2

3×2√2 - 2×3√2 = 6√2 - 6√2 = 0

答：0。

**例题4：** 计算：√2 + √3 + √8

解：

√8 = 2√2

√2 + √3 + 2√2 = 3√2 + √3

答：3√2 + √3。

**例题5：** 计算：(√50 + √8) - (√18 + √2)

解：

√50 = 5√2

√8 = 2√2

√18 = 3√2

(5√2 + 2√2) - (3√2 + √2) = 7√2 - 4√2 = 3√2

答：3√2。

## 六、常见错误

**错误1：没有先化简就合并**

错误做法：√12 + √27 = √39。

正确理解：√12 + √27 = 2√3 + 3√3 = 5√3。

**错误2：不同类也合并**

错误做法：√2 + √3 = √5。

正确理解：不能合并。

**错误3：根号也相加减**

错误做法：2√3 + 3√3 = 5√6。

正确理解：2√3 + 3√3 = 5√3。

**错误4：符号搞错**

错误做法：3√2 - 2√2 = √2（这个对了）。

错误做法：3√2 - 5√2 = 2√2。

正确理解：3√2 - 5√2 = -2√2。

**错误5：括号展开时符号搞错**

错误做法：(√8 + √2) - (√18 - √2) = √8 + √2 - √18 - √2。

正确理解：(√8 + √2) - (√18 - √2) = √8 + √2 - √18 + √2。

## 七、练习题

**练习1：** 计算：4√5 - 2√5

解：

4√5 - 2√5 = 2√5

答：2√5。

**练习2：** 计算：√20 + √45

解：

√20 = 2√5

√45 = 3√5

2√5 + 3√5 = 5√5

答：5√5。

**练习3：** 计算：3√12 - √27

解：

√12 = 2√3

√27 = 3√3

3×2√3 - 3√3 = 6√3 - 3√3 = 3√3

答：3√3。

**练习4：** 计算：√2 + √3 + √18

解：

√18 = 3√2

√2 + √3 + 3√2 = 4√2 + √3

答：4√2 + √3。

**练习5：** 计算：(√32 - √8) + (√18 - √2)

解：

√32 = 4√2

√8 = 2√2

√18 = 3√2

(4√2 - 2√2) + (3√2 - √2) = 2√2 + 2√2 = 4√2

答：4√2。
