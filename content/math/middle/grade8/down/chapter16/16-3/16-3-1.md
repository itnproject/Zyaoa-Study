# 16.3.1 同类二次根式

## 一、同类二次根式的定义

**同类二次根式：化成最简二次根式后，被开方数相同的二次根式**

和同类项类似。

2x 和 3x 是同类项。

2√3 和 3√3 是同类二次根式。

**例子**

√2 和 3√2 是同类二次根式。

√8 和 √2 是同类二次根式（√8 = 2√2）。

## 二、判断方法

**先化简，再看被开方数**

第一步：把每个二次根式化为最简二次根式。

第二步：比较被开方数是否相同。

相同就是同类二次根式。

不同就不是同类二次根式。

## 三、同类二次根式可以合并

**合并方法：系数相加减，根号部分不变**

2√3 + 3√3 = 5√3

5√2 - 2√2 = 3√2

**类比合并同类项**

2x + 3x = 5x

2√3 + 3√3 = 5√3

## 四、例题讲解

**例题1：** 判断：√2 和 √8 是不是同类二次根式？

解：

√2 已经是最简。

√8 = 2√2。

化简后被开方数都是2。

是同类二次根式。

答：是。

**例题2：** 判断：√3 和 √12 是不是同类二次根式？

解：

√3 已经是最简。

√12 = 2√3。

化简后被开方数都是3。

是同类二次根式。

答：是。

**例题3：** 判断：√2 和 √3 是不是同类二次根式？

解：

√2 和 √3 都是最简。

被开方数不同。

不是同类二次根式。

答：不是。

**例题4：** 计算：2√5 + 3√5

解：

2√5 + 3√5 = (2+3)√5 = 5√5

答：5√5。

**例题5：** 计算：√18 + √8

解：

√18 = 3√2

√8 = 2√2

3√2 + 2√2 = 5√2

答：5√2。

## 五、常见错误

**错误1：没有先化简就判断**

错误做法：√2 和 √8 被开方数不同，不是同类。

正确理解：√8 = 2√2，是同类。

**错误2：被开方数不同也合并**

错误做法：√2 + √3 = √5。

正确理解：√2 和 √3 不是同类，不能合并。

**错误3：合并时根号也相加**

错误做法：2√3 + 3√3 = 5√6。

正确理解：2√3 + 3√3 = 5√3。

**错误4：化简错误导致判断错误**

错误做法：√12 = √(4×3) = 4√3。

正确理解：√12 = 2√3。

**错误5：系数和根号混在一起**

错误做法：2√3 + 3√2 = 5√5。

正确理解：不能合并。
