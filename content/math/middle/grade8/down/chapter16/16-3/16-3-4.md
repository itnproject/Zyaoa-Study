# 16.3.4 分母有理化

## 一、分母有理化的定义

**分母有理化：把分母中的根号化去**

使分母变成有理数。

1/√2 = √2/2

3/√5 = 3√5/5

## 二、有理化因式

**乘积不含根号的两个因式互为有理化因式**

√a 和 √a 互为有理化因式。

√a × √a = a

(√a + √b) 和 (√a - √b) 互为有理化因式。

(√a + √b)(√a - √b) = a - b

## 三、单根号分母

**分子分母同乘分母本身**

1/√a = √a/a

b/√a = b√a/a

**例子**

3/√7 = 3√7/7

2/√3 = 2√3/3

## 四、双根号分母（和差型）

**分子分母同乘分母的共轭式**

1/(√a + √b) = (√a - √b)/(a - b)

1/(√a - √b) = (√a + √b)/(a - b)

**例子**

1/(√3 + √2) = (√3 - √2)/(3 - 2) = √3 - √2

2/(√5 - √3) = 2(√5 + √3)/(5 - 3) = √5 + √3

## 五、例题讲解

**例题1：** 分母有理化：3/√6

解：

3/√6 = 3√6/6 = √6/2

答：√6/2。

**例题2：** 分母有理化：1/(√3 + √2)

解：

1/(√3 + √2) = (√3 - √2)/[(√3 + √2)(√3 - √2)]

= (√3 - √2)/(3 - 2)

= √3 - √2

答：√3 - √2。

**例题3：** 分母有理化：2/(√5 - √3)

解：

2/(√5 - √3) = 2(√5 + √3)/[(√5 - √3)(√5 + √3)]

= 2(√5 + √3)/(5 - 3)

= 2(√5 + √3)/2

= √5 + √3

答：√5 + √3。

**例题4：** 分母有理化：(√2 + 1)/(√2 - 1)

解：

(√2 + 1)/(√2 - 1) = (√2 + 1)(√2 + 1)/[(√2 - 1)(√2 + 1)]

= (√2 + 1)²/(2 - 1)

= (2 + 2√2 + 1)/1

= 3 + 2√2

答：3 + 2√2。

**例题5：** 分母有理化：√3/(√3 + √6)

解：

√3/(√3 + √6) = √3(√3 - √6)/[(√3 + √6)(√3 - √6)]

= (3 - √18)/(3 - 6)

= (3 - 3√2)/(-3)

= -1 + √2

= √2 - 1

答：√2 - 1。

## 六、常见错误

**错误1：单根号分母只乘分子**

错误做法：3/√2 = 3√2。

正确理解：3/√2 = 3√2/2。

**错误2：共轭式找错**

错误做法：1/(√3 + √2) 的共轭式是 √3 + √2。

正确理解：共轭式是 √3 - √2。

**错误3：分母展开错误**

错误做法：(√3 + √2)(√3 - √2) = 3 + 2 = 5。

正确理解：(√3 + √2)(√3 - √2) = 3 - 2 = 1。

**错误4：分子展开错误**

错误做法：(√2 + 1)² = 2 + 1 = 3。

正确理解：(√2 + 1)² = 2 + 2√2 + 1 = 3 + 2√2。

**错误5：化简不彻底**

错误做法：3/√6 = 3√6/6 不化简。

正确理解：3√6/6 = √6/2。

## 七、练习题

**练习1：** 分母有理化：5/√10

解：

5/√10 = 5√10/10 = √10/2

答：√10/2。

**练习2：** 分母有理化：1/(√5 - √3)

解：

1/(√5 - √3) = (√5 + √3)/[(√5 - √3)(√5 + √3)]

= (√5 + √3)/(5 - 3)

= (√5 + √3)/2

答：(√5 + √3)/2。

**练习3：** 分母有理化：3/(√7 + 2)

解：

3/(√7 + 2) = 3(√7 - 2)/[(√7 + 2)(√7 - 2)]

= 3(√7 - 2)/(7 - 4)

= 3(√7 - 2)/3

= √7 - 2

答：√7 - 2。

**练习4：** 分母有理化：(√3 - 1)/(√3 + 1)

解：

(√3 - 1)/(√3 + 1) = (√3 - 1)²/[(√3 + 1)(√3 - 1)]

= (3 - 2√3 + 1)/(3 - 1)

= (4 - 2√3)/2

= 2 - √3

答：2 - √3。

**练习5：** 分母有理化：√2/(√2 + √8)

解：

√8 = 2√2

√2/(√2 + 2√2) = √2/(3√2) = 1/3

答：1/3。
