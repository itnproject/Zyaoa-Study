# 16.3.3 二次根式的混合运算

## 一、运算顺序

**先乘方开方，再乘除，最后加减**

**有括号先算括号里的**

**同级运算从左到右**

和整式的运算顺序完全一样。

## 二、乘法公式在二次根式中的应用

**完全平方公式**

(√a + √b)² = a + 2√ab + b

(√a - √b)² = a - 2√ab + b

**平方差公式**

(√a + √b)(√a - √b) = a - b

## 三、运算结果要化为最简二次根式

**计算完后要检查**

能化简的要化简。

结果是最简二次根式。

## 四、例题讲解

**例题1：** 计算：(√3 + √2)(√3 - √2)

解：

用平方差公式：

(√3 + √2)(√3 - √2) = (√3)² - (√2)² = 3 - 2 = 1

答：1。

**例题2：** 计算：(√5 + √3)²

解：

用完全平方公式：

(√5 + √3)² = (√5)² + 2√5·√3 + (√3)² = 5 + 2√15 + 3 = 8 + 2√15

答：8 + 2√15。

**例题3：** 计算：√2 × √6 + √3 × √12

解：

√2 × √6 = √12 = 2√3

√3 × √12 = √36 = 6

2√3 + 6

答：2√3 + 6。

**例题4：** 计算：(2√3 + √6) ÷ √3

解：

(2√3 + √6) ÷ √3 = 2√3/√3 + √6/√3 = 2 + √2

答：2 + √2。

**例题5：** 计算：(√2 + 1)² - (√2 - 1)²

解：

(√2 + 1)² = 2 + 2√2 + 1 = 3 + 2√2

(√2 - 1)² = 2 - 2√2 + 1 = 3 - 2√2

(3 + 2√2) - (3 - 2√2) = 4√2

答：4√2。

## 五、常见错误

**错误1：运算顺序搞错**

错误做法：先加减再乘除。

正确理解：先乘方开方，再乘除，最后加减。

**错误2：完全平方公式用错**

错误做法：(√a + √b)² = a + b。

正确理解：(√a + √b)² = a + 2√ab + b。

**错误3：平方差公式用错**

错误做法：(√a + √b)(√a - √b) = a + b。

正确理解：(√a + √b)(√a - √b) = a - b。

**错误4：结果没有化简**

错误做法：√2 × √8 = √16 = 4（这个对了）。

错误做法：√2 × √6 = √12 不化简。

正确理解：√12 = 2√3。

**错误5：分配律用错**

错误做法：√2(√3 + √5) = √6 + √5。

正确理解：√2(√3 + √5) = √6 + √10。

## 六、练习题

**练习1：** 计算：(√7 + √3)(√7 - √3)

解：

(√7)² - (√3)² = 7 - 3 = 4

答：4。

**练习2：** 计算：(√6 - √2)²

解：

(√6)² - 2√6·√2 + (√2)² = 6 - 2√12 + 2 = 8 - 4√3

答：8 - 4√3。

**练习3：** 计算：√3 × √15 - √5 × √12

解：

√3 × √15 = √45 = 3√5

√5 × √12 = √60 = 2√15

3√5 - 2√15

答：3√5 - 2√15。

**练习4：** 计算：(3√2 - √8) × √2

解：

√8 = 2√2

(3√2 - 2√2) × √2 = √2 × √2 = 2

答：2。

**练习5：** 计算：(√3 + 2)² - (√3 - 2)²

解：

(√3 + 2)² = 3 + 4√3 + 4 = 7 + 4√3

(√3 - 2)² = 3 - 4√3 + 4 = 7 - 4√3

(7 + 4√3) - (7 - 4√3) = 8√3

答：8√3。
