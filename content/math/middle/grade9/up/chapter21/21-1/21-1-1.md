# 21.1.1 一元二次方程的定义

## 一、从生活实例引入

**正方形面积问题**

一个正方形的面积是$25\text{cm}^2$，求它的边长。

设边长为$x$cm。

正方形面积公式：边长的平方。

列方程：$x^2 = 25$。

解得：$x = 5$（边长为正数）。

**矩形面积问题**

一个矩形的长比宽多$3$cm，面积是$40\text{cm}^2$，求宽是多少。

设宽为$x$cm，则长为$(x+3)$cm。

矩形面积公式：长乘以宽。

列方程：$x(x+3) = 40$。

展开：$x^2 + 3x = 40$。

移项：$x^2 + 3x - 40 = 0$。

这就是一个一元二次方程。

## 二、一元二次方程的定义

**只含一个未知数，未知数的最高次数是$2$的整式方程**

"一元"：只含一个未知数。

"二次"：未知数的最高次数是$2$。

"整式"：方程两边都是整式（不含分母中有未知数的情况）。

**判断标准**

1. 只含一个未知数。
2. 未知数的最高次数是$2$。
3. 方程两边都是整式。

**例子**

$x^2 + 3x - 4 = 0$：一元二次方程。

$2x^2 - 5 = 0$：一元二次方程。

$x^2 + x = x^2 + 3$：化简后是$x = 3$，是一元一次方程。

## 三、一般形式

**$ax^2 + bx + c = 0$（$a \neq 0$）**

$a$是二次项系数。

$b$是一次项系数。

$c$是常数项。

$a \neq 0$是必须的，否则就不是二次方程了。

**各项的名称**

$ax^2$：二次项。

$bx$：一次项。

$c$：常数项。

$a$：二次项系数。

$b$：一次项系数。

**例子**

$3x^2 - 5x + 2 = 0$：

二次项是$3x^2$，二次项系数是$3$。

一次项是$-5x$，一次项系数是$-5$。

常数项是$2$。

## 四、将方程化为一般形式

**步骤：去括号→移项→合并同类项**

**例题1：** 将$x(x+3) = 40$化为一般形式。

解：

去括号：$x^2 + 3x = 40$。

移项：$x^2 + 3x - 40 = 0$。

答：一般形式是$x^2 + 3x - 40 = 0$，其中$a=1$，$b=3$，$c=-40$。

**例题2：** 将$2x^2 = 5x - 3$化为一般形式。

解：

移项：$2x^2 - 5x + 3 = 0$。

答：一般形式是$2x^2 - 5x + 3 = 0$，其中$a=2$，$b=-5$，$c=3$。

**例题3：** 将$(x+1)^2 = 2x + 5$化为一般形式。

解：

展开左边：$x^2 + 2x + 1 = 2x + 5$。

移项：$x^2 + 2x - 2x + 1 - 5 = 0$。

合并：$x^2 - 4 = 0$。

答：一般形式是$x^2 - 4 = 0$，其中$a=1$，$b=0$，$c=-4$。

**例题4：** 将$3x(x-2) = 4 - x$化为一般形式。

解：

展开左边：$3x^2 - 6x = 4 - x$。

移项：$3x^2 - 6x + x - 4 = 0$。

合并：$3x^2 - 5x - 4 = 0$。

答：一般形式是$3x^2 - 5x - 4 = 0$，其中$a=3$，$b=-5$，$c=-4$。

**例题5：** 将$\frac{x^2}{2} - x = 3$化为一般形式。

解：

两边乘以$2$：$x^2 - 2x = 6$。

移项：$x^2 - 2x - 6 = 0$。

答：一般形式是$x^2 - 2x - 6 = 0$，其中$a=1$，$b=-2$，$c=-6$。

## 五、判断一个方程是否为一元二次方程

**例题1：** 判断$x^2 + 3x = 5$是否为一元二次方程。

解：

只含一个未知数$x$。

最高次数是$2$。

是整式方程。

答：是一元二次方程。

**例题2：** 判断$\frac{1}{x} + x = 2$是否为一元二次方程。

解：

分母中有未知数$x$。

不是整式方程。

答：不是一元二次方程。

**例题3：** 判断$x^3 + x^2 = 1$是否为一元二次方程。

解：

最高次数是$3$。

不是二次方程。

答：不是一元二次方程。

**例题4：** 判断$2x^2 - 3 = 0$是否为一元二次方程。

解：

只含一个未知数$x$。

最高次数是$2$。

是整式方程。

答：是一元二次方程。

**例题5：** 判断$(x+1)(x-1) = x^2$是否为一元二次方程。

解：

展开左边：$x^2 - 1 = x^2$。

化简：$-1 = 0$。

化简后不含未知数。

答：不是一元二次方程。

## 六、常见错误

**错误1：忘记$a \neq 0$的条件**

错误理解：$0x^2 + 3x - 2 = 0$是一元二次方程。

正确理解：$a$不能为$0$，否则是一次方程。

**错误2：没有化简就判断**

错误做法：$(x+1)^2 = x^2 + 2x + 1$是二次方程。

正确理解：化简后可能消去二次项。

**错误3：混淆各项系数**

错误做法：$3x^2 - 5x + 2 = 0$的一次项系数是$5$。

正确理解：一次项系数是$-5$（带符号）。

**错误4：分母有未知数也认为是二次方程**

错误做法：$\frac{1}{x} + x = 2$是一元二次方程。

正确理解：分母有未知数，不是整式方程。

**错误5：多未知数也认为是一元二次方程**

错误做法：$x^2 + y = 3$是一元二次方程。

正确理解：含有两个未知数，不是一元方程。

## 七、练习题

**练习1：** 将$x(x-4) = 12$化为一般形式，并指出$a$、$b$、$c$的值。

解：

去括号：$x^2 - 4x = 12$。

移项：$x^2 - 4x - 12 = 0$。

答：一般形式是$x^2 - 4x - 12 = 0$，$a=1$，$b=-4$，$c=-12$。

**练习2：** 判断$2x^2 + \frac{1}{x} = 3$是否为一元二次方程。

解：

分母中有未知数$x$。

不是整式方程。

答：不是一元二次方程。

**练习3：** 将$(2x+1)(x-3) = 5$化为一般形式。

解：

展开左边：$2x^2 - 6x + x - 3 = 5$。

合并：$2x^2 - 5x - 3 = 5$。

移项：$2x^2 - 5x - 8 = 0$。

答：一般形式是$2x^2 - 5x - 8 = 0$，$a=2$，$b=-5$，$c=-8$。

**练习4：** 已知方程$(m-1)x^2 + 3x - 2 = 0$是一元二次方程，求$m$的取值范围。

解：

一元二次方程要求二次项系数不为$0$。

即$m-1 \neq 0$。

解得：$m \neq 1$。

答：$m \neq 1$。

**练习5：** 将$\frac{x^2-1}{3} = x$化为一般形式。

解：

两边乘以$3$：$x^2 - 1 = 3x$。

移项：$x^2 - 3x - 1 = 0$。

答：一般形式是$x^2 - 3x - 1 = 0$，$a=1$，$b=-3$，$c=-1$。
