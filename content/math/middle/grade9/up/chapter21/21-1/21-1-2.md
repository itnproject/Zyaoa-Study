# 21.1.2 一元二次方程的解

## 一、方程的解（根）的定义

**使方程左右两边相等的未知数的值**

把未知数的值代入方程。

如果左边等于右边，这个值就是方程的解。

方程的解也叫方程的根。

**例子**

$x^2 = 9$，$x = 3$时，左边$= 9$，右边$= 9$。

所以$x = 3$是方程的解。

同样，$x = -3$也是方程的解。

## 二、代入验证法

**把数值代入方程，检验左右两边是否相等**

**例题1：** 判断$x = 2$是否是方程$x^2 - 3x + 2 = 0$的根。

解：

代入$x = 2$：

左边$= 2^2 - 3 \times 2 + 2 = 4 - 6 + 2 = 0$。

右边$= 0$。

左边等于右边。

答：$x = 2$是方程的根。

**例题2：** 判断$x = 1$是否是方程$x^2 + x - 6 = 0$的根。

解：

代入$x = 1$：

左边$= 1^2 + 1 - 6 = 1 + 1 - 6 = -4$。

右边$= 0$。

左边不等于右边。

答：$x = 1$不是方程的根。

**例题3：** 判断$x = -3$是否是方程$x^2 + 5x + 6 = 0$的根。

解：

代入$x = -3$：

左边$= (-3)^2 + 5 \times (-3) + 6 = 9 - 15 + 6 = 0$。

右边$= 0$。

左边等于右边。

答：$x = -3$是方程的根。

**例题4：** 判断$x = 0$是否是方程$2x^2 - 3x = 0$的根。

解：

代入$x = 0$：

左边$= 2 \times 0^2 - 3 \times 0 = 0$。

右边$= 0$。

左边等于右边。

答：$x = 0$是方程的根。

**例题5：** 判断$x = 4$是否是方程$x^2 - 16 = 0$的根。

解：

代入$x = 4$：

左边$= 4^2 - 16 = 16 - 16 = 0$。

右边$= 0$。

左边等于右边。

答：$x = 4$是方程的根。

## 三、已知根求参数的值

**把根代入方程，解出参数**

**例题1：** 已知$x = 2$是方程$x^2 + mx - 6 = 0$的根，求$m$的值。

解：

代入$x = 2$：

$2^2 + 2m - 6 = 0$。

$4 + 2m - 6 = 0$。

$2m - 2 = 0$。

$2m = 2$。

$m = 1$。

答：$m = 1$。

**例题2：** 已知$x = -1$是方程$2x^2 - kx + 3 = 0$的根，求$k$的值。

解：

代入$x = -1$：

$2 \times (-1)^2 - k \times (-1) + 3 = 0$。

$2 + k + 3 = 0$。

$k + 5 = 0$。

$k = -5$。

答：$k = -5$。

**例题3：** 已知$x = 3$是方程$x^2 - ax + 6 = 0$的根，求$a$的值。

解：

代入$x = 3$：

$3^2 - 3a + 6 = 0$。

$9 - 3a + 6 = 0$。

$15 - 3a = 0$。

$3a = 15$。

$a = 5$。

答：$a = 5$。

**例题4：** 已知$x = 1$和$x = 2$都是方程$x^2 + bx + c = 0$的根，求$b$和$c$的值。

解：

代入$x = 1$：$1 + b + c = 0$，即$b + c = -1$。

代入$x = 2$：$4 + 2b + c = 0$，即$2b + c = -4$。

两式相减：$(2b + c) - (b + c) = -4 - (-1)$。

$b = -3$。

代入$b + c = -1$：$-3 + c = -1$。

$c = 2$。

答：$b = -3$，$c = 2$。

**例题5：** 已知$x = -2$是方程$mx^2 + 3x - 2 = 0$的根，求$m$的值。

解：

代入$x = -2$：

$m \times (-2)^2 + 3 \times (-2) - 2 = 0$。

$4m - 6 - 2 = 0$。

$4m - 8 = 0$。

$4m = 8$。

$m = 2$。

答：$m = 2$。

## 四、一元二次方程可能有两个根

**一元二次方程最多有两个实数根**

**例子**

$x^2 - 5x + 6 = 0$。

代入$x = 2$：$4 - 10 + 6 = 0$，成立。

代入$x = 3$：$9 - 15 + 6 = 0$，成立。

所以方程有两个根：$x_1 = 2$，$x_2 = 3$。

**根的情况**

可能有两个不相等的实数根。

可能有两个相等的实数根（重根）。

可能没有实数根。

## 五、常见错误

**错误1：代入负数时忘记加括号**

错误做法：$x = -2$代入$x^2$，算成$-2^2 = -4$。

正确做法：$(-2)^2 = 4$。

**错误2：只验证一个根就下结论**

错误做法：验证$x = 2$是根，就说只有这一个根。

正确理解：一元二次方程可能有两个根。

**错误3：已知根求参数时计算错误**

错误做法：$2^2 + 2m - 6 = 0$，算成$4 + 2m = 6$，$m = 1$（碰巧对了但过程错）。

正确做法：$4 + 2m - 6 = 0$，$2m = 2$，$m = 1$。

**错误4：忘记检验所有给定的根**

错误做法：已知两个根，只代入一个。

正确做法：两个根都要代入验证。

**错误5：符号错误**

错误做法：$x = -1$代入$-kx$，算成$-k$。

正确做法：$-k \times (-1) = k$。

## 六、练习题

**练习1：** 判断$x = 3$是否是方程$x^2 - 4x + 3 = 0$的根。

解：

代入$x = 3$：

左边$= 3^2 - 4 \times 3 + 3 = 9 - 12 + 3 = 0$。

右边$= 0$。

答：$x = 3$是方程的根。

**练习2：** 已知$x = 1$是方程$x^2 + mx - 2 = 0$的根，求$m$的值。

解：

代入$x = 1$：

$1 + m - 2 = 0$。

$m - 1 = 0$。

$m = 1$。

答：$m = 1$。

**练习3：** 判断$x = -2$和$x = 4$是否都是方程$x^2 - 2x - 8 = 0$的根。

解：

代入$x = -2$：$4 + 4 - 8 = 0$，成立。

代入$x = 4$：$16 - 8 - 8 = 0$，成立。

答：两个都是方程的根。

**练习4：** 已知$x = 2$是方程$3x^2 - kx + 4 = 0$的根，求$k$的值。

解：

代入$x = 2$：

$3 \times 4 - 2k + 4 = 0$。

$12 - 2k + 4 = 0$。

$16 - 2k = 0$。

$2k = 16$。

$k = 8$。

答：$k = 8$。

**练习5：** 验证$x = 1$和$x = -5$是否是方程$x^2 + 4x - 5 = 0$的根。

解：

代入$x = 1$：$1 + 4 - 5 = 0$，成立。

代入$x = -5$：$25 - 20 - 5 = 0$，成立。

答：两个都是方程的根。
