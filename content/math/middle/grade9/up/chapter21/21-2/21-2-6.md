# 21.2.6 根与系数的关系（韦达定理）

## 一、韦达定理

**$x_1+x_2=-\frac{b}{a}$，$x_1 \cdot x_2=\frac{c}{a}$**

一元二次方程$ax^2+bx+c=0$（$a \neq 0$）的两个根为$x_1$、$x_2$。

两根之和等于一次项系数除以二次项系数的相反数。

两根之积等于常数项除以二次项系数。

## 二、用求根公式推导韦达定理

**推导两根之和**

$x_1 = \frac{-b+\sqrt{\Delta}}{2a}$，$x_2 = \frac{-b-\sqrt{\Delta}}{2a}$。

$x_1+x_2 = \frac{-b+\sqrt{\Delta}}{2a} + \frac{-b-\sqrt{\Delta}}{2a}$。

$x_1+x_2 = \frac{-b+\sqrt{\Delta}-b-\sqrt{\Delta}}{2a}$。

$x_1+x_2 = \frac{-2b}{2a} = -\frac{b}{a}$。

**推导两根之积**

$x_1 \cdot x_2 = \frac{-b+\sqrt{\Delta}}{2a} \cdot \frac{-b-\sqrt{\Delta}}{2a}$。

$x_1 \cdot x_2 = \frac{(-b)^2-(\sqrt{\Delta})^2}{4a^2}$。

$x_1 \cdot x_2 = \frac{b^2-(b^2-4ac)}{4a^2}$。

$x_1 \cdot x_2 = \frac{4ac}{4a^2} = \frac{c}{a}$。

## 三、已知一根求另一根

**利用两根之和或两根之积**

**例题1：** 已知方程$x^2-5x+6=0$的一个根是$2$，求另一个根。

解：

两根之和：$x_1+x_2 = 5$。

已知$x_1 = 2$。

$2+x_2 = 5$。

$x_2 = 3$。

答：另一个根是$3$。

**例题2：** 已知方程$2x^2+3x-2=0$的一个根是$\frac{1}{2}$，求另一个根。

解：

两根之积：$x_1 \cdot x_2 = \frac{-2}{2} = -1$。

已知$x_1 = \frac{1}{2}$。

$\frac{1}{2} \cdot x_2 = -1$。

$x_2 = -2$。

答：另一个根是$-2$。

## 四、已知两根求作方程

**利用韦达定理的逆定理**

如果$x_1+x_2 = p$，$x_1 \cdot x_2 = q$。

则方程为$x^2-px+q=0$。

**例题1：** 已知两根为$2$和$3$，求作一元二次方程。

解：

两根之和：$2+3 = 5$。

两根之积：$2 \times 3 = 6$。

方程为$x^2-5x+6=0$。

答：$x^2-5x+6=0$。

**例题2：** 已知两根为$-1$和$4$，求作一元二次方程。

解：

两根之和：$-1+4 = 3$。

两根之积：$-1 \times 4 = -4$。

方程为$x^2-3x-4=0$。

答：$x^2-3x-4=0$。

## 五、求与两根有关的代数式的值

**$x_1^2+x_2^2 = (x_1+x_2)^2-2x_1x_2$**

**$\frac{1}{x_1}+\frac{1}{x_2} = \frac{x_1+x_2}{x_1x_2}$**

**$|x_1-x_2| = \frac{\sqrt{\Delta}}{|a|}$**

**例题1：** 已知方程$x^2-3x+2=0$的两根为$x_1$、$x_2$，求$x_1^2+x_2^2$的值。

解：

$x_1+x_2 = 3$，$x_1x_2 = 2$。

$x_1^2+x_2^2 = (x_1+x_2)^2-2x_1x_2 = 3^2-2 \times 2 = 9-4 = 5$。

答：$x_1^2+x_2^2 = 5$。

**例题2：** 已知方程$2x^2-4x+1=0$的两根为$x_1$、$x_2$，求$\frac{1}{x_1}+\frac{1}{x_2}$的值。

解：

$x_1+x_2 = 2$，$x_1x_2 = \frac{1}{2}$。

$\frac{1}{x_1}+\frac{1}{x_2} = \frac{x_1+x_2}{x_1x_2} = \frac{2}{\frac{1}{2}} = 4$。

答：$\frac{1}{x_1}+\frac{1}{x_2} = 4$。

## 六、常见错误

**错误1：符号搞错**

错误做法：$x_1+x_2 = \frac{b}{a}$。

正确做法：$x_1+x_2 = -\frac{b}{a}$。

**错误2：忘记$a \neq 0$且$\Delta \geq 0$**

错误做法：任何方程都能用韦达定理。

正确理解：方程必须有实数根才能用。

**错误3：两根之积算错**

错误做法：$x_1x_2 = -\frac{c}{a}$。

正确做法：$x_1x_2 = \frac{c}{a}$。

**错误4：求代数式的值时公式用错**

错误做法：$x_1^2+x_2^2 = (x_1+x_2)^2$。

正确做法：$x_1^2+x_2^2 = (x_1+x_2)^2-2x_1x_2$。

**错误5：已知一根求另一根时算错**

错误做法：$x_1+x_2 = 5$，$x_1 = 2$，$x_2 = 7$。

正确做法：$x_2 = 5-2 = 3$。

## 七、练习题

**练习1：** 已知方程$x^2-7x+12=0$的两根为$x_1$、$x_2$，求$x_1+x_2$和$x_1x_2$的值。

解：

$x_1+x_2 = 7$。

$x_1x_2 = 12$。

答：$x_1+x_2 = 7$，$x_1x_2 = 12$。

**练习2：** 已知方程$3x^2+6x-9=0$的两根为$x_1$、$x_2$，求$x_1^2+x_2^2$的值。

解：

$x_1+x_2 = -2$，$x_1x_2 = -3$。

$x_1^2+x_2^2 = (-2)^2-2 \times (-3) = 4+6 = 10$。

答：$x_1^2+x_2^2 = 10$。

**练习3：** 已知两根为$-2$和$5$，求作一元二次方程。

解：

两根之和：$-2+5 = 3$。

两根之积：$-2 \times 5 = -10$。

方程为$x^2-3x-10=0$。

答：$x^2-3x-10=0$。

**练习4：** 已知方程$x^2+4x+3=0$的一个根是$-1$，求另一个根。

解：

两根之和：$x_1+x_2 = -4$。

已知$x_1 = -1$。

$-1+x_2 = -4$。

$x_2 = -3$。

答：另一个根是$-3$。

**练习5：** 已知方程$2x^2-5x+2=0$的两根为$x_1$、$x_2$，求$\frac{1}{x_1}+\frac{1}{x_2}$的值。

解：

$x_1+x_2 = \frac{5}{2}$，$x_1x_2 = 1$。

$\frac{1}{x_1}+\frac{1}{x_2} = \frac{x_1+x_2}{x_1x_2} = \frac{\frac{5}{2}}{1} = \frac{5}{2}$。

答：$\frac{1}{x_1}+\frac{1}{x_2} = \frac{5}{2}$。
