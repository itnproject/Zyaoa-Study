# 21.2.2 配方法

## 一、配方法的原理

**通过配方将方程化为$(x+m)^2 = n$的形式**

利用完全平方公式。

把一般形式的方程转化成可以直接开平方的形式。

## 二、完全平方公式回顾

**$x^2 + 2px + p^2 = (x+p)^2$**

**$x^2 - 2px + p^2 = (x-p)^2$**

关键是"一次项系数一半的平方"。

**例子**

$x^2 + 6x + 9 = (x+3)^2$。

$x^2 - 4x + 4 = (x-2)^2$。

$x^2 + 10x + 25 = (x+5)^2$。

## 三、配方法的步骤

**第一步：移常数项到右边**

**第二步：二次项系数化为$1$**

**第三步：配方（加一次项系数一半的平方）**

**第四步：写成完全平方形式**

**第五步：直接开平方求解**

## 四、例题讲解

**例题1：** 解方程$x^2 + 6x - 7 = 0$。

解：

移常数项：$x^2 + 6x = 7$。

一次项系数是$6$，一半是$3$，平方是$9$。

两边加$9$：$x^2 + 6x + 9 = 7 + 9$。

写成完全平方：$(x+3)^2 = 16$。

开平方：$x + 3 = \pm 4$。

当$x + 3 = 4$时，$x = 1$。

当$x + 3 = -4$时，$x = -7$。

答：$x_1 = 1$，$x_2 = -7$。

**例题2：** 解方程$x^2 - 4x - 5 = 0$。

解：

移常数项：$x^2 - 4x = 5$。

一次项系数是$-4$，一半是$-2$，平方是$4$。

两边加$4$：$x^2 - 4x + 4 = 5 + 4$。

写成完全平方：$(x-2)^2 = 9$。

开平方：$x - 2 = \pm 3$。

当$x - 2 = 3$时，$x = 5$。

当$x - 2 = -3$时，$x = -1$。

答：$x_1 = 5$，$x_2 = -1$。

**例题3：** 解方程$2x^2 + 8x - 10 = 0$。

解：

二次项系数化为$1$：$x^2 + 4x - 5 = 0$。

移常数项：$x^2 + 4x = 5$。

一次项系数是$4$，一半是$2$，平方是$4$。

两边加$4$：$x^2 + 4x + 4 = 5 + 4$。

写成完全平方：$(x+2)^2 = 9$。

开平方：$x + 2 = \pm 3$。

当$x + 2 = 3$时，$x = 1$。

当$x + 2 = -3$时，$x = -5$。

答：$x_1 = 1$，$x_2 = -5$。

**例题4：** 解方程$x^2 + 3x - 1 = 0$。

解：

移常数项：$x^2 + 3x = 1$。

一次项系数是$3$，一半是$\frac{3}{2}$，平方是$\frac{9}{4}$。

两边加$\frac{9}{4}$：$x^2 + 3x + \frac{9}{4} = 1 + \frac{9}{4}$。

写成完全平方：$(x+\frac{3}{2})^2 = \frac{13}{4}$。

开平方：$x + \frac{3}{2} = \pm\frac{\sqrt{13}}{2}$。

$x = -\frac{3}{2} \pm \frac{\sqrt{13}}{2}$。

答：$x_1 = \frac{-3+\sqrt{13}}{2}$，$x_2 = \frac{-3-\sqrt{13}}{2}$。

**例题5：** 解方程$x^2 - 2x + 5 = 0$。

解：

移常数项：$x^2 - 2x = -5$。

一次项系数是$-2$，一半是$-1$，平方是$1$。

两边加$1$：$x^2 - 2x + 1 = -5 + 1$。

写成完全平方：$(x-1)^2 = -4$。

右边是负数，无实数根。

答：方程无实数根。

## 五、配方的关键

**加一次项系数一半的平方**

这是配方法的核心。

一次项系数是$b$，就要加$(\frac{b}{2})^2$。

左边加了，右边也要加。

## 六、常见错误

**错误1：忘记右边也要加**

错误做法：$x^2 + 6x = 7$，左边加$9$，右边不加。

正确做法：两边都加$9$。

**错误2：加错数**

错误做法：$x^2 + 6x = 7$，加$6$（一次项系数）。

正确做法：加$9$（一次项系数一半的平方）。

**错误3：二次项系数不为$1$时直接配方**

错误做法：$2x^2 + 8x = 10$，加$16$。

正确做法：先除以$2$，再配方。

**错误4：符号错误**

错误做法：$x^2 - 4x = 5$，配方成$(x+2)^2$。

正确做法：$(x-2)^2$。

**错误5：开平方时忘记正负号**

错误做法：$(x+3)^2 = 16$，$x+3 = 4$。

正确做法：$x+3 = \pm 4$。

## 七、练习题

**练习1：** 解方程$x^2 + 8x + 12 = 0$。

解：

移常数项：$x^2 + 8x = -12$。

一次项系数是$8$，一半是$4$，平方是$16$。

两边加$16$：$x^2 + 8x + 16 = -12 + 16$。

$(x+4)^2 = 4$。

$x + 4 = \pm 2$。

当$x + 4 = 2$时，$x = -2$。

当$x + 4 = -2$时，$x = -6$。

答：$x_1 = -2$，$x_2 = -6$。

**练习2：** 解方程$x^2 - 6x + 5 = 0$。

解：

移常数项：$x^2 - 6x = -5$。

一次项系数是$-6$，一半是$-3$，平方是$9$。

两边加$9$：$x^2 - 6x + 9 = -5 + 9$。

$(x-3)^2 = 4$。

$x - 3 = \pm 2$。

当$x - 3 = 2$时，$x = 5$。

当$x - 3 = -2$时，$x = 1$。

答：$x_1 = 5$，$x_2 = 1$。

**练习3：** 解方程$3x^2 + 6x - 9 = 0$。

解：

除以$3$：$x^2 + 2x - 3 = 0$。

移常数项：$x^2 + 2x = 3$。

一次项系数是$2$，一半是$1$，平方是$1$。

两边加$1$：$x^2 + 2x + 1 = 3 + 1$。

$(x+1)^2 = 4$。

$x + 1 = \pm 2$。

当$x + 1 = 2$时，$x = 1$。

当$x + 1 = -2$时，$x = -3$。

答：$x_1 = 1$，$x_2 = -3$。

**练习4：** 解方程$x^2 + 5x + 3 = 0$。

解：

移常数项：$x^2 + 5x = -3$。

一次项系数是$5$，一半是$\frac{5}{2}$，平方是$\frac{25}{4}$。

两边加$\frac{25}{4}$：$x^2 + 5x + \frac{25}{4} = -3 + \frac{25}{4}$。

$(x+\frac{5}{2})^2 = \frac{13}{4}$。

$x + \frac{5}{2} = \pm\frac{\sqrt{13}}{2}$。

答：$x_1 = \frac{-5+\sqrt{13}}{2}$，$x_2 = \frac{-5-\sqrt{13}}{2}$。

**练习5：** 解方程$x^2 - 4x + 8 = 0$。

解：

移常数项：$x^2 - 4x = -8$。

一次项系数是$-4$，一半是$-2$，平方是$4$。

两边加$4$：$x^2 - 4x + 4 = -8 + 4$。

$(x-2)^2 = -4$。

右边是负数。

答：方程无实数根。
