# 21.2.1 直接开平方法

## 一、适用形式

**$x^2 = p$或$(mx+n)^2 = p$**

方程可以化成左边是完全平方，右边是常数的形式。

这时候可以直接开平方求解。

**基本思路**

如果$x^2 = p$，那么$x = \pm\sqrt{p}$。

正负号都要考虑。

## 二、当$p > 0$时

**$x = \pm\sqrt{p}$，有两个不相等的实数根**

**例题1：** 解方程$x^2 = 16$。

解：

$x = \pm\sqrt{16}$。

$x = \pm 4$。

答：$x_1 = 4$，$x_2 = -4$。

**例题2：** 解方程$x^2 - 25 = 0$。

解：

移项：$x^2 = 25$。

$x = \pm\sqrt{25}$。

$x = \pm 5$。

答：$x_1 = 5$，$x_2 = -5$。

**例题3：** 解方程$(x-3)^2 = 9$。

解：

$x - 3 = \pm\sqrt{9}$。

$x - 3 = \pm 3$。

当$x - 3 = 3$时，$x = 6$。

当$x - 3 = -3$时，$x = 0$。

答：$x_1 = 6$，$x_2 = 0$。

**例题4：** 解方程$(2x+1)^2 = 25$。

解：

$2x + 1 = \pm\sqrt{25}$。

$2x + 1 = \pm 5$。

当$2x + 1 = 5$时，$2x = 4$，$x = 2$。

当$2x + 1 = -5$时，$2x = -6$，$x = -3$。

答：$x_1 = 2$，$x_2 = -3$。

**例题5：** 解方程$4x^2 = 36$。

解：

两边除以$4$：$x^2 = 9$。

$x = \pm\sqrt{9}$。

$x = \pm 3$。

答：$x_1 = 3$，$x_2 = -3$。

## 三、当$p = 0$时

**$x = 0$，有两个相等的实数根**

**例题1：** 解方程$x^2 = 0$。

解：

$x = 0$。

答：$x_1 = x_2 = 0$。

**例题2：** 解方程$(x-2)^2 = 0$。

解：

$x - 2 = 0$。

$x = 2$。

答：$x_1 = x_2 = 2$。

## 四、当$p < 0$时

**方程无实数根**

**例题1：** 解方程$x^2 = -4$。

解：

任何实数的平方都是非负数。

$x^2$不可能等于$-4$。

答：方程无实数根。

**例题2：** 解方程$(x+1)^2 + 9 = 0$。

解：

移项：$(x+1)^2 = -9$。

左边是非负数，右边是负数。

不可能相等。

答：方程无实数根。

## 五、步骤总结

**第一步：化成$x^2 = p$或$(mx+n)^2 = p$的形式**

**第二步：判断$p$的正负**

$p > 0$：$x = \pm\sqrt{p}$。

$p = 0$：$x = 0$。

$p < 0$：无实数根。

**第三步：写出答案**

## 六、常见错误

**错误1：忘记负号**

错误做法：$x^2 = 16$，$x = 4$。

正确做法：$x = \pm 4$，两个根都要写。

**错误2：负数开平方**

错误做法：$x^2 = -9$，$x = -3$。

正确理解：负数没有实数平方根，无实数根。

**错误3：开平方后忘记化简**

错误做法：$x = \sqrt{16}$，$x = \sqrt{16}$。

正确做法：$x = 4$。

**错误4：$(mx+n)^2 = p$直接开成$mx+n = p$**

错误做法：$(2x+1)^2 = 25$，$2x+1 = 25$。

正确做法：$2x+1 = \pm 5$。

**错误5：忘记判断$p$的正负**

错误做法：$x^2 = -4$，$x = -2$。

正确理解：先判断$p < 0$，无实数根。

## 七、练习题

**练习1：** 解方程$x^2 = 49$。

解：

$x = \pm\sqrt{49}$。

$x = \pm 7$。

答：$x_1 = 7$，$x_2 = -7$。

**练习2：** 解方程$(x+2)^2 = 16$。

解：

$x + 2 = \pm\sqrt{16}$。

$x + 2 = \pm 4$。

当$x + 2 = 4$时，$x = 2$。

当$x + 2 = -4$时，$x = -6$。

答：$x_1 = 2$，$x_2 = -6$。

**练习3：** 解方程$9x^2 = 81$。

解：

两边除以$9$：$x^2 = 9$。

$x = \pm\sqrt{9}$。

$x = \pm 3$。

答：$x_1 = 3$，$x_2 = -3$。

**练习4：** 解方程$(3x-1)^2 = 4$。

解：

$3x - 1 = \pm\sqrt{4}$。

$3x - 1 = \pm 2$。

当$3x - 1 = 2$时，$3x = 3$，$x = 1$。

当$3x - 1 = -2$时，$3x = -1$，$x = -\frac{1}{3}$。

答：$x_1 = 1$，$x_2 = -\frac{1}{3}$。

**练习5：** 解方程$x^2 + 16 = 0$。

解：

移项：$x^2 = -16$。

$p = -16 < 0$。

答：方程无实数根。
