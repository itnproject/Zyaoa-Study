# 21.2.3 公式法

## 一、用配方法推导求根公式

**从一般形式$ax^2+bx+c=0$（$a \neq 0$）出发**

第一步：两边除以$a$。

$x^2 + \frac{b}{a}x + \frac{c}{a} = 0$。

第二步：移常数项。

$x^2 + \frac{b}{a}x = -\frac{c}{a}$。

第三步：配方。

一次项系数是$\frac{b}{a}$，一半是$\frac{b}{2a}$，平方是$\frac{b^2}{4a^2}$。

$x^2 + \frac{b}{a}x + \frac{b^2}{4a^2} = -\frac{c}{a} + \frac{b^2}{4a^2}$。

第四步：写成完全平方。

$(x+\frac{b}{2a})^2 = \frac{b^2-4ac}{4a^2}$。

第五步：开平方。

$x+\frac{b}{2a} = \pm\frac{\sqrt{b^2-4ac}}{2a}$。

第六步：解出$x$。

$x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}$。

## 二、求根公式

**$x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}$（$a \neq 0$，$b^2-4ac \geq 0$）**

这个公式叫一元二次方程的求根公式。

用公式法解方程叫公式法。

## 三、判别式

**$\Delta = b^2-4ac$**

$\Delta$读作"德尔塔"。

$\Delta$决定方程根的情况。

**$\Delta > 0$时有两个不相等的实数根**

$x_1 = \frac{-b+\sqrt{\Delta}}{2a}$，$x_2 = \frac{-b-\sqrt{\Delta}}{2a}$。

**$\Delta = 0$时有两个相等的实数根**

$x_1 = x_2 = -\frac{b}{2a}$。

**$\Delta < 0$时无实数根**

负数没有实数平方根。

## 四、步骤

**第一步：化为一般形式$ax^2+bx+c=0$**

**第二步：找出$a$、$b$、$c$的值**

**第三步：计算$\Delta = b^2-4ac$**

**第四步：判断$\Delta$的正负**

**第五步：代入求根公式**

## 五、例题讲解

**例题1：** 解方程$2x^2-5x+3=0$。

解：

$a=2$，$b=-5$，$c=3$。

$\Delta = (-5)^2-4 \times 2 \times 3 = 25-24 = 1 > 0$。

$x = \frac{5 \pm \sqrt{1}}{2 \times 2} = \frac{5 \pm 1}{4}$。

$x_1 = \frac{5+1}{4} = \frac{6}{4} = \frac{3}{2}$。

$x_2 = \frac{5-1}{4} = \frac{4}{4} = 1$。

答：$x_1 = \frac{3}{2}$，$x_2 = 1$。

**例题2：** 解方程$x^2-4x+4=0$。

解：

$a=1$，$b=-4$，$c=4$。

$\Delta = (-4)^2-4 \times 1 \times 4 = 16-16 = 0$。

$x_1 = x_2 = -\frac{-4}{2 \times 1} = \frac{4}{2} = 2$。

答：$x_1 = x_2 = 2$。

**例题3：** 解方程$3x^2+2x+1=0$。

解：

$a=3$，$b=2$，$c=1$。

$\Delta = 2^2-4 \times 3 \times 1 = 4-12 = -8 < 0$。

答：方程无实数根。

**例题4：** 解方程$x^2+3x-1=0$。

解：

$a=1$，$b=3$，$c=-1$。

$\Delta = 3^2-4 \times 1 \times (-1) = 9+4 = 13 > 0$。

$x = \frac{-3 \pm \sqrt{13}}{2}$。

答：$x_1 = \frac{-3+\sqrt{13}}{2}$，$x_2 = \frac{-3-\sqrt{13}}{2}$。

**例题5：** 解方程$4x^2-12x+9=0$。

解：

$a=4$，$b=-12$，$c=9$。

$\Delta = (-12)^2-4 \times 4 \times 9 = 144-144 = 0$。

$x_1 = x_2 = -\frac{-12}{2 \times 4} = \frac{12}{8} = \frac{3}{2}$。

答：$x_1 = x_2 = \frac{3}{2}$。

## 六、常见错误

**错误1：$b$的符号搞错**

错误做法：$2x^2-5x+3=0$，$b=5$。

正确做法：$b=-5$（带符号）。

**错误2：$\Delta$计算错误**

错误做法：$(-5)^2 = -25$。

正确做法：$(-5)^2 = 25$。

**错误3：分母忘记乘$2$**

错误做法：$x = \frac{-b \pm \sqrt{\Delta}}{a}$。

正确做法：$x = \frac{-b \pm \sqrt{\Delta}}{2a}$。

**错误4：$\Delta < 0$时还代入公式**

错误做法：$\Delta = -8$，$x = \frac{-b \pm \sqrt{-8}}{2a}$。

正确做法：$\Delta < 0$时直接说无实数根。

**错误5：$c$的符号搞错**

错误做法：$x^2+3x-1=0$，$c=1$。

正确做法：$c=-1$（带符号）。

## 七、练习题

**练习1：** 解方程$x^2-5x+6=0$。

解：

$a=1$，$b=-5$，$c=6$。

$\Delta = (-5)^2-4 \times 1 \times 6 = 25-24 = 1 > 0$。

$x = \frac{5 \pm \sqrt{1}}{2} = \frac{5 \pm 1}{2}$。

$x_1 = 3$，$x_2 = 2$。

答：$x_1 = 3$，$x_2 = 2$。

**练习2：** 解方程$2x^2+4x+2=0$。

解：

$a=2$，$b=4$，$c=2$。

$\Delta = 4^2-4 \times 2 \times 2 = 16-16 = 0$。

$x_1 = x_2 = -\frac{4}{2 \times 2} = -1$。

答：$x_1 = x_2 = -1$。

**练习3：** 解方程$x^2+x+1=0$。

解：

$a=1$，$b=1$，$c=1$。

$\Delta = 1^2-4 \times 1 \times 1 = 1-4 = -3 < 0$。

答：方程无实数根。

**练习4：** 解方程$3x^2-6x+1=0$。

解：

$a=3$，$b=-6$，$c=1$。

$\Delta = (-6)^2-4 \times 3 \times 1 = 36-12 = 24 > 0$。

$x = \frac{6 \pm \sqrt{24}}{6} = \frac{6 \pm 2\sqrt{6}}{6} = \frac{3 \pm \sqrt{6}}{3}$。

答：$x_1 = \frac{3+\sqrt{6}}{3}$，$x_2 = \frac{3-\sqrt{6}}{3}$。

**练习5：** 解方程$5x^2-3x-2=0$。

解：

$a=5$，$b=-3$，$c=-2$。

$\Delta = (-3)^2-4 \times 5 \times (-2) = 9+40 = 49 > 0$。

$x = \frac{3 \pm \sqrt{49}}{10} = \frac{3 \pm 7}{10}$。

$x_1 = 1$，$x_2 = -\frac{2}{5}$。

答：$x_1 = 1$，$x_2 = -\frac{2}{5}$。
