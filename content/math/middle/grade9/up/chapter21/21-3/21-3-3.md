# 21.3.3 利润问题

## 一、基本公式

**利润=售价-进价**

利润是卖出价减去成本价。

利润为正表示赚钱。

利润为负表示亏钱。

**总利润=单件利润×销售量**

卖出的总利润等于每件赚的钱乘以卖出的数量。

## 二、涨价/降价对销量的影响

**涨价会减少销量**

每涨价$1$元，销量减少一定数量。

**降价会增加销量**

每降价$1$元，销量增加一定数量。

## 三、列方程求定价

**设未知数**

可以设涨价/降价$x$元。

也可以设售价为$x$元。

**列方程**

总利润=单件利润×销售量。

根据题目要求列方程。

## 四、例题讲解

**例题1：** 某商品进价为$40$元，售价为$60$元时，每天可卖出$100$件。调查发现，每涨价$1$元，每天少卖$2$件。若要每天获利$2250$元，售价应定为多少？

解：

设每件涨价$x$元。

售价：$60+x$元。

单件利润：$60+x-40 = 20+x$元。

销量：$100-2x$件。

总利润：$(20+x)(100-2x) = 2250$。

$2000-40x+100x-2x^2 = 2250$。

$-2x^2+60x-250 = 0$。

$x^2-30x+125 = 0$。

$(x-5)(x-25) = 0$。

$x = 5$或$x = 25$。

售价为$65$元或$85$元。

答：售价应定为$65$元或$85$元。

**例题2：** 某商品进价为$30$元，售价为$50$元时，每天可卖出$200$件。每降价$1$元，每天多卖$20$件。若要每天获利$4800$元，售价应定为多少？

解：

设每件降价$x$元。

售价：$50-x$元。

单件利润：$50-x-30 = 20-x$元。

销量：$200+20x$件。

总利润：$(20-x)(200+20x) = 4800$。

$4000+400x-200x-20x^2 = 4800$。

$-20x^2+200x-800 = 0$。

$x^2-10x+40 = 0$。

$\Delta = 100-160 = -60 < 0$。

答：无法达到每天获利$4800$元。

**例题3：** 某商品进价为$50$元，售价为$80$元时，每天可卖出$60$件。每涨价$2$元，每天少卖$4$件。若要每天获利$2000$元，售价应定为多少？

解：

设每件涨价$2x$元。

售价：$80+2x$元。

单件利润：$80+2x-50 = 30+2x$元。

销量：$60-4x$件。

总利润：$(30+2x)(60-4x) = 2000$。

$1800-120x+120x-8x^2 = 2000$。

$-8x^2 = 200$。

$x^2 = -25$。

答：无法达到每天获利$2000$元。

**例题4：** 某商品进价为$20$元，售价为$40$元时，每天可卖出$300$件。每涨价$1$元，每天少卖$10$件。求每天最大利润及此时的售价。

解：

设每件涨价$x$元。

单件利润：$40+x-20 = 20+x$元。

销量：$300-10x$件。

总利润：$y = (20+x)(300-10x)$。

$y = 6000-200x+300x-10x^2$。

$y = -10x^2+100x+6000$。

$y = -10(x^2-10x)+6000$。

$y = -10(x-5)^2+6250$。

当$x = 5$时，$y$最大为$6250$元。

售价：$40+5 = 45$元。

答：售价定为$45$元时，每天最大利润为$6250$元。

**例题5：** 某商店购进一批商品，每件进价$25$元。若售价为$35$元，可卖出$200$件；若售价每涨$1$元，销量减少$10$件。若要获利$2000$元，售价应定为多少？

解：

设每件涨价$x$元。

售价：$35+x$元。

单件利润：$35+x-25 = 10+x$元。

销量：$200-10x$件。

总利润：$(10+x)(200-10x) = 2000$。

$2000-100x+200x-10x^2 = 2000$。

$-10x^2+100x = 0$。

$-10x(x-10) = 0$。

$x = 0$或$x = 10$。

售价为$35$元或$45$元。

答：售价应定为$35$元或$45$元。

## 五、常见错误

**错误1：单件利润算错**

错误做法：单件利润=售价。

正确做法：单件利润=售价-进价。

**错误2：销量变化方向搞反**

错误做法：涨价后销量增加。

正确做法：涨价后销量减少。

**错误3：忘记检验解的合理性**

错误做法：销量为负数也保留。

正确做法：销量必须为正数，舍去不合理解的。

**错误4：涨价/降价的倍数关系搞错**

错误做法：每涨$2$元少卖$4$件，设涨$x$元，销量减少$2x$件。

正确做法：设涨$2x$元，销量减少$4x$件；或设涨$x$元，销量减少$2x$件。

**错误5：方程列错**

错误做法：总利润=售价×销量。

正确做法：总利润=单件利润×销量。

## 六、练习题

**练习1：** 某商品进价为$60$元，售价为$100$元时，每天可卖出$50$件。每涨价$1$元，每天少卖$1$件。若要每天获利$2400$元，售价应定为多少？

解：

设每件涨价$x$元。

单件利润：$100+x-60 = 40+x$元。

销量：$50-x$件。

$(40+x)(50-x) = 2400$。

$2000-40x+50x-x^2 = 2400$。

$-x^2+10x-400 = 0$。

$x^2-10x+400 = 0$。

$\Delta = 100-1600 < 0$。

答：无法达到每天获利$2400$元。

**练习2：** 某商品进价为$15$元，售价为$25$元时，每天可卖出$400$件。每涨价$1$元，每天少卖$20$件。求每天最大利润及此时的售价。

解：

设每件涨价$x$元。

单件利润：$25+x-15 = 10+x$元。

销量：$400-20x$件。

$y = (10+x)(400-20x)$。

$y = 4000-200x+400x-20x^2$。

$y = -20x^2+200x+4000$。

$y = -20(x-5)^2+4500$。

当$x = 5$时，$y$最大为$4500$元。

售价：$25+5 = 30$元。

答：售价定为$30$元时，每天最大利润为$4500$元。

**练习3：** 某商品进价为$80$元，售价为$120$元时，每天可卖出$40$件。每降价$1$元，每天多卖$4$件。若要每天获利$2400$元，售价应定为多少？

解：

设每件降价$x$元。

单件利润：$120-x-80 = 40-x$元。

销量：$40+4x$件。

$(40-x)(40+4x) = 2400$。

$1600+160x-40x-4x^2 = 2400$。

$-4x^2+120x-800 = 0$。

$x^2-30x+200 = 0$。

$(x-10)(x-20) = 0$。

$x = 10$或$x = 20$。

售价为$110$元或$100$元。

答：售价应定为$110$元或$100$元。

**练习4：** 某商品进价为$30$元，售价为$50$元时，每天可卖出$100$件。每涨价$1$元，每天少卖$5$件。若要每天获利$1500$元，售价应定为多少？

解：

设每件涨价$x$元。

单件利润：$50+x-30 = 20+x$元。

销量：$100-5x$件。

$(20+x)(100-5x) = 1500$。

$2000-100x+100x-5x^2 = 1500$。

$-5x^2 = -500$。

$x^2 = 100$。

$x = 10$或$x = -10$（舍去）。

售价：$50+10 = 60$元。

答：售价应定为$60$元。

**练习5：** 某商品进价为$45$元，售价为$75$元时，每天可卖出$80$件。每涨价$1$元，每天少卖$2$件。若要每天获利$3000$元，售价应定为多少？

解：

设每件涨价$x$元。

单件利润：$75+x-45 = 30+x$元。

销量：$80-2x$件。

$(30+x)(80-2x) = 3000$。

$2400-60x+80x-2x^2 = 3000$。

$-2x^2+20x-600 = 0$。

$x^2-10x+300 = 0$。

$\Delta = 100-1200 < 0$。

答：无法达到每天获利$3000$元。
