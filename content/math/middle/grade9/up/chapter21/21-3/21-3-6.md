# 21.3.6 一元二次方程应用题综合

## 一、审题的要点

**找等量关系**

仔细阅读题目。

找出题目中的等量关系。

等量关系是列方程的关键。

**常见的等量关系**

面积公式、体积公式。

速度×时间=路程。

利润=售价-进价。

总量=各部分之和。

## 二、设未知数的技巧

**直接设**

题目问什么就设什么。

简单直观。

**间接设**

设中间量为未知数。

有时比直接设更方便。

**设元的原则**

便于列方程。

便于计算。

## 三、列方程的注意事项

**单位要统一**

**等式两边量纲要一致**

**不要漏掉条件**

## 四、解的取舍

**既要验根又要验实际意义**

验根：代入原方程检验。

验实际意义：是否符合题目实际情况。

**需要舍去的情况**

长度为负数。

时间为负数。

人数为非整数。

超出范围的值。

## 五、例题讲解

**例题1：** 某商店购进一批商品，每件进价$40$元。若按每件$60$元出售，每天可卖出$100$件。经调查发现，每涨价$1$元，每天少卖$2$件。商店想要每天获利$2250$元，每件商品应定价多少？

解：

设每件涨价$x$元。

售价：$60+x$元。

单件利润：$60+x-40 = 20+x$元。

销量：$100-2x$件。

总利润：$(20+x)(100-2x) = 2250$。

$2000-40x+100x-2x^2 = 2250$。

$-2x^2+60x-250 = 0$。

$x^2-30x+125 = 0$。

$(x-5)(x-25) = 0$。

$x = 5$或$x = 25$。

售价为$65$元或$85$元。

检验：$x=5$时，销量$=90>0$，合理。

$x=25$时，销量$=50>0$，合理。

答：每件商品应定价$65$元或$85$元。

**例题2：** 一个矩形花圃的长比宽多$5$m，面积为$150\text{m}^2$，求花圃的长和宽。

解：

设宽为$x$m。

长为$(x+5)$m。

面积：$x(x+5) = 150$。

$x^2+5x-150 = 0$。

$(x+15)(x-10) = 0$。

$x = 10$或$x = -15$（舍去）。

宽为$10$m，长为$15$m。

答：花圃的长为$15$m，宽为$10$m。

**例题3：** 某工厂去年产值为$200$万元，今年产值为$242$万元，求年增长率。

解：

设年增长率为$x$。

$200(1+x) = 242$。

$1+x = 1.21$。

$x = 0.21 = 21\%$。

答：年增长率为$21\%$。

**例题4：** 一次聚会上，每两个人都握了一次手，总共握手$55$次，求参加聚会的人数。

解：

设参加聚会的人数为$x$。

$\frac{x(x-1)}{2} = 55$。

$x(x-1) = 110$。

$x^2-x-110 = 0$。

$(x-11)(x+10) = 0$。

$x = 11$或$x = -10$（舍去）。

答：参加聚会的有$11$人。

**例题5：** 如图，在矩形$ABCD$中，$AB=8$cm，$BC=6$cm。点$P$从点$A$出发，沿$AB$以$2$cm/s的速度向点$B$移动；同时点$Q$从点$B$出发，沿$BC$以$1$cm/s的速度向点$C$移动。当$\triangle PBQ$的面积为$6\text{cm}^2$时，求移动时间$t$。

解：

$AP = 2t$cm，$PB = 8-2t$cm。

$BQ = t$cm。

$\triangle PBQ$的面积：$\frac{1}{2}(8-2t)t = 6$。

$(8-2t)t = 12$。

$8t-2t^2 = 12$。

$2t^2-8t+12 = 0$。

$t^2-4t+6 = 0$。

$\Delta = 16-24 = -8 < 0$。

答：不存在这样的时间$t$。

## 六、常见错误

**错误1：等量关系找错**

错误做法：把不等关系当成等量关系。

正确做法：仔细分析题目，找到真正的等量关系。

**错误2：设未知数不合理**

错误做法：设的量不便于列方程。

正确做法：选择便于列方程的量作为未知数。

**错误3：忘记检验实际意义**

错误做法：算出负数长度也保留。

正确做法：检验解是否符合实际情况。

**错误4：单位不统一**

错误做法：一边用m，一边用cm。

正确做法：统一单位后再列方程。

**错误5：漏掉条件**

错误做法：只用部分条件列方程。

正确做法：充分利用所有条件。

## 七、练习题

**练习1：** 某商品进价为$50$元，售价为$80$元时，每天可卖出$60$件。每涨价$1$元，每天少卖$2$件。若要每天获利$2000$元，售价应定为多少？

解：

设每件涨价$x$元。

单件利润：$80+x-50 = 30+x$元。

销量：$60-2x$件。

$(30+x)(60-2x) = 2000$。

$1800-60x+60x-2x^2 = 2000$。

$-2x^2 = 200$。

$x^2 = -100$。

答：无法达到每天获利$2000$元。

**练习2：** 一个直角三角形的两条直角边相差$3$cm，面积为$27\text{cm}^2$，求两条直角边的长。

解：

设较短的直角边为$x$cm。

较长的直角边为$(x+3)$cm。

面积：$\frac{1}{2}x(x+3) = 27$。

$x(x+3) = 54$。

$x^2+3x-54 = 0$。

$(x+9)(x-6) = 0$。

$x = 6$或$x = -9$（舍去）。

两条直角边分别为$6$cm和$9$cm。

答：两条直角边分别为$6$cm和$9$cm。

**练习3：** 某市前年GDP为$800$亿元，今年GDP为$1152$亿元，求这两年的平均增长率。

解：

设平均增长率为$x$。

$800(1+x)^2 = 1152$。

$(1+x)^2 = 1.44$。

$1+x = 1.2$或$1+x = -1.2$（舍去）。

$x = 0.2 = 20\%$。

答：平均增长率为$20\%$。

**练习4：** 一个两位数，十位数字与个位数字之和为$7$，且这个两位数比各位数字之积的$3$倍多$4$，求这个两位数。

解：

设十位数字为$x$。

个位数字为$7-x$。

这个两位数：$10x+(7-x) = 9x+7$。

各位数字之积：$x(7-x) = 7x-x^2$。

$9x+7 = 3(7x-x^2)+4$。

$9x+7 = 21x-3x^2+4$。

$3x^2-12x+3 = 0$。

$x^2-4x+1 = 0$。

$x = \frac{4 \pm \sqrt{16-4}}{2} = \frac{4 \pm \sqrt{12}}{2} = 2 \pm \sqrt{3}$。

$x$不是整数，不符合题意。

答：无解（题目数据有问题）。

**练习5：** 某工厂计划生产一批零件，原计划每天生产$40$个，实际每天多生产$10$个，结果提前$3$天完成任务。求这批零件共有多少个。

解：

设这批零件共有$x$个。

原计划天数：$\frac{x}{40}$。

实际天数：$\frac{x}{50}$。

$\frac{x}{40} - \frac{x}{50} = 3$。

$\frac{5x-4x}{200} = 3$。

$\frac{x}{200} = 3$。

$x = 600$。

答：这批零件共有$600$个。
