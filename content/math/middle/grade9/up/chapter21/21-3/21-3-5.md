# 21.3.5 动点问题

## 一、点在边上移动

**求时间或距离**

点从某位置出发，以一定速度移动。

用含时间$t$的代数式表示点的位置。

根据题目条件列方程。

## 二、用含$t$的代数式表示线段长度

**速度×时间=路程**

点移动的距离等于速度乘以时间。

用这个关系表示相关线段的长度。

## 三、根据面积或长度关系列方程

**面积关系**

三角形面积、矩形面积等。

**长度关系**

线段相等、线段和差等。

## 四、注意检验解的合理性

**时间不能为负**

**点不能超出边的范围**

**速度不能为负**

## 五、例题讲解

**例题1：** 如图，在矩形$ABCD$中，$AB=6$cm，$BC=8$cm。点$P$从点$A$出发，沿$AB$以$1$cm/s的速度向点$B$移动；同时点$Q$从点$B$出发，沿$BC$以$2$cm/s的速度向点$C$移动。设移动时间为$t$秒，当$\triangle PBQ$的面积为$8\text{cm}^2$时，求$t$的值。

解：

$AP = t$cm，$PB = 6-t$cm。

$BQ = 2t$cm。

$\triangle PBQ$的面积：$\frac{1}{2} \times PB \times BQ = \frac{1}{2}(6-t)(2t) = (6-t)t$。

$(6-t)t = 8$。

$6t-t^2 = 8$。

$t^2-6t+8 = 0$。

$(t-2)(t-4) = 0$。

$t = 2$或$t = 4$。

检验：$t=2$时，$PB=4>0$，$BQ=4<8$，合理。

$t=4$时，$PB=2>0$，$BQ=8=BC$，合理。

答：$t=2$秒或$t=4$秒。

**例题2：** 如图，在$\triangle ABC$中，$\angle B=90°$，$AB=6$cm，$BC=8$cm。点$P$从点$A$出发，沿$AB$以$1$cm/s的速度向点$B$移动；同时点$Q$从点$B$出发，沿$BC$以$1$cm/s的速度向点$C$移动。当$\triangle PBQ$的面积等于$\triangle ABC$面积的$\frac{1}{4}$时，求移动时间$t$。

解：

$\triangle ABC$的面积：$\frac{1}{2} \times 6 \times 8 = 24\text{cm}^2$。

$\triangle PBQ$的面积应为：$24 \times \frac{1}{4} = 6\text{cm}^2$。

$AP = t$cm，$PB = 6-t$cm。

$BQ = t$cm。

$\triangle PBQ$的面积：$\frac{1}{2}(6-t)t = 6$。

$(6-t)t = 12$。

$6t-t^2 = 12$。

$t^2-6t+12 = 0$。

$\Delta = 36-48 = -12 < 0$。

答：不存在这样的时间$t$。

**例题3：** 如图，在矩形$ABCD$中，$AB=4$cm，$AD=6$cm。点$P$从点$A$出发，沿$AD$以$1$cm/s的速度向点$D$移动。当$BP=5$cm时，求移动时间$t$。

解：

$AP = t$cm。

在Rt$\triangle ABP$中，由勾股定理：

$BP^2 = AB^2 + AP^2$。

$5^2 = 4^2 + t^2$。

$25 = 16 + t^2$。

$t^2 = 9$。

$t = 3$或$t = -3$（舍去）。

检验：$t=3$时，$AP=3<6$，合理。

答：$t=3$秒。

**例题4：** 如图，在矩形$ABCD$中，$AB=8$cm，$BC=6$cm。点$P$从点$A$出发，沿$AB$以$2$cm/s的速度向点$B$移动；同时点$Q$从点$C$出发，沿$CD$以$1$cm/s的速度向点$D$移动。当四边形$APQD$的面积为$20\text{cm}^2$时，求移动时间$t$。

解：

$AP = 2t$cm，$PB = 8-2t$cm。

$CQ = t$cm，$QD = 8-t$cm。

四边形$APQD$是梯形。

上底$AP = 2t$，下底$QD = 8-t$，高$AD = 6$。

面积：$\frac{1}{2}(2t+8-t) \times 6 = 3(t+8)$。

$3(t+8) = 20$。

$3t+24 = 20$。

$3t = -4$。

$t = -\frac{4}{3}$（舍去）。

答：不存在这样的时间$t$。

**例题5：** 如图，在$\triangle ABC$中，$\angle B=90°$，$AB=12$cm，$BC=16$cm。点$P$从点$A$出发，沿$AB$以$3$cm/s的速度向点$B$移动；同时点$Q$从点$B$出发，沿$BC$以$4$cm/s的速度向点$C$移动。当$PQ=10$cm时，求移动时间$t$。

解：

$AP = 3t$cm，$PB = 12-3t$cm。

$BQ = 4t$cm。

在Rt$\triangle PBQ$中，由勾股定理：

$PQ^2 = PB^2 + BQ^2$。

$10^2 = (12-3t)^2 + (4t)^2$。

$100 = 144-72t+9t^2+16t^2$。

$25t^2-72t+44 = 0$。

用公式法：$t = \frac{72 \pm \sqrt{5184-4400}}{50} = \frac{72 \pm \sqrt{784}}{50} = \frac{72 \pm 28}{50}$。

$t = 2$或$t = \frac{44}{50} = 0.88$。

检验：$t=2$时，$PB=6>0$，$BQ=8<16$，合理。

$t=0.88$时，$PB=9.36>0$，$BQ=3.52<16$，合理。

答：$t=2$秒或$t=0.88$秒。

## 六、常见错误

**错误1：线段长度表示错误**

错误做法：$PB = t$（点从$A$出发，$AP=t$，$PB=AB-t$）。

正确做法：$PB = AB-AP = 6-t$。

**错误2：忘记检验解的合理性**

错误做法：算出$t=10$也保留，但点早已超出边的范围。

正确做法：检验点是否还在边上。

**错误3：面积公式用错**

错误做法：三角形面积=底×高。

正确做法：三角形面积=$\frac{1}{2}$×底×高。

**错误4：勾股定理用错**

错误做法：$PQ = PB+BQ$。

正确做法：$PQ^2 = PB^2+BQ^2$。

**错误5：时间范围不考虑**

错误做法：$t$可以为任意正数。

正确做法：$t$必须使点不超出边的范围。

## 七、练习题

**练习1：** 如图，在矩形$ABCD$中，$AB=4$cm，$BC=6$cm。点$P$从点$A$出发，沿$AB$以$1$cm/s的速度向点$B$移动；同时点$Q$从点$B$出发，沿$BC$以$1$cm/s的速度向点$C$移动。当$\triangle PBQ$的面积为$3\text{cm}^2$时，求$t$的值。

解：

$AP = t$cm，$PB = 4-t$cm。

$BQ = t$cm。

$\triangle PBQ$的面积：$\frac{1}{2}(4-t)t = 3$。

$(4-t)t = 6$。

$4t-t^2 = 6$。

$t^2-4t+6 = 0$。

$\Delta = 16-24 = -8 < 0$。

答：不存在这样的时间$t$。

**练习2：** 如图，在$\triangle ABC$中，$\angle B=90°$，$AB=8$cm，$BC=6$cm。点$P$从点$A$出发，沿$AB$以$2$cm/s的速度向点$B$移动。当$BP=4$cm时，求移动时间$t$。

解：

$AP = 2t$cm，$PB = 8-2t$cm。

$8-2t = 4$。

$2t = 4$。

$t = 2$。

检验：$t=2$时，$AP=4<8$，合理。

答：$t=2$秒。

**练习3：** 如图，在矩形$ABCD$中，$AB=6$cm，$BC=8$cm。点$P$从点$A$出发，沿$AB$以$1$cm/s的速度向点$B$移动；同时点$Q$从点$B$出发，沿$BC$以$2$cm/s的速度向点$C$移动。当$\triangle PBQ$的面积为$6\text{cm}^2$时，求$t$的值。

解：

$AP = t$cm，$PB = 6-t$cm。

$BQ = 2t$cm。

$\triangle PBQ$的面积：$\frac{1}{2}(6-t)(2t) = (6-t)t = 6$。

$6t-t^2 = 6$。

$t^2-6t+6 = 0$。

$t = \frac{6 \pm \sqrt{36-24}}{2} = \frac{6 \pm \sqrt{12}}{2} = 3 \pm \sqrt{3}$。

检验：$t=3-\sqrt{3} \approx 1.27$时，$PB \approx 4.73>0$，$BQ \approx 2.54<8$，合理。

$t=3+\sqrt{3} \approx 4.73$时，$PB \approx 1.27>0$，$BQ \approx 9.46>8$，不合理。

答：$t=3-\sqrt{3}$秒。

**练习4：** 如图，在矩形$ABCD$中，$AB=10$cm，$AD=5$cm。点$P$从点$A$出发，沿$AB$以$2$cm/s的速度向点$B$移动。当$DP=5\sqrt{2}$cm时，求移动时间$t$。

解：

$AP = 2t$cm。

在Rt$\triangle ADP$中，由勾股定理：

$DP^2 = AD^2 + AP^2$。

$(5\sqrt{2})^2 = 5^2 + (2t)^2$。

$50 = 25 + 4t^2$。

$4t^2 = 25$。

$t^2 = \frac{25}{4}$。

$t = \frac{5}{2}$或$t = -\frac{5}{2}$（舍去）。

检验：$t=2.5$时，$AP=5<10$，合理。

答：$t=2.5$秒。

**练习5：** 如图，在$\triangle ABC$中，$\angle B=90°$，$AB=6$cm，$BC=8$cm。点$P$从点$A$出发，沿$AB$以$1$cm/s的速度向点$B$移动；同时点$Q$从点$B$出发，沿$BC$以$1$cm/s的速度向点$C$移动。当$\triangle PBQ$的面积等于$\triangle ABC$面积的$\frac{1}{6}$时，求移动时间$t$。

解：

$\triangle ABC$的面积：$\frac{1}{2} \times 6 \times 8 = 24\text{cm}^2$。

$\triangle PBQ$的面积应为：$24 \times \frac{1}{6} = 4\text{cm}^2$。

$AP = t$cm，$PB = 6-t$cm。

$BQ = t$cm。

$\frac{1}{2}(6-t)t = 4$。

$(6-t)t = 8$。

$6t-t^2 = 8$。

$t^2-6t+8 = 0$。

$(t-2)(t-4) = 0$。

$t = 2$或$t = 4$。

检验：$t=2$时，$PB=4>0$，$BQ=2<8$，合理。

$t=4$时，$PB=2>0$，$BQ=4<8$，合理。

答：$t=2$秒或$t=4$秒。
