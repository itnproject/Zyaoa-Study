# 21.3.4 数字与循环问题

## 一、连续整数/奇数/偶数问题

**连续整数**

设中间的数为$x$。

三个连续整数：$x-1$、$x$、$x+1$。

**连续奇数**

设中间的数为$x$。

三个连续奇数：$x-2$、$x$、$x+2$。

**连续偶数**

设中间的数为$x$。

三个连续偶数：$x-2$、$x$、$x+2$。

## 二、两位数/三位数的表示

**两位数**

十位数字为$a$，个位数字为$b$。

这个两位数表示为$10a+b$。

**三位数**

百位数字为$a$，十位数字为$b$，个位数字为$c$。

这个三位数表示为$100a+10b+c$。

## 三、握手问题

**$n$个人，每两人握一次手**

握手次数：$\frac{n(n-1)}{2}$。

每个人和其他$n-1$个人握手。

总共$n(n-1)$次，但每次握手算了两次。

所以要除以$2$。

## 四、比赛场次问题

**单循环赛**

$n$个队，每两队比赛一场。

总场次：$\frac{n(n-1)}{2}$。

**双循环赛**

$n$个队，每两队比赛两场（主客场）。

总场次：$n(n-1)$。

## 五、例题讲解

**例题1：** 三个连续整数的平方和为$50$，求这三个数。

解：

设中间的数为$x$。

三个数：$x-1$、$x$、$x+1$。

$(x-1)^2+x^2+(x+1)^2 = 50$。

$x^2-2x+1+x^2+x^2+2x+1 = 50$。

$3x^2+2 = 50$。

$3x^2 = 48$。

$x^2 = 16$。

$x = 4$或$x = -4$。

三个数为$3$、$4$、$5$或$-5$、$-4$、$-3$。

答：这三个数为$3$、$4$、$5$或$-5$、$-4$、$-3$。

**例题2：** 一个两位数，个位数字比十位数字大$3$，且这个两位数等于各位数字之和的$4$倍，求这个两位数。

解：

设十位数字为$x$。

个位数字为$x+3$。

这个两位数：$10x+(x+3) = 11x+3$。

各位数字之和：$x+(x+3) = 2x+3$。

$11x+3 = 4(2x+3)$。

$11x+3 = 8x+12$。

$3x = 9$。

$x = 3$。

个位数字：$3+3 = 6$。

答：这个两位数是$36$。

**例题3：** 一次聚会上，每两个人都握了一次手，总共握手$45$次，求参加聚会的人数。

解：

设参加聚会的人数为$x$。

$\frac{x(x-1)}{2} = 45$。

$x(x-1) = 90$。

$x^2-x-90 = 0$。

$(x-10)(x+9) = 0$。

$x = 10$或$x = -9$（舍去）。

答：参加聚会的有$10$人。

**例题4：** 一个两位数，十位数字与个位数字之和为$9$，把这个两位数的个位数字与十位数字对调后，所得的新数比原数大$27$，求原数。

解：

设十位数字为$x$。

个位数字为$9-x$。

原数：$10x+(9-x) = 9x+9$。

新数：$10(9-x)+x = 90-10x+x = 90-9x$。

$90-9x = 9x+9+27$。

$90-9x = 9x+36$。

$54 = 18x$。

$x = 3$。

个位数字：$9-3 = 6$。

答：原数是$36$。

**例题5：** 某足球联赛采用单循环赛制，共进行了$120$场比赛，求参赛球队的数量。

解：

设参赛球队数量为$x$。

$\frac{x(x-1)}{2} = 120$。

$x(x-1) = 240$。

$x^2-x-240 = 0$。

$(x-16)(x+15) = 0$。

$x = 16$或$x = -15$（舍去）。

答：参赛球队有$16$支。

## 六、常见错误

**错误1：连续奇数/偶数间隔搞错**

错误做法：三个连续奇数：$x$、$x+1$、$x+2$。

正确做法：三个连续奇数：$x$、$x+2$、$x+4$。

**错误2：两位数表示错误**

错误做法：十位$a$个位$b$，数表示为$ab$。

正确做法：$10a+b$。

**错误3：握手问题忘记除以$2$**

错误做法：$n$个人握手$n(n-1)$次。

正确做法：$\frac{n(n-1)}{2}$次。

**错误4：数字范围不考虑**

错误做法：十位数字可以为$0$。

正确做法：十位数字为$1$到$9$。

**错误5：对调后新数算错**

错误做法：$ab$对调后为$ba$，值不变。

正确做法：$10a+b$对调后为$10b+a$。

## 七、练习题

**练习1：** 三个连续偶数的平方和为$56$，求这三个数。

解：

设中间的数为$x$。

三个数：$x-2$、$x$、$x+2$。

$(x-2)^2+x^2+(x+2)^2 = 56$。

$x^2-4x+4+x^2+x^2+4x+4 = 56$。

$3x^2+8 = 56$。

$3x^2 = 48$。

$x^2 = 16$。

$x = 4$或$x = -4$。

三个数为$2$、$4$、$6$或$-6$、$-4$、$-2$。

答：这三个数为$2$、$4$、$6$或$-6$、$-4$、$-2$。

**练习2：** 一个两位数，个位数字是十位数字的$2$倍，且这个两位数等于各位数字之积的$3$倍，求这个两位数。

解：

设十位数字为$x$。

个位数字为$2x$。

这个两位数：$10x+2x = 12x$。

各位数字之积：$x \cdot 2x = 2x^2$。

$12x = 3 \cdot 2x^2$。

$12x = 6x^2$。

$6x^2-12x = 0$。

$6x(x-2) = 0$。

$x = 0$（舍去）或$x = 2$。

个位数字：$2 \times 2 = 4$。

答：这个两位数是$24$。

**练习3：** 一次会议上，每两个人都握了一次手，总共握手$66$次，求参加会议的人数。

解：

设参加会议的人数为$x$。

$\frac{x(x-1)}{2} = 66$。

$x(x-1) = 132$。

$x^2-x-132 = 0$。

$(x-12)(x+11) = 0$。

$x = 12$或$x = -11$（舍去）。

答：参加会议的有$12$人。

**练习4：** 一个两位数，十位数字比个位数字小$2$，且这个两位数比各位数字之和的$5$倍多$3$，求这个两位数。

解：

设个位数字为$x$。

十位数字为$x-2$。

这个两位数：$10(x-2)+x = 11x-20$。

各位数字之和：$(x-2)+x = 2x-2$。

$11x-20 = 5(2x-2)+3$。

$11x-20 = 10x-10+3$。

$11x-20 = 10x-7$。

$x = 13$（舍去，个位数字不能大于$9$）。

重新检查：$x$必须是个位数字，$0 \leq x \leq 9$。

且十位数字$x-2 \geq 1$，所以$x \geq 3$。

$x = 13$不符合条件，重新计算。

$11x-20 = 10x-7$。

$x = 13$。

答：无解（题目数据有问题）。

**练习5：** 某篮球联赛采用单循环赛制，共进行了$28$场比赛，求参赛球队的数量。

解：

设参赛球队数量为$x$。

$\frac{x(x-1)}{2} = 28$。

$x(x-1) = 56$。

$x^2-x-56 = 0$。

$(x-8)(x+7) = 0$。

$x = 8$或$x = -7$（舍去）。

答：参赛球队有$8$支。
