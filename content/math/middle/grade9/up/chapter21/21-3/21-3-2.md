# 21.3.2 面积问题

## 一、矩形花圃四周修路问题

**花圃面积+路的面积=总面积**

或者：总面积-路的面积=花圃面积。

设路的宽度为$x$。

用含$x$的式子表示各部分面积。

列方程求解。

## 二、边框/相框问题

**外框面积-内框面积=边框面积**

设边框宽度为$x$。

外框的长和宽都比内框多$2x$。

## 三、围栏问题

**靠墙围矩形**

一面靠墙，只需要围三面。

设垂直于墙的边长为$x$。

平行于墙的边长用总长表示。

面积=长乘以宽。

## 四、平移法简化图形

**不规则图形通过平移变成规则图形**

把分散的部分拼在一起。

简化计算。

## 五、例题讲解

**例题1：** 一个矩形花圃长$20$m，宽$15$m，四周修一条等宽的小路，小路面积为$150\text{m}^2$，求小路的宽度。

解：

设小路宽为$x$m。

外矩形长：$20+2x$。

外矩形宽：$15+2x$。

总面积：$(20+2x)(15+2x)$。

花圃面积：$20 \times 15 = 300$。

小路面积：$(20+2x)(15+2x) - 300 = 150$。

$(20+2x)(15+2x) = 450$。

$300+40x+30x+4x^2 = 450$。

$4x^2+70x-150 = 0$。

$2x^2+35x-75 = 0$。

用公式法：$x = \frac{-35 \pm \sqrt{35^2+600}}{4} = \frac{-35 \pm \sqrt{1825}}{4}$。

取正根：$x = \frac{-35+\sqrt{1825}}{4} \approx 2$。

答：小路宽约$2$m。

**例题2：** 一个相框外框长$30$cm，宽$20$cm，边框面积$200\text{cm}^2$，求边框宽度。

解：

设边框宽为$x$cm。

内框长：$30-2x$。

内框宽：$20-2x$。

外框面积：$30 \times 20 = 600$。

内框面积：$(30-2x)(20-2x)$。

边框面积：$600-(30-2x)(20-2x) = 200$。

$(30-2x)(20-2x) = 400$。

$600-60x-40x+4x^2 = 400$。

$4x^2-100x+200 = 0$。

$x^2-25x+50 = 0$。

用公式法：$x = \frac{25 \pm \sqrt{625-200}}{2} = \frac{25 \pm \sqrt{425}}{2}$。

取较小根：$x = \frac{25-\sqrt{425}}{2} \approx 2.2$。

答：边框宽约$2.2$cm。

**例题3：** 用$30$m长的篱笆靠墙围一个矩形花圃，面积为$100\text{m}^2$，求花圃的长和宽。

解：

设垂直于墙的边长为$x$m。

平行于墙的边长为$(30-2x)$m。

面积：$x(30-2x) = 100$。

$30x-2x^2 = 100$。

$2x^2-30x+100 = 0$。

$x^2-15x+50 = 0$。

$(x-5)(x-10) = 0$。

$x = 5$或$x = 10$。

当$x = 5$时，长$= 30-10 = 20$m。

当$x = 10$时，长$= 30-20 = 10$m。

答：长$20$m、宽$5$m或长$10$m、宽$10$m。

**例题4：** 一个矩形场地长$40$m，宽$30$m，中间修两条互相垂直的等宽小路，剩余面积为$900\text{m}^2$，求小路宽度。

解：

设小路宽为$x$m。

用平移法：把两条小路移到边上。

剩余部分拼成一个矩形。

长：$40-x$。

宽：$30-x$。

面积：$(40-x)(30-x) = 900$。

$1200-40x-30x+x^2 = 900$。

$x^2-70x+300 = 0$。

用公式法：$x = \frac{70 \pm \sqrt{4900-1200}}{2} = \frac{70 \pm \sqrt{3700}}{2}$。

取较小根：$x \approx 5$m。

答：小路宽约$5$m。

**例题5：** 一个正方形场地，边长增加$3$m后，面积增加$39\text{m}^2$，求原正方形的边长。

解：

设原正方形边长为$x$m。

原面积：$x^2$。

新面积：$(x+3)^2$。

面积增加：$(x+3)^2-x^2 = 39$。

$x^2+6x+9-x^2 = 39$。

$6x+9 = 39$。

$6x = 30$。

$x = 5$。

答：原正方形边长为$5$m。

## 六、常见错误

**错误1：外框长宽只加一个$x$**

错误做法：外框长$= 20+x$。

正确做法：外框长$= 20+2x$（两边都加）。

**错误2：靠墙围矩形算四面**

错误做法：$2x+2y = 30$。

正确做法：$2x+y = 30$（一面靠墙）。

**错误3：平移法用错**

错误做法：剩余面积$= 40 \times 30 - 2x^2$。

正确做法：剩余面积$= (40-x)(30-x)$。

**错误4：忘记检验解的合理性**

错误做法：算出$x = 25$也保留。

正确做法：$x$不能大于原长宽的一半，舍去。

**错误5：单位不统一**

错误做法：长用m，宽用cm。

正确做法：统一单位。

## 七、练习题

**练习1：** 一个矩形长$12$m，宽$8$m，四周修一条等宽的小路，小路面积为$80\text{m}^2$，求小路宽度。

解：

设小路宽为$x$m。

$(12+2x)(8+2x) - 96 = 80$。

$(12+2x)(8+2x) = 176$。

$96+24x+16x+4x^2 = 176$。

$4x^2+40x-80 = 0$。

$x^2+10x-20 = 0$。

$x = \frac{-10+\sqrt{100+80}}{2} = \frac{-10+\sqrt{180}}{2} \approx 1.7$。

答：小路宽约$1.7$m。

**练习2：** 用$24$m长的篱笆靠墙围一个矩形花圃，面积为$72\text{m}^2$，求花圃的长和宽。

解：

设垂直于墙的边长为$x$m。

平行于墙的边长为$(24-2x)$m。

$x(24-2x) = 72$。

$24x-2x^2 = 72$。

$x^2-12x+36 = 0$。

$(x-6)^2 = 0$。

$x = 6$。

长$= 24-12 = 12$m。

答：长$12$m，宽$6$m。

**练习3：** 一个正方形边长增加$2$m后，面积增加$20\text{m}^2$，求原边长。

解：

设原边长为$x$m。

$(x+2)^2-x^2 = 20$。

$x^2+4x+4-x^2 = 20$。

$4x+4 = 20$。

$4x = 16$。

$x = 4$。

答：原边长为$4$m。

**练习4：** 一个矩形场地长$50$m，宽$40$m，中间修两条互相垂直的等宽小路，剩余面积为$1500\text{m}^2$，求小路宽度。

解：

设小路宽为$x$m。

$(50-x)(40-x) = 1500$。

$2000-50x-40x+x^2 = 1500$。

$x^2-90x+500 = 0$。

$x = \frac{90-\sqrt{8100-2000}}{2} = \frac{90-\sqrt{6100}}{2} \approx 6$m。

答：小路宽约$6$m。

**练习5：** 一个相框外框长$40$cm，宽$30$cm，边框面积$300\text{cm}^2$，求边框宽度。

解：

设边框宽为$x$cm。

内框长：$40-2x$。

内框宽：$30-2x$。

$1200-(40-2x)(30-2x) = 300$。

$(40-2x)(30-2x) = 900$。

$1200-80x-60x+4x^2 = 900$。

$4x^2-140x+300 = 0$。

$x^2-35x+75 = 0$。

$x = \frac{35-\sqrt{1225-300}}{2} \approx 2.4$。

答：边框宽约$2.4$cm。
