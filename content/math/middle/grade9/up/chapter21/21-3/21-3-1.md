# 21.3.1 传播与增长率问题

## 一、传播问题

**每轮传染人数**

一个人传染给$x$个人。

这$x$个人每人又传染给$x$个人。

依次类推。

**公式：$a(1+x)^n = b$**

$a$是初始数量。

$x$是增长率。

$n$是轮数。

$b$是最终数量。

## 二、增长率问题

**$a(1+x)^n = b$**

$a$是原来的量。

$x$是增长率（用小数表示）。

$n$是增长的次数。

$b$是增长后的量。

**例子**

某商品原价$100$元，经过两次涨价，每次涨$10\%$，求现价。

$100 \times (1+0.1)^2 = 100 \times 1.21 = 121$元。

## 三、降低率问题

**$a(1-x)^n = b$**

$x$是降低率（用小数表示）。

其他含义同上。

**例子**

某商品原价$100$元，经过两次降价，每次降$10\%$，求现价。

$100 \times (1-0.1)^2 = 100 \times 0.81 = 81$元。

## 四、增长率和降低率的区别

**增长率用$(1+x)$，降低率用$(1-x)$**

涨价、增长、增加用加号。

降价、降低、减少用减号。

## 五、例题讲解

**例题1：** 某种传染病，最初有$1$人患病，经过两轮传染后共有$121$人患病，求每轮平均一个人传染给几个人。

解：

设每轮平均一个人传染给$x$个人。

第一轮后：$1+x$人。

第二轮后：$(1+x)+x(1+x) = (1+x)^2$人。

$(1+x)^2 = 121$。

$1+x = \pm 11$。

$x = 10$或$x = -12$（舍去）。

答：每轮平均一个人传染给$10$个人。

**例题2：** 某工厂去年的产值是$100$万元，今年的产值是$121$万元，求年增长率。

解：

设年增长率为$x$。

$100(1+x) = 121$。

$1+x = 1.21$。

$x = 0.21 = 21\%$。

答：年增长率为$21\%$。

**例题3：** 某商品原价$200$元，经过两次降价后价格为$162$元，求平均每次降价的百分率。

解：

设平均每次降价的百分率为$x$。

$200(1-x)^2 = 162$。

$(1-x)^2 = 0.81$。

$1-x = 0.9$或$1-x = -0.9$（舍去）。

$x = 0.1 = 10\%$。

答：平均每次降价$10\%$。

**例题4：** 某市前年GDP为$500$亿元，今年GDP为$720$亿元，求这两年的平均增长率。

解：

设平均增长率为$x$。

$500(1+x)^2 = 720$。

$(1+x)^2 = 1.44$。

$1+x = 1.2$或$1+x = -1.2$（舍去）。

$x = 0.2 = 20\%$。

答：平均增长率为$20\%$。

**例题5：** 某药品经过两次降价，每次降价$20\%$，现价为$64$元，求原价。

解：

设原价为$x$元。

$x(1-0.2)^2 = 64$。

$x \times 0.64 = 64$。

$x = 100$。

答：原价为$100$元。

## 六、常见错误

**错误1：忘记平方**

错误做法：$100(1+x) = 121$。

正确做法：$100(1+x)^2 = 121$。

**错误2：增长率写成百分数直接代入**

错误做法：$100(1+21) = 121$。

正确做法：$100(1+0.21) = 121$。

**错误3：降低率用加号**

错误做法：$200(1+0.1)^2 = 162$。

正确做法：$200(1-0.1)^2 = 162$。

**错误4：负根不舍去**

错误做法：$1+x = -11$，$x = -12$也保留。

正确做法：增长率不能为负（在传播问题中），舍去。

**错误5：轮数搞错**

错误做法：两轮传染算成$1+2x$。

正确做法：$(1+x)^2$。

## 七、练习题

**练习1：** 某种细胞每小时分裂一次，$1$个细胞经过$3$小时分裂后变成$8$个，求每小时分裂成几个。

解：

设每小时分裂成$x$个。

$x^3 = 8$。

$x = 2$。

答：每小时分裂成$2$个。

**练习2：** 某商品原价$500$元，经过两次涨价后价格为$605$元，求平均每次涨价的百分率。

解：

设平均每次涨价的百分率为$x$。

$500(1+x)^2 = 605$。

$(1+x)^2 = 1.21$。

$1+x = 1.1$。

$x = 0.1 = 10\%$。

答：平均每次涨价$10\%$。

**练习3：** 某工厂去年产值$200$万元，今年产值$180$万元，求降低率。

解：

设降低率为$x$。

$200(1-x) = 180$。

$1-x = 0.9$。

$x = 0.1 = 10\%$。

答：降低率为$10\%$。

**练习4：** 某种病毒最初$2$人感染，经过两轮传播后共有$72$人感染，求每轮平均一个人传染给几个人。

解：

设每轮平均一个人传染给$x$个人。

$2(1+x)^2 = 72$。

$(1+x)^2 = 36$。

$1+x = 6$。

$x = 5$。

答：每轮平均一个人传染给$5$个人。

**练习5：** 某商品经过两次降价，每次降价$15\%$，现价为$72.25$元，求原价。

解：

设原价为$x$元。

$x(1-0.15)^2 = 72.25$。

$x \times 0.7225 = 72.25$。

$x = 100$。

答：原价为$100$元。
