# 23.2.3 关于原点对称的点的坐标

## 一、点$P(x,y)$关于原点对称的点$P'(-x,-y)$

**坐标变换规律**

横坐标取相反数。

纵坐标取相反数。

$(x,y) \rightarrow (-x,-y)$。

**例子**

$A(2,3)$关于原点对称的点是$A'(-2,-3)$。

$B(-1,4)$关于原点对称的点是$B'(1,-4)$。

## 二、关于$x$轴对称：$(x,-y)$

**坐标变换规律**

横坐标不变。

纵坐标取相反数。

$(x,y) \rightarrow (x,-y)$。

**例子**

$A(2,3)$关于$x$轴对称的点是$A'(2,-3)$。

## 三、关于$y$轴对称：$(-x,y)$

**坐标变换规律**

横坐标取相反数。

纵坐标不变。

$(x,y) \rightarrow (-x,y)$。

**例子**

$A(2,3)$关于$y$轴对称的点是$A'(-2,3)$。

## 四、三种对称的对比记忆

**关于$x$轴对称**

$x$不变，$y$变号。

$(x,y) \rightarrow (x,-y)$。

**关于$y$轴对称**

$x$变号，$y$不变。

$(x,y) \rightarrow (-x,y)$。

**关于原点对称**

$x$、$y$都变号。

$(x,y) \rightarrow (-x,-y)$。

**记忆口诀**

关于谁对称，谁不变。

关于原点对称，都变号。

## 五、利用对称性求函数解析式

**关于$x$轴对称**

$y = f(x)$关于$x$轴对称的函数是$y = -f(x)$。

**关于$y$轴对称**

$y = f(x)$关于$y$轴对称的函数是$y = f(-x)$。

**关于原点对称**

$y = f(x)$关于原点对称的函数是$y = -f(-x)$。

## 六、例题讲解

**例题1：** 求点$A(3,-4)$关于原点、$x$轴、$y$轴对称的点的坐标。

解：

关于原点对称：$(3,-4) \rightarrow (-3,4)$。

关于$x$轴对称：$(3,-4) \rightarrow (3,4)$。

关于$y$轴对称：$(3,-4) \rightarrow (-3,-4)$。

答：关于原点对称$(-3,4)$，关于$x$轴对称$(3,4)$，关于$y$轴对称$(-3,-4)$。

**例题2：** 已知点$P(a,b)$关于原点对称的点是$P'(-2,3)$，求$a$、$b$的值。

解：

$P(a,b)$关于原点对称的点是$P'(-a,-b)$。

$-a = -2$，$-b = 3$。

$a = 2$，$b = -3$。

答：$a = 2$，$b = -3$。

**例题3：** 已知点$A(1,2)$、$B(3,4)$，求线段$AB$关于原点对称的线段$A'B'$的端点坐标。

解：

$A(1,2)$关于原点对称的点是$A'(-1,-2)$。

$B(3,4)$关于原点对称的点是$B'(-3,-4)$。

答：$A'(-1,-2)$，$B'(-3,-4)$。

**例题4：** 已知函数$y = x^2+2x-3$，求它关于$y$轴对称的函数解析式。

解：

关于$y$轴对称，把$x$换成$-x$。

$y = (-x)^2+2(-x)-3$。

$y = x^2-2x-3$。

答：$y = x^2-2x-3$。

**例题5：** 已知点$A(2,1)$、$B(-1,3)$、$C(4,-2)$，求$\triangle ABC$关于原点对称的$\triangle A'B'C'$的面积。

解：

先求$\triangle ABC$的面积。

用坐标公式：$S = \frac{1}{2}|x_1(y_2-y_3)+x_2(y_3-y_1)+x_3(y_1-y_2)|$。

$S = \frac{1}{2}|2(3-(-2))+(-1)((-2)-1)+4(1-3)|$。

$S = \frac{1}{2}|2 \times 5+(-1) \times (-3)+4 \times (-2)|$。

$S = \frac{1}{2}|10+3-8| = \frac{1}{2} \times 5 = 2.5$。

关于原点对称的图形面积不变。

$\triangle A'B'C'$的面积 = $\triangle ABC$的面积 = $2.5$。

答：$\triangle A'B'C'$的面积为$2.5$。

## 七、常见错误

**错误1：坐标变换规律记混**

错误做法：关于$x$轴对称是$(-x,y)$。

正确做法：关于$x$轴对称是$(x,-y)$。

**错误2：符号遗漏**

错误做法：$A(2,-3)$关于原点对称的点是$(2,3)$。

正确做法：$A(2,-3)$关于原点对称的点是$(-2,3)$。

**错误3：关于原点对称与关于$y$轴对称混淆**

错误理解：关于原点对称就是关于$y$轴对称。

正确理解：关于原点对称两个坐标都变号。

**错误4：函数对称变换错误**

错误做法：$y = x^2$关于$y$轴对称是$y = -x^2$。

正确做法：$y = x^2$关于$y$轴对称是$y = (-x)^2 = x^2$。

**错误5：中点公式用错**

错误做法：$A(x,y)$关于原点对称的点是$(\frac{x}{2},\frac{y}{2})$。

正确做法：$A(x,y)$关于原点对称的点是$(-x,-y)$。

## 八、练习题

**练习1：** 求点$P(-5,2)$关于原点、$x$轴、$y$轴对称的点的坐标。

解：

关于原点对称：$(-5,2) \rightarrow (5,-2)$。

关于$x$轴对称：$(-5,2) \rightarrow (-5,-2)$。

关于$y$轴对称：$(-5,2) \rightarrow (5,2)$。

答：关于原点对称$(5,-2)$，关于$x$轴对称$(-5,-2)$，关于$y$轴对称$(5,2)$。

**练习2：** 已知点$M(m,n)$关于$x$轴对称的点是$M'(3,-4)$，求$m$、$n$的值。

解：

$M(m,n)$关于$x$轴对称的点是$M'(m,-n)$。

$m = 3$，$-n = -4$。

$m = 3$，$n = 4$。

答：$m = 3$，$n = 4$。

**练习3：** 已知点$A(-2,3)$、$B(1,-1)$，求线段$AB$关于$y$轴对称的线段$A'B'$的端点坐标。

解：

$A(-2,3)$关于$y$轴对称的点是$A'(2,3)$。

$B(1,-1)$关于$y$轴对称的点是$B'(-1,-1)$。

答：$A'(2,3)$，$B'(-1,-1)$。

**练习4：** 已知函数$y = 2x+1$，求它关于原点对称的函数解析式。

解：

关于原点对称，把$x$换成$-x$，$y$换成$-y$。

$-y = 2(-x)+1$。

$-y = -2x+1$。

$y = 2x-1$。

答：$y = 2x-1$。

**练习5：** 已知点$A(1,2)$、$B(3,1)$、$C(2,4)$，求$\triangle ABC$关于$x$轴对称的$\triangle A'B'C'$的面积。

解：

关于$x$轴对称的图形面积不变。

先求$\triangle ABC$的面积。

$S = \frac{1}{2}|1(1-4)+3(4-2)+2(2-1)|$。

$S = \frac{1}{2}|1 \times (-3)+3 \times 2+2 \times 1|$。

$S = \frac{1}{2}|-3+6+2| = \frac{1}{2} \times 5 = 2.5$。

$\triangle A'B'C'$的面积 = $\triangle ABC$的面积 = $2.5$。

答：$\triangle A'B'C'$的面积为$2.5$。
