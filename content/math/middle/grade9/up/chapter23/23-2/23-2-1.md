# 23.2.1 中心对称的定义与性质

## 一、从生活实例引入

**风车**

风车的叶片绕中心旋转$180°$后与原来重合。

这是中心对称的典型例子。

**太极图**

太极图绕中心旋转$180°$后与原来重合。

黑白两部分互换位置。

**扑克牌图案**

某些扑克牌的图案绕中心旋转$180°$后与原来相同。

如方块、梅花等。

## 二、中心对称的定义

**把一个图形绕某点旋转$180°$后与另一个图形重合**

这个点叫做对称中心。

这两个图形关于这个点中心对称。

**中心对称是旋转的特殊情况**

旋转角为$180°$的旋转就是中心对称。

## 三、对称中心、对称点

**对称中心**

两个图形绕着哪个点对称。

对称中心是对应点连线的中点。

**对称点**

点$A$和点$A'$关于点$O$对称。

$O$是$AA'$的中点。

$OA = OA'$。

## 四、性质1：对称点连线经过对称中心且被对称中心平分

**$O$是$AA'$的中点**

点$A$和点$A'$关于点$O$对称。

$A$、$O$、$A'$三点共线。

$OA = OA'$。

**例子**

$A(2,3)$关于原点$O$的对称点是$A'(-2,-3)$。

$O$是$AA'$的中点。

## 五、性质2：中心对称的两个图形全等

**$\triangle ABC \cong \triangle A'B'C'$**

中心对称不改变图形的形状和大小。

对应边相等。

对应角相等。

## 六、中心对称与旋转的关系

**中心对称是旋转角为$180°$的特殊旋转**

中心对称具有旋转的所有性质。

对应点到对称中心的距离相等。

对应点与对称中心所连线段的夹角等于$180°$。

旋转前后的图形全等。

## 七、例题讲解

**例题1：** 如图，$\triangle ABC$与$\triangle A'B'C'$关于点$O$中心对称。若$OA=3$cm，求$OA'$的长度。

解：

根据中心对称的性质1：对称点连线经过对称中心且被对称中心平分。

$OA' = OA = 3$cm。

答：$OA' = 3$cm。

**例题2：** 如图，$\triangle ABC$与$\triangle A'B'C'$关于点$O$中心对称。若$AB=5$cm，$\angle A = 60°$，求$A'B'$的长度和$\angle A'$的度数。

解：

根据中心对称的性质2：中心对称的两个图形全等。

$\triangle ABC \cong \triangle A'B'C'$。

$A'B' = AB = 5$cm。

$\angle A' = \angle A = 60°$。

答：$A'B' = 5$cm，$\angle A' = 60°$。

**例题3：** 如图，点$A(3,4)$关于原点$O$的对称点是$A'$，求$A'$的坐标。

解：

关于原点对称的点，横纵坐标都取相反数。

$A'(−3,−4)$。

答：$A'(-3,-4)$。

**例题4：** 如图，$\triangle ABC$与$\triangle A'B'C'$关于点$O$中心对称。证明：$AB \parallel A'B'$。

解：

因为$\triangle ABC$与$\triangle A'B'C'$关于点$O$中心对称。

所以$OA = OA'$，$OB = OB'$。

$\angle AOB = \angle A'OB'$（对顶角相等）。

$\triangle AOB \cong \triangle A'OB'$（SAS）。

$\angle OAB = \angle OA'B'$。

所以$AB \parallel A'B'$（内错角相等，两直线平行）。

答：$AB \parallel A'B'$。

**例题5：** 如图，四边形$ABCD$与四边形$A'B'C'D'$关于点$O$中心对称。若四边形$ABCD$的周长为$20$cm，面积为$24\text{cm}^2$，求四边形$A'B'C'D'$的周长和面积。

解：

根据中心对称的性质2：中心对称的两个图形全等。

四边形$A'B'C'D'$的周长 = 四边形$ABCD$的周长 = $20$cm。

四边形$A'B'C'D'$的面积 = 四边形$ABCD$的面积 = $24\text{cm}^2$。

答：周长为$20$cm，面积为$24\text{cm}^2$。

## 八、常见错误

**错误1：对称中心找错**

错误做法：随便选一个点作为对称中心。

正确做法：对称中心是对应点连线的中点。

**错误2：对称点坐标算错**

错误做法：$A(2,3)$关于原点的对称点是$(2,-3)$。

正确做法：$A(2,3)$关于原点的对称点是$(-2,-3)$。

**错误3：中心对称与轴对称混淆**

错误理解：中心对称就是轴对称。

正确理解：中心对称是绕点旋转$180°$，轴对称是沿直线翻折。

**错误4：对应点找错**

错误做法：$A$的对称点是$B'$。

正确做法：$A$的对称点是$A'$。

**错误5：全等性质用错**

错误理解：中心对称的两个图形面积不同。

正确理解：中心对称的两个图形全等，面积相等。

## 九、练习题

**练习1：** 如图，$\triangle ABC$与$\triangle A'B'C'$关于点$O$中心对称。若$OB=4$cm，求$OB'$的长度。

解：

根据中心对称的性质1：$OB' = OB = 4$cm。

答：$OB' = 4$cm。

**练习2：** 如图，点$P(-2,5)$关于原点$O$的对称点是$P'$，求$P'$的坐标。

解：

关于原点对称的点，横纵坐标都取相反数。

$P'(2,-5)$。

答：$P'(2,-5)$。

**练习3：** 如图，$\triangle ABC$与$\triangle A'B'C'$关于点$O$中心对称。若$\angle B = 50°$，$BC=6$cm，求$\angle B'$的度数和$B'C'$的长度。

解：

根据中心对称的性质2：$\triangle ABC \cong \triangle A'B'C'$。

$\angle B' = \angle B = 50°$。

$B'C' = BC = 6$cm。

答：$\angle B' = 50°$，$B'C' = 6$cm。

**练习4：** 如图，线段$AB$与线段$A'B'$关于点$O$中心对称。证明：$AB = A'B'$且$AB \parallel A'B'$。

解：

因为$AB$与$A'B'$关于点$O$中心对称。

所以$OA = OA'$，$OB = OB'$。

$\angle AOB = \angle A'OB'$（对顶角相等）。

$\triangle AOB \cong \triangle A'OB'$（SAS）。

$AB = A'B'$。

$\angle OAB = \angle OA'B'$。

所以$AB \parallel A'B'$。

答：$AB = A'B'$且$AB \parallel A'B'$。

**练习5：** 如图，$\triangle ABC$与$\triangle A'B'C'$关于点$O$中心对称。若$\triangle ABC$的面积为$15\text{cm}^2$，求$\triangle A'B'C'$的面积。

解：

根据中心对称的性质2：$\triangle ABC \cong \triangle A'B'C'$。

$\triangle A'B'C'$的面积 = $\triangle ABC$的面积 = $15\text{cm}^2$。

答：$\triangle A'B'C'$的面积为$15\text{cm}^2$。
