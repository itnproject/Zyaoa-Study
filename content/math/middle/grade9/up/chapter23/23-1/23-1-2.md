# 23.1.2 旋转的性质

## 一、性质1：对应点到旋转中心的距离相等

**$OA = OA'$**

点$A$绕点$O$旋转得到点$A'$。

$OA$和$OA'$的长度相等。

旋转不改变点到旋转中心的距离。

**例子**

点$A$到点$O$的距离是$3$cm。

旋转后点$A'$到点$O$的距离也是$3$cm。

## 二、性质2：对应点与旋转中心所连线段的夹角等于旋转角

**$\angle AOA' = \alpha$**

$\alpha$是旋转角。

对应点与旋转中心所连线段的夹角等于旋转角。

**例子**

旋转角是$60°$。

$\angle AOA' = 60°$。

$\angle BOB' = 60°$。

$\angle COC' = 60°$。

## 三、性质3：旋转前后的图形全等

**$\triangle ABC \cong \triangle A'B'C'$**

旋转不改变图形的形状和大小。

对应边相等：$AB = A'B'$，$AC = A'C'$，$BC = B'C'$。

对应角相等：$\angle A = \angle A'$，$\angle B = \angle B'$，$\angle C = \angle C'$。

## 四、用三角形全等证明旋转性质

**证明$OA = OA'$**

在$\triangle AOB$和$\triangle A'OB'$中。

$OB = OB'$（旋转性质）。

$AB = A'B'$（旋转性质）。

$\angle AOB = \angle A'OB'$（旋转角相等）。

所以$\triangle AOB \cong \triangle A'OB'$（SAS）。

所以$OA = OA'$。

## 五、旋转角的识别与计算

**旋转角的识别**

对应点与旋转中心所连线段的夹角。

$\angle AOA'$、$\angle BOB'$、$\angle COC'$都是旋转角。

它们都相等。

**旋转角的计算**

利用已知条件求旋转角。

可能用到三角形内角和、外角性质等。

## 六、例题讲解

**例题1：** 如图，$\triangle ABC$绕点$O$逆时针旋转$60°$得到$\triangle A'B'C'$。若$OA=4$cm，求$OA'$的长度，并求$\angle AOA'$的度数。

解：

根据旋转性质1：对应点到旋转中心的距离相等。

$OA' = OA = 4$cm。

根据旋转性质2：对应点与旋转中心所连线段的夹角等于旋转角。

$\angle AOA' = 60°$。

答：$OA' = 4$cm，$\angle AOA' = 60°$。

**例题2：** 如图，$\triangle ABC$绕点$A$顺时针旋转得到$\triangle AB'C'$。若$\angle BAC = 50°$，$\angle B'AC = 20°$，求旋转角。

解：

旋转角是$\angle BAB'$或$\angle CAC'$。

$\angle BAB' = \angle BAC - \angle B'AC = 50° - 20° = 30°$。

旋转角是$30°$。

答：旋转角是$30°$。

**例题3：** 如图，$\triangle ABC$绕点$O$旋转得到$\triangle A'B'C'$。若$AB=5$cm，$BC=6$cm，$AC=7$cm，求$A'B'$、$B'C'$、$A'C'$的长度。

解：

根据旋转性质3：旋转前后的图形全等。

$\triangle ABC \cong \triangle A'B'C'$。

$A'B' = AB = 5$cm。

$B'C' = BC = 6$cm。

$A'C' = AC = 7$cm。

答：$A'B' = 5$cm，$B'C' = 6$cm，$A'C' = 7$cm。

**例题4：** 如图，$\triangle ABC$绕点$C$逆时针旋转$90°$得到$\triangle A'B'C$。若$\angle A = 40°$，$\angle B = 60°$，求$\angle A'$、$\angle B'$、$\angle A'CB'$的度数。

解：

根据旋转性质3：旋转前后的图形全等。

$\angle A' = \angle A = 40°$。

$\angle B' = \angle B = 60°$。

$\angle A'CB' = \angle ACB = 180° - 40° - 60° = 80°$。

答：$\angle A' = 40°$，$\angle B' = 60°$，$\angle A'CB' = 80°$。

**例题5：** 如图，$\triangle ABC$绕点$O$旋转得到$\triangle A'B'C'$。若$\angle AOA' = 45°$，$\angle BOB' = 45°$，$\angle COC' = 45°$，求旋转角，并证明$\triangle ABC \cong \triangle A'B'C'$。

解：

旋转角等于对应点与旋转中心所连线段的夹角。

$\angle AOA' = \angle BOB' = \angle COC' = 45°$。

旋转角是$45°$。

证明全等：

$OA = OA'$，$OB = OB'$，$OC = OC'$（性质1）。

$\angle AOB = \angle A'OB'$（旋转角相等）。

$\triangle AOB \cong \triangle A'OB'$（SAS）。

$AB = A'B'$。

同理$AC = A'C'$，$BC = B'C'$。

$\triangle ABC \cong \triangle A'B'C'$（SSS）。

答：旋转角是$45°$，$\triangle ABC \cong \triangle A'B'C'$。

## 七、常见错误

**错误1：旋转角找错**

错误做法：旋转角等于图形的内角。

正确做法：旋转角是对应点与旋转中心所连线段的夹角。

**错误2：对应边找错**

错误做法：$AB$的对应边是$A'C'$。

正确做法：$AB$的对应边是$A'B'$。

**错误3：距离计算错误**

错误做法：$OA' \neq OA$。

正确做法：$OA' = OA$。

**错误4：全等条件用错**

错误做法：用AAA证明全等。

正确做法：用SAS、SSS、ASA、AAS证明全等。

**错误5：旋转角计算错误**

错误做法：旋转角 = $\angle BAC$。

正确做法：旋转角 = $\angle BAB'$或$\angle CAC'$。

## 八、练习题

**练习1：** 如图，$\triangle ABC$绕点$O$逆时针旋转$90°$得到$\triangle A'B'C'$。若$OB=3$cm，求$OB'$的长度，并求$\angle BOB'$的度数。

解：

根据旋转性质1：$OB' = OB = 3$cm。

根据旋转性质2：$\angle BOB' = 90°$。

答：$OB' = 3$cm，$\angle BOB' = 90°$。

**练习2：** 如图，$\triangle ABC$绕点$B$顺时针旋转得到$\triangle A'BC'$。若$\angle ABC = 70°$，$\angle A'BC = 30°$，求旋转角。

解：

旋转角是$\angle ABA'$或$\angle CBC'$。

$\angle ABA' = \angle ABC - \angle A'BC = 70° - 30° = 40°$。

旋转角是$40°$。

答：旋转角是$40°$。

**练习3：** 如图，$\triangle ABC$绕点$O$旋转得到$\triangle A'B'C'$。若$\angle A = 50°$，$\angle B = 70°$，求$\angle A'$、$\angle B'$、$\angle C'$的度数。

解：

根据旋转性质3：$\triangle ABC \cong \triangle A'B'C'$。

$\angle A' = \angle A = 50°$。

$\angle B' = \angle B = 70°$。

$\angle C' = \angle C = 180° - 50° - 70° = 60°$。

答：$\angle A' = 50°$，$\angle B' = 70°$，$\angle C' = 60°$。

**练习4：** 如图，$\triangle ABC$绕点$A$逆时针旋转$60°$得到$\triangle AB'C'$。若$AB=4$cm，$AC=5$cm，求$AB'$、$AC'$的长度和$\angle BAB'$的度数。

解：

根据旋转性质1：$AB' = AB = 4$cm，$AC' = AC = 5$cm。

根据旋转性质2：$\angle BAB' = 60°$。

答：$AB' = 4$cm，$AC' = 5$cm，$\angle BAB' = 60°$。

**练习5：** 如图，$\triangle ABC$绕点$C$旋转得到$\triangle A'B'C$。若$BC=6$cm，$\angle B = 40°$，$\angle A = 60°$，求$B'C$的长度和$\angle A'$、$\angle B'$的度数。

解：

根据旋转性质1：$B'C = BC = 6$cm。

根据旋转性质3：$\triangle ABC \cong \triangle A'B'C$。

$\angle A' = \angle A = 60°$。

$\angle B' = \angle B = 40°$。

答：$B'C = 6$cm，$\angle A' = 60°$，$\angle B' = 40°$。
