# 23.3.2 旋转的综合应用

## 一、旋转在几何证明中的应用

**旋转构造全等三角形**

通过旋转可以将分散的条件集中。

旋转前后的图形全等。

利用全等三角形的性质进行证明。

**例子**

已知$AB = AC$，$\angle BAC = 60°$。

将$\triangle ABC$绕点$A$旋转$60°$。

可以构造等边三角形。

## 二、旋转构造全等三角形

**旋转法**

将图形绕某点旋转一定角度。

旋转后的图形与原图形全等。

利用全等关系证明线段相等或角相等。

**适用情况**

图形中有相等的线段。

图形中有特殊的角度（$60°$、$90°$等）。

需要证明线段相等或角相等。

## 三、旋转与线段最值问题

**旋转转化**

将折线转化为直线。

利用两点之间线段最短。

求线段和的最小值。

**例子**

已知点$A$、$B$在直线$l$同侧。

在$l$上找一点$P$，使$PA+PB$最小。

将$B$关于$l$对称得到$B'$。

$PA+PB = PA+PB'$。

当$A$、$P$、$B'$共线时最小。

## 四、旋转与面积问题

**旋转不改变面积**

旋转前后的图形面积相等。

可以利用旋转将不规则图形转化为规则图形。

**例子**

求阴影部分面积。

通过旋转将阴影部分拼成规则图形。

计算规则图形的面积。

## 五、例题讲解

**例题1：** 如图，在$\triangle ABC$中，$AB = AC$，$\angle BAC = 60°$。将$\triangle ABC$绕点$A$逆时针旋转$60°$得到$\triangle AB'C'$。证明：$\triangle ABB'$是等边三角形。

解：

因为$\triangle ABC$绕点$A$旋转$60°$得到$\triangle AB'C'$。

所以$AB = AB'$（旋转性质）。

$\angle BAB' = 60°$（旋转角）。

在$\triangle ABB'$中，$AB = AB'$，$\angle BAB' = 60°$。

所以$\triangle ABB'$是等边三角形。

答：$\triangle ABB'$是等边三角形。

**例题2：** 如图，正方形$ABCD$中，$E$是$BC$上一点，将$\triangle ABE$绕点$A$逆时针旋转$90°$得到$\triangle ADF$。证明：$EF = BE+DF$。

解：

因为$\triangle ABE$绕点$A$旋转$90°$得到$\triangle ADF$。

所以$BE = DF$（旋转性质）。

$AE = AF$（旋转性质）。

$\angle EAF = 90°$（旋转角）。

在$\triangle AEF$中，$AE = AF$，$\angle EAF = 90°$。

$\triangle AEF$是等腰直角三角形。

$EF = \sqrt{2}AE$。

又因为$BE = DF$。

$EF = BE+DF$。

答：$EF = BE+DF$。

**例题3：** 如图，在$\triangle ABC$中，$\angle C = 90°$，$AC = 3$，$BC = 4$。将$\triangle ABC$绕点$C$逆时针旋转$90°$得到$\triangle A'B'C$。求$AA'$的长度。

解：

因为$\triangle ABC$绕点$C$旋转$90°$得到$\triangle A'B'C$。

所以$CA = CA' = 3$。

$\angle ACA' = 90°$。

在$\triangle ACA'$中，$CA = CA' = 3$，$\angle ACA' = 90°$。

$\triangle ACA'$是等腰直角三角形。

$AA' = \sqrt{3^2+3^2} = \sqrt{18} = 3\sqrt{2}$。

答：$AA' = 3\sqrt{2}$。

**例题4：** 如图，在正方形$ABCD$中，$E$、$F$分别是$BC$、$CD$上的点，且$\angle EAF = 45°$。将$\triangle ABE$绕点$A$逆时针旋转$90°$得到$\triangle ADG$。证明：$EF = BE+DF$。

解：

因为$\triangle ABE$绕点$A$旋转$90°$得到$\triangle ADG$。

所以$BE = DG$，$AE = AG$。

$\angle BAE = \angle DAG$。

$\angle EAF = 45°$。

$\angle BAD = 90°$。

$\angle BAE+\angle DAF = 90°-45° = 45°$。

$\angle DAG+\angle DAF = 45°$。

$\angle GAF = 45°$。

在$\triangle AEF$和$\triangle AGF$中：

$AE = AG$。

$\angle EAF = \angle GAF = 45°$。

$AF = AF$（公共边）。

$\triangle AEF \cong \triangle AGF$（SAS）。

$EF = GF$。

$GF = DG+DF = BE+DF$。

所以$EF = BE+DF$。

答：$EF = BE+DF$。

**例题5：** 如图，$\triangle ABC$是等边三角形，$P$是三角形内一点，$PA = 3$，$PB = 4$，$PC = 5$。将$\triangle ABP$绕点$B$顺时针旋转$60°$得到$\triangle CBP'$。求$\angle APB$的度数。

解：

因为$\triangle ABP$绕点$B$旋转$60°$得到$\triangle CBP'$。

所以$BP = BP' = 4$。

$\angle PBP' = 60°$。

$\triangle PBP'$是等边三角形。

$PP' = 4$。

$AP = CP' = 3$。

在$\triangle PCP'$中，$PC = 5$，$CP' = 3$，$PP' = 4$。

$3^2+4^2 = 9+16 = 25 = 5^2$。

$\triangle PCP'$是直角三角形，$\angle CP'P = 90°$。

$\angle BP'C = \angle BPA$。

$\angle BP'C = \angle BP'P+\angle CP'P = 60°+90° = 150°$。

所以$\angle APB = 150°$。

答：$\angle APB = 150°$。

## 六、常见错误

**错误1：旋转中心选错**

错误做法：旋转中心不是题目要求的点。

正确做法：根据题目条件确定旋转中心。

**错误2：旋转方向搞反**

错误做法：顺时针画成逆时针。

正确做法：注意题目要求的旋转方向。

**错误3：对应点找错**

错误做法：旋转后的对应点找错。

正确做法：旋转前后的点一一对应。

**错误4：全等条件用错**

错误做法：用AAA证明全等。

正确做法：用SAS、SSS、ASA、AAS证明全等。

**错误5：角度计算错误**

错误做法：旋转角不等于对应点与旋转中心所连线段的夹角。

正确做法：旋转角等于对应点与旋转中心所连线段的夹角。

## 七、练习题

**练习1：** 如图，在$\triangle ABC$中，$AB = AC$，$\angle BAC = 90°$。将$\triangle ABC$绕点$A$逆时针旋转$90°$得到$\triangle AB'C'$。证明：$BC \perp B'C'$。

解：

因为$\triangle ABC$绕点$A$旋转$90°$得到$\triangle AB'C'$。

所以$\angle BAB' = 90°$。

$AB = AB'$。

$\angle BAC = \angle B'AC' = 90°$。

$\angle CAC' = 90°$。

$BC$旋转$90°$得到$B'C'$。

所以$BC \perp B'C'$。

答：$BC \perp B'C'$。

**练习2：** 如图，正方形$ABCD$中，$E$是$CD$的中点，将$\triangle ADE$绕点$A$顺时针旋转$90°$得到$\triangle ABF$。证明：$EF = 2DE$。

解：

因为$\triangle ADE$绕点$A$旋转$90°$得到$\triangle ABF$。

所以$DE = BF$，$AE = AF$。

$\angle EAF = 90°$。

$E$是$CD$的中点。

$DE = \frac{1}{2}CD = \frac{1}{2}AB$。

$BF = DE = \frac{1}{2}AB$。

$CF = BC+BF = AB+\frac{1}{2}AB = \frac{3}{2}AB$。

在$\triangle ECF$中，$EC = \frac{1}{2}AB$，$CF = \frac{3}{2}AB$。

$EF = \sqrt{EC^2+CF^2} = \sqrt{(\frac{1}{2}AB)^2+(\frac{3}{2}AB)^2}$。

$EF = \sqrt{\frac{1}{4}AB^2+\frac{9}{4}AB^2} = \sqrt{\frac{10}{4}AB^2} = \frac{\sqrt{10}}{2}AB$。

$2DE = 2 \times \frac{1}{2}AB = AB$。

答：$EF = \frac{\sqrt{10}}{2}AB$。

**练习3：** 如图，在等边$\triangle ABC$中，$D$是$BC$上一点，将$\triangle ABD$绕点$A$逆时针旋转$60°$得到$\triangle ACE$。证明：$\triangle ADE$是等边三角形。

解：

因为$\triangle ABD$绕点$A$旋转$60°$得到$\triangle ACE$。

所以$AD = AE$。

$\angle DAE = 60°$。

在$\triangle ADE$中，$AD = AE$，$\angle DAE = 60°$。

所以$\triangle ADE$是等边三角形。

答：$\triangle ADE$是等边三角形。

**练习4：** 如图，在$\triangle ABC$中，$\angle BAC = 90°$，$AB = AC$。$D$是$BC$上一点，将$\triangle ABD$绕点$A$逆时针旋转$90°$得到$\triangle ACE$。若$BD = 3$，$DC = 4$，求$DE$的长度。

解：

因为$\triangle ABD$绕点$A$旋转$90°$得到$\triangle ACE$。

所以$BD = CE = 3$。

$\angle BAD = \angle CAE$。

$\angle DAE = \angle DAC+\angle CAE = \angle DAC+\angle BAD = \angle BAC = 90°$。

$AD = AE$。

在$\triangle DCE$中，$DC = 4$，$CE = 3$。

$\angle DCE = \angle ACB+\angle ACE = 45°+45° = 90°$。

$DE = \sqrt{DC^2+CE^2} = \sqrt{4^2+3^2} = \sqrt{16+9} = \sqrt{25} = 5$。

答：$DE = 5$。

**练习5：** 如图，正方形$ABCD$的边长为$4$，$E$、$F$分别是$BC$、$CD$上的点，且$BE = 1$，$DF = 2$。将$\triangle ABE$绕点$A$逆时针旋转$90°$得到$\triangle ADG$。求$\triangle AEF$的面积。

解：

因为$\triangle ABE$绕点$A$旋转$90°$得到$\triangle ADG$。

所以$BE = DG = 1$。

$AE = AG$。

$\angle EAG = 90°$。

$CF = CD-DF = 4-2 = 2$。

$CE = BC-BE = 4-1 = 3$。

$EF = \sqrt{CE^2+CF^2} = \sqrt{3^2+2^2} = \sqrt{9+4} = \sqrt{13}$。

$AE = \sqrt{AB^2+BE^2} = \sqrt{4^2+1^2} = \sqrt{16+1} = \sqrt{17}$。

$AF = \sqrt{AD^2+DF^2} = \sqrt{4^2+2^2} = \sqrt{16+4} = \sqrt{20} = 2\sqrt{5}$。

在$\triangle AEF$中，用海伦公式或坐标法求面积。

$S_{\triangle AEF} = S_{\text{正方形}}-S_{\triangle ABE}-S_{\triangle ADF}-S_{\triangle ECF}$。

$S_{\triangle ABE} = \frac{1}{2} \times 4 \times 1 = 2$。

$S_{\triangle ADF} = \frac{1}{2} \times 4 \times 2 = 4$。

$S_{\triangle ECF} = \frac{1}{2} \times 3 \times 2 = 3$。

$S_{\triangle AEF} = 16-2-4-3 = 7$。

答：$\triangle AEF$的面积为$7$。
