# 25.2.2 树状图法求概率

## 一、树状图的适用条件

**三步及以上试验**

试验分三步或更多步进行。

每步都有若干种可能结果。

用树状图可以清晰地列出所有可能结果。

**例子**

连续抛三次硬币。

第一步抛第一次，有2种结果。

第二步抛第二次，有2种结果。

第三步抛第三次，有2种结果。

共8种结果，适合用树状图。

## 二、树状图的画法

**分层画出所有可能**

从起点开始。

第一层画出第一步的所有可能结果。

第二层画出第二步的所有可能结果。

第三层画出第三步的所有可能结果。

**例子**

抛三次硬币：

```
开始
├── 正
│   ├── 正
│   │   ├── 正 → (正,正,正)
│   │   └── 反 → (正,正,反)
│   └── 反
│       ├── 正 → (正,反,正)
│       └── 反 → (正,反,反)
└── 反
    ├── 正
    │   ├── 正 → (反,正,正)
    │   └── 反 → (反,正,反)
    └── 反
        ├── 正 → (反,反,正)
        └── 反 → (反,反,反)
```

## 三、树状图法与列表法的对比

**列表法**

适用于两步试验。

结果较少时使用。

直观清晰。

**树状图法**

适用于三步及以上试验。

结果较多时使用。

层次分明。

**选择**

两步试验优先用列表法。

三步及以上试验优先用树状图法。

## 四、三步摸球问题

**放回摸球**

袋子里有红球和白球。

第一次摸球后放回。

第二次再摸球后放回。

第三次再摸球。

用树状图列出所有可能结果。

**不放回摸球**

袋子里有红球和白球。

第一次摸球后不放回。

第二次再摸球后不放回。

第三次再摸球。

用树状图列出所有可能结果。

## 五、例题讲解

**例题1：** 连续抛三次硬币，用树状图求恰好两次正面朝上的概率。

解：

画树状图（见上文）。

所有可能结果总数 = 8。

恰好两次正面朝上的情况有：(正,正,反)、(正,反,正)、(反,正,正)，共3种。

$P = \frac{3}{8}$。

答：恰好两次正面朝上的概率是$\frac{3}{8}$。

**例题2：** 袋子里有1个红球和2个白球，放回摸三次球，用树状图求恰好两次摸到红球的概率。

解：

每次摸球有3种可能：红、白1、白2。

画树状图。

所有可能结果总数 = $3 \times 3 \times 3 = 27$。

恰好两次摸到红球的情况：

(红,红,白1)、(红,红,白2)、(红,白1,红)、(红,白2,红)、(白1,红,红)、(白2,红,红)，共6种。

$P = \frac{6}{27} = \frac{2}{9}$。

答：恰好两次摸到红球的概率是$\frac{2}{9}$。

**例题3：** 袋子里有2个红球和1个白球，不放回摸三次球，用树状图求第三次摸到红球的概率。

解：

画树状图。

所有可能结果总数 = $3 \times 2 \times 1 = 6$。

第三次摸到红球的情况有：(红1,红2,白)、(红1,白,红2)、(红2,红1,白)、(红2,白,红1)、(白,红1,红2)、(白,红2,红1)。

其中第三次是红球的有：(红1,白,红2)、(红2,白,红1)、(白,红1,红2)、(白,红2,红1)，共4种。

$P = \frac{4}{6} = \frac{2}{3}$。

答：第三次摸到红球的概率是$\frac{2}{3}$。

**例题4：** 从1、2、3中任取三个数（不放回），用树状图求组成的三位数是偶数的概率。

解：

画树状图。

所有可能结果总数 = $3 \times 2 \times 1 = 6$。

组成的三位数有：123、132、213、231、312、321。

偶数有：132、312，共2种。

$P = \frac{2}{6} = \frac{1}{3}$。

答：组成的三位数是偶数的概率是$\frac{1}{3}$。

**例题5：** 连续抛三次硬币，用树状图求至少一次正面朝上的概率。

解：

画树状图。

所有可能结果总数 = 8。

至少一次正面朝上的对立事件是三次都反面朝上。

三次都反面朝上的情况只有1种：(反,反,反)。

至少一次正面朝上的情况有$8-1 = 7$种。

$P = \frac{7}{8}$。

答：至少一次正面朝上的概率是$\frac{7}{8}$。

## 六、常见错误

**错误1：树状图画错**

错误做法：某层漏画分支。

正确做法：每层画出所有可能结果。

**错误2：结果总数数错**

错误做法：数叶子节点时遗漏。

正确做法：仔细数清所有叶子节点。

**错误3：放回与不放回混淆**

错误做法：不放回摸球，树状图中出现相同球。

正确做法：不放回摸球，后续分支减少。

**错误4：条件理解错误**

错误做法：把"至少一次"理解成"恰好一次"。

正确做法：仔细理解题目条件。

**错误5：概率计算错误**

错误做法：$P = \frac{\text{所有可能结果总数}}{\text{符合条件的结果数}}$。

正确做法：$P = \frac{\text{符合条件的结果数}}{\text{所有可能结果总数}}$。

## 七、练习题

**练习1：** 连续抛三次硬币，用树状图求三次都正面朝上的概率。

解：

画树状图。

所有可能结果总数 = 8。

三次都正面朝上的情况只有1种：(正,正,正)。

$P = \frac{1}{8}$。

答：三次都正面朝上的概率是$\frac{1}{8}$。

**练习2：** 袋子里有1个红球和1个白球，放回摸三次球，用树状图求恰好一次摸到红球的概率。

解：

每次摸球有2种可能：红、白。

画树状图。

所有可能结果总数 = $2 \times 2 \times 2 = 8$。

恰好一次摸到红球的情况有：(红,白,白)、(白,红,白)、(白,白,红)，共3种。

$P = \frac{3}{8}$。

答：恰好一次摸到红球的概率是$\frac{3}{8}$。

**练习3：** 从1、2、3、4中任取三个数（不放回），用树状图求组成的三位数能被3整除的概率。

解：

画树状图。

所有可能结果总数 = $4 \times 3 \times 2 = 24$。

能被3整除的条件：各位数字之和能被3整除。

1+2+3=6（能），1+2+4=7（不能），1+3+4=8（不能），2+3+4=9（能）。

能被3整除的组合有：123和234。

123组成的三位数有6种，234组成的三位数有6种。

共12种。

$P = \frac{12}{24} = \frac{1}{2}$。

答：组成的三位数能被3整除的概率是$\frac{1}{2}$。

**练习4：** 袋子里有2个红球和2个白球，不放回摸三次球，用树状图求恰好两次摸到红球的概率。

解：

画树状图。

所有可能结果总数 = $4 \times 3 \times 2 = 24$。

恰好两次摸到红球的情况：

(红1,红2,白1)、(红1,红2,白2)、(红1,白1,红2)、(红1,白2,红2)、(红2,红1,白1)、(红2,红1,白2)、(红2,白1,红1)、(红2,白2,红1)、(白1,红1,红2)、(白1,红2,红1)、(白2,红1,红2)、(白2,红2,红1)，共12种。

$P = \frac{12}{24} = \frac{1}{2}$。

答：恰好两次摸到红球的概率是$\frac{1}{2}$。
