# 25.3.1 概率在实际生活中的应用

## 一、游戏公平性问题

**公平游戏的定义**

每个参与者获胜的概率相等。

这样的游戏是公平的。

**判断方法**

计算每个参与者获胜的概率。

比较概率是否相等。

相等则公平，不相则不公平。

**例子**

抛硬币决定胜负。

正面朝上甲赢，反面朝上乙赢。

$P(\text{甲赢}) = \frac{1}{2}$，$P(\text{乙赢}) = \frac{1}{2}$。

概率相等，游戏公平。

## 二、抽奖活动的概率计算

**抽奖规则**

总共有$n$张奖券。

其中有$m$张中奖券。

每人抽一张。

**中奖概率**

$P(\text{中奖}) = \frac{m}{n}$。

**例子**

100张奖券中有10张中奖券。

$P(\text{中奖}) = \frac{10}{100} = \frac{1}{10}$。

## 三、密码破译的概率

**密码组合**

密码由若干位数字组成。

每位数字有10种可能（0到9）。

**破译概率**

$n$位密码有$10^n$种组合。

随机猜中的概率是$\frac{1}{10^n}$。

**例子**

6位密码有$10^6 = 1000000$种组合。

随机猜中的概率是$\frac{1}{1000000}$。

## 四、生日相同的概率问题

**问题描述**

$n$个人中，至少有两个人生日相同的概率。

**计算方法**

先计算所有人生日都不同的概率。

再用1减去这个概率。

**例子**

23个人中，至少有两人生日相同的概率约为0.5。

30个人中，至少有两人生日相同的概率约为0.7。

## 五、例题讲解

**例题1：** 甲乙两人玩掷骰子游戏，规则是：掷出偶数甲赢，掷出奇数乙赢。判断游戏是否公平。

解：

掷出偶数的情况有2、4、6，共3种。

$P(\text{甲赢}) = \frac{3}{6} = \frac{1}{2}$。

掷出奇数的情况有1、3、5，共3种。

$P(\text{乙赢}) = \frac{3}{6} = \frac{1}{2}$。

$P(\text{甲赢}) = P(\text{乙赢})$。

答：游戏公平。

**例题2：** 某抽奖活动共有500张奖券，其中50张是中奖券。小明买了一张奖券，求他中奖的概率。

解：

总奖券数 = 500。

中奖券数 = 50。

$P(\text{中奖}) = \frac{50}{500} = \frac{1}{10}$。

答：小明中奖的概率是$\frac{1}{10}$。

**例题3：** 某密码是4位数字，随机猜中该密码的概率是多少？

解：

4位密码有$10^4 = 10000$种组合。

随机猜中的概率是$\frac{1}{10000}$。

答：随机猜中该密码的概率是$\frac{1}{10000}$。

**例题4：** 甲乙两人玩掷两个骰子的游戏，规则是：点数之和为偶数甲赢，点数之和为奇数乙赢。判断游戏是否公平。

解：

两个骰子共有36种结果。

点数之和为偶数的情况有18种。

$P(\text{甲赢}) = \frac{18}{36} = \frac{1}{2}$。

点数之和为奇数的情况有18种。

$P(\text{乙赢}) = \frac{18}{36} = \frac{1}{2}$。

$P(\text{甲赢}) = P(\text{乙赢})$。

答：游戏公平。

**例题5：** 某班级有40人，求至少有两人生日相同的概率（一年按365天计算）。

解：

所有人生日都不同的概率：

$P(\text{都不同}) = \frac{365}{365} \times \frac{364}{365} \times \frac{363}{365} \times \cdots \times \frac{326}{365}$。

计算得$P(\text{都不同}) \approx 0.109$。

至少有两人生日相同的概率：

$P = 1-0.109 = 0.891$。

答：至少有两人生日相同的概率约为0.891。

## 六、常见错误

**错误1：公平性判断错误**

错误做法：只看规则，不计算概率。

正确做法：计算每个参与者获胜的概率。

**错误2：抽奖概率计算错误**

错误做法：$P = \frac{\text{总奖券数}}{\text{中奖券数}}$。

正确做法：$P = \frac{\text{中奖券数}}{\text{总奖券数}}$。

**错误3：密码组合数计算错误**

错误做法：4位密码有$4^{10}$种组合。

正确做法：4位密码有$10^4$种组合。

**错误4：生日问题计算错误**

错误做法：直接计算至少两人生日相同的概率。

正确做法：先计算都不同的概率，再用1减。

**错误5：忽略放回与不放回**

错误做法：不放回抽奖，概率不变。

正确做法：不放回抽奖，概率改变。

## 七、练习题

**练习1：** 甲乙两人玩掷骰子游戏，规则是：掷出大于4的点数甲赢，掷出小于3的点数乙赢。判断游戏是否公平。

解：

掷出大于4的情况有5、6，共2种。

$P(\text{甲赢}) = \frac{2}{6} = \frac{1}{3}$。

掷出小于3的情况有1、2，共2种。

$P(\text{乙赢}) = \frac{2}{6} = \frac{1}{3}$。

$P(\text{甲赢}) = P(\text{乙赢})$。

答：游戏公平。

**练习2：** 某抽奖活动共有1000张奖券，其中100张是中奖券。小红买了一张奖券，求她中奖的概率。

解：

总奖券数 = 1000。

中奖券数 = 100。

$P(\text{中奖}) = \frac{100}{1000} = \frac{1}{10}$。

答：小红中奖的概率是$\frac{1}{10}$。

**练习3：** 某密码是3位数字，随机猜中该密码的概率是多少？

解：

3位密码有$10^3 = 1000$种组合。

随机猜中的概率是$\frac{1}{1000}$。

答：随机猜中该密码的概率是$\frac{1}{1000}$。

**练习4：** 甲乙两人玩抛两枚硬币的游戏，规则是：两枚硬币朝上相同甲赢，朝上不同乙赢。判断游戏是否公平。

解：

两枚硬币有4种结果：(正,正)、(正,反)、(反,正)、(反,反)。

朝上相同的情况有2种：(正,正)、(反,反)。

$P(\text{甲赢}) = \frac{2}{4} = \frac{1}{2}$。

朝上不同的情况有2种：(正,反)、(反,正)。

$P(\text{乙赢}) = \frac{2}{4} = \frac{1}{2}$。

$P(\text{甲赢}) = P(\text{乙赢})$。

答：游戏公平。

**练习5：** 某班级有30人，求至少有两人生日相同的概率（一年按365天计算，已知约为0.7）。

解：

所有人生日都不同的概率约为0.3。

至少有两人生日相同的概率：

$P = 1-0.3 = 0.7$。

答：至少有两人生日相同的概率约为0.7。
