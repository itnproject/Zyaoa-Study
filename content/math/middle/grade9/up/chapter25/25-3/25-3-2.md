# 25.3.2 概率与统计的综合应用

## 一、利用统计图表获取概率信息

**条形统计图**

从条形图中读取数据。

计算各类别所占比例。

用比例估计概率。

**扇形统计图**

从扇形图中读取百分比。

百分比就是概率的估计值。

**折线统计图**

从折线图中读取趋势。

用趋势预测概率。

## 二、用样本频率估计总体概率

**抽样调查**

从总体中抽取样本。

计算样本中某事件的频率。

用样本频率估计总体概率。

**例子**

调查1000名学生。

发现有600名学生喜欢数学。

估计所有学生中喜欢数学的概率约为0.6。

## 三、概率与决策问题

**期望值**

期望值 = 各种结果的概率 × 对应结果的数值之和。

用期望值做决策。

**例子**

投资A项目：50%概率赚100元，50%概率亏50元。

期望值 = $0.5 \times 100+0.5 \times (-50) = 25$元。

投资B项目：80%概率赚30元，20%概率亏20元。

期望值 = $0.8 \times 30+0.2 \times (-20) = 20$元。

选择A项目。

## 四、概率与几何图形的结合（几何概型初步）

**几何概型**

试验结果与几何图形的面积有关。

概率 = 目标区域面积 / 总区域面积。

**例子**

在一个边长为4的正方形内随机投点。

求点落在内切圆内的概率。

圆面积 = $\pi \times 2^2 = 4\pi$。

正方形面积 = $4^2 = 16$。

$P = \frac{4\pi}{16} = \frac{\pi}{4}$。

## 五、例题讲解

**例题1：** 某学校调查了500名学生的课外活动情况，结果如下：体育200人，音乐150人，美术100人，其他50人。求随机抽取一名学生，该学生参加体育活动的概率。

解：

总人数 = 500。

参加体育的人数 = 200。

$P(\text{体育}) = \frac{200}{500} = \frac{2}{5}$。

答：随机抽取一名学生参加体育活动的概率是$\frac{2}{5}$。

**例题2：** 某工厂从生产的产品中随机抽取100件进行检测，发现有95件合格。估计该厂产品合格的概率。若该厂生产了10000件产品，估计合格产品有多少件。

解：

样本合格率 = $\frac{95}{100} = 0.95$。

估计产品合格的概率约为0.95。

估计合格产品数量 = $10000 \times 0.95 = 9500$件。

答：估计产品合格的概率约为0.95，合格产品约有9500件。

**例题3：** 某游戏：掷一个骰子，出现6点得10元，出现其他点数得-2元。求玩一次游戏的期望收益。

解：

出现6点的概率 = $\frac{1}{6}$。

出现其他点数的概率 = $\frac{5}{6}$。

期望收益 = $\frac{1}{6} \times 10+\frac{5}{6} \times (-2) = \frac{10}{6}-\frac{10}{6} = 0$元。

答：玩一次游戏的期望收益是0元。

**例题4：** 在一个边长为6的正方形内随机投点，求点落在正方形内切圆内的概率。

解：

正方形边长 = 6。

内切圆半径 = 3。

圆面积 = $\pi \times 3^2 = 9\pi$。

正方形面积 = $6^2 = 36$。

$P = \frac{9\pi}{36} = \frac{\pi}{4}$。

答：点落在内切圆内的概率是$\frac{\pi}{4}$。

**例题5：** 某商场举行抽奖活动，转盘被等分成8份，其中2份是一等奖（价值100元），3份是二等奖（价值50元），3份是三等奖（价值20元）。求抽一次奖的期望收益。

解：

$P(\text{一等奖}) = \frac{2}{8} = \frac{1}{4}$。

$P(\text{二等奖}) = \frac{3}{8}$。

$P(\text{三等奖}) = \frac{3}{8}$。

期望收益 = $\frac{1}{4} \times 100+\frac{3}{8} \times 50+\frac{3}{8} \times 20$。

$= 25+18.75+7.5 = 51.25$元。

答：抽一次奖的期望收益是51.25元。

## 六、常见错误

**错误1：统计图表读取错误**

错误做法：从图表中读取错误数据。

正确做法：仔细读取图表数据。

**错误2：样本代表性忽略**

错误做法：用小样本估计总体。

正确做法：确保样本具有代表性。

**错误3：期望值计算错误**

错误做法：期望值 = 各种结果的数值之和。

正确做法：期望值 = 各种结果的概率 × 对应结果的数值之和。

**错误4：几何概型面积计算错误**

错误做法：用周长比代替面积比。

正确做法：用面积比计算概率。

**错误5：概率与统计混淆**

错误理解：概率就是统计。

正确理解：概率是理论值，统计是实际数据。

## 七、练习题

**练习1：** 某学校调查了800名学生的课外活动情况，结果如下：体育300人，音乐200人，美术150人，其他150人。求随机抽取一名学生，该学生参加音乐活动的概率。

解：

总人数 = 800。

参加音乐的人数 = 200。

$P(\text{音乐}) = \frac{200}{800} = \frac{1}{4}$。

答：随机抽取一名学生参加音乐活动的概率是$\frac{1}{4}$。

**练习2：** 某工厂从生产的产品中随机抽取200件进行检测，发现有190件合格。估计该厂产品合格的概率。若该厂生产了5000件产品，估计合格产品有多少件。

解：

样本合格率 = $\frac{190}{200} = 0.95$。

估计产品合格的概率约为0.95。

估计合格产品数量 = $5000 \times 0.95 = 4750$件。

答：估计产品合格的概率约为0.95，合格产品约有4750件。

**练习3：** 某游戏：掷一个骰子，出现偶数得5元，出现奇数得-3元。求玩一次游戏的期望收益。

解：

出现偶数的概率 = $\frac{3}{6} = \frac{1}{2}$。

出现奇数的概率 = $\frac{3}{6} = \frac{1}{2}$。

期望收益 = $\frac{1}{2} \times 5+\frac{1}{2} \times (-3) = 2.5-1.5 = 1$元。

答：玩一次游戏的期望收益是1元。

**练习4：** 在一个边长为4的正方形内随机投点，求点落在正方形内切圆内的概率。

解：

正方形边长 = 4。

内切圆半径 = 2。

圆面积 = $\pi \times 2^2 = 4\pi$。

正方形面积 = $4^2 = 16$。

$P = \frac{4\pi}{16} = \frac{\pi}{4}$。

答：点落在内切圆内的概率是$\frac{\pi}{4}$。

**练习5：** 某商场举行抽奖活动，转盘被等分成10份，其中1份是一等奖（价值200元），2份是二等奖（价值100元），3份是三等奖（价值50元），4份是未中奖。求抽一次奖的期望收益。

解：

$P(\text{一等奖}) = \frac{1}{10}$。

$P(\text{二等奖}) = \frac{2}{10} = \frac{1}{5}$。

$P(\text{三等奖}) = \frac{3}{10}$。

$P(\text{未中奖}) = \frac{4}{10} = \frac{2}{5}$。

期望收益 = $\frac{1}{10} \times 200+\frac{1}{5} \times 100+\frac{3}{10} \times 50+\frac{2}{5} \times 0$。

$= 20+20+15+0 = 55$元。

答：抽一次奖的期望收益是55元。
