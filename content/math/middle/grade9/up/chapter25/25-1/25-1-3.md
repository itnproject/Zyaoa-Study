# 25.1.3 概率的简单计算

## 一、古典概型

**所有结果等可能且有限**

试验的所有可能结果是有限的。

每个结果出现的可能性相等。

这种试验模型叫古典概型。

**例子**

掷一个骰子，有6种可能结果。

每种结果出现的可能性相等。

这是古典概型。

## 二、概率公式

**$P(A) = \frac{\text{事件}A\text{包含的结果数}}{\text{所有可能结果总数}}$**

分子是事件$A$包含的结果数。

分母是所有可能结果总数。

**例子**

掷一个骰子，求出现偶数的概率。

所有可能结果总数 = 6。

偶数有2、4、6，共3种。

$P(\text{偶数}) = \frac{3}{6} = \frac{1}{2}$。

## 三、摸球问题（放回与不放回）

**放回摸球**

摸出一个球后放回。

再摸第二个球。

每次摸球的结果互不影响。

**不放回摸球**

摸出一个球后不放回。

再摸第二个球。

第二次摸球的结果受第一次影响。

**例子**

袋子里有2个红球和3个白球。

放回摸球：第一次摸到红球的概率是$\frac{2}{5}$。

不放回摸球：第一次摸到红球后，第二次摸到红球的概率是$\frac{1}{4}$。

## 四、掷骰子问题

**一个骰子**

有6种可能结果：1、2、3、4、5、6。

每种结果的可能性相等。

**两个骰子**

有36种可能结果。

每种结果的可能性相等。

**例子**

掷一个骰子，出现点数大于4的概率。

大于4的有5、6，共2种。

$P = \frac{2}{6} = \frac{1}{3}$。

## 五、转盘问题

**等分转盘**

转盘被等分成若干份。

每份被指针指向的可能性相等。

**不等分转盘**

转盘被分成不等的份。

每份被指针指向的可能性不相等。

**例子**

转盘被等分成8份，其中3份是红色。

指针指向红色的概率是$\frac{3}{8}$。

## 六、例题讲解

**例题1：** 掷一个骰子，求出现点数是3的倍数的概率。

解：

所有可能结果：1、2、3、4、5、6，共6种。

3的倍数有3、6，共2种。

$P = \frac{2}{6} = \frac{1}{3}$。

答：出现点数是3的倍数的概率是$\frac{1}{3}$。

**例题2：** 袋子里有3个红球和7个白球，从中摸一个球，求摸到红球的概率。

解：

所有可能结果总数 = 10。

红球有3个。

$P(\text{摸到红球}) = \frac{3}{10}$。

答：摸到红球的概率是$\frac{3}{10}$。

**例题3：** 袋子里有4个红球和6个白球，放回摸两次球，求两次都摸到红球的概率。

解：

第一次摸到红球的概率 = $\frac{4}{10} = \frac{2}{5}$。

放回后，第二次摸到红球的概率 = $\frac{4}{10} = \frac{2}{5}$。

两次都摸到红球的概率 = $\frac{2}{5} \times \frac{2}{5} = \frac{4}{25}$。

答：两次都摸到红球的概率是$\frac{4}{25}$。

**例题4：** 转盘被等分成10份，其中4份是红色，3份是蓝色，3份是绿色。求指针指向红色或蓝色的概率。

解：

所有可能结果总数 = 10。

红色或蓝色共有$4+3 = 7$份。

$P = \frac{7}{10}$。

答：指针指向红色或蓝色的概率是$\frac{7}{10}$。

**例题5：** 掷两个骰子，求点数之和为7的概率。

解：

所有可能结果总数 = $6 \times 6 = 36$。

点数之和为7的情况有：(1,6)、(2,5)、(3,4)、(4,3)、(5,2)、(6,1)，共6种。

$P = \frac{6}{36} = \frac{1}{6}$。

答：点数之和为7的概率是$\frac{1}{6}$。

## 七、常见错误

**错误1：结果总数数错**

错误做法：掷两个骰子，结果总数是12。

正确做法：掷两个骰子，结果总数是36。

**错误2：放回与不放回混淆**

错误做法：不放回摸球，第二次概率不变。

正确做法：不放回摸球，第二次概率改变。

**错误3：等可能条件忽略**

错误做法：不等分转盘，用份数直接算概率。

正确做法：不等分转盘，用面积比算概率。

**错误4：分子分母颠倒**

错误做法：$P(A) = \frac{\text{所有可能结果总数}}{\text{事件}A\text{包含的结果数}}$。

正确做法：$P(A) = \frac{\text{事件}A\text{包含的结果数}}{\text{所有可能结果总数}}$。

**错误5：概率不化简**

错误做法：$P = \frac{3}{6}$。

正确做法：$P = \frac{1}{2}$。

## 八、练习题

**练习1：** 掷一个骰子，求出现点数是质数的概率。

解：

所有可能结果：1、2、3、4、5、6，共6种。

质数有2、3、5，共3种。

$P = \frac{3}{6} = \frac{1}{2}$。

答：出现点数是质数的概率是$\frac{1}{2}$。

**练习2：** 袋子里有5个红球和5个白球，从中摸一个球，求摸到白球的概率。

解：

所有可能结果总数 = 10。

白球有5个。

$P(\text{摸到白球}) = \frac{5}{10} = \frac{1}{2}$。

答：摸到白球的概率是$\frac{1}{2}$。

**练习3：** 袋子里有3个红球和2个白球，不放回摸两次球，求两次都摸到红球的概率。

解：

第一次摸到红球的概率 = $\frac{3}{5}$。

不放回，第二次摸到红球的概率 = $\frac{2}{4} = \frac{1}{2}$。

两次都摸到红球的概率 = $\frac{3}{5} \times \frac{1}{2} = \frac{3}{10}$。

答：两次都摸到红球的概率是$\frac{3}{10}$。

**练习4：** 转盘被等分成12份，其中5份是红色。求指针指向红色的概率。

解：

所有可能结果总数 = 12。

红色有5份。

$P = \frac{5}{12}$。

答：指针指向红色的概率是$\frac{5}{12}$。

**练习5：** 掷两个骰子，求点数之和为8的概率。

解：

所有可能结果总数 = $6 \times 6 = 36$。

点数之和为8的情况有：(2,6)、(3,5)、(4,4)、(5,3)、(6,2)，共5种。

$P = \frac{5}{36}$。

答：点数之和为8的概率是$\frac{5}{36}$。
