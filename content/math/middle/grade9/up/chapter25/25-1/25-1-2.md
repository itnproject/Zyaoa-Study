# 25.1.2 概率的意义

## 一、概率的定义

**刻画随机事件发生可能性大小的数值**

概率用字母$P$表示。

事件$A$的概率记作$P(A)$。

概率是一个介于0和1之间的数。

## 二、概率的取值范围

**$0 \leq P(A) \leq 1$**

概率最小是0。

概率最大是1。

概率不可能是负数。

概率不可能大于1。

## 三、特殊事件的概率

**$P(A) = 0 \Leftrightarrow$ 不可能事件**

不可能事件的概率是0。

例如：掷骰子出现7点的概率是0。

**$P(A) = 1 \Leftrightarrow$ 必然事件**

必然事件的概率是1。

例如：掷骰子出现点数小于7的概率是1。

## 四、概率大小的意义

**概率越接近1，事件越容易发生**

$P(A) = 0.9$表示事件$A$很容易发生。

$P(A) = 0.99$表示事件$A$几乎一定发生。

**概率越接近0，事件越不容易发生**

$P(A) = 0.1$表示事件$A$很难发生。

$P(A) = 0.01$表示事件$A$几乎不可能发生。

## 五、概率与频率的关系

**大量重复试验时频率稳定于概率**

频率 = 事件发生的次数 / 试验总次数。

试验次数越多，频率越接近概率。

**例子**

抛硬币10次，正面朝上6次，频率是0.6。

抛硬币100次，正面朝上52次，频率是0.52。

抛硬币1000次，正面朝上498次，频率是0.498。

频率越来越接近0.5。

## 六、例题讲解

**例题1：** 判断下列概率值是否合理：①$P(A) = 0.5$；②$P(B) = -0.3$；③$P(C) = 1.2$。

解：

①$P(A) = 0.5$：在0到1之间，合理。

②$P(B) = -0.3$：小于0，不合理。

③$P(C) = 1.2$：大于1，不合理。

答：只有①合理。

**例题2：** 掷一个骰子，求出现点数是6的概率。

解：

骰子有6个面，每个面出现的可能性相等。

出现6的情况只有1种。

$P(\text{出现6}) = \frac{1}{6}$。

答：出现点数是6的概率是$\frac{1}{6}$。

**例题3：** 袋子里有3个红球和2个白球，从中摸一个球，求摸到红球的概率。

解：

总共有5个球。

红球有3个。

$P(\text{摸到红球}) = \frac{3}{5}$。

答：摸到红球的概率是$\frac{3}{5}$。

**例题4：** 天气预报说明天下雨的概率是0.8，解释这个概率的意义。

解：

$P(\text{下雨}) = 0.8$。

0.8接近1。

说明明天下雨的可能性很大。

但不是100%会下雨。

答：明天下雨的可能性很大，但不一定下雨。

**例题5：** 抛一枚硬币100次，正面朝上53次。求正面朝上的频率，并估计正面朝上的概率。

解：

频率 = $\frac{53}{100} = 0.53$。

大量重复试验时频率稳定于概率。

估计正面朝上的概率约为0.5。

答：频率是0.53，估计概率约为0.5。

## 七、常见错误

**错误1：概率值超出范围**

错误做法：$P(A) = 1.5$。

正确做法：概率必须在0到1之间。

**错误2：概率与频率混淆**

错误理解：频率就是概率。

正确理解：频率是试验结果，概率是理论值。

**错误3：概率为0认为不可能**

错误理解：概率为0的事件一定不发生。

正确理解：在古典概型中，概率为0是不可能事件。

**错误4：概率为1认为一定发生**

错误理解：概率为1的事件在实际试验中一定发生。

正确理解：概率为1表示理论上一定发生。

**错误5：概率大小理解错误**

错误理解：$P(A) = 0.3$比$P(B) = 0.2$难发生。

正确理解：$P(A) = 0.3$比$P(B) = 0.2$容易发生。

## 八、练习题

**练习1：** 判断下列概率值是否合理：①$P(A) = 0$；②$P(B) = 1$；③$P(C) = -0.5$。

解：

①$P(A) = 0$：在0到1之间，合理（不可能事件）。

②$P(B) = 1$：在0到1之间，合理（必然事件）。

③$P(C) = -0.5$：小于0，不合理。

答：①②合理，③不合理。

**练习2：** 掷一个骰子，求出现点数是偶数的概率。

解：

骰子有6个面。

偶数有2、4、6，共3种。

$P(\text{偶数}) = \frac{3}{6} = \frac{1}{2}$。

答：出现点数是偶数的概率是$\frac{1}{2}$。

**练习3：** 袋子里有4个红球和6个白球，从中摸一个球，求摸到白球的概率。

解：

总共有10个球。

白球有6个。

$P(\text{摸到白球}) = \frac{6}{10} = \frac{3}{5}$。

答：摸到白球的概率是$\frac{3}{5}$。

**练习4：** 某事件发生的概率是0.05，解释这个概率的意义。

解：

$P(A) = 0.05$。

0.05接近0。

说明事件$A$很难发生。

但不是不可能发生。

答：事件$A$很难发生，但有可能发生。

**练习5：** 抛一枚硬币200次，正面朝上98次。求正面朝上的频率，并估计正面朝上的概率。

解：

频率 = $\frac{98}{200} = 0.49$。

大量重复试验时频率稳定于概率。

估计正面朝上的概率约为0.5。

答：频率是0.49，估计概率约为0.5。
