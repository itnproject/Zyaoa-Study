# 22.3.6 二次函数综合应用——等腰三角形与直角三角形

## 一、抛物线上找点构成等腰三角形

**等腰三角形的判定**

两边相等。

两角相等。

**分类讨论**

哪两边相等。

可能有多种情况。

## 二、抛物线上找点构成直角三角形

**直角三角形的判定**

勾股定理。

两直线垂直斜率乘积为 $-1$（高中内容）。

**分类讨论**

哪个角是直角。

可能有多种情况。

## 三、分类讨论思想

**等腰三角形**

$PA=PB$、$PA=AB$、$PB=AB$ 三种情况。

**直角三角形**

$\angle P=90°$、$\angle A=90°$、$\angle B=90°$ 三种情况。

## 四、利用勾股定理和两点间距离公式

**两点间距离公式**

$A(x_1,y_1)$，$B(x_2,y_2)$。

$AB = \sqrt{(x_2-x_1)^2+(y_2-y_1)^2}$。

**勾股定理**

$a^2+b^2=c^2$。

## 五、例题讲解

**例题1：** 如图，抛物线 $y=x^2-4$ 与 $x$ 轴交于 $A$、$B$ 两点。点 $P$ 是抛物线上的动点，当 $\triangle PAB$ 是等腰三角形时，求点 $P$ 的坐标。

解：

求 $A$、$B$ 坐标：$x^2-4=0$。

$x = \pm 2$。

$A(-2,0)$，$B(2,0)$。

设 $P(x,x^2-4)$。

**情况1：$PA=PB$**

$PA^2 = (x+2)^2+(x^2-4)^2$。

$PB^2 = (x-2)^2+(x^2-4)^2$。

$PA^2 = PB^2$。

$(x+2)^2 = (x-2)^2$。

$x^2+4x+4 = x^2-4x+4$。

$8x = 0$。

$x = 0$。

$P(0,-4)$。

**情况2：$PA=AB$**

$AB = 4$。

$PA^2 = 16$。

$(x+2)^2+(x^2-4)^2 = 16$。

展开计算较复杂，此情况可能有解。

**情况3：$PB=AB$**

同理。

答：$P(0,-4)$ 是一个解。

**例题2：** 如图，抛物线 $y=-x^2+1$ 与 $x$ 轴交于 $A$、$B$ 两点，与 $y$ 轴交于点 $C$。点 $P$ 是抛物线上的动点，当 $\triangle PAB$ 是等腰三角形且 $PA=PB$ 时，求点 $P$ 的坐标。

解：

求 $A$、$B$ 坐标：$-x^2+1=0$。

$x = \pm 1$。

$A(-1,0)$，$B(1,0)$。

设 $P(x,-x^2+1)$。

$PA=PB$ 时，$P$ 在 $AB$ 的垂直平分线上。

$AB$ 的垂直平分线是 $y$ 轴。

$x = 0$。

$P(0,1)$。

但 $P$ 不能与 $C$ 重合（否则构不成三角形）。

答：无解（$P$ 与 $C$ 重合）。

**例题3：** 如图，抛物线 $y=x^2-2x-3$ 与 $x$ 轴交于 $A$、$B$ 两点。点 $P$ 是抛物线上的动点，当 $\triangle PAB$ 是直角三角形且 $\angle P=90°$ 时，求点 $P$ 的坐标。

解：

求 $A$、$B$ 坐标：$x^2-2x-3=0$。

$(x-3)(x+1)=0$。

$A(-1,0)$，$B(3,0)$。

设 $P(x,x^2-2x-3)$。

$\angle P=90°$，由勾股定理：

$PA^2+PB^2 = AB^2$。

$PA^2 = (x+1)^2+(x^2-2x-3)^2$。

$PB^2 = (x-3)^2+(x^2-2x-3)^2$。

$AB^2 = 16$。

$(x+1)^2+(x^2-2x-3)^2+(x-3)^2+(x^2-2x-3)^2 = 16$。

$(x+1)^2+(x-3)^2+2(x^2-2x-3)^2 = 16$。

$x^2+2x+1+x^2-6x+9+2(x^2-2x-3)^2 = 16$。

$2x^2-4x+10+2(x^2-2x-3)^2 = 16$。

$2x^2-4x+2(x^2-2x-3)^2 = 6$。

$x^2-2x+(x^2-2x-3)^2 = 3$。

设 $t = x^2-2x$。

$t+(t-3)^2 = 3$。

$t+t^2-6t+9 = 3$。

$t^2-5t+6 = 0$。

$(t-2)(t-3) = 0$。

$t = 2$ 或 $t = 3$。

当 $t=2$ 时：$x^2-2x=2$，$x^2-2x-2=0$，$x = 1 \pm \sqrt{3}$。

当 $t=3$ 时：$x^2-2x=3$，$x^2-2x-3=0$，$x = 3$ 或 $x = -1$（与 $A$、$B$ 重合，舍去）。

$P(1+\sqrt{3},2)$ 或 $P(1-\sqrt{3},2)$。

答：$P(1+\sqrt{3},2)$ 或 $P(1-\sqrt{3},2)$。

**例题4：** 如图，抛物线 $y=-x^2+4$ 与 $x$ 轴交于 $A$、$B$ 两点，与 $y$ 轴交于点 $C$。点 $P$ 是抛物线上的动点，当 $\triangle PAC$ 是等腰三角形且 $PA=PC$ 时，求点 $P$ 的坐标。

解：

求 $A$、$B$、$C$ 坐标：

$A(-2,0)$，$B(2,0)$，$C(0,4)$。

设 $P(x,-x^2+4)$。

$PA^2 = (x+2)^2+(-x^2+4)^2$。

$PC^2 = x^2+(-x^2+4-4)^2 = x^2+x^4$。

$PA^2 = PC^2$。

$(x+2)^2+(-x^2+4)^2 = x^2+x^4$。

$x^2+4x+4+x^4-8x^2+16 = x^2+x^4$。

$4x+4-8x^2+16 = 0$。

$-8x^2+4x+20 = 0$。

$2x^2-x-5 = 0$。

$x = \frac{1 \pm \sqrt{1+40}}{4} = \frac{1 \pm \sqrt{41}}{4}$。

$P(\frac{1+\sqrt{41}}{4},-\frac{1+\sqrt{41}}{16}+4)$ 或 $P(\frac{1-\sqrt{41}}{4},-\frac{1-\sqrt{41}}{16}+4)$。

答：$P(\frac{1 \pm \sqrt{41}}{4},\frac{63 \mp \sqrt{41}}{16})$。

**例题5：** 如图，抛物线 $y=x^2$ 上有两点 $A(1,1)$、$B(-1,1)$。点 $P$ 是抛物线上的动点，当 $\triangle PAB$ 是直角三角形时，求点 $P$ 的坐标。

解：

设 $P(x,x^2)$。

**情况1：$\angle P=90°$**

$PA^2+PB^2 = AB^2$。

$PA^2 = (x-1)^2+(x^2-1)^2$。

$PB^2 = (x+1)^2+(x^2-1)^2$。

$AB^2 = 4$。

$(x-1)^2+(x^2-1)^2+(x+1)^2+(x^2-1)^2 = 4$。

$(x-1)^2+(x+1)^2+2(x^2-1)^2 = 4$。

$x^2-2x+1+x^2+2x+1+2(x^4-2x^2+1) = 4$。

$2x^2+2+2x^4-4x^2+2 = 4$。

$2x^4-2x^2 = 0$。

$2x^2(x^2-1) = 0$。

$x = 0$ 或 $x = \pm 1$（与 $A$、$B$ 重合，舍去）。

$P(0,0)$。

**情况2：$\angle A=90°$**

$PA^2+AB^2 = PB^2$。

$(x-1)^2+(x^2-1)^2+4 = (x+1)^2+(x^2-1)^2$。

$(x-1)^2+4 = (x+1)^2$。

$x^2-2x+1+4 = x^2+2x+1$。

$-2x+4 = 2x$。

$x = 1$（与 $A$ 重合，舍去）。

**情况3：$\angle B=90°$**

同理，$x = -1$（与 $B$ 重合，舍去）。

答：$P(0,0)$。

## 六、常见错误

**错误1：分类讨论不全**

错误做法：只考虑一种情况。

正确做法：等腰三角形考虑三种情况，直角三角形考虑三种情况。

**错误2：距离公式用错**

错误做法：$AB = |x_2-x_1|+|y_2-y_1|$。

正确做法：$AB = \sqrt{(x_2-x_1)^2+(y_2-y_1)^2}$。

**错误3：忘记舍去重合点**

错误做法：求出的点与已知点重合也保留。

正确做法：三点重合不能构成三角形，舍去。

**错误4：勾股定理用错**

错误做法：$a+b=c$。

正确做法：$a^2+b^2=c^2$。

**错误5：计算错误**

错误做法：展开平方时出错。

正确做法：仔细计算，逐步检验。

## 七、练习题

**练习1：** 如图，抛物线 $y=x^2-1$ 与 $x$ 轴交于 $A$、$B$ 两点。点 $P$ 是抛物线上的动点，当 $\triangle PAB$ 是等腰三角形且 $PA=PB$ 时，求点 $P$ 的坐标。

解：

求 $A$、$B$ 坐标：$x^2-1=0$。

$x = \pm 1$。

$A(-1,0)$，$B(1,0)$。

设 $P(x,x^2-1)$。

$PA=PB$ 时，$P$ 在 $AB$ 的垂直平分线上。

$AB$ 的垂直平分线是 $y$ 轴。

$x = 0$。

$P(0,-1)$。

答：$P(0,-1)$。

**练习2：** 如图，抛物线 $y=-x^2+9$ 与 $x$ 轴交于 $A$、$B$ 两点。点 $P$ 是抛物线上的动点，当 $\triangle PAB$ 是等腰三角形且 $PA=PB$ 时，求点 $P$ 的坐标。

解：

求 $A$、$B$ 坐标：$-x^2+9=0$。

$x = \pm 3$。

$A(-3,0)$，$B(3,0)$。

设 $P(x,-x^2+9)$。

$PA=PB$ 时，$P$ 在 $AB$ 的垂直平分线上。

$x = 0$。

$P(0,9)$。

答：$P(0,9)$。

**练习3：** 如图，抛物线 $y=x^2-4x+3$ 与 $x$ 轴交于 $A$、$B$ 两点。点 $P$ 是抛物线上的动点，当 $\triangle PAB$ 是直角三角形且 $\angle P=90°$ 时，求点 $P$ 的坐标。

解：

求 $A$、$B$ 坐标：$x^2-4x+3=0$。

$(x-1)(x-3)=0$。

$A(1,0)$，$B(3,0)$。

设 $P(x,x^2-4x+3)$。

$\angle P=90°$，由勾股定理：

$PA^2+PB^2 = AB^2$。

$PA^2 = (x-1)^2+(x^2-4x+3)^2$。

$PB^2 = (x-3)^2+(x^2-4x+3)^2$。

$AB^2 = 4$。

$(x-1)^2+(x^2-4x+3)^2+(x-3)^2+(x^2-4x+3)^2 = 4$。

$(x-1)^2+(x-3)^2+2(x^2-4x+3)^2 = 4$。

$x^2-2x+1+x^2-6x+9+2(x^2-4x+3)^2 = 4$。

$2x^2-8x+10+2(x^2-4x+3)^2 = 4$。

$2x^2-8x+2(x^2-4x+3)^2 = -6$。

$x^2-4x+(x^2-4x+3)^2 = -3$。

设 $t = x^2-4x$。

$t+(t+3)^2 = -3$。

$t+t^2+6t+9 = -3$。

$t^2+7t+12 = 0$。

$(t+3)(t+4) = 0$。

$t = -3$ 或 $t = -4$。

当 $t=-3$ 时：$x^2-4x=-3$，$x^2-4x+3=0$，$x = 1$ 或 $x = 3$（与 $A$、$B$ 重合，舍去）。

当 $t=-4$ 时：$x^2-4x=-4$，$x^2-4x+4=0$，$(x-2)^2=0$，$x = 2$。

$P(2,-1)$。

答：$P(2,-1)$。

**练习4：** 如图，抛物线 $y=x^2$ 上有两点 $A(2,4)$、$B(-2,4)$。点 $P$ 是抛物线上的动点，当 $\triangle PAB$ 是直角三角形且 $\angle P=90°$ 时，求点 $P$ 的坐标。

解：

设 $P(x,x^2)$。

$\angle P=90°$，由勾股定理：

$PA^2+PB^2 = AB^2$。

$PA^2 = (x-2)^2+(x^2-4)^2$。

$PB^2 = (x+2)^2+(x^2-4)^2$。

$AB^2 = 16$。

$(x-2)^2+(x^2-4)^2+(x+2)^2+(x^2-4)^2 = 16$。

$(x-2)^2+(x+2)^2+2(x^2-4)^2 = 16$。

$x^2-4x+4+x^2+4x+4+2(x^4-8x^2+16) = 16$。

$2x^2+8+2x^4-16x^2+32 = 16$。

$2x^4-14x^2+24 = 0$。

$x^4-7x^2+12 = 0$。

$(x^2-3)(x^2-4) = 0$。

$x^2 = 3$ 或 $x^2 = 4$。

$x = \pm \sqrt{3}$ 或 $x = \pm 2$（与 $A$、$B$ 重合，舍去）。

$P(\sqrt{3},3)$ 或 $P(-\sqrt{3},3)$。

答：$P(\pm \sqrt{3},3)$。

**练习5：** 如图，抛物线 $y=-x^2+4$ 与 $x$ 轴交于 $A$、$B$ 两点，与 $y$ 轴交于点 $C$。点 $P$ 是抛物线上的动点，当 $\triangle PBC$ 是等腰三角形且 $PB=PC$ 时，求点 $P$ 的坐标。

解：

求 $A$、$B$、$C$ 坐标：

$A(-2,0)$，$B(2,0)$，$C(0,4)$。

设 $P(x,-x^2+4)$。

$PB^2 = (x-2)^2+(-x^2+4)^2$。

$PC^2 = x^2+(-x^2+4-4)^2 = x^2+x^4$。

$PB^2 = PC^2$。

$(x-2)^2+(-x^2+4)^2 = x^2+x^4$。

$x^2-4x+4+x^4-8x^2+16 = x^2+x^4$。

$-4x+4-8x^2+16 = 0$。

$-8x^2-4x+20 = 0$。

$2x^2+x-5 = 0$。

$x = \frac{-1 \pm \sqrt{1+40}}{4} = \frac{-1 \pm \sqrt{41}}{4}$。

答：$P(\frac{-1 \pm \sqrt{41}}{4},\frac{63 \pm \sqrt{41}}{16})$。
