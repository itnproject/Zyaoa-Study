# 22.3.3 二次函数的最值应用——拱桥与喷泉

## 一、抛物线形拱桥问题

**建立坐标系**

通常以拱桥的顶点为原点。

或以拱桥的一端为原点。

**待定系数法求解析式**

根据已知点求抛物线的解析式。

## 二、喷泉水柱轨迹问题

**水柱轨迹是抛物线**

水从喷口喷出后沿抛物线运动。

最高点就是抛物线的顶点。

**求最大高度**

求抛物线的顶点纵坐标。

## 三、建立适当的坐标系

**选择原则**

使计算简便。

使已知点坐标简单。

通常选顶点或对称轴上的点为原点。

## 四、待定系数法求解析式

**顶点式：$y=a(x-h)^2+k$**

已知顶点时用顶点式。

**一般式：$y=ax^2+bx+c$**

已知三个点时用一般式。

**交点式：$y=a(x-x_1)(x-x_2)$**

已知与 $x$ 轴的两个交点时用交点式。

## 五、例题讲解

**例题1：** 如图，一座抛物线形拱桥，当水面宽 $4$m 时，拱顶离水面 $2$m。求水面宽 $6$m 时，拱顶离水面多少米。

解：

以拱顶为原点，建立坐标系。

抛物线方程为 $y=ax^2$。

当水面宽 $4$m 时，点 $(2,-2)$ 在抛物线上。

$-2 = a \times 2^2$。

$a = -\frac{1}{2}$。

抛物线方程为 $y = -\frac{1}{2}x^2$。

当水面宽 $6$m 时，$x=3$。

$y = -\frac{1}{2} \times 3^2 = -\frac{9}{2} = -4.5$。

拱顶离水面 $4.5$m。

答：拱顶离水面 $4.5$m。

**例题2：** 如图，喷泉喷出的水柱呈抛物线形，喷口离地面 $1$m，水柱最高点离地面 $3$m，离喷口水平距离 $2$m。求水柱落地点离喷口的水平距离。

解：

以喷口为原点，建立坐标系。

顶点坐标为 $(2,2)$（相对于喷口的高度差）。

抛物线方程为 $y = a(x-2)^2+2$。

喷口 $(0,0)$ 在抛物线上。

$0 = a(0-2)^2+2$。

$0 = 4a+2$。

$a = -\frac{1}{2}$。

抛物线方程为 $y = -\frac{1}{2}(x-2)^2+2$。

水柱落地时 $y = -1$（相对于喷口）。

$-1 = -\frac{1}{2}(x-2)^2+2$。

$-\frac{1}{2}(x-2)^2 = -3$。

$(x-2)^2 = 6$。

$x = 2+\sqrt{6}$ 或 $x = 2-\sqrt{6}$（舍去）。

$x \approx 4.45$m。

答：水柱落地点离喷口约 $4.45$m。

**例题3：** 如图，一座抛物线形拱桥，跨度为 $20$m，拱高为 $5$m。求距拱顶水平距离 $6$m 处的拱高。

解：

以拱顶为原点，建立坐标系。

抛物线方程为 $y = ax^2$。

当 $x=10$ 时，$y=-5$。

$-5 = a \times 100$。

$a = -\frac{1}{20}$。

抛物线方程为 $y = -\frac{1}{20}x^2$。

当 $x=6$ 时，$y = -\frac{1}{20} \times 36 = -1.8$。

该处离拱顶的垂直距离为 $1.8$m。

该处的拱高为 $5-1.8 = 3.2$m。

答：该处的拱高为 $3.2$m。

**例题4：** 如图，喷泉水柱从地面喷出，最高点离地面 $4$m，落地点离喷口 $6$m。求水柱离地面 $3$m 时的水平距离。

解：

以喷口为原点，建立坐标系。

抛物线经过 $(0,0)$ 和 $(6,0)$。

顶点为 $(3,4)$。

抛物线方程为 $y = a(x-3)^2+4$。

把 $(0,0)$ 代入。

$0 = a(0-3)^2+4$。

$0 = 9a+4$。

$a = -\frac{4}{9}$。

抛物线方程为 $y = -\frac{4}{9}(x-3)^2+4$。

当 $y=3$ 时：

$3 = -\frac{4}{9}(x-3)^2+4$。

$-\frac{4}{9}(x-3)^2 = -1$。

$(x-3)^2 = \frac{9}{4}$。

$x-3 = \pm \frac{3}{2}$。

$x = 4.5$ 或 $x = 1.5$。

答：水平距离为 $1.5$m 或 $4.5$m。

**例题5：** 如图，一座抛物线形拱桥，当水面在 $l$ 位置时，水面宽 $8$m，水面离拱顶 $4$m。当水面上升 $1$m 后，求水面宽度。

解：

以拱顶为原点，建立坐标系。

抛物线方程为 $y = ax^2$。

当水面宽 $8$m 时，点 $(4,-4)$ 在抛物线上。

$-4 = a \times 16$。

$a = -\frac{1}{4}$。

抛物线方程为 $y = -\frac{1}{4}x^2$。

水面上升 $1$m 后，$y = -3$。

$-3 = -\frac{1}{4}x^2$。

$x^2 = 12$。

$x = \pm 2\sqrt{3}$。

水面宽度为 $4\sqrt{3} \approx 6.93$m。

答：水面宽度约为 $6.93$m。

## 六、常见错误

**错误1：坐标系建立不合理**

错误做法：随便选原点，导致计算复杂。

正确做法：选顶点或对称点为原点。

**错误2：点的坐标写错**

错误做法：水面宽 $4$m，点坐标写成 $(4,-2)$。

正确做法：点坐标写成 $(2,-2)$（半宽）。

**错误3：待定系数计算错误**

错误做法：代入点时计算错误。

正确做法：仔细代入求解。

**错误4：忽略实际意义**

错误做法：求出负数距离也保留。

正确做法：检验解是否符合实际。

**错误5：解析式形式选错**

错误做法：已知顶点还用一般式。

正确做法：已知顶点用顶点式更简便。

## 七、练习题

**练习1：** 如图，一座抛物线形拱桥，当水面宽 $6$m 时，拱顶离水面 $3$m。求水面宽 $8$m 时，拱顶离水面多少米。

解：

以拱顶为原点，建立坐标系。

抛物线方程为 $y = ax^2$。

当水面宽 $6$m 时，点 $(3,-3)$ 在抛物线上。

$-3 = a \times 9$。

$a = -\frac{1}{3}$。

抛物线方程为 $y = -\frac{1}{3}x^2$。

当水面宽 $8$m 时，$x=4$。

$y = -\frac{1}{3} \times 16 = -\frac{16}{3} \approx -5.33$。

拱顶离水面 $\frac{16}{3}$m。

答：拱顶离水面 $\frac{16}{3}$m。

**练习2：** 如图，喷泉水柱从地面喷出，最高点离地面 $5$m，落地点离喷口 $8$m。求水柱离地面 $4$m 时的水平距离。

解：

以喷口为原点，建立坐标系。

顶点为 $(4,5)$。

抛物线方程为 $y = a(x-4)^2+5$。

把 $(0,0)$ 代入。

$0 = a(0-4)^2+5$。

$0 = 16a+5$。

$a = -\frac{5}{16}$。

抛物线方程为 $y = -\frac{5}{16}(x-4)^2+5$。

当 $y=4$ 时：

$4 = -\frac{5}{16}(x-4)^2+5$。

$-\frac{5}{16}(x-4)^2 = -1$。

$(x-4)^2 = \frac{16}{5}$。

$x-4 = \pm \frac{4}{\sqrt{5}}$。

$x = 4 \pm \frac{4\sqrt{5}}{5}$。

答：水平距离为 $4-\frac{4\sqrt{5}}{5}$m 或 $4+\frac{4\sqrt{5}}{5}$m。

**练习3：** 如图，一座抛物线形拱桥，跨度为 $16$m，拱高为 $4$m。求距拱顶水平距离 $4$m 处的拱高。

解：

以拱顶为原点，建立坐标系。

抛物线方程为 $y = ax^2$。

当 $x=8$ 时，$y=-4$。

$-4 = a \times 64$。

$a = -\frac{1}{16}$。

抛物线方程为 $y = -\frac{1}{16}x^2$。

当 $x=4$ 时，$y = -\frac{1}{16} \times 16 = -1$。

该处离拱顶的垂直距离为 $1$m。

该处的拱高为 $4-1 = 3$m。

答：该处的拱高为 $3$m。

**练习4：** 如图，一座抛物线形拱桥，当水面在 $l$ 位置时，水面宽 $10$m，水面离拱顶 $5$m。当水面上升 $2$m 后，求水面宽度。

解：

以拱顶为原点，建立坐标系。

抛物线方程为 $y = ax^2$。

当水面宽 $10$m 时，点 $(5,-5)$ 在抛物线上。

$-5 = a \times 25$。

$a = -\frac{1}{5}$。

抛物线方程为 $y = -\frac{1}{5}x^2$。

水面上升 $2$m 后，$y = -3$。

$-3 = -\frac{1}{5}x^2$。

$x^2 = 15$。

$x = \pm \sqrt{15}$。

水面宽度为 $2\sqrt{15} \approx 7.75$m。

答：水面宽度约为 $7.75$m。

**练习5：** 如图，喷泉水柱从离地面 $2$m 高的喷口喷出，最高点离地面 $6$m，离喷口水平距离 $3$m。求水柱落地点离喷口的水平距离。

解：

以喷口为原点，建立坐标系。

顶点坐标为 $(3,4)$（相对于喷口的高度差）。

抛物线方程为 $y = a(x-3)^2+4$。

喷口 $(0,0)$ 在抛物线上。

$0 = a(0-3)^2+4$。

$0 = 9a+4$。

$a = -\frac{4}{9}$。

抛物线方程为 $y = -\frac{4}{9}(x-3)^2+4$。

水柱落地时 $y = -2$（相对于喷口）。

$-2 = -\frac{4}{9}(x-3)^2+4$。

$-\frac{4}{9}(x-3)^2 = -6$。

$(x-3)^2 = \frac{54}{4} = \frac{27}{2}$。

$x = 3+\sqrt{\frac{27}{2}} = 3+\frac{3\sqrt{6}}{2} \approx 6.67$。

答：水柱落地点离喷口约 $6.67$m。
