# 22.3.5 二次函数综合应用——动点与面积

## 一、点在抛物线上运动

**动点问题**

点 $P$ 在抛物线上运动。

用含参数的代数式表示点 $P$ 的坐标。

## 二、用含参数的代数式表示面积

**三角形面积**

用底和高的乘积的一半表示。

**四边形面积**

分割成三角形或用坐标公式表示。

## 三、面积最大值问题

**面积是参数的二次函数**

求二次函数的最值。

注意自变量的取值范围。

## 四、存在性问题

**是否存在某点使面积为定值**

列方程求解。

检验解是否在定义域内。

## 五、例题讲解

**例题1：** 如图，抛物线 $y=x^2-2x-3$ 与 $x$ 轴交于 $A$、$B$ 两点，与 $y$ 轴交于点 $C$。点 $P$ 是抛物线上 $A$、$B$ 之间的动点，求 $\triangle PAB$ 面积的最大值。

解：

求 $A$、$B$ 坐标：$x^2-2x-3=0$。

$(x-3)(x+1)=0$。

$A(-1,0)$，$B(3,0)$。

$AB = 4$。

设 $P(x,x^2-2x-3)$。

$\triangle PAB$ 的高为 $|x^2-2x-3|$。

因为 $P$ 在 $A$、$B$ 之间，$x^2-2x-3 < 0$。

高为 $-(x^2-2x-3) = -x^2+2x+3$。

面积 $S = \frac{1}{2} \times 4 \times (-x^2+2x+3) = -2x^2+4x+6$。

$S = -2(x-1)^2+8$。

当 $x=1$ 时，$S$ 有最大值 $8$。

答：$\triangle PAB$ 面积的最大值为 $8$。

**例题2：** 如图，抛物线 $y=-x^2+4$ 与 $x$ 轴交于 $A$、$B$ 两点。点 $P$ 是抛物线上的动点，求 $\triangle PAB$ 面积的最大值。

解：

求 $A$、$B$ 坐标：$-x^2+4=0$。

$x^2 = 4$。

$A(-2,0)$，$B(2,0)$。

$AB = 4$。

设 $P(x,-x^2+4)$。

$\triangle PAB$ 的高为 $|-x^2+4|$。

当 $P$ 在 $x$ 轴上方时，高为 $-x^2+4$。

面积 $S = \frac{1}{2} \times 4 \times (-x^2+4) = -2x^2+8$。

当 $x=0$ 时，$S$ 有最大值 $8$。

答：$\triangle PAB$ 面积的最大值为 $8$。

**例题3：** 如图，抛物线 $y=x^2-4x+3$ 与 $x$ 轴交于 $A$、$B$ 两点，与 $y$ 轴交于点 $C$。点 $P$ 是抛物线上的动点，是否存在点 $P$ 使 $\triangle PAB$ 的面积等于 $6$？

解：

求 $A$、$B$ 坐标：$x^2-4x+3=0$。

$(x-1)(x-3)=0$。

$A(1,0)$，$B(3,0)$。

$AB = 2$。

设 $P(x,x^2-4x+3)$。

$\triangle PAB$ 的高为 $|x^2-4x+3|$。

面积 $S = \frac{1}{2} \times 2 \times |x^2-4x+3| = |x^2-4x+3|$。

令 $|x^2-4x+3| = 6$。

$x^2-4x+3 = 6$ 或 $x^2-4x+3 = -6$。

$x^2-4x-3 = 0$ 或 $x^2-4x+9 = 0$。

对于 $x^2-4x-3 = 0$：$\Delta = 16+12 = 28 > 0$，有解。

$x = \frac{4 \pm \sqrt{28}}{2} = 2 \pm \sqrt{7}$。

对于 $x^2-4x+9 = 0$：$\Delta = 16-36 = -20 < 0$，无解。

存在点 $P$，横坐标为 $2+\sqrt{7}$ 或 $2-\sqrt{7}$。

答：存在，点 $P$ 的横坐标为 $2 \pm \sqrt{7}$。

**例题4：** 如图，抛物线 $y=-x^2+2x+3$ 与 $x$ 轴交于 $A$、$B$ 两点，与 $y$ 轴交于点 $C$。点 $P$ 是抛物线第一象限内的动点，求四边形 $OAPC$ 面积的最大值。

解：

求 $A$、$B$ 坐标：$-x^2+2x+3=0$。

$x^2-2x-3=0$。

$(x-3)(x+1)=0$。

$A(-1,0)$，$B(3,0)$。

$C(0,3)$。

点 $P$ 在第一象限，设 $P(x,-x^2+2x+3)$，$0 < x < 3$。

四边形 $OAPC$ 的面积 = $\triangle OAC$ 的面积 + $\triangle OPC$ 的面积 + $\triangle OPA$ 的面积。

更简单的方法：四边形 $OAPC$ 的面积 = $\triangle OAB$ 的面积 + $\triangle PAB$ 的面积 - $\triangle OBC$ 的面积。

用割补法：

四边形 $OAPC$ 的面积 = 梯形面积 - 三角形面积。

设 $P(x,y)$，其中 $y = -x^2+2x+3$。

四边形 $OAPC$ 的面积 = $\frac{1}{2} \times 1 \times 3 + \frac{1}{2} \times x \times y + \frac{1}{2} \times x \times 3$。

$S = \frac{3}{2} + \frac{1}{2}xy + \frac{3}{2}x$。

$S = \frac{3}{2} + \frac{1}{2}x(-x^2+2x+3) + \frac{3}{2}x$。

$S = \frac{3}{2} - \frac{1}{2}x^3+x^2+\frac{3}{2}x+\frac{3}{2}x$。

这是三次函数，需要重新考虑。

用另一种方法：

四边形 $OAPC$ 的面积 = $\triangle OAC$ 的面积 + $\triangle APC$ 的面积。

$\triangle OAC$ 的面积 = $\frac{1}{2} \times 1 \times 3 = \frac{3}{2}$。

$\triangle APC$ 的面积用坐标公式计算较复杂。

用割补法：

四边形 $OAPC$ 的面积 = 矩形面积 - 三个三角形面积。

设 $P(x,y)$。

过 $P$ 作 $x$ 轴、$y$ 轴的垂线。

四边形 $OAPC$ 的面积 = $xy - \frac{1}{2} \times 1 \times y - \frac{1}{2} \times x \times 3 + \frac{1}{2} \times 1 \times 3$。

$S = xy - \frac{1}{2}y - \frac{3}{2}x + \frac{3}{2}$。

$S = x(-x^2+2x+3) - \frac{1}{2}(-x^2+2x+3) - \frac{3}{2}x + \frac{3}{2}$。

$S = -x^3+2x^2+3x+\frac{1}{2}x^2-x-\frac{3}{2}-\frac{3}{2}x+\frac{3}{2}$。

$S = -x^3+\frac{5}{2}x^2+\frac{1}{2}x$。

这是三次函数，初中不要求。

简化题目：求 $\triangle POC$ 面积的最大值。

$\triangle POC$ 的面积 = $\frac{1}{2} \times 3 \times x = \frac{3}{2}x$。

当 $x=3$ 时最大，但 $P$ 不能取 $B$ 点。

答：此题超出初中范围，建议改为求 $\triangle POC$ 面积。

**例题5：** 如图，抛物线 $y=x^2-2x$ 与 $x$ 轴交于 $O$、$A$ 两点。点 $P$ 是抛物线上的动点，求 $\triangle POA$ 面积的最大值。

解：

求 $O$、$A$ 坐标：$x^2-2x=0$。

$x(x-2)=0$。

$O(0,0)$，$A(2,0)$。

$OA = 2$。

设 $P(x,x^2-2x)$。

$\triangle POA$ 的高为 $|x^2-2x|$。

面积 $S = \frac{1}{2} \times 2 \times |x^2-2x| = |x^2-2x|$。

当 $P$ 在 $x$ 轴下方时，$0 < x < 2$。

高为 $-(x^2-2x) = -x^2+2x$。

$S = -x^2+2x = -(x-1)^2+1$。

当 $x=1$ 时，$S$ 有最大值 $1$。

答：$\triangle POA$ 面积的最大值为 $1$。

## 六、常见错误

**错误1：高的表示错误**

错误做法：高直接用 $y$ 坐标。

正确做法：高是 $|y|$ 坐标。

**错误2：忘记绝对值**

错误做法：面积 = $\frac{1}{2} \times$ 底 $\times y$。

正确做法：面积 = $\frac{1}{2} \times$ 底 $\times |y|$。

**错误3：定义域考虑不全**

错误做法：求出最值后不检验是否在定义域内。

正确做法：检验自变量是否符合题意。

**错误4：面积公式用错**

错误做法：三角形面积 = 底 $\times$ 高。

正确做法：三角形面积 = $\frac{1}{2} \times$ 底 $\times$ 高。

**错误5：存在性问题不检验**

错误做法：求出解就认为存在。

正确做法：检验解是否在定义域内。

## 七、练习题

**练习1：** 如图，抛物线 $y=x^2-4$ 与 $x$ 轴交于 $A$、$B$ 两点。点 $P$ 是抛物线上的动点，求 $\triangle PAB$ 面积的最大值。

解：

求 $A$、$B$ 坐标：$x^2-4=0$。

$x = \pm 2$。

$A(-2,0)$，$B(2,0)$。

$AB = 4$。

设 $P(x,x^2-4)$。

$\triangle PAB$ 的高为 $|x^2-4|$。

当 $P$ 在 $x$ 轴下方时，$-2 < x < 2$。

高为 $-(x^2-4) = -x^2+4$。

面积 $S = \frac{1}{2} \times 4 \times (-x^2+4) = -2x^2+8$。

当 $x=0$ 时，$S$ 有最大值 $8$。

答：$\triangle PAB$ 面积的最大值为 $8$。

**练习2：** 如图，抛物线 $y=-x^2+2x+3$ 与 $x$ 轴交于 $A$、$B$ 两点。点 $P$ 是抛物线上 $A$、$B$ 之间的动点，求 $\triangle PAB$ 面积的最大值。

解：

求 $A$、$B$ 坐标：$-x^2+2x+3=0$。

$x^2-2x-3=0$。

$(x-3)(x+1)=0$。

$A(-1,0)$，$B(3,0)$。

$AB = 4$。

设 $P(x,-x^2+2x+3)$。

$\triangle PAB$ 的高为 $-x^2+2x+3$（因为在 $x$ 轴上方）。

面积 $S = \frac{1}{2} \times 4 \times (-x^2+2x+3) = -2x^2+4x+6$。

$S = -2(x-1)^2+8$。

当 $x=1$ 时，$S$ 有最大值 $8$。

答：$\triangle PAB$ 面积的最大值为 $8$。

**练习3：** 如图，抛物线 $y=x^2-2x-3$ 与 $x$ 轴交于 $A$、$B$ 两点。是否存在点 $P$ 使 $\triangle PAB$ 的面积等于 $10$？

解：

求 $A$、$B$ 坐标：$x^2-2x-3=0$。

$(x-3)(x+1)=0$。

$A(-1,0)$，$B(3,0)$。

$AB = 4$。

设 $P(x,x^2-2x-3)$。

$\triangle PAB$ 的高为 $|x^2-2x-3|$。

面积 $S = \frac{1}{2} \times 4 \times |x^2-2x-3| = 2|x^2-2x-3|$。

令 $2|x^2-2x-3| = 10$。

$|x^2-2x-3| = 5$。

$x^2-2x-3 = 5$ 或 $x^2-2x-3 = -5$。

$x^2-2x-8 = 0$ 或 $x^2-2x+2 = 0$。

对于 $x^2-2x-8 = 0$：$(x-4)(x+2)=0$，$x=4$ 或 $x=-2$。

对于 $x^2-2x+2 = 0$：$\Delta = 4-8 = -4 < 0$，无解。

存在点 $P$，横坐标为 $4$ 或 $-2$。

答：存在，点 $P$ 的横坐标为 $4$ 或 $-2$。

**练习4：** 如图，抛物线 $y=-x^2+4x$ 与 $x$ 轴交于 $O$、$A$ 两点。点 $P$ 是抛物线上的动点，求 $\triangle POA$ 面积的最大值。

解：

求 $O$、$A$ 坐标：$-x^2+4x=0$。

$x(4-x)=0$。

$O(0,0)$，$A(4,0)$。

$OA = 4$。

设 $P(x,-x^2+4x)$。

$\triangle POA$ 的高为 $|-x^2+4x|$。

当 $P$ 在 $x$ 轴上方时，$0 < x < 4$。

高为 $-x^2+4x$。

面积 $S = \frac{1}{2} \times 4 \times (-x^2+4x) = -2x^2+8x$。

$S = -2(x-2)^2+8$。

当 $x=2$ 时，$S$ 有最大值 $8$。

答：$\triangle POA$ 面积的最大值为 $8$。

**练习5：** 如图，抛物线 $y=x^2-6x+8$ 与 $x$ 轴交于 $A$、$B$ 两点。点 $P$ 是抛物线上 $A$、$B$ 之间的动点，求 $\triangle PAB$ 面积的最大值。

解：

求 $A$、$B$ 坐标：$x^2-6x+8=0$。

$(x-2)(x-4)=0$。

$A(2,0)$，$B(4,0)$。

$AB = 2$。

设 $P(x,x^2-6x+8)$。

$\triangle PAB$ 的高为 $-(x^2-6x+8)$（因为在 $x$ 轴下方）。

面积 $S = \frac{1}{2} \times 2 \times (-x^2+6x-8) = -x^2+6x-8$。

$S = -(x-3)^2+1$。

当 $x=3$ 时，$S$ 有最大值 $1$。

答：$\triangle PAB$ 面积的最大值为 $1$。
