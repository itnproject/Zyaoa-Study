# 22.3.1 二次函数的最值应用——面积问题

## 一、用篱笆围矩形面积最大问题

**问题模型**

用一定长度的篱笆围矩形。

求面积最大时的长和宽。

**解题步骤**

设一边长为 $x$。

用含 $x$ 的式子表示另一边长。

列出面积函数。

用配方法或公式法求最值。

**一面靠墙**

## 三、在矩形中截取最大面积

**内接矩形问题**

## 四、例题讲解

**例题1：** 用长为 $20$m 的篱笆围一个矩形，求矩形面积的最大值。

解：

设矩形的一边长为 $x$m。

另一边长为 $(10-x)$m。

面积 $S = x(10-x) = -x^2+10x$。

$S = -(x^2-10x) = -(x-5)^2+25$。

当 $x=5$ 时，$S$ 有最大值 $25$。

答：面积最大值为 $25\text{m}^2$。

**例题2：** 用长为 $24$m 的篱笆靠墙围一个矩形（墙足够长），求矩形面积的最大值。

解：

设垂直于墙的边长为 $x$m。

平行于墙的边长为 $(24-2x)$m。

面积 $S = x(24-2x) = -2x^2+24x$。

$S = -2(x^2-12x) = -2(x-6)^2+72$。

当 $x=6$ 时，$S$ 有最大值 $72$。

答：面积最大值为 $72\text{m}^2$。

**例题3：** 在边长为 $4$ 的正方形 $ABCD$ 中，点 $E$ 在 $AB$ 上，点 $F$ 在 $BC$ 上，且 $AE=BF$，求矩形 $EBFD$ 面积的最大值。

解：

设 $AE=BF=x$。

则 $EB=4-x$，$BF=x$。

矩形 $EBFD$ 的面积 $S = (4-x)x = -x^2+4x$。

$S = -(x-2)^2+4$。

当 $x=2$ 时，$S$ 有最大值 $4$。

答：面积最大值为 $4$。

**例题4：** 用长为 $30$m 的篱笆围一个矩形花圃，中间用一道篱笆隔开，求花圃面积的最大值。

解：

设垂直于隔板的边长为 $x$m。

平行于隔板的边长为 $\frac{30-3x}{2}$m。

面积 $S = x \cdot \frac{30-3x}{2} = -\frac{3}{2}x^2+15x$。

$S = -\frac{3}{2}(x^2-10x) = -\frac{3}{2}(x-5)^2+\frac{75}{2}$。

当 $x=5$ 时，$S$ 有最大值 $\frac{75}{2} = 37.5$。

答：面积最大值为 $37.5\text{m}^2$。

**例题5：** 在一块长 $8$m、宽 $6$m 的矩形空地上，四周修同样宽的小路，中间种花，求种花面积的最大值。

解：

设小路宽为 $x$m。

种花部分的长为 $(8-2x)$m，宽为 $(6-2x)$m。

面积 $S = (8-2x)(6-2x) = 4x^2-28x+48$。

$S = 4(x^2-7x)+48 = 4(x-\frac{7}{2})^2-\frac{1}{4}$。

$a=4>0$，有最小值。

但题目要求最大值，考虑定义域。

$0 < x < 3$。

当 $x$ 接近 $0$ 时，$S$ 接近 $48$。

答：小路宽度接近 $0$ 时，种花面积最大，接近 $48\text{m}^2$。

## 五、常见错误

**错误1：设元不合理**

错误做法：设长和宽两个未知数。

正确做法：设一个未知数，用周长关系表示另一个。

**错误2：忘记定义域**

错误做法：求出最值后不检验是否在定义域内。

正确做法：检验自变量是否符合实际意义。

**错误3：配方法出错**

错误做法：$S = -x^2+10x = -(x-5)^2+5$。

正确做法：$S = -(x-5)^2+25$。

**错误4：靠墙问题边长关系搞错**

错误做法：平行于墙的边长 $= 24-x$。

正确做法：平行于墙的边长 $= 24-2x$。

**错误5：最值类型判断错误**

错误做法：$a>0$ 时求最大值。

正确做法：$a>0$ 时有最小值，$a<0$ 时有最大值。

## 六、练习题

**练习1：** 用长为 $16$m 的篱笆围一个矩形，求矩形面积的最大值。

解：

设一边长为 $x$m。

另一边长为 $(8-x)$m。

面积 $S = x(8-x) = -x^2+8x$。

$S = -(x-4)^2+16$。

当 $x=4$ 时，$S$ 有最大值 $16$。

答：面积最大值为 $16\text{m}^2$。

**练习2：** 用长为 $18$m 的篱笆靠墙围一个矩形，求矩形面积的最大值。

解：

设垂直于墙的边长为 $x$m。

平行于墙的边长为 $(18-2x)$m。

面积 $S = x(18-2x) = -2x^2+18x$。

$S = -2(x-\frac{9}{2})^2+\frac{81}{2}$。

当 $x=\frac{9}{2}$ 时，$S$ 有最大值 $\frac{81}{2} = 40.5$。

答：面积最大值为 $40.5\text{m}^2$。

**练习3：** 在边长为 $6$ 的正方形中，点 $E$ 在 $AB$ 上，点 $F$ 在 $AD$ 上，且 $AE=AF$，求矩形 $AECF$ 面积的最大值。

解：

设 $AE=AF=x$。

矩形面积 $S = x \cdot x = x^2$。

但 $0 < x < 6$。

当 $x$ 接近 $6$ 时，$S$ 接近 $36$。

答：面积最大值接近 $36$（当 $x=6$ 时取到）。

**练习4：** 用长为 $36$m 的篱笆围一个矩形，中间用两道篱笆隔开（平行于一边），求矩形面积的最大值。

解：

设垂直于隔板的边长为 $x$m。

平行于隔板的边长为 $\frac{36-4x}{2} = 18-2x$m。

面积 $S = x(18-2x) = -2x^2+18x$。

$S = -2(x-\frac{9}{2})^2+\frac{81}{2}$。

当 $x=\frac{9}{2}$ 时，$S$ 有最大值 $40.5$。

答：面积最大值为 $40.5\text{m}^2$。

**练习5：** 用长为 $40$m 的篱笆围一个矩形，求矩形面积的最大值及此时的长和宽。

解：

设一边长为 $x$m。

另一边长为 $(20-x)$m。

面积 $S = x(20-x) = -x^2+20x$。

$S = -(x-10)^2+100$。

当 $x=10$ 时，$S$ 有最大值 $100$。

此时长和宽都是 $10$m。

答：面积最大值为 $100\text{m}^2$，此时长和宽都是 $10$m。
