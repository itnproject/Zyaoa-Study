# 22.3.7 二次函数综合应用——平行四边形存在性

## 一、抛物线上找点构成平行四边形

**平行四边形的判定**

两组对边分别平行。

两组对边分别相等。

一组对边平行且相等。

对角线互相平分。

## 二、利用中点坐标公式

**中点坐标公式**

$A(x_1,y_1)$，$B(x_2,y_2)$。

中点坐标为 $(\frac{x_1+x_2}{2},\frac{y_1+y_2}{2})$。

**对角线互相平分**

平行四边形的对角线中点重合。

## 三、分类讨论

**已知边为边或对角线**

已知两点可能是平行四边形的边。

已知两点可能是平行四边形的对角线。

需要分类讨论。

## 四、检验结果的合理性

**点是否在抛物线上**

求出的点必须满足抛物线方程。

**四点是否共线**

四点共线不能构成平行四边形。

## 五、例题讲解

**例题1：** 如图，抛物线 $y=x^2-4$ 与 $x$ 轴交于 $A$、$B$ 两点。点 $P$ 是抛物线上的动点，点 $Q$ 是 $x$ 轴上的动点。是否存在点 $P$、$Q$ 使 $A$、$B$、$P$、$Q$ 构成平行四边形？

解：

求 $A$、$B$ 坐标：$x^2-4=0$。

$x = \pm 2$。

$A(-2,0)$，$B(2,0)$。

设 $P(x,x^2-4)$，$Q(m,0)$。

**情况1：$AB$ 为边**

$AB$ 平行且等于 $PQ$。

$AB$ 在 $x$ 轴上，所以 $PQ$ 也在 $x$ 轴上。

但 $P$ 在抛物线上，$y_P = x^2-4$。

若 $PQ$ 在 $x$ 轴上，则 $y_P = 0$。

$x^2-4 = 0$，$x = \pm 2$。

此时 $P$ 与 $A$ 或 $B$ 重合，不能构成平行四边形。

**情况2：$AB$ 为对角线**

$AB$ 的中点为 $(0,0)$。

$PQ$ 的中点也为 $(0,0)$。

$\frac{x+m}{2} = 0$，$\frac{x^2-4+0}{2} = 0$。

$x^2-4 = 0$，$x = \pm 2$。

此时 $P$ 与 $A$ 或 $B$ 重合，不能构成平行四边形。

答：不存在。

**例题2：** 如图，抛物线 $y=-x^2+4$ 与 $x$ 轴交于 $A$、$B$ 两点，与 $y$ 轴交于点 $C$。点 $P$ 是抛物线上的动点。是否存在点 $P$ 使 $A$、$B$、$C$、$P$ 构成平行四边形？

解：

求 $A$、$B$、$C$ 坐标：

$A(-2,0)$，$B(2,0)$，$C(0,4)$。

设 $P(x,-x^2+4)$。

**情况1：$AB$ 为对角线**

$AB$ 的中点为 $(0,0)$。

$CP$ 的中点也为 $(0,0)$。

$\frac{0+x}{2} = 0$，$\frac{4+(-x^2+4)}{2} = 0$。

$x = 0$，$8-x^2 = 0$。

$x = 0$ 时，$8-0 = 8 \neq 0$。

无解。

**情况2：$AC$ 为对角线**

$AC$ 的中点为 $(-1,2)$。

$BP$ 的中点也为 $(-1,2)$。

$\frac{2+x}{2} = -1$，$\frac{0+(-x^2+4)}{2} = 2$。

$2+x = -2$，$-x^2+4 = 4$。

$x = -4$，$x^2 = 0$。

矛盾，无解。

**情况3：$BC$ 为对角线**

$BC$ 的中点为 $(1,2)$。

$AP$ 的中点也为 $(1,2)$。

$\frac{-2+x}{2} = 1$，$\frac{0+(-x^2+4)}{2} = 2$。

$-2+x = 2$，$-x^2+4 = 4$。

$x = 4$，$x^2 = 0$。

矛盾，无解。

答：不存在。

**例题3：** 如图，抛物线 $y=x^2-2x-3$ 与 $x$ 轴交于 $A$、$B$ 两点，与 $y$ 轴交于点 $C$。点 $P$ 是抛物线上的动点。是否存在点 $P$ 使 $A$、$B$、$C$、$P$ 构成平行四边形？

解：

求 $A$、$B$、$C$ 坐标：

$A(-1,0)$，$B(3,0)$，$C(0,-3)$。

设 $P(x,x^2-2x-3)$。

**情况1：$AB$ 为对角线**

$AB$ 的中点为 $(1,0)$。

$CP$ 的中点也为 $(1,0)$。

$\frac{0+x}{2} = 1$，$\frac{-3+(x^2-2x-3)}{2} = 0$。

$x = 2$，$x^2-2x-6 = 0$。

当 $x=2$ 时，$4-4-6 = -6 \neq 0$。

无解。

**情况2：$AC$ 为对角线**

$AC$ 的中点为 $(-\frac{1}{2},-\frac{3}{2})$。

$BP$ 的中点也为 $(-\frac{1}{2},-\frac{3}{2})$。

$\frac{3+x}{2} = -\frac{1}{2}$，$\frac{0+(x^2-2x-3)}{2} = -\frac{3}{2}$。

$3+x = -1$，$x^2-2x-3 = -3$。

$x = -4$，$x^2-2x = 0$。

当 $x=-4$ 时，$16+8 = 24 \neq 0$。

无解。

**情况3：$BC$ 为对角线**

$BC$ 的中点为 $(\frac{3}{2},-\frac{3}{2})$。

$AP$ 的中点也为 $(\frac{3}{2},-\frac{3}{2})$。

$\frac{-1+x}{2} = \frac{3}{2}$，$\frac{0+(x^2-2x-3)}{2} = -\frac{3}{2}$。

$-1+x = 3$，$x^2-2x-3 = -3$。

$x = 4$，$x^2-2x = 0$。

当 $x=4$ 时，$16-8 = 8 \neq 0$。

无解。

答：不存在。

**例题4：** 如图，抛物线 $y=-x^2+2x+3$ 与 $x$ 轴交于 $A$、$B$ 两点，与 $y$ 轴交于点 $C$。点 $P$ 是抛物线上的动点，点 $Q$ 是 $x$ 轴上的动点。是否存在点 $P$、$Q$ 使 $A$、$C$、$P$、$Q$ 构成平行四边形？

解：

求 $A$、$B$、$C$ 坐标：

$A(-1,0)$，$B(3,0)$，$C(0,3)$。

设 $P(x,-x^2+2x+3)$，$Q(m,0)$。

**情况1：$AC$ 为对角线**

$AC$ 的中点为 $(-\frac{1}{2},\frac{3}{2})$。

$PQ$ 的中点也为 $(-\frac{1}{2},\frac{3}{2})$。

$\frac{x+m}{2} = -\frac{1}{2}$，$\frac{-x^2+2x+3+0}{2} = \frac{3}{2}$。

$x+m = -1$，$-x^2+2x+3 = 3$。

$-x^2+2x = 0$。

$x(2-x) = 0$。

$x = 0$ 或 $x = 2$。

当 $x=0$ 时，$m = -1$，$P(0,3)$ 与 $C$ 重合，舍去。

当 $x=2$ 时，$m = -3$，$P(2,3)$，$Q(-3,0)$。

**情况2：$AP$ 为对角线**

$AP$ 的中点为 $(\frac{-1+x}{2},\frac{-x^2+2x+3}{2})$。

$CQ$ 的中点为 $(\frac{m}{2},\frac{3}{2})$。

$\frac{-1+x}{2} = \frac{m}{2}$，$\frac{-x^2+2x+3}{2} = \frac{3}{2}$。

$-1+x = m$，$-x^2+2x+3 = 3$。

$-x^2+2x = 0$。

$x = 0$ 或 $x = 2$。

当 $x=0$ 时，$m = -1$，$P(0,3)$ 与 $C$ 重合，舍去。

当 $x=2$ 时，$m = 1$，$P(2,3)$，$Q(1,0)$。

**情况3：$AQ$ 为对角线**

$AQ$ 的中点为 $(\frac{-1+m}{2},0)$。

$CP$ 的中点为 $(\frac{x}{2},\frac{-x^2+2x+6}{2})$。

$\frac{-1+m}{2} = \frac{x}{2}$，$0 = \frac{-x^2+2x+6}{2}$。

$-1+m = x$，$-x^2+2x+6 = 0$。

$x^2-2x-6 = 0$。

$x = \frac{2 \pm \sqrt{4+24}}{2} = 1 \pm \sqrt{7}$。

当 $x=1+\sqrt{7}$ 时，$m = 2+\sqrt{7}$。

当 $x=1-\sqrt{7}$ 时，$m = 2-\sqrt{7}$。

答：存在多组解，如 $P(2,3)$、$Q(-3,0)$ 或 $P(2,3)$、$Q(1,0)$ 等。

**例题5：** 如图，抛物线 $y=x^2$ 上有两点 $A(1,1)$、$B(-1,1)$。点 $P$ 是抛物线上的动点，点 $Q$ 是平面内的动点。是否存在点 $P$、$Q$ 使 $A$、$B$、$P$、$Q$ 构成平行四边形且 $AB$ 为对角线？

解：

$AB$ 的中点为 $(0,1)$。

$PQ$ 的中点也为 $(0,1)$。

设 $P(x,x^2)$，$Q(m,n)$。

$\frac{x+m}{2} = 0$，$\frac{x^2+n}{2} = 1$。

$m = -x$，$n = 2-x^2$。

$Q(-x,2-x^2)$。

对于任意 $x$，都存在对应的 $Q$。

例如 $x=2$ 时，$P(2,4)$，$Q(-2,-2)$。

答：存在，如 $P(2,4)$、$Q(-2,-2)$。

## 六、常见错误

**错误1：分类讨论不全**

错误做法：只考虑一种情况。

正确做法：考虑所有可能的对角线组合。

**错误2：中点公式用错**

错误做法：中点坐标 = $(x_1+x_2,y_1+y_2)$。

正确做法：中点坐标 = $(\frac{x_1+x_2}{2},\frac{y_1+y_2}{2})$。

**错误3：忘记检验重合**

错误做法：求出的点与已知点重合也保留。

正确做法：四点重合不能构成平行四边形，舍去。

**错误4：忘记检验共线**

错误做法：四点共线也认为是平行四边形。

正确做法：四点共线不能构成平行四边形。

**错误5：计算错误**

错误做法：解方程时出错。

正确做法：仔细计算，逐步检验。

## 七、练习题

**练习1：** 如图，抛物线 $y=x^2-1$ 与 $x$ 轴交于 $A$、$B$ 两点，与 $y$ 轴交于点 $C$。点 $P$ 是抛物线上的动点。是否存在点 $P$ 使 $A$、$B$、$C$、$P$ 构成平行四边形？

解：

求 $A$、$B$、$C$ 坐标：

$A(-1,0)$，$B(1,0)$，$C(0,-1)$。

设 $P(x,x^2-1)$。

**情况1：$AB$ 为对角线**

$AB$ 的中点为 $(0,0)$。

$CP$ 的中点也为 $(0,0)$。

$\frac{0+x}{2} = 0$，$\frac{-1+(x^2-1)}{2} = 0$。

$x = 0$，$x^2-2 = 0$。

当 $x=0$ 时，$-2 \neq 0$。

无解。

**情况2：$AC$ 为对角线**

$AC$ 的中点为 $(-\frac{1}{2},-\frac{1}{2})$。

$BP$ 的中点也为 $(-\frac{1}{2},-\frac{1}{2})$。

$\frac{1+x}{2} = -\frac{1}{2}$，$\frac{0+(x^2-1)}{2} = -\frac{1}{2}$。

$1+x = -1$，$x^2-1 = -1$。

$x = -2$，$x^2 = 0$。

矛盾，无解。

**情况3：$BC$ 为对角线**

$BC$ 的中点为 $(\frac{1}{2},-\frac{1}{2})$。

$AP$ 的中点也为 $(\frac{1}{2},-\frac{1}{2})$。

$\frac{-1+x}{2} = \frac{1}{2}$，$\frac{0+(x^2-1)}{2} = -\frac{1}{2}$。

$-1+x = 1$，$x^2-1 = -1$。

$x = 2$，$x^2 = 0$。

矛盾，无解。

答：不存在。

**练习2：** 如图，抛物线 $y=-x^2+1$ 与 $x$ 轴交于 $A$、$B$ 两点，与 $y$ 轴交于点 $C$。点 $P$ 是抛物线上的动点，点 $Q$ 是 $x$ 轴上的动点。是否存在点 $P$、$Q$ 使 $A$、$C$、$P$、$Q$ 构成平行四边形？

解：

求 $A$、$B$、$C$ 坐标：

$A(-1,0)$，$B(1,0)$，$C(0,1)$。

设 $P(x,-x^2+1)$，$Q(m,0)$。

**情况1：$AC$ 为对角线**

$AC$ 的中点为 $(-\frac{1}{2},\frac{1}{2})$。

$PQ$ 的中点也为 $(-\frac{1}{2},\frac{1}{2})$。

$\frac{x+m}{2} = -\frac{1}{2}$，$\frac{-x^2+1+0}{2} = \frac{1}{2}$。

$x+m = -1$，$-x^2+1 = 1$。

$-x^2 = 0$。

$x = 0$。

当 $x=0$ 时，$m = -1$，$P(0,1)$ 与 $C$ 重合，舍去。

**情况2：$AP$ 为对角线**

$AP$ 的中点为 $(\frac{-1+x}{2},\frac{-x^2+1}{2})$。

$CQ$ 的中点为 $(\frac{m}{2},\frac{1}{2})$。

$\frac{-1+x}{2} = \frac{m}{2}$，$\frac{-x^2+1}{2} = \frac{1}{2}$。

$-1+x = m$，$-x^2+1 = 1$。

$x = 0$。

当 $x=0$ 时，$m = -1$，$P(0,1)$ 与 $C$ 重合，舍去。

**情况3：$AQ$ 为对角线**

$AQ$ 的中点为 $(\frac{-1+m}{2},0)$。

$CP$ 的中点为 $(\frac{x}{2},\frac{-x^2+2}{2})$。

$\frac{-1+m}{2} = \frac{x}{2}$，$0 = \frac{-x^2+2}{2}$。

$-1+m = x$，$-x^2+2 = 0$。

$x^2 = 2$。

$x = \pm \sqrt{2}$。

当 $x=\sqrt{2}$ 时，$m = 1+\sqrt{2}$。

当 $x=-\sqrt{2}$ 时，$m = 1-\sqrt{2}$。

答：存在，如 $P(\sqrt{2},-1)$、$Q(1+\sqrt{2},0)$。

**练习4：** 如图，抛物线 $y=x^2$ 上有两点 $A(2,4)$、$B(-2,4)$。点 $P$ 是抛物线上的动点，点 $Q$ 是平面内的动点。是否存在点 $P$、$Q$ 使 $A$、$B$、$P$、$Q$ 构成平行四边形且 $AB$ 为对角线？

**练习5：** 如图，抛物线 $y=-x^2+4$ 与 $x$ 轴交于 $A$、$B$ 两点，与 $y$ 轴交于点 $C$。点 $P$ 是抛物线上的动点，点 $Q$ 是 $y$ 轴上的动点。是否存在点 $P$、$Q$ 使 $A$、$C$、$P$、$Q$ 构成平行四边形？

解：

求 $A$、$B$、$C$ 坐标：

$A(-2,0)$，$B(2,0)$，$C(0,4)$。

设 $P(x,-x^2+4)$，$Q(0,n)$。

**情况1：$AC$ 为对角线**

$AC$ 的中点为 $(-1,2)$。

$PQ$ 的中点也为 $(-1,2)$。

$\frac{x+0}{2} = -1$，$\frac{-x^2+4+n}{2} = 2$。

$x = -2$，$-x^2+4+n = 4$。

当 $x=-2$ 时，$-4+4+n = 4$，$n = 4$。

$P(-2,0)$ 与 $A$ 重合，舍去。

**情况2：$AP$ 为对角线**

$AP$ 的中点为 $(\frac{-2+x}{2},\frac{-x^2+4}{2})$。

$CQ$ 的中点为 $(0,\frac{4+n}{2})$。

$\frac{-2+x}{2} = 0$，$\frac{-x^2+4}{2} = \frac{4+n}{2}$。

$-2+x = 0$，$-x^2+4 = 4+n$。

$x = 2$，$n = -x^2 = -4$。

$P(2,0)$ 与 $B$ 重合，但 $A$、$B$、$C$、$Q$ 可以构成平行四边形。

$Q(0,-4)$。

**情况3：$AQ$ 为对角线**

$AQ$ 的中点为 $(-1,\frac{n}{2})$。

$CP$ 的中点为 $(\frac{x}{2},\frac{-x^2+8}{2})$。

$-1 = \frac{x}{2}$，$\frac{n}{2} = \frac{-x^2+8}{2}$。

$x = -2$，$n = -x^2+8 = 4$。

$P(-2,0)$ 与 $A$ 重合，舍去。

答：存在，如 $P(2,0)$、$Q(0,-4)$。
