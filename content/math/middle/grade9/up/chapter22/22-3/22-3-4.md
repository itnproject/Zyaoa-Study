# 22.3.4 二次函数的最值应用——运动轨迹

## 一、篮球投篮轨迹问题

**篮球轨迹是抛物线**

篮球出手后沿抛物线运动。

最高点就是抛物线的顶点。

**求最大高度**

求抛物线的顶点纵坐标。

**求是否进球**

判断篮球经过篮筐位置时的高度。

## 二、铅球/标枪投掷问题

**投掷轨迹是抛物线**

铅球出手后沿抛物线运动。

**求投掷距离**

求抛物线与地面交点的横坐标。

## 三、小球弹跳轨迹问题

**每次弹跳都是抛物线**

每次弹跳的高度逐渐降低。

**求弹跳次数**

根据高度限制求弹跳次数。

## 四、已知图象上的点求解析式

**待定系数法**

根据已知点求抛物线的解析式。

**选择合适的形式**

已知顶点用顶点式。

已知与 $x$ 轴交点用交点式。

已知三个点用一般式。

## 五、例题讲解

**例题1：** 小明投篮，篮球出手点离地面 $2$m，篮球运动的轨迹是抛物线。当篮球水平飞行 $4$m 时达到最高点，最高点离地面 $4$m。求篮球运动的解析式，并判断当篮球水平飞行 $8$m 时的高度。

解：

以出手点在地面的投影为原点，建立坐标系。

出手点坐标为 $(0,2)$。

顶点坐标为 $(4,4)$。

抛物线方程为 $y = a(x-4)^2+4$。

把 $(0,2)$ 代入。

$2 = a(0-4)^2+4$。

$2 = 16a+4$。

$16a = -2$。

$a = -\frac{1}{8}$。

抛物线方程为 $y = -\frac{1}{8}(x-4)^2+4$。

当 $x=8$ 时：

$y = -\frac{1}{8}(8-4)^2+4 = -\frac{1}{8} \times 16+4 = -2+4 = 2$。

答：解析式为 $y = -\frac{1}{8}(x-4)^2+4$，当 $x=8$ 时高度为 $2$m。

**例题2：** 某运动员投铅球，铅球出手点离地面 $1.5$m，铅球运动的轨迹是抛物线。当铅球水平飞行 $6$m 时达到最高点，最高点离地面 $3.5$m。求铅球的投掷距离。

解：

以出手点在地面的投影为原点，建立坐标系。

出手点坐标为 $(0,1.5)$。

顶点坐标为 $(6,3.5)$。

抛物线方程为 $y = a(x-6)^2+3.5$。

把 $(0,1.5)$ 代入。

$1.5 = a(0-6)^2+3.5$。

$1.5 = 36a+3.5$。

$36a = -2$。

$a = -\frac{1}{18}$。

抛物线方程为 $y = -\frac{1}{18}(x-6)^2+3.5$。

铅球落地时 $y=0$：

$0 = -\frac{1}{18}(x-6)^2+3.5$。

$(x-6)^2 = 63$。

$x = 6+\sqrt{63} \approx 13.94$ 或 $x = 6-\sqrt{63}$（舍去）。

答：铅球的投掷距离约为 $13.94$m。

**例题3：** 小球从地面弹出，第一次弹跳的轨迹是抛物线，最高点离地面 $3$m，落地点离弹出点 $4$m。求小球第一次弹跳的解析式。

解：

以弹出点为原点，建立坐标系。

抛物线经过 $(0,0)$ 和 $(4,0)$。

顶点为 $(2,3)$。

抛物线方程为 $y = a(x-2)^2+3$。

把 $(0,0)$ 代入。

$0 = a(0-2)^2+3$。

$0 = 4a+3$。

$a = -\frac{3}{4}$。

抛物线方程为 $y = -\frac{3}{4}(x-2)^2+3$。

答：$y = -\frac{3}{4}(x-2)^2+3$。

**例题4：** 小明投篮，篮球出手点离地面 $2.2$m，篮筐离地面 $3.05$m，篮筐离出手点水平距离 $7$m。篮球运动的轨迹是抛物线，当篮球水平飞行 $4$m 时达到最高点，最高点离地面 $4.5$m。判断篮球能否投进。

解：

以出手点在地面的投影为原点，建立坐标系。

出手点坐标为 $(0,2.2)$。

顶点坐标为 $(4,4.5)$。

抛物线方程为 $y = a(x-4)^2+4.5$。

把 $(0,2.2)$ 代入。

$2.2 = a(0-4)^2+4.5$。

$2.2 = 16a+4.5$。

$16a = -2.3$。

$a = -\frac{2.3}{16} = -0.14375$。

抛物线方程为 $y = -0.14375(x-4)^2+4.5$。

当 $x=7$ 时：

$y = -0.14375(7-4)^2+4.5 = -0.14375 \times 9+4.5 = -1.29375+4.5 = 3.20625$。

$3.20625 > 3.05$。

篮球在篮筐上方，不能投进。

答：不能投进。

**例题5：** 某同学推铅球，铅球出手点离地面 $1.8$m，铅球运动的轨迹是抛物线。已知铅球经过点 $(5,3)$ 和 $(10,2)$，求铅球的投掷距离。

解：

以出手点在地面的投影为原点，建立坐标系。

出手点坐标为 $(0,1.8)$。

设抛物线方程为 $y = ax^2+bx+c$。

把 $(0,1.8)$ 代入：$c = 1.8$。

把 $(5,3)$ 代入：$25a+5b+1.8 = 3$，即 $25a+5b = 1.2$。

把 $(10,2)$ 代入：$100a+10b+1.8 = 2$，即 $100a+10b = 0.2$。

解方程组：

$25a+5b = 1.2$ ①

$100a+10b = 0.2$ ②

② $-2 \times$ ①：$50a = -2.2$。

$a = -0.044$。

代入①：$25 \times (-0.044)+5b = 1.2$。

$-1.1+5b = 1.2$。

$5b = 2.3$。

$b = 0.46$。

抛物线方程为 $y = -0.044x^2+0.46x+1.8$。

铅球落地时 $y=0$：

$-0.044x^2+0.46x+1.8 = 0$。

用公式法：$x = \frac{-0.46 \pm \sqrt{0.2116+0.3168}}{-0.088} = \frac{-0.46 \pm \sqrt{0.5284}}{-0.088} \approx \frac{-0.46 \pm 0.727}{-0.088}$。

$x \approx 13.49$ 或 $x \approx -3.03$（舍去）。

答：铅球的投掷距离约为 $13.49$m。

## 六、常见错误

**错误1：坐标系建立不合理**

错误做法：以出手点为原点，导致地面不在 $x$ 轴上。

正确做法：以出手点在地面的投影为原点。

**错误2：点的坐标写错**

错误做法：出手点坐标写成 $(0,0)$。

正确做法：出手点坐标写成 $(0,h)$，$h$ 是出手高度。

**错误3：落地条件搞错**

错误做法：落地时 $y=h$（出手高度）。

正确做法：落地时 $y=0$（地面）。

**错误4：解析式形式选错**

错误做法：已知三个点还用顶点式。

正确做法：已知三个点用一般式。

**错误5：计算错误**

错误做法：解方程组时计算错误。

正确做法：仔细计算，检验结果。

## 七、练习题

**练习1：** 小明投篮，篮球出手点离地面 $2$m，篮球运动的轨迹是抛物线。当篮球水平飞行 $3$m 时达到最高点，最高点离地面 $3.5$m。求篮球运动的解析式。

解：

以出手点在地面的投影为原点，建立坐标系。

出手点坐标为 $(0,2)$。

顶点坐标为 $(3,3.5)$。

抛物线方程为 $y = a(x-3)^2+3.5$。

把 $(0,2)$ 代入。

$2 = a(0-3)^2+3.5$。

$2 = 9a+3.5$。

$9a = -1.5$。

$a = -\frac{1}{6}$。

抛物线方程为 $y = -\frac{1}{6}(x-3)^2+3.5$。

答：$y = -\frac{1}{6}(x-3)^2+3.5$。

**练习2：** 某运动员投铅球，铅球出手点离地面 $2$m，铅球运动的轨迹是抛物线。当铅球水平飞行 $5$m 时达到最高点，最高点离地面 $4$m。求铅球的投掷距离。

解：

以出手点在地面的投影为原点，建立坐标系。

出手点坐标为 $(0,2)$。

顶点坐标为 $(5,4)$。

抛物线方程为 $y = a(x-5)^2+4$。

把 $(0,2)$ 代入。

$2 = a(0-5)^2+4$。

$2 = 25a+4$。

$25a = -2$。

$a = -\frac{2}{25}$。

抛物线方程为 $y = -\frac{2}{25}(x-5)^2+4$。

铅球落地时 $y=0$：

$0 = -\frac{2}{25}(x-5)^2+4$。

$(x-5)^2 = 50$。

$x = 5+\sqrt{50} = 5+5\sqrt{2} \approx 12.07$。

答：铅球的投掷距离约为 $12.07$m。

**练习3：** 小球从地面弹出，第一次弹跳的轨迹是抛物线，最高点离地面 $4$m，落地点离弹出点 $6$m。求小球第一次弹跳的解析式。

解：

以弹出点为原点，建立坐标系。

抛物线经过 $(0,0)$ 和 $(6,0)$。

顶点为 $(3,4)$。

抛物线方程为 $y = a(x-3)^2+4$。

把 $(0,0)$ 代入。

$0 = a(0-3)^2+4$。

$0 = 9a+4$。

$a = -\frac{4}{9}$。

抛物线方程为 $y = -\frac{4}{9}(x-3)^2+4$。

答：$y = -\frac{4}{9}(x-3)^2+4$。

**练习4：** 小明投篮，篮球出手点离地面 $2.5$m，篮筐离地面 $3.05$m，篮筐离出手点水平距离 $6$m。篮球运动的轨迹是抛物线，当篮球水平飞行 $3$m 时达到最高点，最高点离地面 $4$m。判断篮球能否投进。

解：

以出手点在地面的投影为原点，建立坐标系。

出手点坐标为 $(0,2.5)$。

顶点坐标为 $(3,4)$。

抛物线方程为 $y = a(x-3)^2+4$。

把 $(0,2.5)$ 代入。

$2.5 = a(0-3)^2+4$。

$2.5 = 9a+4$。

$9a = -1.5$。

$a = -\frac{1}{6}$。

抛物线方程为 $y = -\frac{1}{6}(x-3)^2+4$。

当 $x=6$ 时：

$y = -\frac{1}{6}(6-3)^2+4 = -\frac{1}{6} \times 9+4 = -1.5+4 = 2.5$。

$2.5 < 3.05$。

篮球在篮筐下方，不能投进。

答：不能投进。

**练习5：** 某同学推铅球，铅球出手点离地面 $1.5$m，铅球运动的轨迹是抛物线。已知铅球经过点 $(4,2.5)$ 和 $(8,2)$，求铅球的投掷距离。

解：

以出手点在地面的投影为原点，建立坐标系。

出手点坐标为 $(0,1.5)$。

设抛物线方程为 $y = ax^2+bx+c$。

把 $(0,1.5)$ 代入：$c = 1.5$。

把 $(4,2.5)$ 代入：$16a+4b+1.5 = 2.5$，即 $16a+4b = 1$。

把 $(8,2)$ 代入：$64a+8b+1.5 = 2$，即 $64a+8b = 0.5$。

解方程组：

$16a+4b = 1$ ①

$64a+8b = 0.5$ ②

② $-2 \times$ ①：$32a = -1.5$。

$a = -\frac{3}{64} \approx -0.046875$。

代入①：$16 \times (-\frac{3}{64})+4b = 1$。

$-\frac{3}{4}+4b = 1$。

$4b = \frac{7}{4}$。

$b = \frac{7}{16} = 0.4375$。

抛物线方程为 $y = -\frac{3}{64}x^2+\frac{7}{16}x+\frac{3}{2}$。

铅球落地时 $y=0$：

$-\frac{3}{64}x^2+\frac{7}{16}x+\frac{3}{2} = 0$。

$-3x^2+28x+96 = 0$。

$x = \frac{-28 \pm \sqrt{784+1152}}{-6} = \frac{-28 \pm \sqrt{1936}}{-6} = \frac{-28 \pm 44}{-6}$。

$x = 12$ 或 $x = -\frac{8}{3}$（舍去）。

答：铅球的投掷距离为 $12$m。
