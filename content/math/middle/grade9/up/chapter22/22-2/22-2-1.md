# 22.2.1 二次函数与一元二次方程的关系

## 一、求与 $x$ 轴交点

**求 $y=ax^2+bx+c$ 与 $x$ 轴交点**

令 $y=0$。

解方程 $ax^2+bx+c=0$。

方程的根就是交点的横坐标。

**交点坐标**

交点是 $(x_1,0)$ 和 $(x_2,0)$。

## 二、$\Delta$ 与交点个数的关系

**$\Delta>0$ 有两个交点**

方程有两个不相等的实数根。

抛物线与 $x$ 轴有两个不同的交点。

**$\Delta=0$ 有一个交点**

方程有两个相等的实数根。

抛物线与 $x$ 轴有一个交点（切点）。

**$\Delta<0$ 无交点**

方程无实数根。

抛物线与 $x$ 轴没有交点。

## 三、利用图象解一元二次方程

**图象法**

画出 $y=ax^2+bx+c$ 的图象。

图象与 $x$ 轴交点的横坐标就是方程的根。

**近似解**

从图象上可以读出根的近似值。

## 四、例题讲解

**例题1：** 求 $y=x^2-4x+3$ 与 $x$ 轴的交点坐标。

解：

令 $y=0$。

$x^2-4x+3=0$。

$(x-1)(x-3)=0$。

$x=1$ 或 $x=3$。

交点坐标是 $(1,0)$ 和 $(3,0)$。

答：$(1,0)$ 和 $(3,0)$。

**例题2：** 判断 $y=x^2-2x+3$ 与 $x$ 轴有几个交点。

解：

$\Delta = b^2-4ac = 4-12 = -8 < 0$。

无实数根。

与 $x$ 轴没有交点。

答：没有交点。

**例题3：** 已知 $y=x^2-6x+k$ 与 $x$ 轴只有一个交点，求 $k$ 的值。

解：

只有一个交点，说明 $\Delta=0$。

$\Delta = 36-4k = 0$。

$4k = 36$。

$k = 9$。

答：$k=9$。

**例题4：** 利用图象法求 $x^2-2x-3=0$ 的近似根。

解：

画出 $y=x^2-2x-3$ 的图象。

顶点：$x=1$，$y=-4$。

与 $y$ 轴交点：$(0,-3)$。

与 $x$ 轴交点：从图象上看约为 $(-1,0)$ 和 $(3,0)$。

答：$x \approx -1$ 或 $x \approx 3$。

**例题5：** 已知 $y=ax^2+bx+c$ 与 $x$ 轴交于 $(1,0)$ 和 $(3,0)$，求对称轴。

解：

对称轴是两个交点横坐标的中点。

$x = \frac{1+3}{2} = 2$。

对称轴是直线 $x=2$。

答：直线 $x=2$。

## 五、常见错误

**错误1：交点坐标写错**

错误写法：交点是 $1$ 和 $3$。

正确写法：交点是 $(1,0)$ 和 $(3,0)$。

**错误2：$\Delta$ 计算错误**

错误计算：$\Delta = b^2+4ac$。

正确计算：$\Delta = b^2-4ac$。

**错误3：切点理解错误**

错误理解：$\Delta=0$ 时没有交点。

正确理解：$\Delta=0$ 时有一个交点（切点）。

**错误4：忽略 $a \neq 0$**

错误做法：讨论 $a=0$ 的情况。

正确做法：二次函数 $a \neq 0$。

**错误5：对称轴计算错误**

错误计算：对称轴 $= x_1+x_2$。

正确计算：对称轴 $= \frac{x_1+x_2}{2}$。

## 六、练习题

**练习1：** 求 $y=x^2-5x+6$ 与 $x$ 轴的交点坐标。

解：

令 $y=0$。

$x^2-5x+6=0$。

$(x-2)(x-3)=0$。

$x=2$ 或 $x=3$。

交点坐标是 $(2,0)$ 和 $(3,0)$。

答：$(2,0)$ 和 $(3,0)$。

**练习2：** 判断 $y=2x^2+4x+3$ 与 $x$ 轴有几个交点。

解：

$\Delta = 16-24 = -8 < 0$。

无实数根。

与 $x$ 轴没有交点。

答：没有交点。

**练习3：** 已知 $y=x^2+2x+k$ 与 $x$ 轴有两个交点，求 $k$ 的取值范围。

解：

有两个交点，说明 $\Delta>0$。

$\Delta = 4-4k > 0$。

$4k < 4$。

$k < 1$。

答：$k < 1$。

**练习4：** 已知 $y=x^2-4x+k$ 与 $x$ 轴没有交点，求 $k$ 的取值范围。

解：

没有交点，说明 $\Delta<0$。

$\Delta = 16-4k < 0$。

$4k > 16$。

$k > 4$。

答：$k > 4$。

**练习5：** 已知 $y=ax^2+bx+c$ 与 $x$ 轴交于 $(-2,0)$ 和 $(4,0)$，求对称轴。

解：

对称轴是两个交点横坐标的中点。

$x = \frac{-2+4}{2} = 1$。

对称轴是直线 $x=1$。

答：直线 $x=1$。
