# 22.1.6 二次函数 $y=ax^2+bx+c$ 的图象和性质

## 一、配方法将一般式化为顶点式

**配方法步骤**

1. 提取二次项系数。
2. 配方：加一次项系数一半的平方。
3. 写成完全平方形式。

**例子**

$y = x^2-4x+3$。

$y = x^2-4x+4-4+3$。

$y = (x-2)^2-1$。

顶点是 $(2,-1)$。

## 二、顶点坐标公式

**公式：$(-\frac{b}{2a},\frac{4ac-b^2}{4a})$**

横坐标：$x = -\frac{b}{2a}$。

纵坐标：$y = \frac{4ac-b^2}{4a}$。

**对称轴公式：$x = -\frac{b}{2a}$**

**最值公式：$\frac{4ac-b^2}{4a}$**

$a>0$ 时是最小值。

$a<0$ 时是最大值。

## 三、五点法画抛物线草图

**五个关键点**

1. 顶点。
2. 与 $y$ 轴交点 $(0,c)$。
3. 与 $y$ 轴交点关于对称轴的对称点。
4. 与 $x$ 轴的两个交点（如果有）。

**画图步骤**

先找顶点。

再找与坐标轴的交点。

最后描点连线。

## 四、例题讲解

**例题1：** 将 $y=x^2-4x+3$ 化为顶点式，并指出顶点、对称轴。

解：

$y = x^2-4x+4-4+3$。

$y = (x-2)^2-1$。

顶点 $(2,-1)$。

对称轴是直线 $x=2$。

答：$y=(x-2)^2-1$，顶点 $(2,-1)$，对称轴是直线 $x=2$。

**例题2：** 求 $y=2x^2+4x-1$ 的顶点坐标和对称轴。

解：

用公式法。

$x = -\frac{b}{2a} = -\frac{4}{2 \times 2} = -1$。

$y = \frac{4ac-b^2}{4a} = \frac{4 \times 2 \times (-1)-16}{4 \times 2} = \frac{-8-16}{8} = -3$。

顶点 $(-1,-3)$。

对称轴是直线 $x=-1$。

答：顶点 $(-1,-3)$，对称轴是直线 $x=-1$。

**例题3：** 求 $y=-x^2+2x+3$ 的最值。

解：

$a=-1<0$，有最大值。

$x = -\frac{b}{2a} = -\frac{2}{2 \times (-1)} = 1$。

最大值 $= \frac{4ac-b^2}{4a} = \frac{4 \times (-1) \times 3-4}{4 \times (-1)} = \frac{-12-4}{-4} = 4$。

答：当 $x=1$ 时，$y$ 有最大值 $4$。

**例题4：** 画出 $y=x^2-2x-3$ 的草图。

解：

顶点：$x = -\frac{-2}{2} = 1$，$y = 1-2-3 = -4$。顶点 $(1,-4)$。

与 $y$ 轴交点：$(0,-3)$。

与 $x$ 轴交点：$x^2-2x-3=0$，$(x-3)(x+1)=0$，$x=3$ 或 $x=-1$。

交点 $(3,0)$ 和 $(-1,0)$。

描点连线。

答：开口向上，顶点 $(1,-4)$，与 $x$ 轴交于 $(-1,0)$ 和 $(3,0)$。

**例题5：** 将 $y=3x^2-6x+2$ 化为顶点式。

解：

提取 $3$：$y = 3(x^2-2x)+2$。

配方：$y = 3(x^2-2x+1-1)+2$。

$y = 3(x-1)^2-3+2$。

$y = 3(x-1)^2-1$。

答：$y=3(x-1)^2-1$。

## 五、常见错误

**错误1：配方时忘记平衡**

错误做法：$y=x^2-4x+3 = (x-2)^2+3$。

正确做法：$y=(x-2)^2-4+3 = (x-2)^2-1$。

**错误2：公式记错**

错误公式：顶点横坐标 $=\frac{b}{2a}$。

正确公式：顶点横坐标 $=-\frac{b}{2a}$。

**错误3：最值公式记错**

错误公式：最值 $=\frac{b^2-4ac}{4a}$。

正确公式：最值 $=\frac{4ac-b^2}{4a}$。

**错误4：提取系数时漏乘**

错误做法：$y=2x^2+4x-1 = 2(x^2+2x)-1$。

正确做法：$y=2(x^2+2x+1)-2-1 = 2(x+1)^2-3$。

**错误5：五点法找错对称点**

错误做法：与 $y$ 轴交点 $(0,c)$ 的对称点是 $(0,-c)$。

正确做法：对称点是 $(-\frac{b}{a},c)$。

## 六、练习题

**练习1：** 将 $y=x^2+6x+5$ 化为顶点式。

解：

$y = x^2+6x+9-9+5$。

$y = (x+3)^2-4$。

答：$y=(x+3)^2-4$。

**练习2：** 求 $y=-2x^2+4x+1$ 的顶点坐标。

解：

$x = -\frac{4}{2 \times (-2)} = 1$。

$y = \frac{4 \times (-2) \times 1-16}{4 \times (-2)} = \frac{-8-16}{-8} = 3$。

顶点 $(1,3)$。

答：顶点 $(1,3)$。

**练习3：** 求 $y=x^2-4x+7$ 的最值。

解：

$a=1>0$，有最小值。

$x = -\frac{-4}{2} = 2$。

最小值 $= 4-8+7 = 3$。

答：当 $x=2$ 时，$y$ 有最小值 $3$。

**练习4：** 将 $y=2x^2-8x+5$ 化为顶点式。

解：

提取 $2$：$y = 2(x^2-4x)+5$。

配方：$y = 2(x^2-4x+4-4)+5$。

$y = 2(x-2)^2-8+5$。

$y = 2(x-2)^2-3$。

答：$y=2(x-2)^2-3$。

**练习5：** 求 $y=-x^2+6x-5$ 的对称轴和最值。

解：

对称轴：$x = -\frac{6}{2 \times (-1)} = 3$。

$a=-1<0$，有最大值。

最大值 $= -9+18-5 = 4$。

答：对称轴是直线 $x=3$，最大值 $4$。
