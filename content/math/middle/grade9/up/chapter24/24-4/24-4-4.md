# 24.4.4 圆锥的侧面积和全面积

## 一、圆锥的组成

**底面（圆）**

圆锥的底面是一个圆。

底面半径为$r$。

**侧面（曲面）**

圆锥的侧面是一个曲面。

侧面展开后是扇形。

**母线$l$**

圆锥顶点到底面圆周上任意一点的线段。

所有母线长度相等。

**高$h$**

圆锥顶点到底面圆心的距离。

高垂直于底面。

## 二、圆锥的侧面展开图是扇形

**展开过程**

沿一条母线剪开。

侧面展开成一个扇形。

**扇形的半径**

扇形的半径等于圆锥的母线长$l$。

**扇形的弧长**

扇形的弧长等于圆锥底面的周长$2\pi r$。

## 三、侧面积公式

**$S_{侧} = \pi rl$**

推导：

侧面展开图是扇形。

扇形弧长 = 底面周长 = $2\pi r$。

扇形半径 = 母线长 = $l$。

$S_{侧} = \dfrac{1}{2} \times \text{弧长} \times \text{半径} = \dfrac{1}{2} \times 2\pi r \times l = \pi rl$。

## 四、全面积公式

**$S_{全} = \pi rl+\pi r^2$**

全面积 = 侧面积 + 底面积。

底面积 = $\pi r^2$。

$S_{全} = \pi rl+\pi r^2 = \pi r(l+r)$。

## 五、母线、高、半径的关系

**勾股定理**

$l^2 = r^2+h^2$。

$l$是母线。

$r$是底面半径。

$h$是高。

**已知任意两个量，可求第三个量**

## 六、例题讲解

**例题1：** 已知圆锥的底面半径为$3$cm，母线长为$5$cm。求侧面积。

解：

$S_{侧} = \pi rl$。

$r = 3$，$l = 5$。

$S_{侧} = \pi \times 3 \times 5 = 15\pi\text{cm}^2$。

答：侧面积为$15\pi\text{cm}^2$。

**例题2：** 已知圆锥的底面半径为$4$cm，母线长为$6$cm。求全面积。

解：

$S_{全} = \pi rl+\pi r^2$。

$r = 4$，$l = 6$。

$S_{全} = \pi \times 4 \times 6+\pi \times 4^2 = 24\pi+16\pi = 40\pi\text{cm}^2$。

答：全面积为$40\pi\text{cm}^2$。

**例题3：** 已知圆锥的底面半径为$3$cm，高为$4$cm。求母线长和侧面积。

解：

$l^2 = r^2+h^2$。

$l^2 = 3^2+4^2 = 9+16 = 25$。

$l = 5$cm。

$S_{侧} = \pi rl = \pi \times 3 \times 5 = 15\pi\text{cm}^2$。

答：母线长为$5$cm，侧面积为$15\pi\text{cm}^2$。

**例题4：** 已知圆锥的侧面积为$20\pi\text{cm}^2$，底面半径为$4$cm。求母线长。

解：

$S_{侧} = \pi rl$。

$20\pi = \pi \times 4 \times l$。

$20 = 4l$。

$l = 5$cm。

答：母线长为$5$cm。

**例题5：** 已知圆锥的底面半径为$6$cm，母线长为$10$cm。求高和全面积。

解：

$l^2 = r^2+h^2$。

$10^2 = 6^2+h^2$。

$100 = 36+h^2$。

$h^2 = 64$。

$h = 8$cm。

$S_{全} = \pi rl+\pi r^2 = \pi \times 6 \times 10+\pi \times 6^2 = 60\pi+36\pi = 96\pi\text{cm}^2$。

答：高为$8$cm，全面积为$96\pi\text{cm}^2$。

## 七、常见错误

**错误1：侧面积公式记错**

错误做法：$S_{侧} = 2\pi rl$。

正确做法：$S_{侧} = \pi rl$。

**错误2：全面积漏加底面积**

错误做法：全面积 = 侧面积。

正确做法：全面积 = 侧面积 + 底面积。

**错误3：母线与高混淆**

错误理解：母线就是高。

正确理解：母线是顶点到底面圆周的线段，高是顶点到底面圆心的线段。

**错误4：勾股定理用错**

错误做法：$l = r+h$。

正确做法：$l^2 = r^2+h^2$。

**错误5：单位错误**

错误做法：面积单位写成cm。

正确做法：面积单位是$\text{cm}^2$。

## 八、练习题

**练习1：** 已知圆锥的底面半径为$5$cm，母线长为$13$cm。求侧面积。

解：

$S_{侧} = \pi rl$。

$r = 5$，$l = 13$。

$S_{侧} = \pi \times 5 \times 13 = 65\pi\text{cm}^2$。

答：侧面积为$65\pi\text{cm}^2$。

**练习2：** 已知圆锥的底面半径为$3$cm，母线长为$5$cm。求全面积。

解：

$S_{全} = \pi rl+\pi r^2$。

$r = 3$，$l = 5$。

$S_{全} = \pi \times 3 \times 5+\pi \times 3^2 = 15\pi+9\pi = 24\pi\text{cm}^2$。

答：全面积为$24\pi\text{cm}^2$。

**练习3：** 已知圆锥的底面半径为$5$cm，高为$12$cm。求母线长和侧面积。

解：

$l^2 = r^2+h^2$。

$l^2 = 5^2+12^2 = 25+144 = 169$。

$l = 13$cm。

$S_{侧} = \pi rl = \pi \times 5 \times 13 = 65\pi\text{cm}^2$。

答：母线长为$13$cm，侧面积为$65\pi\text{cm}^2$。

**练习4：** 已知圆锥的侧面积为$30\pi\text{cm}^2$，底面半径为$5$cm。求母线长。

解：

$S_{侧} = \pi rl$。

$30\pi = \pi \times 5 \times l$。

$30 = 5l$。

$l = 6$cm。

答：母线长为$6$cm。

**练习5：** 已知圆锥的底面半径为$8$cm，母线长为$17$cm。求高和全面积。

解：

$l^2 = r^2+h^2$。

$17^2 = 8^2+h^2$。

$289 = 64+h^2$。

$h^2 = 225$。

$h = 15$cm。

$S_{全} = \pi rl+\pi r^2 = \pi \times 8 \times 17+\pi \times 8^2 = 136\pi+64\pi = 200\pi\text{cm}^2$。

答：高为$15$cm，全面积为$200\pi\text{cm}^2$。
