# 24.4.1 弧长公式

## 一、弧长公式

**$l = \dfrac{n\pi r}{180}$**

$l$为弧长。

$n$为圆心角度数。

$r$为半径。

$\pi$为圆周率。

## 二、公式的推导

**圆的周长**

圆的周长$C = 2\pi r$。

整个圆对应的圆心角是$360°$。

**按比例分配**

$n°$的圆心角占整个圆的$\frac{n}{360}$。

弧长$l = \frac{n}{360} \times 2\pi r = \dfrac{n\pi r}{180}$。

**理解**

弧长与圆心角成正比。

圆心角越大，弧长越长。

## 三、已知弧长求圆心角或半径

**已知$l$和$r$，求$n$**

$n = \dfrac{180l}{\pi r}$。

**已知$l$和$n$，求$r$**

$r = \dfrac{180l}{n\pi}$。

## 四、弧长公式的应用

**求弧长**

直接代入公式。

**求扇形周长**

扇形周长 = 弧长 + 2条半径。

**实际应用**

计算弯道长度。

计算圆弧轨道长度。

## 五、例题讲解

**例题1：** 已知$\odot O$的半径为$6$cm，圆心角为$60°$。求弧长。

解：

$l = \dfrac{n\pi r}{180}$。

$n = 60$，$r = 6$。

$l = \dfrac{60 \times \pi \times 6}{180} = \dfrac{360\pi}{180} = 2\pi$cm。

答：弧长为$2\pi$cm。

**例题2：** 已知$\odot O$的半径为$9$cm，圆心角为$120°$。求弧长。

解：

$l = \dfrac{n\pi r}{180}$。

$n = 120$，$r = 9$。

$l = \dfrac{120 \times \pi \times 9}{180} = \dfrac{1080\pi}{180} = 6\pi$cm。

答：弧长为$6\pi$cm。

**例题3：** 已知弧长为$4\pi$cm，半径为$8$cm。求圆心角的度数。

解：

$l = \dfrac{n\pi r}{180}$。

$4\pi = \dfrac{n \times \pi \times 8}{180}$。

$4 = \dfrac{8n}{180}$。

$720 = 8n$。

$n = 90$。

答：圆心角为$90°$。

**例题4：** 已知弧长为$5\pi$cm，圆心角为$150°$。求半径。

解：

$l = \dfrac{n\pi r}{180}$。

$5\pi = \dfrac{150 \times \pi \times r}{180}$。

$5 = \dfrac{150r}{180}$。

$900 = 150r$。

$r = 6$cm。

答：半径为$6$cm。

**例题5：** 已知扇形的半径为$10$cm，圆心角为$90°$。求扇形的周长。

解：

先求弧长：$l = \dfrac{90 \times \pi \times 10}{180} = 5\pi$cm。

扇形周长 = 弧长 + 2条半径。

周长 = $5\pi + 2 \times 10 = 5\pi + 20$cm。

答：扇形的周长为$(5\pi+20)$cm。

## 六、常见错误

**错误1：公式记错**

错误做法：$l = \dfrac{n\pi r}{360}$。

正确做法：$l = \dfrac{n\pi r}{180}$。

**错误2：角度与弧度混淆**

错误做法：把角度当成弧度代入。

正确做法：$n$是角度数（度数制）。

**错误3：半径与直径混淆**

错误做法：用直径代替半径。

正确做法：$r$是半径。

**错误4：计算错误**

错误做法：约分错误。

正确做法：仔细约分。

**错误5：扇形周长漏加半径**

错误做法：扇形周长 = 弧长。

正确做法：扇形周长 = 弧长 + 2条半径。

解：

$l = \dfrac{n\pi r}{180}$。

$n = 30$，$r = 12$。

答：弧长为$2\pi$cm。

答：弧长为$6\pi$cm。

$l = \dfrac{n\pi r}{180}$。

$3\pi = \dfrac{n \times \pi \times 9}{180}$。

$3 = \dfrac{9n}{180}$。

$540 = 9n$。

答：圆心角为$60°$。

答：半径为$12$cm。

扇形周长 = 弧长 + 2条半径。
