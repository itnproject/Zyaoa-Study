# 24.4.3 弓形面积

## 一、弓形的定义

**由弦和弦所对的弧围成的图形**

弓形由一条弦和一条弧围成。

弓形的形状像弓箭的弓。

弓形分为劣弧弓形和优弧弓形。

## 二、弓形面积 = 扇形面积 ± 三角形面积

**劣弧弓形：扇形面积 - 三角形面积**

劣弧弓形是小于半圆的弓形。

弓形面积 = 扇形面积 - 三角形面积。

三角形是由圆心和弦的两个端点构成的。

**优弧弓形：扇形面积 + 三角形面积**

优弧弓形是大于半圆的弓形。

弓形面积 = 扇形面积 + 三角形面积。

三角形是由圆心和弦的两个端点构成的。

## 三、劣弧弓形：扇形减三角形

**计算步骤**

求扇形面积：$S_{\text{扇}} = \dfrac{n\pi r^2}{360}$。

求三角形面积：$S_{\triangle} = \frac{1}{2}r^2\sin n°$或用底乘高。

弓形面积 = $S_{\text{扇}}-S_{\triangle}$。

**例子**

半径为$r$，圆心角为$60°$。

$S_{\text{扇}} = \dfrac{60\pi r^2}{360} = \dfrac{\pi r^2}{6}$。

$S_{\triangle} = \frac{1}{2}r^2\sin 60° = \frac{\sqrt{3}}{4}r^2$。

弓形面积 = $\dfrac{\pi r^2}{6}-\frac{\sqrt{3}}{4}r^2$。

## 四、优弧弓形：扇形加三角形

**计算步骤**

求优弧对应的扇形面积。

求三角形面积。

弓形面积 = 扇形面积 + 三角形面积。

**例子**

半径为$r$，劣弧圆心角为$60°$。

优弧圆心角为$300°$。

$S_{\text{扇}} = \dfrac{300\pi r^2}{360} = \dfrac{5\pi r^2}{6}$。

$S_{\triangle} = \frac{\sqrt{3}}{4}r^2$。

弓形面积 = $\dfrac{5\pi r^2}{6}+\frac{\sqrt{3}}{4}r^2$。

## 五、例题讲解

**例题1：** 如图，$\odot O$的半径为$6$cm，弦$AB$所对的圆心角为$60°$。求劣弧弓形的面积。

解：

扇形面积：$S_{\text{扇}} = \dfrac{60 \times \pi \times 6^2}{360} = 6\pi\text{cm}^2$。

$\triangle OAB$是等边三角形（$OA = OB = 6$，$\angle AOB = 60°$）。

$S_{\triangle} = \frac{\sqrt{3}}{4} \times 6^2 = 9\sqrt{3}\text{cm}^2$。

弓形面积 = $S_{\text{扇}}-S_{\triangle} = 6\pi-9\sqrt{3}\text{cm}^2$。

答：弓形面积为$(6\pi-9\sqrt{3})\text{cm}^2$。

**例题2：** 如图，$\odot O$的半径为$4$cm，弦$AB$所对的圆心角为$90°$。求劣弧弓形的面积。

解：

扇形面积：$S_{\text{扇}} = \dfrac{90 \times \pi \times 4^2}{360} = 4\pi\text{cm}^2$。

$\triangle OAB$是等腰直角三角形。

$S_{\triangle} = \frac{1}{2} \times 4 \times 4 = 8\text{cm}^2$。

弓形面积 = $S_{\text{扇}}-S_{\triangle} = 4\pi-8\text{cm}^2$。

答：弓形面积为$(4\pi-8)\text{cm}^2$。

**例题3：** 如图，$\odot O$的半径为$6$cm，弦$AB$所对的圆心角为$120°$。求劣弧弓形的面积。

解：

扇形面积：$S_{\text{扇}} = \dfrac{120 \times \pi \times 6^2}{360} = 12\pi\text{cm}^2$。

作$OC \perp AB$于$C$。

$\angle AOC = 60°$。

$OC = 6 \times \cos 60° = 3$cm。

$AC = 6 \times \sin 60° = 3\sqrt{3}$cm。

$AB = 2AC = 6\sqrt{3}$cm。

$S_{\triangle} = \frac{1}{2} \times AB \times OC = \frac{1}{2} \times 6\sqrt{3} \times 3 = 9\sqrt{3}\text{cm}^2$。

弓形面积 = $S_{\text{扇}}-S_{\triangle} = 12\pi-9\sqrt{3}\text{cm}^2$。

答：弓形面积为$(12\pi-9\sqrt{3})\text{cm}^2$。

**例题4：** 如图，$\odot O$的半径为$4$cm，弦$AB$所对的劣弧圆心角为$90°$。求优弧弓形的面积。

解：

优弧圆心角 = $360°-90° = 270°$。

优弧扇形面积：$S_{\text{扇}} = \dfrac{270 \times \pi \times 4^2}{360} = 12\pi\text{cm}^2$。

$S_{\triangle} = \frac{1}{2} \times 4 \times 4 = 8\text{cm}^2$。

弓形面积 = $S_{\text{扇}}+S_{\triangle} = 12\pi+8\text{cm}^2$。

答：弓形面积为$(12\pi+8)\text{cm}^2$。

**例题5：** 如图，$\odot O$的半径为$2$cm，弦$AB$所对的圆心角为$60°$。求优弧弓形的面积。

解：

优弧圆心角 = $360°-60° = 300°$。

优弧扇形面积：$S_{\text{扇}} = \dfrac{300 \times \pi \times 2^2}{360} = \dfrac{10\pi}{3}\text{cm}^2$。

$\triangle OAB$是等边三角形。

$S_{\triangle} = \frac{\sqrt{3}}{4} \times 2^2 = \sqrt{3}\text{cm}^2$。

弓形面积 = $S_{\text{扇}}+S_{\triangle} = \dfrac{10\pi}{3}+\sqrt{3}\text{cm}^2$。

答：弓形面积为$(\dfrac{10\pi}{3}+\sqrt{3})\text{cm}^2$。

## 六、常见错误

**错误1：劣弧优弧搞反**

错误做法：劣弧弓形用加法。

正确做法：劣弧弓形用减法。

**错误2：三角形面积计算错误**

错误做法：三角形面积公式用错。

正确做法：根据三角形类型选择合适的面积公式。

**错误3：圆心角用错**

错误做法：优弧弓形用劣弧的圆心角。

正确做法：优弧弓形用$360°$减去劣弧圆心角。

**错误4：符号错误**

错误做法：弓形面积 = 三角形面积 - 扇形面积。

正确做法：弓形面积 = 扇形面积 - 三角形面积。

**错误5：单位错误**

错误做法：面积单位写成cm。

正确做法：面积单位是$\text{cm}^2$。

## 七、练习题

**练习1：** 如图，$\odot O$的半径为$8$cm，弦$AB$所对的圆心角为$90°$。求劣弧弓形的面积。

解：

扇形面积：$S_{\text{扇}} = \dfrac{90 \times \pi \times 8^2}{360} = 16\pi\text{cm}^2$。

$S_{\triangle} = \frac{1}{2} \times 8 \times 8 = 32\text{cm}^2$。

弓形面积 = $S_{\text{扇}}-S_{\triangle} = 16\pi-32\text{cm}^2$。

答：弓形面积为$(16\pi-32)\text{cm}^2$。

**练习2：** 如图，$\odot O$的半径为$6$cm，弦$AB$所对的圆心角为$120°$。求劣弧弓形的面积。

解：

扇形面积：$S_{\text{扇}} = \dfrac{120 \times \pi \times 6^2}{360} = 12\pi\text{cm}^2$。

作$OC \perp AB$于$C$。

$\angle AOC = 60°$。

$OC = 6 \times \cos 60° = 3$cm。

$AC = 6 \times \sin 60° = 3\sqrt{3}$cm。

$AB = 6\sqrt{3}$cm。

$S_{\triangle} = \frac{1}{2} \times 6\sqrt{3} \times 3 = 9\sqrt{3}\text{cm}^2$。

弓形面积 = $12\pi-9\sqrt{3}\text{cm}^2$。

答：弓形面积为$(12\pi-9\sqrt{3})\text{cm}^2$。

**练习3：** 如图，$\odot O$的半径为$3$cm，弦$AB$所对的劣弧圆心角为$60°$。求优弧弓形的面积。

解：

优弧圆心角 = $360°-60° = 300°$。

优弧扇形面积：$S_{\text{扇}} = \dfrac{300 \times \pi \times 3^2}{360} = \dfrac{15\pi}{2}\text{cm}^2$。

答：弓形面积为$(\dfrac{15\pi}{2}+\frac{9\sqrt{3}}{4})\text{cm}^2$。

**练习4：** 如图，$\odot O$的半径为$5$cm，弦$AB$所对的圆心角为$90°$。求劣弧弓形的面积。

解：

扇形面积：$S_{\text{扇}} = \dfrac{90 \times \pi \times 5^2}{360} = \dfrac{25\pi}{4}\text{cm}^2$。

$S_{\triangle} = \frac{1}{2} \times 5 \times 5 = \dfrac{25}{2}\text{cm}^2$。

弓形面积 = $\dfrac{25\pi}{4}-\dfrac{25}{2}\text{cm}^2$。

答：弓形面积为$(\dfrac{25\pi}{4}-\dfrac{25}{2})\text{cm}^2$。

**练习5：** 如图，$\odot O$的半径为$4$cm，弦$AB$所对的劣弧圆心角为$120°$。求优弧弓形的面积。

解：

优弧圆心角 = $360°-120° = 240°$。

优弧扇形面积：$S_{\text{扇}} = \dfrac{240 \times \pi \times 4^2}{360} = \dfrac{32\pi}{3}\text{cm}^2$。

作$OC \perp AB$于$C$。

$\angle AOC = 60°$。

$OC = 4 \times \cos 60° = 2$cm。

$AC = 4 \times \sin 60° = 2\sqrt{3}$cm。

$AB = 4\sqrt{3}$cm。

$S_{\triangle} = \frac{1}{2} \times 4\sqrt{3} \times 2 = 4\sqrt{3}\text{cm}^2$。

弓形面积 = $\dfrac{32\pi}{3}+4\sqrt{3}\text{cm}^2$。

答：弓形面积为$(\dfrac{32\pi}{3}+4\sqrt{3})\text{cm}^2$。
