# 24.3.1 正多边形和圆

## 一、正多边形的定义

**各边相等、各角相等的多边形**

正三角形：三边相等，三角相等（都是$60°$）。

正方形：四边相等，四角相等（都是$90°$）。

正五边形：五边相等，五角相等（都是$108°$）。

正$n$边形：$n$边相等，$n$角相等。

## 二、正多边形与圆的关系

**等分圆周得到正多边形**

把圆周$n$等分。

依次连接各分点。

得到圆内接正$n$边形。

**圆是正多边形的外接圆**

正多边形的所有顶点都在圆上。

这个圆叫做正多边形的外接圆。

## 三、正多边形的外接圆、中心、半径、边心距、中心角

**中心**

正多边形外接圆的圆心。

也是正多边形的对称中心。

**半径**

外接圆的半径。

中心到顶点的距离。

**边心距**

中心到边的距离。

边心距垂直于边。

**中心角**

正多边形每一条边所对的圆心角。

中心角 = $\frac{360°}{n}$。

## 四、中心角公式

**中心角 = $\frac{360°}{n}$**

$n$是正多边形的边数。

正三角形的中心角 = $\frac{360°}{3} = 120°$。

正方形的中心角 = $\frac{360°}{4} = 90°$。

正五边形的中心角 = $\frac{360°}{5} = 72°$。

正六边形的中心角 = $\frac{360°}{6} = 60°$。

## 五、正$n$边形的画法

**用量角器画**

画一个圆。

以圆心为顶点，画中心角。

在圆上依次截取等分点。

连接各分点。

**用圆规画（正六边形）**

画一个圆。

以圆上任意一点为圆心，半径为半径画弧。

交圆于一点。

以此点为圆心继续画弧。

依次得到6个等分点。

连接各分点。

## 六、例题讲解

**例题1：** 求正五边形的中心角。

解：

中心角 = $\frac{360°}{n}$。

$n = 5$。

中心角 = $\frac{360°}{5} = 72°$。

答：正五边形的中心角为$72°$。

**例题2：** 求正八边形的中心角。

解：

中心角 = $\frac{360°}{n}$。

$n = 8$。

中心角 = $\frac{360°}{8} = 45°$。

答：正八边形的中心角为$45°$。

**例题3：** 已知正六边形的半径为$4$cm，求边长。

解：

正六边形的中心角 = $\frac{360°}{6} = 60°$。

中心与相邻两个顶点构成等边三角形。

边长 = 半径 = $4$cm。

答：边长为$4$cm。

**例题4：** 已知正方形的边长为$6$cm，求外接圆半径。

解：

正方形的对角线 = $\sqrt{6^2+6^2} = \sqrt{72} = 6\sqrt{2}$cm。

外接圆直径 = 对角线 = $6\sqrt{2}$cm。

外接圆半径 = $\frac{6\sqrt{2}}{2} = 3\sqrt{2}$cm。

答：外接圆半径为$3\sqrt{2}$cm。

**例题5：** 已知正三角形的边心距为$2$cm，求半径。

解：

正三角形的中心角 = $120°$。

中心、边的中点、顶点构成直角三角形。

中心角的一半 = $60°$。

$\cos 60° = \frac{\text{边心距}}{\text{半径}}$。

$\frac{1}{2} = \frac{2}{r}$。

$r = 4$cm。

答：半径为$4$cm。

## 七、常见错误

**错误1：中心角公式记错**

错误做法：中心角 = $\frac{180°}{n}$。

正确做法：中心角 = $\frac{360°}{n}$。

**错误2：边心距与半径混淆**

错误理解：边心距就是半径。

正确理解：边心距是中心到边的距离，半径是中心到顶点的距离。

**错误3：正六边形边长记错**

错误理解：正六边形边长是半径的2倍。

正确理解：正六边形边长等于半径。

**错误4：内角与中心角混淆**

错误理解：正五边形的中心角是$108°$。

正确理解：$108°$是内角，中心角是$72°$。

**错误5：外接圆半径计算错误**

错误做法：正方形外接圆半径等于边长。

正确做法：正方形外接圆半径等于对角线的一半。

## 八、练习题

**练习1：** 求正十二边形的中心角。

解：

中心角 = $\frac{360°}{n}$。

$n = 12$。

中心角 = $\frac{360°}{12} = 30°$。

答：正十二边形的中心角为$30°$。

**练习2：** 求正十边形的中心角。

解：

中心角 = $\frac{360°}{n}$。

$n = 10$。

中心角 = $\frac{360°}{10} = 36°$。

答：正十边形的中心角为$36°$。

**练习3：** 已知正六边形的半径为$5$cm，求边长。

解：

正六边形的中心角 = $\frac{360°}{6} = 60°$。

中心与相邻两个顶点构成等边三角形。

边长 = 半径 = $5$cm。

答：边长为$5$cm。

**练习4：** 已知正方形的边长为$8$cm，求外接圆半径。

解：

正方形的对角线 = $\sqrt{8^2+8^2} = \sqrt{128} = 8\sqrt{2}$cm。

外接圆半径 = $\frac{8\sqrt{2}}{2} = 4\sqrt{2}$cm。

答：外接圆半径为$4\sqrt{2}$cm。

**练习5：** 已知正三角形的半径为$6$cm，求边心距。

解：

正三角形的中心角 = $120°$。

中心角的一半 = $60°$。

$\cos 60° = \frac{\text{边心距}}{\text{半径}}$。

$\frac{1}{2} = \frac{d}{6}$。

$d = 3$cm。

答：边心距为$3$cm。
