# 24.2.3 切线的判定与性质

## 一、切线的判定定理

**经过半径的外端且垂直于这条半径的直线是圆的切线**

已知：$OA$是$\odot O$的半径，直线$l$经过点$A$，且$l \perp OA$。

结论：直线$l$是$\odot O$的切线。

**理解**

直线经过半径的外端（圆上的点）。

直线垂直于这条半径。

满足这两个条件，直线就是切线。

## 二、切线的性质定理

**圆的切线垂直于过切点的半径**

已知：直线$l$是$\odot O$的切线，切点为$A$。

结论：$l \perp OA$。

**理解**

切线与过切点的半径垂直。

这是切线的重要性质。

## 三、证切线的方法

**方法一：连半径证垂直**

已知直线经过圆上一点。

连接圆心和这点（半径）。

证明直线垂直于半径。

**方法二：作垂直证半径**

已知直线与圆的位置关系不确定。

过圆心作直线的垂线。

证明垂线段长度等于半径。

## 四、切线的性质与判定的综合应用

**判定与性质的区别**

判定：已知垂直，证切线。

性质：已知切线，证垂直。

**综合应用**

先用判定证明是切线。

再用性质得到垂直关系。

利用垂直关系进行计算或证明。

## 五、例题讲解

**例题1：** 如图，$AB$是$\odot O$的直径，点$C$在$\odot O$上，直线$CD$经过点$C$，且$\angle OCD = 90°$。证明：直线$CD$是$\odot O$的切线。

解：

$OC$是$\odot O$的半径。

点$C$在$\odot O$上。

直线$CD$经过点$C$。

$\angle OCD = 90°$，即$CD \perp OC$。

根据切线的判定定理：经过半径的外端且垂直于这条半径的直线是圆的切线。

所以直线$CD$是$\odot O$的切线。

答：直线$CD$是$\odot O$的切线。

**例题2：** 如图，直线$l$是$\odot O$的切线，切点为$A$，$OA = 5$cm，点$B$在直线$l$上，$OB = 13$cm。求$AB$的长度。

解：

直线$l$是$\odot O$的切线，切点为$A$。

根据切线的性质定理：$l \perp OA$。

在$\text{Rt}\triangle OAB$中，由勾股定理：

$AB^2 = OB^2 - OA^2$。

$AB^2 = 13^2 - 5^2 = 169 - 25 = 144$。

$AB = 12$cm。

答：$AB = 12$cm。

**例题3：** 如图，$AB$是$\odot O$的直径，$C$是$\odot O$上一点，$\angle BAC = 30°$，直线$CD$经过点$C$，且$\angle ACD = 60°$。证明：直线$CD$是$\odot O$的切线。

解：

连接$OC$。

$OA = OC$（半径相等）。

$\angle OAC = \angle OCA = 30°$。

$\angle OCD = \angle OCA+\angle ACD = 30°+60° = 90°$。

即$CD \perp OC$。

$OC$是半径，点$C$在圆上。

根据切线的判定定理：直线$CD$是$\odot O$的切线。

答：直线$CD$是$\odot O$的切线。

**例题4：** 如图，$PA$、$PB$是$\odot O$的切线，切点分别为$A$、$B$。证明：$PA = PB$。

解：

连接$OA$、$OB$、$OP$。

$PA$是切线，$OA$是半径。

根据切线的性质：$PA \perp OA$。

同理$PB \perp OB$。

在$\text{Rt}\triangle OAP$和$\text{Rt}\triangle OBP$中：

$OA = OB$（半径相等）。

$OP = OP$（公共边）。

$\text{Rt}\triangle OAP \cong \text{Rt}\triangle OBP$（HL）。

所以$PA = PB$。

答：$PA = PB$。

**例题5：** 如图，$AB$是$\odot O$的直径，$C$是$\odot O$上一点，直线$CD$是$\odot O$的切线，切点为$C$。若$\angle BAC = 25°$，求$\angle ACD$的度数。

解：

连接$OC$。

$OA = OC$（半径相等）。

$\angle OAC = \angle OCA = 25°$。

直线$CD$是切线。

根据切线的性质：$CD \perp OC$。

$\angle OCD = 90°$。

$\angle ACD = \angle OCD-\angle OCA = 90°-25° = 65°$。

答：$\angle ACD = 65°$。

## 六、常见错误

**错误1：判定定理条件不满足**

错误做法：直线不经过半径外端就认为是切线。

正确做法：必须经过半径外端且垂直于半径。

**错误2：性质定理用反**

错误做法：已知切线，用判定定理。

正确做法：已知切线，用性质定理得到垂直。

**错误3：切点找错**

错误做法：切点不是半径的外端。

正确做法：切点是半径的外端（圆上的点）。

**错误4：垂直关系用错**

错误做法：切线垂直于直径。

正确做法：切线垂直于过切点的半径。

**错误5：证明方法混淆**

错误做法：连半径证垂直和作垂直证半径混用。

正确做法：根据已知条件选择合适的方法。

## 七、练习题

**练习1：** 如图，$OA$是$\odot O$的半径，直线$l$经过点$A$，且$l \perp OA$。证明：直线$l$是$\odot O$的切线。

解：

$OA$是$\odot O$的半径。

点$A$在$\odot O$上（半径的外端）。

直线$l$经过点$A$。

$l \perp OA$。

根据切线的判定定理：直线$l$是$\odot O$的切线。

答：直线$l$是$\odot O$的切线。

**练习2：** 如图，直线$l$是$\odot O$的切线，切点为$A$，$OA = 3$cm，点$B$在直线$l$上，$OB = 5$cm。求$AB$的长度。

解：

直线$l$是$\odot O$的切线，切点为$A$。

根据切线的性质定理：$l \perp OA$。

在$\text{Rt}\triangle OAB$中，由勾股定理：

$AB^2 = OB^2 - OA^2$。

$AB^2 = 5^2 - 3^2 = 25 - 9 = 16$。

$AB = 4$cm。

答：$AB = 4$cm。

**练习3：** 如图，$AB$是$\odot O$的直径，$C$是$\odot O$上一点，直线$CD$经过点$C$，且$\angle BCD = \angle A$。证明：直线$CD$是$\odot O$的切线。

解：

连接$OC$。

$OA = OC$（半径相等）。

$\angle OAC = \angle OCA$。

$\angle BCD = \angle A = \angle OAC$。

$\angle OCD = \angle OCA+\angle ACD$。

$\angle ACB = 90°$（直径所对的圆周角）。

$\angle A+\angle B = 90°$。

$\angle BCD = \angle A$。

$\angle OCD = \angle OCA+\angle BCD = \angle A+\angle B = 90°$。

即$CD \perp OC$。

根据切线的判定定理：直线$CD$是$\odot O$的切线。

答：直线$CD$是$\odot O$的切线。

**练习4：** 如图，直线$l$是$\odot O$的切线，切点为$A$，$OA = 6$cm，点$B$在直线$l$上，$AB = 8$cm。求$OB$的长度。

解：

直线$l$是$\odot O$的切线，切点为$A$。

根据切线的性质定理：$l \perp OA$。

在$\text{Rt}\triangle OAB$中，由勾股定理：

$OB^2 = OA^2 + AB^2$。

$OB^2 = 6^2 + 8^2 = 36 + 64 = 100$。

$OB = 10$cm。

答：$OB = 10$cm。

**练习5：** 如图，$AB$是$\odot O$的直径，$C$是$\odot O$上一点，直线$CD$是$\odot O$的切线，切点为$C$。若$\angle ABC = 40°$，求$\angle ACD$的度数。

解：

连接$OC$。

$OB = OC$（半径相等）。

$\angle OBC = \angle OCB = 40°$。

直线$CD$是切线。

根据切线的性质：$CD \perp OC$。

$\angle OCD = 90°$。

$\angle ACD = \angle OCD-\angle OCB = 90°-40° = 50°$。

答：$\angle ACD = 50°$。
