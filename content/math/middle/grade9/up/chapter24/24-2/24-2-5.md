# 24.2.5 圆和圆的位置关系

## 一、五种位置关系

**外离**

两个圆没有公共点。

一个圆在另一个圆的外部。

**外切**

两个圆只有一个公共点。

一个圆在另一个圆的外部。

**相交**

两个圆有两个公共点。

**内切**

两个圆只有一个公共点。

一个圆在另一个圆的内部。

**内含**

两个圆没有公共点。

一个圆在另一个圆的内部。

## 二、判断方法

**$d$与$R+r$、$|R-r|$比较**

$d$为两圆圆心距。

$R$、$r$为两圆半径（$R \geq r$）。

## 三、五种情况的数学表达

**$d > R+r \Leftrightarrow$ 外离**

圆心距大于两半径之和。

两个圆没有公共点。

**$d = R+r \Leftrightarrow$ 外切**

圆心距等于两半径之和。

两个圆有一个公共点。

**$|R-r| < d < R+r \Leftrightarrow$ 相交**

圆心距介于两半径之差与和之间。

两个圆有两个公共点。

**$d = |R-r| \Leftrightarrow$ 内切**

圆心距等于两半径之差。

两个圆有一个公共点。

**$d < |R-r| \Leftrightarrow$ 内含**

圆心距小于两半径之差。

两个圆没有公共点。

## 四、例题讲解

**例题1：** 已知$\odot O_1$的半径为$3$cm，$\odot O_2$的半径为$5$cm，圆心距$O_1O_2 = 10$cm。判断两圆的位置关系。

解：

$R = 5$，$r = 3$。

$R+r = 8$，$|R-r| = 2$。

$d = 10$。

$d > R+r$（$10 > 8$）。

所以两圆外离。

答：两圆外离。

**例题2：** 已知$\odot O_1$的半径为$4$cm，$\odot O_2$的半径为$4$cm，圆心距$O_1O_2 = 8$cm。判断两圆的位置关系。

解：

$R = 4$，$r = 4$。

$R+r = 8$，$|R-r| = 0$。

$d = 8$。

$d = R+r$（$8 = 8$）。

所以两圆外切。

答：两圆外切。

**例题3：** 已知$\odot O_1$的半径为$3$cm，$\odot O_2$的半径为$5$cm，圆心距$O_1O_2 = 6$cm。判断两圆的位置关系。

解：

$R = 5$，$r = 3$。

$R+r = 8$，$|R-r| = 2$。

$d = 6$。

$|R-r| < d < R+r$（$2 < 6 < 8$）。

所以两圆相交。

答：两圆相交。

**例题4：** 已知$\odot O_1$的半径为$2$cm，$\odot O_2$的半径为$7$cm，圆心距$O_1O_2 = 5$cm。判断两圆的位置关系。

解：

$R = 7$，$r = 2$。

$R+r = 9$，$|R-r| = 5$。

$d = 5$。

$d = |R-r|$（$5 = 5$）。

所以两圆内切。

答：两圆内切。

**例题5：** 已知$\odot O_1$的半径为$3$cm，$\odot O_2$的半径为$8$cm，圆心距$O_1O_2 = 4$cm。判断两圆的位置关系。

解：

$R = 8$，$r = 3$。

$R+r = 11$，$|R-r| = 5$。

$d = 4$。

$d < |R-r|$（$4 < 5$）。

所以两圆内含。

答：两圆内含。

## 五、常见错误

**错误1：$R$和$r$大小搞反**

错误做法：不区分$R$和$r$的大小。

正确做法：设$R \geq r$。

**错误2：内切与外切混淆**

错误理解：$d = R+r$是内切。

正确理解：$d = R+r$是外切，$d = |R-r|$是内切。

**错误3：$|R-r|$忘记取绝对值**

错误做法：$R-r$（可能为负）。

正确做法：$|R-r|$。

**错误4：相交条件记错**

错误做法：$d < R+r$就是相交。

正确做法：$|R-r| < d < R+r$才是相交。

**错误5：公共点个数记错**

错误理解：外离时有1个公共点。

正确理解：外离时有0个公共点。
