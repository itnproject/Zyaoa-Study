# 24.2.4 切线长定理

## 一、切线长的定义

**切线上切点与圆外一点之间的线段长**

从圆外一点引圆的切线。

切点与圆外一点之间的线段长度。

叫做切线长。

**注意**

切线长不是切线的长度。

切线是直线，没有长度。

切线长是线段的长度。

## 二、切线长定理

**从圆外一点引圆的两条切线，它们的切线长相等**

已知：$PA$、$PB$是$\odot O$的切线，切点分别为$A$、$B$。

结论：$PA = PB$。

**证明**

连接$OA$、$OB$、$OP$。

$PA \perp OA$，$PB \perp OB$（切线性质）。

在$\text{Rt}\triangle OAP$和$\text{Rt}\triangle OBP$中：

$OA = OB$（半径相等）。

$OP = OP$（公共边）。

$\text{Rt}\triangle OAP \cong \text{Rt}\triangle OBP$（HL）。

所以$PA = PB$。

## 三、这一点和圆心的连线平分两条切线的夹角

**$OP$平分$\angle APB$**

由$\text{Rt}\triangle OAP \cong \text{Rt}\triangle OBP$。

$\angle APO = \angle BPO$。

所以$OP$平分$\angle APB$。

**$OP$垂直平分$AB$**

$PA = PB$，$OA = OB$。

$OP$是$AB$的垂直平分线。

## 四、三角形的内切圆、内心

**内切圆**

与三角形三边都相切的圆。

三角形叫做圆的外切三角形。

**内心**

内切圆的圆心。

内心是三角形三条角平分线的交点。

内心到三边的距离相等。

**内心的性质**

内心在三角形内部。

内心到三边的距离等于内切圆半径。

## 五、例题讲解

**例题1：** 如图，$PA$、$PB$是$\odot O$的切线，切点分别为$A$、$B$。若$PA = 8$cm，求$PB$的长度。

解：

根据切线长定理：从圆外一点引圆的两条切线，它们的切线长相等。

$PB = PA = 8$cm。

答：$PB = 8$cm。

**例题2：** 如图，$PA$、$PB$是$\odot O$的切线，切点分别为$A$、$B$。若$\angle APB = 60°$，求$\angle APO$的度数。

解：

根据切线长定理的推论：$OP$平分$\angle APB$。

$\angle APO = \frac{1}{2}\angle APB = \frac{1}{2} \times 60° = 30°$。

答：$\angle APO = 30°$。

**例题3：** 如图，$PA$、$PB$是$\odot O$的切线，切点分别为$A$、$B$。若$PA = 6$cm，$OA = 4$cm，求$OP$的长度。

解：

$PA$是切线，$OA$是半径。

根据切线的性质：$PA \perp OA$。

在$\text{Rt}\triangle OAP$中，由勾股定理：

$OP^2 = OA^2 + PA^2$。

$OP^2 = 4^2 + 6^2 = 16 + 36 = 52$。

$OP = \sqrt{52} = 2\sqrt{13}$cm。

答：$OP = 2\sqrt{13}$cm。

**例题4：** 如图，$\triangle ABC$中，$AB = 10$cm，$BC = 8$cm，$AC = 6$cm。求$\triangle ABC$的内切圆半径。

解：

$6^2+8^2 = 36+64 = 100 = 10^2$。

$\triangle ABC$是直角三角形，$\angle C = 90°$。

直角三角形的内切圆半径公式：$r = \frac{a+b-c}{2}$。

$r = \frac{6+8-10}{2} = \frac{4}{2} = 2$cm。

答：内切圆半径为$2$cm。

**例题5：** 如图，$PA$、$PB$是$\odot O$的切线，切点分别为$A$、$B$，$OP$交$AB$于点$C$。证明：$OP \perp AB$。

解：

根据切线长定理：$PA = PB$。

又$OA = OB$（半径相等）。

$P$、$O$都在$AB$的垂直平分线上。

所以$OP$是$AB$的垂直平分线。

$OP \perp AB$。

答：$OP \perp AB$。

## 六、常见错误

**错误1：切线长与切线混淆**

错误理解：切线长就是切线的长度。

正确理解：切线是直线，没有长度；切线长是线段长度。

**错误2：切线长定理条件不满足**

错误做法：从圆上一点引两条切线。

正确做法：必须从圆外一点引两条切线。

**错误3：内心与外心混淆**

错误理解：内心是垂直平分线的交点。

正确理解：内心是角平分线的交点。

**错误4：内切圆半径公式记错**

错误做法：$r = \frac{a+b+c}{2}$。

正确做法：直角三角形$r = \frac{a+b-c}{2}$。

**错误5：角平分线性质用错**

错误理解：$OP$平分$\angle AOB$。

正确理解：$OP$平分$\angle APB$。

## 七、练习题

**练习1：** 如图，$PA$、$PB$是$\odot O$的切线，切点分别为$A$、$B$。若$PB = 10$cm，求$PA$的长度。

解：

根据切线长定理：$PA = PB = 10$cm。

答：$PA = 10$cm。

**练习2：** 如图，$PA$、$PB$是$\odot O$的切线，切点分别为$A$、$B$。若$\angle APB = 80°$，求$\angle APO$的度数。

解：

根据切线长定理的推论：$OP$平分$\angle APB$。

$\angle APO = \frac{1}{2}\angle APB = \frac{1}{2} \times 80° = 40°$。

答：$\angle APO = 40°$。

**练习3：** 如图，$PA$、$PB$是$\odot O$的切线，切点分别为$A$、$B$。若$PA = 5$cm，$OA = 3$cm，求$OP$的长度。

解：

$PA \perp OA$（切线性质）。

在$\text{Rt}\triangle OAP$中，由勾股定理：

$OP^2 = OA^2 + PA^2$。

$OP^2 = 3^2 + 5^2 = 9 + 25 = 34$。

$OP = \sqrt{34}$cm。

答：$OP = \sqrt{34}$cm。

**练习4：** 如图，$\triangle ABC$中，$AB = 13$cm，$BC = 12$cm，$AC = 5$cm。求$\triangle ABC$的内切圆半径。

解：

$5^2+12^2 = 25+144 = 169 = 13^2$。

$\triangle ABC$是直角三角形，$\angle C = 90°$。

$r = \frac{a+b-c}{2} = \frac{5+12-13}{2} = \frac{4}{2} = 2$cm。

答：内切圆半径为$2$cm。

**练习5：** 如图，$PA$、$PB$是$\odot O$的切线，切点分别为$A$、$B$。若$\angle AOB = 120°$，求$\angle APB$的度数。

解：

在四边形$OAPB$中：

$\angle OAP = 90°$，$\angle OBP = 90°$（切线性质）。

$\angle AOB = 120°$。

四边形内角和为$360°$。

$\angle APB = 360°-90°-90°-120° = 60°$。

答：$\angle APB = 60°$。
