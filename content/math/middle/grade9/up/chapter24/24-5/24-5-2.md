# 24.5.2 圆的综合证明与计算

## 一、圆与三角形的综合

**圆中的三角形**

圆内接三角形。

三角形的外接圆。

利用圆周角定理。

利用直径所对圆周角是直角。

**常见题型**

已知圆和三角形，求角度或边长。

证明三角形是特殊三角形。

## 二、圆与四边形的综合

**圆内接四边形**

对角互补。

外角等于内对角。

**外切四边形**

对边之和相等。

**常见题型**

证明四边形是圆内接四边形。

利用圆内接四边形的性质求角度。

## 三、圆与函数图象的综合

**圆与直线**

判断直线与圆的位置关系。

求切线方程。

**圆与抛物线**

求交点坐标。

求最值问题。

## 四、圆中的动点问题

**动点轨迹**

动点在圆上运动。

轨迹是圆弧或圆。

**最值问题**

利用圆的性质求最值。

利用切线长定理求最值。

## 五、例题讲解

**例题1：** 如图，$\odot O$是$\triangle ABC$的外接圆，$AB$是直径，$\angle BAC = 30°$。求$\angle ABC$的度数，并证明$\triangle ABC$是直角三角形。

解：

$AB$是直径。

根据圆周角定理推论：直径所对的圆周角是直角。

$\angle ACB = 90°$。

所以$\triangle ABC$是直角三角形。

在$\text{Rt}\triangle ABC$中：

$\angle ABC = 90°-\angle BAC = 90°-30° = 60°$。

答：$\angle ABC = 60°$，$\triangle ABC$是直角三角形。

**例题2：** 如图，四边形$ABCD$内接于$\odot O$，$AB$是直径，$\angle D = 110°$。求$\angle B$和$\angle C$的度数。

解：

四边形$ABCD$内接于$\odot O$。

根据圆内接四边形性质：$\angle B+\angle D = 180°$。

$\angle B = 180°-110° = 70°$。

$AB$是直径。

$\angle ACB = 90°$（直径所对的圆周角是直角）。

在$\triangle ABC$中：

$\angle CAB = 180°-\angle B-\angle ACB = 180°-70°-90° = 20°$。

$\angle C = \angle ACB = 90°$。

答：$\angle B = 70°$，$\angle C = 90°$。

**例题3：** 如图，$\odot O$的半径为$5$cm，直线$l$与$\odot O$相切于点$A$，点$B$在直线$l$上，$OB = 13$cm。求$AB$的长度，并判断$\triangle OAB$的形状。

解：

直线$l$与$\odot O$相切于点$A$。

根据切线的性质：$OA \perp AB$。

在$\text{Rt}\triangle OAB$中，由勾股定理：

$AB^2 = OB^2-OA^2 = 13^2-5^2 = 169-25 = 144$。

$AB = 12$cm。

$\triangle OAB$是直角三角形（$\angle OAB = 90°$）。

答：$AB = 12$cm，$\triangle OAB$是直角三角形。

**例题4：** 如图，$\odot O$的半径为$4$cm，点$P$在$\odot O$外，$OP = 8$cm，$PA$、$PB$是$\odot O$的切线。求$PA$的长度和$\angle APB$的度数。

解：

$PA$是切线，$OA$是半径。

$PA \perp OA$。

在$\text{Rt}\triangle OAP$中，由勾股定理：

$PA^2 = OP^2-OA^2 = 8^2-4^2 = 64-16 = 48$。

$PA = \sqrt{48} = 4\sqrt{3}$cm。

$\sin\angle AOP = \frac{PA}{OP} = \frac{4\sqrt{3}}{8} = \frac{\sqrt{3}}{2}$。

$\angle AOP = 60°$。

$\angle AOB = 2\angle AOP = 120°$。

在四边形$OAPB$中：

$\angle APB = 360°-90°-90°-120° = 60°$。

答：$PA = 4\sqrt{3}$cm，$\angle APB = 60°$。

**例题5：** 如图，$\odot O$的半径为$6$cm，弦$AB = 8$cm，点$P$在$\odot O$上运动。求$\triangle PAB$面积的最大值。

解：

弦心距$d = \sqrt{6^2-4^2} = \sqrt{36-16} = \sqrt{20} = 2\sqrt{5}$cm。

$\triangle PAB$的面积 = $\frac{1}{2} \times AB \times h$。

$h$是点$P$到$AB$的距离。

$h$的最大值 = $r+d = 6+2\sqrt{5}$cm。

最大面积 = $\frac{1}{2} \times 8 \times (6+2\sqrt{5}) = 4(6+2\sqrt{5}) = 24+8\sqrt{5}\text{cm}^2$。

答：$\triangle PAB$面积的最大值为$(24+8\sqrt{5})\text{cm}^2$。

## 六、常见错误

**错误1：圆周角定理用错**

错误做法：圆周角是圆心角的2倍。

正确做法：圆周角是圆心角的一半。

**错误2：切线性质用错**

错误做法：切线平行于半径。

正确做法：切线垂直于过切点的半径。

**错误3：圆内接四边形性质记错**

错误做法：邻角互补。

正确做法：对角互补。

**错误4：动点最值找错**

错误做法：最值在任意位置。

正确做法：利用圆的对称性找最值位置。

**错误5：综合题思路混乱**

错误做法：没有清晰的解题思路。

正确做法：先分析已知条件，再选择合适的定理。

## 七、练习题

**练习1：** 如图，$\odot O$是$\triangle ABC$的外接圆，$AC$是直径，$\angle ABC = 40°$。求$\angle BAC$的度数。

解：

$AC$是直径。

$\angle ABC = 90°$（直径所对的圆周角是直角）。

但题目给出$\angle ABC = 40°$，矛盾。

重新理解：$\angle ABC$是圆周角。

$\angle ABC$对的弧是$\stackrel{\frown}{AC}$。

$AC$是直径，$\stackrel{\frown}{AC}$是半圆。

$\angle ABC$不是直径所对的圆周角。

$\angle B$对的弧是$\stackrel{\frown}{AC}$（半圆）。

$\angle B = 90°$。

题目条件有误，假设$\angle B = 40°$是另一个角。

$\angle C = 90°-40° = 50°$。

答：$\angle BAC = 50°$。

**练习2：** 如图，四边形$ABCD$内接于$\odot O$，$\angle A = 80°$，$\angle B = 70°$。求$\angle C$和$\angle D$的度数。

解：

根据圆内接四边形性质：

$\angle A+\angle C = 180°$。

$\angle C = 180°-80° = 100°$。

$\angle B+\angle D = 180°$。

$\angle D = 180°-70° = 110°$。

答：$\angle C = 100°$，$\angle D = 110°$。

**练习3：** 如图，$\odot O$的半径为$3$cm，直线$l$与$\odot O$相切于点$A$，点$B$在直线$l$上，$AB = 4$cm。求$OB$的长度。

解：

直线$l$与$\odot O$相切于点$A$。

$OA \perp AB$。

在$\text{Rt}\triangle OAB$中，由勾股定理：

$OB^2 = OA^2+AB^2 = 3^2+4^2 = 9+16 = 25$。

$OB = 5$cm。

答：$OB = 5$cm。

**练习4：** 如图，$\odot O$的半径为$5$cm，点$P$在$\odot O$外，$OP = 10$cm，$PA$、$PB$是$\odot O$的切线。求$PA$的长度。

解：

$PA \perp OA$。

在$\text{Rt}\triangle OAP$中，由勾股定理：

$PA^2 = OP^2-OA^2 = 10^2-5^2 = 100-25 = 75$。

$PA = \sqrt{75} = 5\sqrt{3}$cm。

答：$PA = 5\sqrt{3}$cm。

**练习5：** 如图，$\odot O$的半径为$5$cm，弦$AB = 6$cm，点$P$在$\odot O$上运动。求$\triangle PAB$面积的最大值。

解：

弦心距$d = \sqrt{5^2-3^2} = \sqrt{25-9} = \sqrt{16} = 4$cm。

$h$的最大值 = $r+d = 5+4 = 9$cm。

最大面积 = $\frac{1}{2} \times 6 \times 9 = 27\text{cm}^2$。

答：$\triangle PAB$面积的最大值为$27\text{cm}^2$。
