# 24.5.1 阴影部分面积计算

## 一、割补法求阴影面积

**割法**

把阴影部分分割成几个规则图形。

分别计算每个规则图形的面积。

把各部分面积相加或相减。

**补法**

把阴影部分补成一个规则图形。

计算规则图形的面积。

减去补上的部分的面积。

## 二、平移法求阴影面积

**平移转化**

把阴影部分平移。

转化为容易计算的图形。

利用平移不改变面积的性质。

**例子**

两个相同的弓形。

平移后拼成一个规则图形。

## 三、旋转法求阴影面积

**旋转转化**

把阴影部分绕某点旋转。

转化为容易计算的图形。

利用旋转不改变面积的性质。

**例子**

扇形中的阴影部分。

旋转后与另一部分重合。

## 四、等积变形法求阴影面积

**等积变形**

把阴影部分变形。

变形前后面积不变。

转化为容易计算的图形。

**例子**

同底等高的三角形面积相等。

利用这个性质进行等积变形。

## 五、例题讲解

**例题1：** 如图，正方形$ABCD$的边长为$4$cm，以$A$为圆心，$4$cm为半径画弧。求阴影部分（扇形与正方形的重叠部分）的面积。

解：

阴影部分是扇形的一部分。

扇形圆心角为$90°$，半径为$4$cm。

$S_{\text{扇}} = \dfrac{90 \times \pi \times 4^2}{360} = 4\pi\text{cm}^2$。

答：阴影部分面积为$4\pi\text{cm}^2$。

**例题2：** 如图，$\odot O$的半径为$6$cm，正方形$ABCD$内接于$\odot O$。求阴影部分（圆与正方形之间的部分）的面积。

解：

圆的面积：$S_{\text{圆}} = \pi \times 6^2 = 36\pi\text{cm}^2$。

正方形的对角线 = 直径 = $12$cm。

正方形的边长$a$满足：$a^2+a^2 = 12^2$。

$2a^2 = 144$，$a^2 = 72$。

正方形面积：$S_{\text{正}} = 72\text{cm}^2$。

阴影面积 = $S_{\text{圆}}-S_{\text{正}} = 36\pi-72\text{cm}^2$。

答：阴影部分面积为$(36\pi-72)\text{cm}^2$。

**例题3：** 如图，半圆的直径为$8$cm，以直径为边作正方形。求阴影部分（半圆与正方形重叠部分）的面积。

解：

半圆面积：$S_{\text{半圆}} = \frac{1}{2}\pi \times 4^2 = 8\pi\text{cm}^2$。

正方形面积：$S_{\text{正}} = 8^2 = 64\text{cm}^2$。

阴影部分是半圆与正方形的重叠部分。

重叠部分就是半圆（半圆完全在正方形内）。

阴影面积 = $8\pi\text{cm}^2$。

答：阴影部分面积为$8\pi\text{cm}^2$。

**例题4：** 如图，$\odot O$的半径为$4$cm，$\angle AOB = 90°$。求阴影部分（弓形）的面积。

解：

扇形面积：$S_{\text{扇}} = \dfrac{90 \times \pi \times 4^2}{360} = 4\pi\text{cm}^2$。

$\triangle OAB$是等腰直角三角形。

$S_{\triangle} = \frac{1}{2} \times 4 \times 4 = 8\text{cm}^2$。

弓形面积 = $S_{\text{扇}}-S_{\triangle} = 4\pi-8\text{cm}^2$。

答：阴影部分面积为$(4\pi-8)\text{cm}^2$。

**例题5：** 如图，两个半径为$4$cm的等圆相交，圆心距为$4$cm。求阴影部分（两圆公共部分）的面积。

解：

连接两圆心$O_1$、$O_2$和交点$A$、$B$。

$O_1A = O_2A = O_1O_2 = 4$cm。

$\triangle O_1AO_2$是等边三角形。

$\angle AO_1O_2 = 60°$。

$\angle AO_1B = 120°$。

一个弓形面积：$S_{\text{弓}} = S_{\text{扇}}-S_{\triangle}$。

$S_{\text{扇}} = \dfrac{120 \times \pi \times 4^2}{360} = \dfrac{16\pi}{3}\text{cm}^2$。

$S_{\triangle} = \frac{1}{2} \times 4 \times 4 \times \sin 120° = 8 \times \frac{\sqrt{3}}{2} = 4\sqrt{3}\text{cm}^2$。

$S_{\text{弓}} = \dfrac{16\pi}{3}-4\sqrt{3}\text{cm}^2$。

阴影面积 = $2S_{\text{弓}} = \dfrac{32\pi}{3}-8\sqrt{3}\text{cm}^2$。

答：阴影部分面积为$(\dfrac{32\pi}{3}-8\sqrt{3})\text{cm}^2$。

## 六、常见错误

**错误1：割补法用错**

错误做法：分割后面积计算错误。

正确做法：确保分割后的图形面积之和等于原图形面积。

**错误2：平移后图形改变**

错误做法：平移后图形形状改变。

正确做法：平移不改变图形的形状和大小。

**错误3：旋转中心选错**

错误做法：旋转中心不在图形上。

正确做法：选择合适的旋转中心。

**错误4：等积变形条件不满足**

错误做法：底或高不相等就用等积变形。

正确做法：确保底和高都相等。

**错误5：阴影部分识别错误**

错误做法：把非阴影部分当成阴影部分。

正确做法：仔细识别阴影部分。

## 七、练习题

**练习1：** 如图，正方形$ABCD$的边长为$6$cm，以$B$为圆心，$6$cm为半径画弧。求阴影部分（扇形）的面积。

解：

扇形圆心角为$90°$，半径为$6$cm。

$S_{\text{扇}} = \dfrac{90 \times \pi \times 6^2}{360} = 9\pi\text{cm}^2$。

答：阴影部分面积为$9\pi\text{cm}^2$。

**练习2：** 如图，$\odot O$的半径为$5$cm，正方形$ABCD$内接于$\odot O$。求阴影部分（圆与正方形之间的部分）的面积。

解：

圆的面积：$S_{\text{圆}} = \pi \times 5^2 = 25\pi\text{cm}^2$。

正方形的对角线 = 直径 = $10$cm。

$2a^2 = 100$，$a^2 = 50$。

正方形面积：$S_{\text{正}} = 50\text{cm}^2$。

阴影面积 = $25\pi-50\text{cm}^2$。

答：阴影部分面积为$(25\pi-50)\text{cm}^2$。

**练习3：** 如图，$\odot O$的半径为$3$cm，$\angle AOB = 60°$。求阴影部分（弓形）的面积。

解：

扇形面积：$S_{\text{扇}} = \dfrac{60 \times \pi \times 3^2}{360} = \frac{3\pi}{2}\text{cm}^2$。

$\triangle OAB$是等边三角形。

$S_{\triangle} = \frac{\sqrt{3}}{4} \times 3^2 = \frac{9\sqrt{3}}{4}\text{cm}^2$。

弓形面积 = $\frac{3\pi}{2}-\frac{9\sqrt{3}}{4}\text{cm}^2$。

答：阴影部分面积为$(\frac{3\pi}{2}-\frac{9\sqrt{3}}{4})\text{cm}^2$。

**练习4：** 如图，半圆的半径为$5$cm，内接矩形的长为$8$cm。求阴影部分（半圆与矩形之间的部分）的面积。

解：

半圆面积：$S_{\text{半圆}} = \frac{1}{2}\pi \times 5^2 = \frac{25\pi}{2}\text{cm}^2$。

矩形的宽：$\sqrt{5^2-4^2} = \sqrt{25-16} = 3$cm。

矩形面积：$S_{\text{矩}} = 8 \times 3 = 24\text{cm}^2$。

阴影面积 = $\frac{25\pi}{2}-24\text{cm}^2$。

答：阴影部分面积为$(\frac{25\pi}{2}-24)\text{cm}^2$。

**练习5：** 如图，$\odot O$的半径为$6$cm，$\angle AOB = 120°$。求阴影部分（弓形）的面积。

解：

扇形面积：$S_{\text{扇}} = \dfrac{120 \times \pi \times 6^2}{360} = 12\pi\text{cm}^2$。

作$OC \perp AB$于$C$。

$\angle AOC = 60°$。

$OC = 6 \times \cos 60° = 3$cm。

$AC = 6 \times \sin 60° = 3\sqrt{3}$cm。

$AB = 6\sqrt{3}$cm。

$S_{\triangle} = \frac{1}{2} \times 6\sqrt{3} \times 3 = 9\sqrt{3}\text{cm}^2$。

弓形面积 = $12\pi-9\sqrt{3}\text{cm}^2$。

答：阴影部分面积为$(12\pi-9\sqrt{3})\text{cm}^2$。
