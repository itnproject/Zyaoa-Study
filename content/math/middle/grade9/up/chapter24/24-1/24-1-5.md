# 24.1.5 圆内接四边形

## 一、圆内接四边形的定义

**四个顶点都在圆上的四边形**

四边形$ABCD$的四个顶点$A$、$B$、$C$、$D$都在$\odot O$上。

四边形$ABCD$叫做$\odot O$的内接四边形。

$\odot O$叫做四边形$ABCD$的外接圆。

**例子**

矩形、正方形都有外接圆。

一般的平行四边形没有外接圆。

## 二、性质1：对角互补

**圆内接四边形的对角互补**

四边形$ABCD$内接于$\odot O$。

$\angle A+\angle C = 180°$。

$\angle B+\angle D = 180°$。

**证明思路**

连接对角线。

利用圆周角定理。

同弧所对的圆周角相等。

对角之和等于$180°$。

## 三、性质2：外角等于内对角

**圆内接四边形的外角等于内对角**

四边形$ABCD$内接于$\odot O$。

延长$AB$到$E$。

$\angle CBE$是外角。

$\angle CBE = \angle D$（内对角）。

**理解**

外角与相邻内角互补。

对角也与相邻内角互补。

所以外角等于内对角。

## 四、判定：对角互补的四边形四点共圆

**对角互补的四边形四点共圆**

四边形$ABCD$中，$\angle A+\angle C = 180°$。

则$A$、$B$、$C$、$D$四点共圆。

**理解**

对角互补是四点共圆的充要条件。

可以用来判断四点是否共圆。

## 五、例题讲解

**例题1：** 如图，四边形$ABCD$内接于$\odot O$，$\angle A = 80°$。求$\angle C$的度数。

解：

四边形$ABCD$内接于$\odot O$。

根据性质1：圆内接四边形的对角互补。

$\angle A+\angle C = 180°$。

$\angle C = 180°-\angle A = 180°-80° = 100°$。

答：$\angle C = 100°$。

**例题2：** 如图，四边形$ABCD$内接于$\odot O$，延长$AB$到$E$，$\angle D = 70°$。求$\angle CBE$的度数。

解：

四边形$ABCD$内接于$\odot O$。

根据性质2：圆内接四边形的外角等于内对角。

$\angle CBE = \angle D = 70°$。

答：$\angle CBE = 70°$。

**例题3：** 如图，四边形$ABCD$中，$\angle A = 60°$，$\angle C = 120°$。判断$A$、$B$、$C$、$D$是否四点共圆。

解：

$\angle A+\angle C = 60°+120° = 180°$。

根据判定：对角互补的四边形四点共圆。

所以$A$、$B$、$C$、$D$四点共圆。

答：$A$、$B$、$C$、$D$四点共圆。

**例题4：** 如图，四边形$ABCD$内接于$\odot O$，$\angle A:\angle B:\angle C = 2:3:4$。求各角的度数。

解：

设$\angle A = 2x$，$\angle B = 3x$，$\angle C = 4x$。

根据性质1：$\angle A+\angle C = 180°$。

$2x+4x = 180°$。

$6x = 180°$。

$x = 30°$。

$\angle A = 60°$，$\angle B = 90°$，$\angle C = 120°$。

$\angle D = 180°-\angle B = 180°-90° = 90°$。

答：$\angle A = 60°$，$\angle B = 90°$，$\angle C = 120°$，$\angle D = 90°$。

**例题5：** 如图，四边形$ABCD$内接于$\odot O$，$\angle A = 50°$，$\angle B = 70°$。求$\angle C$和$\angle D$的度数，并求$\angle DCE$（$E$在$AB$延长线上）的度数。

解：

根据性质1：$\angle A+\angle C = 180°$。

$\angle C = 180°-50° = 130°$。

$\angle B+\angle D = 180°$。

$\angle D = 180°-70° = 110°$。

根据性质2：$\angle DCE = \angle A = 50°$。

答：$\angle C = 130°$，$\angle D = 110°$，$\angle DCE = 50°$。

## 六、常见错误

**错误1：对角互补记成邻角互补**

错误做法：$\angle A+\angle B = 180°$。

正确做法：$\angle A+\angle C = 180°$。

**错误2：外角等于内对角找错**

错误做法：外角等于相邻内角。

正确做法：外角等于内对角（不相邻的内角）。

**错误3：判定条件用错**

错误做法：邻角互补就认为四点共圆。

正确做法：对角互补才能判定四点共圆。

**错误4：忽略"内接"条件**

错误做法：任意四边形都用对角互补。

正确做法：只有圆内接四边形才有对角互补。

**错误5：比例计算错误**

错误做法：设比例时没有利用对角互补。

正确做法：利用对角互补列方程。

## 七、练习题

**练习1：** 如图，四边形$ABCD$内接于$\odot O$，$\angle B = 110°$。求$\angle D$的度数。

解：

四边形$ABCD$内接于$\odot O$。

根据性质1：$\angle B+\angle D = 180°$。

$\angle D = 180°-110° = 70°$。

答：$\angle D = 70°$。

**练习2：** 如图，四边形$ABCD$内接于$\odot O$，延长$BC$到$E$，$\angle A = 65°$。求$\angle DCE$的度数。

解：

四边形$ABCD$内接于$\odot O$。

根据性质2：圆内接四边形的外角等于内对角。

$\angle DCE = \angle A = 65°$。

答：$\angle DCE = 65°$。

**练习3：** 如图，四边形$ABCD$中，$\angle B = 95°$，$\angle D = 85°$。判断$A$、$B$、$C$、$D$是否四点共圆。

解：

$\angle B+\angle D = 95°+85° = 180°$。

根据判定：对角互补的四边形四点共圆。

所以$A$、$B$、$C$、$D$四点共圆。

答：$A$、$B$、$C$、$D$四点共圆。

**练习4：** 如图，四边形$ABCD$内接于$\odot O$，$\angle A:\angle B:\angle C:\angle D = 3:4:5:2$。判断这个四边形是否是圆内接四边形。

解：

$\angle A+\angle C = 3x+5x = 8x$。

$\angle B+\angle D = 4x+2x = 6x$。

如果是圆内接四边形，则$\angle A+\angle C = 180°$，$\angle B+\angle D = 180°$。

但$8x \neq 6x$（$x \neq 0$）。

所以这个四边形不是圆内接四边形。

答：这个四边形不是圆内接四边形。

**练习5：** 如图，四边形$ABCD$内接于$\odot O$，$\angle A = 40°$，$\angle D = 100°$。求$\angle B$和$\angle C$的度数。

解：

根据性质1：$\angle A+\angle C = 180°$。

$\angle C = 180°-40° = 140°$。

$\angle B+\angle D = 180°$。

$\angle B = 180°-100° = 80°$。

答：$\angle B = 80°$，$\angle C = 140°$。
