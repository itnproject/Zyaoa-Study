# 24.1.3 弧、弦、圆心角

## 一、圆心角的定义

**顶点在圆心的角**

圆心角的顶点是圆心。

圆心角的两边是半径。

圆心角所对的弧是两边与圆的交点之间的弧。

圆心角所对的弦是两边与圆的交点之间的线段。

**例子**

$\angle AOB$是圆心角。

顶点$O$是圆心。

$OA$、$OB$是半径。

$\stackrel{\frown}{AB}$是$\angle AOB$所对的弧。

$AB$是$\angle AOB$所对的弦。

## 二、定理

**在同圆或等圆中，相等的圆心角所对的弧相等，所对的弦相等**

已知：在$\odot O$中，$\angle AOB = \angle COD$。

结论：$\stackrel{\frown}{AB} = \stackrel{\frown}{CD}$，$AB = CD$。

**理解**

圆心角相等。

所对的弧相等。

所对的弦相等。

## 三、推论

**在同圆或等圆中，两个圆心角、两条弧、两条弦中有一组量相等，其余各组也相等**

**三种情况**

圆心角相等 $\Rightarrow$ 弧相等，弦相等。

弧相等 $\Rightarrow$ 圆心角相等，弦相等。

弦相等 $\Rightarrow$ 圆心角相等，弧相等。

**前提条件**

必须在同圆或等圆中。

不同圆中不能直接应用。

## 四、1°的弧的定义

**把圆心角分成360等份**

每一份是$1°$的圆心角。

$1°$的圆心角所对的弧是$1°$的弧。

$n°$的圆心角所对的弧是$n°$的弧。

**弧的度数**

弧的度数等于它所对的圆心角的度数。

$\stackrel{\frown}{AB}$的度数 = $\angle AOB$的度数。

## 五、例题讲解

**例题1：** 如图，在$\odot O$中，$\angle AOB = 60°$，$\angle COD = 60°$。证明：$AB = CD$。

解：

在$\odot O$中，$\angle AOB = \angle COD = 60°$。

根据定理：在同圆中，相等的圆心角所对的弦相等。

所以$AB = CD$。

答：$AB = CD$。

**例题2：** 如图，在$\odot O$中，$\stackrel{\frown}{AB} = \stackrel{\frown}{CD}$。证明：$\angle AOB = \angle COD$。

解：

在$\odot O$中，$\stackrel{\frown}{AB} = \stackrel{\frown}{CD}$。

根据推论：在同圆中，相等的弧所对的圆心角相等。

所以$\angle AOB = \angle COD$。

答：$\angle AOB = \angle COD$。

**例题3：** 如图，在$\odot O$中，$AB = CD$，$\angle AOB = 50°$。求$\angle COD$的度数。

解：

在$\odot O$中，$AB = CD$。

根据推论：在同圆中，相等的弦所对的圆心角相等。

所以$\angle COD = \angle AOB = 50°$。

答：$\angle COD = 50°$。

**例题4：** 如图，在$\odot O$中，$\angle AOB = 80°$，求$\stackrel{\frown}{AB}$的度数。

解：

弧的度数等于它所对的圆心角的度数。

$\stackrel{\frown}{AB}$的度数 = $\angle AOB$的度数 = $80°$。

答：$\stackrel{\frown}{AB}$的度数为$80°$。

**例题5：** 如图，在$\odot O$中，$\stackrel{\frown}{AB} = \stackrel{\frown}{CD}$，$AB = 6$cm。求$CD$的长度。

解：

在$\odot O$中，$\stackrel{\frown}{AB} = \stackrel{\frown}{CD}$。

根据推论：在同圆中，相等的弧所对的弦相等。

所以$CD = AB = 6$cm。

答：$CD = 6$cm。

## 六、常见错误

**错误1：忽略"同圆或等圆"的前提**

错误做法：在不同圆中直接用定理。

正确做法：必须在同圆或等圆中才能应用定理。

**错误2：弧的度数与弧长混淆**

错误理解：弧的度数就是弧长。

正确理解：弧的度数是角度，弧长是长度。

**错误3：对应关系找错**

错误做法：$\angle AOB$所对的弦是$AC$。

正确做法：$\angle AOB$所对的弦是$AB$。

**错误4：推论用错方向**

错误理解：只有圆心角相等才能推出弧相等。

正确理解：弧相等、弦相等、圆心角相等可以互相推出。

**错误5：等圆条件不满足**

错误做法：半径不同的圆中，圆心角相等就认为弦相等。

正确做法：必须在同圆或等圆中。

## 七、练习题

**练习1：** 如图，在$\odot O$中，$\angle AOB = 90°$，$\angle COD = 90°$。证明：$\stackrel{\frown}{AB} = \stackrel{\frown}{CD}$。

解：

在$\odot O$中，$\angle AOB = \angle COD = 90°$。

根据定理：在同圆中，相等的圆心角所对的弧相等。

所以$\stackrel{\frown}{AB} = \stackrel{\frown}{CD}$。

答：$\stackrel{\frown}{AB} = \stackrel{\frown}{CD}$。

**练习2：** 如图，在$\odot O$中，$AB = CD$，$\angle COD = 70°$。求$\angle AOB$的度数。

解：

在$\odot O$中，$AB = CD$。

根据推论：在同圆中，相等的弦所对的圆心角相等。

所以$\angle AOB = \angle COD = 70°$。

答：$\angle AOB = 70°$。

**练习3：** 如图，在$\odot O$中，$\stackrel{\frown}{AB}$的度数为$120°$，求$\angle AOB$的度数。

解：

弧的度数等于它所对的圆心角的度数。

$\angle AOB = \stackrel{\frown}{AB}$的度数 = $120°$。

答：$\angle AOB = 120°$。

**练习4：** 如图，在$\odot O$和$\odot O'$中，$\odot O$与$\odot O'$是等圆，$\angle AOB = 45°$，$\angle C'O'D' = 45°$。证明：$AB = C'D'$。

解：

$\odot O$与$\odot O'$是等圆。

$\angle AOB = \angle C'O'D' = 45°$。

根据定理：在等圆中，相等的圆心角所对的弦相等。

所以$AB = C'D'$。

答：$AB = C'D'$。

**练习5：** 如图，在$\odot O$中，$\stackrel{\frown}{AB} = \stackrel{\frown}{CD}$，$\angle AOB = 35°$。求$\angle COD$的度数。

解：

在$\odot O$中，$\stackrel{\frown}{AB} = \stackrel{\frown}{CD}$。

根据推论：在同圆中，相等的弧所对的圆心角相等。

所以$\angle COD = \angle AOB = 35°$。

答：$\angle COD = 35°$。
