# 24.1.2 垂直于弦的直径

## 一、圆的对称性

**圆是轴对称图形**

圆有无数条对称轴。

每条直径所在的直线都是对称轴。

**圆是中心对称图形**

对称中心是圆心。

绕圆心旋转任意角度都与自身重合。

## 二、垂径定理

**定理：垂直于弦的直径平分这条弦，并且平分弦所对的两条弧**

已知：直径$CD \perp$弦$AB$，垂足为$E$。

结论：$AE = BE$，$\stackrel{\frown}{AC} = \stackrel{\frown}{BC}$，$\stackrel{\frown}{AD} = \stackrel{\frown}{BD}$。

**理解**

直径垂直于弦。

直径把弦分成两段相等的线段。

直径把弦所对的两条弧分别平分。

## 三、推论

**推论：平分弦（不是直径）的直径垂直于弦，并且平分弦所对的两条弧**

已知：直径$CD$平分弦$AB$（$AB$不是直径）。

结论：$CD \perp AB$，$\stackrel{\frown}{AC} = \stackrel{\frown}{BC}$，$\stackrel{\frown}{AD} = \stackrel{\frown}{BD}$。

**注意**

弦$AB$不能是直径。

如果$AB$是直径，结论不成立。

## 四、利用垂径定理求弦长、半径、弦心距

**弦心距**

圆心到弦的距离。

记作$d$。

**勾股定理关系**

$r^2 = d^2 + (\frac{AB}{2})^2$。

$r$是半径。

$d$是弦心距。

$AB$是弦长。

**已知任意两个量，可求第三个量**

已知$r$和$d$，求$AB$。

已知$r$和$AB$，求$d$。

已知$d$和$AB$，求$r$。

## 五、勾股定理与垂径定理的结合

**构造直角三角形**

连接圆心和弦的端点。

圆心到弦的垂线。

弦的一半。

**直角三角形三边**

斜边是半径$r$。

一条直角边是弦心距$d$。

另一条直角边是弦长的一半$\frac{AB}{2}$。

**公式**

$r^2 = d^2 + (\frac{AB}{2})^2$。

## 六、例题讲解

**例题1：** 如图，在$\odot O$中，直径$CD \perp$弦$AB$于点$E$。若$AB = 8$cm，求$AE$的长度。

解：

根据垂径定理：垂直于弦的直径平分这条弦。

$AE = BE = \frac{AB}{2}$。

$AE = \frac{8}{2} = 4$cm。

答：$AE = 4$cm。

**例题2：** 如图，在$\odot O$中，半径$OA = 5$cm，弦$AB = 8$cm，$OC \perp AB$于点$C$。求$OC$的长度。

解：

根据垂径定理：$AC = \frac{AB}{2} = \frac{8}{2} = 4$cm。

在$\text{Rt}\triangle OAC$中，由勾股定理：

$OC^2 = OA^2 - AC^2$。

$OC^2 = 5^2 - 4^2 = 25 - 16 = 9$。

$OC = 3$cm。

答：$OC = 3$cm。

**例题3：** 如图，在$\odot O$中，弦$AB = 10$cm，弦心距$OC = 4$cm，求$\odot O$的半径。

解：

根据垂径定理：$AC = \frac{AB}{2} = \frac{10}{2} = 5$cm。

在$\text{Rt}\triangle OAC$中，由勾股定理：

$OA^2 = OC^2 + AC^2$。

$OA^2 = 4^2 + 5^2 = 16 + 25 = 41$。

$OA = \sqrt{41}$cm。

答：$\odot O$的半径为$\sqrt{41}$cm。

**例题4：** 如图，在$\odot O$中，直径$CD$平分弦$AB$（$AB$不是直径）于点$E$。证明：$CD \perp AB$。

解：

根据推论：平分弦（不是直径）的直径垂直于弦。

直径$CD$平分弦$AB$。

$AB$不是直径。

所以$CD \perp AB$。

答：$CD \perp AB$。

**例题5：** 如图，在$\odot O$中，弦$AB = 12$cm，半径$OA = 10$cm，求弦心距。

解：

设弦心距为$d$。

根据垂径定理：弦的一半为$\frac{12}{2} = 6$cm。

在$\text{Rt}\triangle$中，由勾股定理：

$r^2 = d^2 + (\frac{AB}{2})^2$。

$10^2 = d^2 + 6^2$。

$100 = d^2 + 36$。

$d^2 = 64$。

$d = 8$cm。

答：弦心距为$8$cm。

## 七、常见错误

**错误1：忘记弦的一半**

错误做法：直接用弦长代入勾股定理。

正确做法：用弦长的一半代入勾股定理。

**错误2：推论中忽略"不是直径"的条件**

错误做法：平分直径的直径垂直于直径。

正确做法：平分弦（不是直径）的直径才垂直于弦。

**错误3：弦心距概念不清**

错误理解：弦心距是弦的长度。

正确理解：弦心距是圆心到弦的距离。

**错误4：垂径定理与推论混淆**

错误理解：垂直于弦的直径平分弦，所以平分弦的直径垂直于弦。

正确理解：这是两个不同的命题，推论需要"不是直径"的条件。

**错误5：勾股定理用错**

错误做法：$r = d + \frac{AB}{2}$。

正确做法：$r^2 = d^2 + (\frac{AB}{2})^2$。

## 八、练习题

**练习1：** 如图，在$\odot O$中，直径$CD \perp$弦$AB$于点$E$。若$AE = 3$cm，求$AB$的长度。

解：

根据垂径定理：$AE = BE$。

$AB = AE + BE = 2AE$。

$AB = 2 \times 3 = 6$cm。

答：$AB = 6$cm。

**练习2：** 如图，在$\odot O$中，半径$OA = 13$cm，弦$AB = 24$cm，$OC \perp AB$于点$C$。求$OC$的长度。

解：

根据垂径定理：$AC = \frac{AB}{2} = \frac{24}{2} = 12$cm。

在$\text{Rt}\triangle OAC$中，由勾股定理：

$OC^2 = OA^2 - AC^2$。

$OC^2 = 13^2 - 12^2 = 169 - 144 = 25$。

$OC = 5$cm。

答：$OC = 5$cm。

**练习3：** 如图，在$\odot O$中，弦$AB = 16$cm，弦心距$OC = 6$cm，求$\odot O$的半径。

解：

根据垂径定理：$AC = \frac{AB}{2} = \frac{16}{2} = 8$cm。

在$\text{Rt}\triangle OAC$中，由勾股定理：

$OA^2 = OC^2 + AC^2$。

$OA^2 = 6^2 + 8^2 = 36 + 64 = 100$。

$OA = 10$cm。

答：$\odot O$的半径为$10$cm。

**练习4：** 如图，在$\odot O$中，直径$CD$平分弦$AB$于点$E$，$\angle AEC = 90°$。证明：$AB$不是直径。

解：

假设$AB$是直径。

则$AB$和$CD$都是直径。

两条直径互相平分。

但不一定垂直。

题目中$\angle AEC = 90°$，说明$CD \perp AB$。

这与"平分弦（不是直径）的直径垂直于弦"矛盾。

所以$AB$不是直径。

答：$AB$不是直径。

**练习5：** 如图，在$\odot O$中，弦$AB = 8$cm，半径$OA = 5$cm，求弦心距。

解：

设弦心距为$d$。

根据垂径定理：弦的一半为$\frac{8}{2} = 4$cm。

在$\text{Rt}\triangle$中，由勾股定理：

$r^2 = d^2 + (\frac{AB}{2})^2$。

$5^2 = d^2 + 4^2$。

$25 = d^2 + 16$。

$d^2 = 9$。

$d = 3$cm。

答：弦心距为$3$cm。
