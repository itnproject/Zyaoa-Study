# 24.1.4 圆周角

## 一、圆周角的定义

**顶点在圆上，两边都与圆相交的角**

圆周角的顶点在圆上。

圆周角的两边都与圆相交。

圆周角所对的弧是两边与圆的交点之间的弧（不包括顶点）。

**例子**

$\angle ACB$是圆周角。

顶点$C$在圆上。

$CA$、$CB$都与圆相交。

$\angle ACB$所对的弧是$\stackrel{\frown}{AB}$。

## 二、圆周角定理

**一条弧所对的圆周角等于它所对的圆心角的一半**

已知：$\angle ACB$是圆周角，$\angle AOB$是圆心角。

$\angle ACB$和$\angle AOB$都对$\stackrel{\frown}{AB}$。

结论：$\angle ACB = \frac{1}{2}\angle AOB$。

**理解**

同一条弧所对的圆周角和圆心角。

圆周角是圆心角的一半。

## 三、推论1：同弧或等弧所对的圆周角相等

**同弧所对的圆周角相等**

$\angle ACB$和$\angle ADB$都对$\stackrel{\frown}{AB}$。

$\angle ACB = \angle ADB$。

**等弧所对的圆周角相等**

在等圆中，等弧所对的圆周角相等。

## 四、推论2：直径所对的圆周角是直角

**直径所对的圆周角是$90°$**

$AB$是直径。

$\angle ACB$是直径所对的圆周角。

$\angle ACB = 90°$。

**逆定理：$90°$的圆周角所对的弦是直径**

$\angle ACB = 90°$。

$AB$是直径。

## 五、推论3：圆内接四边形的对角互补

**圆内接四边形的对角互补**

四边形$ABCD$内接于$\odot O$。

$\angle A+\angle C = 180°$。

$\angle B+\angle D = 180°$。

**理解**

四个顶点都在圆上的四边形。

对角之和等于$180°$。

## 六、例题讲解

**例题1：** 如图，在$\odot O$中，$\angle AOB = 80°$，点$C$在圆上。求$\angle ACB$的度数。

解：

$\angle AOB$是圆心角，$\angle ACB$是圆周角。

它们都对$\stackrel{\frown}{AB}$。

根据圆周角定理：$\angle ACB = \frac{1}{2}\angle AOB$。

$\angle ACB = \frac{1}{2} \times 80° = 40°$。

答：$\angle ACB = 40°$。

**例题2：** 如图，在$\odot O$中，$\angle ACB = 35°$，求$\angle AOB$的度数。

解：

$\angle ACB$是圆周角，$\angle AOB$是圆心角。

它们都对$\stackrel{\frown}{AB}$。

根据圆周角定理：$\angle AOB = 2\angle ACB$。

$\angle AOB = 2 \times 35° = 70°$。

答：$\angle AOB = 70°$。

**例题3：** 如图，在$\odot O$中，$AB$是直径，点$C$在圆上。求$\angle ACB$的度数。

解：

$AB$是直径。

$\angle ACB$是直径所对的圆周角。

根据推论2：直径所对的圆周角是直角。

$\angle ACB = 90°$。

答：$\angle ACB = 90°$。

**例题4：** 如图，四边形$ABCD$内接于$\odot O$，$\angle A = 70°$。求$\angle C$的度数。

解：

四边形$ABCD$内接于$\odot O$。

根据推论3：圆内接四边形的对角互补。

$\angle A+\angle C = 180°$。

$\angle C = 180°-\angle A = 180°-70° = 110°$。

答：$\angle C = 110°$。

**例题5：** 如图，在$\odot O$中，$\angle ACB = 50°$，$\angle ADB = 50°$。证明：点$C$、$D$在$\stackrel{\frown}{AB}$的同侧。

解：

$\angle ACB = \angle ADB = 50°$。

根据推论1：同弧所对的圆周角相等。

点$C$、$D$都在$\stackrel{\frown}{AB}$所对的圆周角的位置。

如果点$C$、$D$在$\stackrel{\frown}{AB}$的异侧，则$\angle ACB+\angle ADB = 180°$。

但$\angle ACB+\angle ADB = 50°+50° = 100° \neq 180°$。

所以点$C$、$D$在$\stackrel{\frown}{AB}$的同侧。

答：点$C$、$D$在$\stackrel{\frown}{AB}$的同侧。

## 七、常见错误

**错误1：圆周角与圆心角关系记反**

错误做法：圆周角是圆心角的2倍。

正确做法：圆周角是圆心角的一半。

**错误2：对应弧找错**

错误做法：$\angle ACB$对的弧是$\stackrel{\frown}{AC}$。

正确做法：$\angle ACB$对的弧是$\stackrel{\frown}{AB}$。

**错误3：直径所对圆周角记错**

错误理解：直径所对的圆周角是$60°$。

正确理解：直径所对的圆周角是$90°$。

**错误4：圆内接四边形对角互补记错**

错误理解：圆内接四边形的邻角互补。

正确理解：圆内接四边形的对角互补。

**错误5：忽略"同弧"条件**

错误做法：不同的弧所对的圆周角也相等。

正确做法：必须是同弧或等弧所对的圆周角才相等。

## 八、练习题

**练习1：** 如图，在$\odot O$中，$\angle AOB = 100°$，点$C$在圆上。求$\angle ACB$的度数。

解：

$\angle AOB$是圆心角，$\angle ACB$是圆周角。

它们都对$\stackrel{\frown}{AB}$。

根据圆周角定理：$\angle ACB = \frac{1}{2}\angle AOB$。

$\angle ACB = \frac{1}{2} \times 100° = 50°$。

答：$\angle ACB = 50°$。

**练习2：** 如图，在$\odot O$中，$\angle ACB = 25°$，求$\angle AOB$的度数。

解：

$\angle ACB$是圆周角，$\angle AOB$是圆心角。

它们都对$\stackrel{\frown}{AB}$。

根据圆周角定理：$\angle AOB = 2\angle ACB$。

$\angle AOB = 2 \times 25° = 50°$。

答：$\angle AOB = 50°$。

**练习3：** 如图，在$\odot O$中，$AB$是直径，点$C$在圆上，$\angle A = 30°$。求$\angle B$的度数。

解：

$AB$是直径。

$\angle ACB = 90°$（直径所对的圆周角是直角）。

在$\triangle ABC$中，$\angle A+\angle B+\angle C = 180°$。

$\angle B = 180°-30°-90° = 60°$。

答：$\angle B = 60°$。

**练习4：** 如图，四边形$ABCD$内接于$\odot O$，$\angle B = 80°$。求$\angle D$的度数。

解：

四边形$ABCD$内接于$\odot O$。

根据推论3：圆内接四边形的对角互补。

$\angle B+\angle D = 180°$。

$\angle D = 180°-\angle B = 180°-80° = 100°$。

答：$\angle D = 100°$。

**练习5：** 如图，在$\odot O$中，$\angle ACB = 60°$，$\angle ADB = 60°$。证明：$\stackrel{\frown}{AB} = \stackrel{\frown}{AB}$。

解：

$\angle ACB = \angle ADB = 60°$。

根据推论1：同弧所对的圆周角相等。

点$C$、$D$都在$\stackrel{\frown}{AB}$所对的圆周角的位置。

$\angle ACB$和$\angle ADB$都对$\stackrel{\frown}{AB}$。

所以$\stackrel{\frown}{AB} = \stackrel{\frown}{AB}$。

答：$\stackrel{\frown}{AB} = \stackrel{\frown}{AB}$。
