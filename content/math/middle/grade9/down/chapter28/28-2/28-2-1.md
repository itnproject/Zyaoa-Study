# 28.2.1 解直角三角形

## 一、解直角三角形的定义

**由已知元素求出未知元素**

在直角三角形中。

已知一些元素（边或角）。

求出其他未知元素。

这个过程叫做解直角三角形。

## 二、直角三角形中的五个元素

**三条边**

两条直角边a、b。

一条斜边c。

**两个锐角**

∠A和∠B。

**直角**

∠C = 90°（已知）。

## 三、三边关系：勾股定理

**a² + b² = c²**

直角三角形中。

两条直角边的平方和等于斜边的平方。

**例子**

a = 3，b = 4。

c² = 9 + 16 = 25。

c = 5。

## 四、两锐角关系

**∠A + ∠B = 90°**

直角三角形中。

两个锐角互余。

已知一个锐角，可以求另一个锐角。

**例子**

∠A = 30°。

∠B = 90° - 30° = 60°。

## 五、边角关系：三角函数

**正弦**

sinA = $\frac{a}{c}$。

**余弦**

cosA = $\frac{b}{c}$。

**正切**

tanA = $\frac{a}{b}$。

## 六、已知两边解直角三角形

**方法**

第一步：用勾股定理求第三边。

第二步：用三角函数求锐角。

第三步：用互余关系求另一个锐角。

**例子**

已知a = 3，b = 4。

c = $\sqrt{3^2+4^2} = 5$。

tanA = $\frac{3}{4}$，∠A ≈ 36.9°。

∠B = 90° - 36.9° = 53.1°。

## 七、已知一边一角解直角三角形

**方法**

第一步：用互余关系求另一个锐角。

第二步：用三角函数求其他边。

**例子**

已知c = 10，∠A = 30°。

∠B = 90° - 30° = 60°。

a = c · sinA = 10 × $\frac{1}{2}$ = 5。

b = c · cosA = 10 × $\frac{\sqrt{3}}{2}$ = $5\sqrt{3}$。

## 八、例题讲解

**例题1：** 在Rt△ABC中，∠C = 90°，a = 6，b = 8。解这个直角三角形。

解：

由勾股定理：$c = \sqrt{a^2+b^2} = \sqrt{36+64} = \sqrt{100} = 10$。

tanA = $\frac{a}{b} = \frac{6}{8} = \frac{3}{4}$。

∠A ≈ 36.9°。

∠B = 90° - 36.9° = 53.1°。

答：c = 10，∠A ≈ 36.9°，∠B ≈ 53.1°。

**例题2：** 在Rt△ABC中，∠C = 90°，c = 13，a = 5。解这个直角三角形。

解：

由勾股定理：$b = \sqrt{c^2-a^2} = \sqrt{169-25} = \sqrt{144} = 12$。

sinA = $\frac{a}{c} = \frac{5}{13}$。

∠A ≈ 22.6°。

∠B = 90° - 22.6° = 67.4°。

答：b = 12，∠A ≈ 22.6°，∠B ≈ 67.4°。

**例题3：** 在Rt△ABC中，∠C = 90°，∠A = 30°，c = 10。解这个直角三角形。

解：

∠B = 90° - 30° = 60°。

a = c · sinA = 10 × $\frac{1}{2}$ = 5。

b = c · cosA = 10 × $\frac{\sqrt{3}}{2}$ = $5\sqrt{3}$。

答：b = $5\sqrt{3}$，∠B = 60°。

**例题4：** 在Rt△ABC中，∠C = 90°，∠A = 45°，a = 7。解这个直角三角形。

解：

∠B = 90° - 45° = 45°。

因为∠A = ∠B = 45°。

所以b = a = 7。

c = $\sqrt{a^2+b^2} = \sqrt{49+49} = \sqrt{98} = 7\sqrt{2}$。

答：b = 7，c = $7\sqrt{2}$，∠B = 45°。

**例题5：** 在Rt△ABC中，∠C = 90°，a = 5，∠B = 60°。解这个直角三角形。

解：

∠A = 90° - 60° = 30°。

tanB = $\frac{b}{a}$。

tan60° = $\frac{b}{5}$。

$\sqrt{3} = \frac{b}{5}$。

b = $5\sqrt{3}$。

c = $\sqrt{a^2+b^2} = \sqrt{25+75} = \sqrt{100} = 10$。

答：∠A = 30°，b = $5\sqrt{3}$，c = 10。

## 九、常见错误

**错误1：勾股定理用错**

错误做法：a² + b² = c。

正确做法：a² + b² = c²。

**错误2：三角函数用错**

错误做法：sinA = $\frac{b}{c}$。

正确做法：sinA = $\frac{a}{c}$。

**错误3：角度计算错误**

错误做法：∠A + ∠B = 180°。

正确做法：∠A + ∠B = 90°。

**错误4：已知条件不够**

错误做法：只知道一条边就解三角形。

正确做法：至少需要两个元素（至少一条边）。

**错误5：计算器使用错误**

错误做法：角度模式和弧度模式搞混。

正确做法：确保使用角度模式。

## 十、练习题

**练习1：** 在Rt△ABC中，∠C = 90°，a = 9，b = 12。解这个直角三角形。

解：

由勾股定理：$c = \sqrt{a^2+b^2} = \sqrt{81+144} = \sqrt{225} = 15$。

tanA = $\frac{a}{b} = \frac{9}{12} = \frac{3}{4}$。

∠A ≈ 36.9°。

∠B = 90° - 36.9° = 53.1°。

答：c = 15，∠A ≈ 36.9°，∠B ≈ 53.1°。

**练习2：** 在Rt△ABC中，∠C = 90°，c = 15，b = 9。解这个直角三角形。

解：

由勾股定理：$a = \sqrt{c^2-b^2} = \sqrt{225-81} = \sqrt{144} = 12$。

cosA = $\frac{b}{c} = \frac{9}{15} = \frac{3}{5}$。

∠A ≈ 53.1°。

∠B = 90° - 53.1° = 36.9°。

答：a = 12，∠A ≈ 53.1°，∠B ≈ 36.9°。

**练习3：** 在Rt△ABC中，∠C = 90°，∠A = 60°，c = 8。解这个直角三角形。

解：

∠B = 90° - 60° = 30°。

a = c · sinA = 8 × $\frac{\sqrt{3}}{2}$ = $4\sqrt{3}$。

b = c · cosA = 8 × $\frac{1}{2}$ = 4。

答：b = 4，a = $4\sqrt{3}$，∠B = 30°。

**练习4：** 在Rt△ABC中，∠C = 90°，∠A = 30°，b = 6。解这个直角三角形。

解：

∠B = 90° - 30° = 60°。

tanA = $\frac{a}{b}$。

tan30° = $\frac{a}{6}$。

$\frac{\sqrt{3}}{3} = \frac{a}{6}$。

a = $2\sqrt{3}$。

c = $\sqrt{a^2+b^2} = \sqrt{12+36} = \sqrt{48} = 4\sqrt{3}$。

答：∠B = 60°，a = $2\sqrt{3}$，c = $4\sqrt{3}$。

**练习5：** 在Rt△ABC中，∠C = 90°，a = 8，∠A = 45°。解这个直角三角形。

解：

∠B = 90° - 45° = 45°。

因为∠A = ∠B = 45°。

所以b = a = 8。

c = $\sqrt{a^2+b^2} = \sqrt{64+64} = \sqrt{128} = 8\sqrt{2}$。

答：b = 8，c = $8\sqrt{2}$，∠B = 45°。
