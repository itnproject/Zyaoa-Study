# 28.2.2 仰角与俯角

## 一、仰角的定义

**视线在水平线上方时，视线与水平线的夹角**

从低处看高处。

视线与水平线的夹角叫做仰角。

**例子**

站在地面看楼顶。

视线与水平线的夹角就是仰角。

## 二、俯角的定义

**视线在水平线下方时，视线与水平线的夹角**

从高处看低处。

视线与水平线的夹角叫做俯角。

**例子**

站在楼顶看地面。

视线与水平线的夹角就是俯角。

## 三、利用仰角测高度

**方法**

测量观测点到物体底部的水平距离。

测量仰角。

利用正切函数求高度。

**公式**

高度 = 水平距离 × tan(仰角)。

**例子**

观测点距离旗杆底部20m。

仰角为30°。

旗杆高度 = 20 × tan30° = 20 × $\frac{\sqrt{3}}{3}$ ≈ 11.5m。

## 四、利用俯角测距离

**方法**

测量观测点的高度。

测量俯角。

利用正切函数求水平距离。

**公式**

水平距离 = 高度 ÷ tan(俯角)。

**例子**

从50m高的楼顶看地面。

俯角为45°。

水平距离 = 50 ÷ tan45° = 50 ÷ 1 = 50m。

## 五、例题讲解

**例题1：** 小明站在距离旗杆底部15m的地方，测得旗杆顶端的仰角为45°。求旗杆的高度（小明眼睛离地面1.5m）。

解：

设旗杆顶端到小明眼睛水平线的高度为h。

tan45° = $\frac{h}{15}$。

1 = $\frac{h}{15}$。

h = 15m。

旗杆高度 = 15 + 1.5 = 16.5m。

答：旗杆的高度为16.5m。

**例题2：** 从50m高的塔顶看地面上的一个点，俯角为30°。求塔底到这个点的水平距离。

解：

设水平距离为d。

tan30° = $\frac{50}{d}$。

$\frac{\sqrt{3}}{3} = \frac{50}{d}$。

$d = \frac{150}{\sqrt{3}} = 50\sqrt{3}$m。

答：水平距离为$50\sqrt{3}$m。

**例题3：** 一架飞机在2000m的高空飞行，测得地面目标的俯角为60°。求飞机到地面目标的直线距离。

解：

设水平距离为d。

tan60° = $\frac{2000}{d}$。

$\sqrt{3} = \frac{2000}{d}$。

$d = \frac{2000}{\sqrt{3}} = \frac{2000\sqrt{3}}{3}$m。

直线距离 = $\sqrt{d^2+2000^2} = \sqrt{\frac{4000000}{3}+4000000} = \sqrt{\frac{16000000}{3}} = \frac{4000}{\sqrt{3}} = \frac{4000\sqrt{3}}{3}$m。

答：直线距离为$\frac{4000\sqrt{3}}{3}$m。

**例题4：** 从地面上的A点看楼顶的仰角为30°，向前走20m到B点，看楼顶的仰角为45°。求楼的高度。

解：

设楼高为h，B点到楼底的距离为x。

在B点：tan45° = $\frac{h}{x}$，h = x。

在A点：tan30° = $\frac{h}{x+20}$。

$\frac{\sqrt{3}}{3} = \frac{h}{h+20}$。

$\sqrt{3}(h+20) = 3h$。

$\sqrt{3}h+20\sqrt{3} = 3h$。

$h(3-\sqrt{3}) = 20\sqrt{3}$。

$h = \frac{20\sqrt{3}}{3-\sqrt{3}} = \frac{20\sqrt{3}(3+\sqrt{3})}{9-3} = \frac{20\sqrt{3}(3+\sqrt{3})}{6} = \frac{10\sqrt{3}(3+\sqrt{3})}{3} = 10(\sqrt{3}+1)$m。

答：楼的高度为$10(\sqrt{3}+1)$m。

**例题5：** 热气球在100m的高空，测得地面A点的俯角为30°，测得地面B点的俯角为60°。求A、B两点间的距离（A、B在热气球正下方的同侧）。

解：

设热气球正下方为点C。

tan30° = $\frac{100}{AC}$。

$AC = \frac{100}{\sqrt{3}/3} = 100\sqrt{3}$m。

tan60° = $\frac{100}{BC}$。

$BC = \frac{100}{\sqrt{3}} = \frac{100\sqrt{3}}{3}$m。

$AB = AC-BC = 100\sqrt{3}-\frac{100\sqrt{3}}{3} = \frac{200\sqrt{3}}{3}$m。

答：A、B两点间的距离为$\frac{200\sqrt{3}}{3}$m。

## 六、常见错误

**错误1：仰角和俯角搞混**

错误理解：仰角是从高处看低处。

正确理解：仰角是从低处看高处。

**错误2：忽略观测者身高**

错误做法：直接用tan求高度。

正确做法：要加上观测者眼睛离地面的高度。

**错误3：水平距离和直线距离搞混**

错误做法：把水平距离当成直线距离。

正确做法：水平距离是直角边，直线距离是斜边。

**错误4：俯角与三角形内角搞混**

错误做法：俯角直接作为三角形内角。

正确做法：俯角等于三角形中对应的内角（内错角相等）。

**错误5：两次测量问题列式错误**

错误做法：两个方程列错。

正确做法：分别列两个直角三角形的方程。

## 七、练习题

**练习1：** 小明站在距离旗杆底部10m的地方，测得旗杆顶端的仰角为60°。求旗杆的高度（小明眼睛离地面1.6m）。

解：

设旗杆顶端到小明眼睛水平线的高度为h。

tan60° = $\frac{h}{10}$。

$\sqrt{3} = \frac{h}{10}$。

h = $10\sqrt{3}$m。

旗杆高度 = $10\sqrt{3}+1.6$m。

答：旗杆的高度为$(10\sqrt{3}+1.6)$m。

**练习2：** 从80m高的塔顶看地面上的一个点，俯角为45°。求塔底到这个点的水平距离。

解：

设水平距离为d。

tan45° = $\frac{80}{d}$。

1 = $\frac{80}{d}$。

d = 80m。

答：水平距离为80m。

**练习3：** 从地面上的A点看楼顶的仰角为30°，向前走30m到B点，看楼顶的仰角为60°。求楼的高度。

解：

设楼高为h，B点到楼底的距离为x。

在B点：tan60° = $\frac{h}{x}$，$h = x\sqrt{3}$。

在A点：tan30° = $\frac{h}{x+30}$。

$\frac{\sqrt{3}}{3} = \frac{x\sqrt{3}}{x+30}$。

$\frac{1}{3} = \frac{x}{x+30}$。

$x+30 = 3x$。

$2x = 30$。

$x = 15$。

$h = 15\sqrt{3}$m。

答：楼的高度为$15\sqrt{3}$m。

**练习4：** 一架飞机在3000m的高空飞行，测得地面目标的俯角为45°。求飞机到地面目标的直线距离。

解：

设水平距离为d。

tan45° = $\frac{3000}{d}$。

1 = $\frac{3000}{d}$。

d = 3000m。

直线距离 = $\sqrt{3000^2+3000^2} = 3000\sqrt{2}$m。

答：直线距离为$3000\sqrt{2}$m。

**练习5：** 热气球在200m的高空，测得地面A点的俯角为45°，测得地面B点的俯角为30°。求A、B两点间的距离（A、B在热气球正下方的同侧）。

解：

设热气球正下方为点C。

tan45° = $\frac{200}{AC}$。

$AC = 200$m。

tan30° = $\frac{200}{BC}$。

$BC = \frac{200}{\sqrt{3}/3} = 200\sqrt{3}$m。

$AB = BC-AC = 200\sqrt{3}-200 = 200(\sqrt{3}-1)$m。

答：A、B两点间的距离为$200(\sqrt{3}-1)$m。
