# 28.2.4 解直角三角形的综合应用

## 一、不可到达物体的高度测量

**方法**

在两个不同位置测量仰角。

测量两个位置之间的距离。

利用两个直角三角形列方程。

解方程求高度。

**例子**

在A点测得楼顶仰角为30°。

向前走20m到B点，测得楼顶仰角为45°。

设楼高为h，B点到楼底的距离为x。

在B点：tan45° = $\frac{h}{x}$，h = x。

在A点：tan30° = $\frac{h}{x+20}$。

解得h = $10(\sqrt{3}+1)$m。

## 二、含有两个直角三角形的问题

**方法**

找出两个直角三角形。

找到公共边或公共角。

利用三角函数列方程。

解方程求未知量。

**例子**

在△ABC中，∠C = 90°，D在BC上。

∠BAD = 30°，∠CAD = 45°，BC = 10。

设CD = x，则BD = 10-x。

在Rt△ACD中：AC = CD = x。

在Rt△ABC中：tan∠BAC = $\frac{BC}{AC}$ = $\frac{10}{x}$。

∠BAC = 30°+45° = 75°。

需要利用特殊角求解。

## 三、解直角三角形与相似三角形的综合

**方法**

先利用相似三角形求边长关系。

再利用三角函数求角度或边长。

**例子**

在Rt△ABC中，∠C = 90°，CD⊥AB于D。

已知AC = 6，BC = 8。

AB = 10。

△ACD ∽ △ABC。

$\frac{AD}{AC} = \frac{AC}{AB}$。

$AD = \frac{36}{10} = 3.6$。

## 四、解直角三角形与圆的综合

**方法**

利用圆的性质找直角。

直径所对的圆周角是直角。

切线垂直于过切点的半径。

利用三角函数求边长或角度。

**例子**

在⊙O中，AB是直径，C是圆上一点。

∠ACB = 90°。

已知AB = 10，∠A = 30°。

BC = AB · sin30° = 5。

AC = AB · cos30° = $5\sqrt{3}$。

## 五、例题讲解

**例题1：** 如图，为了测量不可到达的塔高，在地面上的A点测得塔顶的仰角为30°，向前走50m到B点，测得塔顶的仰角为60°。求塔高。

解：

设塔高为h，B点到塔底的距离为x。

在B点：tan60° = $\frac{h}{x}$，$h = x\sqrt{3}$。

在A点：tan30° = $\frac{h}{x+50}$。

$\frac{\sqrt{3}}{3} = \frac{x\sqrt{3}}{x+50}$。

$\frac{1}{3} = \frac{x}{x+50}$。

$x+50 = 3x$。

$2x = 50$。

$x = 25$。

$h = 25\sqrt{3}$m。

答：塔高为$25\sqrt{3}$m。

**例题2：** 如图，在Rt△ABC中，∠C = 90°，D是BC上一点，∠ADC = 45°，∠B = 30°，BD = 6。求AC的长度。

解：

在Rt△ACD中，∠ADC = 45°。

所以AC = CD。

设AC = CD = x。

在Rt△ABC中，∠B = 30°。

tan30° = $\frac{AC}{BC} = \frac{x}{x+6}$。

$\frac{\sqrt{3}}{3} = \frac{x}{x+6}$。

$\sqrt{3}(x+6) = 3x$。

$\sqrt{3}x+6\sqrt{3} = 3x$。

$x(3-\sqrt{3}) = 6\sqrt{3}$。

$x = \frac{6\sqrt{3}}{3-\sqrt{3}} = \frac{6\sqrt{3}(3+\sqrt{3})}{9-3} = \frac{6\sqrt{3}(3+\sqrt{3})}{6} = \sqrt{3}(3+\sqrt{3}) = 3\sqrt{3}+3$。

答：AC的长度为$(3\sqrt{3}+3)$。

**例题3：** 如图，在Rt△ABC中，∠C = 90°，CD⊥AB于D。已知AC = 4，BC = 3。求sin∠ACD。

解：

AB = $\sqrt{AC^2+BC^2} = \sqrt{16+9} = 5$。

△ACD ∽ △ABC。

∠ACD = ∠B。

sin∠ACD = sinB = $\frac{AC}{AB} = \frac{4}{5}$。

答：sin∠ACD = $\frac{4}{5}$。

**例题4：** 如图，在⊙O中，AB是直径，C是圆上一点，CD⊥AB于D。已知AB = 8，∠CAB = 30°。求CD的长度。

解：

因为AB是直径。

所以∠ACB = 90°。

在Rt△ABC中，∠CAB = 30°。

BC = AB · sin30° = 8 × $\frac{1}{2}$ = 4。

AC = AB · cos30° = 8 × $\frac{\sqrt{3}}{2}$ = $4\sqrt{3}$。

在Rt△ACD中，∠CAD = 30°。

CD = AC · sin30° = $4\sqrt{3} \times \frac{1}{2} = 2\sqrt{3}$。

答：CD的长度为$2\sqrt{3}$。

**例题5：** 如图，在山脚A点测得山顶P的仰角为30°，沿坡角为15°的斜坡向上走100m到达B点，在B点测得山顶P的仰角为60°。求山高。

解：

设山高为h，山脚到山顶正下方的水平距离为d。

在A点：tan30° = $\frac{h}{d}$，$d = h\sqrt{3}$。

B点的水平位置：从A点沿坡角15°走100m。

水平前进 = 100 × cos15°。

垂直上升 = 100 × sin15°。

在B点：tan60° = $\frac{h-100\sin 15°}{d-100\cos 15°}$。

$\sqrt{3} = \frac{h-100\sin 15°}{h\sqrt{3}-100\cos 15°}$。

这个计算较复杂，用近似值。

sin15° ≈ 0.259，cos15° ≈ 0.966。

$\sqrt{3} = \frac{h-25.9}{h\sqrt{3}-96.6}$。

$3h-96.6\sqrt{3} = h-25.9$。

$2h = 96.6\sqrt{3}-25.9$。

$h ≈ \frac{167.3-25.9}{2} ≈ 70.7$m。

答：山高约为70.7m。

## 六、常见错误

**错误1：两个直角三角形关系找错**

错误做法：找不到两个直角三角形的联系。

正确做法：找到公共边或公共角。

**错误2：不可到达物体高度测量列式错误**

错误做法：只用一个方程。

正确做法：需要列两个方程联立求解。

**错误3：相似三角形对应关系找错**

错误做法：对应边找错。

正确做法：根据相等角找对应边。

**错误4：圆中直角找错**

错误做法：不知道直径所对的圆周角是直角。

正确做法：直径所对的圆周角是90°。

**错误5：复杂问题不会分解**

错误做法：试图一步求解。

正确做法：分解为多个小问题逐步求解。

## 七、练习题

**练习1：** 如图，为了测量不可到达的楼高，在地面上的A点测得楼顶的仰角为45°，向前走30m到B点，测得楼顶的仰角为60°。求楼高。

解：

设楼高为h，B点到楼底的距离为x。

在B点：tan60° = $\frac{h}{x}$，$h = x\sqrt{3}$。

在A点：tan45° = $\frac{h}{x+30}$。

1 = $\frac{x\sqrt{3}}{x+30}$。

$x+30 = x\sqrt{3}$。

$x(\sqrt{3}-1) = 30$。

$x = \frac{30}{\sqrt{3}-1} = \frac{30(\sqrt{3}+1)}{3-1} = 15(\sqrt{3}+1)$。

$h = 15(\sqrt{3}+1)\sqrt{3} = 15(3+\sqrt{3}) = 45+15\sqrt{3}$m。

答：楼高为$(45+15\sqrt{3})$m。

**练习2：** 如图，在Rt△ABC中，∠C = 90°，D是BC上一点，∠ADC = 60°，∠B = 30°，BD = 4。求AC的长度。

解：

在Rt△ACD中，∠ADC = 60°。

tan60° = $\frac{AC}{CD}$。

$AC = CD\sqrt{3}$。

设CD = x，则AC = $x\sqrt{3}$。

在Rt△ABC中，∠B = 30°。

tan30° = $\frac{AC}{BC} = \frac{x\sqrt{3}}{x+4}$。

$\frac{\sqrt{3}}{3} = \frac{x\sqrt{3}}{x+4}$。

$\frac{1}{3} = \frac{x}{x+4}$。

$x+4 = 3x$。

$2x = 4$。

$x = 2$。

$AC = 2\sqrt{3}$。

答：AC的长度为$2\sqrt{3}$。

**练习3：** 如图，在Rt△ABC中，∠C = 90°，CD⊥AB于D。已知AC = 5，BC = 12。求cos∠BCD。

解：

AB = $\sqrt{AC^2+BC^2} = \sqrt{25+144} = \sqrt{169} = 13$。

△BCD ∽ △BAC。

∠BCD = ∠A。

cos∠BCD = cosA = $\frac{AC}{AB} = \frac{5}{13}$。

答：cos∠BCD = $\frac{5}{13}$。

**练习4：** 如图，在⊙O中，AB是直径，C是圆上一点，CD⊥AB于D。已知AB = 10，∠CBA = 30°。求CD的长度。

解：

因为AB是直径。

所以∠ACB = 90°。

在Rt△ABC中，∠CBA = 30°。

AC = AB · sin30° = 10 × $\frac{1}{2}$ = 5。

BC = AB · cos30° = 10 × $\frac{\sqrt{3}}{2}$ = $5\sqrt{3}$。

在Rt△BCD中，∠CBD = 30°。

CD = BC · sin30° = $5\sqrt{3} \times \frac{1}{2} = \frac{5\sqrt{3}}{2}$。

答：CD的长度为$\frac{5\sqrt{3}}{2}$。

**练习5：** 如图，在Rt△ABC中，∠C = 90°，D是AC上一点，∠DBC = 45°，∠A = 30°，AD = 4。求BC的长度。

解：

在Rt△BCD中，∠DBC = 45°。

所以BC = CD。

设BC = CD = x。

在Rt△ABC中，∠A = 30°。

tan30° = $\frac{BC}{AC} = \frac{x}{x+4}$。

$\frac{\sqrt{3}}{3} = \frac{x}{x+4}$。

$\sqrt{3}(x+4) = 3x$。

$\sqrt{3}x+4\sqrt{3} = 3x$。

$x(3-\sqrt{3}) = 4\sqrt{3}$。

$x = \frac{4\sqrt{3}}{3-\sqrt{3}} = \frac{4\sqrt{3}(3+\sqrt{3})}{9-3} = \frac{4\sqrt{3}(3+\sqrt{3})}{6} = \frac{2\sqrt{3}(3+\sqrt{3})}{3} = \frac{6\sqrt{3}+6}{3} = 2\sqrt{3}+2$。

答：BC的长度为$(2\sqrt{3}+2)$。
