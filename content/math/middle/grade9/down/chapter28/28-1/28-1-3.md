# 28.1.3 特殊角的三角函数值

## 一、30°、45°、60°的三角函数值表

| 角度 | sin | cos | tan |
|------|-----|-----|-----|
| 30° | $\frac{1}{2}$ | $\frac{\sqrt{3}}{2}$ | $\frac{\sqrt{3}}{3}$ |
| 45° | $\frac{\sqrt{2}}{2}$ | $\frac{\sqrt{2}}{2}$ | 1 |
| 60° | $\frac{\sqrt{3}}{2}$ | $\frac{1}{2}$ | $\sqrt{3}$ |

**观察规律**

正弦值：从小到大。

余弦值：从大到小。

正切值：从小到大。

## 二、利用直角三角形推导特殊角的三角函数值

**30°角的三角函数值**

在含30°角的直角三角形中。

设30°角所对的边为1。

则斜边为2，60°角所对的边为$\sqrt{3}$。

sin30° = $\frac{1}{2}$，cos30° = $\frac{\sqrt{3}}{2}$，tan30° = $\frac{1}{\sqrt{3}} = \frac{\sqrt{3}}{3}$。

**45°角的三角函数值**

在等腰直角三角形中。

设直角边为1。

则斜边为$\sqrt{2}$。

sin45° = $\frac{1}{\sqrt{2}} = \frac{\sqrt{2}}{2}$，cos45° = $\frac{\sqrt{2}}{2}$，tan45° = 1。

**60°角的三角函数值**

在含30°角的直角三角形中。

60°角所对的边为$\sqrt{3}$，斜边为2。

sin60° = $\frac{\sqrt{3}}{2}$，cos60° = $\frac{1}{2}$，tan60° = $\sqrt{3}$。

## 三、记忆口诀

**一二三、三二一、三九二十七**

**一二三**

正弦值的分子：1、2、3。

分母都是2。

sin30° = $\frac{\sqrt{1}}{2} = \frac{1}{2}$。

sin45° = $\frac{\sqrt{2}}{2}$。

sin60° = $\frac{\sqrt{3}}{2}$。

**三二一**

余弦值的分子：3、2、1。

分母都是2。

cos30° = $\frac{\sqrt{3}}{2}$。

cos45° = $\frac{\sqrt{2}}{2}$。

cos60° = $\frac{\sqrt{1}}{2} = \frac{1}{2}$。

**三九二十七**

tan30° = $\frac{\sqrt{3}}{3}$。

tan45° = 1 = $\frac{\sqrt{9}}{3}$。

tan60° = $\sqrt{3} = \frac{\sqrt{27}}{3}$。

## 四、已知三角函数值求锐角度数

**方法**

根据三角函数值对照特殊角的三角函数值表。

找到对应的角度。

**例子**

已知sinA = $\frac{1}{2}$。

对照表格，sin30° = $\frac{1}{2}$。

所以∠A = 30°。

**例子**

已知tanA = $\sqrt{3}$。

对照表格，tan60° = $\sqrt{3}$。

所以∠A = 60°。

## 五、含特殊角的三角函数式计算

**方法**

先把特殊角的三角函数值代入。

再进行计算。

**例子**

计算：2sin30° + 3cos60°。

2sin30° + 3cos60° = $2 \times \frac{1}{2} + 3 \times \frac{1}{2} = 1 + \frac{3}{2} = \frac{5}{2}$。

## 六、例题讲解

**例题1：** 计算：sin30° + cos60°。

解：

sin30° = $\frac{1}{2}$。

cos60° = $\frac{1}{2}$。

sin30° + cos60° = $\frac{1}{2} + \frac{1}{2} = 1$。

答：1。

**例题2：** 计算：sin²45° + cos²45°。

解：

sin45° = $\frac{\sqrt{2}}{2}$。

cos45° = $\frac{\sqrt{2}}{2}$。

sin²45° + cos²45° = $\left(\frac{\sqrt{2}}{2}\right)^2 + \left(\frac{\sqrt{2}}{2}\right)^2 = \frac{2}{4} + \frac{2}{4} = 1$。

答：1。

**例题3：** 计算：tan60° - 2sin30° + cos45°。

解：

tan60° = $\sqrt{3}$。

sin30° = $\frac{1}{2}$。

cos45° = $\frac{\sqrt{2}}{2}$。

tan60° - 2sin30° + cos45° = $\sqrt{3} - 2 \times \frac{1}{2} + \frac{\sqrt{2}}{2} = \sqrt{3} - 1 + \frac{\sqrt{2}}{2} = \frac{2\sqrt{3}-2+\sqrt{2}}{2}$。

答：$\frac{2\sqrt{3}-2+\sqrt{2}}{2}$。

**例题4：** 已知sinA = $\frac{\sqrt{3}}{2}$，且∠A为锐角。求∠A的度数。

解：

对照特殊角的三角函数值表。

sin60° = $\frac{\sqrt{3}}{2}$。

所以∠A = 60°。

答：∠A = 60°。

**例题5：** 计算：$\frac{\sin 30°}{\cos 60°} + \frac{\tan 45°}{\sin 45°}$。

解：

sin30° = $\frac{1}{2}$。

cos60° = $\frac{1}{2}$。

tan45° = 1。

sin45° = $\frac{\sqrt{2}}{2}$。

$\frac{\sin 30°}{\cos 60°} + \frac{\tan 45°}{\sin 45°} = \frac{1/2}{1/2} + \frac{1}{\sqrt{2}/2} = 1 + \frac{2}{\sqrt{2}} = 1 + \sqrt{2}$。

答：$1+\sqrt{2}$。

## 七、常见错误

**错误1：特殊角的三角函数值记错**

错误记忆：sin30° = $\frac{\sqrt{3}}{2}$。

正确记忆：sin30° = $\frac{1}{2}$。

**错误2：平方计算错误**

错误做法：$\left(\frac{\sqrt{2}}{2}\right)^2 = \frac{2}{2} = 1$。

正确做法：$\left(\frac{\sqrt{2}}{2}\right)^2 = \frac{2}{4} = \frac{1}{2}$。

**错误3：tan45°记错**

错误记忆：tan45° = $\frac{\sqrt{2}}{2}$。

正确记忆：tan45° = 1。

**错误4：cos30°和sin60°搞混**

错误理解：cos30°和sin60°不同。

正确理解：cos30° = sin60° = $\frac{\sqrt{3}}{2}$。

**错误5：计算顺序错误**

错误做法：先加减后乘除。

正确做法：先乘除后加减。

## 八、练习题

**练习1：** 计算：cos30° + sin60°。

解：

cos30° = $\frac{\sqrt{3}}{2}$。

sin60° = $\frac{\sqrt{3}}{2}$。

cos30° + sin60° = $\frac{\sqrt{3}}{2} + \frac{\sqrt{3}}{2} = \sqrt{3}$。

答：$\sqrt{3}$。

**练习2：** 计算：2tan45° - sin30°。

解：

tan45° = 1。

sin30° = $\frac{1}{2}$。

2tan45° - sin30° = $2 \times 1 - \frac{1}{2} = 2 - \frac{1}{2} = \frac{3}{2}$。

答：$\frac{3}{2}$。

**练习3：** 计算：sin²30° + cos²60° + tan45°。

解：

sin30° = $\frac{1}{2}$，sin²30° = $\frac{1}{4}$。

cos60° = $\frac{1}{2}$，cos²60° = $\frac{1}{4}$。

tan45° = 1。

sin²30° + cos²60° + tan45° = $\frac{1}{4} + \frac{1}{4} + 1 = \frac{3}{2}$。

答：$\frac{3}{2}$。

**练习4：** 已知cosA = $\frac{1}{2}$，且∠A为锐角。求∠A的度数。

解：

对照特殊角的三角函数值表。

cos60° = $\frac{1}{2}$。

所以∠A = 60°。

答：∠A = 60°。

**练习5：** 计算：$\frac{\cos 30°}{\sin 60°} + \tan^2 45°$。

解：

cos30° = $\frac{\sqrt{3}}{2}$。

sin60° = $\frac{\sqrt{3}}{2}$。

tan45° = 1，tan²45° = 1。

$\frac{\cos 30°}{\sin 60°} + \tan^2 45° = \frac{\sqrt{3}/2}{\sqrt{3}/2} + 1 = 1 + 1 = 2$。

答：2。
