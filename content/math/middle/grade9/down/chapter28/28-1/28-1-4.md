# 28.1.4 锐角三角函数的增减性与互余关系

## 一、当角度增大时，sin增大、cos减小、tan增大

**正弦的增减性**

当角度从0°增大到90°时。

sinA从0增大到1。

正弦值随角度增大而增大。

**余弦的增减性**

当角度从0°增大到90°时。

cosA从1减小到0。

余弦值随角度增大而减小。

**正切的增减性**

当角度从0°增大到90°时。

tanA从0增大到无穷大。

正切值随角度增大而增大。

**例子**

sin30° = $\frac{1}{2}$，sin45° = $\frac{\sqrt{2}}{2} \approx 0.707$，sin60° = $\frac{\sqrt{3}}{2} \approx 0.866$。

角度增大，正弦值增大。

cos30° = $\frac{\sqrt{3}}{2} \approx 0.866$，cos45° = $\frac{\sqrt{2}}{2} \approx 0.707$，cos60° = $\frac{1}{2}$。

角度增大，余弦值减小。

## 二、互余两角的三角函数关系

**sinA = cos(90°-A)**

一个角的正弦等于它余角的余弦。

**cosA = sin(90°-A)**

一个角的余弦等于它余角的正弦。

**tanA · tan(90°-A) = 1**

互余两角的正切值互为倒数。

**例子**

sin30° = cos60° = $\frac{1}{2}$。

cos30° = sin60° = $\frac{\sqrt{3}}{2}$。

tan30° · tan60° = $\frac{\sqrt{3}}{3} \times \sqrt{3} = 1$。

## 三、利用互余关系进行转化

**方法**

利用sinA = cos(90°-A)进行转化。

利用cosA = sin(90°-A)进行转化。

利用tanA · tan(90°-A) = 1进行转化。

**例子**

计算：sin²20° + sin²70°。

sin70° = cos20°。

sin²20° + sin²70° = sin²20° + cos²20° = 1。

## 四、例题讲解

**例题1：** 比较大小：sin40°和sin50°。

解：

正弦值随角度增大而增大。

40° < 50°。

所以sin40° < sin50°。

答：sin40° < sin50°。

**例题2：** 比较大小：cos20°和cos70°。

解：

余弦值随角度增大而减小。

20° < 70°。

所以cos20° > cos70°。

答：cos20° > cos70°。

**例题3：** 计算：sin²25° + sin²65°。

解：

sin65° = cos25°。

sin²25° + sin²65° = sin²25° + cos²25° = 1。

答：1。

**例题4：** 已知tanA = 2，求tan(90°-A)的值。

解：

tanA · tan(90°-A) = 1。

2 · tan(90°-A) = 1。

tan(90°-A) = $\frac{1}{2}$。

答：$\frac{1}{2}$。

**例题5：** 计算：$\frac{\sin 35°}{\cos 55°} + \frac{\cos 40°}{\sin 50°}$。

解：

cos55° = sin35°。

sin50° = cos40°。

$\frac{\sin 35°}{\cos 55°} + \frac{\cos 40°}{\sin 50°} = \frac{\sin 35°}{\sin 35°} + \frac{\cos 40°}{\cos 40°} = 1 + 1 = 2$。

答：2。

## 五、常见错误

**错误1：增减性搞反**

错误理解：cosA随角度增大而增大。

正确理解：cosA随角度增大而减小。

**错误2：互余关系记错**

错误记忆：sinA = sin(90°-A)。

正确记忆：sinA = cos(90°-A)。

**错误3：正切互余关系记错**

错误记忆：tanA + tan(90°-A) = 1。

正确记忆：tanA · tan(90°-A) = 1。

**错误4：角度范围忽略**

错误做法：对任意角度使用增减性。

正确做法：增减性只在锐角范围内成立。

**错误5：平方关系与互余关系混淆**

错误做法：sinA + cosA = 1。

正确做法：sin²A + cos²A = 1。

所以sin35° < sin55°。

答：sin35° < sin55°。

15° < 75°。

所以cos15° > cos75°。

答：cos15° > cos75°。

**练习3：** 计算：sin²15° + sin²75°。

解：

sin75° = cos15°。

sin²15° + sin²75° = sin²15° + cos²15° = 1。

答：1。

**练习4：** 已知tanA = 3，求tan(90°-A)的值。

解：

tanA · tan(90°-A) = 1。

3 · tan(90°-A) = 1。

tan(90°-A) = $\frac{1}{3}$。

答：$\frac{1}{3}$。

**练习5：** 计算：$\frac{\sin 20°}{\cos 70°} + \frac{\cos 30°}{\sin 60°}$。

解：

cos70° = sin20°。

sin60° = cos30°。

$\frac{\sin 20°}{\cos 70°} + \frac{\cos 30°}{\sin 60°} = \frac{\sin 20°}{\sin 20°} + \frac{\cos 30°}{\cos 30°} = 1 + 1 = 2$。

答：2。
