# 28.1.2 余弦和正切

## 一、余弦的定义

**cosA = ∠A的邻边 / 斜边**

在直角三角形中。

锐角A的邻边与斜边的比值叫做角A的余弦。

记作cosA。

**数学表达**

在Rt△ABC中，∠C = 90°。

cosA = $\frac{\text{∠A的邻边}}{\text{斜边}} = \frac{b}{c}$。

**例子**

在Rt△ABC中，∠C = 90°，b = 4，c = 5。

cosA = $\frac{4}{5}$。

## 二、正切的定义

**tanA = ∠A的对边 / ∠A的邻边**

在直角三角形中。

锐角A的对边与邻边的比值叫做角A的正切。

记作tanA。

**数学表达**

在Rt△ABC中，∠C = 90°。

tanA = $\frac{\text{∠A的对边}}{\text{∠A的邻边}} = \frac{a}{b}$。

**例子**

在Rt△ABC中，∠C = 90°，a = 3，b = 4。

tanA = $\frac{3}{4}$。

## 三、特殊角的余弦值和正切值

**30°角**

cos30° = $\frac{\sqrt{3}}{2}$。

tan30° = $\frac{\sqrt{3}}{3}$。

**45°角**

cos45° = $\frac{\sqrt{2}}{2}$。

tan45° = 1。

**60°角**

cos60° = $\frac{1}{2}$。

tan60° = $\sqrt{3}$。

## 四、锐角三角函数的取值范围

**正弦的范围**

0 < sinA < 1。

**余弦的范围**

0 < cosA < 1。

**正切的范围**

tanA > 0。

正切可以大于1。

## 五、同一个锐角的正弦、余弦、正切之间的关系

**平方关系**

sin²A + cos²A = 1。

**商数关系**

tanA = $\frac{\sin A}{\cos A}$。

**例子**

已知sinA = $\frac{3}{5}$。

cosA = $\sqrt{1-\sin^2 A} = \sqrt{1-\frac{9}{25}} = \sqrt{\frac{16}{25}} = \frac{4}{5}$。

tanA = $\frac{\sin A}{\cos A} = \frac{3/5}{4/5} = \frac{3}{4}$。

## 六、例题讲解

**例题1：** 在Rt△ABC中，∠C = 90°，AB = 10，AC = 6。求cosA和tanA。

解：

先求BC。

由勾股定理：$BC = \sqrt{AB^2-AC^2} = \sqrt{100-36} = \sqrt{64} = 8$。

cosA = $\frac{AC}{AB} = \frac{6}{10} = \frac{3}{5}$。

tanA = $\frac{BC}{AC} = \frac{8}{6} = \frac{4}{3}$。

答：cosA = $\frac{3}{5}$，tanA = $\frac{4}{3}$。

**例题2：** 在Rt△ABC中，∠C = 90°，BC = 5，AC = 12。求sinA、cosA、tanA。

解：

先求AB。

由勾股定理：$AB = \sqrt{AC^2+BC^2} = \sqrt{144+25} = \sqrt{169} = 13$。

sinA = $\frac{BC}{AB} = \frac{5}{13}$。

cosA = $\frac{AC}{AB} = \frac{12}{13}$。

tanA = $\frac{BC}{AC} = \frac{5}{12}$。

答：sinA = $\frac{5}{13}$，cosA = $\frac{12}{13}$，tanA = $\frac{5}{12}$。

**例题3：** 计算：cos30° + tan45°。

解：

cos30° = $\frac{\sqrt{3}}{2}$。

tan45° = 1。

cos30° + tan45° = $\frac{\sqrt{3}}{2} + 1 = \frac{\sqrt{3}+2}{2}$。

答：$\frac{\sqrt{3}+2}{2}$。

**例题4：** 在Rt△ABC中，∠C = 90°，sinA = $\frac{5}{13}$。求cosA和tanA。

解：

由sin²A + cos²A = 1。

cos²A = 1 - sin²A = $1 - \frac{25}{169} = \frac{144}{169}$。

cosA = $\frac{12}{13}$。

tanA = $\frac{\sin A}{\cos A} = \frac{5/13}{12/13} = \frac{5}{12}$。

答：cosA = $\frac{12}{13}$，tanA = $\frac{5}{12}$。

**例题5：** 在Rt△ABC中，∠C = 90°，tanA = $\frac{3}{4}$，AC = 8。求BC和AB的长度。

解：

tanA = $\frac{BC}{AC} = \frac{3}{4}$。

$\frac{BC}{8} = \frac{3}{4}$。

$BC = 6$。

由勾股定理：$AB = \sqrt{AC^2+BC^2} = \sqrt{64+36} = \sqrt{100} = 10$。

答：BC = 6，AB = 10。

## 七、常见错误

**错误1：余弦和正弦搞混**

错误做法：cosA = $\frac{\text{对边}}{\text{斜边}}$。

正确做法：cosA = $\frac{\text{邻边}}{\text{斜边}}$。

**错误2：正切的分子分母搞反**

错误做法：tanA = $\frac{\text{邻边}}{\text{对边}}$。

正确做法：tanA = $\frac{\text{对边}}{\text{邻边}}$。

**错误3：特殊角的三角函数值记错**

错误记忆：tan30° = $\sqrt{3}$。

正确记忆：tan30° = $\frac{\sqrt{3}}{3}$，tan60° = $\sqrt{3}$。

**错误4：平方关系使用错误**

错误做法：sinA + cosA = 1。

正确做法：sin²A + cos²A = 1。

**错误5：邻边找错**

错误做法：邻边找成对边。

正确做法：邻边是组成角A的直角边。

## 八、练习题

**练习1：** 在Rt△ABC中，∠C = 90°，AB = 15，BC = 9。求cosA和tanA。

解：

先求AC。

由勾股定理：$AC = \sqrt{AB^2-BC^2} = \sqrt{225-81} = \sqrt{144} = 12$。

cosA = $\frac{AC}{AB} = \frac{12}{15} = \frac{4}{5}$。

tanA = $\frac{BC}{AC} = \frac{9}{12} = \frac{3}{4}$。

答：cosA = $\frac{4}{5}$，tanA = $\frac{3}{4}$。

**练习2：** 在Rt△ABC中，∠C = 90°，BC = 7，AC = 24。求sinA、cosA、tanA。

解：

先求AB。

由勾股定理：$AB = \sqrt{AC^2+BC^2} = \sqrt{576+49} = \sqrt{625} = 25$。

sinA = $\frac{BC}{AB} = \frac{7}{25}$。

cosA = $\frac{AC}{AB} = \frac{24}{25}$。

tanA = $\frac{BC}{AC} = \frac{7}{24}$。

答：sinA = $\frac{7}{25}$，cosA = $\frac{24}{25}$，tanA = $\frac{7}{24}$。

**练习3：** 计算：sin60° × cos30° + tan45°。

解：

sin60° = $\frac{\sqrt{3}}{2}$。

cos30° = $\frac{\sqrt{3}}{2}$。

tan45° = 1。

sin60° × cos30° + tan45° = $\frac{\sqrt{3}}{2} \times \frac{\sqrt{3}}{2} + 1 = \frac{3}{4} + 1 = \frac{7}{4}$。

答：$\frac{7}{4}$。

**练习4：** 在Rt△ABC中，∠C = 90°，cosA = $\frac{8}{17}$。求sinA和tanA。

解：

由sin²A + cos²A = 1。

sin²A = 1 - cos²A = $1 - \frac{64}{289} = \frac{225}{289}$。

sinA = $\frac{15}{17}$。

tanA = $\frac{\sin A}{\cos A} = \frac{15/17}{8/17} = \frac{15}{8}$。

答：sinA = $\frac{15}{17}$，tanA = $\frac{15}{8}$。

**练习5：** 在Rt△ABC中，∠C = 90°，tanA = $\frac{5}{12}$，BC = 10。求AC和AB的长度。

解：

tanA = $\frac{BC}{AC} = \frac{5}{12}$。

$\frac{10}{AC} = \frac{5}{12}$。

$AC = 24$。

由勾股定理：$AB = \sqrt{AC^2+BC^2} = \sqrt{576+100} = \sqrt{676} = 26$。

答：AC = 24，AB = 26。
