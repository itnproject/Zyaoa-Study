# 28.1.1 正弦

## 一、从生活实例引入

**斜坡的坡度**

上山时，斜坡越陡，走起来越费力。

斜坡的陡峭程度与高度和长度的比值有关。

这个比值就是正弦的概念。

**梯子靠墙的角度**

梯子靠墙时，角度不同，顶端高度不同。

角度越大，顶端越高。

角度与高度的关系就是正弦。

**测量旗杆高度**

站在远处看旗杆顶端。

视线与地面的夹角和旗杆高度有关。

利用这个关系可以求出旗杆高度。

## 二、正弦的定义

**在Rt△ABC中，sinA = ∠A的对边 / 斜边**

在直角三角形中。

锐角A的对边与斜边的比值叫做角A的正弦。

记作sinA。

**数学表达**

在Rt△ABC中，∠C = 90°。

sinA = $\frac{\text{∠A的对边}}{\text{斜边}} = \frac{a}{c}$。

**例子**

在Rt△ABC中，∠C = 90°，a = 3，c = 5。

sinA = $\frac{3}{5}$。

## 三、sinA是一个比值

**只与角度大小有关**

sinA的大小只取决于角A的大小。

与三角形的大小无关。

**例子**

两个直角三角形，角A都是30°。

一个三角形的对边是1，斜边是2。

另一个三角形的对边是2，斜边是4。

sinA都是$\frac{1}{2}$。

**与三角形大小无关**

三角形放大或缩小。

只要角度不变，sinA就不变。

## 四、特殊角的正弦值

**sin30° = $\frac{1}{2}$**

在含30°角的直角三角形中。

30°角所对的直角边是斜边的一半。

所以sin30° = $\frac{1}{2}$。

**sin45° = $\frac{\sqrt{2}}{2}$**

在等腰直角三角形中。

设直角边为1，斜边为$\sqrt{2}$。

所以sin45° = $\frac{1}{\sqrt{2}} = \frac{\sqrt{2}}{2}$。

**sin60° = $\frac{\sqrt{3}}{2}$**

在含30°角的直角三角形中。

设30°角所对的边为1，斜边为2。

60°角所对的边为$\sqrt{3}$。

所以sin60° = $\frac{\sqrt{3}}{2}$。

## 五、正弦值的范围

**0 < sinA < 1**

因为锐角A的对边一定小于斜边。

所以sinA一定小于1。

又因为对边一定大于0。

所以sinA一定大于0。

**角度越大，正弦值越大**

当角A从0°增大到90°时。

sinA从0增大到1。

## 六、例题讲解

**例题1：** 在Rt△ABC中，∠C = 90°，AB = 10，BC = 6。求sinA。

解：

∠A的对边是BC = 6。

斜边是AB = 10。

sinA = $\frac{BC}{AB} = \frac{6}{10} = \frac{3}{5}$。

答：sinA = $\frac{3}{5}$。

**例题2：** 在Rt△ABC中，∠C = 90°，AB = 13，AC = 5。求sinA。

解：

先求BC。

由勾股定理：$BC = \sqrt{AB^2-AC^2} = \sqrt{169-25} = \sqrt{144} = 12$。

∠A的对边是BC = 12。

斜边是AB = 13。

sinA = $\frac{BC}{AB} = \frac{12}{13}$。

答：sinA = $\frac{12}{13}$。

**例题3：** 在Rt△ABC中，∠C = 90°，sinA = $\frac{4}{5}$，AB = 15。求BC的长度。

解：

sinA = $\frac{BC}{AB} = \frac{4}{5}$。

$\frac{BC}{15} = \frac{4}{5}$。

$BC = 15 \times \frac{4}{5} = 12$。

答：BC的长度为12。

**例题4：** 计算：sin30° + sin60°。

解：

sin30° = $\frac{1}{2}$。

sin60° = $\frac{\sqrt{3}}{2}$。

sin30° + sin60° = $\frac{1}{2} + \frac{\sqrt{3}}{2} = \frac{1+\sqrt{3}}{2}$。

答：$\frac{1+\sqrt{3}}{2}$。

**例题5：** 在Rt△ABC中，∠C = 90°，BC = 8，sinA = $\frac{2}{3}$。求AB的长度。

解：

sinA = $\frac{BC}{AB} = \frac{2}{3}$。

$\frac{8}{AB} = \frac{2}{3}$。

$2AB = 24$。

$AB = 12$。

答：AB的长度为12。

## 七、常见错误

**错误1：对边和邻边搞混**

错误做法：sinA = $\frac{\text{邻边}}{\text{斜边}}$。

正确做法：sinA = $\frac{\text{对边}}{\text{斜边}}$。

**错误2：斜边找错**

错误做法：把直角边当成斜边。

正确做法：斜边是直角所对的边，是最长的边。

**错误3：sinA与三角形大小有关**

错误理解：三角形越大，sinA越大。

正确理解：sinA只与角度有关，与三角形大小无关。

**错误4：特殊角的正弦值记错**

错误记忆：sin30° = $\frac{\sqrt{3}}{2}$。

正确记忆：sin30° = $\frac{1}{2}$，sin60° = $\frac{\sqrt{3}}{2}$。

**错误5：正弦值范围错误**

错误理解：sinA可以大于1。

正确理解：0 < sinA < 1。

## 八、练习题

**练习1：** 在Rt△ABC中，∠C = 90°，AB = 8，BC = 5。求sinA。

解：

∠A的对边是BC = 5。

斜边是AB = 8。

sinA = $\frac{BC}{AB} = \frac{5}{8}$。

答：sinA = $\frac{5}{8}$。

**练习2：** 在Rt△ABC中，∠C = 90°，AB = 17，AC = 8。求sinA。

解：

先求BC。

由勾股定理：$BC = \sqrt{AB^2-AC^2} = \sqrt{289-64} = \sqrt{225} = 15$。

∠A的对边是BC = 15。

斜边是AB = 17。

sinA = $\frac{BC}{AB} = \frac{15}{17}$。

答：sinA = $\frac{15}{17}$。

**练习3：** 在Rt△ABC中，∠C = 90°，sinA = $\frac{3}{4}$，AB = 20。求BC的长度。

解：

sinA = $\frac{BC}{AB} = \frac{3}{4}$。

$\frac{BC}{20} = \frac{3}{4}$。

$BC = 20 \times \frac{3}{4} = 15$。

答：BC的长度为15。

**练习4：** 计算：2sin30° + sin45°。

解：

sin30° = $\frac{1}{2}$。

sin45° = $\frac{\sqrt{2}}{2}$。

2sin30° + sin45° = $2 \times \frac{1}{2} + \frac{\sqrt{2}}{2} = 1 + \frac{\sqrt{2}}{2} = \frac{2+\sqrt{2}}{2}$。

答：$\frac{2+\sqrt{2}}{2}$。

**练习5：** 在Rt△ABC中，∠C = 90°，BC = 9，sinA = $\frac{3}{5}$。求AB的长度。

解：

sinA = $\frac{BC}{AB} = \frac{3}{5}$。

$\frac{9}{AB} = \frac{3}{5}$。

$3AB = 45$。

$AB = 15$。

答：AB的长度为15。
