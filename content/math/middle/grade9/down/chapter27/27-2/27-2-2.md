# 27.2.2 相似三角形的判定（一）——AA

## 一、两角分别相等的两个三角形相似

**AA判定定理**

如果两个三角形有两个角分别相等。

那么这两个三角形相似。

简记为AA（Angle-Angle）。

**数学表达**

在$\triangle ABC$和$\triangle DEF$中。

如果$\angle A = \angle D$，$\angle B = \angle E$。

那么$\triangle ABC \sim \triangle DEF$。

## 二、证明思路

**利用三角形内角和推出第三角相等**

三角形内角和为180°。

如果两个角分别相等。

那么第三个角也一定相等。

所以三个角都相等。

三角形相似。

**例子**

$\triangle ABC$中，$\angle A = 50°$，$\angle B = 60°$。

$\triangle DEF$中，$\angle D = 50°$，$\angle E = 60°$。

$\angle C = 180°-50°-60° = 70°$。

$\angle F = 180°-50°-60° = 70°$。

三个角都相等，所以$\triangle ABC \sim \triangle DEF$。

## 三、AA判定是最常用的相似判定方法

**为什么常用**

只需要找到两个角相等。

不需要知道边的长度。

在几何证明中很容易找到相等的角。

**应用场景**

有平行线时，可以找到同位角或内错角相等。

有公共角时，可以直接使用。

有对顶角时，可以直接使用。

## 四、公共角、对顶角、同角的余角相等在相似中的应用

**公共角**

两个三角形有一个公共角。

这个角自然相等。

只需要再找一个角相等即可。

**对顶角**

对顶角相等。

可以作为AA判定的一个条件。

**同角的余角相等**

如果两个角都是同一个角的余角。

那么这两个角相等。

可以作为AA判定的一个条件。

## 五、例题讲解

**例题1：** 如图，在$\triangle ABC$和$\triangle DEF$中，$\angle A = \angle D = 50°$，$\angle B = \angle E = 70°$。判断两个三角形是否相似。

解：

$\angle A = \angle D = 50°$。

$\angle B = \angle E = 70°$。

两个角分别相等。

根据AA判定，$\triangle ABC \sim \triangle DEF$。

答：两个三角形相似。

**例题2：** 如图，在$\triangle ABC$中，$DE \parallel BC$。判断$\triangle ADE$与$\triangle ABC$是否相似。

解：

因为$DE \parallel BC$。

所以$\angle ADE = \angle B$（同位角相等）。

$\angle AED = \angle C$（同位角相等）。

$\angle A$是公共角。

根据AA判定，$\triangle ADE \sim \triangle ABC$。

答：两个三角形相似。

**例题3：** 如图，在$\triangle ABC$中，$\angle A = 40°$，$\angle B = 60°$。在$\triangle DEF$中，$\angle D = 40°$，$\angle F = 80°$。判断两个三角形是否相似。

解：

在$\triangle ABC$中，$\angle C = 180°-40°-60° = 80°$。

在$\triangle DEF$中，$\angle E = 180°-40°-80° = 60°$。

$\angle A = \angle D = 40°$。

$\angle B = \angle E = 60°$。

两个角分别相等。

根据AA判定，$\triangle ABC \sim \triangle DEF$。

答：两个三角形相似。

**例题4：** 如图，$AB$与$CD$相交于点$O$，$\angle A = \angle D$。判断$\triangle AOB$与$\triangle DOC$是否相似。

解：

$\angle A = \angle D$（已知）。

$\angle AOB = \angle DOC$（对顶角相等）。

两个角分别相等。

根据AA判定，$\triangle AOB \sim \triangle DOC$。

答：两个三角形相似。

**例题5：** 如图，在$\text{Rt}\triangle ABC$中，$\angle C = 90°$，$CD \perp AB$于$D$。判断$\triangle ACD$与$\triangle ABC$是否相似。

解：

$\angle A$是公共角。

$\angle ADC = \angle ACB = 90°$。

两个角分别相等。

根据AA判定，$\triangle ACD \sim \triangle ABC$。

答：两个三角形相似。

## 六、常见错误

**错误1：只找一个角相等就判定相似**

错误做法：一个角相等就判定相似。

正确做法：必须两个角相等才能判定相似。

**错误2：对应角找错**

错误做法：随便找两个角。

正确做法：必须找对应角。

**错误3：三角形内角和计算错误**

错误做法：$\angle C = 180°-\angle A+\angle B$。

正确做法：$\angle C = 180°-\angle A-\angle B$。

**错误4：公共角忽略**

错误做法：没有发现公共角。

正确做法：注意观察是否有公共角。

**错误5：对顶角性质忘记**

错误做法：不知道对顶角相等。

正确做法：对顶角一定相等。
