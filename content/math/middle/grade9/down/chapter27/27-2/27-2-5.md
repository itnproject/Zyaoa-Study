# 27.2.5 相似三角形的实际应用

## 一、利用相似测量旗杆高度（影子法）

**原理**

在同一时刻，太阳光线是平行的。

物体和它的影子构成直角三角形。

两个直角三角形相似。

**方法**

测量旗杆影子的长度。

测量一根已知长度的标杆的影子长度。

利用相似三角形对应边成比例求旗杆高度。

**公式**

$\frac{\text{旗杆高度}}{\text{旗杆影长}} = \frac{\text{标杆高度}}{\text{标杆影长}}$。

## 二、利用相似测量河宽

**原理**

在河的一岸选取两个点。

在另一岸选取一个点。

构造相似三角形。

利用对应边成比例求河宽。

**方法**

在河的一岸选取点$A$和点$B$。

在另一岸选取点$C$。

过点$B$作$BD \parallel AC$。

利用相似三角形求河宽。

## 三、利用相似测量建筑物高度

**原理**

与测量旗杆高度类似。

利用影子法或视线法。

构造相似三角形。

**视线法**

人站在一定距离外观察建筑物顶部。

利用人的身高、人到建筑物的距离。

构造相似三角形求建筑物高度。

## 四、小孔成像原理

**原理**

光线通过小孔后形成倒立的像。

物体、小孔、像构成相似三角形。

**公式**

$\frac{\text{像的高度}}{\text{物体高度}} = \frac{\text{像到小孔的距离}}{\text{物体到小孔的距离}}$。

**特点**

像是倒立的。

像的大小与距离有关。

物体离小孔越远，像越小。

## 五、例题讲解

**例题1：** 在同一时刻，一根2m长的标杆影子长3m，旗杆的影子长15m。求旗杆的高度。

解：

设旗杆的高度为$h$m。

根据相似三角形对应边成比例。

$\frac{h}{15} = \frac{2}{3}$。

$3h = 30$。

$h = 10$m。

答：旗杆的高度为10m。

**例题2：** 小明身高1.6m，他的影子长2m。同一时刻，一棵树的影子长10m。求树的高度。

解：

设树的高度为$h$m。

根据相似三角形对应边成比例。

$\frac{h}{10} = \frac{1.6}{2}$。

$\frac{h}{10} = 0.8$。

$h = 8$m。

答：树的高度为8m。

**例题3：** 如图，要测量河宽$AB$。在河岸一侧选取点$C$，使$AC \perp AB$，$AC = 20$m。在$AC$上取点$D$，使$AD = 5$m。过点$D$作$DE \perp AC$，使$B$、$D$、$E$三点共线，测得$DE = 8$m。求河宽$AB$。

解：

因为$AB \perp AC$，$DE \perp AC$。

所以$AB \parallel DE$。

所以$\triangle ABD \sim \triangle EDD$（应为$\triangle CAB \sim \triangle CDE$）。

$\frac{AB}{DE} = \frac{AC}{DC}$。

$DC = AC-AD = 20-5 = 15$m。

$\frac{AB}{8} = \frac{20}{15}$。

$\frac{AB}{8} = \frac{4}{3}$。

$AB = \frac{32}{3}$m。

答：河宽$AB$为$\frac{32}{3}$m。

**例题4：** 小孔成像实验中，物体高6cm，物体到小孔的距离为30cm，像到小孔的距离为10cm。求像的高度。

解：

设像的高度为$h$cm。

根据相似三角形对应边成比例。

$\frac{h}{6} = \frac{10}{30}$。

$\frac{h}{6} = \frac{1}{3}$。

$h = 2$cm。

答：像的高度为2cm。

**例题5：** 小明站在距离建筑物底部20m的地方，他的眼睛离地面1.5m。他抬头看建筑物顶部，视线与地面的夹角使得他的影子顶端刚好在建筑物底部。已知小明身高1.6m，求建筑物的高度。

解：

这个题目条件不够清晰，重新设计。

小明身高1.6m，站在距离建筑物底部30m的地方。

同一时刻，小明的影子长2m，建筑物的影子长25m。

设建筑物的高度为$h$m。

$\frac{h}{25} = \frac{1.6}{2}$。

$\frac{h}{25} = 0.8$。

$h = 20$m。

答：建筑物的高度为20m。

## 六、常见错误

**错误1：影子法条件忽略**

错误做法：不同时刻的影子长度用来计算。

正确做法：必须在同一时刻测量。

**错误2：对应边找错**

错误做法：高度和影长不对应。

正确做法：高度对应高度，影长对应影长。

**错误3：单位不统一**

错误做法：米和厘米混用。

正确做法：计算前统一单位。

**错误4：小孔成像像的方向**

错误做法：小孔成像的像是正立的。

正确做法：小孔成像的像是倒立的。

**错误5：比例式列错**

错误做法：$\frac{\text{高度}}{\text{高度}} = \frac{\text{影长}}{\text{影长}}$。

正确做法：$\frac{\text{高度}}{\text{影长}} = \frac{\text{高度}}{\text{影长}}$。

## 七、练习题

**练习1：** 在同一时刻，一根3m长的标杆影子长4m，旗杆的影子长20m。求旗杆的高度。

解：

设旗杆的高度为$h$m。

根据相似三角形对应边成比例。

$\frac{h}{20} = \frac{3}{4}$。

$4h = 60$。

$h = 15$m。

答：旗杆的高度为15m。

**练习2：** 小红身高1.5m，她的影子长2.5m。同一时刻，一棵树的影子长15m。求树的高度。

解：

设树的高度为$h$m。

根据相似三角形对应边成比例。

$\frac{h}{15} = \frac{1.5}{2.5}$。

$\frac{h}{15} = 0.6$。

$h = 9$m。

答：树的高度为9m。

**练习3：** 小孔成像实验中，物体高8cm，物体到小孔的距离为40cm，像到小孔的距离为15cm。求像的高度。

解：

设像的高度为$h$cm。

根据相似三角形对应边成比例。

$\frac{h}{8} = \frac{15}{40}$。

$\frac{h}{8} = \frac{3}{8}$。

$h = 3$cm。

答：像的高度为3cm。

**练习4：** 在同一时刻，小明身高1.8m，他的影子长3m。同一时刻，教学楼的影子长30m。求教学楼的高度。

解：

设教学楼的高度为$h$m。

根据相似三角形对应边成比例。

$\frac{h}{30} = \frac{1.8}{3}$。

$\frac{h}{30} = 0.6$。

$h = 18$m。

答：教学楼的高度为18m。

**练习5：** 小孔成像实验中，物体高10cm，物体到小孔的距离为50cm，像的高度为4cm。求像到小孔的距离。

解：

设像到小孔的距离为$d$cm。

根据相似三角形对应边成比例。

$\frac{4}{10} = \frac{d}{50}$。

$\frac{2}{5} = \frac{d}{50}$。

$5d = 100$。

$d = 20$cm。

答：像到小孔的距离为20cm。
