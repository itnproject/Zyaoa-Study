# 27.2.3 相似三角形的判定（二）——SAS 和 SSS

## 一、两边成比例且夹角相等的两个三角形相似（SAS）

**SAS判定定理**

如果两个三角形有两边成比例。

并且夹角相等。

那么这两个三角形相似。

简记为SAS（Side-Angle-Side）。

**数学表达**

在$\triangle ABC$和$\triangle DEF$中。

如果$\frac{AB}{DE} = \frac{AC}{DF}$，且$\angle A = \angle D$。

那么$\triangle ABC \sim \triangle DEF$。

**注意**

必须是夹角相等。

不是任意角相等。

## 二、三边成比例的两个三角形相似（SSS）

**SSS判定定理**

如果两个三角形的三边成比例。

那么这两个三角形相似。

简记为SSS（Side-Side-Side）。

**数学表达**

在$\triangle ABC$和$\triangle DEF$中。

如果$\frac{AB}{DE} = \frac{BC}{EF} = \frac{AC}{DF}$。

那么$\triangle ABC \sim \triangle DEF$。

## 三、三种判定方法的对比与选择

**AA判定**

条件：两个角相等。

最常用，最容易找到条件。

优先使用。

**SAS判定**

条件：两边成比例且夹角相等。

当已知两边和夹角时使用。

**SSS判定**

条件：三边成比例。

当已知三边长度时使用。

## 四、直角三角形相似的判定（HL 相似）

**HL相似判定**

如果两个直角三角形的斜边和一条直角边成比例。

那么这两个直角三角形相似。

**数学表达**

在$\text{Rt}\triangle ABC$和$\text{Rt}\triangle DEF$中，$\angle C = \angle F = 90°$。

如果$\frac{AB}{DE} = \frac{AC}{DF}$。

那么$\triangle ABC \sim \triangle DEF$。

## 五、例题讲解

**例题1：** 在$\triangle ABC$和$\triangle DEF$中，$AB = 6$，$AC = 8$，$\angle A = 50°$；$DE = 3$，$DF = 4$，$\angle D = 50°$。判断两个三角形是否相似。

解：

$\frac{AB}{DE} = \frac{6}{3} = 2$。

$\frac{AC}{DF} = \frac{8}{4} = 2$。

$\frac{AB}{DE} = \frac{AC}{DF}$。

$\angle A = \angle D = 50°$（夹角相等）。

根据SAS判定，$\triangle ABC \sim \triangle DEF$。

答：两个三角形相似。

**例题2：** 在$\triangle ABC$和$\triangle DEF$中，$AB = 3$，$BC = 4$，$AC = 5$；$DE = 6$，$EF = 8$，$DF = 10$。判断两个三角形是否相似。

解：

$\frac{AB}{DE} = \frac{3}{6} = \frac{1}{2}$。

$\frac{BC}{EF} = \frac{4}{8} = \frac{1}{2}$。

$\frac{AC}{DF} = \frac{5}{10} = \frac{1}{2}$。

三边成比例。

根据SSS判定，$\triangle ABC \sim \triangle DEF$。

答：两个三角形相似。

**例题3：** 在$\triangle ABC$和$\triangle DEF$中，$AB = 4$，$AC = 6$，$\angle A = 60°$；$DE = 2$，$DF = 3$，$\angle E = 60°$。判断两个三角形是否相似。

解：

$\frac{AB}{DE} = \frac{4}{2} = 2$。

$\frac{AC}{DF} = \frac{6}{3} = 2$。

$\frac{AB}{DE} = \frac{AC}{DF}$。

但$\angle E$不是夹角，$\angle D$才是夹角。

已知$\angle E = 60°$，不是$\angle D = 60°$。

不能用SAS判定。

答：不能判定相似（条件不足）。

**例题4：** 在$\text{Rt}\triangle ABC$和$\text{Rt}\triangle DEF$中，$\angle C = \angle F = 90°$，$AB = 10$，$AC = 6$；$DE = 5$，$DF = 3$。判断两个三角形是否相似。

解：

$\frac{AB}{DE} = \frac{10}{5} = 2$。

$\frac{AC}{DF} = \frac{6}{3} = 2$。

$\frac{AB}{DE} = \frac{AC}{DF}$。

斜边和一条直角边成比例。

根据HL相似判定，$\triangle ABC \sim \triangle DEF$。

答：两个三角形相似。

**例题5：** 在$\triangle ABC$和$\triangle DEF$中，$AB = 5$，$BC = 7$，$AC = 8$；$DE = 10$，$EF = 14$，$DF = 16$。判断两个三角形是否相似，并求相似比。

解：

$\frac{AB}{DE} = \frac{5}{10} = \frac{1}{2}$。

$\frac{BC}{EF} = \frac{7}{14} = \frac{1}{2}$。

$\frac{AC}{DF} = \frac{8}{16} = \frac{1}{2}$。

三边成比例。

根据SSS判定，$\triangle ABC \sim \triangle DEF$。

相似比为$\frac{1}{2}$（或2，取决于顺序）。

答：两个三角形相似，相似比为$\frac{1}{2}$。

## 六、常见错误

**错误1：SAS中角不是夹角**

错误做法：任意角相等就用SAS。

正确做法：必须是两边的夹角相等。

**错误2：SSS中边不对应**

错误做法：随便找三条边计算比值。

正确做法：必须找对应边计算比值。

**错误3：比值计算错误**

错误做法：$\frac{3}{6} = 3$。

正确做法：$\frac{3}{6} = \frac{1}{2}$。

**错误4：HL相似条件不足**

错误做法：一条直角边成比例就判定相似。

正确做法：斜边和一条直角边都成比例。

**错误5：三种判定方法混淆**

错误做法：用AA的条件去套用SAS。

正确做法：根据已知条件选择合适的判定方法。

解：

$\frac{AC}{DF} = \frac{12}{4} = 3$。

$\frac{AB}{DE} = \frac{AC}{DF}$。

$\angle A = \angle D = 40°$（夹角相等）。

根据SAS判定，$\triangle ABC \sim \triangle DEF$。

答：两个三角形相似。

**练习2：** 在$\triangle ABC$和$\triangle DEF$中，$AB = 2$，$BC = 3$，$AC = 4$；$DE = 4$，$EF = 6$，$DF = 8$。判断两个三角形是否相似。

答：两个三角形相似。

答：不能判定相似（条件不足）。
