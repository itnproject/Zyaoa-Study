# 27.2.4 相似三角形的性质

## 一、对应角相等，对应边成比例

**基本性质**

相似三角形的对应角相等。

相似三角形的对应边成比例。

这是相似三角形最基本的性质。

**数学表达**

如果$\triangle ABC \sim \triangle DEF$。

则$\angle A = \angle D$，$\angle B = \angle E$，$\angle C = \angle F$。

且$\frac{AB}{DE} = \frac{BC}{EF} = \frac{AC}{DF} = k$（相似比）。

## 二、对应高的比等于相似比

**性质**

相似三角形对应高的比等于相似比。

**数学表达**

如果$\triangle ABC \sim \triangle DEF$，相似比为$k$。

$AH$和$DG$分别是对应高。

则$\frac{AH}{DG} = k$。

## 三、对应中线的比等于相似比

**性质**

相似三角形对应中线的比等于相似比。

**数学表达**

如果$\triangle ABC \sim \triangle DEF$，相似比为$k$。

$AM$和$DN$分别是对应中线。

则$\frac{AM}{DN} = k$。

## 四、对应角平分线的比等于相似比

**性质**

相似三角形对应角平分线的比等于相似比。

**数学表达**

如果$\triangle ABC \sim \triangle DEF$，相似比为$k$。

$AP$和$DQ$分别是对应角平分线。

则$\frac{AP}{DQ} = k$。

## 五、周长比等于相似比

**性质**

相似三角形的周长比等于相似比。

**数学表达**

如果$\triangle ABC \sim \triangle DEF$，相似比为$k$。

则$\frac{C_{\triangle ABC}}{C_{\triangle DEF}} = k$。

## 六、面积比等于相似比的平方

**性质**

相似三角形的面积比等于相似比的平方。

**数学表达**

如果$\triangle ABC \sim \triangle DEF$，相似比为$k$。

则$\frac{S_{\triangle ABC}}{S_{\triangle DEF}} = k^2$。

## 七、例题讲解

**例题1：** 已知$\triangle ABC \sim \triangle DEF$，相似比为2:3。如果$\triangle ABC$的周长为12cm，求$\triangle DEF$的周长。

解：

周长比等于相似比。

$\frac{C_{\triangle ABC}}{C_{\triangle DEF}} = \frac{2}{3}$。

$\frac{12}{C_{\triangle DEF}} = \frac{2}{3}$。

$2C_{\triangle DEF} = 36$。

$C_{\triangle DEF} = 18$cm。

答：$\triangle DEF$的周长为18cm。

**例题2：** 已知$\triangle ABC \sim \triangle DEF$，相似比为3:4。如果$\triangle ABC$的面积为18cm²，求$\triangle DEF$的面积。

解：

面积比等于相似比的平方。

$\frac{S_{\triangle ABC}}{S_{\triangle DEF}} = \left(\frac{3}{4}\right)^2 = \frac{9}{16}$。

$\frac{18}{S_{\triangle DEF}} = \frac{9}{16}$。

$9S_{\triangle DEF} = 288$。

$S_{\triangle DEF} = 32$cm²。

答：$\triangle DEF$的面积为32cm²。

**例题3：** 已知$\triangle ABC \sim \triangle DEF$，相似比为2:5。如果$\triangle ABC$的高为4cm，求$\triangle DEF$的对应高。

解：

对应高的比等于相似比。

$\frac{h_{\triangle ABC}}{h_{\triangle DEF}} = \frac{2}{5}$。

$\frac{4}{h_{\triangle DEF}} = \frac{2}{5}$。

$2h_{\triangle DEF} = 20$。

$h_{\triangle DEF} = 10$cm。

答：$\triangle DEF$的对应高为10cm。

**例题4：** 已知$\triangle ABC \sim \triangle DEF$，$\triangle ABC$的面积为9cm²，$\triangle DEF$的面积为36cm²。求相似比和周长比。

解：

面积比 = 相似比的平方。

$\frac{9}{36} = \frac{1}{4} = k^2$。

$k = \frac{1}{2}$。

相似比为1:2。

周长比 = 相似比 = 1:2。

答：相似比为1:2，周长比为1:2。

**例题5：** 已知$\triangle ABC \sim \triangle DEF$，相似比为3:5。如果$\triangle ABC$的中线长为6cm，求$\triangle DEF$的对应中线长。

解：

对应中线的比等于相似比。

$\frac{m_{\triangle ABC}}{m_{\triangle DEF}} = \frac{3}{5}$。

$\frac{6}{m_{\triangle DEF}} = \frac{3}{5}$。

$3m_{\triangle DEF} = 30$。

$m_{\triangle DEF} = 10$cm。

答：$\triangle DEF$的对应中线长为10cm。

## 八、常见错误

**错误1：面积比与相似比混淆**

错误做法：面积比等于相似比。

正确做法：面积比等于相似比的平方。

**错误2：周长比计算错误**

错误做法：周长比等于相似比的平方。

正确做法：周长比等于相似比。

**错误3：对应元素找错**

错误做法：高、中线、角平分线不对应。

正确做法：必须找对应的高、中线、角平分线。

**错误4：相似比顺序搞反**

错误做法：相似比可以随便写。

正确做法：相似比是有顺序的。

**错误5：开方错误**

错误做法：面积比为$\frac{1}{4}$，相似比为$\frac{1}{4}$。

正确做法：面积比为$\frac{1}{4}$，相似比为$\frac{1}{2}$。

## 九、练习题

**练习1：** 已知$\triangle ABC \sim \triangle DEF$，相似比为4:5。如果$\triangle ABC$的周长为20cm，求$\triangle DEF$的周长。

解：

周长比等于相似比。

$\frac{C_{\triangle ABC}}{C_{\triangle DEF}} = \frac{4}{5}$。

$\frac{20}{C_{\triangle DEF}} = \frac{4}{5}$。

$4C_{\triangle DEF} = 100$。

$C_{\triangle DEF} = 25$cm。

答：$\triangle DEF$的周长为25cm。

**练习2：** 已知$\triangle ABC \sim \triangle DEF$，相似比为2:3。如果$\triangle ABC$的面积为8cm²，求$\triangle DEF$的面积。

解：

面积比等于相似比的平方。

$\frac{S_{\triangle ABC}}{S_{\triangle DEF}} = \left(\frac{2}{3}\right)^2 = \frac{4}{9}$。

$\frac{8}{S_{\triangle DEF}} = \frac{4}{9}$。

$4S_{\triangle DEF} = 72$。

$S_{\triangle DEF} = 18$cm²。

答：$\triangle DEF$的面积为18cm²。

**练习3：** 已知$\triangle ABC \sim \triangle DEF$，相似比为3:7。如果$\triangle ABC$的高为6cm，求$\triangle DEF$的对应高。

解：

对应高的比等于相似比。

$\frac{h_{\triangle ABC}}{h_{\triangle DEF}} = \frac{3}{7}$。

$\frac{6}{h_{\triangle DEF}} = \frac{3}{7}$。

$3h_{\triangle DEF} = 42$。

$h_{\triangle DEF} = 14$cm。

答：$\triangle DEF$的对应高为14cm。

**练习4：** 已知$\triangle ABC \sim \triangle DEF$，$\triangle ABC$的面积为16cm²，$\triangle DEF$的面积为64cm²。求相似比和周长比。

解：

面积比 = 相似比的平方。

$\frac{16}{64} = \frac{1}{4} = k^2$。

$k = \frac{1}{2}$。

相似比为1:2。

周长比 = 相似比 = 1:2。

答：相似比为1:2，周长比为1:2。

**练习5：** 已知$\triangle ABC \sim \triangle DEF$，相似比为5:8。如果$\triangle ABC$的角平分线长为10cm，求$\triangle DEF$的对应角平分线长。

解：

对应角平分线的比等于相似比。

$\frac{p_{\triangle ABC}}{p_{\triangle DEF}} = \frac{5}{8}$。

$\frac{10}{p_{\triangle DEF}} = \frac{5}{8}$。

$5p_{\triangle DEF} = 80$。

$p_{\triangle DEF} = 16$cm。

答：$\triangle DEF$的对应角平分线长为16cm。
