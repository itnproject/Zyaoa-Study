# 27.2.1 平行线分线段成比例

## 一、平行线分线段成比例定理

**三条平行线截两条直线，所得对应线段成比例**

有三条平行线$l_1$、$l_2$、$l_3$。

两条直线被这三条平行线所截。

所得的对应线段成比例。

**数学表达**

如果$l_1 \parallel l_2 \parallel l_3$。

直线$a$被截得的线段为$AB$、$BC$。

直线$b$被截得的线段为$DE$、$EF$。

则$\frac{AB}{BC} = \frac{DE}{EF}$。

## 二、推论

**平行于三角形一边的直线截其他两边，所得对应线段成比例**

在$\triangle ABC$中。

$DE \parallel BC$。

$D$在$AB$上，$E$在$AC$上。

则$\frac{AD}{DB} = \frac{AE}{EC}$。

**另一种形式**

$\frac{AD}{AB} = \frac{AE}{AC} = \frac{DE}{BC}$。

## 三、利用平行线分线段成比例求线段长度

**方法**

找到平行线。

确定对应线段。

列出比例式。

解方程求未知线段。

**例子**

在$\triangle ABC$中，$DE \parallel BC$。

$AD = 3$，$DB = 2$，$AE = 6$。

求$EC$。

$\frac{AD}{DB} = \frac{AE}{EC}$。

$\frac{3}{2} = \frac{6}{EC}$。

$EC = 4$。

## 四、例题讲解

**例题1：** 如图，在$\triangle ABC$中，$DE \parallel BC$，$AD = 4$，$DB = 2$，$AE = 6$。求$EC$的长度。

解：

因为$DE \parallel BC$。

所以$\frac{AD}{DB} = \frac{AE}{EC}$。

$\frac{4}{2} = \frac{6}{EC}$。

$2 = \frac{6}{EC}$。

$EC = 3$。

答：$EC$的长度为3。

**例题2：** 如图，在$\triangle ABC$中，$DE \parallel BC$，$AD = 3$，$AB = 9$，$DE = 4$。求$BC$的长度。

解：

因为$DE \parallel BC$。

所以$\frac{AD}{AB} = \frac{DE}{BC}$。

$\frac{3}{9} = \frac{4}{BC}$。

$\frac{1}{3} = \frac{4}{BC}$。

$BC = 12$。

答：$BC$的长度为12。

**例题3：** 如图，$l_1 \parallel l_2 \parallel l_3$，直线$a$被截得的线段$AB = 3$，$BC = 5$。直线$b$被截得的线段$DE = 6$。求$EF$的长度。

解：

因为$l_1 \parallel l_2 \parallel l_3$。

所以$\frac{AB}{BC} = \frac{DE}{EF}$。

$\frac{3}{5} = \frac{6}{EF}$。

$3EF = 30$。

$EF = 10$。

答：$EF$的长度为10。

**例题4：** 如图，在$\triangle ABC$中，$DE \parallel BC$，$AD = 2$，$DB = 3$，$EC = 9$。求$AE$的长度。

解：

因为$DE \parallel BC$。

所以$\frac{AD}{DB} = \frac{AE}{EC}$。

$\frac{2}{3} = \frac{AE}{9}$。

$3AE = 18$。

$AE = 6$。

答：$AE$的长度为6。

**例题5：** 如图，在$\triangle ABC$中，$DE \parallel BC$，$AD = 5$，$AB = 15$，$BC = 12$。求$DE$的长度。

解：

因为$DE \parallel BC$。

所以$\frac{AD}{AB} = \frac{DE}{BC}$。

$\frac{5}{15} = \frac{DE}{12}$。

$\frac{1}{3} = \frac{DE}{12}$。

$DE = 4$。

答：$DE$的长度为4。

## 五、常见错误

**错误1：对应线段找错**

错误做法：随便找两条线段列比例。

正确做法：必须找对应线段列比例。

**错误2：比例式列错**

错误做法：$\frac{AD}{AB} = \frac{EC}{AC}$。

正确做法：$\frac{AD}{AB} = \frac{AE}{AC}$。

**错误3：平行线条件忽略**

错误做法：没有平行线也用这个定理。

正确做法：必须有平行线才能用这个定理。

**错误4：计算错误**

错误做法：$\frac{3}{5} = \frac{6}{EF}$，$EF = \frac{18}{5}$。

正确做法：$\frac{3}{5} = \frac{6}{EF}$，$EF = 10$。

**错误5：线段长度关系混淆**

错误做法：$AB = AD+DB$不知道。

正确做法：$AB = AD+DB$。
