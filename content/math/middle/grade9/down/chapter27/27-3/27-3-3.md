# 27.3.3 相似与位似的综合应用

## 一、相似三角形与四边形综合

**方法**

在四边形中构造相似三角形。

利用相似三角形的性质求边长或面积。

利用位似变换解决图形缩放问题。

**常见模型**

平行四边形中的相似三角形。

梯形中的相似三角形。

矩形中的相似三角形。

## 二、相似与函数图象结合

**方法**

在函数图象上找点构造相似三角形。

利用相似三角形的性质求点的坐标。

利用函数解析式求相似比。

**常见类型**

一次函数图象上的相似三角形。

反比例函数图象上的相似三角形。

二次函数图象上的相似三角形。

## 三、相似与动点问题

**方法**

设动点坐标为参数。

利用相似条件列方程。

解方程求参数值。

**常见类型**

动点在直线上运动。

动点在图形边上运动。

动点使两个三角形相似。

## 四、相似与圆结合

**方法**

圆中的弦、切线构造相似三角形。

利用圆周角定理找相等角。

利用相似三角形求线段长度。

**常见模型**

相交弦定理。

切割线定理。

圆幂定理。

## 五、例题讲解

**例题1：** 如图，在平行四边形$ABCD$中，$E$是$BC$上一点，$AE$交$BD$于$F$。已知$BE:EC = 2:1$，$BD = 12$。求$BF$的长度。

解：

因为$AD \parallel BC$。

所以$\angle DAF = \angle BEF$（内错角相等）。

$\angle ADF = \angle EBF$（内错角相等）。

所以$\triangle ADF \sim \triangle EBF$（AA）。

$\frac{BF}{DF} = \frac{BE}{AD}$。

因为$ABCD$是平行四边形，$AD = BC$。

$BE:EC = 2:1$，所以$BE:BC = 2:3$。

$\frac{BF}{DF} = \frac{2}{3}$。

$BF+DF = BD = 12$。

设$BF = 2x$，$DF = 3x$。

$2x+3x = 12$。

$x = \frac{12}{5}$。

$BF = 2x = \frac{24}{5}$。

答：$BF$的长度为$\frac{24}{5}$。

**例题2：** 如图，直线$y = x+2$与$x$轴交于点$A$，与$y$轴交于点$B$。点$P$在直线上，$PC \perp x$轴于$C$。如果$\triangle PCO \sim \triangle ABO$，求点$P$的坐标。

解：

直线$y = x+2$与$x$轴交点$A(-2, 0)$。

与$y$轴交点$B(0, 2)$。

$OA = 2$，$OB = 2$。

设$P(x, x+2)$，则$C(x, 0)$。

$PC = |x+2|$，$OC = |x|$。

因为$\triangle PCO \sim \triangle ABO$。

$\frac{PC}{OB} = \frac{OC}{OA}$。

$\frac{|x+2|}{2} = \frac{|x|}{2}$。

$|x+2| = |x|$。

$x+2 = x$（无解）或$x+2 = -x$。

$2x = -2$。

$x = -1$。

$P(-1, 1)$。

答：点$P$的坐标为$(-1, 1)$。

**例题3：** 如图，在$\triangle ABC$中，$AB = 8$，$AC = 6$，$BC = 10$。点$P$从$B$出发沿$BC$向$C$运动，速度为1单位/秒。点$Q$从$C$出发沿$CA$向$A$运动，速度为1单位/秒。当$\triangle PCQ \sim \triangle BCA$时，求运动时间$t$。

解：

设运动时间为$t$秒。

$BP = t$，$PC = 10-t$。

$CQ = t$，$QA = 6-t$。

因为$\triangle PCQ \sim \triangle BCA$。

$\frac{PC}{BC} = \frac{CQ}{CA}$。

$\frac{10-t}{10} = \frac{t}{6}$。

$6(10-t) = 10t$。

$60-6t = 10t$。

$16t = 60$。

$t = \frac{15}{4}$。

答：运动时间为$\frac{15}{4}$秒。

**例题4：** 如图，在$\odot O$中，弦$AB$与弦$CD$相交于点$P$。已知$AP = 3$，$PB = 4$，$CP = 2$。求$PD$的长度。

解：

连接$AC$、$BD$。

$\angle A = \angle D$（同弧所对的圆周角相等）。

$\angle C = \angle B$（同弧所对的圆周角相等）。

所以$\triangle APC \sim \triangle DPB$（AA）。

$\frac{AP}{DP} = \frac{CP}{BP}$。

$\frac{3}{DP} = \frac{2}{4}$。

$\frac{3}{DP} = \frac{1}{2}$。

$DP = 6$。

答：$PD$的长度为6。

**例题5：** 如图，在$\odot O$中，$AB$是直径，$C$是圆上一点，$CD \perp AB$于$D$。已知$AB = 10$，$CD = 4$。求$AD$的长度。

解：

因为$AB$是直径。

所以$\angle ACB = 90°$（直径所对的圆周角是直角）。

因为$CD \perp AB$。

所以$\angle CDA = \angle CDB = 90°$。

$\angle A = \angle A$（公共角）。

所以$\triangle ACD \sim \triangle ABC$（AA）。

同理$\triangle CBD \sim \triangle ABC$。

所以$\triangle ACD \sim \triangle CBD$。

$\frac{AD}{CD} = \frac{CD}{BD}$。

$CD^2 = AD \cdot BD$。

设$AD = x$，则$BD = 10-x$。

$4^2 = x(10-x)$。

$16 = 10x-x^2$。

$x^2-10x+16 = 0$。

$(x-2)(x-8) = 0$。

$x = 2$或$x = 8$。

答：$AD$的长度为2或8。

## 六、常见错误

**错误1：相似三角形对应关系找错**

错误做法：随便找对应边。

正确做法：根据相等角找对应边。

**错误2：动点问题参数设错**

错误做法：参数设得不合理。

正确做法：根据运动方向和时间设参数。

**错误3：圆中相似条件找错**

错误做法：不知道圆周角定理。

正确做法：利用圆周角定理找相等角。

**错误4：函数图象上点的坐标计算错误**

错误做法：点的坐标代入错误。

正确做法：仔细代入函数解析式。

**错误5：四边形中相似三角形构造错误**

错误做法：找不到相似三角形。

正确做法：利用平行线找相等角。

## 七、练习题

**练习1：** 如图，在梯形$ABCD$中，$AD \parallel BC$，$AD = 4$，$BC = 8$。对角线$AC$与$BD$相交于点$O$。求$\frac{AO}{OC}$。

解：

因为$AD \parallel BC$。

所以$\angle DAO = \angle BCO$（内错角相等）。

$\angle ADO = \angle CBO$（内错角相等）。

所以$\triangle AOD \sim \triangle COB$（AA）。

$\frac{AO}{OC} = \frac{AD}{BC} = \frac{4}{8} = \frac{1}{2}$。

答：$\frac{AO}{OC} = \frac{1}{2}$。

**练习2：** 如图，直线$y = 2x-4$与$x$轴交于点$A$，与$y$轴交于点$B$。点$P$在直线上，$PC \perp x$轴于$C$。如果$\triangle PCO \sim \triangle ABO$，求点$P$的坐标。

解：

直线$y = 2x-4$与$x$轴交点$A(2, 0)$。

与$y$轴交点$B(0, -4)$。

$OA = 2$，$OB = 4$。

设$P(x, 2x-4)$，则$C(x, 0)$。

$PC = |2x-4|$，$OC = |x|$。

因为$\triangle PCO \sim \triangle ABO$。

$\frac{PC}{OB} = \frac{OC}{OA}$。

$\frac{|2x-4|}{4} = \frac{|x|}{2}$。

$|2x-4| = 2|x|$。

$2x-4 = 2x$（无解）或$2x-4 = -2x$。

$4x = 4$。

$x = 1$。

$P(1, -2)$。

答：点$P$的坐标为$(1, -2)$。

**练习3：** 如图，在$\triangle ABC$中，$AB = 6$，$AC = 4$，$BC = 8$。点$P$从$B$出发沿$BC$向$C$运动，速度为1单位/秒。点$Q$从$C$出发沿$CA$向$A$运动，速度为1单位/秒。当$\triangle PCQ \sim \triangle BCA$时，求运动时间$t$。

解：

设运动时间为$t$秒。

$BP = t$，$PC = 8-t$。

$CQ = t$，$QA = 4-t$。

因为$\triangle PCQ \sim \triangle BCA$。

$\frac{PC}{BC} = \frac{CQ}{CA}$。

$\frac{8-t}{8} = \frac{t}{4}$。

$4(8-t) = 8t$。

$32-4t = 8t$。

$12t = 32$。

$t = \frac{8}{3}$。

答：运动时间为$\frac{8}{3}$秒。

**练习4：** 如图，在$\odot O$中，弦$AB$与弦$CD$相交于点$P$。已知$AP = 4$，$PB = 3$，$CP = 2$。求$PD$的长度。

解：

连接$AC$、$BD$。

$\angle A = \angle D$（同弧所对的圆周角相等）。

$\angle C = \angle B$（同弧所对的圆周角相等）。

所以$\triangle APC \sim \triangle DPB$（AA）。

$\frac{AP}{DP} = \frac{CP}{BP}$。

$\frac{4}{DP} = \frac{2}{3}$。

$2DP = 12$。

$DP = 6$。

答：$PD$的长度为6。

**练习5：** 如图，在$\odot O$中，$AB$是直径，$C$是圆上一点，$CD \perp AB$于$D$。已知$AB = 12$，$CD = 6$。求$AD$的长度。

解：

因为$AB$是直径。

所以$\angle ACB = 90°$（直径所对的圆周角是直角）。

因为$CD \perp AB$。

所以$\angle CDA = \angle CDB = 90°$。

$\angle A = \angle A$（公共角）。

所以$\triangle ACD \sim \triangle ABC$（AA）。

同理$\triangle CBD \sim \triangle ABC$。

所以$\triangle ACD \sim \triangle CBD$。

$\frac{AD}{CD} = \frac{CD}{BD}$。

$CD^2 = AD \cdot BD$。

设$AD = x$，则$BD = 12-x$。

$6^2 = x(12-x)$。

$36 = 12x-x^2$。

$x^2-12x+36 = 0$。

$(x-6)^2 = 0$。

$x = 6$。

答：$AD$的长度为6。
