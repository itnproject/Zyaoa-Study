# 27.3.1 位似图形

## 一、从生活实例引入

**投影仪放映**

投影仪把电脑屏幕上的图像放大到幕布上。

放大后的图像和原图像形状相同。

对应点的连线都交于投影仪的镜头。

这就是位似图形。

**照相机拍照**

照相机把远处的景物缩小到照片上。

缩小后的图像和原景物形状相同。

对应点的连线都交于镜头。

这也是位似图形。

## 二、位似图形的定义

**对应点连线交于一点的相似图形**

两个图形是相似图形。

对应点的连线都交于同一点。

这样的两个图形叫做位似图形。

**位似中心**

对应点连线的交点叫做位似中心。

**位似比**

位似图形的相似比叫做位似比。

## 三、位似中心、位似比

**位似中心的位置**

位似中心可以在图形内部。

位似中心可以在图形外部。

位似中心可以在图形上。

**位似比**

位似比$k>1$时，图形放大。

位似比$0<k<1$时，图形缩小。

位似比$k=1$时，图形大小不变。

**位似比的符号**

位似中心同侧时，位似比为正。

位似中心异侧时，位似比为负。

## 四、位似图形一定是相似图形，相似图形不一定是位似图形

**位似图形一定是相似图形**

位似图形满足相似图形的所有条件。

对应角相等，对应边成比例。

**相似图形不一定是位似图形**

相似图形的对应点连线不一定交于一点。

只有对应点连线交于一点的相似图形才是位似图形。

**关系**

位似是相似的特殊情况。

位似比就是相似比。

## 五、例题讲解

**例题1：** 判断下列说法是否正确：①位似图形一定是相似图形；②相似图形一定是位似图形；③位似图形的对应点连线交于一点。

解：

①正确。位似图形一定是相似图形。

②错误。相似图形不一定是位似图形。

③正确。位似图形的对应点连线交于一点（位似中心）。

答：①正确，②错误，③正确。

**例题2：** 如图，$\triangle ABC$与$\triangle A'B'C'$是位似图形，位似中心为$O$。如果$OA = 2$，$OA' = 6$。求位似比。

解：

位似比 = $\frac{OA'}{OA}$。

位似比 = $\frac{6}{2} = 3$。

答：位似比为3。

**例题3：** 如图，$\triangle ABC$与$\triangle A'B'C'$是位似图形，位似中心为$O$，位似比为2。如果$AB = 3$，求$A'B'$的长度。

解：

位似比 = $\frac{A'B'}{AB}$。

$2 = \frac{A'B'}{3}$。

$A'B' = 6$。

答：$A'B'$的长度为6。

**例题4：** 如图，$\triangle ABC$与$\triangle A'B'C'$是位似图形，位似中心为$O$。如果$\triangle ABC$的面积为4cm²，位似比为3。求$\triangle A'B'C'$的面积。

解：

面积比 = 位似比的平方。

$\frac{S_{\triangle A'B'C'}}{S_{\triangle ABC}} = 3^2 = 9$。

$S_{\triangle A'B'C'} = 4 \times 9 = 36$cm²。

答：$\triangle A'B'C'$的面积为36cm²。

**例题5：** 如图，$\triangle ABC$与$\triangle A'B'C'$是位似图形，位似中心为$O$，位似比为$\frac{1}{2}$。如果$\triangle ABC$的周长为20cm，求$\triangle A'B'C'$的周长。

解：

周长比 = 位似比。

$\frac{C_{\triangle A'B'C'}}{C_{\triangle ABC}} = \frac{1}{2}$。

$\frac{C_{\triangle A'B'C'}}{20} = \frac{1}{2}$。

$C_{\triangle A'B'C'} = 10$cm。

答：$\triangle A'B'C'$的周长为10cm。

## 六、常见错误

**错误1：位似与相似混淆**

错误理解：位似和相似是一回事。

正确理解：位似是相似的特殊情况。

**错误2：位似中心找错**

错误做法：随便找一个点作为位似中心。

正确做法：位似中心是对应点连线的交点。

**错误3：位似比计算错误**

错误做法：位似比 = $\frac{OA}{OA'}$。

正确做法：位似比 = $\frac{OA'}{OA}$（新图形比原图形）。

**错误4：面积比计算错误**

错误做法：面积比 = 位似比。

正确做法：面积比 = 位似比的平方。

**错误5：位似比符号忽略**

错误做法：位似比只有正值。

正确做法：位似中心异侧时，位似比为负。

## 七、练习题

**练习1：** 判断下列说法是否正确：①位似图形的对应边平行；②位似图形的对应点连线交于一点；③位似图形一定是全等图形。

解：

①正确。位似图形的对应边平行（或在同一直线上）。

②正确。位似图形的对应点连线交于位似中心。

③错误。位似图形不一定是全等图形，只有位似比为1时才是全等图形。

答：①正确，②正确，③错误。

**练习2：** 如图，$\triangle ABC$与$\triangle A'B'C'$是位似图形，位似中心为$O$。如果$OA = 3$，$OA' = 9$。求位似比。

解：

位似比 = $\frac{OA'}{OA}$。

位似比 = $\frac{9}{3} = 3$。

答：位似比为3。

**练习3：** 如图，$\triangle ABC$与$\triangle A'B'C'$是位似图形，位似中心为$O$，位似比为4。如果$BC = 2$，求$B'C'$的长度。

解：

位似比 = $\frac{B'C'}{BC}$。

$4 = \frac{B'C'}{2}$。

$B'C' = 8$。

答：$B'C'$的长度为8。

**练习4：** 如图，$\triangle ABC$与$\triangle A'B'C'$是位似图形，位似中心为$O$。如果$\triangle ABC$的面积为5cm²，位似比为2。求$\triangle A'B'C'$的面积。

解：

面积比 = 位似比的平方。

$\frac{S_{\triangle A'B'C'}}{S_{\triangle ABC}} = 2^2 = 4$。

$S_{\triangle A'B'C'} = 5 \times 4 = 20$cm²。

答：$\triangle A'B'C'$的面积为20cm²。

**练习5：** 如图，$\triangle ABC$与$\triangle A'B'C'$是位似图形，位似中心为$O$，位似比为$\frac{1}{3}$。如果$\triangle ABC$的周长为18cm，求$\triangle A'B'C'$的周长。

解：

周长比 = 位似比。

$\frac{C_{\triangle A'B'C'}}{C_{\triangle ABC}} = \frac{1}{3}$。

$\frac{C_{\triangle A'B'C'}}{18} = \frac{1}{3}$。

$C_{\triangle A'B'C'} = 6$cm。

答：$\triangle A'B'C'$的周长为6cm。
