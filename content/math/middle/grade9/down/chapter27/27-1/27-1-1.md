# 27.1.1 相似图形

## 一、从生活实例引入

**照片放大缩小**

同一张照片可以放大，也可以缩小。

放大后的照片和原照片形状相同。

只是大小不同。

这就是相似图形。

**地图与实际地形**

地图是实际地形的缩小版。

地图上的道路形状与实际道路形状相同。

只是大小不同。

地图与实际地形是相似图形。

**不同尺寸的国旗**

不同尺寸的国旗形状相同。

只是大小不同。

它们都是相似图形。

## 二、相似图形的定义

**形状相同、大小不一定相同的图形**

两个图形形状完全相同。

大小可以相同，也可以不同。

这样的两个图形叫做相似图形。

**例子**

两个大小不同的正方形是相似图形。

两个大小不同的圆是相似图形。

两个大小不同的等边三角形是相似图形。

## 三、相似图形与全等图形的区别与联系

**全等图形**

形状相同，大小也相同。

可以完全重合。

全等是相似的特殊情况。

**相似图形**

形状相同，大小不一定相同。

不一定能完全重合。

相似包含全等。

**联系**

全等图形一定是相似图形。

相似图形不一定是全等图形。

相似比为1时，相似图形就是全等图形。

## 四、相似比的概念

**对应边的比值**

两个相似图形中。

对应边的长度之比叫做相似比。

相似比通常用字母$k$表示。

**例子**

两个相似正方形，边长分别为2和4。

相似比$k = \frac{4}{2} = 2$。

或$k = \frac{2}{4} = \frac{1}{2}$。

**注意**

相似比是有顺序的。

第一个图形与第二个图形的相似比是$k$。

第二个图形与第一个图形的相似比是$\frac{1}{k}$。

## 五、判断两个图形是否相似

**判断方法**

观察两个图形的形状是否相同。

对应角是否相等。

对应边是否成比例。

**例子**

两个矩形，长宽比分别为2:1和4:2。

2:1 = 4:2 = 2。

对应边成比例，对应角都是90°。

所以这两个矩形相似。

**反例**

两个矩形，长宽比分别为2:1和3:1。

2:1 ≠ 3:1。

对应边不成比例。

所以这两个矩形不相似。

## 六、例题讲解

**例题1：** 判断下列各组图形是否相似：①两个圆；②两个正方形；③两个等边三角形。

解：

①两个圆：所有圆的形状都相同，只是大小不同。所以两个圆一定相似。

②两个正方形：所有正方形的形状都相同，只是大小不同。所以两个正方形一定相似。

③两个等边三角形：所有等边三角形的形状都相同，只是大小不同。所以两个等边三角形一定相似。

答：①相似，②相似，③相似。

**例题2：** 两个相似矩形的边长分别为3cm和6cm。求相似比。

解：

相似比 = $\frac{\text{第二个图形的边长}}{\text{第一个图形的边长}}$。

$k = \frac{6}{3} = 2$。

答：相似比为2。

**例题3：** 判断两个矩形是否相似：矩形A的长为4cm，宽为2cm；矩形B的长为6cm，宽为3cm。

解：

矩形A的长宽比 = $\frac{4}{2} = 2$。

矩形B的长宽比 = $\frac{6}{3} = 2$。

长宽比相等，对应角都是90°。

所以两个矩形相似。

答：两个矩形相似。

**例题4：** 判断两个矩形是否相似：矩形A的长为4cm，宽为2cm；矩形B的长为6cm，宽为2cm。

解：

矩形A的长宽比 = $\frac{4}{2} = 2$。

矩形B的长宽比 = $\frac{6}{2} = 3$。

长宽比不相等。

所以两个矩形不相似。

答：两个矩形不相似。

**例题5：** 已知两个相似三角形的相似比为3:2。如果第一个三角形的一边长为9cm，求第二个三角形对应边的长度。

解：

相似比 = $\frac{\text{第一个三角形的边长}}{\text{第二个三角形的对应边长}} = \frac{3}{2}$。

设第二个三角形对应边长为$x$cm。

$\frac{9}{x} = \frac{3}{2}$。

$3x = 18$。

$x = 6$cm。

答：第二个三角形对应边的长度为6cm。

## 七、常见错误

**错误1：相似与全等混淆**

错误理解：相似图形就是全等图形。

正确理解：全等是相似的特殊情况，相似图形大小可以不同。

**错误2：相似比顺序搞反**

错误做法：相似比可以随便写。

正确做法：相似比是有顺序的，要注意哪个图形比哪个图形。

**错误3：矩形相似判断错误**

错误理解：所有矩形都相似。

正确理解：只有长宽比相等的矩形才相似。

**错误4：对应边找错**

错误做法：随便找两条边计算比值。

正确做法：必须找对应边计算比值。

**错误5：相似比计算错误**

错误做法：相似比 = 边长之差。

正确做法：相似比 = 对应边的比值。

## 八、练习题

**练习1：** 判断下列各组图形是否相似：①两个等腰直角三角形；②两个菱形；③两个正六边形。

解：

①两个等腰直角三角形：所有等腰直角三角形的形状都相同。所以一定相似。

②两个菱形：菱形的内角可以不同，形状不一定相同。所以不一定相似。

③两个正六边形：所有正六边形的形状都相同。所以一定相似。

答：①相似，②不一定相似，③相似。

**练习2：** 两个相似正方形的边长分别为5cm和10cm。求相似比。

解：

相似比 = $\frac{10}{5} = 2$。

答：相似比为2。

**练习3：** 判断两个矩形是否相似：矩形A的长为8cm，宽为4cm；矩形B的长为12cm，宽为6cm。

解：

矩形A的长宽比 = $\frac{8}{4} = 2$。

矩形B的长宽比 = $\frac{12}{6} = 2$。

长宽比相等，对应角都是90°。

所以两个矩形相似。

答：两个矩形相似。

**练习4：** 判断两个矩形是否相似：矩形A的长为5cm，宽为3cm；矩形B的长为10cm，宽为4cm。

解：

矩形A的长宽比 = $\frac{5}{3}$。

矩形B的长宽比 = $\frac{10}{4} = \frac{5}{2}$。

$\frac{5}{3} \neq \frac{5}{2}$。

长宽比不相等。

所以两个矩形不相似。

答：两个矩形不相似。

**练习5：** 已知两个相似三角形的相似比为2:5。如果第一个三角形的一边长为4cm，求第二个三角形对应边的长度。

解：

相似比 = $\frac{\text{第一个三角形的边长}}{\text{第二个三角形的对应边长}} = \frac{2}{5}$。

设第二个三角形对应边长为$x$cm。

$\frac{4}{x} = \frac{2}{5}$。

$2x = 20$。

$x = 10$cm。

答：第二个三角形对应边的长度为10cm。
