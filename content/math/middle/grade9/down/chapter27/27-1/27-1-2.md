# 27.1.2 相似多边形

## 一、相似多边形的定义

**对应角相等、对应边成比例的多边形**

两个多边形。

对应角都相等。

对应边都成比例。

这样的两个多边形叫做相似多边形。

**例子**

两个相似三角形。

对应角相等，对应边成比例。

两个相似正方形。

对应角都是90°，对应边成比例。

## 二、相似比

**对应边的比**

两个相似多边形中。

对应边的长度之比叫做相似比。

相似比通常用字母$k$表示。

**例子**

两个相似五边形。

第一个五边形边长为2，第二个五边形对应边长为6。

相似比$k = \frac{6}{2} = 3$。

## 三、相似多边形的性质

**周长比等于相似比**

两个相似多边形的周长之比等于相似比。

如果相似比为$k$。

则周长比也为$k$。

**面积比等于相似比的平方**

两个相似多边形的面积之比等于相似比的平方。

如果相似比为$k$。

则面积比为$k^2$。

**例子**

两个相似三角形，相似比为2。

周长比 = 2。

面积比 = $2^2 = 4$。

## 四、判断两个多边形是否相似的方法

**判断步骤**

第一步：检查对应角是否相等。

第二步：检查对应边是否成比例。

两个条件都满足，则多边形相似。

**三角形相似的特殊性**

三角形只需要满足对应角相等即可。

因为角相等必然导致边成比例。

**多边形相似的必要条件**

多边形必须同时满足角相等和边成比例。

只满足一个条件不够。

## 五、例题讲解

**例题1：** 两个相似四边形的相似比为3:1。如果第一个四边形的周长为24cm，求第二个四边形的周长。

解：

周长比等于相似比。

$\frac{\text{第一个四边形的周长}}{\text{第二个四边形的周长}} = \frac{3}{1}$。

$\frac{24}{\text{第二个四边形的周长}} = 3$。

第二个四边形的周长 = $\frac{24}{3} = 8$cm。

答：第二个四边形的周长为8cm。

**例题2：** 两个相似五边形的相似比为2:3。如果第一个五边形的面积为20cm²，求第二个五边形的面积。

解：

面积比等于相似比的平方。

$\frac{\text{第一个五边形的面积}}{\text{第二个五边形的面积}} = \left(\frac{2}{3}\right)^2 = \frac{4}{9}$。

$\frac{20}{\text{第二个五边形的面积}} = \frac{4}{9}$。

第二个五边形的面积 = $20 \times \frac{9}{4} = 45$cm²。

答：第二个五边形的面积为45cm²。

**例题3：** 判断两个四边形是否相似：四边形A的四个角分别为90°、90°、90°、90°，四边长分别为2、3、2、3；四边形B的四个角分别为90°、90°、90°、90°，四边长分别为4、6、4、6。

解：

对应角都相等（都是90°）。

对应边的比：$\frac{4}{2} = 2$，$\frac{6}{3} = 2$，$\frac{4}{2} = 2$，$\frac{6}{3} = 2$。

对应边成比例，比值都为2。

所以两个四边形相似。

答：两个四边形相似。

**例题4：** 两个相似六边形的面积比为4:9。求它们的相似比和周长比。

解：

面积比 = 相似比的平方。

$\frac{4}{9} = k^2$。

$k = \frac{2}{3}$。

相似比为2:3。

周长比 = 相似比 = 2:3。

答：相似比为2:3，周长比为2:3。

**例题5：** 两个相似三角形的面积比为1:4。如果第一个三角形的周长为6cm，求第二个三角形的周长。

解：

面积比 = 相似比的平方。

$\frac{1}{4} = k^2$。

$k = \frac{1}{2}$。

相似比为1:2。

周长比 = 相似比 = 1:2。

$\frac{6}{\text{第二个三角形的周长}} = \frac{1}{2}$。

第二个三角形的周长 = 12cm。

答：第二个三角形的周长为12cm。

## 六、常见错误

**错误1：面积比与相似比混淆**

错误做法：面积比等于相似比。

正确做法：面积比等于相似比的平方。

**错误2：周长比计算错误**

错误做法：周长比等于相似比的平方。

正确做法：周长比等于相似比。

**错误3：对应边找错**

错误做法：随便找两条边计算比值。

正确做法：必须找对应边计算比值。

**错误4：多边形相似条件不足**

错误理解：对应角相等的多边形一定相似。

正确理解：多边形相似需要对应角相等且对应边成比例。

**错误5：相似比顺序搞反**

错误做法：相似比可以随便写。

正确做法：相似比是有顺序的。

## 七、练习题

**练习1：** 两个相似三角形的相似比为4:1。如果第一个三角形的周长为20cm，求第二个三角形的周长。

解：

周长比等于相似比。

$\frac{\text{第一个三角形的周长}}{\text{第二个三角形的周长}} = \frac{4}{1}$。

$\frac{20}{\text{第二个三角形的周长}} = 4$。

第二个三角形的周长 = $\frac{20}{4} = 5$cm。

答：第二个三角形的周长为5cm。

**练习2：** 两个相似四边形的相似比为1:3。如果第一个四边形的面积为10cm²，求第二个四边形的面积。

$\frac{\text{第一个四边形的面积}}{\text{第二个四边形的面积}} = \left(\frac{1}{3}\right)^2 = \frac{1}{9}$。

$\frac{10}{\text{第二个四边形的面积}} = \frac{1}{9}$。

第二个四边形的面积 = $10 \times 9 = 90$cm²。

答：第二个四边形的面积为90cm²。

**练习3：** 两个相似五边形的面积比为9:16。求它们的相似比和周长比。

$\frac{9}{16} = k^2$。

$k = \frac{3}{4}$。

相似比为3:4。

周长比 = 相似比 = 3:4。

答：相似比为3:4，周长比为3:4。

**练习4：** 两个相似三角形的面积比为1:9。如果第一个三角形的周长为5cm，求第二个三角形的周长。

解：

面积比 = 相似比的平方。

$\frac{1}{9} = k^2$。

$k = \frac{1}{3}$。

相似比为1:3。

周长比 = 相似比 = 1:3。
