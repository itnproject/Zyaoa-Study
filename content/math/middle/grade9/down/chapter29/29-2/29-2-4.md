# 29.2.4 用小正方体搭几何体

## 一、根据三视图判断小正方体的个数

**方法**

先看俯视图，确定底层小正方体的位置。

再看主视图和左视图，确定每列的高度。

综合判断小正方体的个数。

**例子**

俯视图显示底层有3个小正方体。

主视图显示最高2层。

左视图显示最高2层。

综合判断共5个小正方体。

## 二、由俯视图中的数字标出小正方体的个数

**方法**

在俯视图的每个位置上标出该位置小正方体的个数。

数字表示该位置叠放的小正方体数量。

**例子**

俯视图是2×2的方格。

左上角标2，右上角标1。

左下角标1，右下角标3。

表示左上角叠放2个，右上角叠放1个。

左下角叠放1个，右下角叠放3个。

共7个小正方体。

## 三、最少需要多少个小正方体

**方法**

根据三视图确定每个位置的最小高度。

求和得到最少个数。

**原则**

每个位置的高度至少满足主视图和左视图的要求。

## 四、最多可以有多少个小正方体

**方法**

根据三视图确定每个位置的最大高度。

求和得到最多个数。

**原则**

每个位置的高度不超过主视图和左视图的限制。

## 五、例题讲解

**例题1：** 一个几何体由若干个小正方体搭成，俯视图如下（数字表示该位置小正方体的个数）：
```
2 1
1 3
```
求小正方体的总个数。

解：

左上角2个，右上角1个。

左下角1个，右下角3个。

总数 = 2+1+1+3 = 7个。

答：共7个小正方体。

**例题2：** 一个几何体由若干个小正方体搭成，俯视图是2×2的方格，主视图从左到右高度为2、3，左视图从左到右高度为3、2。求最少需要多少个小正方体。

解：

设俯视图四个位置为：
```
a b
c d
```

主视图：a和c的最大值为2，b和d的最大值为3。

左视图：a和b的最大值为3，c和d的最大值为2。

要使总数最少。

a = 2（满足主视图第一列和左视图第一行）。

b = 3（满足左视图第一行）。

c = 1（满足主视图第一列）。

d = 2（满足主视图第二列和左视图第二行）。

最少 = 2+3+1+2 = 8个。

答：最少需要8个小正方体。

**例题3：** 一个几何体由若干个小正方体搭成，俯视图是2×2的方格，主视图从左到右高度为2、3，左视图从左到右高度为3、2。求最多可以有多少个小正方体。

解：

设俯视图四个位置为：
```
a b
c d
```

主视图：a和c的最大值为2，b和d的最大值为3。

左视图：a和b的最大值为3，c和d的最大值为2。

要使总数最多。

a = 2（不超过主视图第一列限制）。

b = 3（不超过主视图第二列限制）。

c = 2（不超过左视图第二行限制）。

d = 2（不超过左视图第二行限制）。

最多 = 2+3+2+2 = 9个。

答：最多可以有9个小正方体。

**例题4：** 一个几何体由若干个小正方体搭成，俯视图如下：
```
1 2 1
```
主视图从左到右高度为1、2、1，左视图高度为2。求小正方体的总个数。

解：

俯视图只有一行三个位置。

主视图高度为1、2、1。

左视图高度为2（从侧面看最高为2）。

中间位置高度为2。

左右位置高度为1。

总数 = 1+2+1 = 4个。

答：共4个小正方体。

**例题5：** 一个几何体由若干个小正方体搭成，俯视图如下：
```
1 1
1 1
```
主视图从左到右高度为2、1，左视图从左到右高度为1、2。求小正方体的总个数。

解：

设俯视图四个位置为：
```
a b
c d
```

已知a = b = c = d = 1（俯视图每个位置至少1个）。

主视图：a和c的最大值为2，b和d的最大值为1。

左视图：a和b的最大值为1，c和d的最大值为2。

a和c中至少有一个为2。

b和d都为1。

a和b最大值为1，所以a = 1。

c和d最大值为2，所以c = 2。

但俯视图显示每个位置都是1。

这说明俯视图只显示位置，不显示高度。

a = 1，b = 1，c = 2，d = 1。

总数 = 1+1+2+1 = 5个。

答：共5个小正方体。

## 六、常见错误

**错误1：俯视图数字理解错误**

错误理解：俯视图中的数字表示位置编号。

正确理解：俯视图中的数字表示该位置小正方体的个数。

**错误2：最少最多个数搞混**

错误做法：最少和最多个数算成一样。

正确做法：最少取最小值，最多取最大值。

**错误3：主视图和左视图对应错误**

错误做法：主视图和左视图的方向搞反。

正确做法：主视图从正面看，左视图从左面看。

**错误4：小正方体个数计算错误**

错误做法：只算俯视图的格子数。

正确做法：每个位置的格子数要相加。

**错误5：高度限制忽略**

错误做法：不考虑主视图和左视图的高度限制。

正确做法：每个位置的高度不能超过视图限制。

## 七、练习题

**练习1：** 一个几何体由若干个小正方体搭成，俯视图如下（数字表示该位置小正方体的个数）：
```
3 2
1 2
```
求小正方体的总个数。

解：

左上角3个，右上角2个。

左下角1个，右下角2个。

总数 = 3+2+1+2 = 8个。

答：共8个小正方体。

**练习2：** 一个几何体由若干个小正方体搭成，俯视图是2×2的方格，主视图从左到右高度为3、2，左视图从左到右高度为2、3。求最少需要多少个小正方体。

解：

设俯视图四个位置为：
```
a b
c d
```

主视图：a和c的最大值为3，b和d的最大值为2。

左视图：a和b的最大值为2，c和d的最大值为3。

要使总数最少。

a = 2（满足左视图第一行）。

b = 2（满足主视图第二列）。

c = 3（满足左视图第二行）。

d = 1（满足主视图第二列和左视图第二行）。

最少 = 2+2+3+1 = 8个。

答：最少需要8个小正方体。

**练习3：** 一个几何体由若干个小正方体搭成，俯视图是2×2的方格，主视图从左到右高度为3、2，左视图从左到右高度为2、3。求最多可以有多少个小正方体。

左视图：a和b的最大值为2，c和d的最大值为3。

d = 2（不超过主视图第二列限制）。

最多 = 2+2+3+2 = 9个。

**练习4：** 一个几何体由若干个小正方体搭成，俯视图如下：
```
2 1 3
```
主视图从左到右高度为2、1、3，左视图高度为3。求小正方体的总个数。

解：

俯视图只有一行三个位置。

主视图高度为2、1、3。

左视图高度为3（从侧面看最高为3）。

三个位置高度分别为2、1、3。

总数 = 2+1+3 = 6个。

答：共6个小正方体。

**练习5：** 一个几何体由若干个小正方体搭成，俯视图如下：
```
1 1 1
1 1 1
```
主视图从左到右高度为2、1、2，左视图从左到右高度为1、2。求小正方体的总个数。

解：

设俯视图六个位置为：
```
a b c
d e f
```

主视图：a和d的最大值为2，b和e的最大值为1，c和f的最大值为2。

左视图：a、b、c的最大值为1，d、e、f的最大值为2。

b和e最大值为1，所以b = 1，e = 1。

a、b、c最大值为1，所以a = 1，c = 1。

a和d最大值为2，a = 1，所以d = 2。

c和f最大值为2，c = 1，所以f = 2。

总数 = 1+1+1+2+1+2 = 8个。

答：共8个小正方体。
