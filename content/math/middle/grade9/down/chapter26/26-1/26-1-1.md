# 26.1.1 反比例函数的定义

## 一、从生活实例引入

**路程一定时速度与时间的关系**

路程$s$一定。

速度$v$与时间$t$的关系是$v = \frac{s}{t}$。

时间越长，速度越小。

速度和时间成反比。

**矩形面积一定时长与宽的关系**

矩形面积$S$一定。

长$a$与宽$b$的关系是$a = \frac{S}{b}$。

宽越大，长越小。

长和宽成反比。

**工作总量一定时效率与时间的关系**

工作总量$W$一定。

效率$p$与时间$t$的关系是$p = \frac{W}{t}$。

时间越长，效率越低。

效率和时间成反比。

## 二、反比例函数的定义

**形如$y = \frac{k}{x}$（$k \neq 0$）的函数**

$k$是常数。

$k \neq 0$。

$x$是自变量。

$y$是因变量。

**例子**

$y = \frac{6}{x}$是反比例函数，$k = 6$。

$y = -\frac{3}{x}$是反比例函数，$k = -3$。

$y = \frac{1}{2x}$是反比例函数，$k = \frac{1}{2}$。

## 三、自变量$x$的取值范围

**$x \neq 0$**

分母不能为0。

所以$x \neq 0$。

自变量的取值范围是所有不等于0的实数。

**例子**

$y = \frac{6}{x}$中，$x$可以取任何不等于0的数。

$x = 1$时，$y = 6$。

$x = 2$时，$y = 3$。

$x = -3$时，$y = -2$。

## 四、反比例函数的三种表达形式

**$y = \frac{k}{x}$**

这是最常见的形式。

$k$是比例系数。

**$xy = k$**

两边同乘$x$得到。

两个变量的积是常数。

**$y = kx^{-1}$**

用负指数表示。

$x^{-1} = \frac{1}{x}$。

**三种形式等价**

$y = \frac{k}{x} \Leftrightarrow xy = k \Leftrightarrow y = kx^{-1}$。

## 五、反比例函数与正比例函数的对比

**正比例函数**

形式：$y = kx$（$k \neq 0$）。

图象是过原点的直线。

$y$随$x$增大而增大（$k > 0$）或减小（$k < 0$）。

**反比例函数**

形式：$y = \frac{k}{x}$（$k \neq 0$）。

图象是双曲线。

$y$随$x$的变化关系更复杂。

**对比**

正比例函数：$y$与$x$的比是常数。

反比例函数：$y$与$x$的积是常数。

## 六、判断一个函数是否为反比例函数

**判断方法**

看是否能化成$y = \frac{k}{x}$的形式。

$k$必须是不等于0的常数。

**例子**

$y = \frac{3}{x}$：是，$k = 3$。

$y = \frac{x}{3}$：不是，这是正比例函数。

$y = \frac{3}{x}+1$：不是，多了常数项。

$xy = 5$：是，$k = 5$。

## 七、例题讲解

**例题1：** 判断下列函数是否为反比例函数：①$y = \frac{2}{x}$；②$y = 2x$；③$y = \frac{2}{x}+1$；④$xy = 3$。

解：

①$y = \frac{2}{x}$：符合$y = \frac{k}{x}$的形式，$k = 2$，是反比例函数。

②$y = 2x$：这是正比例函数，不是反比例函数。

③$y = \frac{2}{x}+1$：多了常数项1，不是反比例函数。

④$xy = 3$：可以化成$y = \frac{3}{x}$，$k = 3$，是反比例函数。

答：①是，②不是，③不是，④是。

**例题2：** 已知$y$与$x$成反比例，当$x = 2$时，$y = 6$。求反比例函数的解析式。

解：

设$y = \frac{k}{x}$。

把$x = 2$，$y = 6$代入：

$6 = \frac{k}{2}$。

$k = 12$。

所以$y = \frac{12}{x}$。

答：反比例函数的解析式是$y = \frac{12}{x}$。

**例题3：** 已知反比例函数$y = \frac{k}{x}$的图象经过点$(3, -4)$。求$k$的值。

解：

把$x = 3$，$y = -4$代入$y = \frac{k}{x}$：

$-4 = \frac{k}{3}$。

$k = -12$。

答：$k$的值是$-12$。

**例题4：** 已知$y$与$x$成反比例，当$x = -3$时，$y = 4$。求当$x = 6$时，$y$的值。

解：

设$y = \frac{k}{x}$。

把$x = -3$，$y = 4$代入：

$4 = \frac{k}{-3}$。

$k = -12$。

所以$y = -\frac{12}{x}$。

当$x = 6$时，$y = -\frac{12}{6} = -2$。

答：当$x = 6$时，$y = -2$。

**例题5：** 判断函数$y = \frac{1}{x^2}$是否为反比例函数。

解：

反比例函数的形式是$y = \frac{k}{x}$。

$y = \frac{1}{x^2}$的分母是$x^2$，不是$x$。

不能化成$y = \frac{k}{x}$的形式。

所以不是反比例函数。

答：不是反比例函数。

## 八、常见错误

**错误1：$k = 0$的情况**

错误理解：$y = \frac{0}{x}$是反比例函数。

正确理解：$k \neq 0$，$y = \frac{0}{x}$不是反比例函数。

**错误2：自变量取值范围忽略**

错误做法：认为$x$可以取0。

正确做法：$x \neq 0$。

**错误3：形式判断错误**

错误理解：$y = \frac{1}{x}+1$是反比例函数。

正确理解：多了常数项，不是反比例函数。

**错误4：$k$的符号判断错误**

错误做法：$xy = -3$中$k = 3$。

正确做法：$xy = -3$中$k = -3$。

**错误5：反比例与正比例混淆**

错误理解：$y = \frac{k}{x}$是正比例函数。

正确理解：$y = \frac{k}{x}$是反比例函数，$y = kx$是正比例函数。

## 九、练习题

**练习1：** 判断下列函数是否为反比例函数：①$y = \frac{5}{x}$；②$y = \frac{x}{5}$；③$y = 5x^{-1}$；④$y = \frac{5}{x+1}$。

解：

①$y = \frac{5}{x}$：符合$y = \frac{k}{x}$的形式，$k = 5$，是反比例函数。

②$y = \frac{x}{5}$：这是正比例函数，不是反比例函数。

③$y = 5x^{-1}$：即$y = \frac{5}{x}$，是反比例函数。

④$y = \frac{5}{x+1}$：分母是$x+1$，不是$x$，不是反比例函数。

答：①是，②不是，③是，④不是。

**练习2：** 已知$y$与$x$成反比例，当$x = 4$时，$y = 3$。求反比例函数的解析式。

解：

设$y = \frac{k}{x}$。

把$x = 4$，$y = 3$代入：

$3 = \frac{k}{4}$。

$k = 12$。

所以$y = \frac{12}{x}$。

答：反比例函数的解析式是$y = \frac{12}{x}$。

**练习3：** 已知反比例函数$y = \frac{k}{x}$的图象经过点$(-2, 5)$。求$k$的值。

解：

把$x = -2$，$y = 5$代入$y = \frac{k}{x}$：

$5 = \frac{k}{-2}$。

$k = -10$。

答：$k$的值是$-10$。

**练习4：** 已知$y$与$x$成反比例，当$x = 2$时，$y = -6$。求当$x = -3$时，$y$的值。

解：

设$y = \frac{k}{x}$。

把$x = 2$，$y = -6$代入：

$-6 = \frac{k}{2}$。

$k = -12$。

所以$y = -\frac{12}{x}$。

当$x = -3$时，$y = -\frac{12}{-3} = 4$。

答：当$x = -3$时，$y = 4$。

**练习5：** 判断函数$y = \frac{3}{2x}$是否为反比例函数，如果是，求$k$的值。

解：

$y = \frac{3}{2x} = \frac{3/2}{x}$。

符合$y = \frac{k}{x}$的形式，$k = \frac{3}{2}$。

是反比例函数。

答：是反比例函数，$k = \frac{3}{2}$。
