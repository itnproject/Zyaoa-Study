# 26.1.2 反比例函数的图象和性质（一）

## 一、描点法画图象

**列表**

选取自变量$x$的一些值。

计算对应的函数值$y$。

注意$x$不能取0。

正负数都要取。

**描点**

在坐标系中描出这些点。

点要描得准确。

**连线**

用平滑的曲线连接各点。

从左到右依次连接。

**例子**

画$y = \frac{6}{x}$的图象。

列表：$x$取$-6, -3, -2, -1, 1, 2, 3, 6$。

对应$y$值：$-1, -2, -3, -6, 6, 3, 2, 1$。

描点连线。

## 二、双曲线的概念

**两支曲线**

反比例函数的图象由两支曲线组成。

这两支曲线叫做双曲线。

**关于原点对称**

两支曲线关于原点对称。

一支在第一象限，另一支在第三象限。

或一支在第二象限，另一支在第四象限。

**例子**

$y = \frac{6}{x}$的图象是双曲线。

两支分别在第一、三象限。

## 三、$k>0$时图象在一、三象限

**图象位置**

当$k>0$时。

双曲线的两支分别在第一象限和第三象限。

**例子**

$y = \frac{6}{x}$中，$k = 6 > 0$。

图象在第一、三象限。

$x>0$时，$y>0$。

$x<0$时，$y<0$。

## 四、$k<0$时图象在二、四象限

**图象位置**

当$k<0$时。

双曲线的两支分别在第二象限和第四象限。

**例子**

$y = -\frac{6}{x}$中，$k = -6 < 0$。

图象在第二、四象限。

$x>0$时，$y<0$。

$x<0$时，$y>0$。

## 五、双曲线无限接近坐标轴但永不相交

**渐近线**

$x$轴和$y$轴是双曲线的渐近线。

双曲线无限接近坐标轴。

但永远不会与坐标轴相交。

**原因**

$x \neq 0$，所以图象不与$y$轴相交。

$y = \frac{k}{x} \neq 0$，所以图象不与$x$轴相交。

**例子**

$y = \frac{6}{x}$中。

当$x$很大时，$y$很小，接近0。

当$x$很小时，$y$很大，接近无穷。

但$y$永远不等于0。

## 六、例题讲解

**例题1：** 用描点法画出$y = \frac{4}{x}$的图象，并指出图象所在的象限。

解：

列表：

$x$: $-4, -2, -1, 1, 2, 4$

$y$: $-1, -2, -4, 4, 2, 1$

描点并连线。

$k = 4 > 0$。

图象在第一、三象限。

答：图象在第一、三象限。

**例题2：** 已知反比例函数$y = \frac{k}{x}$的图象经过点$(2, 3)$。判断图象所在的象限。

解：

把$x = 2$，$y = 3$代入：

$3 = \frac{k}{2}$。

$k = 6$。

$k > 0$。

图象在第一、三象限。

答：图象在第一、三象限。

**例题3：** 反比例函数$y = \frac{m-2}{x}$的图象在第二、四象限。求$m$的取值范围。

解：

图象在第二、四象限。

说明$k < 0$。

即$m-2 < 0$。

$m < 2$。

答：$m$的取值范围是$m < 2$。

**例题4：** 判断点$(-3, 2)$是否在反比例函数$y = -\frac{6}{x}$的图象上。

解：

把$x = -3$代入$y = -\frac{6}{x}$：

$y = -\frac{6}{-3} = 2$。

计算得到的$y$值与点的纵坐标相等。

所以点在图象上。

答：点在图象上。

**例题5：** 反比例函数$y = \frac{k}{x}$的图象与$x$轴有交点吗？为什么？

解：

假设图象与$x$轴有交点。

则交点的纵坐标$y = 0$。

代入$y = \frac{k}{x}$得$0 = \frac{k}{x}$。

这要求$k = 0$。

但反比例函数要求$k \neq 0$。

矛盾。

所以图象与$x$轴没有交点。

答：没有交点，因为$y = \frac{k}{x} \neq 0$。

## 七、常见错误

**错误1：把两支曲线连在一起**

错误做法：用曲线把第一象限和第三象限的分支连起来。

正确做法：两支曲线是分开的，不能连接。

**错误2：图象与坐标轴相交**

错误做法：画图时让曲线碰到坐标轴。

正确做法：曲线无限接近坐标轴，但永不相交。

**错误3：象限判断错误**

错误做法：$k>0$时认为图象在二、四象限。

正确做法：$k>0$时图象在一、三象限。

**错误4：描点不对称**

错误做法：只取正数点，不取负数点。

正确做法：正负数都要取，保证图象完整。

**错误5：连线不平滑**

错误做法：用折线连接各点。

正确做法：用平滑的曲线连接各点。

## 八、练习题

**练习1：** 用描点法画出$y = -\frac{4}{x}$的图象，并指出图象所在的象限。

解：

列表：

$x$: $-4, -2, -1, 1, 2, 4$

$y$: $1, 2, 4, -4, -2, -1$

描点并连线。

$k = -4 < 0$。

图象在第二、四象限。

答：图象在第二、四象限。

**练习2：** 已知反比例函数$y = \frac{k}{x}$的图象经过点$(-2, -3)$。判断图象所在的象限。

解：

把$x = -2$，$y = -3$代入：

$-3 = \frac{k}{-2}$。

$k = 6$。

$k > 0$。

图象在第一、三象限。

答：图象在第一、三象限。

**练习3：** 反比例函数$y = \frac{3-m}{x}$的图象在第一、三象限。求$m$的取值范围。

解：

图象在第一、三象限。

说明$k > 0$。

即$3-m > 0$。

$m < 3$。

答：$m$的取值范围是$m < 3$。

**练习4：** 判断点$(4, -1)$是否在反比例函数$y = -\frac{4}{x}$的图象上。

解：

把$x = 4$代入$y = -\frac{4}{x}$：

$y = -\frac{4}{4} = -1$。

计算得到的$y$值与点的纵坐标相等。

所以点在图象上。

答：点在图象上。

**练习5：** 反比例函数$y = \frac{k}{x}$的图象与$y$轴有交点吗？为什么？

解：

假设图象与$y$轴有交点。

则交点的横坐标$x = 0$。

但反比例函数中$x \neq 0$。

矛盾。

所以图象与$y$轴没有交点。

答：没有交点，因为$x \neq 0$。
