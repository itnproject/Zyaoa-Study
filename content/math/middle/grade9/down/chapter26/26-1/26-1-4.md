# 26.1.4 反比例函数中 k 的几何意义

## 一、矩形面积 = |k|

**过双曲线上任意一点作x轴、y轴的垂线**

设点$P(x, y)$在双曲线$y = \frac{k}{x}$上。

过点$P$作$x$轴的垂线，垂足为$A$。

过点$P$作$y$轴的垂线，垂足为$B$。

则矩形$OAPB$的面积 = $|x| \times |y| = |xy| = |k|$。

**例子**

$y = \frac{6}{x}$上一点$P(2, 3)$。

矩形面积 = $2 \times 3 = 6 = |k|$。

## 二、三角形面积 = |k|/2

**过双曲线上任意一点作x轴或y轴的垂线**

设点$P(x, y)$在双曲线$y = \frac{k}{x}$上。

过点$P$作$x$轴的垂线，垂足为$A$。

则$\triangle OAP$的面积 = $\frac{1}{2} \times |x| \times |y| = \frac{|k|}{2}$。

**例子**

$y = \frac{6}{x}$上一点$P(2, 3)$。

$\triangle OAP$的面积 = $\frac{1}{2} \times 2 \times 3 = 3 = \frac{|k|}{2}$。

## 三、利用k的几何意义求面积

**矩形面积**

无论点$P$在双曲线的哪个位置。

矩形面积始终等于$|k|$。

**三角形面积**

无论点$P$在双曲线的哪个位置。

三角形面积始终等于$\frac{|k|}{2}$。

**例子**

$y = \frac{8}{x}$上任意一点$P$。

过$P$作坐标轴的垂线。

矩形面积 = 8。

三角形面积 = 4。

## 四、利用面积求k的值

**已知面积求k**

矩形面积 = $|k|$。

三角形面积 = $\frac{|k|}{2}$。

由面积可以求出$|k|$。

再根据图象所在象限确定$k$的符号。

**例子**

已知矩形面积为6。

$|k| = 6$。

图象在一、三象限，$k > 0$。

所以$k = 6$。

## 五、例题讲解

**例题1：** 点$P$是反比例函数$y = \frac{6}{x}$图象上的一点，过点$P$作$x$轴、$y$轴的垂线，垂足分别为$A$、$B$。求矩形$OAPB$的面积。

解：

矩形面积 = $|k|$。

$k = 6$。

矩形面积 = 6。

答：矩形$OAPB$的面积为6。

**例题2：** 点$P$是反比例函数$y = -\frac{8}{x}$图象上的一点，过点$P$作$x$轴的垂线，垂足为$A$。求$\triangle OAP$的面积。

解：

三角形面积 = $\frac{|k|}{2}$。

$k = -8$，$|k| = 8$。

三角形面积 = $\frac{8}{2} = 4$。

答：$\triangle OAP$的面积为4。

**例题3：** 点$P$是反比例函数$y = \frac{k}{x}$图象上的一点，过点$P$作$x$轴、$y$轴的垂线，垂足分别为$A$、$B$。已知矩形$OAPB$的面积为12，且图象在第二、四象限。求$k$的值。

解：

矩形面积 = $|k| = 12$。

图象在第二、四象限，说明$k < 0$。

所以$k = -12$。

答：$k$的值是$-12$。

**例题4：** 如图，点$A$、$B$在反比例函数$y = \frac{4}{x}$的图象上，分别过点$A$、$B$作$x$轴的垂线，垂足分别为$C$、$D$。比较$\triangle OAC$和$\triangle OBD$的面积。

解：

$\triangle OAC$的面积 = $\frac{|k|}{2} = \frac{4}{2} = 2$。

$\triangle OBD$的面积 = $\frac{|k|}{2} = \frac{4}{2} = 2$。

两个三角形面积相等。

答：$\triangle OAC$和$\triangle OBD$的面积相等，都为2。

**例题5：** 点$P$是反比例函数$y = \frac{k}{x}$图象上的一点，过点$P$作$x$轴的垂线，垂足为$A$。已知$\triangle OAP$的面积为3，且图象在第一、三象限。求反比例函数的解析式。

解：

三角形面积 = $\frac{|k|}{2} = 3$。

$|k| = 6$。

图象在第一、三象限，说明$k > 0$。

所以$k = 6$。

反比例函数的解析式为$y = \frac{6}{x}$。

答：反比例函数的解析式为$y = \frac{6}{x}$。

## 六、常见错误

**错误1：忘记取绝对值**

错误做法：矩形面积 = $k$。

正确做法：矩形面积 = $|k|$。

**错误2：三角形面积公式记错**

错误做法：三角形面积 = $|k|$。

正确做法：三角形面积 = $\frac{|k|}{2}$。

**错误3：k的符号判断错误**

错误做法：面积为6，所以$k = 6$。

正确做法：面积为6，$|k| = 6$，还需根据象限判断符号。

**错误4：点的位置理解错误**

错误理解：只有第一象限的点才满足这个性质。

正确理解：双曲线上任意一点都满足这个性质。

**错误5：面积计算错误**

错误做法：矩形面积 = $x \times y$（不考虑符号）。

正确做法：矩形面积 = $|x| \times |y| = |k|$。
