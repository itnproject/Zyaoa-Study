# 26.1.3 反比例函数的图象和性质（二）

## 一、增减性

**$k>0$时在每个象限内$y$随$x$增大而减小**

在第一象限内。

$x$增大，$y$减小。

在第三象限内。

$x$增大，$y$减小。

**例子**

$y = \frac{6}{x}$中，$k = 6 > 0$。

在第一象限：$x$从1到2，$y$从6到3，减小。

在第三象限：$x$从$-2$到$-1$，$y$从$-3$到$-6$，减小。

**$k<0$时在每个象限内$y$随$x$增大而增大**

在第二象限内。

$x$增大，$y$增大。

在第四象限内。

$x$增大，$y$增大。

**例子**

$y = -\frac{6}{x}$中，$k = -6 < 0$。

在第二象限：$x$从$-2$到$-1$，$y$从3到6，增大。

在第四象限：$x$从1到2，$y$从$-6$到$-3$，增大。

## 二、"在每个象限内"这个前提的重要性

**不能跨象限比较**

不能说"$y$随$x$增大而减小"。

必须说"在每个象限内，$y$随$x$增大而减小"。

**例子**

$y = \frac{6}{x}$中。

$x = -1$时，$y = -6$。

$x = 1$时，$y = 6$。

$x$从$-1$增大到1，$y$从$-6$增大到6。

这说明跨象限比较时，增减性不成立。

**正确表述**

$k>0$时，在每个象限内，$y$随$x$增大而减小。

$k<0$时，在每个象限内，$y$随$x$增大而增大。

## 三、$|k|$越大，双曲线离原点越远

**$|k|$的意义**

$|k|$越大，双曲线离原点越远。

$|k|$越小，双曲线离原点越近。

**例子**

$y = \frac{1}{x}$和$y = \frac{6}{x}$。

$x = 1$时，$y = \frac{1}{x}$的$y = 1$，$y = \frac{6}{x}$的$y = 6$。

$y = \frac{6}{x}$的图象离原点更远。

## 四、反比例函数的对称性

**关于原点中心对称**

双曲线关于原点对称。

点$(x, y)$在图象上，则点$(-x, -y)$也在图象上。

**关于$y = x$轴对称**

当$k>0$时，双曲线关于直线$y = x$对称。

点$(a, b)$在图象上，则点$(b, a)$也在图象上。

**关于$y = -x$轴对称**

当$k<0$时，双曲线关于直线$y = -x$对称。

点$(a, b)$在图象上，则点$(-b, -a)$也在图象上。

## 五、例题讲解

**例题1：** 已知点$A(-2, y_1)$、$B(-1, y_2)$、$C(3, y_3)$都在反比例函数$y = \frac{6}{x}$的图象上。比较$y_1$、$y_2$、$y_3$的大小。

解：

$k = 6 > 0$。

$A$、$B$在第三象限，$C$在第一象限。

在第三象限内，$y$随$x$增大而减小。

$-2 < -1$，所以$y_1 > y_2$。

第一象限的$y$值为正，第三象限的$y$值为负。

所以$y_3$最大。

$y_1 = \frac{6}{-2} = -3$，$y_2 = \frac{6}{-1} = -6$，$y_3 = \frac{6}{3} = 2$。

$y_3 > y_1 > y_2$。

答：$y_3 > y_1 > y_2$。

**例题2：** 已知点$A(-3, y_1)$、$B(2, y_2)$、$C(4, y_3)$都在反比例函数$y = -\frac{12}{x}$的图象上。比较$y_1$、$y_2$、$y_3$的大小。

解：

$k = -12 < 0$。

$A$在第二象限，$B$、$C$在第四象限。

在第四象限内，$y$随$x$增大而增大。

$2 < 4$，所以$y_2 < y_3$。

第二象限的$y$值为正，第四象限的$y$值为负。

所以$y_1$最大。

$y_1 = -\frac{12}{-3} = 4$，$y_2 = -\frac{12}{2} = -6$，$y_3 = -\frac{12}{4} = -3$。

$y_1 > y_3 > y_2$。

答：$y_1 > y_3 > y_2$。

**例题3：** 反比例函数$y = \frac{m+2}{x}$的图象在每个象限内$y$随$x$增大而增大。求$m$的取值范围。

解：

在每个象限内$y$随$x$增大而增大。

说明$k < 0$。

即$m+2 < 0$。

$m < -2$。

答：$m$的取值范围是$m < -2$。

**例题4：** 已知反比例函数$y = \frac{k}{x}$的图象经过点$A(2, 4)$。判断该图象关于哪条直线对称，并判断点$B(-4, -2)$是否在图象上。

解：

把$(2, 4)$代入：$4 = \frac{k}{2}$，$k = 8$。

$k = 8 > 0$。

图象关于直线$y = x$对称。

点$A(2, 4)$关于原点的对称点是$(-2, -4)$。

把$x = -4$代入$y = \frac{8}{x}$：$y = \frac{8}{-4} = -2$。

所以点$B(-4, -2)$在图象上。

答：图象关于直线$y = x$对称，点$B(-4, -2)$在图象上。

**例题5：** 已知反比例函数$y = \frac{k}{x}$的图象关于直线$y = x$对称，且经过点$(2, 3)$。求$k$的值，并判断点$(3, 2)$是否在图象上。

解：

图象关于直线$y = x$对称，说明$k > 0$。

把$(2, 3)$代入：$3 = \frac{k}{2}$，$k = 6$。

因为图象关于$y = x$对称，点$(2, 3)$在图象上。

所以点$(3, 2)$也在图象上。

验证：$y = \frac{6}{3} = 2$，正确。

答：$k = 6$，点$(3, 2)$在图象上。

## 六、常见错误

**错误1：跨象限比较大小**

错误做法：直接比较不同象限的点的纵坐标。

正确做法：先判断象限，再比较。

**错误2：增减性表述不完整**

错误表述：$k>0$时，$y$随$x$增大而减小。

正确表述：$k>0$时，在每个象限内，$y$随$x$增大而减小。

**错误3：对称性混淆**

错误理解：$k<0$时关于$y = x$对称。

正确理解：$k>0$时关于$y = x$对称，$k<0$时关于$y = -x$对称。

**错误4：$|k|$的意义理解错误**

错误理解：$|k|$越大，双曲线离原点越近。

正确理解：$|k|$越大，双曲线离原点越远。

**错误5：点的位置判断错误**

错误做法：不计算就判断点所在的象限。

正确做法：代入计算或根据$k$的符号判断。

## 七、练习题

**练习1：** 已知点$A(-3, y_1)$、$B(-2, y_2)$、$C(4, y_3)$都在反比例函数$y = \frac{12}{x}$的图象上。比较$y_1$、$y_2$、$y_3$的大小。

解：

$k = 12 > 0$。

$A$、$B$在第三象限，$C$在第一象限。

在第三象限内，$y$随$x$增大而减小。

$-3 < -2$，所以$y_1 > y_2$。

第一象限的$y$值为正，第三象限的$y$值为负。

所以$y_3$最大。

$y_1 = \frac{12}{-3} = -4$，$y_2 = \frac{12}{-2} = -6$，$y_3 = \frac{12}{4} = 3$。

$y_3 > y_1 > y_2$。

答：$y_3 > y_1 > y_2$。

**练习2：** 已知点$A(-4, y_1)$、$B(3, y_2)$、$C(6, y_3)$都在反比例函数$y = -\frac{12}{x}$的图象上。比较$y_1$、$y_2$、$y_3$的大小。

解：

$k = -12 < 0$。

$A$在第二象限，$B$、$C$在第四象限。

在第四象限内，$y$随$x$增大而增大。

$3 < 6$，所以$y_2 < y_3$。

第二象限的$y$值为正，第四象限的$y$值为负。

所以$y_1$最大。

$y_1 = -\frac{12}{-4} = 3$，$y_2 = -\frac{12}{3} = -4$，$y_3 = -\frac{12}{6} = -2$。

$y_1 > y_3 > y_2$。

答：$y_1 > y_3 > y_2$。

**练习3：** 反比例函数$y = \frac{3-m}{x}$的图象在每个象限内$y$随$x$增大而减小。求$m$的取值范围。

解：

在每个象限内$y$随$x$增大而减小。

说明$k > 0$。

即$3-m > 0$。

$m < 3$。

答：$m$的取值范围是$m < 3$。

**练习4：** 比较反比例函数$y = \frac{2}{x}$和$y = \frac{5}{x}$的图象，哪个离原点更远？

解：

$|k_1| = 2$，$|k_2| = 5$。

$|k_2| > |k_1|$。

$|k|$越大，双曲线离原点越远。

所以$y = \frac{5}{x}$的图象离原点更远。

答：$y = \frac{5}{x}$的图象离原点更远。

**练习5：** 已知反比例函数$y = \frac{k}{x}$的图象经过点$(4, 2)$。判断该图象关于哪条直线对称，并判断点$(2, 4)$是否在图象上。
