# 26.3.1 反比例函数与一次函数的图象共存问题

## 一、根据k和b的符号判断图象所在象限

**反比例函数$y = \frac{k}{x}$**

$k>0$时，图象在一、三象限。

$k<0$时，图象在二、四象限。

**一次函数$y = kx+b$**

$k>0$，$b>0$时，图象过一、二、三象限。

$k>0$，$b<0$时，图象过一、三、四象限。

$k<0$，$b>0$时，图象过一、二、四象限。

$k<0$，$b<0$时，图象过二、三、四象限。

## 二、反比例函数与一次函数图象在同一坐标系中的位置关系

**$k$同号时**

反比例函数$y = \frac{k}{x}$与一次函数$y = kx+b$。

$k$的符号相同。

图象有特定的位置关系。

**$k$异号时**

反比例函数$y = \frac{k_1}{x}$与一次函数$y = k_2 x+b$。

$k_1$与$k_2$符号不同。

图象有不同的位置关系。

## 三、利用图象特征排除错误选项

**观察法**

观察反比例函数图象所在象限。

判断$k$的符号。

观察一次函数图象的倾斜方向。

判断$k$的符号。

观察一次函数与$y$轴的交点。

判断$b$的符号。

**排除法**

根据$k$和$b$的符号。

排除不符合的选项。

## 四、例题讲解

**例题1：** 在同一坐标系中，反比例函数$y = \frac{k}{x}$与一次函数$y = kx+1$（$k \neq 0$）的图象可能是（ ）。

A. 反比例函数在一、三象限，一次函数过一、二、三象限

B. 反比例函数在一、三象限，一次函数过二、三、四象限

C. 反比例函数在二、四象限，一次函数过一、二、三象限

D. 反比例函数在二、四象限，一次函数过一、三、四象限

解：

若$k>0$，反比例函数在一、三象限。

一次函数$y = kx+1$中，$k>0$，$b = 1>0$。

一次函数过一、二、三象限。

选项A符合。

若$k<0$，反比例函数在二、四象限。

一次函数$y = kx+1$中，$k<0$，$b = 1>0$。

一次函数过一、二、四象限。

没有选项符合。

答：选A。

**例题2：** 在同一坐标系中，反比例函数$y = \frac{2}{x}$与一次函数$y = -x+3$的图象有几个交点？

解：

反比例函数$y = \frac{2}{x}$在一、三象限。

一次函数$y = -x+3$过一、二、四象限。

两个图象在第一象限可能有交点。

联立方程：$\frac{2}{x} = -x+3$。

$2 = -x^2+3x$。

$x^2-3x+2 = 0$。

$(x-1)(x-2) = 0$。

$x = 1$或$x = 2$。

两个解都在第一象限。

答：有2个交点。

**例题3：** 已知反比例函数$y = \frac{k}{x}$与一次函数$y = 2x+b$的图象都经过点$(1, 2)$。求$k$和$b$的值。

解：

把$(1, 2)$代入$y = \frac{k}{x}$：

$2 = \frac{k}{1}$，$k = 2$。

把$(1, 2)$代入$y = 2x+b$：

$2 = 2 \times 1+b$，$b = 0$。

答：$k = 2$，$b = 0$。

**例题4：** 在同一坐标系中，反比例函数$y = \frac{k}{x}$与一次函数$y = -kx+2$（$k \neq 0$）的图象可能是（ ）。

A. 反比例函数在一、三象限，一次函数过一、二、四象限

B. 反比例函数在一、三象限，一次函数过一、二、三象限

C. 反比例函数在二、四象限，一次函数过一、二、三象限

D. 反比例函数在二、四象限，一次函数过二、三、四象限

解：

若$k>0$，反比例函数在一、三象限。

一次函数$y = -kx+2$中，$-k<0$，$b = 2>0$。

一次函数过一、二、四象限。

选项A符合。

若$k<0$，反比例函数在二、四象限。

一次函数$y = -kx+2$中，$-k>0$，$b = 2>0$。

一次函数过一、二、三象限。

选项C符合。

答：选A或C。

**例题5：** 已知反比例函数$y = \frac{k}{x}$（$k>0$）与一次函数$y = x+b$的图象没有交点。求$b$的取值范围。

解：

联立方程：$\frac{k}{x} = x+b$。

$k = x^2+bx$。

$x^2+bx-k = 0$。

没有交点，说明方程无实数根。

判别式$\Delta = b^2-4 \times 1 \times (-k) = b^2+4k < 0$。

但$k>0$，$b^2 \geq 0$。

$b^2+4k > 0$恒成立。

所以方程一定有实数根。

两个图象一定有交点。

答：不存在这样的$b$值。

## 五、常见错误

**错误1：k的符号判断错误**

错误做法：不根据图象判断$k$的符号。

正确做法：根据图象所在象限判断$k$的符号。

**错误2：一次函数象限判断错误**

错误做法：$k>0$，$b>0$时认为过一、三、四象限。

正确做法：$k>0$，$b>0$时过一、二、三象限。

**错误3：交点个数判断错误**

错误做法：只看图象就判断交点个数。

正确做法：联立方程，用判别式判断。

**错误4：忽略k≠0的条件**

错误做法：不考虑$k \neq 0$。

正确做法：$k \neq 0$是反比例函数的定义条件。

**错误5：图象位置关系混淆**

错误做法：把反比例函数和一次函数的位置关系搞混。

正确做法：分别判断两个函数的位置。

## 六、练习题

**练习1：** 在同一坐标系中，反比例函数$y = \frac{k}{x}$与一次函数$y = kx-1$（$k \neq 0$）的图象可能是（ ）。

A. 反比例函数在一、三象限，一次函数过一、三、四象限

B. 反比例函数在一、三象限，一次函数过一、二、三象限

C. 反比例函数在二、四象限，一次函数过一、二、四象限

D. 反比例函数在二、四象限，一次函数过二、三、四象限

解：

若$k>0$，反比例函数在一、三象限。

一次函数$y = kx-1$中，$k>0$，$b = -1<0$。

一次函数过一、三、四象限。

选项A符合。

若$k<0$，反比例函数在二、四象限。

一次函数$y = kx-1$中，$k<0$，$b = -1<0$。

一次函数过二、三、四象限。

选项D符合。

答：选A或D。

**练习2：** 在同一坐标系中，反比例函数$y = \frac{3}{x}$与一次函数$y = -x+4$的图象有几个交点？

解：

联立方程：$\frac{3}{x} = -x+4$。

$3 = -x^2+4x$。

$x^2-4x+3 = 0$。

$(x-1)(x-3) = 0$。

$x = 1$或$x = 3$。

两个解都在第一象限。

答：有2个交点。

**练习3：** 已知反比例函数$y = \frac{k}{x}$与一次函数$y = 3x-1$的图象都经过点$(1, 2)$。求$k$的值。

解：

把$(1, 2)$代入$y = \frac{k}{x}$：

$2 = \frac{k}{1}$，$k = 2$。

答：$k = 2$。

**练习4：** 在同一坐标系中，反比例函数$y = \frac{k}{x}$与一次函数$y = -kx-2$（$k \neq 0$）的图象可能是（ ）。

A. 反比例函数在一、三象限，一次函数过二、三、四象限

B. 反比例函数在一、三象限，一次函数过一、二、三象限

C. 反比例函数在二、四象限，一次函数过一、二、四象限

D. 反比例函数在二、四象限，一次函数过一、三、四象限

解：

若$k>0$，反比例函数在一、三象限。

一次函数$y = -kx-2$中，$-k<0$，$b = -2<0$。

一次函数过二、三、四象限。

选项A符合。

若$k<0$，反比例函数在二、四象限。

一次函数$y = -kx-2$中，$-k>0$，$b = -2<0$。

一次函数过一、三、四象限。

选项D符合。

答：选A或D。

**练习5：** 已知反比例函数$y = \frac{k}{x}$（$k<0$）与一次函数$y = x+b$的图象没有交点。求$b$的取值范围。

解：

联立方程：$\frac{k}{x} = x+b$。

$k = x^2+bx$。

$x^2+bx-k = 0$。

没有交点，说明方程无实数根。

判别式$\Delta = b^2-4 \times 1 \times (-k) = b^2+4k < 0$。

$b^2 < -4k$。

因为$k<0$，$-4k>0$。

$-\sqrt{-4k} < b < \sqrt{-4k}$。

答：$b$的取值范围是$-\sqrt{-4k} < b < \sqrt{-4k}$。
