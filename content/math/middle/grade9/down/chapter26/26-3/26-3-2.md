# 26.3.2 反比例函数与一次函数的交点问题

## 一、联立方程求交点坐标

**方法**

联立反比例函数和一次函数的方程。

消去$y$，得到关于$x$的方程。

解方程求出$x$的值。

代入求$y$的值。

**例子**

$y = \frac{6}{x}$与$y = x+1$。

联立：$\frac{6}{x} = x+1$。

$6 = x^2+x$。

$x^2+x-6 = 0$。

$(x+3)(x-2) = 0$。

$x = -3$或$x = 2$。

$x = -3$时，$y = -2$。

$x = 2$时，$y = 3$。

交点为$(-3, -2)$和$(2, 3)$。

## 二、利用交点坐标求函数解析式

**已知交点求反比例函数**

设$y = \frac{k}{x}$。

把交点坐标代入。

求出$k$的值。

**已知交点求一次函数**

设$y = kx+b$。

把两个交点坐标代入。

解方程组求出$k$和$b$。

**例子**

已知交点$(2, 3)$和$(-3, -2)$。

反比例函数：$3 = \frac{k}{2}$，$k = 6$，$y = \frac{6}{x}$。

一次函数：$\begin{cases} 3 = 2k+b \\ -2 = -3k+b \end{cases}$。

解得$k = 1$，$b = 1$，$y = x+1$。

## 三、利用图象比较函数值的大小

**方法**

画出两个函数的图象。

找到交点。

观察在交点两侧哪个函数图象在上方。

**例子**

$y = \frac{6}{x}$与$y = x+1$的交点为$(-3, -2)$和$(2, 3)$。

当$x<-3$时，一次函数在上方，$x+1 > \frac{6}{x}$。

当$-3<x<0$时，反比例函数在上方，$\frac{6}{x} > x+1$。

当$0<x<2$时，反比例函数在上方，$\frac{6}{x} > x+1$。

当$x>2$时，一次函数在上方，$x+1 > \frac{6}{x}$。

## 四、反比例函数与一次函数围成的图形面积

**方法**

找到交点坐标。

确定图形范围。

用割补法求面积。

**初中方法**

利用三角形和梯形面积公式。

分割图形为规则图形。

分别计算面积后相加或相减。

## 五、例题讲解

**例题1：** 求反比例函数$y = \frac{8}{x}$与一次函数$y = 2x-6$的交点坐标。

解：

联立方程：$\frac{8}{x} = 2x-6$。

$8 = 2x^2-6x$。

$2x^2-6x-8 = 0$。

$x^2-3x-4 = 0$。

$(x-4)(x+1) = 0$。

$x = 4$或$x = -1$。

$x = 4$时，$y = \frac{8}{4} = 2$。

$x = -1$时，$y = \frac{8}{-1} = -8$。

答：交点坐标为$(4, 2)$和$(-1, -8)$。

**例题2：** 已知反比例函数$y = \frac{k}{x}$与一次函数$y = x+3$的图象交于点$A(1, m)$和点$B(n, -1)$。求$k$的值和一次函数的解析式。

解：

点$A(1, m)$在一次函数上：$m = 1+3 = 4$。

点$A(1, 4)$在反比例函数上：$4 = \frac{k}{1}$，$k = 4$。

点$B(n, -1)$在一次函数上：$-1 = n+3$，$n = -4$。

验证：点$B(-4, -1)$在反比例函数上：$-1 = \frac{4}{-4}$，正确。

答：$k = 4$，一次函数解析式为$y = x+3$。

**例题3：** 已知反比例函数$y = \frac{6}{x}$与一次函数$y = x-1$的图象交于点$A$和点$B$。利用图象比较$\frac{6}{x}$与$x-1$的大小。

解：

联立方程：$\frac{6}{x} = x-1$。

$6 = x^2-x$。

$x^2-x-6 = 0$。

$(x-3)(x+2) = 0$。

$x = 3$或$x = -2$。

交点为$(-2, -3)$和$(3, 2)$。

当$x<-2$时，$x-1 > \frac{6}{x}$。

当$-2<x<0$时，$\frac{6}{x} > x-1$。

当$0<x<3$时，$\frac{6}{x} > x-1$。

当$x>3$时，$x-1 > \frac{6}{x}$。

答：见上述分析。

**例题4：** 已知反比例函数$y = \frac{4}{x}$与一次函数$y = x$的图象交于点$A$和点$B$。求$\triangle OAB$的面积（$O$为原点）。

解：

联立方程：$\frac{4}{x} = x$。

$x^2 = 4$。

$x = 2$或$x = -2$。

交点为$A(2, 2)$和$B(-2, -2)$。

$O(0, 0)$，$A(2, 2)$，$B(-2, -2)$。

$A$和$B$关于原点对称。

$O$、$A$、$B$三点共线。

$\triangle OAB$的面积为0。

答：$\triangle OAB$的面积为0（三点共线）。

**例题5：** 已知反比例函数$y = \frac{6}{x}$与一次函数$y = -x+5$的图象交于点$A$和点$B$。求$\triangle OAB$的面积（$O$为原点）。

解：

联立方程：$\frac{6}{x} = -x+5$。

$6 = -x^2+5x$。

$x^2-5x+6 = 0$。

$(x-2)(x-3) = 0$。

$x = 2$或$x = 3$。

交点为$A(2, 3)$和$B(3, 2)$。

用割补法求面积。

过$A$、$B$分别作$x$轴的垂线，垂足为$C(2, 0)$、$D(3, 0)$。

梯形$ACDB$的面积 = $\frac{1}{2} \times (3+2) \times (3-2) = \frac{5}{2}$。

$\triangle OAC$的面积 = $\frac{1}{2} \times 2 \times 3 = 3$。

$\triangle OBD$的面积 = $\frac{1}{2} \times 3 \times 2 = 3$。

$\triangle OAB$的面积 = $S_{\triangle OAC}+S_{\text{梯形}ACDB}-S_{\triangle OBD} = 3+\frac{5}{2}-3 = \frac{5}{2}$。

答：$\triangle OAB$的面积为$\frac{5}{2}$。

## 六、常见错误

**错误1：联立方程解错**

错误做法：$\frac{k}{x} = kx+b$直接化简错误。

正确做法：两边同乘$x$，化为一元二次方程。

**错误2：交点坐标代入错误**

错误做法：把$x$和$y$的值代反。

正确做法：仔细对应$x$和$y$的值。

**错误3：函数值大小比较错误**

错误做法：不考虑$x$的取值范围。

正确做法：分区间讨论。

**错误4：面积计算错误**

错误做法：直接用公式，不考虑图形形状。

正确做法：用割补法或分割法求面积。

**错误5：三点共线未判断**

错误做法：三点共线时还计算面积。

正确做法：先判断是否共线。

## 七、练习题

**练习1：** 求反比例函数$y = \frac{12}{x}$与一次函数$y = 3x-9$的交点坐标。

解：

联立方程：$\frac{12}{x} = 3x-9$。

$12 = 3x^2-9x$。

$3x^2-9x-12 = 0$。

$x^2-3x-4 = 0$。

$(x-4)(x+1) = 0$。

$x = 4$或$x = -1$。

$x = 4$时，$y = \frac{12}{4} = 3$。

$x = -1$时，$y = \frac{12}{-1} = -12$。

答：交点坐标为$(4, 3)$和$(-1, -12)$。

**练习2：** 已知反比例函数$y = \frac{k}{x}$与一次函数$y = 2x-2$的图象交于点$A(2, m)$和点$B(n, -4)$。求$k$的值。

解：

点$A(2, m)$在一次函数上：$m = 2 \times 2-2 = 2$。

点$A(2, 2)$在反比例函数上：$2 = \frac{k}{2}$，$k = 4$。

验证：点$B(n, -4)$在一次函数上：$-4 = 2n-2$，$n = -1$。

点$B(-1, -4)$在反比例函数上：$-4 = \frac{4}{-1}$，正确。

答：$k = 4$。

**练习3：** 已知反比例函数$y = \frac{4}{x}$与一次函数$y = x-3$的图象交于点$A$和点$B$。利用图象比较$\frac{4}{x}$与$x-3$的大小。

解：

联立方程：$\frac{4}{x} = x-3$。

$4 = x^2-3x$。

$x^2-3x-4 = 0$。

$(x-4)(x+1) = 0$。

$x = 4$或$x = -1$。

交点为$(-1, -4)$和$(4, 1)$。

当$x<-1$时，$x-3 > \frac{4}{x}$。

当$-1<x<0$时，$\frac{4}{x} > x-3$。

当$0<x<4$时，$\frac{4}{x} > x-3$。

当$x>4$时，$x-3 > \frac{4}{x}$。

答：见上述分析。

**练习4：** 已知反比例函数$y = \frac{2}{x}$与一次函数$y = -x+3$的图象交于点$A$和点$B$。求$\triangle OAB$的面积（$O$为原点）。

解：

联立方程：$\frac{2}{x} = -x+3$。

$2 = -x^2+3x$。

$x^2-3x+2 = 0$。

$(x-1)(x-2) = 0$。

$x = 1$或$x = 2$。

交点为$A(1, 2)$和$B(2, 1)$。

过$A$、$B$分别作$x$轴的垂线，垂足为$C(1, 0)$、$D(2, 0)$。

梯形$ACDB$的面积 = $\frac{1}{2} \times (2+1) \times (2-1) = \frac{3}{2}$。

$\triangle OAC$的面积 = $\frac{1}{2} \times 1 \times 2 = 1$。

$\triangle OBD$的面积 = $\frac{1}{2} \times 2 \times 1 = 1$。

$\triangle OAB$的面积 = $S_{\triangle OAC}+S_{\text{梯形}ACDB}-S_{\triangle OBD} = 1+\frac{3}{2}-1 = \frac{3}{2}$。

答：$\triangle OAB$的面积为$\frac{3}{2}$。

**练习5：** 已知反比例函数$y = \frac{8}{x}$与一次函数$y = -x+6$的图象交于点$A$和点$B$。求$\triangle OAB$的面积（$O$为原点）。

解：

联立方程：$\frac{8}{x} = -x+6$。

$8 = -x^2+6x$。

$x^2-6x+8 = 0$。

$(x-2)(x-4) = 0$。

$x = 2$或$x = 4$。

交点为$A(2, 4)$和$B(4, 2)$。

过$A$、$B$分别作$x$轴的垂线，垂足为$C(2, 0)$、$D(4, 0)$。

梯形$ACDB$的面积 = $\frac{1}{2} \times (4+2) \times (4-2) = 6$。

$\triangle OAC$的面积 = $\frac{1}{2} \times 2 \times 4 = 4$。

$\triangle OBD$的面积 = $\frac{1}{2} \times 4 \times 2 = 4$。

$\triangle OAB$的面积 = $S_{\triangle OAC}+S_{\text{梯形}ACDB}-S_{\triangle OBD} = 4+6-4 = 6$。

答：$\triangle OAB$的面积为6。
