# 26.2.1 反比例函数与实际应用（一）

## 一、行程问题

**路程一定，速度与时间成反比**

路程$s$一定。

速度$v$与时间$t$的关系是$v = \frac{s}{t}$。

这是反比例函数关系。

**例子**

甲乙两地相距120km。

速度$v$与时间$t$的关系是$v = \frac{120}{t}$。

速度越大，时间越短。

## 二、工程问题

**工作量一定，效率与时间成反比**

工作量$W$一定。

效率$p$与时间$t$的关系是$p = \frac{W}{t}$。

这是反比例函数关系。

**例子**

一项工程总量为60。

效率$p$与时间$t$的关系是$p = \frac{60}{t}$。

效率越高，时间越短。

## 三、面积问题

**面积一定，长与宽成反比**

矩形面积$S$一定。

长$a$与宽$b$的关系是$a = \frac{S}{b}$。

这是反比例函数关系。

**例子**

矩形面积为24。

长$a$与宽$b$的关系是$a = \frac{24}{b}$。

宽越大，长越小。

## 四、物理中的反比例关系

**压强一定时压力与受力面积**

压强$P$一定。

压力$F$与受力面积$S$的关系是$F = P \times S$。

这是正比例关系。

**压力一定时压强与受力面积**

压力$F$一定。

压强$p$与受力面积$S$的关系是$p = \frac{F}{S}$。

这是反比例关系。

**例子**

压力为100N。

压强$p$与受力面积$S$的关系是$p = \frac{100}{S}$。

受力面积越大，压强越小。

## 五、例题讲解

**例题1：** 甲乙两地相距180km，一辆汽车从甲地到乙地。求速度$v$（km/h）与时间$t$（h）的函数关系式。如果汽车用3小时到达，求汽车的速度。

解：

路程 = 180km。

$v = \frac{180}{t}$。

当$t = 3$时，$v = \frac{180}{3} = 60$km/h。

答：函数关系式为$v = \frac{180}{t}$，汽车的速度为60km/h。

**例题2：** 一项工程，如果每天完成5个单位的工作量，需要12天完成。求每天的工作效率$p$与所需天数$t$的函数关系式。如果要在8天内完成，每天需要完成多少工作量？

解：

工作总量 = $5 \times 12 = 60$。

$p = \frac{60}{t}$。

当$t = 8$时，$p = \frac{60}{8} = 7.5$。

答：函数关系式为$p = \frac{60}{t}$，每天需要完成7.5个单位的工作量。

**例题3：** 一个矩形的面积为36cm²。求长$a$（cm）与宽$b$（cm）的函数关系式。如果宽为4cm，求长。

解：

面积 = 36cm²。

$a = \frac{36}{b}$。

当$b = 4$时，$a = \frac{36}{4} = 9$cm。

答：函数关系式为$a = \frac{36}{b}$，长为9cm。

**例题4：** 某物体受到的压力为200N。求压强$p$（Pa）与受力面积$S$（m²）的函数关系式。如果受力面积为0.5m²，求压强。

解：

压力 = 200N。

$p = \frac{200}{S}$。

当$S = 0.5$时，$p = \frac{200}{0.5} = 400$Pa。

答：函数关系式为$p = \frac{200}{S}$，压强为400Pa。

**例题5：** 某工厂生产一批零件，如果每天生产20个，需要15天完成。求每天生产数量$n$与所需天数$d$的函数关系式。如果要在10天内完成，每天需要生产多少个？

解：

零件总数 = $20 \times 15 = 300$。

$n = \frac{300}{d}$。

当$d = 10$时，$n = \frac{300}{10} = 30$。

答：函数关系式为$n = \frac{300}{d}$，每天需要生产30个。

## 六、常见错误

**错误1：函数关系式写错**

错误做法：$v = st$。

正确做法：$v = \frac{s}{t}$。

**错误2：单位不统一**

错误做法：路程用km，时间用分钟。

正确做法：统一单位后再计算。

**错误3：自变量取值范围忽略**

错误做法：不考虑实际意义。

正确做法：自变量必须大于0。

**错误4：计算错误**

错误做法：$p = \frac{60}{8} = 7$。

正确做法：$p = \frac{60}{8} = 7.5$。

**错误5：反比例与正比例混淆**

错误理解：速度越大，时间越长。

正确理解：速度越大，时间越短。
