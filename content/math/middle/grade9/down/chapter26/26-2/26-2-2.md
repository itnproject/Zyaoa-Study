# 26.2.2 反比例函数与实际应用（二）

## 一、杠杆原理

**$F_1 L_1 = F_2 L_2$**

杠杆平衡时。

动力$F_1$与动力臂$L_1$的积等于阻力$F_2$与阻力臂$L_2$的积。

当$F_2$和$L_2$一定时。

$F_1 = \frac{F_2 L_2}{L_1}$。

$F_1$与$L_1$成反比。

**例子**

阻力为100N，阻力臂为2m。

$F_1 = \frac{200}{L_1}$。

动力臂越长，所需动力越小。

## 二、欧姆定律

**$I = \frac{U}{R}$**

电压$U$一定时。

电流$I$与电阻$R$成反比。

这是反比例函数关系。

**例子**

电压为12V。

$I = \frac{12}{R}$。

电阻越大，电流越小。

## 三、气体体积与压强的反比关系

**玻意耳定律**

温度一定时。

一定质量气体的压强$p$与体积$V$成反比。

$pV = k$（常数）。

$p = \frac{k}{V}$。

**例子**

$pV = 100$。

$p = \frac{100}{V}$。

体积越大，压强越小。

## 四、经济问题中的反比例关系

**单价与数量**

总价一定时。

单价$p$与数量$n$成反比。

$p = \frac{\text{总价}}{n}$。

**人均费用**

总费用一定时。

人均费用$c$与人数$n$成反比。

$c = \frac{\text{总费用}}{n}$。

**例子**

总费用为600元。

$c = \frac{600}{n}$。

人数越多，人均费用越少。

## 五、例题讲解

**例题1：** 杠杆平衡时，阻力为80N，阻力臂为3m。求动力$F$（N）与动力臂$L$（m）的函数关系式。如果动力臂为4m，求动力。

解：

$F \times L = 80 \times 3 = 240$。

$F = \frac{240}{L}$。

当$L = 4$时，$F = \frac{240}{4} = 60$N。

答：函数关系式为$F = \frac{240}{L}$，动力为60N。

**例题2：** 电路中电压为24V。求电流$I$（A）与电阻$R$（Ω）的函数关系式。如果电阻为6Ω，求电流。

解：

$I = \frac{24}{R}$。

当$R = 6$时，$I = \frac{24}{6} = 4$A。

答：函数关系式为$I = \frac{24}{R}$，电流为4A。

**例题3：** 一定质量的气体，在温度不变时，压强$p$（kPa）与体积$V$（L）成反比。已知当体积为5L时，压强为20kPa。求$p$与$V$的函数关系式。如果体积为4L，求压强。

解：

$pV = k$。

$20 \times 5 = 100$。

$p = \frac{100}{V}$。

当$V = 4$时，$p = \frac{100}{4} = 25$kPa。

答：函数关系式为$p = \frac{100}{V}$，压强为25kPa。

**例题4：** 某班级组织活动，总费用为800元。求人均费用$c$（元）与参加人数$n$的函数关系式。如果有20人参加，求人均费用。

解：

$c = \frac{800}{n}$。

当$n = 20$时，$c = \frac{800}{20} = 40$元。

答：函数关系式为$c = \frac{800}{n}$，人均费用为40元。

**例题5：** 某商品总价为360元。求单价$p$（元）与购买数量$n$的函数关系式。如果购买12件，求单价。

解：

$p = \frac{360}{n}$。

当$n = 12$时，$p = \frac{360}{12} = 30$元。

答：函数关系式为$p = \frac{360}{n}$，单价为30元。

## 六、常见错误

**错误1：杠杆原理公式记错**

错误做法：$F_1 + L_1 = F_2 + L_2$。

正确做法：$F_1 L_1 = F_2 L_2$。

**错误2：欧姆定律应用错误**

错误做法：$I = UR$。

正确做法：$I = \frac{U}{R}$。

**错误3：气体定律常数计算错误**

错误做法：$k = p+V$。

正确做法：$k = pV$。

**错误4：自变量取值范围忽略**

错误做法：不考虑实际意义。

正确做法：自变量必须大于0。

**错误5：单位不统一**

错误做法：压强用kPa，体积用m³。

正确做法：统一单位后再计算。
