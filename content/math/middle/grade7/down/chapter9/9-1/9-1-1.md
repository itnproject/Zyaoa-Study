# 9.1.1 不等式及其解集

## 一、从生活实例认识不等式

在我们的日常生活中，"相等"的情况其实并不多见，更多的是"不相等"。

比如你去游乐园玩过山车，门口写着"身高超过1.2米才能乘坐"。这句话的意思就是你的身高必须大于1.2米，用数学式子表示就是：身高 > 1.2米。

再比如，爸爸开车时看到限速标志写着"限速60km/h"，意思是车速不能超过60km/h，也就是车速 ≤ 60km/h。

还有，你去超市买东西，带了50元，想买一个35元的书包。买完后剩下的钱是50 - 35 = 15元，剩下的钱不等于0，也就是 50 - 35 ≠ 0。

这些用不等号连接的式子，就叫做不等式。

## 二、什么是不等式

用不等号把两个式子连接起来的式子，叫做不等式。

不等式用来表示两个量之间的大小关系，而不是相等关系。

## 三、五种不等号

不等号一共有五种，每一种都有特定的含义：

**大于号（>）**：表示左边的数比右边的数大。比如 5 > 3，读作"5大于3"。

**小于号（<）**：表示左边的数比右边的数小。比如 2 < 7，读作"2小于7"。

**大于等于号（≥）**：表示左边的数大于或等于右边的数。比如 x ≥ 60，读作"x大于或等于60"，也可以说"x不小于60"或"x至少是60"。

**小于等于号（≤）**：表示左边的数小于或等于右边的数。比如 x ≤ 100，读作"x小于或等于100"，也可以说"x不超过100"或"x至多是100"。

**不等于号（≠）**：表示两边的数不相等。比如 x ≠ 0，读作"x不等于0"。

记忆小技巧：不等号的开口方向总是朝着较大的那个数。比如 5 > 3，开口朝着5，说明5更大。

## 四、不等式的解

能使不等式成立的未知数的值，叫做这个不等式的解。

比如不等式 x > 3，当 x = 4 时，4 > 3 成立，所以 x = 4 是这个不等式的一个解。

当 x = 5 时，5 > 3 也成立，所以 x = 5 也是解。

当 x = 3 时，3 > 3 不成立，所以 x = 3 不是解。

当 x = 2 时，2 > 3 不成立，所以 x = 2 也不是解。

你会发现，不等式的解通常不止一个，而是有无数个。

## 五、不等式的解集

一个不等式的所有解组成的集合，叫做这个不等式的解集。

比如 x > 3 的解集就是所有大于3的数组成的集合。

解集强调的是"所有解"，而不是某一个具体的解。

## 六、解集在数轴上的表示

数轴是表示不等式解集的最好工具。

**表示规则：**

第一步：在数轴上找到边界点。

第二步：确定用空心圆圈还是实心圆圈。

- 如果不等号是 > 或 <（不带等号），用空心圆圈，表示不包含这个点。
- 如果不等号是 ≥ 或 ≤（带等号），用实心圆圈，表示包含这个点。

第三步：确定方向。

- 大于（> 或 ≥）向右画线。
- 小于（< 或 ≤）向左画线。

**举例说明：**

x > 3：在数轴上3的位置画空心圆圈，向右画线。

x ≥ 3：在数轴上3的位置画实心圆圈，向右画线。

x < 5：在数轴上5的位置画空心圆圈，向左画线。

x ≤ 5：在数轴上5的位置画实心圆圈，向左画线。

## 七、例题讲解

**例题1：** 判断下列式子哪些是不等式：① 3 > 1  ② x + 2 = 5  ③ 2x - 1 < 7  ④ a ≠ 0  ⑤ 3 + 2 = 5

解：不等式是用不等号连接的式子。

① 3 > 1，用了大于号，是不等式。

② x + 2 = 5，用了等号，是等式，不是不等式。

③ 2x - 1 < 7，用了小于号，是不等式。

④ a ≠ 0，用了不等于号，是不等式。

⑤ 3 + 2 = 5，用了等号，是等式，不是不等式。

所以不等式有：①③④

**例题2：** 判断 x = 2 是否是不等式 2x + 1 > 4 的解。

解：把 x = 2 代入不等式左边。

左边 = 2 × 2 + 1 = 4 + 1 = 5

右边 = 4

因为 5 > 4 成立，所以 x = 2 是这个不等式的解。

**例题3：** 判断 x = 1 是否是不等式 3x - 2 ≤ 1 的解。

解：把 x = 1 代入不等式左边。

左边 = 3 × 1 - 2 = 3 - 2 = 1

右边 = 1

因为 1 ≤ 1 成立（1等于1，满足"小于或等于"），所以 x = 1 是这个不等式的解。

**例题4：** 在数轴上表示不等式 x ≥ -2 的解集。

解：第一步，在数轴上找到-2的位置。

第二步，因为是≥（带等号），所以用实心圆圈。

第三步，因为是"大于等于"，所以向右画线。

结果：在-2处画实心圆圈，从-2向右画一条射线。

**例题5：** 写出数轴上表示的解集对应的不等式：在数轴上4的位置是空心圆圈，向左画线。

解：空心圆圈表示不包含4，所以不等号不带等号。

向左画线表示小于。

所以对应的不等式是 x < 4。

## 八、常见错误

**错误1：混淆空心圆圈和实心圆圈**

错误做法：x ≥ 3 用空心圆圈表示。

正确做法：≥ 带等号，必须用实心圆圈。只有 > 或 < 才用空心圆圈。

**错误2：方向画反**

错误做法：x > 2 向左画线。

正确做法：大于向右，小于向左。可以这样记：数轴上右边的数总比左边的大。

**错误3：把等式当成不等式**

错误做法：认为 x + 3 = 7 是不等式。

正确做法：等式用等号连接，不等式用不等号连接，两者完全不同。

**错误4：不理解"至少""至多"的含义**

错误做法："至少5个"写成 x > 5。

正确做法："至少5个"意思是5个也可以，应该是 x ≥ 5。"至多5个"是 x ≤ 5。

**错误5：判断解时计算错误**

错误做法：判断 x = 3 是否是 2x > 7 的解，算成 2 × 3 = 6 > 7，认为是解。

正确做法：2 × 3 = 6，6 > 7 不成立，所以 x = 3 不是解。

## 九、练习题

**练习1：** 用不等式表示下列语句：

（1）x的3倍大于5

（2）y与2的和不小于8

（3）a的2倍减去1不超过10

解：

（1）"大于"用 >，所以是 3x > 5

（2）"不小于"就是"大于或等于"，用 ≥，所以是 y + 2 ≥ 8

（3）"不超过"就是"小于或等于"，用 ≤，所以是 2a - 1 ≤ 10

**练习2：** 判断 x = 3 是否是下列不等式的解：

（1）2x + 1 > 6

（2）5 - x ≥ 2

解：

（1）把 x = 3 代入：2 × 3 + 1 = 7，7 > 6 成立，所以 x = 3 是解。

（2）把 x = 3 代入：5 - 3 = 2，2 ≥ 2 成立，所以 x = 3 是解。

**练习3：** 在数轴上表示下列不等式的解集：

（1）x > -1

（2）x ≤ 4

解：

（1）在-1处画空心圆圈，向右画线。

（2）在4处画实心圆圈，向左画线。

**练习4：** 写出下列数轴表示的不等式：

（1）在2处是实心圆圈，向右画线

（2）在-3处是空心圆圈，向左画线

解：

（1）实心圆圈表示带等号，向右表示大于，所以是 x ≥ 2

（2）空心圆圈表示不带等号，向左表示小于，所以是 x < -3

**练习5：** 某游乐园规定身高不超过1.4米的儿童可以免费入园。用不等式表示免费入园的身高条件，并判断身高1.4米的小朋友是否可以免费入园。

解：设身高为 h 米。

"不超过1.4米"就是"小于或等于1.4米"，所以不等式是 h ≤ 1.4。

当 h = 1.4 时，1.4 ≤ 1.4 成立，所以身高1.4米的小朋友可以免费入园。

注意：≤ 包含等于的情况，所以刚好1.4米也是免费的。
