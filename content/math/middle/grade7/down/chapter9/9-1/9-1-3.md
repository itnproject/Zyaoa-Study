# 9.1.3 一元一次不等式的解法

## 一、什么是一元一次不等式

只含有一个未知数，并且未知数的次数是1的不等式，叫做一元一次不等式。

比如：2x + 3 > 7，3x - 1 ≤ 5，-x + 4 < 2

这些不等式都只有一个未知数x，而且x的次数都是1。

像 x² + 1 > 0 这样的就不是一元一次不等式，因为x的次数是2。

像 x + y > 3 这样的也不是，因为有两个未知数。

## 二、解一元一次不等式的步骤

解一元一次不等式的步骤和解一元一次方程非常相似，一共分五步：

**第一步：去分母**

如果不等式中有分母，两边同时乘以分母的最小公倍数，消去分母。

注意：如果乘的是负数，不等号方向要改变。

**第二步：去括号**

按照去括号法则，把括号去掉。

括号前是正号，括号内各项不变号。

括号前是负号，括号内各项都要变号。

**第三步：移项**

把含有未知数的项移到不等号的一边，常数项移到另一边。

移项要变号，这和方程一样。

**第四步：合并同类项**

把同类项合并，化简不等式。

**第五步：系数化为1**

两边同时除以未知数的系数。

注意：如果系数是负数，不等号方向要改变！这是和方程最大的区别。

## 三、解不等式和解方程的区别

解方程和解不等式的前四步完全一样。

唯一的区别在第五步：系数化为1时。

方程两边除以负数，等号不变。

不等式两边除以负数，不等号必须改变方向！

这是考试中最大的陷阱，一定要特别注意。

## 四、解集在数轴上的表示

解出不等式后，要把解集在数轴上表示出来。

记住规则：

> 或 < 用空心圆圈，≥ 或 ≤ 用实心圆圈。

大于向右画，小于向左画。

## 五、例题讲解

**例题1：** 解不等式 2x + 3 > 7，并在数轴上表示解集。

解：

第一步：没有分母，跳过。

第二步：没有括号，跳过。

第三步：移项，2x > 7 - 3

2x > 4

第四步：已经是最简形式。

第五步：系数化为1，两边除以2（正数），不等号不变。

x > 2

解集是 x > 2。

在数轴上表示：在2处画空心圆圈，向右画线。

**例题2：** 解不等式 5 - 3x ≤ 2，并在数轴上表示解集。

解：

第一步：没有分母，跳过。

第二步：没有括号，跳过。

第三步：移项，-3x ≤ 2 - 5

-3x ≤ -3

第四步：已经是最简形式。

第五步：系数化为1，两边除以-3（负数），不等号方向改变。

x ≥ 1

注意：不等号从 ≤ 变成了 ≥！

解集是 x ≥ 1。

在数轴上表示：在1处画实心圆圈，向右画线。

**例题3：** 解不等式 3(x - 1) < 2x + 4，并在数轴上表示解集。

解：

第一步：没有分母，跳过。

第二步：去括号，3x - 3 < 2x + 4

第三步：移项，3x - 2x < 4 + 3

第四步：合并同类项，x < 7

第五步：系数已经是1。

解集是 x < 7。

在数轴上表示：在7处画空心圆圈，向左画线。

**例题4：** 解不等式 (2x - 1)/3 ≥ (x + 1)/2，并在数轴上表示解集。

解：

第一步：去分母，两边同时乘6（3和2的最小公倍数）。

6 × (2x - 1)/3 ≥ 6 × (x + 1)/2

2(2x - 1) ≥ 3(x + 1)

第二步：去括号，4x - 2 ≥ 3x + 3

第三步：移项，4x - 3x ≥ 3 + 2

第四步：合并同类项，x ≥ 5

第五步：系数已经是1。

解集是 x ≥ 5。

在数轴上表示：在5处画实心圆圈，向右画线。

**例题5：** 解不等式 1 - (x - 3)/2 > (2x + 1)/3，并在数轴上表示解集。

解：

第一步：去分母，两边同时乘6（2和3的最小公倍数）。

6 × 1 - 6 × (x - 3)/2 > 6 × (2x + 1)/3

6 - 3(x - 3) > 2(2x + 1)

注意：6也要乘！每一项都要乘最小公倍数。

第二步：去括号，6 - 3x + 9 > 4x + 2

第三步：移项，-3x - 4x > 2 - 6 - 9

第四步：合并同类项，-7x > -13

第五步：系数化为1，两边除以-7（负数），不等号方向改变。

x < 13/7

解集是 x < 13/7。

在数轴上表示：在13/7处画空心圆圈，向左画线。

## 六、常见错误

**错误1：系数化为1时，除以负数忘记变号**

错误做法：由 -2x > 6，得到 x > -3。

正确做法：两边除以-2，不等号变向，x < -3。

**错误2：去分母时漏乘**

错误做法：解 (x + 1)/2 > 3，两边乘2得到 x + 1/2 > 3。

正确做法：每一项都要乘2，应该是 x + 1 > 6。

**错误3：去括号时符号错误**

错误做法：解 2 - (x - 3) > 1，去括号得到 2 - x - 3 > 1。

正确做法：括号前是负号，括号内各项要变号，应该是 2 - x + 3 > 1。

**错误4：移项不变号**

错误做法：由 3x + 2 > 5，移项得到 3x > 5 + 2 = 7。

正确做法：移项要变号，3x > 5 - 2 = 3。

**错误5：解集表示错误**

错误做法：x ≥ 3 用空心圆圈表示。

正确做法：≥ 带等号，必须用实心圆圈。

## 七、练习题

**练习1：** 解不等式 4x - 3 > 2x + 5，并在数轴上表示解集。

解：

移项：4x - 2x > 5 + 3

合并同类项：2x > 8

系数化为1：x > 4

解集是 x > 4。

在数轴上表示：在4处画空心圆圈，向右画线。

**练习2：** 解不等式 3 - 2x ≥ 7，并在数轴上表示解集。

解：

移项：-2x ≥ 7 - 3

-2x ≥ 4

系数化为1，两边除以-2（负数），不等号变向：x ≤ -2

解集是 x ≤ -2。

在数轴上表示：在-2处画实心圆圈，向左画线。

**练习3：** 解不等式 2(x + 1) - 3 < 4x - 1，并在数轴上表示解集。

解：

去括号：2x + 2 - 3 < 4x - 1

2x - 1 < 4x - 1

移项：2x - 4x < -1 + 1

合并同类项：-2x < 0

系数化为1，两边除以-2（负数），不等号变向：x > 0

解集是 x > 0。

在数轴上表示：在0处画空心圆圈，向右画线。

**练习4：** 解不等式 (x + 2)/3 ≤ (2x - 1)/4，并在数轴上表示解集。

解：

去分母，两边乘12：4(x + 2) ≤ 3(2x - 1)

去括号：4x + 8 ≤ 6x - 3

移项：4x - 6x ≤ -3 - 8

合并同类项：-2x ≤ -11

系数化为1，两边除以-2（负数），不等号变向：x ≥ 11/2

解集是 x ≥ 11/2（即 x ≥ 5.5）。

在数轴上表示：在11/2处画实心圆圈，向右画线。

**练习5：** 解不等式 5 - (2x - 1)/3 > x + 2，并在数轴上表示解集。

解：

去分母，两边乘3：15 - (2x - 1) > 3(x + 2)

去括号：15 - 2x + 1 > 3x + 6

16 - 2x > 3x + 6

移项：-2x - 3x > 6 - 16

合并同类项：-5x > -10

系数化为1，两边除以-5（负数），不等号变向：x < 2

解集是 x < 2。

在数轴上表示：在2处画空心圆圈，向左画线。
