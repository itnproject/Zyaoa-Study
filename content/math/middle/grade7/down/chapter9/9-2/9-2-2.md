# 9.2.2 一元一次不等式的实际应用

## 一、从生活实例引入

不等式在我们的生活中无处不在。

你去商场买东西，看到"满200减50"的活动。这意味着你的消费金额要达到200元才能享受优惠，也就是消费金额 ≥ 200元。

你坐公交车，车上有"限载50人"的标志。这意味着车上的人数不能超过50人，也就是人数 ≤ 50人。

你去电影院看电影，门口写着"1.3米以下儿童免票"。这意味着身高不超过1.3米可以免票，也就是身高 ≤ 1.3米。

这些生活中的问题，都可以用不等式来解决。

## 二、列不等式解应用题的步骤

**第一步：审题**

仔细阅读题目，找出题目中的关键词。

常见的关键词有：超过、不足、至少、最多、不低于、不超过、大于、小于等。

**第二步：设未知数**

根据题目要求，设出合适的未知数。

通常设题目问的量为未知数。

**第三步：找不等关系**

从题目中找出表示大小关系的语句，确定不等关系。

**第四步：列不等式**

根据不等关系，列出一元一次不等式。

**第五步：解不等式**

按照解不等式的步骤，求出未知数的取值范围。

**第六步：结合实际意义作答**

根据题目的实际背景，对解集进行合理的解释。

比如人数必须是正整数，长度必须是正数等。

## 三、常见关键词对应的不等号

**"超过""大于""多于"**：对应 >

比如"超过50人"就是 x > 50。

**"不足""小于""少于"**：对应 <

比如"不足100元"就是 x < 100。

**"至少""不低于""不少于""最少"**：对应 ≥

比如"至少5个"就是 x ≥ 5。

**"至多""不超过""不多于""最多"**：对应 ≤

比如"不超过60km/h"就是 x ≤ 60。

**"正数"**：对应 > 0

**"非负数"**：对应 ≥ 0

**"负数"**：对应 < 0

**"非正数"**：对应 ≤ 0

## 四、例题讲解

**例题1：** 小明带了100元去书店，想买一些笔记本，每本笔记本8元。他最多能买多少本笔记本？

解：

设小明能买x本笔记本。

根据题意，买笔记本的总费用不能超过100元。

列不等式：8x ≤ 100

解不等式：x ≤ 100/8

x ≤ 12.5

因为笔记本的本数必须是整数，所以x最大取12。

答：小明最多能买12本笔记本。

**例题2：** 某出租车收费标准是：起步价10元（含3公里），超过3公里后每公里2元。小红有30元，她最多能坐多少公里？

解：

设小红能坐x公里（x > 3）。

根据题意，总费用 = 起步价 + 超出部分费用 = 10 + 2(x - 3)

总费用不能超过30元。

列不等式：10 + 2(x - 3) ≤ 30

去括号：10 + 2x - 6 ≤ 30

2x + 4 ≤ 30

2x ≤ 26

x ≤ 13

答：小红最多能坐13公里。

**例题3：** 某工厂生产一批零件，原计划每天生产50个，实际每天比原计划多生产10个，结果提前2天完成任务。这批零件至少有多少个？

解：

设这批零件有x个。

原计划需要的天数：x/50 天

实际每天生产60个，实际需要的天数：x/60 天

根据题意，实际比原计划少用2天。

列不等式：x/50 - x/60 ≥ 2

通分：(6x - 5x)/300 ≥ 2

x/300 ≥ 2

x ≥ 600

答：这批零件至少有600个。

**例题4：** 某商场搞促销活动，一种商品原价200元，现打八折出售。如果商场要保证每件商品的利润不低于20元，这种商品的进价最高是多少元？

解：

设这种商品的进价为x元。

打折后的售价：200 × 0.8 = 160元

利润 = 售价 - 进价 = 160 - x

根据题意，利润不低于20元。

列不等式：160 - x ≥ 20

-x ≥ 20 - 160

-x ≥ -140

x ≤ 140

答：这种商品的进价最高是140元。

**例题5：** 某学校组织学生春游，每辆大巴车可以坐45人，租金500元。如果参加春游的学生有200人，至少需要租几辆大巴车？

解：

设需要租x辆大巴车。

根据题意，x辆大巴车至少要能坐200人。

列不等式：45x ≥ 200

x ≥ 200/45

x ≥ 4.44...

因为大巴车的数量必须是整数，所以x最小取5。

答：至少需要租5辆大巴车。

## 五、常见错误

**错误1：关键词理解错误**

错误做法："至少5个"写成 x > 5。

正确做法："至少5个"包含5个，应该是 x ≥ 5。

**错误2：忽略实际意义**

错误做法：求出 x ≤ 12.5 后，直接回答12.5。

正确做法：实际问题中，物品数量必须是整数，应该回答12。

**错误3：不等关系找错**

错误做法：把"不超过"理解成 <。

正确做法："不超过"是 ≤，包含等于的情况。

**错误4：单位不统一**

错误做法：题目中一个量用米，一个量用厘米，直接列不等式。

正确做法：先统一单位，再列不等式。

**错误5：设未知数不合理**

错误做法：题目问"至少需要几辆车"，却设总费用为未知数。

正确做法：题目问什么就设什么为未知数。

## 六、练习题

**练习1：** 某公园门票成人票每张30元，学生票每张15元。一个旅游团有20人，其中学生人数不超过12人，这个旅游团最多需要多少元门票？

解：

设学生有x人，则成人有(20 - x)人。

根据题意，x ≤ 12。

总费用 = 15x + 30(20 - x) = 15x + 600 - 30x = 600 - 15x

要使总费用最多，需要x最小。

因为x是学生人数，最少可以是0人。

当x = 0时，总费用 = 600元。

但题目说学生人数不超过12人，没有说最少多少人。

如果全是成人，费用最多：20 × 30 = 600元。

答：这个旅游团最多需要600元门票。

**练习2：** 小明家距学校3公里，他步行速度是每小时4公里。如果他要在20分钟内到达学校，他的速度至少要提高到每小时多少公里？

解：

设小明的速度为x公里/小时。

20分钟 = 1/3小时

根据题意，时间 = 路程/速度 ≤ 1/3

3/x ≤ 1/3

两边乘3x（x > 0）：9 ≤ x

x ≥ 9

答：他的速度至少要提高到每小时9公里。

**练习3：** 某商品进价为80元，标价为120元。商店准备打折销售，但要保证利润率不低于5%。这种商品最多可以打几折？

解：

设打x折（x为小数，如0.8表示八折）。

打折后售价：120x 元

利润：120x - 80 元

利润率 = 利润/进价 = (120x - 80)/80

根据题意，利润率不低于5% = 0.05。

列不等式：(120x - 80)/80 ≥ 0.05

120x - 80 ≥ 4

120x ≥ 84

x ≥ 0.7

答：最多可以打七折（0.7折）。

**练习4：** 某班有学生45人，在一次数学测验中，及格（60分及以上）的学生占全班人数的80%以上。及格的学生至少有多少人？

解：

设及格的学生有x人。

根据题意，x/45 ≥ 0.8

x ≥ 45 × 0.8

x ≥ 36

答：及格的学生至少有36人。

**练习5：** 某快递公司规定，包裹重量不超过5公斤时，运费为10元；超过5公斤后，每超出1公斤加收2元。小李寄了一个包裹，运费不超过20元，这个包裹最重多少公斤？

解：

设包裹重x公斤（x > 5）。

运费 = 10 + 2(x - 5)

根据题意，运费不超过20元。

列不等式：10 + 2(x - 5) ≤ 20

10 + 2x - 10 ≤ 20

2x ≤ 20

x ≤ 10

答：这个包裹最重10公斤。
