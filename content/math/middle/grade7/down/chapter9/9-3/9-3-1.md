# 9.3.1 一元一次不等式组

## 一、从生活实例引入

你去游乐园玩过山车，门口写着"身高超过1.2米且不超过1.9米才能乘坐"。

这句话包含两个条件：身高 > 1.2米，同时身高 ≤ 1.9米。

两个条件必须同时满足，这就是不等式组。

再比如，某学校规定学生的体温在36度到37.5度之间才能进校。

也就是体温 ≥ 36度，同时体温 ≤ 37.5度。

## 二、什么是一元一次不等式组

把几个一元一次不等式合在一起，就组成了一个一元一次不等式组。

比如：
```
x > 2
x < 5
```
这就是一个不等式组，包含两个不等式。

## 三、不等式组的解集

不等式组中各个不等式的解集的公共部分，叫做这个不等式组的解集。

公共部分就是同时满足所有不等式的x的取值范围。

如果几个不等式的解集没有公共部分，那么这个不等式组无解。

## 四、用数轴求不等式组的解集

求不等式组解集的方法：

第一步：分别求出每个不等式的解集。

第二步：把每个不等式的解集在同一条数轴上表示出来。

第三步：找出所有解集的重叠部分，这个重叠部分就是不等式组的解集。

如果没有重叠部分，不等式组无解。

## 五、例题讲解

**例题1：** 解不等式组：
```
x > 2
x < 5
```

解：

第一个不等式的解集：x > 2

第二个不等式的解集：x < 5

在数轴上表示：

x > 2：在2处画空心圆圈，向右画线。

x < 5：在5处画空心圆圈，向左画线。

重叠部分：2到5之间（不包含2和5）。

所以不等式组的解集是 2 < x < 5。

**例题2：** 解不等式组：
```
x ≥ -1
x ≤ 3
```

解：

第一个不等式的解集：x ≥ -1

第二个不等式的解集：x ≤ 3

重叠部分：-1到3之间（包含-1和3）。

所以不等式组的解集是 -1 ≤ x ≤ 3。

**例题3：** 解不等式组：
```
x > 3
x > 1
```

解：

第一个不等式的解集：x > 3

第二个不等式的解集：x > 1

在数轴上，x > 3 是3右边，x > 1 是1右边。

重叠部分是3右边（因为3右边的数一定也在1右边）。

所以不等式组的解集是 x > 3。

**例题4：** 解不等式组：
```
x < 2
x > 5
```

解：

第一个不等式的解集：x < 2

第二个不等式的解集：x > 5

在数轴上，x < 2 是2左边，x > 5 是5右边。

两者没有重叠部分。

所以这个不等式组无解。

**例题5：** 解不等式组：
```
2x - 1 > 3
x + 2 ≤ 6
```

解：

先解第一个不等式：2x - 1 > 3

2x > 4

x > 2

再解第二个不等式：x + 2 ≤ 6

x ≤ 4

所以不等式组变为：
```
x > 2
x ≤ 4
```

重叠部分：2到4之间（不包含2，包含4）。

所以不等式组的解集是 2 < x ≤ 4。

## 六、常见错误

**错误1：不理解"公共部分"的含义**

错误做法：把两个解集合并，写成 x > 2 或 x < 5。

正确做法：不等式组要求同时满足，是"且"的关系，不是"或"的关系。

**错误2：数轴表示错误**

错误做法：把两个不等式画在两条不同的数轴上。

正确做法：必须在同一条数轴上表示，才能看出重叠部分。

**错误3：解单个不等式时出错**

错误做法：解 2x - 1 > 3 得到 x > 1。

正确做法：2x > 4，x > 2。

**错误4：边界点判断错误**

错误做法：x > 2 且 x ≤ 4，写成 2 ≤ x ≤ 4。

正确做法：x > 2 不包含2，应该是 2 < x ≤ 4。

**错误5：无解时强行写出解集**

错误做法：x < 2 且 x > 5，写成 2 < x < 5。

正确做法：两者没有重叠，应该回答无解。

## 七、练习题

**练习1：** 解不等式组：
```
x > -2
x < 3
```

解：

第一个不等式的解集：x > -2

第二个不等式的解集：x < 3

重叠部分：-2到3之间（不包含-2和3）。

所以不等式组的解集是 -2 < x < 3。

**练习2：** 解不等式组：
```
x ≥ 1
x ≥ 4
```

解：

第一个不等式的解集：x ≥ 1

第二个不等式的解集：x ≥ 4

重叠部分：x ≥ 4（因为≥4的数一定也≥1）。

所以不等式组的解集是 x ≥ 4。

**练习3：** 解不等式组：
```
3x + 1 > 7
2x - 3 ≤ 5
```

解：

解第一个不等式：3x > 6，x > 2

解第二个不等式：2x ≤ 8，x ≤ 4

重叠部分：2 < x ≤ 4

所以不等式组的解集是 2 < x ≤ 4。

**练习4：** 解不等式组：
```
x ≤ -1
x ≥ 2
```

解：

第一个不等式的解集：x ≤ -1

第二个不等式的解集：x ≥ 2

在数轴上，x ≤ -1 是-1左边，x ≥ 2 是2右边。

两者没有重叠部分。

所以这个不等式组无解。

**练习5：** 解不等式组：
```
x + 3 > 0
2x - 4 < 6
```

解：

解第一个不等式：x > -3

解第二个不等式：2x < 10，x < 5

重叠部分：-3到5之间（不包含-3和5）。

所以不等式组的解集是 -3 < x < 5。
