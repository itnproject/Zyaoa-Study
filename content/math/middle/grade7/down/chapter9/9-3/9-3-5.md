# 9.3.5 不等式与方程组的综合

## 一、含参数的不等式组

这类问题的特点是：不等式组中含有字母参数，已知不等式组的解集，求参数的值或范围。

解题思路：先解出不等式组（用参数表示），再根据已知解集确定参数的范围。

## 二、方程组与不等式的综合

这类问题的特点是：先给出一个方程组，求出方程组的解，再把解代入不等式中，求出参数的范围。

解题思路：先解方程组，再代入不等式求解。

## 三、整数解问题

这类问题的特点是：求满足不等式（组）的整数解的个数或具体值。

解题思路：先求出不等式（组）的解集，再在解集中找出整数。

## 四、分类讨论思想

当不等式中含有参数时，参数的正负会影响不等号的方向，这时需要分类讨论。

比如解 ax > b，需要讨论：

当 a > 0 时，x > b/a

当 a < 0 时，x < b/a

当 a = 0 时，如果 b < 0，解集为全体实数；如果 b ≥ 0，无解。

## 五、例题讲解

**例题1：** 已知不等式组：
```
x > a
x < 5
```
的解集是 2 < x < 5，求a的值。

解：

不等式组的解集是 a < x < 5（因为a < 5时才有解）。

已知解集是 2 < x < 5。

对比可知 a = 2。

答：a的值是2。

**例题2：** 已知关于x的不等式组：
```
x > m
x ≤ 3
```
有解，求m的取值范围。

解：

不等式组有解的条件是 m < 3。

如果 m ≥ 3，那么 x > m 和 x ≤ 3 没有公共部分，无解。

所以m的取值范围是 m < 3。

答：m < 3。

**例题3：** 已知方程组：
```
x + y = 5
2x - y = 1
```
的解满足 x > y，求x和y的值。

解：

先解方程组。

两式相加：3x = 6，x = 2

代入第一式：2 + y = 5，y = 3

检验：x = 2，y = 3，x > y 即 2 > 3 不成立。

所以这个方程组的解不满足 x > y。

答：方程组的解是 x = 2，y = 3，但不满足 x > y。

**例题4：** 已知关于x、y的方程组：
```
x + y = a
x - y = 2
```
的解满足 x > 0 且 y > 0，求a的取值范围。

解：

先解方程组。

两式相加：2x = a + 2，x = (a + 2)/2

两式相减：2y = a - 2，y = (a - 2)/2

根据题意：x > 0 且 y > 0

(a + 2)/2 > 0，a + 2 > 0，a > -2

(a - 2)/2 > 0，a - 2 > 0，a > 2

不等式组：
```
a > -2
a > 2
```

同大取大：a > 2

答：a的取值范围是 a > 2。

**例题5：** 求不等式组：
```
2x - 1 > 3
3x + 2 ≤ 14
```
的所有整数解。

解：

解第一个不等式：2x > 4，x > 2

解第二个不等式：3x ≤ 12，x ≤ 4

不等式组的解集：2 < x ≤ 4

在这个范围内的整数有：3、4

答：整数解是 x = 3 和 x = 4。

## 六、常见错误

**错误1：含参数时不讨论正负**

错误做法：由 ax > b 直接得到 x > b/a。

正确做法：需要讨论a的正负，a < 0 时不等号要变向。

**错误2：解方程组时计算错误**

错误做法：解方程组时符号出错。

正确做法：仔细计算，代入检验。

**错误3：整数解遗漏**

错误做法：解集是 2 < x ≤ 5，只写出3、4、5，漏掉边界。

正确做法：仔细检查边界，2 < x ≤ 5 的整数解是3、4、5。

**错误4：有解和无解的条件搞反**

错误做法：x > m, x < 3 有解的条件写成 m > 3。

正确做法：有解的条件是 m < 3。

**错误5：代入时符号错误**

错误做法：把方程组的解代入不等式时符号弄错。

正确做法：仔细代入，注意正负号。

## 七、练习题

**练习1：** 已知不等式组：
```
x ≥ a
x < 4
```
的解集是 1 ≤ x < 4，求a的值。

解：

不等式组的解集是 a ≤ x < 4（当 a < 4 时）。

已知解集是 1 ≤ x < 4。

对比可知 a = 1。

答：a的值是1。

**练习2：** 已知关于x的不等式组：
```
x < m
x ≥ -1
```
无解，求m的取值范围。

解：

不等式组无解的条件是 m ≤ -1。

因为如果 m > -1，那么 -1 ≤ x < m 有解。

只有当 m ≤ -1 时，x < m 和 x ≥ -1 没有公共部分。

答：m ≤ -1。

**练习3：** 已知关于x、y的方程组：
```
2x + y = 7
x - y = a
```
的解满足 x + y > 0，求a的取值范围。

解：

先解方程组。

两式相加：3x = 7 + a，x = (7 + a)/3

代入第二式：(7 + a)/3 - y = a

y = (7 + a)/3 - a = (7 + a - 3a)/3 = (7 - 2a)/3

根据题意：x + y > 0

(7 + a)/3 + (7 - 2a)/3 > 0

(14 - a)/3 > 0

14 - a > 0

a < 14

答：a的取值范围是 a < 14。

**练习4：** 求不等式组：
```
3x + 1 ≥ -5
2x - 3 < 5
```
的所有整数解。

解：

解第一个不等式：3x ≥ -6，x ≥ -2

解第二个不等式：2x < 8，x < 4

不等式组的解集：-2 ≤ x < 4

在这个范围内的整数有：-2、-1、0、1、2、3

答：整数解是 x = -2, -1, 0, 1, 2, 3。

**练习5：** 已知关于x的不等式 (a - 2)x > a - 2 的解集是 x < 1，求a的取值范围。

解：

由 (a - 2)x > a - 2 得到 x < 1

说明两边除以 (a - 2) 时，不等号方向改变了。

根据不等式的性质3，只有除以负数时不等号才会改变。

所以 a - 2 < 0

a < 2

答：a的取值范围是 a < 2。
