# 9.3.4 不等式组的实际应用

## 一、从生活实例引入

生活中很多问题需要同时满足多个条件。

比如安排住宿：一个旅行团有50人，酒店有大房间（住6人）和小房间（住4人），要求每个房间都住满，且总房间数不超过10间。这就需要用不等式组来解决。

再比如分配物资：学校买了100本图书，要分给两个班级，一班分到的不少于一班的2倍，二班分到的不少于20本。这也需要用不等式组。

## 二、列不等式组解应用题的步骤

**第一步：审题**

仔细阅读题目，理解题意，找出题目中的所有条件。

**第二步：设未知数**

根据题目要求，设出合适的未知数。

**第三步：找不等关系**

从题目中找出所有的不等关系，通常有两个或以上。

**第四步：列不等式组**

根据不等关系，列出不等式组。

**第五步：解不等式组**

求出不等式组的解集。

**第六步：结合实际意义作答**

根据题目的实际背景，对解集进行合理的解释。

## 三、方案设计类问题

这类问题的特点是：求出范围后，需要列举可能的整数解。

比如求出的解集是 3 ≤ x ≤ 7，那么x可以取3、4、5、6、7。

然后根据题目要求，选择符合条件的方案。

## 四、最优方案问题

在可行方案中选择最佳方案。

通常需要先求出所有可行方案，再比较哪个方案最优。

最优的标准可能是费用最低、效率最高、时间最短等。

## 五、例题讲解

**例题1：** 某学校组织学生植树，计划植树不少于100棵，不超过150棵。如果每人植3棵，参加植树的学生人数至少多少人？至多多少人？

解：

设参加植树的学生有x人。

根据题意，植树总数为3x棵。

列不等式组：
```
3x ≥ 100
3x ≤ 150
```

解第一个不等式：x ≥ 100/3，x ≥ 33.33...

解第二个不等式：x ≤ 50

不等式组的解集：33.33... ≤ x ≤ 50

因为人数必须是整数，所以x可以取34到50。

答：参加植树的学生至少34人，至多50人。

**例题2：** 某工厂生产A、B两种产品，生产一件A产品需要2小时，生产一件B产品需要3小时。工厂每天工作时间不超过8小时，且A产品的产量不少于B产品的2倍。如果每天生产A产品x件，B产品y件，列出满足条件的不等式组。

解：

根据题意：

工作时间不超过8小时：2x + 3y ≤ 8

A产品产量不少于B产品的2倍：x ≥ 2y

产量不能为负：x ≥ 0，y ≥ 0

不等式组为：
```
2x + 3y ≤ 8
x ≥ 2y
x ≥ 0
y ≥ 0
```

**例题3：** 某商场计划购进甲、乙两种商品共100件，甲商品每件进价30元，乙商品每件进价50元。商场预算不超过4000元，且甲商品的数量不少于乙商品的3倍。问商场有几种进货方案？

解：

设购进甲商品x件，则乙商品为(100 - x)件。

根据题意：

预算不超过4000元：30x + 50(100 - x) ≤ 4000

甲商品不少于乙商品的3倍：x ≥ 3(100 - x)

解第一个不等式：30x + 5000 - 50x ≤ 4000

-20x ≤ -1000

x ≥ 50

解第二个不等式：x ≥ 300 - 3x

4x ≥ 300

x ≥ 75

不等式组的解集：x ≥ 75 且 x ≥ 50

同大取大：x ≥ 75

又因为甲商品最多100件，所以 75 ≤ x ≤ 100。

x可以取75、76、77、...、100，共26种方案。

答：商场有26种进货方案。

**例题4：** 某旅行社组织旅游，有大巴（每辆坐45人，租金500元）和中巴（每辆坐30人，租金350元）两种车型。旅行团有120人，要求每辆车都坐满或接近坐满，且总租金不超过2000元。问有几种租车方案？哪种方案最省钱？

解：

设租大巴x辆，中巴y辆。

根据题意：

人数要求：45x + 30y ≥ 120

租金要求：500x + 350y ≤ 2000

x、y为非负整数。

列举可能的方案：

方案1：x = 0，30y ≥ 120，y ≥ 4，350 × 4 = 1400 ≤ 2000，可行。租金1400元。

方案2：x = 1，45 + 30y ≥ 120，30y ≥ 75，y ≥ 3，500 + 350 × 3 = 1550 ≤ 2000，可行。租金1550元。

方案3：x = 2，90 + 30y ≥ 120，30y ≥ 30，y ≥ 1，1000 + 350 = 1350 ≤ 2000，可行。租金1350元。

方案4：x = 3，135 + 30y ≥ 120，y ≥ 0，1500 ≤ 2000，可行。租金1500元。

方案5：x = 4，180 ≥ 120，y = 0，2000 ≤ 2000，可行。租金2000元。

比较租金：方案3最省钱，租金1350元。

答：有5种租车方案，租2辆大巴和1辆中巴最省钱。

**例题5：** 某班级组织春游，需要租船。大船每条坐6人，租金80元；小船每条坐4人，租金50元。班级有36人，要求每条船都坐满，且总租金不超过500元。问有几种租船方案？

解：

设租大船x条，小船y条。

根据题意：

人数要求：6x + 4y = 36（要求坐满，所以是等式）

租金要求：80x + 50y ≤ 500

x、y为非负整数。

由 6x + 4y = 36，化简得 3x + 2y = 18

y = (18 - 3x)/2 = 9 - 1.5x

因为y是整数，所以1.5x必须是整数，x必须是偶数。

x = 0时，y = 9，租金 = 50 × 9 = 450 ≤ 500，可行。

x = 2时，y = 6，租金 = 160 + 300 = 460 ≤ 500，可行。

x = 4时，y = 3，租金 = 320 + 150 = 470 ≤ 500，可行。

x = 6时，y = 0，租金 = 480 ≤ 500，可行。

答：有4种租船方案。

## 六、常见错误

**错误1：漏掉不等关系**

错误做法：只列出一个不等式，忽略其他条件。

正确做法：仔细审题，找出所有不等关系。

**错误2：不考虑实际意义**

错误做法：求出解集后直接回答，不考虑整数限制。

正确做法：根据题目实际背景，取合适的整数值。

**错误3：方案设计时遗漏方案**

错误做法：只列举部分方案，没有全部列举。

正确做法：按照顺序逐一列举，确保不遗漏。

**错误4：最优方案比较错误**

错误做法：比较时看错数据。

正确做法：列出所有方案的费用，逐一比较。

**错误5：设未知数不合理**

错误做法：设的未知数与题目要求不符。

正确做法：根据题目要求设未知数，通常设题目问的量。

## 七、练习题

**练习1：** 某学校购买篮球和足球共20个，篮球每个80元，足球每个50元。学校预算不超过1300元，且篮球数量不少于足球的2倍。问有几种购买方案？

解：

设购买篮球x个，则足球为(20 - x)个。

预算：80x + 50(20 - x) ≤ 1300

80x + 1000 - 50x ≤ 1300

30x ≤ 300

x ≤ 10

篮球不少于足球的2倍：x ≥ 2(20 - x)

x ≥ 40 - 2x

3x ≥ 40

x ≥ 40/3，x ≥ 13.33...

x ≤ 10 且 x ≥ 13.33...，无解。

答：没有满足条件的购买方案。

**练习2：** 某工厂生产两种零件，甲零件每件利润5元，乙零件每件利润8元。工厂每天最多生产50件，且甲零件的产量不少于乙零件的3倍。问每天生产甲、乙零件各多少件时利润最大？

解：

设生产甲零件x件，乙零件y件。

产量限制：x + y ≤ 50

甲不少于乙的3倍：x ≥ 3y

x、y为非负整数。

利润 = 5x + 8y

由 x ≥ 3y 和 x + y ≤ 50

当 y = 0 时，x ≤ 50，利润 = 5 × 50 = 250元

当 y = 1 时，x ≥ 3，x ≤ 49，利润 = 5 × 49 + 8 = 253元

当 y = 2 时，x ≥ 6，x ≤ 48，利润 = 5 × 48 + 16 = 256元

当 y = 12 时，x ≥ 36，x ≤ 38，利润 = 5 × 38 + 96 = 286元

当 y = 12 时，x = 38，利润 = 190 + 96 = 286元

当 y = 13 时，x ≥ 39，x ≤ 37，无解。

最大利润在 y = 12，x = 38 时取得，利润286元。

答：生产甲零件38件，乙零件12件时利润最大，为286元。

**练习3：** 某旅行社安排住宿，大房间每间住4人，小房间每间住2人。旅行团有30人，要求每间房都住满，且总房间数不超过10间。问有几种安排方案？

解：

设大房间x间，小房间y间。

人数：4x + 2y = 30，化简得 2x + y = 15

房间数：x + y ≤ 10

由 y = 15 - 2x

代入：x + 15 - 2x ≤ 10

-x ≤ -5

x ≥ 5

又因为 y = 15 - 2x ≥ 0，所以 x ≤ 7.5，x ≤ 7

x可以取5、6、7。

x = 5时，y = 5，房间数 = 10 ≤ 10，可行。

x = 6时，y = 3，房间数 = 9 ≤ 10，可行。

x = 7时，y = 1，房间数 = 8 ≤ 10，可行。

答：有3种安排方案。

**练习4：** 某商店购进A、B两种商品共80件，A商品每件进价20元，B商品每件进价30元。商店预算不超过2000元，且A商品的数量不少于B商品。问有几种进货方案？

解：

设购进A商品x件，则B商品为(80 - x)件。

预算：20x + 30(80 - x) ≤ 2000

20x + 2400 - 30x ≤ 2000

-10x ≤ -400

x ≥ 40

A不少于B：x ≥ 80 - x

2x ≥ 80

x ≥ 40

又因为x ≤ 80，所以 40 ≤ x ≤ 80。

x可以取40到80，共41种方案。

答：有41种进货方案。

**练习5：** 某班级组织活动，需要购买矿泉水和饮料共50瓶。矿泉水每瓶2元，饮料每瓶5元。班费不超过180元，且矿泉水的数量不少于饮料的3倍。问有几种购买方案？哪种方案最省钱？

解：

设购买矿泉水x瓶，则饮料为(50 - x)瓶。

预算：2x + 5(50 - x) ≤ 180

2x + 250 - 5x ≤ 180

-3x ≤ -70

x ≥ 70/3，x ≥ 23.33...，x ≥ 24

矿泉水不少于饮料的3倍：x ≥ 3(50 - x)

x ≥ 150 - 3x

4x ≥ 150

x ≥ 37.5，x ≥ 38

又因为x ≤ 50，所以 38 ≤ x ≤ 50。

x可以取38到50，共13种方案。

最省钱方案：x = 50（全买矿泉水），费用 = 2 × 50 = 100元。

答：有13种购买方案，全买矿泉水最省钱，费用100元。
