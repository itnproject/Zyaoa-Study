# 9.3.3 含等号的不等式组

## 一、空心圆圈与实心圆圈的区别

在数轴上表示不等式的解集时，圆圈有两种：

**空心圆圈**：表示不包含这个点，对应 > 或 <。

**实心圆圈**：表示包含这个点，对应 ≥ 或 ≤。

这个区别在不等式组中非常重要，因为边界点是否取到直接影响最终答案。

## 二、含等号的不等式组解集的边界处理

当不等式组中含有等号时，解集的边界是否包含等号，取决于原不等式是否包含等号。

如果一个不等式是 x ≥ 2，另一个是 x < 5，那么解集是 2 ≤ x < 5。

左边界2包含等号（因为原不等式是≥），右边界5不包含等号（因为原不等式是<）。

## 三、边界点是否取到的判断方法

判断边界点是否取到，要看这个边界点对应的原不等式是否带等号。

如果原不等式是 ≥ 或 ≤，边界点取到，用实心圆圈。

如果原不等式是 > 或 <，边界点不取到，用空心圆圈。

当两个不等式在同一个边界点时，只要有一个不等式不包含这个点，最终解集就不包含这个点。

## 四、综合题：既有>又有≥的情况

比如不等式组：
```
x > 2
x ≥ 2
```

x > 2 表示x在2的右边，不包含2。

x ≥ 2 表示x在2的右边，包含2。

同时满足两个条件，x必须在2的右边且不包含2（因为第一个不等式不包含2）。

所以解集是 x > 2。

再比如：
```
x > 2
x ≥ 3
```

同大取大，3较大。

解集是 x ≥ 3。

## 五、例题讲解

**例题1：** 解不等式组：
```
x ≥ -2
x < 4
```

解：

第一个不等式的解集：x ≥ -2（包含-2）

第二个不等式的解集：x < 4（不包含4）

重叠部分：-2到4之间，包含-2，不包含4。

所以解集是 -2 ≤ x < 4。

在数轴上表示：在-2处画实心圆圈，在4处画空心圆圈，中间连线。

**例题2：** 解不等式组：
```
x > 1
x ≤ 1
```

解：

x > 1 表示x在1的右边，不包含1。

x ≤ 1 表示x在1的左边，包含1。

两者没有公共部分（一个在1右边，一个在1左边，1本身只满足第二个不等式）。

所以这个不等式组无解。

**例题3：** 解不等式组：
```
x ≥ 3
x ≥ 5
```

解：同大取大，5较大。

解集是 x ≥ 5。

在数轴上表示：在5处画实心圆圈，向右画线。

**例题4：** 解不等式组：
```
2x + 1 ≥ 5
3x - 2 < 7
```

解：

解第一个不等式：2x ≥ 4，x ≥ 2

解第二个不等式：3x < 9，x < 3

不等式组变为：
```
x ≥ 2
x < 3
```

解集是 2 ≤ x < 3。

在数轴上表示：在2处画实心圆圈，在3处画空心圆圈，中间连线。

**例题5：** 解不等式组：
```
x + 2 > 0
2x - 4 ≤ 0
x ≥ 1
```

解：

解第一个不等式：x > -2

解第二个不等式：2x ≤ 4，x ≤ 2

第三个不等式：x ≥ 1

不等式组变为：
```
x > -2
x ≤ 2
x ≥ 1
```

在数轴上找三个解集的公共部分。

x > -2：-2右边

x ≤ 2：2左边（包含2）

x ≥ 1：1右边（包含1）

三者的公共部分：1到2之间，包含1和2。

所以解集是 1 ≤ x ≤ 2。

## 六、常见错误

**错误1：等号遗漏**

错误做法：x ≥ 2, x < 5，解集写成 2 < x < 5。

正确做法：x ≥ 2 包含2，应该是 2 ≤ x < 5。

**错误2：同大取大时等号处理错误**

错误做法：x > 2, x ≥ 3，解集写成 x > 3。

正确做法：x ≥ 3 包含3，且3 > 2，解集是 x ≥ 3。

**错误3：无解时误判**

错误做法：x > 2, x ≤ 2，认为解集是 x = 2。

正确做法：x > 2 不包含2，x ≤ 2 包含2，两者没有公共部分，无解。

**错误4：三个不等式时漏掉一个**

错误做法：只考虑两个不等式，忽略第三个。

正确做法：三个不等式的解集都要考虑，找三者的公共部分。

**错误5：数轴上实心空心画错**

错误做法：≥ 画空心圆圈。

正确做法：≥ 和 ≤ 画实心圆圈，> 和 < 画空心圆圈。

## 七、练习题

**练习1：** 解不等式组：
```
x ≥ -3
x ≤ 2
```

解：

第一个不等式的解集：x ≥ -3（包含-3）

第二个不等式的解集：x ≤ 2（包含2）

解集是 -3 ≤ x ≤ 2。

在数轴上表示：在-3和2处都画实心圆圈，中间连线。

**练习2：** 解不等式组：
```
x > 0
x ≥ 4
```

解：同大取大，4较大。

x ≥ 4 包含4。

解集是 x ≥ 4。

**练习3：** 解不等式组：
```
3x - 1 ≥ 2
x + 1 < 5
```

解：

解第一个不等式：3x ≥ 3，x ≥ 1

解第二个不等式：x < 4

解集是 1 ≤ x < 4。

**练习4：** 解不等式组：
```
x > -1
x ≤ -1
```

解：

x > -1 表示-1右边，不包含-1。

x ≤ -1 表示-1左边，包含-1。

两者没有公共部分。

无解。

**练习5：** 解不等式组：
```
x + 1 ≥ 0
2x - 3 > -1
x ≤ 3
```

解：

解第一个不等式：x ≥ -1

解第二个不等式：2x > 2，x > 1

第三个不等式：x ≤ 3

不等式组变为：
```
x ≥ -1
x > 1
x ≤ 3
```

三者的公共部分：x > 1 且 x ≤ 3（因为x > 1 已经包含了 x ≥ -1）。

解集是 1 < x ≤ 3。
