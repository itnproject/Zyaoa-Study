# 9.3.2 不等式组解集的四种情况

## 一、口诀记忆

求不等式组的解集，有一个非常好用的口诀：

**大大取大，小小取小，大小小大中间找，大大小小找不到。**

这个口诀概括了不等式组解集的四种基本情况。

下面我们来逐一讲解。

## 二、情况一：同大取大（大大取大）

当两个不等式都是"大于"型时，取较大的那个数作为边界。

比如：
```
x > 2
x > 5
```

x > 2 表示x在2的右边，x > 5 表示x在5的右边。

同时满足两个条件，x必须在5的右边（因为5右边的数一定也在2右边）。

所以解集是 x > 5，取较大的数5。

再比如：
```
x ≥ 3
x ≥ 1
```

解集是 x ≥ 3，取较大的数3。

## 三、情况二：同小取小（小小取小）

当两个不等式都是"小于"型时，取较小的那个数作为边界。

比如：
```
x < 8
x < 3
```

x < 8 表示x在8的左边，x < 3 表示x在3的左边。

同时满足两个条件，x必须在3的左边（因为3左边的数一定也在8左边）。

所以解集是 x < 3，取较小的数3。

再比如：
```
x ≤ 6
x ≤ 4
```

解集是 x ≤ 4，取较小的数4。

## 四、情况三：大小小大中间找

当一个不等式是"大于"型，另一个是"小于"型，且"大于"的数小于"小于"的数时，解集在两个数之间。

比如：
```
x > 2
x < 7
```

x > 2 表示x在2的右边，x < 7 表示x在7的左边。

同时满足两个条件，x必须在2和7之间。

所以解集是 2 < x < 7。

再比如：
```
x ≥ 1
x ≤ 5
```

解集是 1 ≤ x ≤ 5。

注意：这里"大于"的数（1）要小于"小于"的数（5），才有中间部分。

## 五、情况四：大大小小找不到

当一个不等式是"大于"型，另一个是"小于"型，但"大于"的数大于"小于"的数时，无解。

比如：
```
x > 7
x < 2
```

x > 7 表示x在7的右边，x < 2 表示x在2的左边。

7右边的数和2左边的数没有重叠部分。

所以这个不等式组无解。

再比如：
```
x ≥ 5
x ≤ 3
```

解集无解，因为5右边的数和3左边的数没有重叠。

## 六、四种情况总结

| 类型 | 不等式组 | 解集 | 口诀 |
|------|----------|------|------|
| 同大取大 | x > a, x > b (a < b) | x > b | 大大取大 |
| 同小取小 | x < a, x < b (a > b) | x < b | 小小取小 |
| 中间找 | x > a, x < b (a < b) | a < x < b | 大小小大中间找 |
| 找不到 | x > a, x < b (a > b) | 无解 | 大大小小找不到 |

## 七、例题讲解

**例题1：** 解不等式组：
```
x > -1
x > 3
```

解：两个都是"大于"型，同大取大。

-1和3中，3较大。

所以解集是 x > 3。

**例题2：** 解不等式组：
```
x < 6
x < 2
```

解：两个都是"小于"型，同小取小。

6和2中，2较小。

所以解集是 x < 2。

**例题3：** 解不等式组：
```
x > -3
x < 4
```

解：一个"大于"一个"小于"，且-3 < 4，属于"大小小大中间找"。

所以解集是 -3 < x < 4。

**例题4：** 解不等式组：
```
x > 5
x < 1
```

解：一个"大于"一个"小于"，但5 > 1，属于"大大小小找不到"。

所以这个不等式组无解。

**例题5：** 解不等式组：
```
2x + 1 > 5
3x - 2 < 10
```

解：

先解第一个不等式：2x > 4，x > 2

再解第二个不等式：3x < 12，x < 4

不等式组变为：
```
x > 2
x < 4
```

属于"大小小大中间找"，2 < 4。

所以解集是 2 < x < 4。

## 八、常见错误

**错误1：口诀用反**

错误做法：x > 2, x > 5，取小的，得到 x > 2。

正确做法：同大取大，应该取 x > 5。

**错误2：不先化简就套口诀**

错误做法：2x > 4, x < 4，直接套口诀。

正确做法：先化简为 x > 2, x < 4，再套口诀。

**错误3：等号处理错误**

错误做法：x ≥ 2, x ≤ 5，写成 2 < x < 5。

正确做法：带等号的要保留等号，应该是 2 ≤ x ≤ 5。

**错误4：判断"中间找"还是"找不到"时出错**

错误做法：x > 3, x < 3，认为有解。

正确做法：x > 3 和 x < 3 没有公共部分，无解。

**错误5：三个不等式时不会处理**

错误做法：遇到三个不等式就乱了。

正确做法：先分别求出每个不等式的解集，再在数轴上找三个解集的公共部分。

## 九、练习题

**练习1：** 解不等式组：
```
x > 0
x > -2
```

解：同大取大，0和-2中，0较大。

解集是 x > 0。

**练习2：** 解不等式组：
```
x ≤ 7
x ≤ 3
```

解：同小取小，7和3中，3较小。

解集是 x ≤ 3。

**练习3：** 解不等式组：
```
x ≥ -4
x < 2
```

解：一个"大于等于"一个"小于"，且-4 < 2，属于"大小小大中间找"。

解集是 -4 ≤ x < 2。

**练习4：** 解不等式组：
```
x > 6
x ≤ 4
```

解：一个"大于"一个"小于等于"，但6 > 4，属于"大大小小找不到"。

无解。

**练习5：** 解不等式组：
```
4x - 3 ≥ 5
2x + 1 < 9
```

解：

解第一个不等式：4x ≥ 8，x ≥ 2

解第二个不等式：2x < 8，x < 4

不等式组变为：
```
x ≥ 2
x < 4
```

属于"大小小大中间找"，2 < 4。

解集是 2 ≤ x < 4。
