# 数轴

## 学习目标

- 认识数轴
- 会在数轴上表示有理数
- 利用数轴比较有理数的大小

## 数轴的三要素

数轴是规定了原点、正方向和单位长度的直线。

1. **原点**：表示0的点
2. **正方向**：通常规定向右为正方向
3. **单位长度**：选取适当的长度作为单位长度

```
     -3   -2   -1    0    1    2    3
    ---|----|----|----|----|----|----|--->
              负方向    |    正方向
                       原点
```

## 在数轴上表示数

- 正数在原点的右边
- 负数在原点的左边
- 0在原点

例：在数轴上表示 -2, 0, 3

```
     -2         0         3
    ---|--------|--------|--->
```

## 利用数轴比较大小

在数轴上，右边的点表示的数总比左边的点表示的数大。

- 3 > 0 > -2
- -1 > -3

## 数轴上的距离

数轴上两点之间的距离等于这两点所表示的数的差的绝对值。

例：数轴上表示 -2 和 3 的两点之间的距离

距离 = |3 - (-2)| = |3 + 2| = |5| = 5

## 练习

1. 在数轴上表示 -1, 2, 0
2. 比较大小：-4 和 -1
3. 数轴上 -3 和 2 之间的距离是多少？

## 小结

数轴是研究有理数的重要工具，三要素缺一不可：原点、正方向、单位长度。
