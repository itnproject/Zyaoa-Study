# 1.5.4 加法计算技巧

## 技巧一：相反数结合法

互为相反数的两个数先加，和为0。

这样可以简化计算。

比如：(-5)+(+3)+(+5)，先算(-5)+(+5)=0，再加3。

## 技巧二：同号结合法

正数和正数先加，负数和负数先加。

然后再把两个结果相加。

这样可以避免符号混乱。

## 技巧三：凑整法

能凑成整十整百的数先加。

这样计算更快。

比如：(-7)+(+3)+(+4)，先算(+3)+(+4)=7，再算(-7)+7=0。

## 技巧四：分母相同结合法

分数加法中，分母相同的先加。

这样可以避免通分。

## 技巧五：拆分法

把一个数拆成两个数的和。

然后分别相加。

比如：(-8)+(+5)，可以拆成(-8)+(+8)+(-3)=0+(-3)=-3。

## 例题讲解

**例1** 计算：(-15)+(+8)+(+15)+(-8)

**解：**

运用相反数结合法。

[(-15)+(+15)]+[(+8)+(-8)]

=0+0

=0

**答：** 0

**例2** 计算：(-3)+(+7)+(-5)+(+2)+(-4)+(+3)

**解：**

运用同号结合法。

负数：(-3)+(-5)+(-4)=-12

正数：(+7)+(+2)+(+3)=12

(-12)+(+12)=0

**答：** 0

**例3** 计算：(-9)+(+4)+(+5)+(-1)

**解：**

运用凑整法。

(+4)+(+5)=9

(-9)+9=0

0+(-1)=-1

**答：** -1

**例4** 计算：1/3+(-1/2)+2/3+(-1/2)

**解：**

运用分母相同结合法。

(1/3+2/3)+[(-1/2)+(-1/2)]

=1+(-1)

=0

**答：** 0

**例5** 计算：(-7)+(+4)

**解：**

运用拆分法。

(-7)+(+7)+(-3)

=0+(-3)

=-3

**答：** -3

## 常见错误

**错误1：相反数找错**

要找准互为相反数的两个数。

**错误2：同号结合时符号搞错**

同号结合时符号不变。

**错误3：凑整时算错**

凑整要确保凑的是整数。

**错误4：分母相同时分子算错**

分母相同，分子相加。

**错误5：拆分时搞错符号**

拆分后的两个数符号要正确。

## 练习题

**1.** 计算：(-12)+(+7)+(+12)+(-7)

**答案：** 0

**2.** 计算：(-4)+(+9)+(-3)+(+1)+(-2)+(-1)

**答案：** 0

**讲解：** 负数：(-4)+(-3)+(-2)+(-1)=-10，正数：(+9)+(+1)=10，(-10)+10=0。

**3.** 计算：(-6)+(+3)+(+3)+(-2)

**答案：** -2

**讲解：** (+3)+(+3)=6，(-6)+6=0，0+(-2)=-2。

**4.** 计算：2/5+(-1/3)+3/5+(-2/3)

**答案：** 0

**讲解：** (2/5+3/5)+[(-1/3)+(-2/3)]=1+(-1)=0。

**5.** 计算：(-9)+(+5)

**答案：** -4

**讲解：** (-9)+(+9)+(-4)=0+(-4)=-4。
