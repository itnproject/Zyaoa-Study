# 1.1.1 什么是正数

## 从生活说起

冬天看天气预报，温度显示 5°C，表示零上5度。

小明身高150厘米，比标准身高高出3厘米。

爸爸这个月收入比上个月多了2000元。

这些"高出"、"多了"、"零上"的量，在数学中用正数来表示。

## 正数的定义

**正数：大于0的数叫做正数。**

正数有三种写法：
- 带"+"号：+5、+3.14、+1/2
- 不带"+"号：5、3.14、1/2（最常用）
- 两种写法表示的是同一个数

+5 和 5 是完全一样的，只是写法不同。

## 正数的分类

正数包括三类：
- **正整数**：1、2、3、100、1000……
- **正分数**：1/2、3/4、5/6……
- **正小数**：0.5、3.14、2.718……

它们都大于0，所以都是正数。

## 例题讲解

**例1** 判断下列各数哪些是正数：-3，+5，0，-1/2，2.5

**解：**
大于0的数才是正数。
-3 小于0，不是正数。
+5 大于0，是正数。
0 既不是正数也不是负数。
-1/2 小于0，不是正数。
2.5 大于0，是正数。

**答：** +5 和 2.5 是正数。

**例2** 用正数表示：零上8°C，盈利500元，向东走3米

**解：**
零上8°C 记作 +8°C 或 8°C
盈利500元 记作 +500元 或 500元
向东走3米 记作 +3米 或 3米

**例3** 比较大小：+3 和 3 哪个大？

**解：**
+3 和 3 表示的是同一个数。
+号可以省略不写。
所以 +3 = 3，它们一样大。

## 常见错误

**错误1** 认为 +5 比 5 大

+5 和 5 是同一个数，只是写法不同。正号可以省略。

**错误2** 认为 0 是正数

0 既不是正数也不是负数，它是正数和负数的分界线。

**错误3** 认为只有整数才是正数

正数包括正整数、正分数、正小数。0.5、1/2 都是正数。

## 练习题

**1.** 下列各数中，正数有：-2，+7，0，-0.5，3/4，1.8

**答案：** +7、3/4、1.8

**讲解：** 大于0的数是正数。-2和-0.5小于0，0既不是正数也不是负数。

**2.** 用正数表示：温度上升5°C

**答案：** +5°C 或 5°C

**3.** 判断：+10 和 10 哪个大？

**答案：** 一样大

**讲解：** +10 和 10 是同一个数，正号可以省略。

**4.** 写出3个正数（至少包含一个分数和一个小数）

**答案：** 示例：5、1/3、0.75（答案不唯一）

**5.** 下列说法正确的是：
A. 0是最小的正数
B. +3比3大
C. 正数都大于0
D. 正数只有整数

**答案：** C

**讲解：** 正数的定义就是大于0的数。0不是正数，+3和3相等，正数还包括分数和小数。
