# 1.2.4 利用数轴比较大小

## 数轴上的大小规律

数轴上，越往右的数越大。

越往左的数越小。

这是数轴最基本的性质。

## 正数、0、负数的大小关系

正数都大于0。

负数都小于0。

正数大于一切负数。

## 两个负数比较大小

两个负数，在数轴上越靠左的越小。

绝对值大的负数反而小。

比如：-5 < -3，因为5>3，所以-5<-3。

## 例题讲解

**例1** 比较大小：-2和3

**解：**

-2是负数，3是正数。

正数大于一切负数。

所以-2 < 3。

**答：** -2 < 3

**例2** 比较大小：-5和-2

**解：**

两个都是负数。

在数轴上，-5在-2的左边。

越靠左的数越小。

或者：|-5|=5，|-2|=2，5>2，所以-5<-2。

**答：** -5 < -2

**例3** 比较大小：0和-3

**解：**

0大于一切负数。

-3是负数。

所以0 > -3。

**答：** 0 > -3

**例4** 将下列各数从小到大排列：-3，0，2，-1，5

**解：**

在数轴上从左到右依次是：-3，-1，0，2，5。

所以从小到大排列：-3 < -1 < 0 < 2 < 5。

**答：** -3 < -1 < 0 < 2 < 5

**例5** 比较大小：-4和-6

**解：**

两个都是负数。

|-4|=4，|-6|=6。

6>4，所以-6<-4。

或者：在数轴上，-6在-4的左边，所以-6<-4。

**答：** -4 > -6

## 常见错误

**错误1：认为-5比-3大**

负数比较大小，绝对值大的反而小。

-5 < -3。

**错误2：认为负数比0大**

0大于一切负数。

**错误3：忘记正数大于一切负数**

任何正数都大于任何负数。

不需要比较绝对值。

**错误4：多个数比较时顺序搞错**

最好画数轴辅助。

从左到右就是从小到大。

**错误5：混淆大小比较和绝对值比较**

比较数的大小看数轴位置。

比较绝对值看距离原点的远近。

## 练习题

**1.** 比较大小：-4和-1

**答案：** -4 < -1

**讲解：** 两个负数，绝对值大的反而小。4>1，所以-4<-1。

**2.** 比较大小：2和-5

**答案：** 2 > -5

**讲解：** 正数大于一切负数。

**3.** 比较大小：0和-10

**答案：** 0 > -10

**4.** 下列说法正确的是：
A. -10比-1大
B. 负数比0大
C. 正数大于一切负数
D. 两个负数，绝对值大的大

**答案：** C

**5.** 将下列各数从小到大排列：-3，0，2，-1，5

**答案：** -3 < -1 < 0 < 2 < 5

**讲解：** 数轴上从左到右依次增大。
