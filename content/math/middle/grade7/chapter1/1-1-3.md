# 1.1.3 0的特殊性

## 0到底是什么

0是一个很特殊的数。

它既不是正数，也不是负数。

0是正数和负数的分界线。

## 0不是正数

正数的定义是大于0的数。

0不可能大于它自己。

所以0不是正数。

## 0不是负数

负数的定义是小于0的数。

0不可能小于它自己。

所以0不是负数。

## 0是分界线

在数轴上，0在正数和负数中间。

正数在0的右边，负数在0的左边。

就像温度计上的0°C，上面是零上，下面是零下。

## 0在生活中的含义

0°C 不是没有温度，而是水的冰点。

海拔0米 不是没有高度，而是海平面的高度。

账户余额0元 不是没有账户，而是收支刚好相等。

## 例题讲解

**例1** 判断：0是正数吗？0是负数吗？

**解：**
正数要大于0，0不大于0，所以0不是正数。
负数要小于0，0不小于0，所以0不是负数。

**答：** 0既不是正数也不是负数。

**例2** 下列各数中，既不是正数也不是负数的是：-3，0，+5，-1/2

**解：**
-3 小于0，是负数。
0 既不是正数也不是负数。
+5 大于0，是正数。
-1/2 小于0，是负数。

**答：** 0

**例3** 温度从 -2°C 上升到 2°C，经过了多少度？

**解：**
从 -2°C 到 0°C，上升了2度。
从 0°C 到 2°C，上升了2度。
一共上升了 2 + 2 = 4度。

**答：** 4°C

## 常见错误

**错误1** 认为0是正数

0既不是正数也不是负数，它是分界线。

**错误2** 认为0没有意义

0有明确的含义，表示正负的分界点。

**错误3** 认为从-3到3只相差3

从-3到0相差3，从0到3相差3，一共相差6。

**1.** 0是正数还是负数？

**答案：** 都不是

**讲解：** 0是正数和负数的分界线，它既不是正数也不是负数。

B. 0是最大的负数

D. 0既是正数也是负数

**答案：** C

**5.** 从 -4 到 +4 一共相差多少？
