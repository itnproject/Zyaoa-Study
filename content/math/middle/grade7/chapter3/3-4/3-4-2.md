# 3.4.2 去分母解方程

## 一、从生活实例引入

想象一下你要分蛋糕。

一个蛋糕要分给几个人，每个人分到几分之一个蛋糕。

分数计算起来比较麻烦。

如果我们在方程中看到分数，也会觉得不好算。

这时候我们可以想办法去掉分母。

去掉分母的方法就是方程两边同时乘以分母的最小公倍数。

这样分数就变成了整数，计算起来就简单多了。

## 二、去分母的方法

去分母的方法很简单。

找到方程中所有分母的最小公倍数。

方程两边同时乘以这个最小公倍数。

这样所有的分母就都去掉了。

例：解方程x/2 + x/3 = 5。

分母是2和3，最小公倍数是6。

两边同时乘以6：6 × (x/2 + x/3) = 6 × 5。

即3x + 2x = 30。

5x = 30。

x = 6。

## 三、每一项都要乘以最小公倍数

去分母时最容易犯的错误就是漏乘。

方程的每一项都要乘以最小公倍数，不能漏掉任何一项。

特别是常数项，很多同学会忘记乘。

例：解方程x/4 + 2 = x/2。

分母是4和2，最小公倍数是4。

两边同时乘以4：4 × (x/4 + 2) = 4 × (x/2)。

注意每一项都要乘：x + 8 = 2x。

移项：8 = 2x - x。

x = 8。

## 四、分子是多项式的要加括号

当分子是一个多项式时，去分母后要给分子加括号。

这是因为分子是一个整体，不能分开。

例：解方程(x + 3)/2 = 5。

两边同时乘以2：x + 3 = 10。

x = 7。

例：解方程(2x - 1)/3 = 4。

两边同时乘以3：2x - 1 = 12。

2x = 13。

x = 6.5。

## 五、去完分母后的完整步骤

去完分母后，按照以下步骤继续解方程。

第一步：去括号（如果有括号）。

第二步：移项。

第三步：合并同类项。

第四步：系数化为1。

第五步：检验。

例：解方程(x + 1)/2 + (x - 1)/3 = 4。

第一步，去分母。分母2和3的最小公倍数是6。

两边同时乘以6：3(x + 1) + 2(x - 1) = 24。

第二步，去括号：3x + 3 + 2x - 2 = 24。

第三步，合并同类项：5x + 1 = 24。

第四步，移项：5x = 23。

第五步，系数化为1：x = 4.6。

第六步，检验。

左边：(4.6 + 1)/2 + (4.6 - 1)/3 = 5.6/2 + 3.6/3 = 2.8 + 1.2 = 4。

右边：4。

左边等于右边，正确。

## 六、例题讲解

例题1：解方程x/3 + x/6 = 3。

解：分母3和6的最小公倍数是6。

两边同时乘以6：2x + x = 18。

合并：3x = 18。

x = 6。

检验：6/3 + 6/6 = 2 + 1 = 3，正确。

例题2：解方程(x - 2)/4 = 3。

解：两边同时乘以4：x - 2 = 12。

x = 14。

检验：(14 - 2)/4 = 12/4 = 3，正确。

例题3：解方程x/2 + x/4 = 6。

解：分母2和4的最小公倍数是4。

两边同时乘以4：2x + x = 24。

3x = 24。

x = 8。

检验：8/2 + 8/4 = 4 + 2 = 6，正确。

例题4：解方程(2x + 1)/3 - (x - 1)/2 = 1。

解：分母3和2的最小公倍数是6。

两边同时乘以6：2(2x + 1) - 3(x - 1) = 6。

去括号：4x + 2 - 3x + 3 = 6。

合并：x + 5 = 6。

x = 1。

检验：左边(2 + 1)/3 - (1 - 1)/2 = 1 - 0 = 1，右边1，正确。

例题5：解方程(x + 3)/5 + (x - 2)/3 = 2。

解：分母5和3的最小公倍数是15。

两边同时乘以15：3(x + 3) + 5(x - 2) = 30。

去括号：3x + 9 + 5x - 10 = 30。

合并：8x - 1 = 30。

移项：8x = 31。

x = 31/8 = 3.875。

检验：左边(3.875 + 3)/5 + (3.875 - 2)/3 = 6.875/5 + 1.875/3 = 1.375 + 0.625 = 2，右边2，正确。

## 七、常见错误

错误1：漏乘常数项。

纠正：方程的每一项都要乘以最小公倍数，包括常数项。

错误2：分子是多项式时忘记加括号。

纠正：分子是多项式时，去分母后要给分子加括号。

错误3：找错最小公倍数。

纠正：最小公倍数要找准，可以列出来验证一下。

错误4：去分母后符号搞错。

纠正：去分母时注意括号前的符号，是负号要变号。

错误5：检验时计算错误。

纠正：检验时分数计算要仔细，一步一步算。

## 八、练习题

练习1：解方程x/2 + x/5 = 7。

答案：最小公倍数10。5x + 2x = 70，7x = 70，x = 10。检验：10/2 + 10/5 = 5 + 2 = 7，正确。

练习2：解方程(x + 1)/3 = 4。

答案：两边乘以3：x + 1 = 12，x = 11。检验：(11 + 1)/3 = 12/3 = 4，正确。

练习3：解方程x/3 + x/4 = 7。

答案：最小公倍数12。4x + 3x = 84，7x = 84，x = 12。检验：12/3 + 12/4 = 4 + 3 = 7，正确。

练习4：解方程(3x - 1)/2 + (x + 2)/4 = 5。

答案：最小公倍数4。2(3x - 1) + (x + 2) = 20。6x - 2 + x + 2 = 20。7x = 20，x = 20/7。检验：左边(60/7 - 1)/2 + (20/7 + 2)/4 = (53/7)/2 + (34/7)/4 = 53/14 + 34/28 = 53/14 + 17/14 = 70/14 = 5，右边5，正确。

练习5：解方程(x - 3)/6 + (x + 1)/2 = 3。

答案：最小公倍数6。(x - 3) + 3(x + 1) = 18。x - 3 + 3x + 3 = 18。4x = 18，x = 4.5。检验：左边(4.5 - 3)/6 + (4.5 + 1)/2 = 1.5/6 + 5.5/2 = 0.25 + 2.75 = 3，右边3，正确。
