# 3.1.2 方程的解

## 一、从生活实例引入

我们来玩一个猜数游戏。

我心里想了一个数，把这个数加上5以后等于12。

你能猜出我心里想的是几吗？

你可以一个一个地试。

试1：1 + 5 = 6，不等于12，不对。

试2：2 + 5 = 7，不等于12，不对。

试3：3 + 5 = 8，不等于12，不对。

试7：7 + 5 = 12，等于12，对了！

这个7就是我们要求的数。

在方程里，这个让方程左右两边相等的数，就叫做方程的解。

## 二、方程的解的定义

方程的解就是使方程左右两边相等的未知数的值。

也就是说，把这个数代入方程后，左边算出来的结果和右边算出来的结果一样。

比如说方程x + 5 = 12。

把x = 7代入左边，7 + 5 = 12。

右边就是12。

左边等于右边，所以x = 7是这个方程的解。

## 三、如何检验一个数是不是方程的解

检验一个数是不是方程的解，步骤很简单。

第一步：把这个数代入方程的左边，算出结果。

第二步：把这个数代入方程的右边，算出结果。

第三步：比较左右两边的结果，如果相等就是解，不相等就不是解。

我们来看一个例子。

检验x = 3是不是方程2x + 1 = 7的解。

把x = 3代入左边：2 × 3 + 1 = 6 + 1 = 7。

右边就是7。

左边等于右边，所以x = 3是方程的解。

再来看一个例子。

检验x = 4是不是方程3x - 2 = 10的解。

把x = 4代入左边：3 × 4 - 2 = 12 - 2 = 10。

右边就是10。

左边等于右边，所以x = 4是方程的解。

再来看一个不是解的例子。

检验x = 2是不是方程5x + 3 = 18的解。

把x = 2代入左边：5 × 2 + 3 = 10 + 3 = 13。

右边就是18。

左边13不等于右边18，所以x = 2不是方程的解。

## 四、解方程和方程的解的区别

这两个概念很容易混淆，一定要分清楚。

方程的解是一个数，是结果。

解方程是一个过程，是求这个结果的过程。

打个比方，方程的解就像是目的地。

解方程就像是从出发地走到目的地的路。

比如说方程x + 3 = 8。

方程的解是x = 5，这是一个数，是结果。

解方程的过程是：x + 3 = 8，两边同时减去3，得到x = 5。

解方程是过程，方程的解是结果。

## 五、例题讲解

例题1：检验x = 6是不是方程x - 4 = 2的解。

解：把x = 6代入左边：6 - 4 = 2。

右边就是2。

左边等于右边，所以x = 6是方程的解。

例题2：检验x = 5是不是方程2x + 3 = 12的解。

解：把x = 5代入左边：2 × 5 + 3 = 10 + 3 = 13。

右边就是12。

左边13不等于右边12，所以x = 5不是方程的解。

例题3：检验x = 7是不是方程3x - 6 = 15的解。

解：把x = 7代入左边：3 × 7 - 6 = 21 - 6 = 15。

右边就是15。

左边等于右边，所以x = 7是方程的解。

例题4：检验x = 2是不是方程4x + 5 = 13的解。

解：把x = 2代入左边：4 × 2 + 5 = 8 + 5 = 13。

右边就是13。

左边等于右边，所以x = 2是方程的解。

例题5：检验x = 10是不是方程x ÷ 2 + 3 = 8的解。

解：把x = 10代入左边：10 ÷ 2 + 3 = 5 + 3 = 8。

右边就是8。

左边等于右边，所以x = 10是方程的解。

## 六、常见错误

错误1：只代入左边计算，不代入右边比较。

纠正：检验必须左右两边都算，然后比较是否相等。

错误2：计算错误导致判断错误。

纠正：代入计算时要仔细，一步一步算，不要跳步。

错误3：把解方程和方程的解搞混。

纠正：方程的解是一个数，解方程是一个过程，两者不一样。

错误4：认为方程只有一个解。

纠正：有些方程有多个解，有些方程无解，不能一概而论。

错误5：检验时忘记写结论。

纠正：检验完一定要写清楚是解还是不是解，不能只算不写结论。

## 七、练习题

练习1：检验x = 8是不是方程x + 7 = 15的解。

答案：把x = 8代入左边：8 + 7 = 15。右边就是15。左边等于右边，所以x = 8是方程的解。

练习2：检验x = 3是不是方程4x - 5 = 7的解。

答案：把x = 3代入左边：4 × 3 - 5 = 12 - 5 = 7。右边就是7。左边等于右边，所以x = 3是方程的解。

练习3：检验x = 6是不是方程2x + 4 = 15的解。

答案：把x = 6代入左边：2 × 6 + 4 = 12 + 4 = 16。右边就是15。左边16不等于右边15，所以x = 6不是方程的解。

练习4：检验x = 9是不是方程3x - 8 = 19的解。

答案：把x = 9代入左边：3 × 9 - 8 = 27 - 8 = 19。右边就是19。左边等于右边，所以x = 9是方程的解。

练习5：检验x = 4是不是方程5x ÷ 2 = 10的解。

答案：把x = 4代入左边：5 × 4 ÷ 2 = 20 ÷ 2 = 10。右边就是10。左边等于右边，所以x = 4是方程的解。
