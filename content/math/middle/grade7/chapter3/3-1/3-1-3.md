# 3.1.3 一元一次方程的定义

## 一、元与次的含义

在学一元一次方程之前，我们先弄懂两个词的意思。

元就是未知数的意思。

一个方程里有几个不同的未知数，就是几元。

比如说x + 3 = 7，只有一个未知数x，就是一元。

比如说x + y = 10，有两个未知数x和y，就是二元。

次就是未知数的最高次数的意思。

未知数的次数就是未知数上面那个小数字。

比如说x²，x的次数就是2。

比如说x³，x的次数就是3。

比如说x，x的次数就是1，通常不写出来。

## 二、一元一次方程的定义

一元一次方程就是只含有一个未知数，且未知数的次数都是1的方程。

这里有两个关键词：一个未知数、次数是1。

一个未知数就是说方程里只能有一种字母，不能有两种或更多。

次数是1就是说未知数不能有平方、立方等，只能是一次方。

一元一次方程的标准形式是ax + b = 0，其中a不等于0。

a不等于0这个条件很重要，如果a等于0，未知数x就没有了。

## 三、判断哪些是一元一次方程

例1：2x + 3 = 7

这个方程只有一个未知数x，是一元。

x的次数是1，是一次。

所以它是一元一次方程。

例2：x² + 2x = 8

这个方程只有一个未知数x，是一元。

但是x有平方，最高次数是2，不是一次。

所以它不是一元一次方程。

例3：x + y = 10

这个方程有两个未知数x和y，是二元。

不是一元，所以它不是一元一次方程。

例4：3x - 5 = 0

这个方程只有一个未知数x，是一元。

x的次数是1，是一次。

所以它是一元一次方程。

例5：5 = 10

这个方程没有未知数。

不是一元，所以它不是一元一次方程。

例6：4/x + 2 = 6

这个方程只有一个未知数x，是一元。

但是x在分母上，次数不是1。

所以它不是一元一次方程。

例7：2(x + 3) = 10

这个方程只有一个未知数x，是一元。

去括号后x的次数还是1，是一次。

所以它是一元一次方程。

例8：|x| + 3 = 7

这个方程只有一个未知数x，是一元。

但是x有绝对值符号，不是标准的一次形式。

所以它不是一元一次方程。

## 四、标准形式ax + b = 0

一元一次方程都可以化成ax + b = 0的形式。

其中a是x的系数，a不能等于0。

b是常数项，可以是任何数。

我们来看几个例子。

例1：2x + 3 = 7

移项得2x + 3 - 7 = 0，即2x - 4 = 0。

这里a = 2，b = -4。

例2：5x = 15

移项得5x - 15 = 0。

这里a = 5，b = -15。

例3：3 - x = 2

移项得-x + 3 - 2 = 0，即-x + 1 = 0。

这里a = -1，b = 1。

## 五、a不等于0的重要性

为什么a不能等于0呢？

我们来看看如果a = 0会怎样。

假设方程是0x + 3 = 0。

0乘以任何数都是0，所以0x = 0。

方程变成0 + 3 = 0，即3 = 0。

这显然是不成立的，矛盾了。

所以当a = 0时，方程要么无解，要么有无数个解。

这就不是一元一次方程了。

## 六、例题讲解

例题1：判断3x + 5 = 20是不是一元一次方程。

解：这个方程只有一个未知数x。

x的次数是1。

所以它是一元一次方程。

例题2：判断x² - 4 = 0是不是一元一次方程。

解：这个方程只有一个未知数x。

但是x的次数是2，不是1。

所以它不是一元一次方程。

例题3：判断2x + 3y = 12是不是一元一次方程。

解：这个方程有两个未知数x和y。

不是一元。

所以它不是一元一次方程。

例题4：判断4x - 8 = 0是不是一元一次方程。

解：这个方程只有一个未知数x。

x的次数是1。

所以它是一元一次方程。

例题5：判断5 = 5是不是一元一次方程。

解：这个方程没有未知数。

不是一元。

所以它不是一元一次方程。

## 七、常见错误

错误1：看到有x就认为是一元一次方程。

纠正：还要看x的次数是不是1，还要看有没有其他未知数。

错误2：认为x² + x = 6是一元一次方程。

纠正：x的最高次数是2，不是一次，所以不是。

错误3：认为x + y = 5是一元一次方程。

纠正：有两个未知数，是二元，不是一元。

错误4：忘记a不等于0这个条件。

纠正：标准形式中a必须不等于0，否则就不是一元一次方程。

错误5：认为1/x + 2 = 5是一元一次方程。

纠正：x在分母上，次数不是1，所以不是。

## 八、练习题

练习1：判断7x - 3 = 18是不是一元一次方程。

答案：是一元一次方程。只有一个未知数x，x的次数是1。

练习2：判断3x² + 2x = 5是不是一元一次方程。

答案：不是一元一次方程。x的最高次数是2，不是1。

练习3：判断x + 2y = 8是不是一元一次方程。

答案：不是一元一次方程。有两个未知数x和y，是二元。

练习4：判断6x = 0是不是一元一次方程。

答案：是一元一次方程。只有一个未知数x，x的次数是1，a = 6不等于0。

练习5：判断2x + 3 = 2x + 5是不是一元一次方程。

答案：不是一元一次方程。化简后3 = 5，矛盾，无解，不符合一元一次方程的定义。
