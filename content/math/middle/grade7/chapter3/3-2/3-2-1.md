# 3.2.1 等式的性质1

## 一、从生活实例引入

想象一下你家里的天平。

天平左边放了一个100克的砝码。

天平右边也放了一个100克的砝码。

天平平衡了，说明左右两边一样重。

现在你在左边再加一个50克的砝码。

为了保持平衡，你必须在右边也加一个50克的砝码。

加了以后天平还是平衡的。

这就是等式的性质1在生活中的体现。

## 二、等式的性质1

等式的性质1：等式两边同时加或减同一个数，等式仍然成立。

用字母表示就是：如果a = b，那么a + c = b + c，a - c = b - c。

这个性质很好理解。

天平两边一样重，同时加同样重的东西，还是平衡的。

天平两边一样重，同时减同样重的东西，还是平衡的。

## 三、用具体数字验证

我们来看几个具体的例子。

例1：3 = 3，这是成立的。

两边同时加5：3 + 5 = 3 + 5，即8 = 8，仍然成立。

两边同时减2：3 - 2 = 3 - 2，即1 = 1，仍然成立。

例2：7 = 7，这是成立的。

两边同时加10：7 + 10 = 7 + 10，即17 = 17，仍然成立。

两边同时减4：7 - 4 = 7 - 4，即3 = 3，仍然成立。

例3：12 = 12，这是成立的。

两边同时加8：12 + 8 = 12 + 8，即20 = 20，仍然成立。

两边同时减6：12 - 6 = 12 - 6，即6 = 6，仍然成立。

## 四、性质1在解方程中的应用

等式的性质1是解方程的重要工具。

我们来看一个方程：x + 5 = 12。

我们想要求出x是多少。

根据性质1，两边同时减去5。

左边：x + 5 - 5 = x。

右边：12 - 5 = 7。

所以x = 7。

再看一个方程：x - 3 = 8。

根据性质1，两边同时加上3。

左边：x - 3 + 3 = x。

右边：8 + 3 = 11。

所以x = 11。

## 五、例题讲解

例题1：解方程x + 7 = 15。

解：两边同时减去7。

x + 7 - 7 = 15 - 7。

x = 8。

检验：把x = 8代入原方程，左边8 + 7 = 15，右边15，相等。

例题2：解方程x - 4 = 9。

解：两边同时加上4。

x - 4 + 4 = 9 + 4。

x = 13。

检验：把x = 13代入原方程，左边13 - 4 = 9，右边9，相等。

例题3：解方程x + 12 = 20。

解：两边同时减去12。

x + 12 - 12 = 20 - 12。

x = 8。

检验：把x = 8代入原方程，左边8 + 12 = 20，右边20，相等。

例题4：解方程x - 6 = 3。

解：两边同时加上6。

x - 6 + 6 = 3 + 6。

x = 9。

检验：把x = 9代入原方程，左边9 - 6 = 3，右边3，相等。

例题5：解方程15 + x = 25。

解：两边同时减去15。

15 + x - 15 = 25 - 15。

x = 10。

检验：把x = 10代入原方程，左边15 + 10 = 25，右边25，相等。

## 六、常见错误

错误1：只在方程的一边加减，忘记另一边也要加减。

纠正：等式的性质要求两边同时进行相同的运算，不能只做一边。

错误2：加减的数不一样。

纠正：两边必须加减同一个数，不能左边减5右边减3。

错误3：计算错误。

纠正：做加减法时要仔细，一步一步算，不要跳步。

错误4：忘记写等号。

纠正：每一步都要写等号，保持等式的形式。

错误5：检验时不代入原方程。

纠正：检验一定要代入最开始的方程，不能代入中间步骤。

## 七、练习题

练习1：解方程x + 9 = 16。

答案：两边同时减去9，x = 16 - 7 = 7。检验：7 + 9 = 16，正确。

练习2：解方程x - 5 = 12。

答案：两边同时加上5，x = 12 + 5 = 17。检验：17 - 5 = 12，正确。

练习3：解方程x + 20 = 35。

答案：两边同时减去20，x = 35 - 20 = 15。检验：15 + 20 = 35，正确。

练习4：解方程x - 8 = 7。

答案：两边同时加上8，x = 7 + 8 = 15。检验：15 - 8 = 7，正确。

练习5：解方程25 + x = 40。

答案：两边同时减去25，x = 40 - 25 = 15。检验：25 + 15 = 40，正确。
