# 正数和负数

## 引入

生活中我们经常遇到具有相反意义的量：

- 温度：零上5°C 与 零下3°C
- 海拔：高于海平面100米 与 低于50米
- 收入：盈利200元 与 亏损80元

## 定义

**正数**：大于0的数，如 5、3.14、100

**负数**：小于0的数，前面加负号（-），如 -3、-2.5、-80

**0**：既不是正数也不是负数

## 数轴的初步感受

把正数和负数放在一条直线上：

```
  -3   -2   -1    0    1    2    3
---|----|----|----|----|----|----|---
         负数    |    正数
```

- 0的左边是负数，右边是正数
- 越往右数越大，越往左数越小

## 常见误区

- 0 是正数还是负数？都不是
- 带 + 号的一定是正数吗？是的
- -0 等于什么？等于 0

## 练习

1. 判断下列各数是正数、负数还是0：-5, 0, 3.14, -2.5, 100
2. 在数轴上表示下列各数：-2, 0, 3, -1
3. 比较大小：-3 和 2 哪个大？

## 小结

正数和负数是用来表示具有相反意义的量的数学工具。0既不是正数也不是负数，它是正数和负数的分界点。
