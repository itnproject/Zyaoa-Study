# 有理数

## 学习目标

- 理解有理数的概念
- 掌握有理数的分类
- 会比较有理数的大小

## 有理数的定义

整数和分数统称为有理数。

有理数包括：
- **正整数**：1, 2, 3, ...
- **零**：0
- **负整数**：-1, -2, -3, ...
- **正分数**：1/2, 3/4, ...
- **负分数**：-1/2, -3/4, ...

## 有理数的分类

```
有理数
├── 整数
│   ├── 正整数（1, 2, 3, ...）
│   ├── 零（0）
│   └── 负整数（-1, -2, -3, ...）
── 分数
    ├── 正分数（1/2, 3/4, ...）
    └── 负分数（-1/2, -3/4, ...）
```

## 有理数的大小比较

### 数轴法

在数轴上，右边的数总比左边的数大。

### 规则

1. 正数 > 0 > 负数
2. 两个正数：绝对值大的大
3. 两个负数：绝对值大的反而小

例：比较 -3 和 -5
- |-3| = 3，|-5| = 5
- 3 < 5，所以 -3 > -5

## 相反数

只有符号不同的两个数互为相反数。

- 5 的相反数是 -5
- -3 的相反数是 3
- 0 的相反数是 0

## 绝对值

一个数在数轴上到原点的距离叫做这个数的绝对值。

- |5| = 5
- |-3| = 3
- |0| = 0
